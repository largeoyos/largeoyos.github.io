## 第七节：综合应用——视觉里程计

这是整个系列的收官节。我们要把前六节的所有工具——ORB特征匹配、对极几何、光流——全部串联成一个有实际意义的系统：**视觉里程计（Visual Odometry，VO）**。

视觉里程计要回答的问题是：**只用一个摄像头，能不能估计出相机（或者搭载它的机器人/无人机/自动驾驶车）在空间中走过的轨迹？**

答案是可以的，而且原理此前已经全部学过了。

---

### 什么是视觉里程计

"里程计"这个词来自汽车仪表盘，原本指用车轮转数来估计行驶距离的装置。视觉里程计做的事情类似，只不过它的"传感器"是摄像头——通过分析连续帧之间图像的变化，推断相机的运动。

它的输出是一条**相机轨迹**：每一帧对应一个位置和朝向，把所有帧的位置连起来，就得到了相机走过的路径。

视觉里程计是视觉 SLAM（Simultaneous Localization and Mapping，即时定位与地图构建）的核心子模块。完整的 SLAM 系统在 VO 的基础上还增加了回环检测、地图优化等模块，但 VO 是基础中的基础。

---

### 整体架构

一个完整的单目视觉里程计系统，流程如下：

```
视频帧流
    ↓
┌─────────────────────────────────────────┐
│  前端（特征追踪）                         │
│  ORB检测 → LK追踪 → 剔除外点            │
└─────────────────┬───────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│  运动估计                                │
│  本质矩阵E → 分解R和t → 三角化得到3D点   │
└─────────────────┬───────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│  尺度恢复（单目的难题）                   │
│  参考帧间距 or 已知结构 or 融合IMU        │
└─────────────────┬───────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│  位姿累积                                │
│  T_world = T_world × T_relative          │
└─────────────────┬───────────────────────┘
                  ↓
            轨迹输出与可视化
```

我们从第一步开始，逐模块实现。

### 模块一：前端特征追踪

前端负责在连续帧之间找到可靠的像素对应关系。这里有两种策略，各有优劣。

**策略A：ORB 检测+匹配**，每帧重新检测 ORB 特征点，用 BFMatcher 跨帧匹配。优点是匹配质量高、对大运动鲁棒；缺点是每帧都要重新检测描述子，计算量较大。

**策略B：LK 光流追踪**，第一帧检测角点，后续帧用 LK 追踪这些点的位置。优点是速度快、轨迹连续；缺点是追踪失败时需要重新初始化，长时间追踪会有漂移。

实际工程中通常用策略B作为主干，当追踪点数量不足时触发策略A重新初始化。我们按这个思路来实现：

```python
import cv2
import numpy as np
from collections import deque
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

class FeatureTracker:
    """
    前端特征追踪器：用 ShiTomasi + LK 追踪特征点
    当追踪点数量不足时，自动重新检测
    """

    def __init__(self, min_points=50, max_points=200):
        self.min_points = min_points   # 最少保留点数，低于此值触发重新检测
        self.max_points = max_points   # 最多追踪点数

        self.shi_tomasi_params = dict(
            maxCorners=max_points,
            qualityLevel=0.01,
            minDistance=10,
            blockSize=7
        )
        self.lk_params = dict(
            winSize=(21, 21),
            maxLevel=3,
            criteria=(cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 30, 0.01)
        )

        self.prev_gray  = None
        self.prev_points = None

    def detect(self, gray):
        """在当前帧重新检测角点"""
        points = cv2.goodFeaturesToTrack(gray, mask=None, **self.shi_tomasi_params)
        return points

    def track(self, curr_gray):
        """
        追踪上一帧的特征点到当前帧
        返回：上一帧的有效点，当前帧对应的点
        """
        # 第一帧，直接检测
        if self.prev_points is None or len(self.prev_points) < self.min_points:
            self.prev_points = self.detect(curr_gray)
            self.prev_gray = curr_gray.copy()
            return None, None

        # LK 追踪：前向
        curr_points, status, _ = cv2.calcOpticalFlowPyrLK(
            self.prev_gray, curr_gray,
            self.prev_points, None, **self.lk_params
        )

        # 反向验证（前向-反向误差检验）：
        # 用追踪到的点反向追踪回上一帧，
        # 如果反向结果和原始点距离超过阈值，说明追踪不可靠
        prev_points_back, status_back, _ = cv2.calcOpticalFlowPyrLK(
            curr_gray, self.prev_gray,
            curr_points, None, **self.lk_params
        )

        # 计算前向-反向误差
        fb_error = np.abs(self.prev_points - prev_points_back).max(axis=2)

        # 同时满足：前向成功 + 反向误差小于1像素
        good_mask = (status.ravel() == 1) & (fb_error.ravel() < 1.0)

        good_prev = self.prev_points[good_mask]
        good_curr = curr_points[good_mask]

        # 更新状态
        self.prev_gray   = curr_gray.copy()
        self.prev_points = good_curr.reshape(-1, 1, 2)

        # 追踪点太少时补充新点
        if len(good_curr) < self.min_points:
            new_points = self.detect(curr_gray)
            if new_points is not None:
                self.prev_points = np.vstack([
                    self.prev_points,
                    new_points
                ])

        return good_prev, good_curr
```

### 模块二：运动估计

有了两帧之间的像素对应点，用第三节学过的本质矩阵来估计相对运动：

```python
class MotionEstimator:
    """
    从特征点对应关系估计两帧之间的相对位姿（R, t）
    """

    def __init__(self, K):
        """
        K: 相机内参矩阵 (3x3)
        [[fx, 0, cx],
         [0, fy, cy],
         [0,  0,  1]]
        """
        self.K = K

    def estimate(self, pts1, pts2):
        """
        输入：两帧中对应的像素坐标
        输出：旋转矩阵R，平移方向t（无尺度），内点掩膜
        """
        if len(pts1) < 5:
            return None, None, None

        # 估计本质矩阵（需要内参K）
        # threshold=1.0 对应1像素的重投影误差阈值
        E, mask = cv2.findEssentialMat(
            pts1, pts2, self.K,
            method=cv2.RANSAC,
            prob=0.999,
            threshold=1.0
        )

        if E is None:
            return None, None, None

        # 从E中恢复R和t
        # recoverPose 内部做SVD分解+手性检验
        # 返回通过手性检验的内点数量
        n_inliers, R, t, mask_pose = cv2.recoverPose(
            E, pts1, pts2, self.K, mask=mask
        )

        if n_inliers < 10:  # 内点太少，运动估计不可靠
            return None, None, None

        return R, t, mask_pose.ravel().astype(bool)

    def triangulate(self, pts1, pts2, R, t):
        """
        三角化：从两帧的像素坐标和相对位姿，恢复3D点坐标
        用于后续的尺度估计
        """
        # 构建投影矩阵 P = K @ [R|t]
        # 第一帧设为世界坐标系原点：P1 = K @ [I|0]
        P1 = self.K @ np.hstack([np.eye(3), np.zeros((3,1))])
        # 第二帧：P2 = K @ [R|t]
        P2 = self.K @ np.hstack([R, t])

        # OpenCV 的三角化函数
        pts1_h = pts1.T.astype(np.float64)  # (2, N)
        pts2_h = pts2.T.astype(np.float64)  # (2, N)

        points_4d = cv2.triangulatePoints(P1, P2, pts1_h, pts2_h)

        # 从齐次坐标转换为3D坐标，除以第四维
        points_3d = (points_4d[:3] / points_4d[3]).T  # (N, 3)

        # 只保留在相机前方的点（Z > 0）
        valid = points_3d[:, 2] > 0
        return points_3d, valid
```

### 模块三：尺度恢复

单目相机的尺度不确定性是视觉里程计最棘手的问题。最简单的处理方式是**固定尺度**——假设每帧之间相机的移动距离是一个固定值（比如1个单位），这样整个轨迹的形状是正确的，只是绝对尺寸不知道。

更好的方式是用**三角化的3D点来传播尺度**：如果我们知道上一次估计的两帧之间的绝对距离（比如通过IMU或已知场景尺寸），可以把当前帧新三角化出来的点和上一帧已知的3D点做比较，从而把尺度传递下去。

```python
def recover_scale(points_3d_prev, points_3d_curr, valid_prev, valid_curr):
    """
    通过比较相邻两次三角化结果的3D点间距来恢复尺度
    原理：同一批3D点，在两次三角化中得到的相对距离应该相同
    scale = (上次三角化的点间距) / (本次三角化的点间距)
    """
    # 找到两次都有效的公共点
    common = valid_prev & valid_curr
    if common.sum() < 3:
        return 1.0  # 无法估计，返回单位尺度

    p_prev = points_3d_prev[common]
    p_curr = points_3d_curr[common]

    # 计算所有点对之间的距离
    # 用中位数而不是均值，对异常点更鲁棒
    ratios = []
    n = min(len(p_prev), 50)  # 最多用50对点
    for i in range(n - 1):
        d_prev = np.linalg.norm(p_prev[i] - p_prev[i+1])
        d_curr = np.linalg.norm(p_curr[i] - p_curr[i+1])
        if d_curr > 1e-6:
            ratios.append(d_prev / d_curr)

    if not ratios:
        return 1.0

    return float(np.median(ratios))
```

### 模块四：位姿累积与轨迹构建

每帧估计出的是相对于上一帧的局部运动 (Rrel,trel)，需要把它们累积成相对于第一帧（世界坐标系）的全局位姿：

```python
class PoseAccumulator:
    """
    把每帧的局部相对运动累积成全局轨迹
    """

    def __init__(self):
        # 当前相机在世界坐标系中的位姿
        # 用 4x4 齐次变换矩阵表示
        self.T_world = np.eye(4)  # 初始位置是世界坐标系原点

        # 记录所有历史位置，用于可视化
        self.trajectory = [self.T_world[:3, 3].copy()]

    def update(self, R_rel, t_rel, scale=1.0):
        """
        输入相对旋转R_rel和相对平移t_rel（带尺度）
        更新全局位姿
        """
        # 构建相对运动的 4x4 变换矩阵
        T_rel = np.eye(4)
        T_rel[:3, :3] = R_rel
        T_rel[:3,  3] = t_rel.ravel() * scale

        # 位姿累积：T_world = T_world × T_rel
        # 注意矩阵乘法的顺序：右乘 = 在当前坐标系下的相对运动
        self.T_world = self.T_world @ T_rel

        # 记录当前位置（变换矩阵的第四列的前三行）
        position = self.T_world[:3, 3].copy()
        self.trajectory.append(position)

        return position

    def get_trajectory(self):
        return np.array(self.trajectory)
```

### 完整系统集成

把所有模块串联起来，构成完整的视觉里程计系统：

```python
class MonocularVO:
    """
    单目视觉里程计完整实现
    """

    def __init__(self, K, min_track_points=50):
        self.K = K
        self.tracker   = FeatureTracker(min_points=min_track_points)
        self.estimator = MotionEstimator(K)
        self.accumulator = PoseAccumulator()

        self.prev_points_3d = None  # 上一帧三角化的3D点
        self.frame_idx = 0

        # 统计信息
        self.stats = {
            'n_tracked': [],
            'n_inliers': [],
            'scales':    []
        }

    def process_frame(self, frame):
        """
        处理一帧图像，返回当前相机位置
        """
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

        # Step 1：特征追踪
        pts_prev, pts_curr = self.tracker.track(gray)

        if pts_prev is None or len(pts_prev) < 5:
            self.frame_idx += 1
            return self.accumulator.get_trajectory()[-1], frame

        # Step 2：运动估计
        R, t, inlier_mask = self.estimator.estimate(
            pts_prev.reshape(-1, 2),
            pts_curr.reshape(-1, 2)
        )

        if R is None:
            self.frame_idx += 1
            return self.accumulator.get_trajectory()[-1], frame

        # Step 3：三角化当前帧的3D点（用于尺度估计）
        pts_prev_in = pts_prev.reshape(-1,2)[inlier_mask]
        pts_curr_in = pts_curr.reshape(-1,2)[inlier_mask]

        points_3d_curr, valid_curr = self.estimator.triangulate(
            pts_prev_in, pts_curr_in, R, t
        )

        # Step 4：尺度恢复
        scale = 1.0  # 默认单位尺度
        if self.prev_points_3d is not None and len(self.prev_points_3d) > 0:
            n = min(len(self.prev_points_3d), len(points_3d_curr))
            valid_prev = np.ones(n, dtype=bool)  # 简化：假设上次的点都有效
            valid_curr_sub = valid_curr[:n]
            scale = recover_scale(
                self.prev_points_3d[:n],
                points_3d_curr[:n],
                valid_prev,
                valid_curr_sub
            )
            # 尺度异常值过滤：尺度突变通常意味着估计出错
            scale = np.clip(scale, 0.1, 10.0)

        self.prev_points_3d = points_3d_curr[valid_curr]

        # Step 5：位姿累积
        position = self.accumulator.update(R, t, scale)

        # 记录统计数据
        self.stats['n_tracked'].append(len(pts_prev))
        self.stats['n_inliers'].append(inlier_mask.sum())
        self.stats['scales'].append(scale)

        # 在图像上画出追踪点和运动箭头
        vis_frame = self.visualize_tracking(frame, pts_prev, pts_curr, inlier_mask)

        self.frame_idx += 1
        return position, vis_frame

    def visualize_tracking(self, frame, pts_prev, pts_curr, inlier_mask):
        """在图像上可视化追踪状态"""
        vis = frame.copy()
        for i, (prev, curr) in enumerate(zip(
            pts_prev.reshape(-1,2),
            pts_curr.reshape(-1,2)
        )):
            if inlier_mask[i]:
                # 内点：绿色箭头
                cv2.arrowedLine(vis,
                    tuple(prev.astype(int)),
                    tuple(curr.astype(int)),
                    (0, 255, 0), 1, tipLength=0.4)
                cv2.circle(vis, tuple(curr.astype(int)), 3, (0,255,0), -1)
            else:
                # 外点（被RANSAC剔除）：红色
                cv2.circle(vis, tuple(curr.astype(int)), 3, (0,0,255), -1)

        # 显示统计信息
        n_in = inlier_mask.sum()
        n_total = len(inlier_mask)
        cv2.putText(vis,
            f"Frame:{self.frame_idx}  Track:{n_total}  Inlier:{n_in}({n_in/n_total*100:.0f}%)",
            (10, 30), cv2.FONT_HERSHEY_SIMPLEX, 0.6, (255,255,255), 2)

        return vis

def run_vo_on_video(video_path, K):
    """
    在视频文件上运行视觉里程计，实时显示轨迹
    """
    cap = cv2.VideoCapture(video_path)
    vo  = MonocularVO(K)

    # 创建轨迹画布（俯视图，XZ平面）
    traj_canvas = np.zeros((600, 600, 3), dtype=np.uint8)
    canvas_center = np.array([300, 300])
    traj_scale = 5.0   # 轨迹缩放系数（调整使轨迹填满画布）

    while True:
        ret, frame = cap.read()
        if not ret:
            break

        position, vis_frame = vo.process_frame(frame)

        # 在轨迹画布上画点（俯视XZ平面）
        # X 是横向，Z 是前向
        px = int(canvas_center[0] + position[0] * traj_scale)
        pz = int(canvas_center[1] - position[2] * traj_scale)  # Z轴向上所以取负

        if 0 <= px < 600 and 0 <= pz < 600:
            cv2.circle(traj_canvas, (px, pz), 2, (0, 255, 0), -1)

        # 画坐标轴参考
        cv2.line(traj_canvas, (300,0), (300,600), (50,50,50), 1)
        cv2.line(traj_canvas, (0,300), (600,300), (50,50,50), 1)
        cv2.circle(traj_canvas, (px, pz), 5, (0,0,255), -1)  # 当前位置红点

        # 显示两个窗口
        cv2.imshow('Visual Odometry - Tracking', vis_frame)
        cv2.imshow('Visual Odometry - Trajectory (Top View)', traj_canvas)

        if cv2.waitKey(30) & 0xFF == ord('q'):
            break

    cap.release()
    cv2.destroyAllWindows()

    # 输出最终的3D轨迹
    trajectory = vo.accumulator.get_trajectory()
    plot_trajectory_3d(trajectory)
    return trajectory

def plot_trajectory_3d(trajectory):
    """绘制完整的3D轨迹"""
    fig = plt.figure(figsize=(10, 8))
    ax  = fig.add_subplot(111, projection='3d')

    x = trajectory[:, 0]
    y = trajectory[:, 1]
    z = trajectory[:, 2]

    # 用颜色编码时间顺序（蓝=开始，红=结束）
    n = len(trajectory)
    colors = plt.cm.coolwarm(np.linspace(0, 1, n))

    for i in range(n - 1):
        ax.plot(x[i:i+2], z[i:i+2], -y[i:i+2],
                color=colors[i], linewidth=1.5)

    ax.scatter(x[0],  z[0],  -y[0],  c='blue', s=100, marker='o', label='Start')
    ax.scatter(x[-1], z[-1], -y[-1], c='red',  s=100, marker='*', label='End')

    ax.set_xlabel('X (m)')
    ax.set_ylabel('Z (m) - Forward')
    ax.set_zlabel('Y (m) - Up')
    ax.set_title('Monocular Visual Odometry Trajectory')
    ax.legend()
    plt.tight_layout()
    plt.show()
```

### 累积误差：VO 的根本局限

视觉里程计有一个绕不开的问题：**累积漂移（Accumulated Drift）**。

每帧的运动估计都有微小误差，这些误差会随时间累积。走了一圈回到起点，轨迹的终点和起点往往不重合——这个偏差就是漂移。漂移量通常用"行进距离的百分比"来衡量，好的系统能做到 0.5%~2%，差的系统可能 5% 以上。

解决漂移的方法在完整 SLAM 系统中有三个层次。**局部优化**（Bundle Adjustment）：不只用相邻两帧估计运动，而是把多帧联合优化，最小化所有观测的重投影误差。**回环检测**：识别出"现在看到的场景以前见过"，用这个约束把轨迹"拉回来"，消除长距离漂移。**全局优化**（Pose Graph Optimization）：把所有位姿和回环约束建成一个图，全局优化所有位姿。

### 整个系列的知识图谱

走完七节课，回头看看我们建立的知识体系：

```
SIFT（你的起点）
  ↓ 借鉴思想，追求速度
ORB（第一、二节）
  特征检测（FAST） + 描述（rBRIEF） + 匹配（比率测试+RANSAC）
  ↓ 匹配点对 → 几何关系
对极几何（第三节）
  基础矩阵F → 本质矩阵E → 分解R和t
  ↓ 已知R和t → 稠密深度
立体匹配（第四节）
  整流 → 视差图（BM/SGBM） → 深度图 → 点云
  ↓ 转向时序处理
光流（第五、六节）
  稀疏（LK）：追踪角点，快速，用于VO前端
  稠密（Farneback）：分析运动场，用于视频理解
  ↓ 一切串联
视觉里程计（第七节）
  追踪 → 估计运动 → 累积位姿 → 输出轨迹
```

这条线索背后有一个统一的思想：**用图像中的局部结构（角点、梯度、纹理）来推断世界的几何（深度、运动、位姿）**。从 SIFT 到 VO，你走过的不只是七个算法，而是整个传统计算机视觉的核心方法论。

---

### 下一步可以去哪里

传统视觉算法学完了，有几个方向可以继续深入。

**工程方向**：研究成熟的开源 SLAM 系统，如 ORB-SLAM3、VINS-Mono、OpenVINS，它们是这些原理的极致工程化实现，代码质量极高，读懂一个就能让你的工程能力大幅提升。

**理论深入**：学习非线性优化（g2o、Ceres Solver）和李群李代数（旋转的参数化），这是理解 Bundle Adjustment 和位姿图优化的数学基础，推荐高翔的《视觉SLAM十四讲》。

**深度学习方向**：了解 SuperPoint（深度学习特征点）、RAFT（深度学习光流）、DepthAnything（单目深度估计），看看神经网络如何在这些传统问题上超越了经典方法，以及两者如何融合。

七节课到这里就全部结束了。从 ORB 的二进制描述子，到极线几何的数学之美，到光流的运动感知，到最后把它们串成一个能"感知自身运动"的系统——希望这条路走得清晰、扎实。
