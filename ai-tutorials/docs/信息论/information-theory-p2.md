## 模块 3：联合熵、条件熵、互信息

到现在我们处理的都是**单个**随机变量。但通信的本质是"输入 → 信道 → 输出"——发送 X，收到 Y。X 和 Y 是成对的。

这一节我们要回答四个问题：

1. **(X,Y)(X,Y) 整体**有多少不确定性？→ 联合熵
2. **已知 Y 之后**，X 还剩多少不确定性？→ 条件熵
3. **Y 告诉了我们关于 X 的多少信息**？→ 互信息
4. 这些量之间有什么关系？→ 一张神图（韦恩图）

---

### 一、补一个概念：联合分布与条件分布

你只学过高中概率，这里需要先补两个概念。

#### 联合分布

设 X 和 Y 是两个随机变量。它们一起取值(x,y)的概率记作：

p(x,y)=P(X=x,Y=y)

这叫**联合概率分布**。它描述了 X 和 Y "同时"取某对值的概率。

举例：抛两枚硬币，X 是第一枚，Y 是第二枚。

||Y=Y=正|Y=Y=反|
|---|---|---|
|X=X=正|0.25|0.25|
|X=X=反|0.25|0.25|

这就是 p(x,y) 的全部信息（一个 2×22×2 表）。

#### 边缘分布

如果我只关心 X、不关心 Y，可以把 Y "求和掉"：

p(x)=∑yp(x,y)p(x)=y∑​p(x,y)

这叫**边缘分布**（之所以叫"边缘"，是因为在表格里它出现在表格边缘的求和栏）。

#### 条件分布

已知 Y=yY=y 的前提下，X=xX=x 的概率：

p(x∣y)=p(x,y)p(y)p(x∣y)=p(y)p(x,y)​

这就是高中你学过的条件概率，只是写成随机变量的形式。

#### 一个要记住的关系

p(x,y)=p(y)⋅p(x∣y)=p(x)⋅p(y∣x)

这叫**乘法公式**，后面反复要用。

#### 独立的定义

X 与 Y **独立**，当且仅当对所有 x,yx,y：

p(x,y)=p(x)⋅p(y)

或者等价地p(x∣y)=p(x)（已知 Y 不改变 X 的分布）。

好，概率工具齐了。下面进入正题。

---

### 二、联合熵 H(X,Y)

把(X,Y)看成**一个整体随机变量**——它的取值是一对(x,y)，概率是 p(x,y)。直接套上一节熵的定义：

 H(X,Y)=−∑x,yp(x,y)log⁡p(x,y) H(X,Y)=−x,y∑​p(x,y)logp(x,y)​

它衡量的是 **(X,Y)(X,Y) 这一对的总不确定性**。

举例：两枚独立均匀硬币，4 种等概率结果，每种 0.250.25：

H(X,Y)=−4×0.25log⁡20.25=−log⁡20.25=2 比特H(X,Y)=−4×0.25log2​0.25=−log2​0.25=2 比特

正好是H(X)+H(Y)=1+1=2。这不是巧合——独立时，联合熵等于两个熵之和（后面会证）。

---

### 三、条件熵 H(X∣Y)

这是这一节**最重要也最容易混的概念**，慢慢讲。

#### 先想一个具体场景

设 X 是"明天是否下雨"，Y 是"今天的气压读数"。Y 不能完全确定 X，但**已知 Y 之后，X 的不确定性会减小**。

我们想量化：**已知 Y 之后，X 还剩多少不确定性？**

#### 第一步：固定 Y=yY=y 时的熵

如果 Y 已经确定取了某个具体值 y，那 X 服从条件分布 p(x∣y)。这个分布的熵是：

H(X∣Y=y)=−∑xp(x∣y)log⁡p(x∣y)H(X∣Y=y)=−x∑​p(x∣y)logp(x∣y)

注意：**这是一个具体数值**，对应 Y 取某一个特定值 y 时，X 还剩的不确定性。

#### 第二步：对所有 y 取期望

但 Y 本身也是随机的，会取不同的值。我们要的是**平均**意义下的"已知 Y 后 X 的不确定性"——也就是把上面那个数对 Y 取期望：

H(X∣Y)=∑yp(y)⋅H(X∣Y=y)H(X∣Y)=y∑​p(y)⋅H(X∣Y=y)

展开来看：

H(X∣Y)=∑yp(y)[−∑xp(x∣y)log⁡p(x∣y)]H(X∣Y)=y∑​p(y)[−x∑​p(x∣y)logp(x∣y)]

把 p(y) 乘进去，再用p(x,y)=p(y)p(x∣y)：

 H(X∣Y)=−∑x,yp(x,y)log⁡p(x∣y) H(X∣Y)=−x,y∑​p(x,y)logp(x∣y)​

这就是**条件熵**的定义式。

#### 务必理清的细节

注意公式里有两个不同的概率，**不要搞混**：

- 求和的"权重"是 p(x,y)（联合概率）
- 取对数的对象是 p(x∣y)（条件概率）

**口诀**：联合概率加权，条件概率取对数。

#### 直觉理解

- H(X)：你对 X 的不确定性。
- H(X∣Y)：**已经看到 Y 之后**，你对 X 还剩的不确定性。
- 显然H(X∣Y)≤H(X)——多看到一个相关变量，不确定性只会减少或不变，**不可能增加**。这条不等式叫"**条件熵不大于熵**"，是信息论中极其重要的事实。

#### 两个极端例子

**例 1：X 与 Y 独立**

p(x∣y)=p(x)，所以：

H(X∣Y)=−∑x,yp(x,y)log⁡p(x)=−∑xp(x)log⁡p(x)=H(X)H(X∣Y)=−x,y∑​p(x,y)logp(x)=−x∑​p(x)logp(x)=H(X)

**Y 啥都没告诉你关于 X 的信息**，所以 X 的不确定性没变。

**例 2：Y 完全决定 X**（比如 X=YX=Y 或X=f(Y)）

已知 Y 后 X 完全确定，H(X∣Y=y)=0对所有 y 成立，所以：

H(X∣Y)=0

---

### 四、链式法则——一个漂亮的恒等式

把条件熵的定义和联合熵串起来，能得到一个非常重要的恒等式。

我们看 H(X,Y)。利用p(x,y)=p(y)p(x∣y)：

H(X,Y)=−∑x,yp(x,y)log⁡p(x,y)=−∑x,yp(x,y)log⁡[p(y)p(x∣y)]=−∑x,yp(x,y)log⁡p(y)−∑x,yp(x,y)log⁡p(x∣y)=−∑yp(y)log⁡p(y)+H(X∣Y)=H(Y)+H(X∣Y)H(X,Y)​=−x,y∑​p(x,y)logp(x,y)=−x,y∑​p(x,y)log[p(y)p(x∣y)]=−x,y∑​p(x,y)logp(y)−x,y∑​p(x,y)logp(x∣y)=−y∑​p(y)logp(y)+H(X∣Y)=H(Y)+H(X∣Y)​

（中间倒数第二步用了∑xp(x,y)=p(y)把 x 求和掉。）

得到**链式法则**：

H(X,Y)=H(Y)+H(X∣Y)=H(X)+H(Y∣X)

**直观解读**：(X,Y)总的不确定性 = "先看 Y" 的不确定性 + "已知 Y 后再看 X" 的不确定性。这非常符合直觉——你可以分两步揭开(X,Y)。

---

### 五、互信息 I(X;Y)

终于到本节的高潮——互信息。

#### 提出问题

我们已经有两个量：

- H(X)：X 原本的不确定性
- H(X∣Y)：已知 Y 之后 X 还剩的不确定性

**两者之差就是"Y 告诉了我们关于 X 的多少信息"**：

 I(X;Y)=H(X)−H(X∣Y) I(X;Y)=H(X)−H(X∣Y)​

这个量叫做 **X 与 Y 的互信息**（Mutual Information），是信息论中最重要的概念之一，地位甚至高于熵。

#### 互信息的对称性

直觉上，$Y$ 提供的关于 $X$ 的信息量，应当等于 $X$ 提供的关于 $Y$ 的信息量。下面进行验证。

由链式法则：

H(X)+H(Y∣X)=H(Y)+H(X∣Y)

整理得：

H(X)−H(X∣Y)=H(Y)−H(Y∣X)

也就是：

I(X;Y)=I(Y;X)I(X;Y)=I(Y;X)

**互信息是对称的**。所以记号写 I(X;Y)（用分号，强调对称），不写箭头方向。

#### 互信息的另一个公式

利用H(X∣Y)=H(X,Y)−H(Y)：

I(X;Y)=H(X)+H(Y)−H(X,Y)I(X;Y)=H(X)+H(Y)−H(X,Y)

直接展开成概率形式：

 I(X;Y)=∑x,yp(x,y)log⁡p(x,y)p(x)p(y) I(X;Y)=x,y∑​p(x,y)logp(x)p(y)p(x,y)​​

这个形式很有内涵：它衡量的是**联合分布 p(x,y) 与"独立分布乘积"p(x)p(y)之间的差异**。

- 如果 X,YX,Y 独立 →p(x,y)=p(x)p(y)→ 比值为 1 →log1=0→ I(X;Y)=0I(X;Y)=0
- 如果 X,YX,Y 越"紧密相关" → 联合分布偏离独立越远 → 互信息越大

下一模块讲 KL 散度时你会发现：**互信息其实就是联合分布与边缘乘积分布的 KL 散度**。先记住这个伏笔。

#### 互信息的性质

**性质 1：非负性** I(X;Y)≥0I(X;Y)≥0

等号成立 ⟺ X 与 Y 独立。

**直觉**：知道 Y 至多帮你减少对 X 的不确定性，不可能增加。**多一个观测不会让你"更糊涂"**——这是信息论的基本伦理。

严格证明需要 Jensen 不等式或 Gibbs 不等式，下一模块讲 KL 散度时一并证。

**性质 2：上界**

I(X;Y)≤min⁡{H(X),H(Y)}I(X;Y)≤min{H(X),H(Y)}

因为 I(X;Y)=H(X)−H(X∣Y)≤H(X)I(X;Y)=H(X)−H(X∣Y)≤H(X)（条件熵非负），同理≤H(Y)。

**直觉**：Y 告诉你关于 X 的信息，不可能超过 X 本身的总信息量。

**性质 3：自互信息**

I(X;X)=H(X)−H(X∣X)=H(X)−0=H(X)I(X;X)=H(X)−H(X∣X)=H(X)−0=H(X)

**X 跟自己的互信息就是熵**。所以熵也叫"自信息"。这从另一个角度说明熵的本质。

### 六、那张神图：信息韦恩图

把上面所有量画在一张图里，你会看到惊人的结构对应。

```
          H(X, Y)
   ┌─────────────────────┐
   │                     │
   │   H(X | Y)   I(X;Y)   H(Y | X)
   │   ┌─────┬───────┬─────┐
   │   │     │       │     │
   │   │  ●  │   ●   │  ●  │
   │   │     │       │     │
   │   └─────┴───────┴─────┘
   │   ←── H(X) ──→
   │           ←── H(Y) ──→
   └─────────────────────┘
```

把 H(X) 看作一个圆，H(Y) 看作另一个圆。两个圆**部分重叠**：

- 整个左圆 = H(X)
- 整个右圆 = H(Y)
- **左圆独有的部分** = H(X∣Y)（Y 不知道的关于 X 的信息）
- **右圆独有的部分** = H(Y∣X)
- **两圆相交的部分** = I(X;Y)（共享信息）
- **两圆并集** = H(X,Y)（总信息）

这张图把模块 3 所有公式可视化：

|公式|韦恩图含义|
|---|---|
|H(X,Y)=H(X)+H(Y∣X)H(X,Y)=H(X)+H(Y∣X)|并集 = 左圆 + 右圆独有|
|H(X,Y)=H(X)+H(Y)−I(X;Y)H(X,Y)=H(X)+H(Y)−I(X;Y)|并集 = 左 + 右 − 相交|
|I(X;Y)=H(X)−H(X∣Y)I(X;Y)=H(X)−H(X∣Y)|相交 = 左圆 − 左圆独有|
|I(X;Y)=H(X)+H(Y)−H(X,Y)I(X;Y)=H(X)+H(Y)−H(X,Y)|相交 = 左 + 右 − 并集|

**强烈建议你把这张图记在脑子里**。后面所有的信息量关系，看图就能秒推。考试也是这张图的天下。

设联合分布如下：

||Y=0Y=0|Y=1Y=1|p(x)|

|X=0X=0|1/8|3/8|1/2|
|X=1X=1|3/8|1/8|1/2|
|p(y)|1/2|1/2||

**算 H(X)**：均匀，H(X)=1。 **算 H(Y)**：均匀，H(Y)=1。

**算 H(X,Y)**：四个值，两个 1/8 两个 3/8。

H(X,Y)=−2⋅18log⁡218−2⋅38log⁡238H(X,Y)=−2⋅81​log2​81​−2⋅83​log2​83​

log2(1/8)=−3，log2(3/8)=log23−3≈−1.415。

H(X,Y)≈14⋅3+34⋅1.415=0.75+1.061=1.811 比特H(X,Y)≈41​⋅3+43​⋅1.415=0.75+1.061=1.811 比特

**算 I(X;Y)**：用韦恩图公式

I(X;Y)=H(X)+H(Y)−H(X,Y)=1+1−1.811=0.189 比特I(X;Y)=H(X)+H(Y)−H(X,Y)=1+1−1.811=0.189 比特

### 八、为什么互信息这么重要

提前剧透一下后面会看到的应用：

1. **信道容量**（模块 6）：信道容量 C=max⁡p(x)I(X;Y)C=maxp(x)​I(X;Y)。即"在所有可能的输入分布中，能传递的最大互信息"。这是后面整个理论的支柱。
2. **机器学习中的特征选择**：选哪些特征 Y 来预测标签 X？挑 I(X;Y) 大的——这些特征"含 X 的信息"最多。
3. **神经网络的信息瓶颈理论**：深度学习里有一派理论用互信息分析每一层"保留了多少输入信息""学到了多少标签信息"。

互信息几乎是现代信息论应用最广的概念。

**四个量，一张图**：

- 多一个观测不会增加不确定性。
- 互信息衡量"两个变量有多依赖"。

到现在，我们已经能用熵、条件熵、互信息描述各种信息关系了。但你可能注意到了一个事——互信息的公式 ∑p(x,y)logp(x,y)p(x)p(y)∑p(x,y)logp(x)p(y)p(x,y) 看起来是在比较两个分布：实际的 p(x,y) 和"假装独立"的p(x)p(y)。

这种"比较两个分布"的思路非常重要。下一模块我们要把它一般化，得到一个量——**KL 散度**（相对熵）——它是机器学习里几乎无处不在的概念，也是证明前面那些不等式的钥匙。

## 模块 4：相对熵（KL 散度）

上一节末尾我留了一个伏笔：互信息的公式

I(X;Y)=∑x,yp(x,y)log⁡p(x,y)p(x)p(y)I(X;Y)=x,y∑​p(x,y)logp(x)p(y)p(x,y)​

看起来像是在**比较两个分布**——真实的联合分布 p(x,y) 和"假装独立"的p(x)p(y)。

这一节我们把这种"比较分布"的思路一般化，得到信息论中第三大核心概念：**相对熵**（Kullback-Leibler Divergence，简称 **KL 散度**）。

它是机器学习的核心工具，是证明前几节所有不等式的钥匙，也是连接信息论与统计、与物理、与深度学习的桥梁。

---

### 一、提出问题：怎么衡量"两个分布的差异"？

设 P 和 Q 是同一个样本空间上的两个概率分布。

举例：一枚硬币的"真实分布" P 是 p(正)=0.7,p(反)=0.3p(正)=0.7,p(反)=0.3。但你不知道，你以为它均匀，假设了一个 Q：q(正)=q(反)=0.5q(正)=q(反)=0.5。

**问**：Q 跟 P 差多少？

你可能想到的几种"距离"：

- ∣p−q∣∣p−q∣ 各分量绝对值之和（叫"全变差距离"）
- ∑(p−q)2∑(p−q)2 平方和（叫"L2 距离"）

这些"距离"在数学上都成立，但**不是信息论的视角**。信息论问的是一个更尖锐的问题：

> 如果我**误以为**分布是 Q，但**真实**是 P，我会"亏多少信息"？

这才是 KL 散度要回答的问题。

---

### 二、从编码长度推出 KL 散度

回忆模块 2 的解读 3：**熵是最优编码长度的下限**。具体地说，对于真实分布 p(x)，最优编码方案下，事件 x 应该用约−logp(x)比特来编码。

**关键洞察**：编码长度由你**以为的概率**决定，但事件**按真实概率发生**。

#### 场景

- 真实分布是 P，事件 x 真实出现的概率是 p(x)。
- 但你**误以为**分布是 Q，所以你给事件 x 分配了−logq(x)比特的码字。

#### 你实际的平均编码长度

事件按 p(x) 发生，每次用−logq(x)比特：

L实际=∑xp(x)⋅(−log⁡q(x))=−∑xp(x)log⁡q(x)L实际​=x∑​p(x)⋅(−logq(x))=−x∑​p(x)logq(x)

这个量有个名字，叫**交叉熵**（Cross Entropy），记作 H(P,Q)：

H(P,Q)=−∑xp(x)log⁡q(x)H(P,Q)=−x∑​p(x)logq(x)

#### 最优情况下的平均编码长度

如果你知道真实分布是 P，最优编码就是按 p(x) 分配：

L最优=−∑xp(x)log⁡p(x)=H(P)L最优​=−x∑​p(x)logp(x)=H(P)

#### "亏掉"的部分

你用了错的分布编码，比最优情况多花了多少？

L实际−L最优=−∑xp(x)log⁡q(x)−(−∑xp(x)log⁡p(x))=∑xp(x)log⁡p(x)q(x)L实际​−L最优​=−x∑​p(x)logq(x)−(−x∑​p(x)logp(x))=x∑​p(x)logq(x)p(x)​

**这就是 KL 散度**：

 DKL(P ∥ Q)=∑xp(x)log⁡p(x)q(x) DKL​(P∥Q)=x∑​p(x)logq(x)p(x)​​

它告诉你：**用错误分布 Q 编码真实分布 P 的数据，平均每个符号要多花多少比特**。

#### 三个量的关系

 H(P,Q)=H(P)+DKL(P ∥ Q) H(P,Q)=H(P)+DKL​(P∥Q)​

**交叉熵 = 熵 + KL 散度**。

直观读：**你的实际花费 = 最优花费 + 因为搞错分布多付的代价**。

### 三、KL 散度的另一种解读：期望

把 KL 散度的公式重写一下：

DKL(P ∥ Q)=∑xp(x)log⁡p(x)q(x)=Ex∼P[log⁡p(x)q(x)]DKL​(P∥Q)=x∑​p(x)logq(x)p(x)​=Ex∼P​[logq(x)p(x)​]

它是**对数似然比 logp(x)q(x)logq(x)p(x) 在 P 下的期望**。

这个解读在统计学中极其重要：对数似然比是"从数据判断到底是 P 还是 Q 生成的"最优判据。KL 散度就是这个判据在真分布下的期望——衡量两个分布"有多容易区分"。

### 四、KL 散度的性质

#### 性质 1：非负性（Gibbs 不等式）

DKL(P ∥ Q)≥0DKL​(P∥Q)≥0

等号成立 ⟺ P=QP=Q（即对所有 x 都有p(x)=q(x)）。

这是信息论的核心不等式，名叫 **Gibbs 不等式**。我马上证明它——这是模块 4 的技术核心。

#### 性质 2：不对称

DKL(P ∥ Q)≠DKL(Q ∥ P)DKL​(P∥Q)=DKL​(Q∥P)

注意这一点！KL 散度**不是数学意义上的距离**——距离要求对称，但 KL 不对称。所以严格地说它不叫"距离"，叫"散度"（divergence）。

直觉上，"用 Q 假装 P 的代价"和"用 P 假装 Q 的代价"本来就不一样。后面会有具体例子。

#### 性质 3：当q(x)=0但p(x)>0时，KL 散度为无穷

因为 log⁡p(x)0=+∞log0p(x)​=+∞。

直观理解：你以为某个事件不可能（q=0q=0），但它真实有概率发生（p>0p>0）——这是"灾难性的错误"，编码方案直接崩溃。

### 五、Gibbs 不等式的证明

这是本模块唯一一个需要点技术的证明，也是信息论中最常用的证明套路。看一遍就懂。

#### 工具：lnx≤x−1

对自然对数，有不等式：

ln⁡x≤x−1,等号当且仅当 x=1lnx≤x−1,等号当且仅当 x=1

这是因为f(x)=lnx−(x−1)在 x=1x=1 处取最大值 0（用导数验证：f′(x)=1/x−1f′(x)=1/x−1，零点在 x=1x=1）。

几何上：y=lnx的图像在 x=1x=1 处与切线y=x−1相切，整条曲线在切线下方。

#### 证明

我们证 DKL(P ∥ Q)≥0DKL​(P∥Q)≥0，等价于证 −DKL(P ∥ Q)≤0−DKL​(P∥Q)≤0。

为了用上面的不等式，我们换成自然对数（KL 用 log2 还是 ln 只差一个常数因子，不影响正负号）：

−DKL(P ∥ Q)=−∑xp(x)ln⁡p(x)q(x)=∑xp(x)ln⁡q(x)p(x)≤∑xp(x)(q(x)p(x)−1)（用 ln⁡x≤x−1）=∑x[q(x)−p(x)]=∑xq(x)−∑xp(x)=1−1=0−DKL​(P∥Q)​=−x∑​p(x)lnq(x)p(x)​=x∑​p(x)lnp(x)q(x)​≤x∑​p(x)(p(x)q(x)​−1)（用 lnx≤x−1）=x∑​[q(x)−p(x)]=x∑​q(x)−x∑​p(x)=1−1=0​

所以 −DKL(P ∥ Q)≤0−DKL​(P∥Q)≤0，即 DKL(P ∥ Q)≥0DKL​(P∥Q)≥0。■■

**等号条件**：lnx=x−1仅当 x=1x=1，即 q(x)p(x)=1p(x)q(x)=1 对所有 x（更严格地说，对所有p(x)>0的 x）。也就是 P=QP=Q。

#### 这个证明的威力

Gibbs 不等式是上一节那两个未证不等式的钥匙。我们立刻验证：

**用 Gibbs 不等式证 H(X)≤log⁡2nH(X)≤log2​n**

设 X 有 n 种取值，P 是 X 的真实分布，Q 是均匀分布 q(x)=1nq(x)=n1。

0≤DKL(P ∥ Q)=∑xp(x)log⁡p(x)1/n=∑xp(x)log⁡p(x)+∑xp(x)log⁡n=−H(X)+log⁡n0≤DKL​(P∥Q)​=x∑​p(x)log1/np(x)​=x∑​p(x)logp(x)+x∑​p(x)logn=−H(X)+logn​

所以 H(X)≤lognH(X)≤logn。等号当 P 是均匀分布时取到。■■

这就是模块 2 留下的"最大熵定理"的证明。

**用 Gibbs 不等式证 I(X;Y)≥0I(X;Y)≥0**

回忆互信息的公式：

I(X;Y)=∑x,yp(x,y)log⁡p(x,y)p(x)p(y)I(X;Y)=x,y∑​p(x,y)logp(x)p(y)p(x,y)​

把 p(x,y) 看作真实分布，p(x)p(y)看作另一个分布（注意∑x,yp(x)p(y)=1，确实是合法的概率分布）。直接套 KL 散度的定义：

 I(X;Y)=DKL(p(x,y) ∥ p(x)p(y)) I(X;Y)=DKL​(p(x,y)∥p(x)p(y))​

由 Gibbs 不等式，I(X;Y)≥0I(X;Y)≥0。等号当p(x,y)=p(x)p(y)，即 X,YX,Y 独立时取到。■■

**这是个深刻的结果**：

> **互信息 = 联合分布与"独立分布"之间的 KL 散度。**

它衡量"X 和 Y 离独立有多远"。这就是上一节末尾留下的伏笔。

### 六、一个具体计算例子

回到本节开头的硬币：真实分布 P 是p+=0.7,p−=0.3；你猜的分布 Q 是q+=q−=0.5。

#### 算 DKL(P ∥ Q)DKL​(P∥Q)

DKL(P ∥ Q)=0.7log⁡20.70.5+0.3log⁡20.30.5=0.7log⁡21.4+0.3log⁡20.6≈0.7×0.485+0.3×(−0.737)≈0.3398−0.2211≈0.119 比特DKL​(P∥Q)​=0.7log2​0.50.7​+0.3log2​0.50.3​=0.7log2​1.4+0.3log2​0.6≈0.7×0.485+0.3×(−0.737)≈0.3398−0.2211≈0.119 比特​

意思是：你用均匀编码 Q 来编真实是 70-30 偏分布的数据，每个符号平均**多浪费 0.119 比特**。

#### 算 DKL(Q ∥ P)DKL​(Q∥P)（验证不对称性）

DKL(Q ∥ P)=0.5log⁡20.50.7+0.5log⁡20.50.3≈0.5×(−0.485)+0.5×0.737≈0.126 比特DKL​(Q∥P)​=0.5log2​0.70.5​+0.5log2​0.30.5​≈0.5×(−0.485)+0.5×0.737≈0.126 比特​

确实，0.119≠0.1260.119=0.126，**KL 散度不对称**。

### 七、KL 散度在机器学习中的核心地位

电子信息专业的同学未来很可能接触机器学习，这里提前埋下伏笔——**KL 散度和交叉熵几乎是所有现代分类模型的损失函数核心**。

#### 场景：分类问题

你训练一个神经网络做分类。对每个样本：

- **真实标签** 是一个分布 P。比如三分类问题，真标签是"猫"，那P=(1,0,0)（这种分布叫 **one-hot 分布**）。
- **模型预测** 是一个分布 Q。比如模型输出Q=(0.7,0.2,0.1)。

你希望模型预测尽量接近真实——也就是 Q 接近 P，即 DKL(P ∥ Q)DKL(P∥Q) 越小越好。

#### 简化为交叉熵

回忆 H(P,Q)=H(P)+DKL(P ∥ Q)H(P,Q)=H(P)+DKL​(P∥Q)。

对一个固定的训练样本，真实分布 P 是固定的（one-hot），所以 H(P) 是常数（实际上 one-hot 分布H(P)=0）。最小化 DKL(P ∥ Q)DKL(P∥Q) 等价于最小化 H(P,Q)——即**最小化交叉熵**。

这就是为什么深度学习里分类任务的标准损失函数叫 **Cross-Entropy Loss**（交叉熵损失）。它本质上是 KL 散度的化简形式。

PyTorch 里的 `nn.CrossEntropyLoss`、TensorFlow 里的 `categorical_crossentropy`——背后都是这个公式。

### 八、KL 散度无处不在：一份地图

为了让你理解 KL 散度的地位，列一份它出现的领域：

|领域|KL 散度的角色|
|---|---|
|**信息论**|编码效率损失|
|**统计学**|分布拟合的优化目标（最大似然估计等价于最小化 KL）|
|**机器学习**|交叉熵损失、变分自编码器（VAE）、强化学习的策略优化|
|**物理学**|热力学第二定律、自由能|
|**生物信息学**|DNA 序列分析、群体遗传|
|**金融**|风险中性测度变换|

这个量不亚于熵的地位。**信息论里有"两大支柱"——熵和 KL 散度**。互信息其实是 KL 散度的一种特例。

### 九、本模块小结

**核心定义**：

DKL(P ∥ Q)=∑xp(x)log⁡p(x)q(x)DKL​(P∥Q)=x∑​p(x)logq(x)p(x)​

衡量"用 Q 来近似 P 的代价"。

**核心性质**：

1. DKL≥0DKL​≥0，等号当且仅当 P=QP=Q（**Gibbs 不等式**）。
2. 不对称：DKL(P ∥ Q)≠DKL(Q ∥ P)DKL​(P∥Q)=DKL​(Q∥P)。
3. q(x)=0q(x)=0 而p(x)>0时为无穷。

**核心关系**：

- H(P,Q)=H(P)+DKL(P ∥ Q)H(P,Q)=H(P)+DKL​(P∥Q)（交叉熵 = 熵 + KL）
- I(X;Y)=DKL(p(x,y) ∥ p(x)p(y))I(X;Y)=DKL​(p(x,y)∥p(x)p(y))（互信息是 KL 的特例）

**Gibbs 不等式的两个推论**：

- H(X)≤log⁡nH(X)≤logn（最大熵定理）
- I(X;Y)≥0I(X;Y)≥0（互信息非负）

我们已经学完了信息论的**度量工具箱**。回顾一下：

|---|---|---|
