# 第十一讲：多元线性回归——预测与解释的利器

---

## 为什么多元回归值得单独深入讲？

很多同学在学过一元线性回归之后，会觉得多元回归不过是"多加几个变量"，没什么新东西可学。这个想法在概念层面有一定道理，但在实践层面却是危险的误解。

多元回归引入了一系列在一元情形中完全不存在的新问题：多个预测变量之间可能高度相关（多重共线性），使得系数估计极不稳定；变量太多时需要选择哪些变量纳入模型；预测值和残差的诊断变得更复杂；系数的解释需要"控制其他变量"的思维……

这些问题不是技术细节，而是影响结论可靠性的核心问题。本讲的目标是把多元回归从"多加几个变量的一元回归"升级为一套有完整理论支撑、有严格诊断流程的分析框架。

---

## 模型设定：矩阵语言的力量

设有 $n$ 个观测，$p$ 个预测变量（自变量），一个响应变量（因变量）$Y$。多元线性回归模型是：

$$Y_i = \beta_0 + \beta_1 X_{i1} + \beta_2 X_{i2} + \cdots + \beta_p X_{ip} + \varepsilon_i, \quad i = 1, 2, \ldots, n$$

用矩阵语言写成：

$$\boldsymbol{Y} = \boldsymbol{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}$$

其中 $\boldsymbol{Y}$（$n \times 1$）是响应变量向量，$\boldsymbol{X}$（$n \times (p+1)$）是**设计矩阵**（第一列全为1，对应截距 $\beta_0$），$\boldsymbol{\beta}$（$(p+1) \times 1$）是待估计的系数向量，$\boldsymbol{\varepsilon}$（$n \times 1$）是误差向量，假设 $\boldsymbol{\varepsilon} \sim N(\boldsymbol{0}, \sigma^2 \boldsymbol{I})$（正态、独立、同方差）。

矩阵形式的最大好处是：原本需要对每个系数分别写出的复杂推导，在矩阵语言下变成一行公式。

### 最小二乘估计

最小二乘法最小化残差平方和：

$$\text{RSS} = |\boldsymbol{Y} - \boldsymbol{X}\boldsymbol{\beta}|^2 = (\boldsymbol{Y} - \boldsymbol{X}\boldsymbol{\beta})^\top(\boldsymbol{Y} - \boldsymbol{X}\boldsymbol{\beta})$$

对 $\boldsymbol{\beta}$ 求导令其为零，得到**正规方程（normal equations）**：

$$\boldsymbol{X}^\top \boldsymbol{X} \hat{\boldsymbol{\beta}} = \boldsymbol{X}^\top \boldsymbol{Y}$$

若 $\boldsymbol{X}^\top \boldsymbol{X}$ 可逆，解为：

$$\hat{\boldsymbol{\beta}} = (\boldsymbol{X}^\top \boldsymbol{X})^{-1} \boldsymbol{X}^\top \boldsymbol{Y}$$

这个公式的几何意义非常深刻：$\hat{\boldsymbol{Y}} = \boldsymbol{X}\hat{\boldsymbol{\beta}} = \boldsymbol{X}(\boldsymbol{X}^\top\boldsymbol{X})^{-1}\boldsymbol{X}^\top\boldsymbol{Y}$ 是 $\boldsymbol{Y}$ 在 $\boldsymbol{X}$ 的列空间上的**正交投影**。矩阵 $\boldsymbol{H} = \boldsymbol{X}(\boldsymbol{X}^\top\boldsymbol{X})^{-1}\boldsymbol{X}^\top$ 叫做**帽子矩阵（hat matrix）**，因为它把 $\boldsymbol{Y}$ "变成" $\hat{\boldsymbol{Y}}$（加了一顶帽子）。帽子矩阵在回归诊断中极为重要，后面会用到。

---

## 系数的解释：偏效应的本质

多元回归系数的解释与一元回归有一个根本区别，必须讲清楚。

在一元回归 $Y = \beta_0 + \beta_1 X + \varepsilon$ 中，$\hat{\beta}_1$ 的含义是：$X$ 增加1个单位，$Y$ 平均增加 $\hat{\beta}_1$ 个单位。简单直接。

在多元回归 $Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p + \varepsilon$ 中，$\hat{\beta}_j$ 的含义是：**在保持其他所有变量 $X_1, \ldots, X_{j-1}, X_{j+1}, \ldots, X_p$ 不变的条件下**，$X_j$ 增加1个单位，$Y$ 平均增加 $\hat{\beta}_j$ 个单位。

这个"控制其他变量不变"的条件至关重要，它的数学含义是：$\hat{\beta}_j$ 衡量的是 $X_j$ 对 $Y$ 的**净效应（net effect）**，剔除了其他变量的影响之后的效应。

这带来一个在一元情形中不存在的现象：**$X_j$ 在一元回归中对 $Y$ 的效应，可能与它在多元回归中的系数完全不同，甚至符号相反。** 这个现象叫做**辛普森悖论（Simpson's Paradox）**的回归版本，或者叫**混淆（confounding）**。

一个经典例子：研究冰淇淋销量（$Y$）与溺水人数（$X_1$）的关系，一元回归可能给出正相关（$\hat{\beta}_1 > 0$）。但当控制了"气温"（$X_2$）之后，这个正相关消失了——真正的原因是气温高既导致冰淇淋卖得好，也导致游泳人多，从而溺水多。$X_1$ 和 $Y$ 的一元相关是**伪相关**，是被 $X_2$（气温）混淆的。多元回归通过同时控制 $X_2$，揭示了 $X_1$ 对 $Y$ 的真实净效应。

## 模型的整体检验与分量检验

### $F$ 检验：整体显著性

首先检验模型整体是否有解释力，零假设是所有回归系数（除截距外）都为零：

$$H_0: \beta_1 = \beta_2 = \cdots = \beta_p = 0$$

对应的 $F$ 统计量是：

$$F = \frac{(\text{SSR}/p)}{(\text{SSE}/(n-p-1))} = \frac{MS_R}{MS_E}$$

其中 $\text{SSR} = \sum(\hat{Y}_i - \bar{Y})^2$ 是回归平方和（模型解释的变异），$\text{SSE} = \sum(Y_i - \hat{Y}_i)^2$ 是残差平方和（模型未解释的变异）。在 $H_0$ 下，$F \sim F(p, n-p-1)$。

$R^2 = \text{SSR}/\text{SST}$ 是决定系数，描述模型解释了多大比例的总变异。但注意：**$R^2$ 随着变量增多而单调增大**，即使加入完全无关的变量，$R^2$ 也不会减小。因此比较不同变量数目的模型时，应该用**调整 $R^2$**：

$$\bar{R}^2 = 1 - \frac{\text{SSE}/(n-p-1)}{\text{SST}/(n-1)} = 1 - (1 - R^2)\frac{n-1}{n-p-1}$$

调整 $R^2$ 对增加变量有惩罚，只有当新变量解释的变异大于"纯偶然"时，调整 $R^2$ 才会增大。

### $t$ 检验：单个系数的显著性

在整体 $F$ 检验显著后，进一步检验每个系数是否显著不为零：

$$H_0: \beta_j = 0$$

统计量是：

$$t_j = \frac{\hat{\beta}_j}{\text{se}(\hat{\beta}_j)} \sim t(n-p-1)$$

其中 $\text{se}(\hat{\beta}_j) = \hat{\sigma}\sqrt{[(\boldsymbol{X}^\top\boldsymbol{X})^{-1}]_{jj}}$ 是 $\hat{\beta}_j$ 的标准误，$\hat{\sigma}^2 = \text{SSE}/(n-p-1)$ 是误差方差的估计。

**一个重要提示**：单个 $t$ 检验是在模型中保留了所有其他变量的条件下检验某个变量是否显著，它的结果受到其他变量的影响。$t$ 检验不显著，不代表该变量与 $Y$ 无关，只代表在控制了其他变量之后，该变量没有额外的解释力——这可能是因为它的信息已经被其他变量"代为解释"了。

## 多重共线性：最重要的多元回归问题

多重共线性（multicollinearity）是指预测变量之间存在高度的线性相关性。它是多元回归中最常见、影响最深远的问题，在一元回归里完全不存在。

### 为什么多重共线性是个问题？

从矩阵角度理解最清晰。系数估计是 $\hat{\boldsymbol{\beta}} = (\boldsymbol{X}^\top\boldsymbol{X})^{-1}\boldsymbol{X}^\top\boldsymbol{Y}$，$\hat{\boldsymbol{\beta}}$ 的协方差矩阵是 $\text{Cov}(\hat{\boldsymbol{\beta}}) = \sigma^2(\boldsymbol{X}^\top\boldsymbol{X})^{-1}$。

当预测变量之间高度相关时，$\boldsymbol{X}^\top\boldsymbol{X}$ 接近奇异（行列式接近零），其逆矩阵 $(\boldsymbol{X}^\top\boldsymbol{X})^{-1}$ 的对角元素会变得很大，也就是说 $\hat{\beta}_j$ 的方差会急剧膨胀。结果是：

系数估计极不稳定——数据的微小变化（比如多加几个样本）可能导致系数估计发生巨大变化，甚至符号改变。

系数的 $t$ 统计量变小（因为标准误变大），很多变量看起来不显著，但整体 $F$ 检验可能高度显著——这种"整体显著但个别不显著"的矛盾模式，是多重共线性的典型症状。

系数的解释变得困难——当 $X_1$ 和 $X_2$ 高度相关时，"控制 $X_2$ 不变、改变 $X_1$"在实践中几乎不可能，对应的系数 $\hat{\beta}_1$ 没有实质意义。

### 诊断：方差膨胀因子

**方差膨胀因子（Variance Inflation Factor，VIF）** 是诊断多重共线性最常用的工具。第 $j$ 个变量的 VIF 定义为：

$$\text{VIF}_j = \frac{1}{1 - R_j^2}$$

其中 $R_j^2$ 是把 $X_j$ 作为因变量、其他 $p-1$ 个变量作为自变量做回归时得到的 $R^2$——它衡量 $X_j$ 被其他变量"解释"了多少。

$R_j^2$ 越接近1，说明 $X_j$ 与其他变量越接近线性关系，VIF 越大。直觉上，$\text{VIF}_j$ 告诉你 $\hat{\beta}_j$ 的方差，相比于完全没有共线性时（$R_j^2 = 0$，$\text{VIF}_j = 1$），膨胀了多少倍。

**判断标准**：$\text{VIF}_j > 10$ 通常被视为严重共线性的信号（对应 $R_j^2 > 0.9$），$\text{VIF}_j > 5$ 也值得注意。但这些只是经验法则，需要结合实质背景判断。

### 处理多重共线性的方法

**变量选择**：如果两个高度相关的变量 $X_1$ 和 $X_2$ 只保留一个，问题自然消失。选择哪个，根据领域知识、理论依据和单独与 $Y$ 的相关性来决定。

**主成分回归（PCR）**：用 $X$ 变量的前 $k$ 个主成分代替原始变量做回归。主成分之间互不相关（正交），从根本上消除了多重共线性。代价是失去了系数对原始变量的直接解释。

**岭回归（Ridge Regression）**：在正规方程中加入一个岭惩罚 $\lambda \boldsymbol{I}$：

$$\hat{\boldsymbol{\beta}}_{\text{ridge}} = (\boldsymbol{X}^\top\boldsymbol{X} + \lambda\boldsymbol{I})^{-1}\boldsymbol{X}^\top\boldsymbol{Y}$$

加入 $\lambda \boldsymbol{I}$ 使矩阵远离奇异，系数估计变得稳定。代价是引入了偏差（估计不再无偏），但方差大幅减小——这是一个**偏差-方差权衡（bias-variance tradeoff）**，在预测任务中通常是合算的交换。$\lambda$ 越大，系数越被"压缩"向零，偏差越大方差越小。

## 变量选择：如何构建最优模型

当候选变量很多时，如何选择进入最终模型的变量子集，是回归分析中的重要实践问题。

### 全子集回归

理论上最彻底的方法：对 $p$ 个候选变量的所有 $2^p$ 个子集各自建模，用某个准则选出最优子集。但 $p$ 大时计算量爆炸（$p=20$ 时有超过100万个子集），实践中只适用于 $p \leq 20$ 左右。

### 逐步回归

逐步回归是全子集回归的计算近似，有三种变体。

**前向选择（Forward Selection）**：从只有截距的空模型开始，每步添加一个"加入后模型改善最大"的变量，直到没有变量能显著改善模型为止。贪婪算法，计算快，但可能错过"两个变量联合才有效果"的情形。

**后向消除（Backward Elimination）**：从包含所有变量的全模型开始，每步删除一个"对模型贡献最小"的变量，直到所有剩余变量都显著。比前向选择更可靠（因为从完整模型出发，能看到所有变量的联合效果），但需要 $n > p$ 才能启动。

**逐步回归（Stepwise Regression）**：前向选择和后向消除的结合，每步既考虑添加新变量，也考虑删除已有变量。最灵活，是实践中最常用的变体。

### 信息准则：AIC 与 BIC

逐步回归中，每步的决策依据是某个**模型选择准则**。最常用的两个是：

**AIC（赤池信息准则，Akaike Information Criterion）**：

$$\text{AIC} = 2p - 2\ln(\hat{L})$$

其中 $\hat{L}$ 是最大化的似然函数值，$p$ 是模型参数个数（包括截距和 $\sigma^2$）。AIC 用对数似然来衡量拟合优度，用 $2p$ 作为复杂度惩罚。AIC 越小越好。

**BIC（贝叶斯信息准则，Bayesian Information Criterion）**：

$$\text{BIC} = p\ln(n) - 2\ln(\hat{L})$$

BIC 的惩罚项是 $p\ln(n)$，当 $n > 7$ 时 $\ln(n) > 2$，BIC 对复杂度的惩罚比 AIC 更重。在大样本下，BIC 渐近一致地选出真实模型（如果真实模型在候选集内），而 AIC 倾向于选择略微复杂一些的模型（偏向预测精度）。

**如何选择 AIC 还是 BIC？** 目标是**预测**时用 AIC（更宽松，模型更灵活，预测误差更小）；目标是**发现真实变量**或需要**简洁可解释的模型**时用 BIC（更严格，惩罚多余变量）。

## 回归诊断：检验模型假设

建立模型之后，必须检验误差的假设（正态性、独立性、同方差性、线性性）是否合理。这一步在实践中往往被忽略，却是保证结论可靠性的关键。

### 残差图

**残差 vs. 拟合值图**（$e_i$ vs. $\hat{Y}_i$）：如果假设成立，点应该随机散布在零线两侧，没有任何规律。如果出现"漏斗形"（方差随拟合值增大），说明存在**异方差**；如果出现弯曲模式，说明**线性假设**可能不成立，需要加入二次项或做变量变换。

**正态概率图（Q-Q图）**：把标准化残差的分位数对正态分布的理论分位数作图。如果残差正态，点应该落在一条直线上。两端翘起说明有重尾（比正态更多极端值），S形说明分布偏斜。

### 强影响点的诊断

多元回归中，单个观测对拟合结果的影响差异很大，需要识别几类特殊点。

**杠杆点（leverage point）** 是在预测变量空间中位置极端的点，用帽子矩阵的对角元素 $h_{ii}$ 来衡量，$h_{ii}$ 越大表示杠杆越高。高杠杆点不一定有问题（如果它的 $Y$ 值符合模型趋势），但如果同时 $Y$ 值也偏离预测，就会对回归系数产生很大影响。

**Cook 距离（Cook's Distance）** 综合衡量一个观测对所有系数估计的总影响：

$$D_i = \frac{(\hat{\boldsymbol{\beta}}_{(-i)} - \hat{\boldsymbol{\beta}})^\top \boldsymbol{X}^\top\boldsymbol{X} (\hat{\boldsymbol{\beta}}_{(-i)} - \hat{\boldsymbol{\beta}})}{(p+1)\hat{\sigma}^2}$$

其中 $\hat{\boldsymbol{\beta}}_{(-i)}$ 是删除第 $i$ 个观测后的系数估计。$D_i > 1$ 通常被视为强影响点，需要仔细检查。

## 本讲的核心收获

多元线性回归的矩阵形式 $\boldsymbol{Y} = \boldsymbol{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}$，最小二乘估计 $\hat{\boldsymbol{\beta}} = (\boldsymbol{X}^\top\boldsymbol{X})^{-1}\boldsymbol{X}^\top\boldsymbol{Y}$ 是 $\boldsymbol{Y}$ 向 $\boldsymbol{X}$ 列空间的正交投影。系数解释必须强调"控制其他变量不变"的偏效应含义。

多重共线性是多元回归特有的核心问题，VIF 是主要诊断工具，处理方法有变量选择、主成分回归和岭回归。变量选择中 AIC 偏向预测，BIC 偏向模型简洁。回归诊断通过残差图和 Cook 距离检验模型假设和识别强影响点。

下一讲，我们将在多元回归的基础上，进入**广义线性模型**，重点讲解当因变量不是连续正态变量时（比如二分类的0/1结果，或计数数据）如何建立回归模型，核心方法是在多元统计中应用极广的 **Logistic 回归**。

# 第十二讲：Logistic 回归与广义线性模型——当因变量不再是连续的

---

## 线性回归的边界在哪里？

上一讲建立的多元线性回归框架非常强大，但它有一个隐含的前提：**因变量 $Y$ 是连续的，且在理论上可以取任意实数值**。这在很多问题中是合理的——成绩、收入、温度都是连续变量。

但现实中大量重要的问题，因变量根本不是连续的。

一家银行想预测贷款申请者是否会违约，$Y$ 只有两个值：1（违约）或0（不违约）。一位医生想根据病理指标判断肿瘤是恶性还是良性。一个推荐系统想预测用户是否会点击某篇文章。这些都是**二分类问题**，$Y \in {0, 1}$。

如果把线性回归硬套在这种问题上，会发生什么？假设你用线性回归预测违约概率，拟合出的方程是 $\hat{Y} = 0.3 + 0.05X_1 - 0.02X_2$。当某个客户的预测值是 $\hat{Y} = 1.3$ 或 $\hat{Y} = -0.2$ 时，这个"概率"超出了 $[0,1]$ 的范围，根本没有意义。线性概率模型还有另一个问题：它假设自变量每增加一个单位，概率变化量是固定的，但概率靠近0或1时变化应该越来越难，而不是线性的。

**Logistic 回归**正是为了解决这个问题而生的——它保留了线性回归的线性预测器结构，同时通过一个巧妙的变换，保证预测值永远在 $(0,1)$ 之间，并且正确地描述了概率随预测变量变化的非线性模式。

---

## Logistic 回归的推导：从概率到对数优势比

### 第一步：从概率到优势比

设 $p = P(Y=1 \mid \boldsymbol{x})$ 是给定预测变量 $\boldsymbol{x}$ 时，$Y=1$ 的概率。

首先把概率变换为**优势比（odds）**：

$$\text{odds} = \frac{p}{1-p}$$

优势比的含义是：事件发生的概率与不发生的概率之比。如果 $p = 0.75$，则 $\text{odds} = 0.75/0.25 = 3$，意思是"发生的可能性是不发生的3倍"。

优势比的范围是 $(0, +\infty)$，比概率 $(0,1)$ 的范围更大，但仍然不是全体实数。

### 第二步：从优势比到对数优势比

再取自然对数，得到**对数优势比（log-odds，也叫 logit）**：

$$\text{logit}(p) = \ln\frac{p}{1-p}$$

当 $p \to 0$ 时，$\text{logit}(p) \to -\infty$；当 $p \to 1$ 时，$\text{logit}(p) \to +\infty$；当 $p = 0.5$ 时，$\text{logit}(p) = 0$。logit 的范围是 $(-\infty, +\infty)$，正好覆盖全体实数！

### 第三步：建立线性模型

现在对 logit 建立线性模型：

$$\ln\frac{p}{1-p} = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p$$

右边的线性预测器可以取任意实数，左边的 logit 也可以取任意实数——两边的值域完美匹配！

### 第四步：反解出概率

把上面的方程反解，得到概率关于预测变量的表达式：

$$p = P(Y=1 \mid \boldsymbol{x}) = \frac{e^{\beta_0 + \boldsymbol{\beta}^\top \boldsymbol{x}}}{1 + e^{\beta_0 + \boldsymbol{\beta}^\top \boldsymbol{x}}} = \frac{1}{1 + e^{-(\beta_0 + \boldsymbol{\beta}^\top \boldsymbol{x})}}$$

这个函数叫做 **Logistic 函数**（也叫 Sigmoid 函数），它把 $(-\infty, +\infty)$ 上的线性预测器"压缩"到 $(0,1)$ 内，形成一条漂亮的 S 形曲线——在中间部分近似线性，在两端趋向0和1时变得平坦。

---

## Logistic 函数的几何直觉

Logistic 函数的 S 形曲线有很好的实际意义。以信用评分（$X$，越高越好）预测违约概率（$p$）为例：评分极低时，违约概率接近1，且从"很低"变到"更低"时，概率变化很小（曲线平坦）；评分在中等水平时，概率变化最快（曲线最陡）；评分极高时，概率接近0，同样变化缓慢。

这种"两端平坦、中间陡峭"的形状，正确反映了现实中概率变化的规律：当事件已经几乎确定发生或不发生时，额外的信息对概率的影响很小；在不确定性最大的区域，信息最有价值。

---

## 参数估计：最大似然，而非最小二乘

Logistic 回归的系数**不能**用最小二乘法估计——因为残差 $Y_i - \hat{p}_i$ 不再满足正态分布（$Y_i$ 是0或1，$\hat{p}_i$ 是连续概率值）。

正确的估计方法是**最大似然估计（Maximum Likelihood Estimation，MLE）**。

第 $i$ 个观测的似然贡献是：

$$L_i = p_i^{Y_i}(1-p_i)^{1-Y_i}$$

这个表达式很巧妙：当 $Y_i = 1$ 时，$L_i = p_i$（希望概率大）；当 $Y_i = 0$ 时，$L_i = 1 - p_i$（希望概率小）。

取对数，得到对数似然：

$$\ell(\boldsymbol{\beta}) = \sum_{i=1}^n \left[Y_i \ln p_i + (1-Y_i)\ln(1-p_i)\right]$$

最大化 $\ell(\boldsymbol{\beta})$ 对 $\boldsymbol{\beta}$ 没有解析解，需要用**Newton-Raphson 迭代**（或其等价的迭代加权最小二乘 IRLS）数值求解。具体迭代细节这里不展开，实际中统计软件会自动完成。

MLE 在大样本下有优良的统计性质：**一致性**（估计量收敛到真实值）、**渐近正态性**（估计量的分布近似正态，可以做 $z$ 检验）、**渐近有效性**（在所有一致估计中方差最小）。

---

## 系数的解释：对数优势比的变化

Logistic 回归系数的解释与线性回归根本不同，是初学者最容易出错的地方。

**$\hat{\beta}_j$ 的含义**：在保持其他变量不变的条件下，$X_j$ 增加1个单位，**对数优势比增加 $\hat{\beta}_j$**。

等价地，$e^{\hat{\beta}_j}$ 是**优势比（odds ratio，OR）**：$X_j$ 增加1个单位，优势比变为原来的 $e^{\hat{\beta}_j}$ 倍。

这个解释有三个关键点要记住。

第一，系数描述的是对数优势比（或优势比）的变化，**不是概率的变化**。"优势比增加"不等于"概率增加了同样的量"——概率的变化量取决于当前的概率水平（在S曲线的哪个位置）。

第二，$e^{\hat{\beta}_j} > 1$ 意味着 $X_j$ 增加时，事件发生的优势比增大（正向效应）；$e^{\hat{\beta}_j} < 1$ 意味着优势比减小（负向效应）；$e^{\hat{\beta}_j} = 1$（即 $\hat{\beta}_j = 0$）意味着 $X_j$ 与结果无关。

第三，优势比有对称性：如果某因素使优势比变为2倍，那么该因素不存在时，优势比就是原来的 $1/2$。

**一个具体例子**：假设 $\hat{\beta}_{\text{年龄}} = 0.04$，那么 $e^{0.04} \approx 1.041$。这意味着年龄每增加1岁，违约的优势比增加约4.1%，在其他条件不变的情况下。这不代表违约概率增加4.1%——如果基础违约概率是50%（优势比为1），增加4.1%后优势比为1.041，对应概率为 $1.041/2.041 \approx 51%$，增加约1个百分点。但如果基础违约概率是10%（优势比为0.111），增加4.1%后优势比为0.1155，对应概率约为10.4%，增加只有0.4个百分点。

## 模型评估：Logistic 回归的检验工具

### 系数的显著性检验

由于MLE的渐近正态性，单个系数的检验用 **Wald 检验**：

$$z_j = \frac{\hat{\beta}_j}{\text{se}(\hat{\beta}_j)} \overset{a}{\sim} N(0,1)$$

大样本下 $z_j^2 \sim \chi^2(1)$，$p$ 值可以直接计算。对于小样本，Wald 检验不太可靠，此时推荐用**似然比检验（Likelihood Ratio Test，LRT）**：

$$G^2 = -2[\ell(\text{简化模型}) - \ell(\text{完整模型})] \sim \chi^2(df)$$

其中 $df$ 是两个模型参数个数之差。LRT 在样本量不大时比 Wald 检验更可靠。

### 拟合优度：偏差与伪 $R^2$

Logistic 回归没有 $R^2$ 的直接对应物（因为没有"总平方和"的概念），但有几个类似的指标。

**偏差（Deviance）** 定义为：

$$D = -2\ell(\hat{\boldsymbol{\beta}})$$

这是模型对数似然的负两倍，越小说明拟合越好。可以用于比较嵌套模型（两个模型的偏差之差服从 $\chi^2$ 分布）。

**McFadden 伪 $R^2$**：

$$R^2_{McFadden} = 1 - \frac{\ell(\hat{\boldsymbol{\beta}})}{\ell(\hat{\beta}_0)}$$

其中 $\ell(\hat{\beta}_0)$ 是只有截距的零模型的对数似然。伪 $R^2$ 在0到1之间，越大越好，但不能与线性回归的 $R^2$ 直接比较——McFadden 伪 $R^2$ 在 0.2 到 0.4 之间就已经代表相当好的拟合了。

### 分类性能：混淆矩阵与 ROC 曲线

Logistic 回归给出的是概率预测，要转化为类别预测，需要选择一个**分类阈值（cutoff）** $c$：若 $\hat{p}_i > c$ 则预测 $Y_i = 1$，否则预测 $Y_i = 0$。通常默认 $c = 0.5$，但在类别不平衡或误分类代价不对称时，需要调整。

给定阈值 $c$，分类结果用**混淆矩阵（confusion matrix）** 来总结：

||预测正例（1）|预测负例（0）|
|:--|:-:|:-:|
|**真实正例（1）**|TP（真正例）|FN（假负例）|
|**真实负例（0）**|FP（假正例）|TN（真负例）|

从混淆矩阵可以计算多个性能指标：

**敏感度（Sensitivity）**，又叫真正例率（TPR）：$\text{TPR} = \frac{TP}{TP+FN}$，模型正确识别真实正例的比例。

**特异度（Specificity）**：$\frac{TN}{TN+FP}$，模型正确识别真实负例的比例。

**ROC 曲线（Receiver Operating Characteristic Curve）** 把阈值 $c$ 从0变化到1，对应的 TPR（纵轴）和假正例率 FPR = $1-\text{Specificity}$（横轴）画出的曲线。完美模型的ROC曲线经过左上角（$(0,1)$），随机猜测的ROC曲线是对角线。

**AUC（Area Under the Curve）** 是ROC曲线下的面积，取值在0.5（随机猜测）到1（完美分类）之间。AUC 是评估分类模型最常用的单一指标，因为它不依赖于阈值的选择，反映了模型在所有可能阈值下的综合性能。AUC 的直觉解释是：**随机选取一个正例和一个负例，模型给正例打分高于负例的概率等于 AUC**。

## 广义线性模型的统一框架

Logistic 回归并不是孤立的方法，它是**广义线性模型（Generalized Linear Models，GLM）** 框架的一个特例。理解这个框架，能让你把多种看似不同的回归方法统一在同一个视角下。

广义线性模型由三个部分组成。

**随机成分**：因变量 $Y$ 的分布，属于**指数族分布（exponential family）**的某个成员。线性回归用正态分布，Logistic 回归用二项分布，计数数据用泊松分布，生存时间用伽马分布……

**系统成分**：线性预测器 $\eta = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p$，与线性回归完全相同。

**连接函数（link function）**：连接均值 $\mu = E(Y)$ 与线性预测器 $\eta$ 的函数 $g$，使得 $g(\mu) = \eta$。不同的分布有不同的典型连接函数。

|因变量类型|分布|连接函数 $g(\mu)$|模型名称|
|:--|:--|:--|:--|
|连续，正态|正态|$\mu$（恒等函数）|线性回归|
|二分类（0/1）|二项|$\ln\frac{\mu}{1-\mu}$（logit）|Logistic 回归|
|计数数据|泊松|$\ln(\mu)$（对数）|泊松回归|
|正连续数据|伽马|$\ln(\mu)$（对数）|伽马回归|
|有序多分类|多项|累积 logit|有序 Logistic 回归|

这个框架的美妙之处在于：**所有 GLM 的参数估计都用最大似然，都可以用迭代加权最小二乘（IRLS）数值求解，系数的推断都依赖相同的渐近理论。** 你只需要根据因变量的类型选择合适的分布和连接函数，其余的框架是统一的。

### 泊松回归：处理计数数据

当因变量是计数数据（如某网站每天的访客数、某地区每年的交通事故数、某药物临床试验中的不良事件次数），且取值为非负整数时，应该用**泊松回归**，而不是线性回归。

泊松回归的模型是：

$$\ln(\mu_i) = \beta_0 + \beta_1 X_{i1} + \cdots + \beta_p X_{ip}$$

或等价地：$\mu_i = e^{\beta_0 + \boldsymbol{\beta}^\top \boldsymbol{x}_i}$。

系数 $\hat{\beta}_j$ 的解释：$X_j$ 增加1个单位，$\mu$（计数均值）变为原来的 $e^{\hat{\beta}_j}$ 倍。这叫做**发生率比（incidence rate ratio，IRR）**。

泊松回归有一个重要假设：均值等于方差（泊松分布的性质）。现实中计数数据经常出现**过离散（overdispersion）**——方差远大于均值，违反了泊松假设。此时应该用**负二项回归（Negative Binomial Regression）**，它允许均值和方差独立，是处理过离散计数数据的标准方案。

## Logistic 回归 vs. 判别分析：什么时候用哪个？

这是一个学完这两讲之后必然会产生的问题。两者都可以做二分类问题，区别是什么？

**建模思路的区别**：判别分析（LDA）对每组数据的联合分布建模（$P(\boldsymbol{x} \mid Y = k)$），再用贝叶斯定理反推后验概率；Logistic 回归直接对后验概率建模（$P(Y=1 \mid \boldsymbol{x})$），不对 $\boldsymbol{x}$ 的分布做任何假设。

**假设条件的区别**：LDA 假设各组数据服从多元正态分布且协方差矩阵相同，这是更强的假设；Logistic 回归对 $\boldsymbol{x}$ 的分布不做任何假设，只对条件概率建模，假设更弱。

**实践中的选择**：如果数据真的接近多元正态，LDA 的参数效率更高（更少的数据就能达到同样的效果），表现可能优于 Logistic 回归；如果数据明显非正态（比如有大量分类型预测变量），Logistic 回归更合适。现代实践中，Logistic 回归的应用更广泛，因为它假设更少，解释更直接，且预测变量可以是任意类型的混合。

---

## 本讲的核心收获

Logistic 回归通过 logit 连接函数，把线性预测器与概率联系起来，保证预测值永远在 $(0,1)$ 之间，正确描述了概率随预测变量变化的 S 形非线性关系。参数用最大似然估计，系数解释为对数优势比的变化，$e^{\hat{\beta}_j}$ 是优势比（odds ratio）。

模型评估使用似然比检验、伪 $R^2$、混淆矩阵和 AUC-ROC 曲线。AUC 是不依赖阈值的综合分类性能指标，其直觉是"模型给随机正例打分高于随机负例的概率"。

Logistic 回归是广义线性模型（GLM）框架的一个特例，该框架通过选择不同的随机成分（分布族）和连接函数，统一处理了正态、二项、泊松等各种类型因变量的回归问题。
