## 弹性力学入门讲义

### 第一节：从胡克定律到连续介质——弹性力学的世界观

---

#### 一、此前已经知道的：高中的弹簧模型

高中物理里，我们学过**胡克定律**：

F=kx

弹簧受力 F，伸长量为 x，k 是弹簧的劲度系数。

这个公式简洁优美，但它描述的是一根**整体的弹簧**——我们不关心弹簧内部发生了什么，只关心两端的力和总形变量。

这就像把弹簧当成一个"黑箱"。

**弹性力学要做的，就是打开这个黑箱。**

---

#### 二、从弹簧到固体：三个追问

打开黑箱之后，我们自然会问三个问题：

**追问1：力是怎么在材料内部传递的？**

你拉弹簧的一端，另一端就有力。这个力是怎么从一个原子传到下一个原子，最终传遍整个物体的？

**追问2：形变是怎么分布的？**

弹簧伸长了5mm，但这5mm是均匀分布在每一圈上，还是集中在某几圈？橡皮泥被拉伸时，中间和两端的变形一样吗？

**追问3：材料什么时候会断裂？**

弹簧拉到什么程度会永久变形？桥梁在什么位置最危险？

高中物理无法回答这些问题。弹性力学就是为了回答这些问题而生的。

---

#### 三、弹性力学的核心假设：连续介质

现实中，金属是由离散的原子组成的，原子之间有间隙。但弹性力学做了一个重要的**简化假设**：

> 把固体看成**连续分布的介质**，忽略原子间隙，认为物质充满整个空间。

这就像我们研究水流时，不去考虑每个水分子，而是把水看成连续的流体。

这个假设在宏观尺度下极其精确。只要我们关心的结构尺寸远大于原子间距（~0.3纳米），连续介质假设就成立。

**类比：** 从飞机上看海面，海浪是连续平滑的曲面；但凑近看，海面是由无数水分子跳动的。弹性力学永远站在"飞机高度"看问题。

---

#### 四、弹性力学的三大支柱

整个弹性力学建立在三类方程的基础上：

```
┌─────────────────────────────────────────────┐
│           弹性力学的三大支柱                  │
│                                             │
│  1. 几何方程          2. 物理方程            │
│   （变形怎么描述）      （材料怎么响应）       │
│        ↓                    ↓               │
│   应变 ε ←──────────────── 应力 σ           │
│        ↑                    ↑               │
│        └──── 3. 平衡方程 ───┘               │
│              （力怎么平衡）                   │
└─────────────────────────────────────────────┘
```

|支柱|高中对应概念|弹性力学的升级|
|---|---|---|
|**几何方程**|伸长量 x|应变张量 εij（描述各个方向的变形）|
|**物理方程**|胡克定律 F=kx|广义胡克定律（应力与应变的张量关系）|
|**平衡方程**|∑F=0|微元体的平衡微分方程|

后续每一节，我们都会深入讲解其中一个支柱。

---

#### 五、两个最重要的新概念预告

在结束第一节之前，先认识两个贯穿全课程的核心概念：

##### 🔵 应力（Stress）—— 内部的"力的强度"

高中说"弹力是10N"，但同样是10N，作用在细钢丝上和作用在粗钢柱上，危险程度完全不同。

**应力 = 力 ÷ 面积**，单位是帕斯卡（Pa）。

它描述的是材料内部某一截面上，单位面积承受的力。这才是材料"感受到"的真实负担。

##### 🔵 应变（Strain）—— 相对变形量

高中说"弹簧伸长了5mm"，但同样是5mm，对1cm的弹簧和1m的弹簧意义完全不同。

**应变 = 伸长量 ÷ 原长**，无量纲。

它描述的是材料内部的相对变形，才能公平地比较不同尺寸的物体。

## 第二节：应力——材料内部的力

---

### 一、一个思想实验：把钢柱切开

想象一根竖直的钢柱，顶上压着重物 F=1000 N。

```
        ↓ F = 1000 N
      ┌─────┐
      │     │
      │  钢  │  ← 柱子内部"感受"到了什么？
      │  柱  │
      │     │
      └─────┘
        ↑ 1000 N（地面支撑）
```

但**钢柱内部**的力是多少？

**思想实验：用一把无限锋利的刀，水平切开钢柱。**

切开瞬间，上半段和下半段失去了联系。如果不施加任何外力，上半段会因为重力（和顶部压力）而落下。

这说明：**切开之前，下半段对上半段一定有一个向上的支撑力。** 这个力的大小必须等于 1000 N（才能支撑上半段静止）。

这个"切开后才显现出来的内部力"，就是**内力**。

---

#### 二、从内力到应力

现在问一个关键问题：

> 如果钢柱的截面积是 1 cm²，和截面积是 100 cm² 的钢柱，它们都承受 1000 N，**危险程度一样吗**？

显然不一样。细的更危险，因为单位面积承受的力更大。

所以我们定义：

σ=FAσ=AF

这就是**应力**（stress），单位帕斯卡（Pa = N/m²）。

- 1 cm² 的钢柱：σ=1000/10−4=107 Pa = 10 MPa
- 100 cm² 的钢柱：σ=1000/10−2=105 Pa = 0.1 MPa

**应力才是材料真正"感受"到的力的强度。**

---

#### 三、应力的两种基本类型

刚才切开钢柱时，内力是**垂直于截面**的。但内力不一定都垂直于截面。

考虑两种情况：

**情况A：拉伸钢柱（截面水平切开）**

```
        ↑ F        内力垂直于截面
      ┌─────┐      →  正应力 σ
      │  ↑  │
      └─────┘
        ↓ F
```

**情况B：剪切一块橡皮（截面水平切开）**

```
   →→→→→→→        内力平行于截面
   ┌─────┐        →  切应力 τ
   │ → → │
   └─────┘
   ←←←←←←←
```

由此定义两种应力：

|名称|符号|方向|物理含义|
|---|---|---|---|
|**正应力**|σ (sigma)|垂直于截面|拉伸或压缩|
|**切应力**|τ (tau)|平行于截面|剪切、扭转|

约定：

- σ>0：拉应力（拉伸为正）
- σ<0：压应力
- τ 的正负方向后面再讲

---

#### 四、关键洞察：应力依赖于截面方向

这里有一个**最容易让初学者困惑**的点，请仔细思考。

回到拉伸的钢柱。如果我们**斜着切**，会发生什么？

```
        ↑ F = 1000 N
      ┌─────┐
      │   ╱ │     ← 沿斜面切开
      │ ╱   │
      └─────┘
        ↓ F
```

斜面上的内力还是 1000 N（因为支撑上半段的总力没变），但**斜面的面积变大了**！

如果原截面积 A = 10 cm²，斜面（45°）的面积约为 A/cos45°≈14.1A/cos45°≈14.1 cm²。

更重要的是：1000 N 的内力，在斜面上既不完全垂直，也不完全平行——它**同时有正应力和切应力**！

把 1000 N 分解到斜面的法向和切向：

σθ=FcosθA/cosθ=FAcos2θσθ=A/cosθFcosθ=AFcos2θτθ=FsinθA/cosθ=FAsinθcosθτθ=A/cosθFsinθ=AFsinθcosθ

**关键结论：**

> 在物体内部同一点，沿不同方向切开，得到的应力是不一样的！

这就引出一个深刻的问题：**要描述一点的应力状态，光给一个数 σ 是不够的。**

---

#### 五、应力的完整描述：应力张量

要完全描述一点的应力状态，需要在该点取一个**无穷小的立方体微元**，看它六个面上的应力。

```
        z
        ↑
        │     σ_zz
        │    ↑
        │   ┌──┐ → σ_zx
        │   │  │
   ─────┼───┴──┘──→ x
       /
     y
```

每个面上的应力可以分解为 1 个正应力 + 2 个切应力（沿两个切向方向）。三个面就有 9 个分量：

σ=(σxτxyτxzτyxσyτyzτzxτzyσz)σ=σxτyxτzxτxyσyτzyτxzτyzσz

**符号约定：** τxy 表示"作用在垂直于 x 轴的面上、沿 y 方向的切应力"。

第一个下标 = 截面的法向；第二个下标 = 力的方向。

这个由 9 个分量组成的量，叫做**应力张量**（stress tensor）。

---

#### 六、一个意外的对称性：切应力互等定理

9 个分量看起来很多，但其实**只有 6 个是独立的**。

考虑微元体的力矩平衡。如下图，把微元体的 xy 截面放大看：

```
         τ_yx
     ←←←←←←←←←
    ┌──────────┐ ↑
  ↓ │          │ ↑
  ↓ │          │ ↑  τ_xy
  ↓ │          │ ↑
    └──────────┘ ↑
     →→→→→→→→→
         τ_yx
```

如果 τxy≠τyxτxy=τyx，微元体会发生旋转——但它处于平衡，不能旋转！

通过力矩平衡（详细推导留作思考），可得：

τxy=τyx,τyz=τzy,τzx=τxz

这就是**切应力互等定理**。它意味着应力张量是**对称矩阵**：

σ=(σxτxyτxzτxyσyτyzτxzτyzσz)σ=σxτxyτxzτxyσyτyzτxzτyzσz

独立分量从 9 个减少到 **6 个**：3 个正应力 + 3 个切应力。

---

#### 七、一个具体例子：单向拉伸的应力分析

回到最初的钢柱拉伸问题，钢柱沿 z 轴方向。在钢柱内部任一点：

σ=(0000σ0)σ=0000σ0

只有 σz=σ0=F/A，其他全为零——这就是"单向应力状态"。

**但你斜着切呢？** 我们前面算过，斜面上既有正应力也有切应力。这两种描述是**等价**的——同一个应力张量，从不同坐标系看而已。

> 应力张量是这一点的本质，9 个分量只是它在某个坐标系下的"分身"。

这正是张量这个数学工具的威力：它本身是客观的，分量随坐标变化，但物理实质不变。

|**正应力 σ**|垂直于截面，对应拉/压|

## 第三节：应变——形变的精确描述

---

### 一、位移 ≠ 变形：一个容易混淆的区别

先看一个例子：把一块橡皮从桌子的左边平移到右边。

```
  ┌─────┐              ┌─────┐
  │     │    ─────→    │     │
  └─────┘              └─────┘
   原位置               新位置
```

橡皮上每个点都移动了，有**位移**。但橡皮有没有变形？**没有。** 它的形状和大小完全没变。

再看另一个例子：拉伸橡皮。

```
  ┌─────┐              ┌──────────┐
  │     │    ─────→    │          │
  └─────┘              └──────────┘
   原状态               拉伸后
```

这次橡皮有**变形**，也有位移。

**结论：位移是点的位置变化；变形是物体形状的改变。弹性力学关心的是变形，而不是位移本身。**

那么，如何从位移中提取出"真正的变形"？这是本节的核心问题。

---

#### 二、最简单的情况：一维应变

先从一维开始。一根长为 L 的杆，受拉后变为 L+ΔL。

ε=ΔLε=LΔL

这个量：

- 无量纲（长度/长度）
- ε>0 表示伸长，ε<0 表示压缩
- 描述的是**相对**变形，和绝对长度无关

**例子：** 1 m 的钢丝伸长 1 m，ε=0.001=10−3。钢的弹性应变通常在 10−3 量级以内，非常小。

但一维还远远不够，我们需要描述三维空间里任意形状的变形。

---

#### 三、从位移到应变：正式推导

##### 设置符号

在三维空间中，物体内每个点 (x,y,z) 受力后发生位移，设位移分量为：

u=u(x,y,z),v=v(x,y,z),w=w(x,y,z)

分别是 x、y、z 方向的位移。**注意：** 不同位置的点，位移可以不同。

##### 正应变的推导

考虑 x 轴方向上相距 dx 的两点 A 和 B：

```
变形前：  A ●────────────● B
              dx

变形后：  A'●──────────────● B'
               dx + (∂u/∂x)dx
```

A 点的位移是 u，B 点的位移是 u+∂u∂xdxu+∂x∂udx（泰勒展开，高阶项忽略）。

因此 AB 段的伸长量为：

δ=(u+∂u∂xdx)−u=∂u∂xdxδ=(u+∂x∂udx)−u=∂x∂udx

x 方向的正应变：

εx=δdx=∂u∂xεx=dxδ=∂x∂u

类似地：

εy=∂v∂y,εz=∂w∂zεy=∂y∂v,εz=∂z∂w

**三个正应变，分别描述三个方向的拉伸或压缩。**

---

#### 四、切应变：不只是拉伸，还有错动

正应变只描述了长度变化，但变形还有另一种形式——**角度变化**，即剪切。

考虑一个正方形微元，受剪切后变成平行四边形：

```
变形前：              变形后：

  D ●────────● C       D'●──────────● C'
    │        │           ╱          ╱
    │        │         ╱    γ     ╱
  A ●────────● B     A'●──────────● B'
```

AB 边转动了角度 α，AD 边转动了角度 β。

**切应变** γxy 定义为两条原本互相垂直的边，变形后夹角的改变量：

γxy=α+β

现在用位移来表达这个角度。

A 点在 y 方向位移为 v，B 点（沿 x 方向距 A 为 dx）在 y 方向位移为 v+∂v∂xdxv+∂x∂vdx。

所以 AB 边的转角：

α=(v+∂v∂xdx)−vdx=∂v∂xα=dx(v+∂x∂vdx)−v=∂x∂v

同理，AD 边的转角：

β=∂u∂yβ=∂y∂u

因此：

γxy=∂v∂x+∂u∂yγxy=∂x∂v+∂y∂u

三个方向的切应变：

γyz=∂w∂y+∂v∂z,γzx=∂u∂z+∂w∂xγyz=∂y∂w+∂z∂v,γzx=∂z∂u+∂x∂w

---

#### 五、一个关键问题：变形 vs 转动

这里有一个**非常深刻**的细节，教材往往一笔带过。

考虑一个微元，仅仅发生了**刚体转动**（没有任何变形）：

```
变形前：          转动后：

  ●────→          ↗
  │              ●
  ↓             ╱
               ╱  （整体旋转了 θ 角）
```

刚体转动时，∂v∂x≠0∂x∂v=0，∂u∂y≠0∂y∂u=0，但物体没有变形！

我们来看看这时候的 ∂v∂x∂x∂v 和 ∂u∂y∂y∂u：

- 纯转动（逆时针角度 θ 很小）：∂v∂x=θ∂x∂v=θ，∂u∂y=−θ∂y∂u=−θ

此时 γxy=θ+(−θ)=0 ✅ 正确！切应变为零。

这不是巧合，而是 γxy=∂v∂x+∂u∂yγxy=∂x∂v+∂y∂u 这个定义**刻意剔除了刚体转动**的结果。

位移梯度可以分解为：

∂ui∂xj=12(∂ui∂xj+∂uj∂xi)⏟应变（对称部分）+12(∂ui∂xj−∂uj∂xi)⏟刚体转动（反对称部分）∂xj∂ui=应变（对称部分）21(∂xj∂ui+∂xi∂uj)+刚体转动（反对称部分）21(∂xj∂ui−∂xi∂uj)

**弹性力学只关心对称部分——那才是真正的变形。**

---

#### 六、应变张量

把所有应变分量整理成矩阵，得到**应变张量** ε：

ε=(εxεxyεxzεxyεyεyzεxzεyzεz)ε=εxεxyεxzεxyεyεyzεxzεyzεz

其中正应变在对角线，切应变在非对角线。

⚠️ **注意一个约定：**

工程上常用的切应变 γxy 和张量切应变 εxy 的关系是：

εxy=12γxy=12(∂v∂x+∂u∂y)εxy=21γxy=21(∂x∂v+∂y∂u)

张量切应变多了一个 1221，这是为了让应变张量是**对称的**，与应力张量的结构完全一致。

|类型|对角元素|非对角元素|
|---|---|---|
|应力张量 σ|正应力 σx,σy,σzσx,σy,σz|切应力 τxy 等|
|应变张量 ε|正应变 εx,εy,εzεx,εy,εz|张量切应变 εxy 等|

两者结构完全对称，这不是巧合——后面讲广义胡克定律时，这种对称性将发挥重要作用。

---

#### 七、几何方程汇总

把位移 (u,v,w) 与应变联系起来的六个方程，统称为**几何方程**（又叫应变-位移关系）：

$$\boxed{ \begin{aligned} \varepsilon_{x} &= \frac{\partial u}{\partial x} \ \varepsilon_{y} &= \frac{\partial v}{\partial y} \ \varepsilon_{z} &= \frac{\partial w}{\partial z} \end{aligned} \qquad \begin{aligned} \varepsilon_{xy} &= \frac{1}{2}\left(\frac{\partial u}{\partial y} + \frac{\partial v}{\partial x}\right) \ \varepsilon_{yz} &= \frac{1}{2}\left(\frac{\partial v}{\partial z} + \frac{\partial w}{\partial y}\right) \ \varepsilon_{zx} &= \frac{1}{2}\left(\frac{\partial w}{\partial x} + \frac{\partial u}{\partial z}\right) \end{aligned} }$$

这就是弹性力学三大支柱中的**第一根支柱：几何方程**。

#### 八、体积应变：变形对体积的影响

最后介绍一个实用的量。正方体微元三个方向都发生正应变时，体积怎么变？

原体积：V=dx⋅dy⋅dz

变形后三边：(1+εx)dx，(1+εy)dy，(1+εz)dz

新体积：V′=(1+εx)(1+εy)(1+εz)⋅dx dy dzV′=(1+εx)(1+εy)(1+εz)⋅dxdydz

展开（忽略应变的高阶小量，因为弹性应变 ≪1≪1）：

V′≈(1+εx+εy+εz)⋅V′≈(1+εx+εy+εz)⋅V

**体积应变**（体胀量）定义为：

e=V′−V=εx+εy+εzze=V′−V=εx+εy+εz

即应变张量对角元素之和，也叫应变张量的**迹**（trace）。

> 切应变不改变体积，只改变形状——这个结论直觉上也是对的，平行四边形和正方形面积相同。

#### 九、本节小结

```
位移场 (u, v, w)
       │
       │  几何方程（对位移求偏导）
       ↓
应变张量 ε（6个独立分量）
  ├── 正应变 εxx, εyy, εzz  → 描述拉压
  ├── 切应变 εxy, εyz, εzx  → 描述剪切
  └── 体积应变 e = εxx+εyy+εzz → 描述体积变化
```

|概念|公式|物理意义|
|---|---|---|
|正应变|εx=∂u/∂xεx=∂u/∂x|x 方向相对伸长|
|切应变|εxy=12(∂u/∂y+∂v/∂x)εxy=21(∂u/∂y+∂v/∂x)|直角的改变量的一半|
|体积应变|e=εx+εy+εz|相对体积变化|
|关键区别|应变 ≠ 位移，应变 = 剔除刚体运动后的真实变形||
