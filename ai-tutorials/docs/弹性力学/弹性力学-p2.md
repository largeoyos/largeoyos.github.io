## 第四节：广义胡克定律——应力与应变的联系

---

### 一、回顾高中：弹簧的胡克定律

高中里，胡克定律写作：

F=kx⟹x=FkF=kx⟹x=kF

用应力和应变的语言改写：σ=Eε，即

ε=σEε=Eσ

其中 E 叫做**弹性模量**（Young's modulus），单位 Pa。

这就是一维胡克定律。E 越大，材料越"硬"——同样的应力，变形越小。

|材料|弹性模量 E|
|---|---|
|钢|210 GPa|
|铝|70 GPa|
|混凝土|30 GPa|
|橡胶|0.01～0.1 GPa|
|骨骼|15～25 GPa|

但这还只是一维的。真实世界是三维的，一个方向受力，**三个方向都会变形**。

---

#### 二、一个被高中忽略的现象：泊松效应

做一个简单的实验：拉伸一根橡皮筋。

```
拉伸前：   ┌──────────────┐
           │              │   宽度 b
           └──────────────┘
                长度 L

拉伸后：   ┌────────────────────┐
           │                    │  宽度 b' < b
           └────────────────────┘
                  长度 L' > L
```

轴向伸长了，但**横向变细了**！这叫**泊松效应**。

定义**泊松比** ν（念"nu"）：

ν=−横向应变轴向应变=−εyεxν=−轴向应变横向应变=−εxεy

负号是因为：轴向拉伸（εx>0）时横向收缩（εy<0），加负号使 ν>0。

|材料|泊松比 ν|
|---|---|
|钢|0.25～0.30|
|铝|0.33|
|混凝土|0.15～0.20|
|橡胶|≈ 0.50|
|软木|≈ 0（几乎不收缩）|

泊松比的理论范围是 −1<ν≤0.5。大多数材料 ν≈0.25∼0.35ν≈0.25∼0.35。

> **ν=0.5 意味着什么？** 体积不变！橡胶近似满足这个条件——拉伸时，它只改变形状，不改变体积。

---

#### 三、单向拉伸的三维应变

现在仅在 x 方向施加应力 σx（其他方向无应力），三个方向的应变分别是：

εx=σxxE（轴向伸长）εx=Eσx（轴向伸长）εy=−νσxxE（横向收缩）εy=−νEσx（横向收缩）εz=−νσxxE（横向收缩）εz=−νEσx（横向收缩）

**泊松比把三个方向的变形耦合在一起了。** 这是高中物理完全没有涉及的。

---

#### 四、叠加原理：三个方向同时受力

现在三个方向同时有正应力 σx、σy、σz，怎么办？

**叠加原理**（线弹性范围内成立）：每个应力分量独立产生的应变可以直接叠加。

以 εx 为例：

- σx 贡献：+σxxE+Eσx
- σy 贡献（泊松效应）：−νσyyE−Eνσy
- σz 贡献（泊松效应）：−νσzzE−Eνσz

三项叠加：

εx=1E[σx−ν(σy+σz)]εx=E1[σx−ν(σy+σz)]

类似地：

εy=1E[σy−ν(σx+σz)]εy=E1[σy−ν(σx+σz)]εz=1E[σz−ν(σx+σy)]εz=E1[σz−ν(σx+σy)]

---

#### 五、切应力与切应变的关系

正应力产生正应变，切应力产生切应变。对于切应变，胡克定律的形式是：

γxy=τxyG,γyz=τyzG,γzx=τzxGγxy=Gτxy,γyz=Gτyz,γzx=Gτzx

其中 G 叫**剪切模量**（shear modulus），单位同样是 Pa。

重要结论：**G 不是独立的材料常数！** 对于各向同性材料（各方向性质相同的材料），可以证明：

G=E2(1+ν)G=2(1+ν)E

以钢为例：E=210 GPa，ν=0.3，则 G=2102×1.3≈80.8G=2×1.3210≈80.8 GPa。

> 这意味着描述各向同性线弹性材料，**只需要两个独立常数：E 和 ν**。

---

#### 六、广义胡克定律完整形式

把所有关系汇总，得到**广义胡克定律**（弹性力学第二大支柱——物理方程）：

$$\boxed{ \begin{aligned} \varepsilon_{x} &= \frac{1}{E}\left[\sigma_{x} - \nu(\sigma_{y}+\sigma_{z})\right] \ \varepsilon_{y} &= \frac{1}{E}\left[\sigma_{y} - \nu(\sigma_{x}+\sigma_{z})\right] \ \varepsilon_{z} &= \frac{1}{E}\left[\sigma_{z} - \nu(\sigma_{x}+\sigma_{y})\right] \ \varepsilon_{xy} &= \frac{\tau_{xy}}{2G} \ \varepsilon_{yz} &= \frac{\tau_{yz}}{2G} \ \varepsilon_{zx} &= \frac{\tau_{zx}}{2G} \end{aligned} }$$

这六个方程，是**应力→应变**的完整映射，也可以反过来写成**应变→应力**。

---

#### 七、反过来：由应变求应力

工程中有时先测量应变（贴应变片），再推算应力。从广义胡克定律解出应力：

σx=E(1+ν)(1−2ν)[(1−ν)εx+ν(εy+εz)]σx=(1+ν)(1−2ν)E[(1−ν)εx+ν(εy+εz)]

写成更紧凑的形式，引入**拉梅常数**（Lamé constants）：

λ=νE(1+ν)(1−2ν),μ=G=E2(1+ν)λ=(1+ν)(1−2ν)νE,μ=G=2(1+ν)E

则：

σij=λe δij+2μεij

其中 e=εx+εy+εz 是体积应变，δij 是克罗内克符号（i=j 时为1，否则为0）。

这是弹性力学中**最优雅的写法**——两个拉梅常数，一个公式，概括了全部六个方程。

---

#### 八、体积应变与静水压力

把三个正应变方程相加，利用体积应变 e=εx+εy+εz：

e=1E[(σx+σy+σz)−2ν(σx+σy+σz)]e=E1[(σx+σy+σz)−2ν(σx+σy+σz)]e=1−2νE(σx+σy+σz)=pKe=E1−2ν(σx+σy+σz)=Kp

其中定义**平均应力**（静水压力）p=σx+σy+σz3p=3σx+σy+σz，以及**体积模量**：

K=E3(1−2ν)K=3(1−2ν)E

这给出了一个漂亮的物理图像：

```
  体积变化  ←────────────────→  形状变化

  由平均应力决定               由偏应力决定
  体积模量 K 控制              剪切模量 G 控制

  ν → 0.5 时，K → ∞           材料不可压缩
  ν → 0 时，K = E/3
```

## 第五节：平衡方程——力在材料内部如何传递

---

### 一、从质点平衡到连续体平衡

高中物理里，对一个质点列平衡方程非常简单：

∑Fx=0,∑Fy=0,∑Fz=0

但连续体不是质点，它是由**无穷多个点**组成的。每个点的受力情况可以不同，应力在空间中连续变化。

问题变成：**如果应力在空间中不均匀分布，每一个小微元体如何保持平衡？**

这正是平衡方程要回答的。

---

#### 二、微元体的受力分析

在物体内部取一个边长为 dx、dy、dz 的无穷小正方体微元：

```
              σ_yy + (∂σ_yy/∂y)dy
              ↑
         ─────┼─────
        ╱     ↑     ╱│
       ╱      │    ╱ │
      ┌───────────┐  │  → σ_xx + (∂σ_xx/∂x)dx
      │           │  │
  ←   │           │  ┘
 σ_xx │           │ ╱
      │           │╱
      └───────────┘
              │
              ↓ σ_yy
```

关键观察：**微元体两个相对面上的应力不相等！**

以 x 方向为例，左面的正应力是 σx，右面（距离 dx）的正应力是：

σx+∂σx∂xdxσx+∂x∂σxxdx

这个差值 ∂σx∂xdx∂x∂σxxdx 就是应力在空间的变化率——正是这种变化率产生了合力。

---

#### 三、推导 x 方向的平衡方程

对微元体，在 x 方向上列出所有力（只考虑正应力和切应力在 x 方向的贡献）：

**来自左右面（法向 x）的正应力：**

(σx+∂σx∂xdx)dy dz−σx dy dz=∂σx∂xdx dy dz(σx+∂x∂σxxdx)dydz−σxxdydz=∂x∂σxxdxdydz

**来自前后面（法向 y）的切应力 τyx：**

(τyx+∂τyx∂ydy)dx dz−τyx dx dz=∂τyx∂ydx dy dz(τyx+∂y∂τyxdy)dxdz−τyxdxdz=∂y∂τyxdxdydz

**来自上下面（法向 z）的切应力 τzx：**

∂τzx∂zdx dy dz∂z∂τzxdxdydz

**体力**（重力、磁力等分布在体积内的力）：设 x 方向体力密度为 fx（单位 N/m³）：

fx dx dy dzfxdxdydz

静力平衡要求 x 方向合力为零，除以 dx dy dzdxdydz：

∂σx∂x+∂τyx∂y+∂τzx∂z+fx=0∂x∂σx+∂y∂τyx+∂z∂τzx+fx=0

---

#### 四、三个方向的平衡方程

完全类比，y 和 z 方向也能列出同样形式的方程。三个平衡方程合在一起：

$$\boxed{ \begin{aligned} \frac{\partial \sigma_{x}}{\partial x} + \frac{\partial \tau_{yx}}{\partial y} + \frac{\partial \tau_{zx}}{\partial z} + f_x &= 0 \[6pt] \frac{\partial \tau_{xy}}{\partial x} + \frac{\partial \sigma_{y}}{\partial y} + \frac{\partial \tau_{zy}}{\partial z} + f_y &= 0 \[6pt] \frac{\partial \tau_{xz}}{\partial x} + \frac{\partial \tau_{yz}}{\partial y} + \frac{\partial \sigma_{z}}{\partial z} + f_z &= 0 \end{aligned} }$$

这就是弹性力学的**第三大支柱：平衡微分方程**。

用张量指标记法，三个方程可以合并成一行：

∂σij∂xj+fi=0∂xj∂σij+fi=0

其中求和遵循**爱因斯坦求和约定**（重复下标自动求和）。这一行字，包含了全部三个方程。

---

#### 五、深入理解：平衡方程的物理含义

平衡方程看起来是数学，但它有深刻的物理意义。

以第一个方程为例：

∂σx∂x+∂τyx∂y+∂τzx∂z+fx=0∂x∂σx+∂y∂τyx+∂z∂τzx+fx=0

用语言翻译：

> **"x 方向的体力" + "应力在 x 方向产生的合力（来自三个面）" = 0**

这里有一个非常优美的物理图像——**应力梯度就是力**：

应力梯度∼∂σ∂x⟺单位体积的力应力梯度∼∂x∂σ⟺单位体积的力

类比流体力学：压强梯度 −∂p/∂x−∂p/∂x 就是流体单位体积受到的压力驱动力（这正是伯努利方程的核心）。

**直觉：** 如果一点的应力四面八方都相等，那合力为零；只有当应力分布不均匀时，才有净力，微元才"感受"到力。

---

#### 六、一个生动的类比：水压与平衡

想象深海中的一个水微元。水压随深度增大：

p(z)=p0+ρgz

在 z 方向，压强梯度产生的向上合力恰好平衡重力：

−∂p∂z=ρg=fz−∂z∂p=ρg=fz

这正是流体的平衡方程！弹性力学的平衡方程是它的推广——从标量压强推广到张量应力。

```
流体（简单）：         弹性体（完整）：

  ∂p/∂z + ρg = 0      ∂σ_ij/∂x_j + f_i = 0

  只有压强（1个量）      有完整应力张量（6个量）
  各向同性               可以各向异性
```

---

#### 七、动力学情形：不平衡时怎么办

如果微元体不静止，而是在加速运动，牛顿第二定律变为 F=ma。

设材料密度为 ρ，加速度为 u¨iu¨i，平衡方程升级为**运动方程**：

∂σij∂xj+fi=ρu¨i∂xj∂σij+fi=ρu¨i

右端 ρu¨iρu¨i 是单位体积的惯性力（类比 ma）。

这是弹性动力学的基础方程——描述**弹性波**（地震波、超声波）传播的方程就从这里出发。

静力学是动力学的特例（加速度为零）。

---

#### 八、边界条件：方程的"边界"

平衡方程是在物体**内部**成立的。但要完整求解问题，还需要知道物体**表面**的条件，即**边界条件**。

边界条件有两类：

##### 🔵 力边界条件（应力边界条件）

在物体表面，已知外力的分布。

设表面某点的外法向量为 n=(nx,ny,nz)，表面受到的面力为 T=(Tx,Ty,Tz)，则：

Ti=σijnj

展开写：

Tx=σxxnx+τyxny+τzxnzTy=τxynx+σyyny+τzynzTz=τxznx+τyzny+σzznz

这叫**柯西公式**（Cauchy formula），它把表面力与内部应力联系起来。

**物理意义：** 表面的外法向量决定了"从哪个角度切开"，应力张量则决定了切开后截面上的力。

##### 🔵 位移边界条件

在物体表面某些部分，已知位移（通常是固定约束）：

ui=uˉi（已知值）ui=uˉi（已知值）

例如悬臂梁的固定端：u=v=w=0。

##### 混合边界条件

实际问题往往是：一部分边界给定力，另一部分边界给定位移。

```
┌────────────────────────┐
│                        │ ← 已知面力 T（力边界条件）
│      弹性体             │
│                        │
└────────────────────────┘
         ↑
    固定端：u=v=w=0
   （位移边界条件）
```

#### 九、把三大支柱合在一起

现在三大支柱全部就位，来看整个弹性力学问题的结构：

```
已知：
  外力（体力 f，面力 T）
  边界约束（位移边界条件）
  材料参数（E, ν）

未知量：
  位移场：u, v, w        （3个函数）
  应变场：εij            （6个函数）
  应力场：σij            （6个函数）
  共 15 个未知函数

方程：
  几何方程（第三节）       6个方程   ε ← u
  广义胡克定律（第四节）   6个方程   σ ← ε
  平衡方程（本节）         3个方程   ∂σ/∂x + f = 0
  共 15 个方程

方程数 = 未知数数 ✅  问题在数学上封闭！
```

这是一个**完备的偏微分方程组**，理论上可以求解任意弹性力学问题。

#### 十、化简：纳维方程

实际求解时，15个方程太多，能不能化简？

把广义胡克定律代入平衡方程，再利用几何方程，可以消去应力和应变，只保留**位移**作为未知量。最终得到**纳维方程**（Navier equations）：

(λ+μ)∂e∂xi+μ∇2ui+fi=0(λ+μ)∂xi∂e+μ∇2ui+fi=0

其中：

- e=εx+εy+εz 是体积应变
- ∇2=∂2∂x2+∂2∂y2+∂2∂z2∇2=∂x2∂2+∂y2∂2+∂z2∂2 是拉普拉斯算子
- λ、μ 是拉梅常数

**15个方程化简为3个方程，只求3个未知位移函数。** 这是弹性力学的标准求解路线。

---

#### 十一、一个简单例子：均匀受压的球

球形弹性体，表面均匀受压力 p（静水压力状态）。

由对称性，应力状态为：

σx=σy=σz=−p,τxy=τyz=τzx=0

验证平衡方程（无体力 f=0）：

∂(−p)∂x+∂0∂y+∂0∂z=0✓∂x∂(−p)+∂y∂0+∂z∂0=0✓

（因为 p 是常数，偏导为零）

这个均匀应力场自动满足平衡方程。再由广义胡克定律（第四节），体积应变：

e=3(1−2ν)E(−p)=−pKe=E3(1−2ν)(−p)=−Kp

负号表示体积压缩，与直觉一致。
