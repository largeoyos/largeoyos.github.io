## 第六节：平面问题——化三维为二维的艺术

---

### 一、为什么需要简化？

上一节建立了完整的三维弹性力学方程组：15个未知函数，15个偏微分方程。理论上完备，但实际求解极其困难——大多数三维问题没有解析解。

工程师的智慧在于：**识别问题的几何特征，合理降维。**

现实中有大量结构，虽然是三维的，但由于几何形状或载荷的特殊性，第三个方向的信息是"冗余"的——忽略它，问题从三维降为二维，方程数从15个降到**5个**，求解难度大幅下降。

这就是**平面问题**。

平面问题有两种截然不同的类型，初学者极容易混淆：

---

#### 二、第一种：平面应力（Plane Stress）

##### 适用场景

**薄板**在板面内受力：

```
        ↑↑↑↑↑ 面内载荷
      ┌──────────┐
      │          │  厚度 t 很小
  →→→ │  薄  板  │ →→→
      │          │
      └──────────┘
        ↓↓↓↓↓

  z 方向（厚度方向）：无约束，可自由变形
```

**典型例子：** 飞机蒙皮、压力容器壁、薄板冲压件。

##### 核心假设

板很薄，z 方向（厚度方向）的应力可以忽略：

σz=0,τxz=0,τyz=0

**直觉理解：** 板的上下表面是自由面，没有外力，所以 σz=0 在上下表面成立。薄板的厚度很小，应力来不及从零"积累"出大的值，所以整个厚度上都近似为零。

##### 保留的量

非零的应力只有三个：

σx,σy,τxyσx,σy,τxy

##### 对应的应变

代入广义胡克定律：

εx=1E(σx−νσy)εx=E1(σx−νσy)εy=1E(σy−νσx)εy=E1(σy−νσx)εz=−νE(σx+σy)εz=−Eν(σx+σy)εxy=τxy2Gεxy=2Gτxy

注意：εz≠0εz=0！虽然 z 方向没有应力，但由于泊松效应，z 方向**有应变**——薄板在面内受拉时，厚度会变薄。

> 平面应力：**应力是二维的，应变是三维的。**

---

#### 三、第二种：平面应变（Plane Strain）

##### 适用场景

**很长的柱体**，沿轴向均匀受力：

```
                      ← 很长（沿 z 方向）→

          ┌──────────────────────────────┐
         ╱│                              │╲
       │  │      任意截面形状             │  │
        ╲ │                              │ ╱
          └──────────────────────────────┘

  截面（xy 平面）内受力，z 方向无穷长（或被约束）
```

**典型例子：** 挡土墙、大坝、隧道、长管道、地基。

##### 核心假设

由于结构无限长且截面不变，沿 z 方向不可能有变形：

εz=0,εxz=0,εyz=0

**直觉理解：** 柱体太长，任何一个截面的变形都和相邻截面一样，z 方向没有相对位移，因此 εz=0。

##### 对应的应力

由广义胡克定律，εz=0 意味着：

0=1E[σz−ν(σx+σy)]0=E1[σz−ν(σx+σy)]σz=ν(σx+σy)

注意：σz≠0σz=0！虽然 z 方向没有应变，但**有应力**——这是维持 εz=0 所必须的约束反力。

> 平面应变：**应变是二维的，应力是三维的。**

---

#### 四、两种平面问题的对比

```
┌─────────────┬──────────────────────┬──────────────────────┐
│             │    平面应力           │    平面应变           │
├─────────────┼──────────────────────┼──────────────────────┤
│ 适用对象    │ 薄板（厚度 ≪ 面积）   │ 长柱体（长度 ≫ 截面） │
│ 典型例子    │ 飞机蒙皮、薄壁容器   │ 大坝、隧道、挡土墙   │
│ 零应力      │ σzz=τxz=τyz=0        │ —                    │
│ 零应变      │ —                    │ εzz=εxz=εyz=0        │
│ 特殊之处    │ εzz≠0（泊松收缩）    │ σzz≠0（约束反力）    │
│ 独立未知量  │ σxx,σyy,τxy          │ σxx,σyy,τxy          │
└─────────────┴──────────────────────┴──────────────────────┘
```

**神奇的是：两种情况的控制方程形式完全相同！** 只是材料常数的对应关系不同。

平面应变可以用平面应力的方程，只需做替换：

E→E1−ν2,ν→ν1−νE→1−ν2E,ν→1−ν

这说明两类问题在数学上是统一的。

#### 五、平面问题的方程组

两种平面问题都归结为求解同一套二维方程，未知量只有三个：σx，σy，τxy。

**平衡方程（二维）：**

∂σx∂x+∂τxy∂y+fx=0∂x∂σx+∂y∂τxy+fx=0∂τxy∂x+∂σy∂y+fy=0∂x∂τxy+∂y∂σy+fy=0

**变形协调方程：**

除了平衡方程，还需要一个条件：应变必须来自单值连续的位移场（不能出现"撕裂"或"重叠"）。

由几何方程推导，三个应变分量 εx、εy、εxy 满足：

∂2εx∂y2+∂2εy∂x2=2∂2εxy∂x∂y∂y2∂2εx+∂x2∂2εy=2∂x∂y∂2εxy

这叫**变形协调方程**（相容方程）。

直觉理解：三个应变分量都由两个位移函数 u、v 决定，它们之间不是独立的，必须满足某种约束关系。协调方程正是这种约束。

---

#### 六、艾里应力函数：一箭三雕的妙招

现在有两个平衡方程、一个协调方程，共三个方程，三个未知量。能否进一步化简？

**艾里（Airy）1862年的天才想法：**

引入一个**标量函数** φ(x,y)（艾里应力函数），定义：

σx=∂2φ∂y2,σy=∂2φ∂x2,τxy=−∂2φ∂x∂yσx=∂y2∂2φ,σy=∂x2∂2φ,τxy=−∂x∂y∂2φ

**验证：** 将这三个表达式代入平衡方程（无体力）：

∂∂x(∂2φ∂y2)+∂∂y(−∂2φ∂x∂y)=∂3φ∂x∂y2−∂3φ∂x∂y2=0✓∂x∂(∂y2∂2φ)+∂y∂(−∂x∂y∂2φ)=∂x∂y2∂3φ−∂x∂y2∂3φ=0✓

**平衡方程自动满足！** 这是艾里函数最大的优点——只要应力由 φ 的二阶偏导定义，平衡方程就永远成立，不需要再验证。

三个未知量 (σx,σy,τxy) 被一个函数 φ 代替。

---

#### 七、双调和方程：弹性力学最经典的方程

现在只剩一个条件没用——协调方程。

把艾里函数定义的应力代入广义胡克定律得到应变，再代入协调方程，整理后得到：

∇4φ=0∇4φ=0

其中 ∇4∇4 是**双调和算子**（重调和算子）：

∇4=∇2∇2=(∂2∂x2+∂2∂y2)2=∂4∂x4+2∂4∂x2∂y2+∂4∂y4∇4=∇2∇2=(∂x2∂2+∂y2∂2)2=∂x4∂4+2∂x2∂y2∂4+∂y4∂4

展开写：

∂4φ∂x4+2∂4φ∂x2∂y2+∂4φ∂y4=0∂x4∂4φ+2∂x2∂y2∂4φ+∂y4∂4φ=0

这就是**双调和方程**，也叫重调和方程。

```
三维弹性力学                    平面问题

15个方程，15个未知函数   →   1个方程，1个未知函数

  纳维方程（3个）         →      ∇⁴φ = 0

这是弹性力学最大的化简成就之一
```

**双调和方程的神奇性质：**

- 与材料常数 E、ν **无关**！（对平面应力和平面应变都成立）
- 这意味着：在同样边界条件下，**所有各向同性弹性材料的应力分布完全相同**，与 E、ν 无关。
- 材料常数只影响位移和应变，不影响应力。

#### 八、求解双调和方程：构造多项式解

最简单的求解方法是猜多项式形式的 φ。

**任何次数 ≤3≤3 的完整多项式都自动满足双调和方程**（因为四阶导数为零）。

**例一：φ=a2y2φ=2ay2**

σx=∂2φ∂y2=a,σy=0,τxy=0σx=∂y2∂2φ=a,σy=0,τxy=0

这描述的是**均匀单向拉伸**（x 方向均匀应力 σx=a）。

**例二：φ=b2x2φ=2bx2**

σx=0,σy=b,τxy=0

均匀单向拉伸，但换了方向。

**例三：φ=cxy**

σx=0,σy=0,τxy=−c

均匀纯剪切状态。

**例四（四次多项式）：梁的弯曲**

取 φ=d6xy3φ=6dxy3，验证：∇4φ=0∇4φ=0 ✓

σx=∂2φ∂y2=dxy,σy=0,τxy=−d2y2σx=∂y2∂2φ=dxy,σy=0,τxy=−2dy2

这正是材料力学里**纯弯梁**的应力分布：σx 沿截面高度线性分布，这就是著名的弯曲正应力公式 σ=My/I 的来源！

#### 九、极坐标形式：处理圆孔问题

对于含圆孔的板、圆柱体等问题，用极坐标 (r,θ) 更方便。

极坐标下的双调和方程：

∇4φ=(∂2∂r2+1r∂∂r+1r2∂2∂θ2)2φ=0∇4φ=(∂r2∂2+r1∂r∂+r21∂θ2∂2)2φ=0

极坐标下应力分量：

σr=1r∂φ∂r+1r2∂2φ∂θ2σr=r1∂r∂φ+r21∂θ2∂2φσθ=∂2φ∂r2σθ=∂r2∂2φτrθ=−∂∂r(1r∂φ∂θ)τrθ=−∂r∂(r1∂θ∂φ)

**重要例子：圆孔应力集中**

无限大板，远端均匀拉伸 σ0，板中有小圆孔（半径 a）。

这是弹性力学的经典问题，解为（**柯希（Kirsch）解**，1898年）：

σr=σ02(1−a2r2)+σ02(1−4a2r2+3a4r4)cos2θσr=2σ0(1−r2a2)+2σ0(1−r24a2+r43a4)cos2θσθ=σ02(1+a2r2)−σ02(1+3a4r4)cos2θσθ=2σ0(1+r2a2)−2σ0(1+r43a4)cos2θ

在圆孔边缘 r=a，θ=90°θ=90° 处：

σθ=3σ0

**应力集中系数为 3！** 圆孔边缘的应力是远端应力的3倍。

```
远端均匀应力 σ₀        圆孔边缘 σ_θθ = 3σ₀

  ↑↑↑↑↑↑↑            ↑↑↑  ↑↑↑
  │                  ←    ○    →
  │     ○            ↓↓↓  ↓↓↓
  ↓↓↓↓↓↓↓

  应力集中系数 = 3（与孔的大小无关！）
```

这个结论极其重要——飞机机身开窗、管道开孔，都要考虑这个3倍应力集中，这正是工程设计中圆角比尖角更安全的理论依据。

## 第七节：能量方法——用能量的眼光看弹性力学

---

### 一、换一个视角

前六节我们一直在用**力**的语言：应力、平衡方程、边界条件……

这套方法逻辑严密，但求解复杂问题时往往陷入繁琐的偏微分方程，难以下手。

现在换一个视角——**能量**。

高中物理里，能量方法已经展示过它的威力：

- 不想求绳子张力？用能量守恒直接算速度。
- 不想分析复杂受力？用功能定理一步到位。

弹性力学的能量方法有同样的精神：**绕开局部的应力细节，从整体的能量关系直接得到答案。**

而且，能量方法还是现代**有限元法**的理论基础——没有这一节，就无法理解计算机如何模拟复杂结构。

---

#### 二、弹性应变能：弹性体储存的能量

##### 从弹簧出发

高中里，弹簧的弹性势能：

W=12kx2=12FxW=21kx2=21Fx

用应力应变语言改写（σ=Eε，一维）：

W=12σε⋅VW=21σε⋅V

其中 V 是弹簧体积。单位体积的弹性势能（**应变能密度**）：

w=12σε=σ22E=Eε22w=21σε=2Eσ2=2Eε2

##### 推广到三维

三维应力状态下，应变能密度是所有应力分量做功的总和：

w=12(σxεx+σyεy+σzεz+2τxyεxy+2τyzεyz+2τzxεzx)w=21(σxεx+σyεy+σzεz+2τxyεxy+2τyzεyz+2τzxεzx)

用张量记法极其简洁：

w=12σijεijw=21σijεij

代入广义胡克定律，用应力表达：

w=12E[σx2+σy2+σz2−2ν(σxσy+σyσz+σzσx)]+12G(τxy2+τyz2+τzx2)w=2E1[σx2+σy2+σz2−2ν(σxσy+σyσz+σzσx)]+2G1(τxy2+τyz2+τzx2)

整个弹性体的**总应变能**：

U=∭Vw dVU=∭VwdV

---

#### 三、应变能的物理意义

应变能有三个关键性质，值得仔细品味：

**性质一：应变能是正定的**

w≥0

无论什么应力状态，应变能密度永远非负。等号成立当且仅当应力为零。这反映了弹性材料的稳定性——不能从变形中"凭空"获取能量。

**性质二：应力是应变能对应变的导数**

σij=∂w∂εijσij=∂εij∂w

验证（一维）：w=12Eε2w=21Eε2，∂w∂ε=Eε=σ∂ε∂w=Eε=σ ✓

这个关系极其优美——应力不再是独立定义的量，而是应变能的"梯度"。这是现代连续介质力学的出发点之一。

**性质三：卡氏定理（Castigliano's theorem）**

若把应变能写成外力的函数 U(F1,F2,…)，则：

δi=∂U∂Fiδi=∂Fi∂U

第 i 个力对应的位移，等于应变能对该力的偏导数。

这是一个**神奇的定理**——不需要解任何微分方程，只需对应变能求偏导，就能得到位移！

#### 四、虚功原理：能量方法的基石

##### 什么是虚位移？

"虚位移"是一个假想的、无限小的位移 δu，它：

- 满足位移边界条件（约束处虚位移为零）
- 与实际运动无关，纯粹是数学上的"试探"
- 不需要真实发生

**类比：** 你站在山坡上，想知道这是不是最低点。你可以想象自己向各个方向迈一小步（虚位移），看看势能会不会降低——实际上你并没有动。

##### 虚功原理的表述

对于处于平衡状态的弹性体，对任意虚位移 δu：

δW外=δUδW外=δU

**外力做的虚功 = 应变能的变化**

展开写：

∭Vf⋅δu dV+∬ST⋅δu dS=∭Vσijδεij dV∭Vf⋅δudV+∬ST⋅δudS=∭VσijδεijdV

左边：体力和面力做的虚功；右边：应变能的增量。

##### 虚功原理的深刻之处

虚功原理与平衡方程**完全等价**，但有本质区别：

```
平衡方程（微分形式）          虚功原理（积分形式）

  ∂σij/∂xj + fi = 0    ↔    δWext = δU

  在每一点成立               在整体上成立
  需要应力可微               对不连续问题也适用
  难以直接求解               可以选取近似函数求解
```

虚功原理的积分形式对数值方法（有限元）更友好，因为它允许使用**近似函数**。

#### 五、最小势能原理

##### 势能的定义

定义弹性体的**总势能**：

Π=U−W外Π=U−W外

其中 U 是应变能，W外W外 是外力势（外力做的功）。

具体地：

Π=∭Vw dV−∭Vf⋅u dV−∬ST⋅u dSΠ=∭VwdV−∭Vf⋅udV−∬ST⋅udS

##### 最小势能原理

> **在所有满足位移边界条件的位移场中，真实的位移场使总势能取极小值。**

δΠ=0⟺真实解δΠ=0⟺真实解

**类比高中物理：** 重力场中，稳定平衡位置是势能最小的位置。弹性体的平衡也是势能最小的状态——这是自然界普遍遵循的"最懒原则"。

```
         势能 Π
          ↑
          │      ×（非真实位移场）
          │   ×     ×
          │      ★（真实解，势能最小）
          └──────────────────→ 位移场空间
```

最小势能原理是弹性力学中**最强大的变分原理**，它把一个偏微分方程的求解问题，转化为一个**泛函极值问题**。

#### 六、瑞利-里兹法：用能量方法近似求解

最小势能原理不仅有理论意义，还能直接用来**近似求解**问题。

##### 基本思路

不去求精确解（满足偏微分方程的函数），而是：

1. 猜一族"试探函数"（含若干待定系数）
2. 代入总势能表达式
3. 对待定系数求极值（令偏导为零）
4. 得到最优近似解

##### 具体步骤

设位移场的近似形式为：

u≈∑i=1naiϕi(x,y)u≈i=1∑naiϕi(x,y)

其中 ϕiϕi 是满足位移边界条件的已知函数，ai 是待定系数。

代入势能表达式Π(a1,a2,…,an)，令：

∂Π∂ai=0,i=1,2,…,n∂ai∂Π=0,i=1,2,…,n

得到 n 个代数方程，解出 ai，即得近似解。

##### 一个完整例子：悬臂梁的挠度

**问题：** 悬臂梁，长 L，端部受集中力 P，求挠度曲线 v(x)。

```
  固定端                    自由端
  ↑↑↑↑↑                       ↓ P
  ┌────────────────────────────●
  └────────────────────────────
  x=0                        x=L
```

**第一步：** 选试探函数（满足边界条件 v(0)=0，v′(0)=0v′(0)=0）：

v(x)=a1(xL)2+a2(xL)3v(x)=a1(Lx)2+a2(Lx)3

**第二步：** 计算弯曲应变能（梁弯曲时主要是正应力做功）：

U=∫0LEI2(v′′)2dxU=∫0L2EI(v′′)2dx

其中 EI 是弯曲刚度，v′′=d2vdx2v′′=dx2d2v。

**第三步：** 外力势（端部集中力 P 的势能）：

W外=P⋅v(L)=P(a1+a2)W外=P⋅v(L)=P(a1+a2)

**第四步：** 总势能：

Π=EI2∫0L(v′′)2 dx−P(a1+a2)Π=2EI∫0L(v′′)2dx−P(a1+a2)

计算 v′′v′′：

v′′=2a1L2+6a2xL3v′′=L22a1+L36a2x

代入积分（过程略）：

Π=EI2L3(4a12+12a1a2+12a22)−P(a1+a2)Π=2L3EI(4a12+12a1a2+12a22)−P(a1+a2)

**第五步：** 令 ∂Π∂a1=0∂a1∂Π=0，∂Π∂a2=0∂a2∂Π=0：

EIL3(4a1+6a2)=PL3EI(4a1+6a2)=PEIL3(6a1+12a2)=PL3EI(6a1+12a2)=P

解方程组：

a1=PL32EI,a2=−PL36EIa1=2EIPL3,a2=−6EIPL3

**挠度曲线：**

v(x)=PL3EI[12(xL)2−16(xL)3]=Px26EI(3L−x)v(x)=EIPL3[21(Lx)2−61(Lx)3]=6EIPx2(3L−x)

这正是材料力学的**精确解**！这个例子中，试探函数恰好包含了精确解，所以结果完全正确。

#### 七、从瑞利-里兹法到有限元法

瑞利-里兹法的局限：试探函数是**全局定义**的，难以处理复杂几何形状。

**有限元法的思想：** 把结构分成很多小单元（三角形、四边形等），在每个单元内用简单的局部插值函数（通常是线性或二次多项式），整体上拼成近似解。

```
瑞利-里兹法：               有限元法：

  一个全局函数               很多局部函数
  φ(x,y) 覆盖全域           每个单元内定义简单函数

  ┌─────────────┐           ┌──┬──┬──┬──┐
  │             │           │╲ │╲ │╲ │╲ │
  │  一个函数   │    →      ├──┼──┼──┼──┤
  │             │           │╲ │╲ │╲ │╲ │
  └─────────────┘           └──┴──┴──┴──┘

  难以处理复杂边界           任意复杂形状都能剖分
```

有限元法的核心步骤：

最小势能原理→单元插值代数方程组Ku=F最小势能原理单元插值代数方程组Ku=F

其中 K 是**刚度矩阵**，u 是节点位移向量，F 是节点力向量。

这个线性方程组可以用计算机高效求解，这就是为什么现代工程设计（汽车碰撞、飞机强度、芯片封装）都依赖有限元软件。

#### 八、互等定理：一个意外的对称性

能量方法还能推导出一个惊人的定理。

**贝蒂互等定理（Betti's theorem）：**

对同一弹性体施加两组不同的载荷（状态①和状态②）：

W12=W21

即：**状态①的力在状态②的位移上做的功，等于状态②的力在状态①的位移上做的功。**

```
状态①：力 F₁ → 位移 u₁
状态②：力 F₂ → 位移 u₂

F₁ · u₂ = F₂ · u₁
```

**例子：** 简支梁，跨中加力 P 产生端部转角 θ；端部加力矩 M 产生跨中挠度 δ。

贝蒂定理：P⋅δ=M⋅θ

不需要任何计算，只用这个关系，就能由一种载荷情况的解推出另一种！

这在实验测量中极其有用——测量困难的量，可以通过测量容易的量间接得到。
