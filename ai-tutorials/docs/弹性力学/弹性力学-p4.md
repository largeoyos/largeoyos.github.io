## 第八节：弹性波——振动与波动的统一

---

### 一、从静力学到动力学：加上时间

前七节讨论的都是**静力学**问题——载荷不随时间变化，结构处于平衡状态。

但现实世界是动态的：地震、爆炸、敲击、超声波探伤……这些都涉及**随时间变化的弹性变形**。

回忆第五节，静力平衡方程是：

∂σij∂xj+fi=0∂xj∂σij+fi=0

加入惯性力（牛顿第二定律），升级为**运动方程**：

∂σij∂xj+fi=ρu¨i∂xj∂σij+fi=ρu¨i

右端 ρu¨iρu¨i 是单位体积的惯性力，ρ 是密度，u¨i=∂2ui∂t2u¨i=∂t2∂2ui 是加速度。

这一个方程的改变，打开了一个全新的世界——**弹性波**。

---

#### 二、推导波动方程

忽略体力（fi=0），把广义胡克定律和几何方程代入运动方程，得到用位移表示的**纳维运动方程**：

(λ+μ)∂e∂xi+μ∇2ui=ρu¨i(λ+μ)∂xi∂e+μ∇2ui=ρu¨i

其中 e=εx+εy+εz 是体积应变，λ、μ 是拉梅常数。

用向量形式写得更优雅：

(λ+μ)∇(∇⋅u)+μ∇2u=ρu¨(λ+μ)∇(∇⋅u)+μ∇2u=ρu¨

这个方程看起来复杂，但隐藏着一个深刻的结构。

**关键操作：** 对方程做两种数学运算——取散度和取旋度——可以把它分解成两个独立的波动方程。

---

#### 三、分解：两种独立的运动

##### 第一步：取散度

对纳维方程两边取散度（∇⋅∇⋅），利用 ∇⋅(∇2u)=∇2(∇⋅u)∇⋅(∇2u)=∇2(∇⋅u)：

(λ+μ)∇2e+μ∇2e=ρe¨(λ+μ)∇2e+μ∇2e=ρe¨(λ+2μ)∇2e=ρe¨(λ+2μ)∇2e=ρe¨∇2e=1cP2e¨,cP=λ+2μρ∇2e=cP21e¨,cP=ρλ+2μ

这是关于**体积应变 e** 的标准波动方程！

e 描述的是体积的胀缩——这种波是**压缩波（纵波，P波）**，传播速度 cP。

##### 第二步：取旋度

对纳维方程两边取旋度（∇×∇×），利用 ∇×(∇ϕ)=0∇×(∇ϕ)=0（梯度的旋度为零）：

μ∇2(∇×u)=ρ(∇×u¨)μ∇2(∇×u)=ρ(∇×u¨)

定义旋转向量 ω=∇×uω=∇×u（描述微元的转动）：

∇2ω=1cS2ω¨,cS=μρ∇2ω=cS21ω¨,cS=ρμ

这是关于**旋转场 ω** 的波动方程！

ω 描述的是微元的剪切转动——这种波是**剪切波（横波，S波）**，传播速度 cS。

#### 六、一维弹性波：最简单的情形

为了建立直觉，先看一维情形：一根无限长细杆，沿 x 方向传播的纵波。

纳维方程退化为：

(λ+2μ)∂2u∂x2=ρ∂2u∂t2(λ+2μ)∂x2∂2u=ρ∂t2∂2u

对于细杆（侧面自由，平面应力状态），等效弹性常数变为 E，波动方程简化为：

E∂2u∂x2=ρ∂2u∂t2⟹∂2u∂x2=1c2∂2u∂t2,c=EρE∂x2∂2u=ρ∂t2∂2u⟹∂x2∂2u=c21∂t2∂2u,c=ρE

这是经典的**一维波动方程**，解为：

u(x,t)=f(x−ct)+g(x+ct)

f(x−ct)：向右传播的波；g(x+ct)：向左传播的波。

**直觉理解：** f(x−ct) 在 t=0 时是 f(x)，在 t 时刻是 f(x−ct)——整个波形向右平移了 ct，形状不变。这就是**行波**。

#### 七、反射与透射：波遇到界面

当弹性波从一种介质传入另一种介质时，会发生**反射**和**透射**。

设界面两侧介质的波阻抗分别为：

Z1=ρ1c1,Z2=ρ2c2

反射系数和透射系数（位移幅值之比）：

R=Z2−Z1Z2+Z1,T=2Z2+Z1R=Z2+Z1Z2−Z1,T=Z2+Z12Z2

**三个极端情形：**

**情形一：** Z2=Z1（阻抗匹配）

R=0,T=1

全部透射，无反射。这是超声波探头设计的目标——用耦合剂消除气隙，实现阻抗匹配。

**情形二：** Z2≫Z1Z2≫Z1（从软介质入射到硬介质，如从土壤到岩石）

R→1,T→2R→1,T→2

几乎全反射，反射波与入射波同相（加强）。

**情形三：** Z2=0（自由端）

R=−1,T=0

全反射，但反射波反相（翻转）——这正是波在绳子自由端反射时的情形。

#### 八、地震波：弹性波最壮观的应用

地震是弹性波理论最震撼的应用场景。

##### 地震波的种类

地震产生的波不止P波和S波，还有在地表传播的**面波**：

```
地球内部（体波）：
  P波 ──→  压缩波，最先到达，破坏力较小
  S波 ──→  剪切波，其次到达，水平晃动，破坏力大

地球表面（面波）：
  瑞利波（Rayleigh wave）──→ 质点做椭圆运动，地面翻滚
  洛夫波（Love wave）     ──→ 水平剪切，地面横向摆动，
                               对建筑破坏最大
```

##### 用地震波"看"地球内部

地球是一个巨大的弹性体。地震波在传播过程中，遇到不同密度、不同弹性常数的岩层，会发生折射和反射。

通过分析全球地震台网记录到的波形，科学家可以反推地球内部的结构：

```
          地震发生
             ↓
    ┌────────●────────┐
    │   地壳（薄）     │  ← P波速度 ~6 km/s
    │                 │
    │    地幔（厚）    │  ← P波速度 ~8～13 km/s
    │                 │
    │  外核（液态！）  │  ← S波消失！（液体不传横波）
    │                 │
    │   内核（固态）   │  ← S波重现
    └─────────────────┘
```

**最关键的发现：** 地球外核不传S波！这直接证明了外核是**液态**的——液体没有剪切刚度（μ=0），无法传播横波。这个结论完全来自弹性波理论，人类从未直接"看到"地核。

#### 九、表面波：瑞利波

除了在无限体内传播的体波，弹性半空间（有自由表面的弹性体）还存在沿表面传播的**瑞利波**。

瑞利波的特点：

- 能量集中在表面附近，随深度**指数衰减**
- 质点做**逆时针椭圆运动**（类似海浪）
- 传播速度 cR≈0.92cS，比S波略慢

```
传播方向 →

表面：  ↙↖  ↙↖  ↙↖  ↙↖   （椭圆运动）

深处：  振幅迅速减小，几乎不动
```

瑞利波速度（近似公式，ν=0.25 时）：

cR≈0.862+1.14ν1+νcS≈0.919 cScR≈1+ν0.862+1.14νcS≈0.919cS

**工程应用：** 地面上的机器振动，主要通过瑞利波传播——这就是为什么铁路、地铁旁边的建筑会感受到地面振动。

#### 十、弹性波的频散：波速随频率变化

在无限均匀弹性体中，弹性波是**非频散**的——不同频率的波速度相同，波形传播时不变形。

但在**有限尺寸的结构**（板、杆、壳）中，波会产生**频散**——波速随频率变化。

以弹性板中的Lamb波为例：

```
波速
  ↑
  │    高频极限 → 瑞利波速 cR
  │   ╭──────────────────────────
  │  ╱
  │ ╱  对称模式（S0）
  │╱
  ├────────────────────────────→ 频率
  │╲
  │ ╲  反对称模式（A0）
  │  ╲______________________
  │  低频极限 → 弯曲波（频散极强）
```

频散意味着：不同频率的成分以不同速度传播，脉冲信号在传播过程中会**展宽变形**。

这在超声无损检测中非常重要——工程师必须了解Lamb波的频散特性，才能正确解读检测信号。

## 第九节：断裂力学初步——裂纹尖端的应力奇异性

---

### 一、一个让经典理论崩溃的问题

1919年，英国工程师格里菲斯（Griffith）发现了一个令人困惑的现象：

玻璃的**理论强度**（根据原子间作用力估算）约为 10 GPa，但实际测量的断裂强度只有约 100 MPa——**差了100倍**！

为什么材料实际上比理论预测弱得多？

更奇怪的是：同样的玻璃，拉成很细的纤维后，强度反而大幅提升，接近理论值。

经典弹性力学对这些问题完全束手无策——它假设材料是完整的连续体，没有缺陷。

**答案藏在裂纹里。**

---

#### 二、应力集中：从圆孔到裂纹

第六节我们学过，圆孔边缘的应力集中系数为3。那么，如果把圆孔越压越扁，变成一条细长的椭圆孔，最后变成一条**裂纹**，会发生什么？

椭圆孔（长轴 a，短轴 b）尖端的应力集中系数：

Kt=1+2ab=1+2aρKt=1+2ba=1+2ρa

其中 ρ=b2/a 是椭圆尖端的**曲率半径**。

当椭圆变成裂纹时，b→0b→0，ρ→0ρ→0：

Kt=1+2aρ→∞Kt=1+2ρa→∞

**裂纹尖端的应力集中系数是无穷大！**

这就是为什么真实材料比理论值弱得多——哪怕是极其微小的裂纹，在尖端也会产生巨大的应力集中，导致材料在远低于理论强度时就断裂。

---

#### 三、裂纹的三种基本模式

在分析裂纹之前，先定义裂纹的三种基本开裂方式（任何复杂开裂都是这三种的叠加）：

```
模式 I（张开型）      模式 II（滑开型）     模式 III（撕开型）

    ↑  ↑  ↑              → → →               ⊙  ⊙  ⊙
  ┌──────────┐         ┌──────────┐         ┌──────────┐
  │          │         │→ → → →  │         │          │
  │    ──    │         │    ──   │         │    ──    │
  │  裂纹    │         │  裂纹   │         │  裂纹    │
  └──────────┘         └──────────┘         └──────────┘
    ↓  ↓  ↓              ← ← ←               ⊗  ⊗  ⊗

  垂直裂纹面拉伸       平行裂纹面滑动       沿裂纹前缘撕裂
  最常见，最危险       面内剪切             面外剪切
```

工程中最重要的是**模式I（张开型）**，我们重点分析它。

#### 四、裂纹尖端的应力场：精确解

考虑无限大板中的一条长为 2a 的穿透裂纹，远端受均匀拉应力 σ0（模式I）。

建立以裂纹尖端为原点的极坐标系 (r,θ)：

```
          σ₀
       ↑↑↑↑↑↑↑

   ────────────────────
           ● ← 裂纹尖端
   ────────────────────

       ↓↓↓↓↓↓↓
          σ₀
```

用艾里应力函数（第六节）求解，得到裂纹尖端附近（r≪ar≪a）的应力场：

$$\boxed{ \begin{aligned} \sigma_{x} &= \frac{K_I}{\sqrt{2\pi r}}\cos\frac{\theta}{2}\left(1-\sin\frac{\theta}{2}\sin\frac{3\theta}{2}\right) \[6pt] \sigma_{y} &= \frac{K_I}{\sqrt{2\pi r}}\cos\frac{\theta}{2}\left(1+\sin\frac{\theta}{2}\sin\frac{3\theta}{2}\right) \[6pt] \tau_{xy} &= \frac{K_I}{\sqrt{2\pi r}}\sin\frac{\theta}{2}\cos\frac{\theta}{2}\cos\frac{3\theta}{2} \end{aligned} }$$

其中 KI 叫做**应力强度因子**（stress intensity factor），对于这个问题：

KI=σ0πa

**裂纹尖端的应力是无穷大的！**

这叫做**应力奇异性**，奇异指数为 −1/2。

```

  ↑
  │

  │                      ×  ×  ×
```

**但这并不是问题！** 真实材料在裂纹尖端会发生**塑性变形**（金属）或**微裂纹**（陶瓷），这些非弹性行为限制了实际应力的大小。弹性解在尖端小范围内不成立，但在稍远处仍然精确。

#### 六、应力强度因子 K：断裂力学的核心

观察裂纹尖端应力场的结构：

σij=KI2πrfij(θ)σij=2πrKIfij(θ)

所有应力分量都正比于 KI，角度分布 fij(θ) 是固定的（与载荷、几何无关）。

这意味着：**KI 完全决定了裂纹尖端应力场的强度。**

不管是什么形状的结构、什么样的载荷，只要 KI 相同，裂纹尖端的应力场就完全相同。

**应力强度因子的一般形式：**

KI=Yσπa

其中：

- σ 是名义应力（远端载荷）
- a 是裂纹半长
- Y 是无量纲几何修正因子（取决于结构形状和裂纹位置）

#### 七、格里菲斯能量理论：裂纹为什么会扩展？

格里菲斯从能量角度给出了答案。

##### 能量平衡

裂纹扩展时，两种能量发生变化：

**释放的弹性应变能：** 裂纹扩展后，裂纹附近的材料卸载，释放应变能 ΔU。

**消耗的表面能：** 新裂纹面需要消耗能量（打断原子键），表面能增量 ΔWs=4aγ （γ 是表面能密度，每单位面积，因子4来自裂纹两侧各两个面）。

裂纹扩展的条件：

d(ΔU)da≥d(ΔWs)dadad(ΔU)≥dad(ΔWs)

**释放的应变能速率 ≥ 创造新表面所需能量速率**

对于无限大板中心裂纹，可以计算出：

d(ΔU)da=πσ2aEdad(ΔU)=Eπσ2a

格里菲斯断裂准则：

σf=2Eγπaσf=πa2Eγ

这就是格里菲斯公式——预测裂纹开始扩展时的临界应力。

**代入数字感受一下：** 玻璃的 E=70 GPa，γ=1 J/m²，裂纹长 a=1 μm：

σf=2×70×109×1π×10−6≈210 MPaσf=π×10−62×70×109×1≈210 MPa

与实验值吻合！而且裂纹越长，断裂应力越低——这解释了为什么有划痕的玻璃更容易断裂。

#### 八、断裂韧性 KIC：材料抵抗断裂的能力

把格里菲斯准则用 KI 来表达：

裂纹扩展的临界条件：

KI=KIC

其中 KIC 叫做**断裂韧性**（fracture toughness），是材料固有属性，单位 MPa·m1/2。

KIC=σfπac⟺σf=KICπacKIC=σfπac⟺σf=πacKIC

|---|---|
|玻璃|0.7～1.0|
|陶瓷（氧化铝）|3～5|
|混凝土|0.5～1.5|

**KIC 越大，材料越难断裂。** 玻璃的 KIC 只有钢的百分之一，所以玻璃非常脆。

#### 九、裂纹尖端塑性区

前面说过，真实金属材料在裂纹尖端会发生塑性变形。弹性解预测 σy→∞σy→∞，但实际上超过屈服强度 σY 后材料就屈服了。

**塑性区半径**（沿 θ=0 方向）：

令 σy=σY，由弹性解：

KI2πrp=σY2πrpKI=σYrp=12π(KIσY)2rp=2π1(σYKI)2

这是**Irwin塑性区修正**。

塑性区的大小决定了断裂力学的适用范围：

```
塑性区很小                      塑性区很大
（高强钢、陶瓷）                （低碳钢、铝合金）
         │                              │
         ↓                              ↓
线弹性断裂力学（LEFM）          弹塑性断裂力学（EPFM）
   K_I = K_{IC} 适用              需要 J 积分等方法
```

**断裂力学的适用条件（小范围屈服）：**

a,(W−a),B≥2.5(KICσY)2a,(W−a),B≥2.5(σYKIC)2

即试样尺寸必须远大于塑性区尺寸。

#### 十、疲劳裂纹扩展：Paris定律

工程结构很少因为一次过载断裂，更常见的是**疲劳**——在远低于断裂载荷的循环载荷下，裂纹缓慢扩展，最终断裂。

1961年，Paris发现裂纹扩展速率与应力强度因子幅值的关系：

dadN=C(ΔK)mdNda=C(ΔK)m

其中：

- da/dN：每个加载循环裂纹扩展量（m/cycle）
- ΔK=Kmax−Kmin：应力强度因子幅值
- C、m：材料常数（对钢，m≈3）

这就是**Paris定律**，是疲劳断裂力学的基础。

##### 疲劳寿命预测

已知初始裂纹 a0，临界裂纹 ac=(KICYσπ)2ac=(YσπKIC)2，积分Paris定律：

Nf=∫a0acdaC(ΔK)m=∫a0acdaC(YΔσπa)mNf=∫a0acC(ΔK)mda=∫a0acC(YΔσπa)mda

对 m=2（简化），Y=1：

Nf=1Cπ(Δσ)2lnaca0Nf=Cπ(Δσ)21lna0ac

**这个公式的工程价值：** 飞机机身、发动机叶片、核反应堆压力容器……都需要用这个方法预测安全寿命，制定检修周期。

#### 十一、断裂力学的三角关系

断裂力学的核心是三个量之间的关系：

```
            断裂韧性 K_IC
           （材料属性，实验测定）
                  │
         ┌────────┴────────┐
         │                 │
    裂纹尺寸 a         工作应力 σ
    （无损检测确定）    （设计载荷）
         │                 │
         └────────┬────────┘
                  │
           K_I = Yσ√(πa)
                  │
             K_I < K_IC  →  安全
             K_I = K_IC  →  临界
             K_I > K_IC  →  断裂
```

工程设计中，三个量中知道任意两个，就能确定第三个：

- **已知 σ 和 a**：计算 KI，判断是否安全（**安全评估**）
- **已知 KIC 和 σ**：计算最大允许裂纹 ac（**无损检测标准**）
- **已知 KIC 和 a**：计算最大允许应力 σf（**载荷限制**）

#### 十二、一个完整的工程案例

**问题：** 一块高强钢板（KIC=60 MPa·m1/2，σY=1400 MPa），工作应力 σ=500 MPa，无损检测能发现的最小裂纹为 amin=2 m。

**（1）当前是否安全？**

$K_I = 500 \times \sqrt{\pi \times 0.002} = 39.6\,\text{MPa}\cdot\text{m}^{1/2}$

KI=39.6<KIC=60 MPa·m1/2 ✅ 安全。

**（2）安全裕度多大？**

临界裂纹尺寸：

ac=1π(KICσ)2=1π(60500)2=4.58 mmac=π1(σKIC)2=π1(50060)2=4.58 m

安全裂纹范围：22 m → 4.58 m，只有2倍多的裕度，需要定期检测！

**（3）塑性区多大？**

rp=12π(KIσY)2=12π(39.61400)2=0.127 mmrp=2π1(σYKI)2=2π1(140039.6)2=0.127 m

塑性区直径约0.25 m，远小于裂纹尺寸2 m，线弹性断裂力学适用 ✅
