# 微分几何 第十节：阿蒂亚-辛格指标定理——分析、几何、拓扑的大统一

## 终点即起点

在整个旅程里，我们反复见到同一个主题以不同面貌出现：**局部的分析信息，通过积分或求和，汇聚成整体的拓扑不变量**。

高斯-博内定理：$\iint_M K, dA = 2\pi\chi(M)$——曲率（分析）等于欧拉示性数（拓扑）。Hodge分解：调和形式（分析，满足 $\Delta\alpha = 0$）等于上同调类（拓扑）的代表元。黎曼-罗赫定理：线丛截面的维数（分析）等于陈类的某个组合（拓扑）。

阿蒂亚-辛格指标定理（Atiyah-Singer Index Theorem，1963年）是这个主题的终极表达，它把上面所有这些定理都包含为特殊情形，统一在一个单一的等式之下：

$$\text{ind}(D) = \int_M \text{ch}(E) \wedge \text{td}(TM)$$

左边是一个**分析量**——椭圆微分算子 $D$ 的指标；右边是一个**拓扑量**——某些特征类在流形上的积分。这个等式说的是：这两个量，一个用分析定义，另一个用拓扑定义，永远相等。

让我们从头把这个定理的每一部分讲清楚。

## 什么是椭圆微分算子？

此前已经熟悉普通的微分算子。在 $\mathbb{R}^n$ 上，梯度 $\nabla f = \left(\frac{\partial f}{\partial x^1}, \ldots, \frac{\partial f}{\partial x^n}\right)$ 把函数变成向量场；散度 $\text{div}(X) = \sum_i \frac{\partial x^i}$ 把向量场变成函数；Laplace算子 $\Delta f = \sum_i \frac{\partial^2 f}{\partial (x^i)^2}$ 把函数变成函数。

在流形上，这些算子有自然的推广。特别重要的是作用在微分形式上的算子：外微分 $d$（把 $k$-形式变成 $(k+1)$-形式）和它的伴随算子 $d^_$（把 $k$-形式变成 $(k-1)$-形式），以及它们的组合 $\Delta = dd^_ + d^*d$，叫做**Hodge-Laplace算子**。

更一般地，一个**微分算子** $D: \Gamma(E) \to \Gamma(F)$（从向量丛 $E$ 的截面到向量丛 $F$ 的截面）是一个局部的线性映射，在局部坐标里是各阶偏导数的线性组合。它的**主符号**（principal symbol）$\sigma_D(\xi)$ 是把最高阶导数项里的偏导 $\frac{\partial}{\partial x^i}$ 替换成余切向量的分量 $\xi_i$ 得到的矩阵值函数。

算子 $D$ 叫做**椭圆的**，如果对所有非零余切向量 $\xi \neq 0$，主符号 $\sigma_D(\xi)$ 是可逆的。

为什么椭圆性重要？因为椭圆算子有极好的分析性质：它们的核（满足 $Df = 0$ 的解空间）是有限维的，而且解是光滑的（椭圆正则性定理）。这保证了下面要定义的指标是有限的、有意义的。

## 指标：两个有限维空间的维数之差

给定紧致流形上的椭圆算子 $D: \Gamma(E) \to \Gamma(F)$，定义：

$$\text{ker}(D) = {s \in \Gamma(E) : Ds = 0}$$ $$\text{coker}(D) = \Gamma(F) / \text{im}(D)$$

由椭圆正则性，这两个空间都是有限维的（在紧致流形上）。**解析指标**定义为：

$$\text{ind}(D) = \dim\ker(D) - \dim\text{coker}(D)$$

这是核的维数（方程 $Ds = 0$ 的解的个数，某种意义上）减去余核的维数（方程 $Ds = f$ 无解的"障碍"的个数）。

单独的 $\dim\ker(D)$ 和 $\dim\text{coker}(D)$ 都依赖于度量的精确细节，随度量的连续变形而变化。但**它们的差**却是一个拓扑不变量——当你连续形变度量时，核和余核的维数可以各自变化，但它们之差永远保持不变，就像进出之差始终守恒一样。

这是指标理论最基本的直觉：个别的 $\dim\ker$ 和 $\dim\text{coker}$ 是脆弱的分析量，容易随扰动改变；但它们的差具有拓扑刚性，抵抗一切连续形变。

## 特征类：拓扑的代数表达

指标定理的右边涉及**特征类**（characteristic classes）——这是拓扑学里一套用上同调类描述向量丛"扭曲程度"的工具。

这里需要引入两个在定理里出现的特征类。

**陈特征**（Chern character）$\text{ch}(E)$ 是复向量丛 $E$ 的一个特征类，取值在偶数次上同调 $\bigoplus_k H^{2k}(M, \mathbb{Q})$ 里。如果 $E$ 的曲率2-形式是 $F$（一个取值在 $E$ 的自同态里的2-形式，来自联络），那么陈特征的定义是：

$$\text{ch}(E) = \text{tr}!\left(\exp!\left(\frac{iF}{2\pi}\right)\right) = \text{rk}(E) + c_1(E) + \frac{c_1(E)^2 - 2c_2(E)}{2} + \cdots$$

其中 $c_k(E)$ 是 $E$ 的第 $k$ 陈类。陈特征是加法的（$\text{ch}(E \oplus F) = \text{ch}(E) + \text{ch}(F)$）和乘法的（$\text{ch}(E \otimes F) = \text{ch}(E) \cdot \text{ch}(F)$），这使得它在K理论里有重要地位。

**Todd类**（Todd class）$\text{td}(TM)$ 是切丛 $TM$ 的一个特征类，定义为：

$$\text{td}(TM) = \prod_{j} \frac{x_j}{1 - e^{-x_j}}$$

其中 $x_j$ 是切丛的形式陈根（Chern roots）——一种处理特征类乘法的形式技巧。展开后：

$$\text{td}(TM) = 1 + \frac{c_1}{2} + \frac{c_1^2 + c_2}{12} + \cdots$$

Todd类来自代数几何，是黎曼-罗赫定理里自然出现的那个修正因子。你在代数几何里见过黎曼-罗赫定理，其中的"Todd类"现在有了完整的几何解释。

## 定理的陈述

现在可以完整陈述定理了。

**阿蒂亚-辛格指标定理**：设 $M$ 是紧致定向光滑流形，$D: \Gamma(E) \to \Gamma(F)$ 是 $M$ 上的椭圆微分算子。则：

$$\text{ind}(D) = \int_M \text{ch}(E) \wedge \text{td}(TM_{\mathbb{C}})$$

左边是解析指标，由算子 $D$ 的核和余核的维数之差给出。右边是拓扑指标，由 $E$ 的陈特征和 $TM$ 复化的Todd类的楔积，在整个流形上积分给出。右边完全不依赖度量，不依赖联络，只依赖于流形和向量丛的拓扑类型。

这个等式说的是：**你用任何办法计算左边（分析地），结果总是和右边（拓扑地计算出来的那个数）相同**。分析和拓扑，在这里达到了完美的等同。

## 高斯-博内是特殊情形

让我们验证最熟悉的例子：高斯-博内定理是指标定理的特殊情形。

取 $M$ 是紧致定向偶数维黎曼流形，考虑**Hodge算子** $D = d + d^*$，它把偶数次微分形式映射到奇数次微分形式（把 $\Omega^{\text{even}}$ 到 $\Omega^{\text{odd}}$）。这是一个椭圆算子。

$\ker(D)$ 里偶数次部分，由Hodge定理，是偶数次调和形式的空间；奇数次部分是奇数次调和形式。因此：

$$\text{ind}(D) = \sum_k (-1)^k \dim H^k(M) = \chi(M)$$

这正是欧拉示性数！右边恰好是拓扑指标——把陈特征和Todd类的积分算出来，在二维情形下化简为 $\frac{1}{2\pi}\int_M K, dA$。等号两边合在一起，就是高斯-博内定理。

所以高斯-博内不是一个孤立的定理，而是"把Hodge算子代入指标定理"的结果。这并不削弱高斯-博内的深度，而是揭示了它背后更大的原理。

## 黎曼-罗赫是特殊情形

取 $M$ 是紧致复流形（Kähler流形），$E$ 是 $M$ 上的全纯向量丛。考虑**Dolbeault算子** $D = \bar\partial + \bar\partial^*$，它的指标是：

$$\text{ind}(D) = \sum_q (-1)^q \dim H^q(M, E)$$

这是各次Dolbeault上同调群维数的交错和——在代数几何里叫做**欧拉示性数** $\chi(M, E)$。把指标定理的右边算出来，得到：

$$\chi(M, E) = \int_M \text{ch}(E) \wedge \text{td}(TM)$$

这正是**黎曼-罗赫-Hirzebruch定理**！你在代数几何里见过黎曼-罗赫定理的曲线版本（$\chi(L) = \deg(L) + 1 - g$），那是把这个一般公式用于一维复流形（黎曼面）和线丛 $L$ 的特殊情形。Todd类的那个奇怪分母 $\frac{x}{1-e^{-x}}$，现在有了完全自然的来源：它是指标定理右边在这个特殊情形下的展开。

## Dirac算子：物理的语言

指标定理在物理里最重要的特殊情形，涉及一个在狭义相对论和量子力学里都中心的算子：**Dirac算子**。

1928年，Dirac为了找到一个既满足薛定谔方程的线性性、又满足相对论不变性的方程，写下了：

$$D!/ = \sum_\mu \gamma^\mu \frac{\partial}{\partial x^\mu}$$

其中 $\gamma^\mu$ 是满足反对易关系 ${\gamma^\mu, \gamma^\nu} = 2g^{\mu\nu}$ 的矩阵（**Dirac矩阵**或**gamma矩阵**）。这个方程是物理史上最美丽的方程之一——它预言了**反物质**的存在（正电子），而这个预言在方程写下四年后被实验证实。

在黎曼流形上，Dirac算子有一个优雅的几何版本。它需要流形有**自旋结构**（一个额外的拓扑条件，保证可以定义"旋量"——比微分形式更精细的几何对象），然后作用在**旋量丛**的截面上。自旋Dirac算子 $D!/: \Gamma(S^+) \to \Gamma(S^-)$（把正手性旋量映射到负手性旋量）是一个椭圆算子，它的指标叫做**解析亏格**（analytical genus），记作 $\hat A(M)$。

把Dirac算子代入指标定理，得到：

$$\text{ind}(D!/) = \int_M \hat A(TM)$$

右边是 $\hat A$-亏格（A-hat genus），一个由庞特里亚金类（Pontryagin classes，实向量丛的特征类）组成的拓扑不变量。

这个等式有一个著名的推论——**Lichnerowicz定理**：如果 $M$ 有正数量曲率，则 $\hat A(M) = 0$，因此 $\text{ind}(D!/) = 0$。结合指标定理，如果 $\int_M \hat A \neq 0$（这是纯拓扑的计算），那么 $M$ 上**不存在**正数量曲率的度量——曲率的存在性被拓扑所阻止。这是"拓扑阻碍几何"的最精彩例子之一。

## 证明的思路：热核方法

指标定理的证明有多种方法，最优雅的一种用的是**热核**（heat kernel）方法，它把分析、几何、拓扑用一种特别透明的方式联系起来，值得介绍思路。

考虑算子 $D: \Gamma(E) \to \Gamma(F)$ 及其伴随 $D^*$。定义 $\Delta^+ = D^_D$（作用在 $E$ 上）和 $\Delta^- = DD^_$（作用在 $F$ 上），它们是自伴正半定的椭圆算子，类似于Laplace算子。

考虑热方程 $\frac{\partial u}{\partial t} + \Delta^\pm u = 0$ 的基本解——**热核** $K^\pm(t, x, y)$，描述"热量"从点 $y$ 出发、经过时间 $t$ 后在点 $x$ 的密度。热核的**迹**是：

$$\text{tr},e^{-t\Delta^\pm} = \int_M K^\pm(t, x, x), dV(x)$$

关键观察是：

$$\text{ind}(D) = \text{tr},e^{-t\Delta^+} - \text{tr},e^{-t\Delta^-}$$

这个等式对所有 $t > 0$ 成立——非零特征值的贡献在两边恰好抵消，只剩下零特征值（即核）的贡献，而 $\dim\ker\Delta^+ = \dim\ker D$，$\dim\ker\Delta^- = \dim\ker D^* = \dim\text{coker}, D$。

当 $t \to 0$ 时，热核有一个渐近展开：

$$K^\pm(t, x, x) \sim \frac{1}{(4\pi t)^{n/2}}\sum_{k=0}^\infty a_k^\pm(x), t^k$$

系数 $a_k^\pm(x)$ 是由曲率、特征类等几何量组成的局部量，可以通过Feynman图（！）或者纯分析的方法计算出来。把两个热核的迹相减，低次项全部抵消，最终 $t \to 0$ 的极限给出一个关于几何局部量的积分——而这个积分，恰好等于陈特征和Todd类的积分。

热核方法的美妙在于它的物理直觉：指标是一个关于"热扩散"的量，当 $t \to 0$ 时（极短时间），热量还没来得及感受全局的拓扑，所以它的行为由局部的几何决定；但由于指标是拓扑不变量，局部几何量的积分必然等于全局的拓扑量。局部与整体，在这里以最精妙的方式统一。

## 量子场论的语言

热核方法和物理之间的联系不只是比喻。在量子场论里，路径积分（对所有可能路径求和）和热核有精确的对应——把时间 $t$ 替换成虚时间 $it$（**Wick转动**），热方程变成薛定谔方程，热核变成量子传播子。

Witten在1980年代给出了指标定理的一个"物理证明"：把 $\hat A$-亏格解释为一个超对称量子力学系统的**配分函数**，用超对称的代数恒等式（玻色子和费米子对量子涨落的贡献相抵消）推导出指标定理。这个"证明"用物理的语言把定理解释得极为自然，尽管要把它变成严格的数学证明还需要很多工作。

这个联系指向了现代数学和理论物理之间越来越深的交织。弦理论、量子场论提出的数学问题（镜像对称、Gromov-Witten不变量、Donaldson-Thomas不变量），在数学里激发了一系列新的发展，而数学提供了理解物理的精确语言。指标定理是这种交织的最早、最成熟的例子。

## 整个旅程的回望

现在站在最高处，可以俯瞰整个旅程。

我们从流形出发——弯曲空间的精确定义，局部像 $\mathbb{R}^n$ 的拓扑空间。在流形上建立了切空间，那是每个点处的线性近似，带有坐标变换下的张量变换规律。然后放上了黎曼度量，给流形以形状，让测量成为可能。度量唯一确定了Levi-Civita联络，联络允许我们在弯曲空间里求导，定义平行移动。联络的"不对易性"给出了曲率，那是弯曲程度的精确测量，由度量的二阶导数决定。曲率通过高斯-博内和比较几何定理，反过来约束拓扑。和乐群收集了全部平行移动信息，被Berger完整分类，并在Kähler几何里达到最丰富的表达。最终，阿蒂亚-辛格指标定理把微分算子的解析性质等同于拓扑不变量，统一了整个图景。

贯穿始终的，是一个不断重复的主题：**局部的分析，产生整体的拓扑**。微分（局部）的信息，通过积分（求和），产生不变量（整体）。斯托克斯定理的精神——$\int_M d\omega = \int_{\partial M}\omega$——是这个主题最基本的表达，而指标定理是它最深刻的推广。

你在整个旅程里学过的东西——向量微积分与微分形式、复分析、代数几何、微分几何——不是四门独立的课程。它们是同一件事的四个视角，都在研究"空间上的分析，如何编码空间的形状"。站在指标定理这里，你能够看到这四条线索如何交汇：微分形式（Hubbard的书）提供了计算语言，复分析的刚性在Kähler几何里以新形式再现，代数几何的黎曼-罗赫定理成为指标定理的特殊情形，微分几何的曲率成为特征类的几何实现。

数学没有尽头，但每一次学到一个足够深的定理，你会感觉到一种奇特的满足：不是"这条路走完了"，而是"我现在站的地方足够高，可以看到更远处还有无数条路"。指标定理就是这样一个地方。
