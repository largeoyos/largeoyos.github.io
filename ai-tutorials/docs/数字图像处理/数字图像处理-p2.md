## 第三节：空间域滤波与卷积——图像处理的核心引擎

上一节的点变换有一个根本限制：**每个像素的处理完全独立于它的邻居**。这意味着点变换对图像的"结构"一无所知——它不知道某个像素旁边是边缘还是平坦区域，不知道某个亮点是真实的高光还是噪声。

而现实中很多重要的图像操作恰恰需要"看邻居"才能完成：模糊需要把邻近像素的值混合在一起，边缘检测需要找到像素值发生突变的地方，锐化需要强调一个像素与其邻居的差异。这些操作的统一数学框架，就是本节的主角——**空间域滤波**，而实现它的核心工具是**卷积（Convolution）**。

理解卷积，不仅是理解经典图像处理的关键，更是理解现代深度学习中卷积神经网络（CNN）的必要前提。所以请跟紧这一节，打好这个基础。

---

### 3.1 邻域处理的直觉：一个像素如何"听取"邻居意见

我们先用一个直觉性的例子来建立感觉，再引入数学语言。

假设你是图像中坐标 (x,y) 处的一个像素，值为 150。你的上下左右以及斜角方向共有 8 个邻居，组成一个 3×3 的小方块。现在我们想对你做"模糊"处理，最简单的方式是：把你和你的 8 个邻居的值取平均，用这个平均值替换你原来的值。

这就是**均值滤波**的本质。注意它做的事情：输出值不再只取决于你自己，而是取决于以你为中心的一个小区域。如果你恰好是噪声点（一个孤立的异常亮点），取平均后这个异常就被"稀释"了，噪声得到抑制。

但均值滤波只是最简单的情况。更一般地，我们可以给 9 个像素分配不同的权重，中心像素权重大，周围像素权重小——这样既考虑了邻域信息，又不至于完全"淹没"自身的值。不同的权重方案，产生完全不同的视觉效果。而这套"权重方案"，就是我们即将引入的**卷积核（Kernel）**。

---

### 3.2 卷积：滑动的加权求和

#### 卷积核是什么

卷积核（也叫滤波器、模板）是一个小的数字矩阵，通常是奇数尺寸的正方形，如 3×3、5×5、7×7。奇数尺寸是为了保证它有一个明确的中心点。

每个卷积核定义了一种"邻域加权规则"：当核中心对准图像中的某个像素时，核中每个数字代表对应邻居像素的权重。

#### 卷积操作的步骤

卷积的过程分为四步，在整幅图像上反复执行：

第一步，将卷积核中心对准当前目标像素。第二步，将核中每个元素与图像中对应位置的像素值相乘。第三步，将所有乘积加在一起，得到一个数。第四步，这个数就是输出图像中该位置的新像素值。然后核向右滑动一格，重复这个过程，直到遍历整幅图像。

用数学公式表达，输出图像 g 在位置 (x,y) 的值为：

g(x,y)=∑s=−a∑t=−bbh(s,t)⋅f(x+s, y+t)g(x,y)=s=−a∑at=−b∑bh(s,t)⋅f(x+s, y+t)

其中 h 是卷积核，f 是输入图像，(s,t) 在核的范围内遍历。这个双重求和看起来有些抽象，但它的本质非常具体：**就是把核翻转后盖在图像上，逐元素相乘再求和**。

我们用一个数字例子来走一遍全过程，彻底消除抽象感。假设图像的一个 3×3 区域是：

```
  10   20   30
  40   50   60
  70   80   90
```

我们使用一个均值滤波核（9 个元素均为 1991）：

```
  1/9  1/9  1/9
```

对中心像素（值为 50）做卷积计算：

(10+20+30+40+50+60+70+80+90)×19=450×19=50(10+20+30+40+50+60+70+80+90)×91=450×91=50

在这个特殊例子里结果恰好还是 50，因为这块区域的值均匀递增。如果这个区域中心有一个噪声点（比如中心值异常地变成了 200），均值后的结果会被拉向正常值，噪声就被平滑掉了。

#### 边界问题：图像"边上"怎么办

当核的中心移动到图像边缘时，核的一部分会"超出"图像边界，没有对应的像素值可以参与计算。这是卷积实现中必须处理的问题，常见的解决方案有三种。

**补零（Zero Padding）**：超出边界的位置用 0 填充。这是最常用也是深度学习框架中的默认做法，优点是简单，缺点是边缘区域会因为引入了人为的 0 值而产生轻微的暗边效应。

**镜像填充（Mirror Padding）**：将图像边缘的像素值镜像复制出去，这样边缘区域的统计特性与内部更接近，通常效果更自然。

**复制边缘（Replicate Padding）**：将最边缘的一行或一列像素值向外复制延伸。这三种方法在大多数情况下差别不大，只在图像边缘几个像素的范围内有细微区别。

---

### 3.3 三类核的深度理解：模糊、锐化、边缘

掌握了卷积机制之后，接下来最重要的问题是：**如何设计卷积核来实现我们想要的视觉效果？** 我们通过三种最经典的核来建立直觉。

#### 平滑核：模糊与去噪

均值滤波核我们已经见过了。它的问题是对所有邻居一视同仁，包括离得较远的邻居，这会导致模糊效果比较"生硬"，边缘被破坏得比较严重。

更聪明的做法是**高斯滤波核**。它的权重按照二维高斯函数（即钟形曲线的二维版本）分布，距离中心越近权重越大，距离越远权重越小，权重之和为 1：

h(s,t)=12πσ2e−s2+t22σ2h(s,t)=2πσ21e−2σ2s2+t2

一个典型的 3×3 高斯核（σ≈0.85）如下：

```
  1/16   2/16   1/16
  2/16   4/16   2/16
  1/16   2/16   1/16
```

注意中心权重（4/16）是角点权重（1/16）的 4 倍。与均值核相比，高斯核更"尊重"中心像素，模糊效果更柔和，在去除噪声的同时对边缘的破坏也更小。这就是为什么高斯滤波是图像处理中使用最广泛的平滑方法。

σ（标准差）参数控制模糊程度：σ 越大，高斯曲线越宽，核的影响范围越广，图像越模糊。在 OpenCV 中，`cv2.GaussianBlur(img, (5,5), sigmaX=1.0)` 就是应用 5×5 高斯核，σ=1.0 的模糊。

#### 锐化核：强调细节

锐化的逻辑与平滑正好相反。平滑是让一个像素趋向邻居的平均值（消除差异），而锐化是让一个像素**更加偏离**邻居的平均值（强调差异）。

一个直觉性的推导：如果平滑图像 fˉfˉ 代表邻域的平均，那么差值 f−fˉf−fˉ 就代表该像素相对于邻域的"突出程度"，即**细节信息**。我们可以把这个细节加回去，得到锐化图像：

g=f+k⋅(f−fˉ)=(1+k)f−kfˉg=f+k⋅(f−fˉ)=(1+k)f−kfˉ

其中 k 控制锐化强度。这个原理被称为**非锐化掩模（Unsharp Masking）**，名字听起来有点反直觉，但"非锐化掩模"的意思正是"用模糊图像作为掩模来提取细节，再叠加回去"。

当 k=1 时，对应的 3×3 锐化核是：

```
   0   -1    0
  -1    5   -1
   0   -1    0
```

你可以验证：将这个核应用于一个均匀区域（所有像素值相同），输出值等于输入值（因为 5−4×1=1，乘以相同值后还是原值）。但在边缘处（相邻像素值差异大），中心值会被放大，边缘变得更清晰锐利。

#### 边缘检测核：找到突变

边缘是图像中像素值发生**急剧变化**的地方。从数学上看，变化率对应导数，所以边缘检测的本质是**对图像求梯度**。

在离散图像中，导数用差分来近似。最简单的水平方向差分是 f(x,y+1)−f(x,y−1)（即右侧像素减去左侧像素），这对应的 1×3 核是 [−1 0 1]。把它扩展到 3×3，并对垂直方向加权求和，就得到了著名的 **Sobel 算子**。

水平方向（检测竖向边缘）的 Sobel 核 Gx 是：

```
  -1    0    1
  -2    0    2
  -1    0    1
```

垂直方向（检测横向边缘）的 Sobel 核 Gy 是：

```
  -1   -2   -1
   0    0    0
   1    2    1
```

注意 Gx 的中间列全为 0，左列全为负，右列全为正——它在计算"右侧减左侧"的加权差值。如果某处从左到右亮度急剧增加（竖向边缘），Gx 就会给出一个大的正值；如果亮度均匀，差值接近零。

综合两个方向的梯度，边缘强度可以用如下公式计算：

∣∇f∣=Gx2+Gy2∣∇f∣=Gx2+Gy2

实际应用中为了计算效率，有时用绝对值代替平方根：∣Gx∣+∣Gy∣。

还有一个更精确的边缘检测算子——**Laplacian 算子**，它对应的是二阶导数（变化率的变化率），能更精确地定位边缘位置：

```
   0   -1    0
  -1    4   -1
   0   -1    0
```

Laplacian 对噪声非常敏感，因此实际中通常先做高斯平滑再做 Laplacian，这个组合被称为 **LoG（Laplacian of Gaussian）**，是图像处理中的经典组合。

---

### 3.4 卷积的本质：一个统一的视角

学完这三类核之后，请退一步，思考它们的共性。

平滑核的权重全为正，且求和为 1——这意味着输出是输入的加权平均，不会超出原来的范围。锐化核有正有负，中心为大正数——这意味着输出强调了中心像素与邻居的差异。边缘检测核左右（或上下）对称但符号相反，求和为 0——这意味着在均匀区域输出为 0，只在有差异的地方才有响应。

全正且和为 1 → 问"这里的平均亮度是多少"；正负对称且和为 0 → 问"这里的亮度在某方向上有多少变化"；负值邻居、大正中心 → 问"这里的像素有多突出于邻域"。

这种理解方式非常重要，它会在你后来学习卷积神经网络时再次出现：CNN 的每一层卷积核的权重是**学出来的**，而不是人工设计的，但它们学到的核，往往自然地呈现出上面这些模式——浅层学习边缘，中层学习纹理，深层学习语义。传统图像处理与深度学习在这里产生了深刻的联系。

### 3.5 代码实践

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

img = cv2.imread("photo.jpg", cv2.IMREAD_GRAYSCALE).astype(np.float32)

# --- 高斯平滑 ---
# ksize=(5,5) 表示 5x5 的核，sigmaX=1.5 控制模糊程度
blurred = cv2.GaussianBlur(img, (5, 5), sigmaX=1.5)

# --- 锐化：非锐化掩模原理 ---
# 细节 = 原图 - 模糊图
detail = img - blurred
# 锐化 = 原图 + 强度系数 × 细节
k = 1.5
sharpened = np.clip(img + k * detail, 0, 255).astype(np.uint8)

# --- Sobel 边缘检测 ---
# 分别计算水平和垂直方向的梯度
# cv2.CV_32F 表示输出为浮点数（需要负值）
gx = cv2.Sobel(img, cv2.CV_32F, dx=1, dy=0, ksize=3)  # 水平梯度
gy = cv2.Sobel(img, cv2.CV_32F, dx=0, dy=1, ksize=3)  # 垂直梯度
# 合并梯度，计算边缘强度图
edges = np.sqrt(gx**2 + gy**2)
edges = np.clip(edges, 0, 255).astype(np.uint8)

# --- 可视化四种结果 ---
fig, axes = plt.subplots(1, 4, figsize=(18, 5))
for ax, image, title in zip(
    axes,
    [img.astype(np.uint8), blurred.astype(np.uint8), sharpened, edges],
    ["原图", "高斯平滑（去噪）", "非锐化掩模（锐化）", "Sobel 边缘"]
):
    ax.imshow(image, cmap='gray', vmin=0, vmax=255)
    ax.set_title(title)
    ax.axis('off')

plt.tight_layout()
plt.show()
```

### 本节小结与思考题

本节的核心是：卷积是一种"以邻域为单位"的加权求和操作，通过设计不同的卷积核，我们可以实现平滑、锐化、边缘检测等截然不同的效果。卷积核的数值模式决定了它"问"的问题，而图像给出的答案就是输出图像。

留给你的思考题是：如果我们把高斯核的所有权重乘以 −1−1，然后加上一个让中心像素权重为正的偏置，会得到什么效果？你能从数学上推导出结果，并预测它与锐化核之间的关系吗？

**下一节**我们将进入**非线性滤波**的世界。卷积滤波是线性的，有一类重要的噪声（椒盐噪声）是它的死穴——均值和高斯滤波无法有效去除，而**中值滤波**和**双边滤波**将给出优雅的解决方案。

## 第四节：非线性滤波——当卷积遇到它的边界

上一节我们深入理解了卷积滤波的本质：用一个固定的线性加权求和来综合邻域信息。这套框架非常强大，但它有一个与生俱来的局限，理解这个局限，正是本节的起点。

---

### 4.1 线性滤波的死穴：椒盐噪声

我们先来认识一种特殊的噪声——**椒盐噪声（Salt-and-Pepper Noise）**。它的成因通常是传感器损坏、传输错误或存储介质缺陷：图像中随机有一些像素被强制变成纯白（255，"盐"）或纯黑（0，"椒"），与周围像素毫无关系，就像把一张照片随机撒上了黑白芝麻。

现在思考一个问题：用高斯滤波去处理这种噪声，会发生什么？

假设图像某处有一个值为 255 的噪声点，周围 8 个像素的真实值都在 100 左右。高斯滤波会将这个 255 与周围的 100 做加权平均，结果大约是 255×0.25+100×0.75≈139。原本应该是 100 的地方，变成了 139——噪声没有消除，只是被"稀释扩散"到了邻域，变成了一个模糊的亮斑。

这就是线性滤波的根本问题：**它无法区分"这个高值是真实的边缘"还是"这个高值是噪声"**，它只是机械地做加权平均，将所有极端值都向均值拉近。对于椒盐噪声这种"极端异常值"，线性滤波不但没有去除，反而将其污染扩散到了邻域，图像变得模糊且仍有残留噪声。

解决这个问题需要一种根本不同的思路——不是加权平均，而是**排序与选择**。

---

### 4.2 中值滤波：用排序代替平均

**中值滤波（Median Filter）**的思想极其简单，却异常有效。它的操作步骤是：以当前像素为中心取一个 3×3（或更大）的邻域，将邻域内所有像素值**排序**，然后取排序后的**中间值**（中位数）作为输出，替换中心像素。

用一个数字例子来感受。假设某 3×3 邻域的像素值是：

```
  98   102   100
  97   255    99
 101   100    98
```

中心像素值为 255（一个噪声点）。将 9 个值排序：97,98,98,99,100,100,101,102,255。中位数是第 5 个值，即 **100**。于是 255 这个噪声点被完美地替换为 100，与周围的真实值完全吻合，噪声消失了，而且邻域内的其他像素几乎不受影响。

为什么中值滤波能做到这一点？关键在于：**中位数对异常值天然免疫**。无论那个噪声点是 255 还是 0，排序后它都处于序列的最末端，永远不会成为中位数，只要噪声点在邻域内不超过半数，中位数就是"真实值的代表"。

这与均值形成了鲜明对比——均值会被任何极端值拉偏，而中位数不会。统计学中把这种性质称为**鲁棒性（Robustness）**，中值滤波是鲁棒统计思想在图像处理中的直接体现。

中值滤波的另一个优点是**保边性**——它在去除噪声的同时能很好地保留边缘。为什么？因为在边缘处，邻域内的像素值分成明显的"亮组"和"暗组"两群，中位数会落在其中一群内，而不是两群的平均值，因此边缘不会被模糊掉。这是均值滤波做不到的。

中值滤波的代价是计算量：排序比加法乘法慢得多，尤其当核变大时（7×7 核需要排 49 个数）。不过现代处理器对此有专门优化，实际应用中速度可以接受。

---

### 4.3 高斯滤波的另一个死穴：边缘模糊

中值滤波解决了椒盐噪声的问题，但它不是万能的。对于另一种常见噪声——**高斯噪声**（每个像素被叠加了一个随机的小扰动，类似相机在高 ISO 下产生的颗粒感），中值滤波的效果反而不如高斯滤波好，因为这种噪声没有极端异常值，每个像素都只是轻微偏离真实值，取中位数的意义就没那么大了。

那对于高斯噪声，难道只能回到高斯滤波，接受边缘被模糊的代价吗？

这里有一个深刻的矛盾值得我们认真想一想：**去噪和保边是天然冲突的**。去噪需要"混合"邻域像素来平均掉随机扰动，而保边需要在边缘两侧的像素之间保持分离，不进行混合。传统高斯滤波用同一套权重处理图像的每个位置，无论那里是平坦区域还是边缘——这正是它的局限所在。

打破这个矛盾，需要一个更聪明的想法：**让权重随图像内容自适应变化**。在平坦区域，邻域像素都比较相似，尽管混合；在边缘附近，混合只发生在同侧的像素之间，不越过边缘。这就是双边滤波的核心思想。

---

### 4.4 双边滤波：同时考虑空间距离与像素值差异

**双边滤波（Bilateral Filter）**由 Tomasi 和 Manduchi 于 1998 年提出，是一个兼顾去噪与保边的优雅方案。它的命名来自它计算权重的方式——同时考虑**两个**因素。

普通高斯滤波的权重只取决于**空间距离**：离中心越近，权重越大。而双边滤波在此基础上引入了第二个因子——**像素值差异**：与中心像素值越相近，权重越大；差异越大，权重越小。

用公式来表达，双边滤波的输出是：

g(x,y)=1W∑(s,t)∈Ωf(s,t)⋅e−(x−s)2+(y−t)22σs2⏟空间权重⋅e−[f(x,y)−f(s,t)]22σr2⏟值域权重g(x,y)=W1(s,t)∈Ω∑f(s,t)⋅空间权重e−2σs2(x−s)2+(y−t)2⋅值域权重e−2σr2[f(x,y)−f(s,t)]2

其中 W 是归一化系数（保证权重之和为 1），σs 控制空间高斯的宽度，σr 控制值域高斯的宽度。

让我们用文字来理解这个公式的含义。对于图像中某个平坦区域的像素，它的邻居们像素值都与它相近，值域权重接近 1，退化为普通高斯滤波，噪声被有效平滑。对于边缘处的像素，边缘另一侧的邻居像素值与它差异很大，值域权重趋近于 0，这些邻居实际上被"忽略"了；只有同侧（与中心像素值相近的）邻居才被纳入计算，于是边缘不会被模糊。

你可以把双边滤波想象成一种"有选择性的耳朵"：在嘈杂但均匀的地方（平坦区域），它广泛听取邻居意见来过滤噪声；在有重要边界的地方，它只听"和自己相似的"那一侧邻居，从而保持了边界的清晰。

参数 σs 和 σr 各司其职：σs 越大，空间影响范围越广，类似高斯模糊的半径；σr 越大，值域宽容度越高，更多像素被纳入计算，保边性越弱但平滑效果越强；σr 越小，保边性越强，但对噪声的抑制也越弱。调节这两个参数，可以在去噪与保边之间找到平衡。

双边滤波的代价是**计算量远大于线性滤波**，因为每个像素的权重都不同（取决于当前中心像素的值），无法用卷积这种固定核的方式快速实现，必须逐像素独立计算。对于大图像，速度会比较慢，这也是多年来研究者不断提出加速算法的动力所在。

### 4.5 导向滤波：双边滤波的高效继承者

既然双边滤波速度慢，有没有在保持保边特性的同时更高效的方法？2010 年，何恺明（是的，正是后来提出 ResNet 的那位）在读博期间提出了**导向滤波（Guided Filter）**，给出了一个优雅的回答。

导向滤波的核心思想是：假设输出图像在局部小窗口内可以用导向图像（Guidance Image）来线性表示，即 gi=ak⋅Gi+bk，其中 G 是导向图（可以是图像本身，也可以是另一张参考图），(ak,bk) 是在每个局部窗口 k 内估计的线性系数。通过最小二乘法求解这些系数，再对所有重叠窗口的结果取平均，就得到了输出。

这个线性假设带来了巨大的计算优势：它可以用**盒型滤波（Box Filter）**高效实现，时间复杂度与图像大小呈线性关系，与核的大小无关——这意味着用大核做导向滤波，速度并不比小核慢多少。

导向滤波的另一个优点是它的**各向同性不足**恰好带来了更好的边缘保护：在边缘处，线性模型无法同时拟合边缘两侧的像素，因此会自然地在边缘处产生较大的系数变化，从而"保留"了边缘。

在实际应用中，导向滤波已经在很多场合取代了双边滤波，特别是需要实时处理或处理高分辨率图像的场景。

### 4.6 代码实践：四种滤波方法的对比

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

# 读取原始图像（灰度）
img = cv2.imread("photo.jpg", cv2.IMREAD_GRAYSCALE)

# 人工添加椒盐噪声，用于测试中值滤波
def add_salt_pepper(image, prob=0.05):
    noisy = image.copy()
    # 随机选取 prob 比例的像素设为 255 或 0
    rng = np.random.default_rng(42)
    mask = rng.random(image.shape)
    noisy[mask < prob / 2] = 0      # 椒（黑点）
    noisy[mask > 1 - prob / 2] = 255  # 盐（白点）
    return noisy

# 人工添加高斯噪声，用于测试双边滤波
def add_gaussian_noise(image, sigma=25):
    rng = np.random.default_rng(42)
    noise = rng.normal(0, sigma, image.shape)
    noisy = np.clip(image.astype(np.float32) + noise, 0, 255)
    return noisy.astype(np.uint8)

sp_noisy = add_salt_pepper(img)
gauss_noisy = add_gaussian_noise(img)

# --- 对椒盐噪声做处理 ---
# 高斯滤波：只是把噪声扩散，效果不好
gauss_on_sp = cv2.GaussianBlur(sp_noisy, (5, 5), sigmaX=1.5)
# 中值滤波：核大小必须是奇数，3x3 通常已经足够
median_on_sp = cv2.medianBlur(sp_noisy, ksize=3)

# --- 对高斯噪声做处理 ---
# 高斯滤波：平滑有效但边缘模糊
gauss_on_gauss = cv2.GaussianBlur(gauss_noisy, (9, 9), sigmaX=2.0)
# 双边滤波：d=9 是邻域直径，sigmaColor=75 是值域参数，sigmaSpace=75 是空间参数
bilateral_on_gauss = cv2.bilateralFilter(gauss_noisy, d=9,
                                          sigmaColor=75, sigmaSpace=75)

# --- 可视化 ---
fig, axes = plt.subplots(2, 4, figsize=(20, 10))

# 第一行：椒盐噪声的处理对比
axes[0, 0].imshow(img, cmap='gray', vmin=0, vmax=255)
axes[0, 0].set_title("原图")
axes[0, 1].imshow(sp_noisy, cmap='gray', vmin=0, vmax=255)
axes[0, 1].set_title("椒盐噪声")
axes[0, 2].imshow(gauss_on_sp, cmap='gray', vmin=0, vmax=255)
axes[0, 2].set_title("高斯滤波（失败：噪声扩散）")
axes[0, 3].imshow(median_on_sp, cmap='gray', vmin=0, vmax=255)
axes[0, 3].set_title("中值滤波（成功：噪声消除）")

# 第二行：高斯噪声的处理对比
axes[1, 0].imshow(img, cmap='gray', vmin=0, vmax=255)
axes[1, 0].set_title("原图")
axes[1, 1].imshow(gauss_noisy, cmap='gray', vmin=0, vmax=255)
axes[1, 1].set_title("高斯噪声")
axes[1, 2].imshow(gauss_on_gauss, cmap='gray', vmin=0, vmax=255)
axes[1, 2].set_title("高斯滤波（去噪但边缘模糊）")
axes[1, 3].imshow(bilateral_on_gauss, cmap='gray', vmin=0, vmax=255)
axes[1, 3].set_title("双边滤波（去噪且保边）")

for ax in axes.ravel():
    ax.axis('off')

plt.tight_layout()
plt.show()
```

### 4.7 选择哪种滤波？一个实用的决策框架

学完这几种方法，你可能会问：实际面对一张噪声图像，该怎么选？这里提供一个思考框架，帮你做出有依据的判断。

首先判断噪声类型。如果图像中有明显的随机黑白点（孤立的极端值），那是椒盐噪声，首选中值滤波。如果图像整体有均匀的颗粒感（类似胶片颗粒或高 ISO 摄影），那是高斯噪声，需要在高斯滤波和双边滤波之间选择。

其次判断边缘是否重要。如果图像中有重要的边缘信息需要保留（比如医学图像中的器官边界、文档图像中的文字轮廓），选择双边滤波或导向滤波。如果图像主要是平坦区域（比如天空、皮肤），边缘不多，高斯滤波就足够了，速度还更快。

最后考虑实时性要求。如果需要实时处理（视频流、实时预览），高斯滤波和中值滤波效率更高；双边滤波较慢；导向滤波是保边滤波中速度最快的选择。

### 本节小结与思考题

本节的核心思想是：滤波方法的选择应该匹配噪声的统计特性和图像的结构特性。线性滤波（高斯）适合高斯噪声的平滑去除，但会模糊边缘；中值滤波用排序代替平均，对椒盐噪声有天然免疫力；双边滤波通过引入值域相似性权重，在去噪的同时自适应地保护边缘；导向滤波则用局部线性假设实现了更高效的保边滤波。

这里留给你一个深度思考题：中值滤波在处理椒盐噪声时表现优异，但如果椒盐噪声的密度非常高（比如 40% 的像素都是噪声），3×3 的中值滤波会失效吗？为什么？如果失效了，有什么解决方案？你能从中位数的统计原理出发推导出"噪声密度的临界值"吗？
