## 第十一节：卷积神经网络——用图像处理的眼光重新理解深度学习

这是本系列的最终章。在过去十节中，我们从像素矩阵出发，一步步建立起了完整的图像处理知识体系：点变换、空间滤波、频率域分析、图像分割、形态学、特征提取、几何变换、多尺度分析……现在，我们要用这套知识作为"解码器"，重新审视卷积神经网络（CNN）的每一个设计决策。

这节课的目的不是教你如何训练一个神经网络——那是深度学习课程的任务。我们的目标是回答一个更深层的问题：**CNN 为什么是这样设计的？它的每个组件，用图像处理的语言来说，究竟在做什么？**

---

### 11.1 从手工特征到可学习特征：一个范式转变

回忆第八节，我们学习了 SIFT、HOG、LBP 这些经典特征。它们都有一个共同的局限：**特征提取规则由人类专家设计，固定不变**。SIFT 假设局部外观可以用梯度方向直方图来描述，HOG 假设形状信息主要来自梯度分布——这些假设在很多场合是对的，但它们是人类对视觉的"猜测"，不是从数据中学到的最优方案。

CNN 的核心革命在于：**用数据驱动的方式自动学习最优的特征提取器**，而不是靠人工设计。但这里有一个关键问题：学习什么？学习的参数是什么形式？

答案就在我们第三节深入讲过的卷积核上。CNN 的每一层卷积层，包含若干个可学习的卷积核，网络通过反向传播自动调整这些卷积核的权重，使得提取出的特征对最终任务（分类、检测、分割等）最有用。

为了认识这门语言，我们需要深入理解 CNN 的每个组件。

---

### 11.2 卷积层：第三节的延伸与升华

我们在第三节已经深入理解了卷积操作：一个卷积核在图像上滑动，做加权求和，不同的核实现不同的功能——平滑、锐化、边缘检测。CNN 的卷积层做的是完全相同的操作，只有一个根本区别：**核的权重不是人工设计的，而是通过梯度下降从数据中学习的**。

让我们来想一想，CNN 第一个卷积层会学到什么。给定大量自然图像，为了让后续层能够区分不同的图像内容，第一层卷积核需要提取最基础的视觉信息。实验表明，训练好的 CNN 第一层卷积核，几乎无一例外地呈现为各种方向的**边缘检测器**和**颜色对比检测器**——这与 Sobel、Gabor 等人工设计的边缘检测核高度相似。

这不是巧合，而是一个深刻的结论：**边缘和颜色对比确实是自然图像中最基础、最有信息量的特征**，无论是人工设计还是自动学习，都会收敛到这个答案。CNN 通过大量数据"重新发现"了图像处理研究者几十年前就知道的事实，只是以一种更系统、更自动的方式。

CNN 卷积层还有几个与经典卷积不同的重要设计。首先是**多通道卷积**：输入图像有 3 个颜色通道（RGB），卷积核也相应地有 3 层，在每个通道上分别做卷积再求和，这使得卷积核能够同时感知颜色信息和空间结构。其次是**多个并行核**：一个卷积层通常包含几十到几百个不同的卷积核，每个核学习检测不同的模式，所有核的输出堆叠在一起，形成多通道的特征图。第三个是**参数共享**：同一个卷积核在整幅图像上共享权重，这使得 CNN 具有天然的**平移不变性**——无论目标出现在图像的哪个位置，都能被同一个核检测到。

---

### 11.3 激活函数：引入非线性

纯粹的线性卷积操作（加权求和）有一个根本局限：无论叠加多少层线性操作，最终仍然是线性的，表达能力等同于单层线性变换。为了让网络能够学习复杂的非线性函数（比如"这张图像里有没有猫"这种高度非线性的判断），每个卷积操作之后都需要一个**激活函数**。

最广泛使用的激活函数是 **ReLU（Rectified Linear Unit）**：f(x)=max(0,x)。负值变为零，正值保持不变。

从图像处理的角度，ReLU 与我们第二节讲过的**截断（Clipping）**操作高度相似——像素值超出范围时截断到边界。ReLU 本质上是在做一种"单侧截断"：只保留卷积响应为正的（激活的）部分，负响应被抑制。

为什么这样有效？你可以这样理解：卷积核在寻找特定模式，当图像中存在这个模式时响应为正（找到了），不存在时响应为负（没找到）。ReLU 让"找到了"的信号通过，"没找到"的信号归零，使得特征图变得稀疏——大部分位置是零，只有真正检测到特定模式的位置才有非零响应。这种稀疏性一方面有助于防止过拟合，另一方面也让后续层的计算更高效。

---

### 11.4 池化层：第十节金字塔思想的神经网络版本

**池化层（Pooling Layer）**是 CNN 中另一个核心组件，通常紧跟在卷积层之后。最常用的是 2×2 最大池化：将特征图分成若干个 2×2 的非重叠区域，每个区域只保留最大值，丢弃其他三个值，结果是特征图的空间分辨率减半。

从第十节的视角来看，池化层做的事情与高斯金字塔的降采样完全类似——将特征图的空间分辨率减半，使后续层的感受野成倍增大，能够"看到"更大范围的图像内容。随着网络加深，特征图越来越小，每个特征单元对应的原始图像区域越来越大，网络从关注局部细节逐渐过渡到关注全局结构——这正是多尺度分析的核心思想。

最大池化（取区域内的最大值）比平均池化（取平均值）更常用，原因可以从特征检测的角度来理解：卷积核在某个位置给出高响应，意味着在该位置检测到了目标模式。最大池化保留了"这个区域内某个地方检测到了这个模式"的信息，而平均池化则把这个强响应稀释了。换句话说，最大池化回答的是"这个区域内有没有这个模式"（有则保留强响应），平均池化回答的是"这个区域内平均有多少这个模式"——前者对于目标检测更有用。

池化层还给网络带来了一定程度的**空间不变性**：如果特征在 2×2 区域内移动了一个像素，最大值不变，池化结果不受影响。这使得网络对小的位置偏移更加鲁棒。

---

### 11.5 感受野：理解深层网络"看到"什么

**感受野（Receptive Field）**是理解 CNN 深层能力的关键概念。一个神经元的感受野，是指原始输入图像中对该神经元的激活值有影响的区域大小。

第一个卷积层使用 3×3 的核，每个输出神经元的感受野就是 3×3。经过池化（分辨率减半）再加一个 3×3 卷积，第二层的感受野在原始图像中变成 10×10。继续叠加，第三层、第四层的感受野依次快速增大。深层网络的神经元可以有几百个像素的感受野，能够感知整个物体甚至场景的全局结构。

这正是深层 CNN 强大的根本原因：**浅层神经元感受野小，检测局部细节（边缘、纹理）；深层神经元感受野大，综合全局信息理解语义（物体、场景）**。这与我们在第十节看到的图像金字塔结构完全对应——浅层对应金字塔底部（高分辨率、局部细节），深层对应金字塔顶部（低分辨率、全局结构）。

---

### 11.6 跳跃连接：拉普拉斯金字塔的神经网络版本

普通的 CNN 按顺序一层一层前向传播，信息只能向前流动。但这种线性结构有一个问题：在深层网络中，梯度在反向传播时会逐渐减弱（梯度消失问题），导致浅层的参数几乎无法更新，网络难以训练。

**ResNet（残差网络）**的跳跃连接（Skip Connection）解决了这个问题。它在每个"残差块"中，将输入直接加到若干层卷积之后的输出上：output=F(x)+x，其中 F(x) 是几层卷积的变换。

从图像处理的角度，这个设计有一个非常优雅的解读：网络不是在学习从输入到输出的完整变换，而是在学习**残差**——输出相对于输入的"修正量"。这与拉普拉斯金字塔的思想惊人地相似：拉普拉斯金字塔的每一层 Li=Gi−Upsample(Gi+1) 存储的正是"残差"——当前层相对于粗糙重建版本的细节差异。ResNet 的残差块在做同样的事：不直接变换特征，而是学习在当前特征基础上需要"加入"或"修正"的信息。

**U-Net** 则是一个更直接对应拉普拉斯金字塔重建的架构。它有一个编码器路径（逐层降采样，类似高斯金字塔的构建）和一个解码器路径（逐层上采样，类似拉普拉斯重建），以及连接编码器和解码器对应层的跳跃连接（类似重建时"加回细节"的操作）。这使得解码器在每一层都能同时获得深层的语义信息（来自编码器底部）和浅层的细节信息（来自跳跃连接），从而在图像分割任务中实现精确到像素级别的预测。

---

### 11.7 CNN 特征的层次结构：一个完整的视角

将前面所有内容综合起来，我们可以建立一幅 CNN 特征层次结构的完整图景。

在第一到第二层，CNN 学到的是各种方向的边缘、颜色梯度、简单纹理——这与 Sobel 边缘检测、Gabor 滤波器高度相似，是人类视觉皮层 V1 区（初级视皮层）处理的内容。在第三到第四层，CNN 组合浅层的边缘特征，学到更复杂的结构：曲线、角点、简单形状、材质纹理——这对应人类视觉皮层 V2/V4 区处理的内容。在第五层及以上，CNN 学到的特征开始有强烈的语义意义：人脸的局部结构、车轮的圆形轮廓、文字的笔画模式——这些"神经元"只对特定类别的高级视觉概念有强烈响应。最终，全连接层（或全局平均池化）将所有空间特征聚合成一个固定维度的向量，用于最终的分类或其他任务。

这个层次结构与我们在第八节讨论特征提取时建立的"好特征"框架完全对应：浅层提供细节和可定位性（高判别性），深层提供语义和不变性（高鲁棒性）。CNN 通过深度叠加，在同一个框架内同时实现了两个目标——而这正是 SIFT、HOG 等手工特征无法做到的。

---

### 11.8 代码实践：从图像处理视角解剖 CNN

```python
import numpy as np
import matplotlib.pyplot as plt

# 我们用 PyTorch 来可视化 CNN 的中间层特征，
# 从图像处理的视角直接观察每层在"做什么"
try:
    import torch
    import torch.nn as nn
    import torchvision.models as models
    import torchvision.transforms as transforms
    from PIL import Image
    TORCH_AVAILABLE = True
except ImportError:
    TORCH_AVAILABLE = False
    print("PyTorch 未安装，以下代码仅供阅读理解")

if TORCH_AVAILABLE:
    # ---- 第一部分：可视化预训练 VGG 的第一层卷积核 ----
    # VGG 是一个经典的深度 CNN，其第一层卷积核接近人工设计的边缘检测器
    vgg = models.vgg16(pretrained=False)  # 不下载预训练权重，只看结构
    # 实际使用时可以用 pretrained=True 下载 ImageNet 预训练权重

    # 第一个卷积层的权重形状是 (64, 3, 3, 3)：
    # 64 个卷积核，每个核有 3 个通道（对应 RGB），每个通道 3x3
    first_layer_weights = vgg.features[0].weight.data.numpy()
    print(f"第一层卷积核形状: {first_layer_weights.shape}")
    print("64 个核，每个核 3通道×3×3，学习检测不同方向的边缘和颜色对比")

    # 可视化前 16 个卷积核（只取 RGB 三通道合并显示）
    fig, axes = plt.subplots(4, 4, figsize=(12, 12))
    for i, ax in enumerate(axes.ravel()):
        if i < 16:
            # 取第 i 个核，形状 (3, 3, 3)，转置为 (3, 3, 3) HWC 格式
            kernel = first_layer_weights[i].transpose(1, 2, 0)
            # 归一化到 [0,1] 用于显示
            kernel = (kernel - kernel.min()) / (kernel.max() - kernel.min() + 1e-8)
            ax.imshow(kernel)
            ax.set_title(f"核 {i+1}", fontsize=8)
        ax.axis('off')

    plt.suptitle("VGG 第一层卷积核（64个中的前16个）\n"
                 "注意：这些核的形状与 Sobel、Gabor 等人工设计的边缘检测器高度相似\n"
                 "CNN 通过数据学习，自动重新发现了人类专家设计的特征",
                 fontsize=11)
    plt.tight_layout()
    plt.show()

    # ---- 第二部分：用纯 NumPy 手动实现一个微型 CNN ----
    # 不依赖 PyTorch，从零实现前向传播，加深对每层操作的理解
    import cv2

    class MiniCNN:
        """
        一个极简的 CNN，只包含：
        卷积层（使用 Sobel 核模拟第一层边缘检测）→
        ReLU 激活（截断负值）→
        最大池化（2×2，分辨率减半）→
        第二层卷积（用均值核模拟池化后的平滑）
        这不是一个可训练的网络，而是用于演示 CNN 各层操作的可视化工具。
        """

        def __init__(self):
            # 模拟第一层卷积核：水平和垂直 Sobel 边缘检测
            # 真实 CNN 中这些值是通过训练学到的，
            # 但 Sobel 核恰好是网络倾向于学习的典型形状
            self.conv1_kernels = np.array([
                # 水平边缘检测核（Sobel Y）
                [[[-1,-2,-1],[0,0,0],[1,2,1]],
                 [[-1,-2,-1],[0,0,0],[1,2,1]],
                 [[-1,-2,-1],[0,0,0],[1,2,1]]],
                # 垂直边缘检测核（Sobel X）
                [[[-1,0,1],[-2,0,2],[-1,0,1]],
                 [[-1,0,1],[-2,0,2],[-1,0,1]],
                 [[-1,0,1],[-2,0,2],[-1,0,1]]],
                # 45 度方向边缘
                [[[0,1,2],[-1,0,1],[-2,-1,0]],
                 [[0,1,2],[-1,0,1],[-2,-1,0]],
                 [[0,1,2],[-1,0,1],[-2,-1,0]]],
                # 中心-周边对比（类似 Laplacian）
                [[[-1,-1,-1],[-1,8,-1],[-1,-1,-1]],
                 [[-1,-1,-1],[-1,8,-1],[-1,-1,-1]],
                 [[-1,-1,-1],[-1,8,-1],[-1,-1,-1]]],
            ], dtype=np.float32)  # shape: (4, 3, 3, 3) = (核数, 输入通道, H, W)

        def conv2d(self, input_tensor, kernels, padding=1):
            """
            手动实现多通道卷积。
            input_tensor: (H, W, C_in)
            kernels: (C_out, C_in, kH, kW)
            输出: (H, W, C_out)
            """
            H, W, C_in = input_tensor.shape
            C_out, _, kH, kW = kernels.shape

            # 对输入做零填充，保持输出尺寸不变
            padded = np.pad(input_tensor,
                            [(padding,padding), (padding,padding), (0,0)],
                            mode='constant')

            output = np.zeros((H, W, C_out), dtype=np.float32)
            for c_out in range(C_out):
                for c_in in range(C_in):
                    # 对每对（输出通道，输入通道）做 2D 卷积
                    kernel = kernels[c_out, c_in]
                    # 使用 OpenCV 的 filter2D 做单通道卷积，高效且准确
                    output[:,:,c_out] += cv2.filter2D(
                        padded[:,:,c_in], -1, kernel,
                        borderType=cv2.BORDER_CONSTANT
                    )[padding:padding+H, padding:padding+W]
            return output

        def relu(self, x):
            """ReLU 激活：截断负值，只让正响应通过。"""
            return np.maximum(0, x)

        def max_pool2d(self, x, pool_size=2):
            """
            2×2 最大池化：每个 2×2 区域取最大值。
            分辨率减半，感受野加倍，对小位移鲁棒。
            """
            H, W, C = x.shape
            H_out, W_out = H // pool_size, W // pool_size
            output = np.zeros((H_out, W_out, C), dtype=np.float32)
            for i in range(H_out):
                for j in range(W_out):
                    # 取对应 2×2 区域的最大值
                    region = x[i*pool_size:(i+1)*pool_size,
                               j*pool_size:(j+1)*pool_size, :]
                    output[i, j, :] = region.max(axis=(0,1))
            return output

        def forward(self, img_rgb):
            """完整的前向传播，输出每个中间层的特征图用于可视化。"""
            # 归一化到 [-1, 1]（CNN 的标准预处理）
            x = img_rgb.astype(np.float32) / 127.5 - 1.0

            # 第一层卷积：提取边缘特征（4 个核，4 种边缘方向）
            conv1_out = self.conv2d(x, self.conv1_kernels)
            print(f"卷积层输出形状: {conv1_out.shape}（H×W×4通道）")

            # ReLU：只保留正响应（"找到了这种边缘"的位置）
            relu1_out = self.relu(conv1_out)
            print(f"ReLU 后形状: {relu1_out.shape}（形状不变，负值归零）")

            # 最大池化：分辨率减半，感受野加倍
            pool1_out = self.max_pool2d(relu1_out, pool_size=2)
            print(f"池化后形状: {pool1_out.shape}（H和W各减半）")

            return conv1_out, relu1_out, pool1_out

    # 读取测试图像并运行微型 CNN
    img = cv2.imread("photo.jpg")
    if img is not None:
        img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
        # 缩小图像加速演示
        img_small = cv2.resize(img_rgb, (256, 256))

        cnn = MiniCNN()
        conv_out, relu_out, pool_out = cnn.forward(img_small)

        # ---- 可视化 CNN 各层的输出 ----
        fig, axes = plt.subplots(4, 4, figsize=(16, 16))

        # 第一列：原始输入
        axes[0,0].imshow(img_small)
        axes[0,0].set_title("输入图像\n(256×256×3 RGB)")

        # 第二列：4个通道的卷积输出（卷积后，有正有负）
        for i in range(4):
            channel = conv_out[:,:,i]
            # 以零为中心，用发散色图显示（正值为暖色，负值为冷色）
            vmax = np.abs(channel).max()
            axes[i,1].imshow(channel, cmap='RdBu_r', vmin=-vmax, vmax=vmax)
            axes[i,1].set_title(f"卷积输出-通道{i+1}\n"
                                 f"（暖色=正响应，冷色=负响应）")

        # 第三列：ReLU 后（负值归零）
        for i in range(4):
            axes[i,2].imshow(relu_out[:,:,i], cmap='hot')
            axes[i,2].set_title(f"ReLU后-通道{i+1}\n（只剩正响应位置）")

        # 第四列：最大池化后（分辨率减半）
        for i in range(4):
            axes[i,3].imshow(pool_out[:,:,i], cmap='hot')
            axes[i,3].set_title(f"池化后-通道{i+1}\n"

        for ax in axes.ravel():
```

### 11.9 整个课程的知识图谱：一次深度回望

走到这里，让我们停下来，用一张"知识地图"来回顾这十一节走过的路程，看清楚它们之间的内在联系。

一切从**像素矩阵**开始（第一节）——图像是数字，这是整个体系的基石。**点变换**（第二节）是最简单的操作，每个像素独立变换，无法感知邻域结构。这个局限引出了**空间域滤波**（第三节），卷积操作让每个像素"听取"邻居意见，实现平滑、锐化、边缘检测，也成为 CNN 的核心机制。当卷积遇到它的局限——椒盐噪声——时，**非线性滤波**（第四节）用排序代替加权和，引出了双边滤波这种更智能的自适应方法。

当我们想从全局理解图像的频率特性时，**傅里叶变换**（第五节）给了我们频率域的视角，揭示了低频与高频、模糊与边缘、噪声与细节的本质关系，也是 JPEG 压缩的理论基础。有了对图像结构的理解，我们开始思考如何让计算机"看出"图像中的有意义区域，这就是**图像分割**（第六节），从最简单的阈值到分水岭、GrabCut，一路走向全局优化。分割得到的二值图往往不完美，需要**形态学处理**（第七节）这套几何工具来清理结构，腐蚀、膨胀、开闭运算构成了一个优雅的集合论框架。

当我们需要从图像中提取有意义的描述时，**特征提取**（第八节）引出了 Harris、SIFT、HOG、LBP 这些经典方法，它们代表了深度学习前的最高水平，也是理解 CNN 的重要参照。有了特征，我们可以处理**多幅图像之间的关系**——**几何变换与配准**（第九节）用单应矩阵和 RANSAC 实现了鲁棒的图像对齐，是全景拼接等应用的基础。然后**多尺度分析**（第十节）用高斯和拉普拉斯金字塔统一了"不同距离观察同一场景"的思想，而这正是 SIFT 尺度不变性和 FPN 多尺度检测的理论基础。

最后，**CNN**（本节）将所有这些思想融合在一个可学习的框架中：卷积层是可学习的边缘/特征检测器，ReLU 是非线性门控，池化层是降采样（金字塔），跳跃连接是残差/细节补充（拉普拉斯重建），多层堆叠实现了从局部细节到全局语义的层次化理解。

本节的核心洞见是：CNN 不是凭空出现的黑盒，它的每一个设计决策都有深刻的图像处理根源。卷积层重新发现了边缘检测，池化层实现了多尺度分析，跳跃连接对应拉普拉斯重建，感受野对应多尺度金字塔的层次结构。理解了这些联系，你对 CNN 的认识就从"它能用"上升到了"我知道为什么它能用"。

走完这十一节，你建立的不只是一系列孤立的技术知识，而是一套完整的**视觉计算思维方式**：图像是数字，操作是数学，不变性是核心追求，多尺度是基本视角，从局部到全局是普遍规律。这套思维方式，无论面对经典算法还是最新的 Vision Transformer、扩散模型，都能帮助你看清楚它们在做什么，为什么有效，以及有什么局限。

最后留给你一个开放性的思考，没有标准答案，但值得长期思考：整个课程中，我们一直在追求对图像的"理解"——从像素到边缘，从边缘到形状，从形状到物体，从物体到场景。但什么是真正的"理解"？CNN 在 ImageNet 上的分类准确率超过了人类，但当你给它看一张图像然后稍微旋转一点，它可能就识别失败了，而人类永远不会犯这个错误。这说明 CNN 学到的"理解"与人类的"理解"之间还有什么本质差距？而弥补这个差距，正是计算机视觉未来最重要的研究方向之一。

### 第四层：你还差的传统视觉算法

我们的课程已经覆盖了SIFT的原理和特征匹配，这是第四层的核心之一。但还有几块重要内容没有涉及。

**ORB（Oriented FAST and Rotated BRIEF）**在代码中出现过，但没有深入讲解其原理。ORB是SIFT的开源高速替代品，它组合了两个独立的算法：FAST角点检测器（比Harris快得多的关键点定位方法）和BRIEF描述子（一种用像素对随机比较生成二进制串的方法，类似LBP的思路）。理解ORB的关键在于理解**二进制描述子**的设计哲学——用汉明距离代替欧氏距离，匹配速度提升数十倍。这不只是工程技巧，而是对"什么信息是必要的"这个问题的深刻回答。

**立体视觉（Stereo Vision）**是你目前完全没有接触的一块。它的核心问题是：给定两台水平放置的相机拍摄的两幅图像，如何计算场景中每个点的深度？这里涉及极线几何（Epipolar Geometry）、基础矩阵（Fundamental Matrix）、本质矩阵（Essential Matrix）这一套优美的数学框架。你在第九节学过单应矩阵，立体视觉可以看作它的"立体版本"——不是同一平面的两个视角，而是真正的三维场景重建。这是自动驾驶、机器人导航的核心感知技术，也是理解深度估计类深度学习模型的必要基础。

**光流（Optical Flow）**是另一块缺失。光流研究的是视频中像素如何随时间运动——每个像素从当前帧到下一帧移动了多少、往哪个方向移动。Lucas-Kanade方法和Horn-Schunck方法是两个经典算法，前者是局部方法（类似我们学过的邻域处理思想），后者是全局优化方法（类似GrabCut的能量最小化思路）。光流是视频理解、目标跟踪、运动分割的基础，也是后来FlowNet、PWC-Net等深度光流网络的理论前身。

### 第五层：你目前的准备情况

你的十一节课为深度学习视觉打下了非常好的理论基础，但从理解原理到真正掌握第五层，还需要补充几个过渡性知识。

在进入YOLO和Faster RCNN之前，你需要真正理解**目标检测的问题定义**：它不只是分类（这张图有没有猫），而是同时回答"有什么"和"在哪里"——输出是类别标签加上边界框坐标。这个双重任务的设计，催生了anchor、IoU、NMS（非极大值抑制）等一系列你需要掌握的概念。其中NMS（非极大值抑制）与你学过的形态学细化和极值检测有相似的哲学——去除冗余，保留最强响应。

**语义分割**是你在第六节图像分割基础上的自然延伸，但深度学习方法（FCN、DeepLab、SegFormer）的输出粒度要求到每个像素，这就把U-Net的编解码结构和跳跃连接（你在第十一节已经理解了）变得至关重要。此前已经有了很好的基础。

**姿态估计**是第五层中对你来说最陌生的领域，它需要额外理解关键点检测（Keypoint Detection）和热图（Heatmap）表示方法，这是一套与我们学过的方法有所不同的输出范式。

### 建议的学习路径

考虑到你已有的基础，我建议按以下顺序补充。首先完成第四层的两块缺失：先学立体视觉（因为它与你已掌握的几何变换知识衔接最紧密），再学光流（因为它引出了时序建模的思维，是进入视频理解的钥匙）。

然后进入第五层时，不要急着学具体模型，先花时间理解**检测任务的核心设计问题**：如何定义"好的检测"（IoU）、如何生成候选区域（anchor vs anchor-free）、如何处理多尺度目标（此前已经理解了FPN）。把这些基础概念搞清楚之后，YOLO和Faster RCNN的设计差异会变得非常清晰，而不是两套需要分别记忆的东西。
