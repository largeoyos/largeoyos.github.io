# 第十四节：算术几何——当代数遇上几何

类域论是代数数论的高峰，但它本质上仍然是"一维"的——研究的是数域（零维的点）的扩张。算术几何的诞生，是把这套思想推广到"高维"的尝试：不只研究方程的解的个数（零维信息），而是研究解集的**几何形状**，以及这个形状如何随着不同的数域和局部域而变化。

这是一个真正的范式转变。你不再只问"方程有没有整数解"，而是问"所有解构成的空间长什么样"，然后用几何的工具来回答算术的问题。

---

## 14.1 为什么要用几何语言研究数论？

让我们从一个你熟悉的例子开始感受这种转变。

勾股方程 x² + y² = 1 在有理数上的所有解（即本原勾股数）由参数化公式给出：

$$x = \frac{1-t^2}{1+t^2}, \quad y = \frac{2t}{1+t^2}, \quad t \in \mathbb{Q}$$

这个参数化从几何上看非常自然：在单位圆上取点 (−1, 0)，过这个点作斜率为 t 的直线，它与圆的另一个交点恰好是 (x, y)。所有有理斜率 t ∈ ℚ 对应圆上所有的有理点（除了 (−1, 0) 本身）。

这里发生了一件深刻的事：**一个数论问题（找方程的有理解）被转化成了一个几何问题（直线与曲线的交点），而几何问题的解又给出了数论问题的完整答案**。这正是算术几何的核心思想——用几何来驾驭算术。

但为什么这行得通？直线和圆在代数上都是简单对象，交点的计算是代数运算，而代数运算在有理数、整数、或任何域上都可以进行。所以"几何"提供的其实是一套**语言和直觉**，使我们能把代数方程的解的结构（无论定义在哪个域上）用熟悉的几何概念来描述和分析。

---

## 14.2 代数簇：方程的解集作为几何对象

算术几何的基本对象是**代数簇**（algebraic variety）。

最直接的定义是：代数簇是一组多项式方程的公共零点集。比如，单个多项式 f(x, y) = 0 的零点集是一条**代数曲线**，两个多项式 f(x, y, z) = 0，g(x, y, z) = 0 的公共零点集可能是一条**空间曲线**，更一般地，n 个变量中 k 个方程的公共零点集（在一般位置下）是一个 n−k 维的**代数簇**。

关键在于"定义域"的选取：你可以问这些方程在 ℂ、ℝ、ℚ、𝔽_p（有限域）、ℚ_p（p 进数域）或任何其他域上的零点集。不同的域给出不同的"解集"，但**方程本身（即几何对象）是固定的**。算术几何的核心任务，正是理解同一个几何对象在不同域上的解集之间的关系。

一个经典例子是**费马曲线** xⁿ + yⁿ = zⁿ（齐次化后是射影空间中的曲线）。费马大定理等价于：当 n ≥ 3 时，这条曲线在 ℚ 上除了平凡点（某个坐标为 0 的解）之外没有其他有理点。Wiles 的证明正是通过研究这条曲线（和相关的椭圆曲线）的几何来实现的。

---

## 14.3 概形：Grothendieck 的革命

20 世纪代数几何最重要的进步，是 Grothendieck 在 1950−60 年代引入的**概形**（scheme）理论。概形是"代数簇"概念的深刻推广，它允许我们在任意交换环（不只是域）上定义几何对象，从而把代数几何和代数数论统一在同一个框架下。

直觉上，你可以把概形理解为"可以同时在所有域和环上解释的几何对象"。一个具体的例子：方程 x² + y² = 1 定义了一个**概形** X，它可以在 ℚ 上被问"有多少有理点"，在 𝔽_p 上被问"有多少模 p 的解"，在 ℤ 上被问"有多少整数解"，在 ℝ 上被问"曲线长什么样"，所有这些问题的答案都是同一个几何对象 X 在不同"纤维"（fiber）上的体现。

Grothendieck 的语言用**环的谱**（spectrum of a ring）来构造概形。对交换环 R，其谱 Spec(R) 是 R 的所有素理想的集合，配备一个特殊的拓扑（Zariski 拓扑）和一个结构层（structure sheaf，描述"局部函数"的代数对象）。概形就是局部同构于某个 Spec(R) 的带层空间。

这个定义的美妙之处在于：

整数环 ℤ 的谱 Spec(ℤ) 包含所有素理想 (p)（p 为素数）以及零理想 (0)，它像一条"算术直线"，每个素数对应一个"点"。数域 K 的整数环 𝒪_K 的谱 Spec(𝒪_K) 是一条"算术曲线"，每个素理想 𝔭 对应一个点，而 K 本身是这条曲线的"一般纤维"。方程 f(x) = 0 的解集既可以看作通常意义下的几何曲线（在复数或实数上），也可以看作 Spec(ℤ[x]/(f)) → Spec(ℤ) 这个概形映射——不同素数 p 上的"纤维"就是方程模 p 的解集。

最后这个观点极为重要：**一个整系数多项式方程，可以看作"Spec(ℤ) 上的一个几何对象"，而在每个素数 p 处取纤维，就得到了方程模 p 的解集**。这把"模 p 的解"和"有理数或整数解"统一在一个几何图像里。

## 14.4 椭圆曲线：算术几何的核心对象

在算术几何的所有研究对象中，**椭圆曲线**（elliptic curve）是最重要、研究最深入、应用最广泛的一类。

椭圆曲线是亏格为 1 的光滑射影曲线，带有一个指定的有理点（作为"零点"）。在特征不等于 2 或 3 的域上，椭圆曲线总可以写成 **Weierstrass 方程**：

$$y^2 = x^3 + ax + b$$

其中 a, b 是域中的元素，判别式 Δ = −16(4a³ + 27b²) ≠ 0（保证曲线光滑，没有奇点）。

椭圆曲线最特别的地方是，它的点集（加上一个"无穷远点" O）在一个自然定义的加法下构成一个**Abel 群**。这个加法的定义来自代数几何：过椭圆曲线上两点 P 和 Q 作直线，它与曲线的第三个交点记为 R，然后把 R 关于 x 轴的对称点定义为 P + Q。这个看起来奇特的定义，其实是椭圆曲线的代数结构（三次方程的因子分解）的几何表达。

群律的代数公式也非常精确。若 P = (x₁, y₁)，Q = (x₂, y₂) 是曲线上两个不同的点（x₁ ≠ x₂），令斜率 λ = (y₂−y₁)/(x₂−x₁)，则 P+Q = (x₃, y₃) 其中 x₃ = λ² − x₁ − x₂，y₃ = λ(x₁−x₃) − y₁。这个公式可以在任何域上计算——这正是椭圆曲线能够跨越不同域工作的代数基础。

---

## 14.5 有理点：Mordell-Weil 定理

在算术上，我们最关心的是椭圆曲线的**有理点群** E(ℚ)——所有坐标在 ℚ 中的点，连同无穷远点 O，在上面定义的群律下构成一个群。

**定理（Mordell，1922；Weil，1928）**：椭圆曲线的有理点群 E(ℚ) 是**有限生成 Abel 群**，因此同构于：

$$E(\mathbb{Q}) \cong \mathbb{Z}^r \oplus E(\mathbb{Q})_{\text{tors}}$$

其中 r ≥ 0 是**秩**（rank），ℤʳ 是自由部分，E(ℚ)_tors 是**挠子群**（torsion subgroup，即有限阶元素构成的子群）。

挠子群已经被完全分类：Mazur 定理（1978 年）证明了 E(ℚ)_tors 只有 15 种可能的结构（ℤ/nℤ 对 n = 1,...,10, 12，以及 ℤ/2ℤ × ℤ/2nℤ 对 n = 1,...,4）。

秩 r 则神秘得多。它衡量的是椭圆曲线有多少"独立的"无穷阶有理点——r = 0 时只有有限多个有理点（都是挠点），r ≥ 1 时有无穷多个有理点（可以由生成元通过群运算生成）。目前没有已知的算法能在有限步内确定任意椭圆曲线的秩，**秩的计算**是数论最深刻的未解问题之一。

关于秩，最重要的猜想是 **BSD 猜想**（Birch 和 Swinnerton-Dyer 猜想，1960 年代），我们下面会详细介绍。

---

## 14.6 有限域上的点：Weil 猜想

在算术几何中，除了有理点，另一个极为重要的问题是**有限域上的点的个数**。设 E 是定义在 ℤ 上的椭圆曲线（即 a, b ∈ ℤ），对每个素数 p（不整除判别式 Δ），可以把方程模 p 来考虑：

$$y^2 \equiv x^3 + ax + b \pmod{p}$$

这是有限域 𝔽_p 上的椭圆曲线 E_p，其有理点个数记为 #E(𝔽_p)。

一个基本的估计是 **Hasse 定理**（1933 年）：

$$\big|#E(\mathbb{F}_p) - (p+1)\big| \leq 2\sqrt{p}$$

有限域上的点数位于 $p+1$ 附近，误差不超过 $2\sqrt{p}$。这一误差尺度与**黎曼假设**中的误差估计相似：在 RH 成立时，$\pi(x)$ 与 $\operatorname{Li}(x)$ 的误差为 $O(\sqrt{x}\log x)$。这种相似并非巧合，背后存在深刻联系。

定义 **迹** aₚ = p+1 − #E(𝔽_p)，Hasse 定理说 |aₚ| ≤ 2√p。可以写 αₚ = p + 1 − aₚ · 其中 αₚ 和 ᾱₚ 是绝对值为 √p 的共轭复数（即 αₚ · ᾱₚ = p）。这和黎曼 ζ 函数的非平凡零点全在实部 1/2 的直线上（即 |e^{iθ}| = 1 而 |p^{1/2} · e^{iθ}| = √p）高度类比。

为了完整描述 E 在所有有限域 𝔽_{p^n} 上的点数，引入椭圆曲线的 **L 函数**：

$$L(E, s) = \prod_{p \nmid \Delta} \frac{1}{1 - a_p p^{-s} + p^{1-2s}} \cdot \prod_{p \mid \Delta} (\text{局部因子})$$

这是一个 Dirichlet 级数，类比于 Riemann ζ 函数和 Dirichlet L 函数，但现在的局部因子来自椭圆曲线在每个素数处的几何信息。它编码了 E 在所有有限域上的点数信息，是连接椭圆曲线的几何和解析的核心对象。

---

## 14.7 Weil 猜想与 étale 上同调

有限域上代数簇的点数计数问题，被 Weil（1949 年）组织成了一套宏大的猜想——**Weil 猜想**，后来由 Grothendieck 和 Deligne 完全证明（Deligne 的最终证明在 1974 年）。

对有限域 𝔽_q（q = pⁿ）上的光滑射影代数簇 X，定义其**泽塔函数**（zeta function）：

$$Z(X/\mathbb{F}_q, T) = \exp!\left(\sum_{n=1}^{\infty} #X(\mathbb{F}_{q^n}) \frac{T^n}{n}\right)$$

Weil 猜想断言这个形式幂级数满足三个性质。第一是**有理性**：Z(X/𝔽_q, T) 是 T 的有理函数（即多项式之商）。第二是**函数方程**：Z 满足一个类似黎曼 ζ 函数的函数方程，体现 X 的 Poincaré 对偶性。第三是**黎曼假设**：Z 的分子和分母的根（即 Z 的"零点"和"极点"）的绝对值是 q 的特定次幂，具体地，次数为 i 的上同调群对应的根的绝对值恰好是 q^{i/2}。

Weil 猜想的第三部分（"有限域上的黎曼假设"）是最深刻、最难证明的部分，Deligne 的工作是二十世纪代数几何的最高峰之一。证明的工具是 Grothendieck 发展的 **étale 上同调**（étale cohomology）——一种在代数簇上定义的上同调理论，类比于拓扑空间的奇异上同调，但可以用于有限域上的代数簇。

为什么需要"étale"上同调而不是普通的上同调？普通的代数拓扑上同调在特征为 p 的域上会出现问题（系数需要是 ℓ 进数，ℓ ≠ p），而 étale 拓扑（用代数方法定义的一种"精细拓扑"）绕开了这个困难。Grothendieck 的天才之处在于，他发现正确的上同调理论不依赖于"点集拓扑"的直觉，而可以完全用代数语言（范畴论和位形）来定义。

## 14.8 BSD 猜想：椭圆曲线最深刻的问题

回到椭圆曲线的有理点。

**BSD 猜想**（Birch 和 Swinnerton-Dyer，1960 年代）给出了一个惊人的预测：椭圆曲线 E 的秩 r，等于其 L 函数 L(E, s) 在 s = 1 处的**零点阶数**！即：

$$r = \text{ord}_{s=1} L(E, s)$$

更精确地，BSD 猜想的弱形式说：L(E, 1) = 0 当且仅当 r ≥ 1（即 E(ℚ) 有无穷多个有理点）。强形式给出 L(E, s) 在 s = 1 处的 Taylor 展开的精确公式，其中系数涉及到椭圆曲线的各种算术不变量（Tate-Shafarevich 群的阶、正则子、周期等）。

这个猜想把两件看起来完全无关的事情联系起来：左边 r 是纯粹代数-算术的（有理点群的结构），右边是 L 函数的解析性质（复变函数的零点）。这种"解析对象控制算术对象"的哲学，贯穿了整个数论，但 BSD 猜想把它推到了一个前所未有的深度。

BSD 猜想是**七个千禧年问题之一**，解决它有 100 万美元的奖励，但至今仍未完全证明。目前最好的结果是：当 L(E, 1) ≠ 0 时（即解析零点阶数为 0），r = 0 是已知的（Coates-Wiles，1977 年，以及后续工作）；当 L(E, s) 在 s = 1 处有一阶零点时，r = 1 在很多情形下是已知的（Gross-Zagier，1986 年，以及 Kolyvagin，1988 年）。但更高阶零点的情形，理论工具仍然不足。

## 14.9 模形式与 Taniyama-Shimura-Weil 猜想

费马大定理的证明用到了一个关于椭圆曲线的深刻猜想，由 Taniyama（1955 年）、Shimura（1957 年）和 Weil（1967 年）逐步发展，由 Wiles 和 Taylor-Wiles 在 1995 年（对半稳定椭圆曲线）证明，Breuil-Conrad-Diamond-Taylor 在 2001 年完全证明。

**定理（模性定理）**：每个定义在 ℚ 上的椭圆曲线都是**模的**，即存在一个模形式 f 使得 L(E, s) = L(f, s)。

什么是**模形式**（modular form）？它是上半复平面 ℍ = {z ∈ ℂ : Im(z) > 0} 上的全纯函数 f(z)，在模群 SL₂(ℤ)（或其子群）的作用下满足特定的变换规律：

$$f!\left(\frac{az+b}{cz+d}\right) = (cz+d)^k f(z)$$

其中 k 是模形式的**权**（weight），(a b; c d) 是整数矩阵满足 ad−bc = 1。这些变换规律使得模形式有非常强的对称性，它们可以展开成 Fourier 级数 f(z) = Σ_{n=0}^∞ aₙ e^{2πinz}，系数 aₙ 携带了丰富的算术信息。

模性定理说，椭圆曲线 E 的 L 函数 L(E, s) = Σ aₙ/nˢ 中的系数 aₙ，恰好等于某个权为 2 的模形式 f 的 Fourier 系数。这是一个令人叹为观止的结论——连续的分析对象（模形式）和离散的算术对象（椭圆曲线）之间存在精确的等价关系。

Wiles 的证明路线是：Frey（1984 年）发现如果费马大定理 aᵖ + bᵖ = cᵖ 有解，可以构造一条椭圆曲线 E_{Frey}；Ribet（1990 年）证明这条曲线"太奇特"，不可能是模的；而 Wiles 证明了所有（半稳定）椭圆曲线都是模的，矛盾，从而证明了费马大定理。

---

## 14.10 Langlands 纲领的影子

模性定理把椭圆曲线（几何对象）和权为 2 的模形式（自守形式）联系起来，这只是一个更宏大纲领的特例——**Langlands 纲领**。

Langlands 纲领（Robert Langlands，1967 年）是一套关于数论、代数几何和表示论的宏大猜想体系，其核心思想是：

**Galois 表示**（即 Galois 群 Gal(Q̄/ℚ) 的线性表示，描述代数方程的对称性）和**自守形式**（即满足特定对称性的解析函数，广义的模形式）之间存在深刻的一一对应。

这个对应推广了你学过的很多内容：类域论是 Langlands 对应在"一维 Abel 表示"情形的完整理论（即 GL₁ 的情形）；模性定理是"二维表示"情形（GL₂）的一个重要特例；更高维的情形（GLₙ，n ≥ 3）大部分仍是公开问题。

Langlands 纲领中已经完全证明的深刻结果包括：Langlands 关于 GL₂ 的基本引理（2009 年，Ngô Bảo Châu 因此获得 Fields 奖），以及函数域上的 Langlands 对应（Drinfeld 对 GL₂，Lafforgue 对一般 GLₙ，均获 Fields 奖）。数域上的完整 Langlands 对应仍是当代数学最核心的开放问题。

---

## 本节小结

算术几何把代数几何的语言和工具引入数论，核心思想是把方程的解集看作几何对象，然后研究这个对象在不同域上（有理数、有限域、p 进数）的表现及其相互关系。Grothendieck 的概形理论提供了统一的语言，把所有这些域上的几何纳入同一个框架。椭圆曲线是最核心的研究对象，其有理点群由 Mordell-Weil 定理刻画，秩的计算由 BSD 猜想（未证明）联系到 L 函数的解析性质。Weil 猜想（由 Deligne 证明）揭示了有限域上点数和 L 函数零点的深刻联系，模性定理（由 Wiles 等人证明）把椭圆曲线和模形式等同，是费马大定理证明的核心。Langlands 纲领把这一切组织成一个统一的框架，连接 Galois 表示、自守形式和 L 函数，是当代数论最宏大的研究纲领。

我们的旅程从整除、GCD 出发，经过模运算、算术函数、连分数、加法数论，进入解析数论的 ζ 函数和素数定理，再经过代数数论的整数环、理想、类群、p 进数、类域论，最终到达算术几何的椭圆曲线、模形式和 Langlands 纲领。这是一段从"1+1"到"费马大定理"的完整旅程，而这段旅程的尽头，是当代数学仍在探索的疆域。
