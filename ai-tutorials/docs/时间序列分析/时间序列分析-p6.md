# 时间序列分析 · 第十二课：函数型时间序列与现代方法

---

## 从标量到曲线：一个自然的推广

前十一课里，每个时刻的观测值都是一个数——一个标量，或者一个有限维向量。但现实中越来越多的数据天然地是"曲线"或"函数"。

想象一个气象站，每天连续记录24小时的气温变化。你可以把它看成每天48个半小时的标量读数，然后用一个48维的 VAR 模型来处理。但这样做会丢失一个关键信息：这48个数字不是独立的——它们是同一条平滑曲线上的离散采样点，有内在的连续性结构。强行用离散向量来处理，就像用像素列表来描述一幅画，忽略了像素之间的空间关系。

类似的情形还有很多。每个交易日的股票日内收益率曲线（以时间为自变量），每年的气候异常曲线（以月份为自变量），每位患者的脑电图记录（以频率为自变量）——这些数据的自然单位都是"一条曲线"，而不是"一个数"。当这样的曲线按时间顺序排列时，就形成了**函数型时间序列**（functional time series）。

---

## 函数型数据分析：把曲线当作观测单元

**函数型数据分析**（Functional Data Analysis，FDA）的核心思想是把每条曲线当作一个整体的"观测单元"，而不是一堆离散点的集合。它的数学基础是你在泛函分析里学过的 Hilbert 空间——函数空间 $L^2([0,1])$，配上内积 $\langle f, g \rangle = \int_0^1 f(x)g(x)dx$。

对于一条曲线 $X_i(t)$（$t \in [0,1]$，$i$ 是样本编号），FDA 的第一步通常是把离散观测拟合成光滑曲线——用 B 样条、傅里叶基或小波基来表示，把无限维的函数压缩到有限维的系数向量。这一步叫做**光滑化**（smoothing），它把数据从"$n \times p$ 的矩阵"变成"$n$ 条曲线的集合"。

在拿到一组曲线之后，最重要的工具是**函数主成分分析**（Functional PCA，FPCA）。FPCA 寻找一组正交的基函数 $\phi_1(t), \phi_2(t), \ldots$，使得每条曲线的方差被尽可能地集中在前几个主成分上。数学上，这等价于求协方差算子（一个从 $L^2$ 到 $L^2$ 的自伴算子）的特征函数：

$$\int_0^1 C(s, t) \phi_k(t) dt = \lambda_k \phi_k(s)$$

其中 $C(s,t) = \text{Cov}(X(s), X(t))$ 是协方差核函数（二元函数），$\lambda_k$ 是特征值，$\phi_k$ 是特征函数。你会立刻认出，这正是自伴紧算子的谱分解——泛函分析里的谱定理在这里有直接的应用。每条曲线被投影到前 $K$ 个特征函数上，得到 $K$ 个标量得分 $\xi_{ik} = \langle X_i - \mu, \phi_k \rangle$，把无限维问题降维到 $K$ 维。

## 函数型时间序列：曲线的自回归

当这些曲线按时间顺序排列时，我们需要建模曲线之间的**时间依赖性**。最自然的推广是**函数型 AR(1) 模型**（FAR(1)）：

$$X_t(u) = \int_0^1 \Psi(u, v) X_{t-1}(v) dv + \varepsilon_t(u)$$

其中 $\Psi(u, v)$ 是一个**算子核**（operator kernel），决定了上一条曲线如何影响当前曲线的每个点。把 $\Psi$ 理解为一个从 $L^2$ 到 $L^2$ 的有界线性算子 $\mathcal{A}$，FAR(1) 就是 $X_t = \mathcal{A} X_{t-1} + \varepsilon_t$——一个在 Hilbert 空间里的 AR(1)。平稳条件是算子 $\mathcal{A}$ 的算子范数 $|\mathcal{A}| < 1$，和标量 AR(1) 的 $|\phi| < 1$ 完全类比。

实践中的处理方法是：先用 FPCA 把每条曲线投影到前 $K$ 个特征函数上，得到 $K$ 维得分向量 $\xi_t = (\xi_{t1}, \ldots, \xi_{tK})'$，然后对得分向量建一个标准的 VAR(p) 模型。这把无限维问题化归为有限维，用我们已经熟悉的工具来处理。

函数型时间序列的一个漂亮应用是**利率期限结构的建模**。每天的收益率曲线（以到期期限为自变量）就是一条函数，而不同交易日的收益率曲线形成了一个函数型时间序列。Nelson-Siegel 模型实际上就是一种特殊的三因子函数型模型——用三个特征函数（水平、斜率、曲率）来描述每天的收益率曲线，再对三个得分做 VAR 建模。

## 深度学习与时间序列：一个新的范式

过去十年，深度学习在时间序列预测领域产生了巨大影响。理解它的威力和局限，需要先理解它和我们已学的统计模型的本质联系与区别。

在统计模型里，我们总是从一个具体的数据生成机制出发（比如"这个序列是 AR(2) 过程"），然后在这个假设下做推断。这叫做**参数化建模**——先假设一个函数形式，再估计参数。深度学习采取了完全不同的哲学：用一个足够复杂的**通用函数近似器**（universal function approximator）来直接学习从过去到未来的映射，不做任何关于数据生成过程的参数假设。这是一种彻底的**非参数化**（或者说，过度参数化）方法。

理解这个区别很重要：统计模型的强项是**可解释性**和**小样本效率**——如果你的先验知识（模型假设）是对的，统计模型用很少的数据就能得到很好的估计。深度学习的强项是**大数据下的模式发现**——当数据量足够大，复杂的非线性关系不需要被手动指定，神经网络可以自动发现。

---

## LSTM：为序列设计的记忆单元

**LSTM**（Long Short-Term Memory，长短期记忆网络）由 Hochreiter 和 Schmidhuber 在1997年提出，是专为处理序列数据而设计的递归神经网络。

普通的递归神经网络（RNN）把序列 $x_1, x_2, \ldots, x_t$ 逐步处理，在每个时刻 $t$ 维护一个"隐状态" $h_t$：

$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$$

$h_t$ 扮演了"记忆"的角色，把过去的信息传递到未来。但普通 RNN 有一个著名的**梯度消失问题**：在反向传播训练时，关于早期时刻 $x_1$ 的梯度要经过很多次矩阵乘法才能传到当前时刻，如果矩阵的特征值小于1，梯度就会指数衰减为零，网络无法学习长期依赖。

LSTM 通过引入一个额外的**单元状态** $C_t$（cell state）和三个**门**（gate）来解决这个问题。遗忘门 $f_t$ 控制从 $C_{t-1}$ 中保留多少信息，输入门 $i_t$ 控制把多少新信息写入 $C_t$，输出门 $o_t$ 控制从 $C_t$ 中输出多少到隐状态 $h_t$：

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$$ $$i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)$$ $$\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C)$$ $$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$ $$o_t = \sigma(W_o [h_{t-1}, x_t] + b_o)$$ $$h_t = o_t \odot \tanh(C_t)$$

其中 $\sigma$ 是 sigmoid 函数（输出在 $[0,1]$ 之间，自然地充当"门的开合程度"），$\odot$ 是逐元素乘法。关键在于 $C_t$ 的更新方程是**加法**而不是乘法——梯度可以直接沿 $C_t$ 这条"高速公路"流动，不会被矩阵乘法消耗，从而有效地学习长期依赖。

你会注意到 LSTM 和状态空间模型（第七课）有惊人的相似之处：$C_t$ 类似于不可观测的状态向量，三个门类似于 Kalman 增益对信息的动态加权，$h_t$ 类似于观测量。这个类比不只是表面的——有研究表明，在线性化的特殊情形下，LSTM 可以被解读为一种参数化的 Kalman 滤波器，只是参数通过梯度下降而不是通过矩阵方程来估计。

## Transformer 与注意力机制：打破时间顺序的束缚

LSTM 虽然解决了梯度消失问题，但它的递归结构有一个本质限制：处理时刻 $t$ 时必须先处理完 $t-1$，无法并行化，训练速度受限于序列长度。更深的问题是，即使 LSTM 能学习长期依赖，它也需要把很久以前的信息"压缩"存储在固定大小的隐状态里，这对超长序列是一个瓶颈。

**Transformer**（Vaswani 等，2017年）彻底打破了递归结构，用**自注意力机制**（self-attention）直接计算序列中任意两个位置之间的依赖关系，允许完全的并行计算。

自注意力的核心计算是：对序列中每个位置 $t$，计算它对所有其他位置 $s$ 的"注意力权重"，然后把所有位置的值按权重加权求和：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中 $Q$（query）、$K$（key）、$V$（value）是输入序列经过三个不同线性变换得到的矩阵，$d_k$ 是维度（用于缩放，防止内积过大）。这个计算的含义是：位置 $t$ 的输出是所有位置的值 $V$ 的加权平均，权重由位置 $t$ 的查询向量 $Q_t$ 和每个位置的键向量 $K_s$ 的相似度决定。相似度高（$Q_t$ 和 $K_s$ 内积大）的位置获得更高的注意力权重，其值对当前位置的影响也更大。

你会发现，这个机制和谱分析里的思想有一个深层的共鸣：自注意力是在计算**序列不同位置之间的一种"相关性矩阵"**，然后用这个矩阵对值进行加权求和——这和谱分析里用协方差结构来描述时间依赖的思路，在本质上是相通的。两者都在问"这个位置的信息和那个位置有多相关"，只是谱分析用的是固定的统计协方差，而注意力机制用的是通过数据学习的动态相关性。

## 统计模型与深度学习的比较：一个坦诚的评估

在时间序列预测领域，统计模型和深度学习各有其优势，理解这个比较比盲目追随任何一方都重要。

统计模型的核心优势是**可解释性**：ARIMA 的参数有明确的统计意义（AR 系数是偏自相关，差分阶数对应单整阶数），GARCH 的参数描述了波动率的聚集性和持续性，VECM 的系数直接对应协整关系和调整速度。这些解释对经济学研究至关重要——你不只是想要一个好的预测，你想理解为什么经济系统是这样运作的。此外，统计模型在**小样本**下表现更好，因为它们把领域知识编码在模型结构里，不需要大量数据来"发现"这些结构。

深度学习的核心优势是**大数据下的非参数灵活性**：当数据量足够大，神经网络可以捕捉任意复杂的非线性关系，不需要人工指定函数形式。在某些大规模预测任务（如同时预测几千种商品的销售量，或者大量传感器的读数），深度学习确实展现了显著优于传统统计模型的准确性。

但必须指出的是，在**单变量短期预测**这个经典任务上，大量严格的比较研究（包括著名的 M4 和 M5 竞赛）发现，精心调参的统计模型（ETS、ARIMA、Theta 方法）和复杂的深度学习模型的预测精度往往相差无几，有时候统计模型还更胜一筹。深度学习的优势主要体现在：数据量很大、序列很多（可以跨序列学习共享模式）、或者存在复杂非线性的场景。在数据量有限、需要可解释性、或者需要严格的不确定性量化（预测区间）时，统计模型往往是更合适的选择。

## 一个思考题

我们看到了 LSTM 和状态空间模型的相似性，以及 Transformer 注意力机制和自相关/谱分析的相通性。这些不只是表面的类比——它们提示我们，深度学习并没有"脱离"统计学的基本框架，而只是用一种更灵活的参数化方式来实现类似的思想。

基于这个认识，想一想：**如果你手边有100年的月度宏观经济数据，你会用什么模型来做5年期的预测？** 你会如何在统计模型（ARIMA、VAR、VECM）和深度学习（LSTM、Transformer）之间做出选择？你认为这个问题有"正确答案"吗？这个思考没有标准答案，但它会帮助你把整个课程学到的东西整合成一个有机的判断框架。
