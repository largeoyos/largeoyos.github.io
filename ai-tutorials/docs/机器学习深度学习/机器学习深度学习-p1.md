## 机器学习与深度学习 · 第一节：从你已知的概念出发

### 一、此前已经在学机器学习了

先告诉你一个令人惊喜的事实：**你之前学的很多内容，本质上就是机器学习的核心数学**。

在信息论那门课里，你学到了交叉熵损失——你的笔记里写道，"最小化交叉熵等价于最大似然估计"。这句话不是一个应用例子，它就是机器学习里**分类问题的核心训练目标**。每次你打开 PyTorch 写 `nn.CrossEntropyLoss`，你在做的事情，此前已经从信息论层面理解了。

在SLAM那条路上，你学了**Bundle Adjustment（BA）**——给定一堆相机位姿和三维路标点，最小化重投影误差。这个过程用到了非线性最小二乘优化（Gauss-Newton / Levenberg-Marquardt）。机器学习的训练，**本质上就是同一件事**：给定一个目标函数，用梯度下降或其变体去最小化它。BA和神经网络训练的区别只是"参数"的含义不同——BA里是相机位姿，深度学习里是权重矩阵。

这就是我们的起点：**机器学习 = 定义损失函数 + 优化它**。

---

### 二、什么是机器学习？一个精确的定义

机器学习的经典定义来自 Tom Mitchell（1997年）：

> 如果一个程序，通过经验 E 在任务 T 上的表现 P 不断提高，我们就说它在学习。

这个定义虽然简洁，但有时候反而不够直觉。让我换一种工程师的说法：

**传统编程**的逻辑是：你写规则，程序根据规则处理数据，输出结果。

**机器学习**的逻辑是：你给数据和期望的结果，程序自己学出规则（参数），以后用这套规则处理新数据。

类比一下你SLAM里的内容：你没有手写"第327个特征点在地图里的坐标是(1.3, 0.7, 2.1)"，而是用BA优化出来的。机器学习也是如此——你没有手写"猫的耳朵是尖的，狗的耳朵是圆的"这样的规则，而是让模型从数万张猫狗图片中自己学出来。

---

### 三、机器学习的三大类型

机器学习按照"学习信号来自哪里"可以分成三类，理解这个分类比记住名词更重要。

**监督学习（Supervised Learning）** 是最常见的情形：每个训练样本都有一个正确答案（标签）。比如"这张图是猫，标签是1"、"这张图是狗，标签是0"。模型通过不断预测、与正确答案对比、调整参数来学习。你在信息论里学的交叉熵损失，就是监督学习里分类任务的标准目标函数。

**无监督学习（Unsupervised Learning）** 是没有标签的情形：数据扔给你，你自己发现结构。聚类（K-Means）、降维（PCA）、密度估计都属于这类。你在信息论里学的变分自编码器（VAE）就是典型的无监督生成模型。

**强化学习（Reinforcement Learning）** 是通过"试错+奖励信号"来学习的情形。你在信息论笔记里提到的 PPO 算法（训练ChatGPT用的），就属于这类。agent在环境中行动，环境给出奖励，agent学习最大化累计奖励的策略。

### 四、从线性回归开始，理解"学习"的本质

最简单的机器学习模型是**线性回归**。虽然简单，但它包含了所有机器学习方法的核心要素，值得深入理解。

想象你有一批数据：每个学生学习的小时数 x，和他的考试分数 y。你想找到一条直线 y=wx+b，让它尽量"贴合"这些数据点，以后给一个新的 x，预测他的分数。

这里面有三个核心要素：**模型**（直线 y=wx+b）、**损失函数**（预测值和真实值的差距）、**优化算法**（怎么找到最好的 w 和 b）。

损失函数通常用均方误差（MSE）：

L(w,b)=1N∑i=1N(yi−(wxi+b))2L(w,b)=N1i=1∑N(yi−(wxi+b))2

这个式子的意义：把所有数据点上"预测误差的平方"加起来，取平均。你想让这个值尽量小。

怎么找到最小值？对 w 和 b 求偏导，令导数为零，解方程——这是解析解。但实际的神经网络参数可能有数十亿个，解析法行不通，所以我们用**梯度下降**：

w←w−α⋅∂L∂w←w−α⋅∂w∂L

这里 α 叫**学习率**，控制每次更新的步幅。梯度 ∂L∂w∂w∂L 告诉你损失函数在当前位置"朝哪个方向上坡最陡"，你往反方向走一步，损失就减小。

用 Python 写出来，逻辑是这样的：

```python
import numpy as np

# 生成一些模拟数据：真实关系是 y = 2x + 1，加上噪声
X = np.random.randn(100)
y = 2 * X + 1 + 0.3 * np.random.randn(100)

# 初始化参数（随机猜一个起点）
w, b = 0.0, 0.0
alpha = 0.01  # 学习率

# 梯度下降迭代 500 次
for step in range(500):
    # 正向计算：用当前 w, b 做预测
    y_pred = w * X + b

    # 计算损失（均方误差）
    loss = np.mean((y_pred - y) ** 2)

    # 计算梯度（对 w 和 b 的偏导数）
    dL_dw = np.mean(2 * (y_pred - y) * X)
    dL_db = np.mean(2 * (y_pred - y))

    # 更新参数：往梯度反方向走一步
    w -= alpha * dL_dw
    b -= alpha * dL_db

    if step % 100 == 0:
        print(f"Step {step}: loss={loss:.4f}, w={w:.3f}, b={b:.3f}")

# 训练结束后，w 应接近 2，b 应接近 1
print(f"\n最终结果: w={w:.3f}, b={b:.3f}")
```

运行这段代码，你会看到 w 从随机值逐渐收敛到接近 2，b 收敛到接近 1——模型"学"到了数据背后的规律。这就是机器学习最核心的过程。

## 第二节：从线性模型到神经网络

先来回应你上节课的两个思考题，因为答案会直接引出这节的核心内容。

### 思考题的答案

**为什么机器学习用 SGD 而不用 LM？**

关键在于数据量。BA 里你可能有几千个路标点和几十帧图像，参数量是几万量级，LM 需要计算 Hessian 矩阵（或其近似），计算量是参数量的平方级，完全承受得起。但 ImageNet 有 128 万张图，一个现代神经网络有几亿个参数——如果你要算一个几亿×几亿的矩阵，内存就先爆了。SGD 的思路是：**不用全部数据算一次完美的更新，而是随机抽一小批数据（mini-batch）算一个"粗糙但够用"的梯度，快速迭代**。粗糙没关系，因为迭代足够多次之后，随机误差会互相抵消，整体仍然收敛。这是一个用精度换速度的工程决策，恰好在大数据场景下非常有效。

**线性模型不够用怎么办？**

你可能直觉上想到："加更多参数"，或者"用曲线代替直线"。这两个方向都对，而且它们最终汇聚成同一个答案——**神经网络**。具体是怎么做到的，就是这节的主题。

---

### 一、线性模型的根本局限

线性回归的预测是 y=wx+b，无论你把 w 和 b 调到什么值，输出永远是输入的线性函数。问题在于，现实世界里大多数有趣的关系都不是线性的。

更致命的是，就算你把很多线性层叠在一起，结果还是线性的。设想两层线性变换：

z=W2(W1x+b1)+b2=(W2W1)x+(W2b1+b2)

你会发现 W2W1 可以合并成一个矩阵，W2b1+b2 可以合并成一个偏置——两层等价于一层。**堆再多线性层，表达能力没有增加**。

这就引出了神经网络最关键的一个设计决策：**在每一层的线性变换之后，加一个非线性函数**。这个函数叫**激活函数（Activation Function）**。

---

### 二、激活函数：非线性的来源

最经典也是目前最常用的激活函数叫 **ReLU（Rectified Linear Unit）**，形式极其简单：

ReLU(x)=max(0,x)

负数变成 0，正数保持不变。就这么一个折叠，打破了线性，让堆叠层数变得有意义。

你可能觉得这太简单了，能有什么用？"任意函数"包括猫狗分类、语音识别、围棋下法——只要数据够、网络够大、训练得当。

另一个你会遇到的激活函数是 **Sigmoid**：

σ(x)=1e−x+1σ(x)=e−x+11

它把任意实数压缩到 (0,1) 之间，非常适合用在二分类的输出层（输出可以解释为"属于正类的概率"）。你在信息论里学的逻辑斯谛回归，输出层用的就是 Sigmoid。

还有 **Tanh**，把输出压缩到 (−1,1) 之间，是 Sigmoid 的"零中心化"版本，在某些场景下训练更稳定。

这三者的关系值得记住：**Sigmoid 和 Tanh 是早期神经网络的主流，ReLU 是现代深度网络的主流**。原因我们在讲反向传播的时候会解释清楚——涉及到一个叫"梯度消失"的问题。

---

### 三、神经网络的结构

现在把线性层和激活函数组合起来，就得到了神经网络的基本单元——**全连接层（Fully Connected Layer）**，也叫**线性层**。

一个神经元的计算是：

a=ReLU(w1x1+w2x2+⋯+wnxn+b)a=ReLU(w1x1+w2x2+⋯+wnxn+b)

把很多神经元并排放，就构成一**层**。把很多层串联起来，就构成了一个**多层感知机（MLP，Multi-Layer Perceptron）**，这是最基础的神经网络架构。

层与层之间的关系是：上一层每个神经元的输出，都连接到下一层每个神经元的输入——这就是"全连接"的含义。用矩阵写出来，一层的计算是：

h=ReLU(Wx+b)

其中 W 是权重矩阵，x 是输入向量，b 是偏置向量，h 是这一层的输出（也叫**隐藏层激活值**）。

整个网络的术语是这样的：第一层叫**输入层**，最后一层叫**输出层**，中间所有层叫**隐藏层**。隐藏层的数量决定了网络的"深度"——**"深度学习"的"深"，就是指隐藏层多**。

### 四、用 PyTorch 写一个真正的神经网络

让我们用代码把上面的概念落地。我们来解决一个比线性回归更有趣的问题：识别手写数字（MNIST 数据集）。

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# ---- 1. 准备数据 ----
# MNIST 是 28×28 的灰度手写数字图像，共 10 个类别（0-9）
transform = transforms.ToTensor()  # 把图像像素值从 [0,255] 归一化到 [0,1]

train_data = datasets.MNIST(root='./data', train=True, download=True, transform=transform)
test_data  = datasets.MNIST(root='./data', train=False, download=True, transform=transform)

# DataLoader 负责每次随机抽取 64 张图（mini-batch），这就是 SGD 里的"随机"
train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
test_loader  = DataLoader(test_data,  batch_size=64, shuffle=False)

# ---- 2. 定义网络结构 ----
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        # 28×28 的图像展平后是 784 维向量
        # 我们建一个三层网络：784 → 256 → 128 → 10
        self.layers = nn.Sequential(
            nn.Linear(784, 256),  # 第一隐藏层
            nn.ReLU(),            # 非线性激活，打破线性
            nn.Linear(256, 128),  # 第二隐藏层
            nn.ReLU(),
            nn.Linear(128, 10),   # 输出层：10 个类别，输出 10 个分数（logits）
            # 注意：这里不加激活函数，因为 CrossEntropyLoss 内部会做 Softmax
        )

    def forward(self, x):
        x = x.view(-1, 784)  # 把 28×28 的图像展平成 784 维向量
        return self.layers(x)

model = MLP()
print(f"模型参数量: {sum(p.numel() for p in model.parameters()):,}")
# 你会看到大约 235,146 个参数——是线性回归 2 个参数的十万倍

# ---- 3. 定义损失函数和优化器 ----
# CrossEntropyLoss = Softmax + 负对数似然，你在信息论里已经理解了它的本质
criterion = nn.CrossEntropyLoss()

# Adam 是 SGD 的改进版，自动调整每个参数的学习率，实践中收敛更快
optimizer = optim.Adam(model.parameters(), lr=1e-3)

# ---- 4. 训练循环 ----
for epoch in range(5):
    model.train()
    total_loss = 0

    for images, labels in train_loader:
        # 前向传播：计算预测值
        outputs = model(images)

        # 计算损失：预测分布与真实标签之间的交叉熵
        loss = criterion(outputs, labels)

        # 反向传播：自动计算所有参数的梯度
        optimizer.zero_grad()  # 先清零上一步的梯度（否则会累加）
        loss.backward()        # 反向传播，计算梯度
        optimizer.step()       # 用梯度更新参数

        total_loss += loss.item()

    # 每个 epoch 结束后，在测试集上评估准确率
    model.eval()
    correct = 0
    with torch.no_grad():  # 评估时不需要梯度，节省内存
        for images, labels in test_loader:
            outputs = model(images)
            predicted = outputs.argmax(dim=1)  # 取分数最高的类别作为预测
            correct += (predicted == labels).sum().item()

    accuracy = correct / len(test_data)
    print(f"Epoch {epoch+1}: loss={total_loss/len(train_loader):.4f}, "
          f"test accuracy={accuracy:.4f}")
```

训练完成后，你会看到测试准确率达到约 97%——用不到 300,000 个参数，识别手写数字的准确率达到了人类水平。

### 五、反向传播：梯度是怎么算出来的

代码里有一行 `loss.backward()`，它神奇地把所有参数的梯度都算出来了。这背后是**反向传播算法（Backpropagation）**，这是深度学习最核心的算法之一，值得真正理解而不是当黑盒来用。

本质上，反向传播就是**链式法则的系统化应用**。你在高数里学过链式法则：如果 z=f(y)，y=g(x)，那么：

dzdx=dzdy⋅dydxdxdz=dydz⋅dxdy

神经网络的每一层都是一个函数，整个网络是函数的复合。反向传播从输出层的损失出发，一层一层往回传，用链式法则逐步计算每一层权重的梯度。

你可以把它想象成一条"信号流"：前向传播时，数据从输入层流向输出层，计算出预测值和损失；反向传播时，"梯度信号"从损失出发，反向流回每一层，告诉每个参数"你应该往哪个方向调整、调整多少"。

这里有一个重要的直觉：**梯度的大小代表了这个参数对最终损失的"影响力"**。影响力大（梯度大）的参数，每次更新幅度也更大；影响力小的参数，更新幅度也小。这使得训练是"自适应"的。

### 六、这节课的思考题

**第一个问题**：我们说 ReLU 是 max(0,x)，那它在 x=0 这个点不可导（左导数是 0，右导数是 1，不相等）。但深度学习训练完全没有因此崩溃——你觉得为什么？

**第二个问题**：上面的 MLP 把 28×28 的图像直接展平成 784 维向量再处理。这样做有什么潜在的问题？（提示：想想图像里相邻像素之间的关系，以及展平操作对这种关系的影响。）

第二个问题的答案，会引出下一节的主题：**卷积神经网络（CNN）**——深度学习在图像任务上真正腾飞的关键。
