## 第三节：卷积神经网络（CNN）

先来回应上节课的思考题，因为答案会直接引出这节的核心直觉。

### 思考题的答案

**ReLU 在 x=0 不可导，为什么训练没有崩溃？**

有两个原因。第一，在连续的实数空间里，训练过程中某个神经元的激活值精确等于 0 的概率是测度零事件，几乎不会发生。第二，就算真的遇到了，PyTorch 等框架在实现时会人为规定"在 0 点的次梯度为 0 或 1"，这个约定在实践中完全不影响训练效果。数学上的严格性在这里让步给了工程实用性，这是深度学习领域的常见现象。

**MLP 把图像展平成向量，有什么问题？**

这是一个很关键的观察。当你把 28×28 的像素矩阵展平成 784 维向量时，你实际上**抹去了像素之间的空间关系**。原本"左上角的像素和它右边的像素相邻"这个事实，在展平之后完全消失了——第 0 号位置和第 1 号位置在向量里紧挨着，但第 0 号位置和第 28 号位置（图像里同一列的下一行）在向量里却相距很远。MLP 没有办法先验地知道哪些输入维度之间有空间关联。

更实际的问题是：如果同一只猫出现在图像的左上角还是右下角，展平后的向量会完全不同，但显然这是同一只猫。MLP 需要从数据里反复见到猫在各种位置的图像，才能学会"位置无关的"猫的概念，这非常低效。

这两个问题——**无法利用空间结构、对位置变化敏感**——正是 CNN 想要解决的。

---

### 一、图像的本质：局部结构与平移不变性

在设计 CNN 之前，先理解图像数据的两个重要特性，这两个特性决定了 CNN 的设计哲学。

**第一个特性：局部性（Locality）。** 图像里有意义的模式，往往由局部像素共同构成。一条边缘是相邻像素之间的亮度突变，一个角点是两条边缘的交汇，一只眼睛是由瞳孔、眼白、眼皮这些局部区域拼成的。换句话说，**识别一个局部特征，你不需要看整张图，只需要看一小块区域**。

**第二个特性：平移不变性（Translation Invariance）。** 一条水平边缘，不管出现在图像的左上角还是右下角，它都是水平边缘，应该被同一个"边缘检测器"识别出来。这意味着，**同一个特征检测器应该在图像的每个位置都适用**，而不是为左上角的边缘训练一个检测器、再为右下角的边缘单独训练另一个。

CNN 的设计就是把这两个特性直接编码进网络结构里。

---

### 二、卷积操作：滑动窗口的特征检测器

卷积操作的核心思想非常直观：用一个小的"检测器"（叫**卷积核**或**滤波器**，filter），在图像上从左到右、从上到下滑动，每滑到一个位置就计算一次"这个位置有没有我想检测的东西"。

具体计算是这样的。假设你有一个 3×3 的卷积核 K，图像的当前位置是一个 3×3 的小块 P，那么这个位置的输出是：

output=∑i=13∑j=13Kij⋅Pijoutput=i=1∑3j=1∑3Kij⋅Pij

这就是逐元素相乘再求和——本质上是两个矩阵的**内积**，衡量当前小块和卷积核的"相似程度"。如果当前位置的像素模式和卷积核很像，内积就大；如果完全不像，内积就小甚至为负。

把这个检测器在整张图像上滑一遍，你就得到了一张新的图像，叫**特征图（Feature Map）**。特征图上每个位置的值，代表了原图对应位置"含有该滤波器所检测特征的强度"。

这里有一个非常重要的认识：**卷积核的权重是共享的**。同一个卷积核在图像每个位置使用相同的权重——这直接实现了平移不变性，而且参数量大幅减少（一个 3×3 的卷积核只有 9 个参数，而 MLP 里相应的连接可能有几万个）。

一张图类比：如果你是一个"边缘检测专家"，你扫描整张图的方式不是雇 1000 个人分别盯着 1000 个区域，而是你自己带着同一套"边缘判断标准"，从左扫到右。这就是权重共享。

---

### 三、CNN 的完整结构

一个典型的 CNN 由三种层交替叠加而成：**卷积层、激活层、池化层**，最后接全连接层做分类。

**卷积层**包含多个卷积核，每个卷积核负责检测一种特征，输出对应的特征图。比如第一层的 16 个卷积核，可能分别检测水平边缘、垂直边缘、45度边缘等低级特征，输出 16 张特征图。

**激活层**紧跟在卷积层之后，通常就是 ReLU——和 MLP 一样，打破线性。

**池化层（Pooling）**是 CNN 特有的一种层。最常见的是**最大池化（Max Pooling）**：用一个 2×2 的窗口在特征图上滑动，每个位置只保留窗口内的最大值，输出尺寸缩小为原来的一半。池化的作用有两个：一是降低特征图的空间尺寸，减少计算量；二是引入一定的**位置不敏感性**——一个特征在 2×2 区域内的小幅位移不会改变池化的输出。

网络越深，感受野越大，检测的特征越抽象。**浅层卷积核检测边缘、纹理等低级特征；深层卷积核的感受野覆盖原图的大片区域，开始检测"眼睛"、"轮子"这样的高级语义特征**。这个层次化的特征抽取过程，是 CNN 最优雅的设计之处。

---

### 四、用 PyTorch 实现 CNN

把上面的概念写成代码，并和上节课的 MLP 对比：

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# 数据加载（和上节相同）
transform = transforms.ToTensor()
train_data = datasets.MNIST('./data', train=True,  download=True, transform=transform)
test_data  = datasets.MNIST('./data', train=False, download=True, transform=transform)
train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
test_loader  = DataLoader(test_data,  batch_size=64, shuffle=False)

class CNN(nn.Module):
    def __init__(self):
        super().__init__()

        # ---- 特征提取部分：卷积层负责"看图" ----
        self.features = nn.Sequential(
            # 第一个卷积块
            # in_channels=1（灰度图），out_channels=16（输出16张特征图）
            # kernel_size=3（3×3的卷积核），padding=1（保持尺寸不变）
            nn.Conv2d(1, 16, kernel_size=3, padding=1),  # 输出: 16×28×28
            nn.ReLU(),
            nn.MaxPool2d(2),   # 空间尺寸减半：输出 16×14×14

            # 第二个卷积块：特征图数量翻倍，感受野更大，检测更复杂的特征
            nn.Conv2d(16, 32, kernel_size=3, padding=1), # 输出: 32×14×14
            nn.ReLU(),
            nn.MaxPool2d(2),   # 再次减半：输出 32×7×7
        )

        # ---- 分类部分：全连接层负责"做判断" ----
        self.classifier = nn.Sequential(
            nn.Flatten(),          # 把 32×7×7 的特征图展平成 1568 维向量
            nn.Linear(32*7*7, 128),
            nn.ReLU(),
            nn.Linear(128, 10),   # 输出 10 个类别的分数
        )

    def forward(self, x):
        x = self.features(x)      # 先用卷积提取空间特征
        x = self.classifier(x)    # 再用全连接做分类
        return x

model = CNN()
# 注意和上节 MLP 的参数量对比
print(f"CNN 参数量: {sum(p.numel() for p in model.parameters()):,}")
# 大约 21,898 个参数，只有 MLP 的 1/10！但准确率会更高

criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=1e-3)

# 训练循环（和上节完全相同，结构分离使得训练代码可以复用）
for epoch in range(5):
    model.train()
    total_loss = 0
    for images, labels in train_loader:
        outputs = model(images)
        loss = criterion(outputs, labels)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        total_loss += loss.item()

    model.eval()
    correct = 0
    with torch.no_grad():
        for images, labels in test_loader:
            predicted = model(images).argmax(dim=1)
            correct += (predicted == labels).sum().item()

    print(f"Epoch {epoch+1}: loss={total_loss/len(train_loader):.4f}, "
          f"accuracy={correct/len(test_data):.4f}")
```

你会发现 CNN 用约 22,000 个参数，达到约 99% 的测试准确率——而 MLP 用了 235,000 个参数，只达到 97%。**参数更少，效果更好**，这正是因为 CNN 的结构设计利用了图像数据的先验知识（局部性和平移不变性），而 MLP 要从数据中从零学习这些结构。

### 五、现实世界里的 CNN：从 LeNet 到 ResNet

MNIST 是一个"教学玩具"，真实世界的图像任务要复杂得多。了解 CNN 的演进历史，能让你感受到这个领域是怎样一步步解决真实问题的。

**LeNet（1998年）** 是 CNN 的奠基之作，由 Yann LeCun 提出，用于银行支票上的手写数字识别，结构和我们上面写的非常相似。这是第一个在商业上大规模部署的神经网络。

**AlexNet（2012年）** 是深度学习革命的起点。它在 ImageNet 大规模图像识别竞赛中，把错误率从 26% 一举降到 15%，领先第二名近 10 个百分点。关键创新是：更深的网络、ReLU 激活函数（取代 Sigmoid）、Dropout 正则化、以及 GPU 并行训练。从这一年起，深度学习开始统治计算机视觉。

**VGGNet（2014年）** 的贡献是证明了"深度很重要"——它使用 16-19 层网络，但设计极其简洁，全部用 3×3 的小卷积核堆叠。这个设计告诉大家：两个 3×3 卷积的感受野等于一个 5×5 卷积，但参数量更少、非线性更多。

**ResNet（2015年）** 解决了一个关键问题：网络越深，训练越难。理论上深度越深表达能力越强，但实验中 56 层的网络比 20 层网络训练误差还要高——这不是过拟合，而是优化困难。ResNet 的解决方案是**残差连接（Residual Connection）**：

h=F(x)+x

也就是让每一层学"残差"F(x)，而不是直接学目标映射。输入 x 通过一条"捷径"直接加到输出上。这个简单的改动允许梯度在反向传播时直接流过捷径，缓解了深层网络中梯度消失的问题。ResNet-152 有 152 层，在 ImageNet 上首次超过人类水平，残差连接的思想至今仍是深度学习架构设计的核心概念之一。

---

### 六、从机器人视觉的角度理解 CNN

因为你之前深入学过 SLAM 和机器人视觉，这里做一个直接的连接，帮助你把知识串起来。

在 SLAM 里，你学过 ORB 特征点：先用 FAST 角点检测器找关键点，再用 BRIEF 描述子描述每个关键点周围的局部图像块。本质上，**BRIEF 描述子就是一个手工设计的"特征提取器"，它查看关键点周围的像素模式**。

CNN 的做法是：**不手工设计这个特征提取器，而是让它从数据中自动学习**。CNN 浅层学到的卷积核，往往和 Sobel 边缘检测算子、Gabor 滤波器等传统手工特征高度相似——但它是自动学出来的，而且会为具体任务做最优化的定制。

这就是为什么深度学习出现后，传统视觉里大量手工设计特征（SIFT、HOG、LBP）逐渐被 CNN 特征取代——在有足够数据的情况下，学出来的特征几乎总是比设计出来的特征更好。

### 七、这节课的思考题

**第一个问题**：ResNet 的残差连接 F(x)+x 要求 F(x) 和 x 的维度必须一致，才能相加。但如果我们做了池化（空间尺寸减半）或者增加了通道数，维度就不一致了。你觉得这种情况应该怎么处理？

**第二个问题**：CNN 非常擅长处理图像，但如果输入是一段文字——"今天天气真好"——你会怎么用神经网络来处理它？文字序列和图像的本质区别是什么？

第二个问题的答案会引出下一节的主题：**循环神经网络与 Transformer**——深度学习处理序列数据的核心架构，也是 ChatGPT 背后最关键的技术。

## 第四节：序列数据与 Transformer

先来回应上节课的思考题。

### 思考题的答案

**ResNet 维度不匹配时怎么办？**

这是一个很实际的工程问题。ResNet 的解决方案非常优雅：当维度不匹配时，在捷径上加一个 1×1 的卷积层来做维度对齐。1×1 卷积不改变空间尺寸，但可以改变通道数；如果空间尺寸也需要改变（比如经过了池化），就给这个 1×1 卷积设置 stride=2，让它同时完成降采样。这个设计被称为"投影捷径（projection shortcut）"，用最少的参数解决了维度对齐的问题。这种"用最简单的方式绕过障碍"的工程思维，在深度学习架构设计里非常普遍。

**文字和图像的本质区别是什么？**

图像的像素在空间上是**同时存在**的，没有顺序，你可以从任何方向扫描。但文字是**有顺序的序列**："我打了他"和"他打了我"用了完全相同的字，意思却截然相反——顺序携带了语义。而且序列的长度是可变的，一篇文章可以有 100 个字，也可以有 10000 个字，但 CNN 的输入尺寸是固定的。更重要的是，序列中存在**长程依赖**："那个昨天在图书馆里看书的女生**她**……"——"她"指代的是很多词之前出现的"女生"，要理解"她"，你必须记住很久之前的信息。

这三个特性——有序性、变长性、长程依赖——构成了序列数据的核心挑战。接下来我们先看深度学习最早是怎么应对这个挑战的，然后再看它最终是怎么被彻底解决的。

---

### 一、最朴素的想法：用记忆来处理序列

处理序列数据，你首先需要的是**记忆**。当你读到一句话的第 10 个字时，你仍然记得前 9 个字说了什么，因为这段上下文影响着你对第 10 个字的理解。

深度学习早期的解决方案叫**循环神经网络（RNN，Recurrent Neural Network）**，它的设计思路极其直白：在处理序列的每一步，除了接收当前的输入，还维护一个"隐状态向量" h，用来存储截至目前的"记忆"。每一步的更新公式是：

ht=tanh(Whht−1+Wxxt+b)

直白地说：新的记忆 ht 由旧的记忆 ht−1 和当前输入 xt 共同决定。处理完整个序列后，最终的隐状态 hT 理论上浓缩了整个序列的信息，可以用来做分类或者生成下一个词。

RNN 的设计很有吸引力，也确实在 2010 年代早中期取得了很多成果。但它有一个根本性的缺陷，和你在 SLAM 里遇到过的问题本质上相同——**梯度消失**。

想象你要通过反向传播，让网络学到"'她'指代100步之前的'女生'"这件事。梯度需要从第 100 步一步步反向传播回第 1 步，经过 100 次矩阵乘法。如果每次乘法让梯度缩小一点点（比如乘以 0.9），100 步后梯度变成 0.9100≈0.000026，几乎为零——网络完全学不到长程依赖。反之若每次放大，梯度会爆炸到无穷大。RNN 在处理超过二三十步的依赖时，往往力不从心。

LSTM（Long Short-Term Memory）通过引入精心设计的"门控机制"部分地缓解了这个问题，在 2010 年代几乎统治了所有的序列建模任务。但它只是缓解，不是根治，而且 RNN 类模型有另一个工程上的致命弱点：**必须按顺序处理**，第 t 步必须等第 t−1 步完成才能开始，无法并行，在现代 GPU 上效率极差。

这两个问题——长程依赖和无法并行——在 2017 年被一篇论文彻底解决了。

---

### 二、Transformer：用注意力代替记忆

2017 年，Google 的研究员发表了一篇题为《Attention Is All You Need》的论文，提出了 **Transformer** 架构。它的核心洞察是：**与其让信息在时间步之间逐步传递，不如让序列中的每个位置直接"关注"序列中所有其他位置**。

这个思想有一个很好的人类类比。你在读一篇文章时，并不是把文章从头到尾念一遍、用记忆串联起来，而是在理解某个词的时候，你的注意力会自动跳到最相关的上下文——读到"她"时，你的眼睛会回扫找到"女生"。Transformer 把这个机制直接编码进了数学操作里。

这个机制叫**自注意力（Self-Attention）**，是 Transformer 的核心。

---

### 三、自注意力机制：从直觉到数学

理解自注意力最好的方式是从一个具体的例子出发。假设我们有一个句子"猫 坐 在 垫子 上"，我们想计算"猫"这个词在整个句子语境下的表示。

自注意力的思路是：让"猫"去"询问"序列中所有其他词（包括自己）——"你和我有多相关？"——然后根据相关程度，把所有词的信息加权求和，得到"猫"在这个语境下的丰富表示。

数学上，每个词被映射成三个向量：**Query（查询）q、Key（键）k、Value（值）v**。这三个名字来自信息检索的类比：你有一个查询（Query），你在一堆键（Key）里找最匹配的，然后返回对应的值（Value）。

对于位置 i 的词，它对位置 j 的注意力权重是：

αij=softmax(qi⋅kjdk)αij=softmax(dkqi⋅kj)

这里 qi⋅kjqi⋅kj 是内积，衡量两个词的相关程度，dk 是缩放因子（防止内积值过大导致 softmax 饱和）。Softmax 把所有位置的分数归一化成概率分布，使得所有 αij 之和为 1。

最终，位置 i 的输出是所有位置的 Value 向量的加权和：

oi=∑jαijvjoi=j∑αijvj

这个过程同时在所有位置发生，写成矩阵形式非常简洁：

Attention(Q,K,V)=softmax(QK⊤dk)VAttention(Q,K,V)=softmax(dkQK⊤)V

关键点在于：**所有位置之间的注意力权重是同时计算的，没有时序依赖，天然支持并行**。这解决了 RNN 无法并行的问题。同时，每个位置都可以直接关注序列中任意距离的其他位置，梯度不需要经过长链传播——这解决了长程依赖的问题。

一个值得你停下来品味的对比：RNN 像一个人在传阅一份文件，每个人读完加上自己的注释再传给下一个人，信息在传递中逐渐失真；Transformer 像一次圆桌会议，每个人同时听到所有人在说什么，然后根据与自己的相关程度决定听谁的。

---

### 四、完整的 Transformer 块

自注意力之后，还有几个组件构成完整的 Transformer 块，每个都有明确的作用。

**多头注意力（Multi-Head Attention）** 是对自注意力的扩展。单头注意力只能关注一种"相关性"，但一个词和其他词之间可能有多种关系——比如"打"这个词，既和"主语"相关，又和"宾语"相关，还和"时态"相关。多头注意力把 Q、K、V 分别线性投影成 h 个子空间，在每个子空间里独立计算注意力，最后把所有头的输出拼接起来。这样，不同的头可以学到关注不同类型的关系。

**前馈网络（Feed-Forward Network）** 紧跟在注意力层之后，是一个两层的 MLP，对每个位置的表示独立做非线性变换。你可以把注意力层理解为"信息聚合"——把相关的上下文信息收集过来；把前馈层理解为"信息加工"——对聚合后的信息做进一步的特征变换。

**残差连接和层归一化（LayerNorm）** 出现在每个子层之后。残差连接此前已经熟悉了（来自 ResNet）；LayerNorm 是对每个位置的特征向量做归一化，稳定训练。这两个组件加在一起，使得 Transformer 可以堆叠很多层而不崩溃。

**位置编码（Positional Encoding）** 解决一个微妙但关键的问题：自注意力的计算是"置换不变"的，也就是说如果你把输入序列的词打乱顺序，注意力权重会重新排列，但最终结果在数学上等价——Transformer 天生不知道词的顺序。为了把顺序信息注入进去，我们在每个词的嵌入向量上加上一个**位置编码**向量，用正弦和余弦函数的不同频率编码不同位置。这样，第 1 个位置和第 100 个位置的词，即使词本身相同，它们的输入向量也不同。

---

### 五、从 Transformer 到 GPT：语言模型的本质

理解了 Transformer 的结构，再来理解 GPT 类大语言模型就非常自然了。

GPT 的训练任务极其简单：**给定前面所有的词，预测下一个词**。这叫**自回归语言模型（Autoregressive Language Model）**。训练数据就是互联网上的大量文本——书籍、网页、论文——不需要任何人工标注，文本本身就是自带标签的：每个词都是前面所有词的"正确答案"。

训练的损失函数正是你在信息论里学过的交叉熵：

L=−∑tlogP(词t∣词1,词2,…,词t−1)L=−t∑logP(词t∣词1,词2,…,词t−1)

这个目标函数有一个深刻的含义：要预测下一个词，模型必须理解语法（"动词后面通常接什么"）、事实（"巴黎是法国的……"后面接"首都"）、逻辑（"因为……所以……"的因果关系）。**准确预测下一个词，在某种意义上等价于理解语言**。这个洞察是 GPT 系列模型最核心的哲学。

GPT-3 有 1750 亿个参数，训练数据有 45TB 文本，在这个简单任务上训练到极致之后，涌现出了翻译、写作、编程、推理等能力——没有任何一个能力是被显式训练的。这种"从单一任务中涌现出多种能力"的现象，是当前 AI 研究里最令人着迷也最难解释的现象之一。

### 六、用代码感受 Transformer 的核心

我们不写完整的 GPT，而是把自注意力机制的核心用代码写出来，让你感受它的简洁：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class SelfAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        # d_model 是词向量的维度，num_heads 是注意力头数
        # 每个头处理 d_model // num_heads 维的子空间
        self.num_heads = num_heads
        self.d_head = d_model // num_heads

        # Q、K、V 的线性投影层：把输入映射到查询、键、值空间
        # 注意这里用单个大矩阵表示所有头，计算更高效
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)

        # 输出投影：把多头结果合并回 d_model 维
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x, mask=None):
        B, T, D = x.shape  # B=batch, T=序列长度, D=d_model

        # 计算 Q、K、V，然后 reshape 成多头形式
        # (B, T, D) -> (B, num_heads, T, d_head)
        Q = self.W_q(x).view(B, T, self.num_heads, self.d_head).transpose(1, 2)
        K = self.W_k(x).view(B, T, self.num_heads, self.d_head).transpose(1, 2)
        V = self.W_v(x).view(B, T, self.num_heads, self.d_head).transpose(1, 2)

        # 核心的注意力计算：Q 和 K 做矩阵乘法，得到注意力分数矩阵
        # (B, num_heads, T, d_head) @ (B, num_heads, d_head, T) -> (B, num_heads, T, T)
        # 这个 T×T 的矩阵是所有位置对之间的相关程度，这就是"所有位置同时互相关注"
        scores = Q @ K.transpose(-2, -1) / math.sqrt(self.d_head)

        if mask is not None:
            # 用于语言模型：当前位置不能看到未来的词
            # 把未来位置的分数设为负无穷，softmax 后权重为 0
            scores = scores.masked_fill(mask == 0, float('-inf'))

        # Softmax 归一化，得到注意力权重（可以理解为"分配注意力的比例"）
        attn_weights = F.softmax(scores, dim=-1)

        # 用注意力权重对 V 做加权求和
        # (B, num_heads, T, T) @ (B, num_heads, T, d_head) -> (B, num_heads, T, d_head)
        out = attn_weights @ V

        # 把多头结果合并，恢复成 (B, T, D) 的形状
        out = out.transpose(1, 2).contiguous().view(B, T, D)
        return self.W_o(out)

# 验证一下：一个序列长度为 10、维度为 64 的 batch
x = torch.randn(2, 10, 64)  # batch_size=2, seq_len=10, d_model=64
attn = SelfAttention(d_model=64, num_heads=8)
out = attn(x)
print(f"输入形状: {x.shape}")   # torch.Size([2, 10, 64])
print(f"输出形状: {out.shape}") # torch.Size([2, 10, 64])
# 形状不变，但每个位置的向量现在已经"看到"了整个序列的上下文
```

注意输入和输出的形状相同——自注意力不改变序列的形状，它只是让每个位置的向量变得更"有上下文意识"。这也是 Transformer 可以堆叠很多层的原因：每一层的输入输出接口完全一致。

### 七、知识串联：此前已经建立的完整图景

走到这里，值得停下来看看你现在掌握的知识是怎样连接成一个整体的。

从**信息论**的角度，交叉熵损失是 KL 散度的特例，训练神经网络等价于最大似然估计，VAE 的正则项就是 KL 散度，PPO 的策略约束就是 KL 散度——信息论是理解深度学习目标函数的统一语言。

从**优化**的角度，BA 和神经网络训练是同一件事——最小化一个目标函数，用梯度和迭代更新参数。区别只是规模和数据类型不同。

从**架构**的角度，MLP 是基础、CNN 是利用了图像的空间先验、Transformer 是利用了注意力机制处理任意序列——三者都是"堆叠可学习的参数化函数"，通过反向传播端到端优化。

从**机器人视觉**的角度，传统特征（ORB、SIFT）是手工设计的特征提取器，CNN 学出了更好的特征提取器，而现代语义 SLAM 正在把 Transformer 引入进来做场景语义理解。

### 八、这节课的思考题

**第一个问题**：自注意力的时间复杂度是 O(T2)，因为需要计算所有位置对之间的注意力分数（T×T×T 的矩阵）。当序列长度 T 很大时（比如一本书有几万个词），这会成为瓶颈。你能想到什么方向来缓解这个问题？

**第二个问题**：GPT 是"给定上文预测下一个词"，这种训练方式有一个限制——它只能看到当前词**左边**的上下文。但有时候你需要同时利用左边和右边的上下文（比如完形填空："猫坐在___上"，理解"上"有助于判断空格里填什么）。你觉得应该怎么改造训练目标来解决这个问题？

第二个问题的答案，正是 BERT 的核心创新。而这两个问题合在一起，指向下一节的主题：**预训练与微调——大语言模型是怎样被"造出来"并"用起来"的**，以及整个深度学习领域当前最前沿的范式。
