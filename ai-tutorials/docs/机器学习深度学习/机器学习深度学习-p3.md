## 第五节：预训练、微调与大语言模型的完整图景

先来回应上节课的两个思考题，因为它们直接引出了现代 AI 最核心的两个概念。

### 思考题的答案

**自注意力的 O(T2) 复杂度怎么缓解？**

这是当前学术界非常活跃的研究方向，已经产生了很多方案，但核心思路只有几类。第一类是"稀疏注意力"——不让每个位置关注所有其他位置，而是只关注局部窗口内的位置，或者通过某种规则选出最重要的少数位置来关注，把 T2 的计算压缩成 T⋅T⋅T 甚至 T⋅logTT⋅logT。第二类是"线性注意力"——通过改变注意力的计算顺序，把矩阵乘法的顺序从 (QK⊤)V(QK⊤)V 变成 Q(K⊤V)，后者的复杂度是线性的。第三类是工程层面的优化，比如 FlashAttention，不改变数学，但通过精心管理 GPU 显存的读写顺序，把实际运行速度提升数倍。现在大多数大模型都在用 FlashAttention。

**如何同时利用左右两边的上下文？**

GPT 的训练目标是从左到右预测下一个词，所以每个词只能看到左边。如果你想让每个词同时看到两边，最直接的思路是：**不预测下一个词，而是随机遮住一些词，让模型根据两边的上下文来预测被遮住的词**。这个任务叫"掩码语言模型（Masked Language Model，MLM）"，正是 BERT 的核心训练目标。它就像一个超大规模的完形填空练习——模型做了海量完形填空之后，对语言的双向理解能力就训练出来了。

---

### 一、一个根本性的问题：标注数据从哪里来？

在进入预训练和微调之前，我们需要先理解深度学习在 2017 年之前面临的一个根本性瓶颈。

监督学习需要标注数据——每张图片需要人工标注"这是猫"，每条医疗记录需要医生标注"这是某某疾病"，每段法律文本需要律师标注"这属于合同纠纷"。标注的成本极高，专业领域尤其如此。ImageNet 有 128 万张标注图像，是 22,000 名工人花了两年半时间标注的——这是一个例外，而不是常态。

在大多数实际任务里，标注数据只有几千条甚至几百条，但神经网络要学好，通常需要几十万条以上。这个矛盾产生了一个直接的问题：**能不能先用没有标注的大量数据，把模型"预先训练"到一个好的起点，然后再用少量标注数据做最终的任务适配？**

这个思路叫**预训练（Pre-training）+ 微调（Fine-tuning）**，是现代深度学习最重要的范式转变，没有之一。

---

### 二、预训练的核心思想：自监督学习

预训练之所以可行，依赖于一个关键的洞察：**大量无标注数据本身就隐含着丰富的监督信号，只要你设计合适的"自监督任务"**。

所谓自监督任务，是指标签从数据本身自动生成，不需要人工标注。GPT 的"预测下一个词"就是一个自监督任务——把一段文本的每个词都当作前面词的标签，一句话同时提供了几十个训练样本，完全不需要人工介入。BERT 的"预测被遮住的词"也是自监督任务——随机遮住 15% 的词，这些被遮住的词自然地成为了标签。

互联网上有多少文本？万亿量级的词。这意味着 GPT-4 这样的模型，它的预训练数据集里有数以亿计的自监督训练样本，数量之大是任何人工标注数据集都无法企及的。

你可以用一个类比来理解预训练的本质：一个刚从医学院毕业的实习医生（随机初始化的神经网络），直接上手诊断罕见病，因为缺乏经验，效果会很差。但如果他先广泛阅读了数百万份医学文献、病例报告、教科书（预训练），在这个过程中建立了对人体、疾病、症状的深刻理解，然后再专门针对某种罕见病的几百个病例进行专项训练（微调），他会比从零开始的实习医生强得多。**预训练提供了通用知识，微调提供了任务专门化。**

---

### 三、BERT：双向预训练的范式

BERT（Bidirectional Encoder Representations from Transformers，2018年，Google）是第一个真正引爆"预训练+微调"范式的模型，值得深入理解它的设计。

BERT 使用的是 Transformer 的**编码器（Encoder）**部分。注意这里有一个重要区分：Transformer 原始论文里有编码器和解码器两个部分——编码器用于理解输入（每个位置可以看到所有其他位置），解码器用于生成输出（每个位置只能看到左边，防止"作弊"看未来）。BERT 只用编码器，所以每个词天然能看到左右两边的上下文，这正是它"双向"的来源。

BERT 的预训练有两个任务同时进行。第一个是**掩码语言模型（MLM）**：随机遮住输入序列 15% 的词，用特殊符号 `[MASK]` 替代，让模型预测这些词是什么。第二个是**下一句预测（NSP）**：给模型两个句子，让它判断这两个句子在原文中是否是连续的，帮助模型学习句子之间的关系。

预训练完成后，你会得到一个"通才模型"——它对语言有深刻的理解，但没有针对任何特定任务优化。把它用到具体任务上，就需要**微调**。

---

### 四、微调：把通才变成专家

微调的过程在工程上非常简单，但效果往往令人惊讶。以情感分类任务为例（判断一段评论是正面还是负面），你只需要做以下几步：

拿到预训练好的 BERT 模型，在它的输出层上面加一个小的分类头（通常就是一层线性层），然后用你的几千条标注数据，以一个很小的学习率在整个模型上继续做梯度下降。因为学习率很小，预训练阶段学到的通用语言知识基本保留，只是在特定任务的方向上做了轻微调整。

```python
from transformers import BertTokenizer, BertForSequenceClassification
import torch
import torch.optim as optim

# Hugging Face 的 transformers 库封装了预训练模型，一行代码加载
# 这个模型已经在大量文本上预训练好了，包含了丰富的语言知识
tokenizer = BertTokenizer.from_pretrained('bert-base-chinese')
model = BertForSequenceClassification.from_pretrained(
    'bert-base-chinese',
    num_labels=2  # 正面/负面，二分类
)

# 假设我们有一些情感分类数据
texts  = ["这个产品真的很好用！", "质量太差了，非常失望。", "还不错，价格合理。"]
labels = [1, 0, 1]  # 1=正面, 0=负面

# tokenizer 负责把文字转换成 BERT 能理解的数字序列
# 包括：分词、添加特殊符号 [CLS] 和 [SEP]、截断/填充到统一长度
inputs = tokenizer(texts, return_tensors='pt', padding=True, truncation=True)
label_tensor = torch.tensor(labels)

# 微调：用一个很小的学习率（2e-5，比预训练时小很多）
# 防止把预训练学到的知识"覆盖"掉
optimizer = optim.AdamW(model.parameters(), lr=2e-5)

# 微调循环：和之前的训练代码结构完全一致
for epoch in range(3):
    model.train()
    outputs = model(**inputs, labels=label_tensor)

    # BertForSequenceClassification 直接返回 loss
    # 它在 BERT 的 [CLS] 向量上接了一个线性分类头，交叉熵损失
    loss = outputs.loss

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    print(f"Epoch {epoch+1}, Loss: {loss.item():.4f}")

# 推理：对新文本做预测
model.eval()
with torch.no_grad():
    test_input = tokenizer(["服务态度很好，下次还来！"], return_tensors='pt')
    logits = model(**test_input).logits
    prediction = logits.argmax(dim=1).item()
    print(f"预测结果: {'正面' if prediction == 1 else '负面'}")
```

这里最值得注意的是：BERT 有 1.1 亿个参数，而你的分类任务可能只有几千条训练数据。在传统的监督学习思维里，用几千条数据训练一个 1.1 亿参数的模型，过拟合会非常严重。但预训练改变了这个等式——大部分参数在预训练阶段已经找到了很好的值，微调只是在这个基础上做微小调整，所需数据量大幅减少。这种现象深刻地改变了机器学习的工程实践。

---

### 五、GPT 路线 vs BERT 路线：两种哲学

预训练语言模型在 2018-2020 年间形成了两条主要路线，理解它们的区别有助于你理解现代 AI 的技术选择。

BERT 路线（编码器）的设计目标是**理解**。双向上下文让它对语言的语义理解非常深刻，在各类"理解类"任务上表现出色：情感分析、命名实体识别、阅读理解、文本分类。但它的结构决定了它不擅长**生成**——你没法用 BERT 写一段文章，因为它的训练方式不是从左到右预测词，它不知道"给定上文，下一个词是什么"这件事该怎么做。

GPT 路线（解码器）的设计目标是**生成**。从左到右预测词的训练方式，使得它天然就会生成连贯的文本。你给它一个开头，它就能续写下去。GPT-2 发布时（2019年），OpenAI 甚至一度以"这个模型生成的文本太逼真、可能被用于制造虚假信息"为由，拒绝公开完整模型。

这两条路线在后来逐渐走向了一个趋势：**规模**。研究者发现，在同样的架构和训练目标下，把模型做大、把数据堆多，模型能力会出现近乎惊人的提升。GPT-3（2020年，1750亿参数）展示了一个此前从未见过的现象——它不需要微调，只需在输入里给几个例子，就能完成各种任务。这个现象叫**少样本学习（Few-Shot Learning）**，或者更极端的情形叫**零样本学习（Zero-Shot Learning）**。

---

### 六、涌现能力：规模带来的惊喜

GPT-3 的出现引出了深度学习里目前最令人困惑也最令人兴奋的现象：**涌现（Emergence）**。

涌现是指：某些能力在模型规模较小时完全不存在（准确率接近随机猜测），但当规模超过某个阈值后，突然出现并快速提升。这不是一个平滑的提升曲线，而是一个"突变"。

举几个具体例子。三位数的算术题，在 10 亿参数以下的模型里完全做不了，但在超过一定规模后突然变得可以。多步推理任务，小模型一步都走不通，大模型突然能完成完整的推理链。

这个现象在理论上还没有完全被解释清楚，但有一个直觉上合理的类比：语言里的很多技能是相互依赖的，就像一座桥需要每根桁架都就位才能承重。模型规模增大时，各种基础技能逐渐学好，当所有前置技能都到位时，更复杂的高阶技能突然"解锁"了。

这个发现彻底改变了 AI 研究的方向，催生了"Scaling Law（规模定律）"的研究——系统地研究模型能力和参数量、数据量、算力之间的数学关系。

---

### 七、指令微调与 RLHF：从语言模型到助手

GPT-3 虽然能力惊人，但它本质上是一个"续写机器"——你给它"巴黎是法国的"，它就续写"首都"；你给它"如何制造危险物品"，它可能也会直接续写下去，因为它的训练目标只是预测下一个词，没有任何关于"有帮助"或"安全"的概念。

把语言模型变成一个"有用的、诚实的、无害的"AI 助手，需要额外的训练步骤，这个过程叫 **RLHF（Reinforcement Learning from Human Feedback，基于人类反馈的强化学习）**。它分为三个阶段。

**第一阶段：监督微调（SFT）。** 人工标注员写出高质量的回答示例，用这些示例对预训练模型做监督微调，让模型学会"一个好助手应该怎么回答问题"的基本格式和风格。

**第二阶段：训练奖励模型。** 让语言模型对同一个问题生成多个不同质量的回答，人工标注员对这些回答进行排序（"A回答比B好，B比C好"）。用这些偏好数据训练一个**奖励模型（Reward Model）**，让它学会预测"人类会认为这个回答有多好"——本质上是把人类的主观判断转化成一个可以被自动计算的分数。

**第三阶段：强化学习优化。** 用上节课提到的 PPO 算法，以奖励模型的输出作为奖励信号，继续优化语言模型，让它倾向于生成奖励模型打分高（也就是人类认为好）的回答。在这个过程中，还需要用 KL 散度约束（你在信息论里学过！）来防止语言模型为了追求高奖励而走火入魔，生成一些奖励模型打高分但实际上一塌糊涂的回答。

这三个阶段就是 InstructGPT 和 ChatGPT 背后的核心训练流程。你会发现，整个流程串联了你学过的所有知识：交叉熵损失（第一阶段）、人类偏好建模（第二阶段）、强化学习 + KL 散度约束（第三阶段）。

---

### 八、整个旅程的全景回顾

走到这里，我们已经从最基础的线性回归，走到了 ChatGPT 背后的完整技术栈。让我把这个旅程串成一条完整的线。

第一节建立的核心认识是：机器学习 = 定义损失函数 + 用梯度下降优化参数，这是所有后续内容的基础语言。第三节的 CNN 展示了如何把数据的先验结构（图像的局部性和平移不变性）编码进网络架构，用更少的参数取得更好的效果。第四节的 Transformer 用注意力机制替代了顺序记忆，同时解决了长程依赖和并行化两个 RNN 的根本缺陷。这一节的预训练+微调则揭示了：无标注数据 + 自监督任务，可以训练出通用的知识基础，少量标注数据再做任务专门化，这个范式彻底改变了 AI 的工程实践和研究方向。

从信息论贯穿始终的角度看：交叉熵损失是 KL 散度；训练语言模型等价于最小化模型分布和真实语言分布之间的 KL 散度；RLHF 里用 KL 散度约束策略更新。信息论不是机器学习的"背景知识"，它就是机器学习的数学骨架。

---

### 九、这节课的思考题

**第一个问题**：RLHF 的奖励模型是在学习"人类认为什么样的回答好"，但人类的判断本身可能存在偏见（比如更喜欢听起来自信的回答，即使它是错的）。这会带来什么风险？你能想到什么方向来缓解这个问题？

**第二个问题**：我们整个系列讲的是"判别式"和"生成式"两类模型——CNN 判断"这张图是猫"，GPT 生成"下一个词"。但还有一类非常重要的生成模型，它的工作原理完全不同：它不是从左到右一步步生成，而是从一张纯噪声图像出发，一步步"去噪"，最终得到一张清晰的图像。你在日常生活中大概率已经用过它——Midjourney、Stable Diffusion 背后的技术。你对它的工作原理有什么猜测？

第二个问题引出的，正是我们下一节的主题：**扩散模型（Diffusion Models）**——当前最强大的图像生成技术，同时也是深度学习和概率论最优雅的结合之一。

## 第六节：扩散模型（Diffusion Models）

先来回应上节课的两个思考题。

### 思考题的答案

**RLHF 奖励模型的偏见风险？**

这个问题触及了当前 AI 对齐研究最核心的挑战之一，叫做**奖励欺骗（Reward Hacking）**。如果奖励模型本身有缺陷，被它训练出来的语言模型会学会"迎合奖励模型的偏好"而不是"真正对用户有帮助"。比如人类标注员可能偏好更长、更流畅、语气更自信的回答，即使内容是错的——模型就会学会用华丽的语言包装错误信息。这个现象叫**奉承性（Sycophancy）**，是当前大模型的已知缺陷之一。缓解方向包括：引入多个独立的奖励信号而不是单一奖励模型、用 AI 辅助人类评估（Constitutional AI，Anthropic 提出的方法）、以及主动检测和惩罚模型的奉承行为。这些都是活跃的研究前沿，没有完美的解决方案。

**纯噪声"去噪"成图像的原理猜测？**

该问题涉及一种“逆向过程”：先给图像加噪，再学习反向去噪。下面将这一思路展开为完整理论。

---

### 一、从一个物理类比出发

想象你把一滴墨水滴进一杯清水里。墨水分子在水中做随机的布朗运动，不断扩散，最终均匀地分布在整杯水里——这个过程叫**扩散（Diffusion）**。扩散是不可逆的：你永远没法把已经均匀分布的墨水分子自发地重新聚集回那一滴。

**扩散模型的核心问题是：如果我们有一个神经网络，能不能学会"逆转扩散过程"？**

对应到图像上：一张清晰的图像（墨水刚滴入）经过不断加噪，最终变成纯高斯噪声（墨水完全扩散）。扩散模型训练一个神经网络，学会从这个"完全扩散"的状态，一步步逆向推演，恢复出原始图像。生成新图像时，从一张随机噪声出发，让神经网络一步步去噪，最终"凭空"生成一张从未存在过的清晰图像。

这个思想之所以优雅，在于它把一个极其困难的问题（直接生成高维图像）分解成了许多个相对简单的子问题（每一步只需要去掉少量噪声）。

---

### 二、前向过程：把图像变成噪声

扩散模型分为两个过程。**前向过程（Forward Process）**是把数据逐步加噪，这个过程是固定的，不需要学习。**逆向过程（Reverse Process）**是学习如何去噪，这是神经网络需要学的部分。

前向过程非常简单。给定一张原始图像 x0，我们在 T 个时间步里逐步向它添加少量高斯噪声：

xt=1−βt⋅xt−1+βt⋅ϵ,ϵ∼N(0,I)xt=1−βt⋅xt−1+βt⋅ϵ,ϵ∼N(0,I)

这里 βt 是一个很小的数（比如 0.0001 到 0.02 之间），控制每一步加噪的强度。每一步都保留大部分原始信号（乘以 1−βt，接近 1），同时混入少量随机噪声。经过 T=1000 步之后，图像已经几乎完全变成了标准高斯噪声，原始图像的所有结构都消失了。

有一个数学上非常方便的性质：你不需要一步步迭代才能得到第 t 步的噪声图像，可以直接一步跳到任意时间步：

xt=αˉt⋅x0+1−αˉt⋅ϵxt=αˉt⋅x0+1−αˉt⋅ϵ

其中 αˉt=∏s=1t(1−βs)αˉt=∏s=1t(1−βs)，随 t 增大而递减，趋向于 0。这个封闭形式使得训练时可以高效地对任意时间步采样，而不必逐步模拟整个前向过程。

你可以把这个过程想象成：原始图像的"信号"在 αˉtαˉt 的系数下逐渐被压缩，噪声在 1−αˉt1−αˉt 的系数下逐渐占主导，两个系数的平方和始终等于 1，保持了数值稳定性。

---

### 三、逆向过程：学习去噪

如果前向过程是"加噪声"，逆向过程就是"去噪声"。数学上，逆向过程的每一步都是一个条件概率分布：

p(xt−1∣xt)

这个分布的意思是："给定当前噪声程度为 t 的图像，稍微少一点噪声（t−1 时刻）的图像应该长什么样？"

问题在于，直接计算这个分布是不可能的——它需要知道整个数据集的分布。但我们可以用神经网络来**近似**它。

关键的数学洞察来自贝叶斯定理。可以证明，如果 βt 足够小，逆向分布也近似是高斯分布，只是均值和方差未知。于是问题转化为：训练一个神经网络 ϵθϵθ，给定加噪图像 xt 和时间步 t，预测当前图像里混入的噪声 ϵϵ。

训练目标极其简洁：

L=Et,x0,ϵ[∥ϵ−ϵθ(xt,t)∥2]L=Et,x0,ϵ[∥ϵ−ϵθ(xt,t)∥2]

意思是：从真实数据 x0 出发，随机采样一个时间步 t，用一步法生成 xt（混入噪声 ϵϵ），然后让神经网络预测这个噪声，用均方误差衡量预测准确性。这是一个标准的回归问题，用普通的梯度下降就能训练。

这里有一个令人惊讶的简洁性：**我们把"学习生成图像"这个听起来极其复杂的任务，转化成了"预测图像里加了多少噪声"这个相对普通的回归任务**。这种把困难问题转化成简单问题的能力，是应用数学里最美的技艺之一。

---

### 四、生成过程：从噪声到图像

训练完成后，生成一张图像的过程如下。首先从标准高斯分布采样一张纯噪声 xT∼N(0,I)xT∼N(0,I)。然后从 t=T 到 t=1，在每一步用神经网络预测当前的噪声，从 xt 中减去这部分噪声，得到稍微干净一点的 xt−1，同时加入少量新的随机噪声保持随机性。重复 1000 步之后，得到的 x0 就是生成的图像。

完整的一步去噪公式是：

xt−1=11−βt(xt−βt1−αˉtϵθ(xt,t))+βt⋅zxt−1=1−βt1(xt−1−αˉtβtϵθ(xt,t))+βt⋅z

其中 z∼N(0,I)z∼N(0,I) 是每一步新加入的少量随机噪声（当 t=1 时不加）。这个公式看起来复杂，但本质上就是"减去预测的噪声，再加上少量随机扰动"，随机扰动保证了每次从同一个起点出发都能生成不同的图像。

一个值得停下来思考的问题：为什么要在去噪的同时还往里加噪声？这是因为我们在做的不是确定性的图像恢复，而是从一个概率分布中采样。每一步加入的随机噪声，使得最终的生成结果覆盖了真实数据分布的多样性，而不是总是收敛到同一张"平均图像"。

---

### 五、U-Net：扩散模型的神经网络主干

扩散模型的神经网络 ϵθϵθ 需要满足一个特殊的要求：**输入和输出的形状完全相同**（都是图像尺寸），因为我们要预测和输入图像等尺寸的噪声图。

最适合这个任务的架构叫 **U-Net**，最初是 2015 年为医学图像分割设计的，但在扩散模型里大放异彩。U-Net 的结构像字母 U，分为下采样路径（编码器）和上采样路径（解码器）两部分，并且在对应层之间有**跳跃连接（skip connections）**：

下采样路径用卷积+池化把图像尺寸逐步缩小，同时增加通道数，逐层提取越来越抽象的特征。这个过程和普通 CNN 相同。上采样路径用转置卷积把特征图尺寸逐步放大，恢复空间分辨率，逐层重建细节。跳跃连接把下采样路径中对应尺寸的特征图直接拼接到上采样路径，使得解码器在重建细节时能直接访问编码器提取的局部特征，不会因为多次下采样而丢失细节。

除了图像本身，U-Net 还接受时间步 t 作为输入，通常用类似位置编码的方式把 t 编码成一个向量，然后加到每一层的特征图上。这让网络知道"现在是去噪过程的哪个阶段"——第 800 步（噪声很多，需要恢复大的结构）和第 50 步（噪声很少，需要恢复精细细节）需要做的事完全不同，网络的行为也应该不同。

---

### 六、条件生成：文字控制图像

到目前为止描述的扩散模型是**无条件生成**——随机生成图像，但无法控制生成什么内容。Stable Diffusion 和 Midjourney 的核心技术是**条件扩散模型**，允许用文字描述来引导生成过程。

实现方式并不复杂，核心是把文字信息注入到 U-Net 里。具体步骤是：先用一个文本编码器（通常是 CLIP 模型里的 Transformer，或者直接用一个语言模型）把文字描述编码成一个向量序列，然后在 U-Net 的每一层，用**交叉注意力（Cross-Attention）**把图像特征和文字特征关联起来。

交叉注意力和自注意力的区别是：自注意力让图像的每个位置关注图像里所有其他位置；交叉注意力让图像的每个位置关注**文字序列里的所有词**。于是，图像里对应"猫"的区域会在文字中重点关注"cat"这个词，对应"草地"的区域会重点关注"meadow"。文字和图像就通过注意力机制被深度绑定在一起。

训练时，以文字描述作为条件，在去噪任务中同时提供文字信息，让网络学会"在这段文字的引导下，图像应该长什么样"。生成时，提供一段新的文字描述，网络就会在去噪过程中不断朝着符合这段文字的方向引导，最终生成匹配的图像。

这里有一个叫**分类器引导（Classifier-Free Guidance）**的技巧，大幅提升了文字条件的控制力。训练时随机以一定概率把文字条件置空（无条件），让模型同时学会有条件和无条件两种生成方式。推理时，把有条件的预测和无条件的预测做线性外插：

ϵ~=ϵθ(xt,∅)+w⋅(ϵθ(xt,c)−ϵθ(xt,∅))ϵ~=ϵθ(xt,∅)+w⋅(ϵθ(xt,c)−ϵθ(xt,∅))

其中 c 是文字条件，w 是引导强度（通常取 7.5 左右）。w>1 时，生成方向被"放大"到比有条件预测更加符合文字描述的方向，代价是多样性略有下降。这就是 Stable Diffusion 里 CFG Scale 参数的含义。

### 七、用代码感受扩散模型的核心

我们不从头实现一个完整的扩散模型（那需要大量 GPU 和数据），但可以把前向过程和去噪步骤的核心逻辑写出来，感受它的数学优雅：

```python
import torch
import numpy as np
import matplotlib.pyplot as plt

# ---- 前向过程：把图像逐步变成噪声 ----

T = 1000  # 总时间步数
# beta 调度：从小到大线性增加，早期加噪少，后期加噪多
betas = torch.linspace(1e-4, 0.02, T)

# 预计算 alpha 和它的累积乘积，方便直接跳到任意时间步
alphas = 1.0 - betas
alpha_bars = torch.cumprod(alphas, dim=0)  # alpha_bar[t] = 连乘 alpha[0..t]

def add_noise(x0, t):
    """
    前向过程的一步法：直接从 x0 跳到时间步 t
    不需要逐步迭代，这是扩散模型训练高效的关键
    """
    alpha_bar_t = alpha_bars[t].view(-1, 1, 1, 1)  # 适配图像维度

    # 从标准正态分布采样噪声，形状和输入图像相同
    epsilon = torch.randn_like(x0)

    # 混合原始图像和噪声：信号系数 + 噪声系数，平方和为 1
    x_t = torch.sqrt(alpha_bar_t) * x0 + torch.sqrt(1 - alpha_bar_t) * epsilon

    return x_t, epsilon  # 同时返回添加的噪声，训练时作为标签

def reverse_step(x_t, t, predicted_noise):
    """
    逆向过程的一步：从 x_t 去噪到 x_{t-1}
    这是推理时神经网络预测噪声后执行的操作
    """
    beta_t      = betas[t]
    alpha_t     = alphas[t]
    alpha_bar_t = alpha_bars[t]

    # 计算均值：用预测的噪声从 x_t 中减去噪声成分
    mean = (1 / torch.sqrt(alpha_t)) * (
        x_t - (beta_t / torch.sqrt(1 - alpha_bar_t)) * predicted_noise
    )

    if t == 0:
        return mean  # 最后一步不加噪声，直接返回均值

    # 中间步骤：加入少量随机噪声，保持生成多样性
    z = torch.randn_like(x_t)
    return mean + torch.sqrt(beta_t) * z

# ---- 可视化前向过程 ----
# 模拟一张 64×64 的"图像"（实际上是随机生成的，用于演示）
x0 = torch.randn(1, 1, 64, 64)  # batch=1, channel=1, H=64, W=64

# 在不同时间步观察图像的噪声程度
timesteps_to_show = [0, 100, 300, 500, 700, 999]

print("不同时间步的信噪比（signal: noise ratio）：")
for t in timesteps_to_show:
    signal_coef = torch.sqrt(alpha_bars[t]).item()
    noise_coef  = torch.sqrt(1 - alpha_bars[t]).item()
    print(f"  t={t:4d}: 信号系数={signal_coef:.4f}, 噪声系数={noise_coef:.4f}")

# 你会看到类似这样的输出：
# t=   0: 信号系数=0.9999, 噪声系数=0.0100   ← 几乎是原图
# t= 100: 信号系数=0.9516, 噪声系数=0.3071   ← 轻微噪声
# t= 500: 信号系数=0.5227, 噪声系数=0.8524   ← 噪声占主导
# t= 999: 信号系数=0.0087, 噪声系数=0.9999   ← 几乎是纯噪声
```

运行这段代码，你会非常直观地看到：随着 t 增大，信号系数从接近 1 降到接近 0，噪声系数从接近 0 升到接近 1——图像就是沿着这条轨迹"融化"进噪声的，逆向过程就是沿这条轨迹"结晶"回来。

用 Hugging Face 的 diffusers 库，两行代码就能体验完整的扩散模型生成：

```python
from diffusers import StableDiffusionPipeline
import torch

# 加载预训练的 Stable Diffusion 模型
# 它的权重包含了在数十亿图文对上训练得到的知识
pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    torch_dtype=torch.float16  # 用半精度浮点数，节省显存
).to("cuda")

# 文字引导的图像生成：1000 步去噪，从纯噪声到清晰图像
image = pipe(
    prompt="a photograph of an astronaut riding a horse on Mars, cinematic lighting",
    num_inference_steps=50,  # 实际只用 50 步，DDIM 加速采样
    guidance_scale=7.5       # CFG scale，控制文字引导强度
).images[0]

image.save("generated.png")
```

### 八、扩散模型与其他生成模型的关系

你可能听说过几类生成模型的名字，了解它们之间的关系能帮助你建立更完整的图景。

**变分自编码器（VAE）**是你在信息论里学过的，它用编码器把图像压缩成隐向量，用解码器重建图像，训练目标包含重建误差和 KL 散度正则项。VAE 生成速度快（一步解码），但生成质量相对有限，图像往往偏模糊。值得一提的是，Stable Diffusion 实际上在 VAE 的**隐空间**里做扩散，而不是在像素空间里——先用 VAE 把图像压缩到低维隐空间（压缩 8 倍），在隐空间里做扩散模型，最后用 VAE 解码器还原到像素。这大幅降低了计算量，这就是"Latent Diffusion Model"的含义。

**生成对抗网络（GAN）**是 2014 年提出的另一类生成模型，思路完全不同：同时训练一个生成器和一个判别器，生成器努力生成逼真的图像，判别器努力分辨真假，两者博弈使得生成器越来越强。GAN 生成速度极快（一步前向传播），在高分辨率图像生成上曾长期领先，但训练极不稳定，且生成多样性有限（容易出现"模式坍塌"）。2022 年之后，扩散模型在质量和多样性上全面超越了 GAN。

**扩散模型**的优势是生成质量高、训练稳定、覆盖数据分布的多样性好，劣势是推理慢（需要几十到几百步去噪）。DDIM（去噪扩散隐式模型）、一致性模型（Consistency Models）等技术正在把步数压缩到个位数，逐步解决这个问题。

### 九、这节课的思考题

**第一个问题**：扩散模型的训练目标是让神经网络预测加入的噪声 ϵϵ。但另一种等价的表述是：让网络直接预测去噪后的原始图像 x0。这两种表述在数学上是等价的（因为已知 xt 和 ϵϵ，就能算出 x0，反之亦然）。你觉得预测噪声 ϵϵ 和预测原始图像 x0，在训练难度上有什么直觉上的区别？为什么原始论文选择了预测噪声？

**第二个问题**：我们整个课程学了监督学习（CNN 做分类）、无监督/自监督学习（BERT、GPT 预训练）、强化学习（RLHF），以及生成模型（扩散模型）。回顾一下，你觉得这四种范式各自最大的局限性是什么？有没有一种统一的方式把它们结合起来？

这两个问题没有标准答案，它们指向的是当前研究的开放前沿。第二个问题尤其重要，因为它的答案正是整个 AI 领域正在探索的方向——**多模态模型、世界模型、具身智能**。如果你想，我们可以在下一节把这些前沿方向串联成一幅完整的地图，作为这个系列的收尾。

## 第七节：前沿方向与完整地图

先来回应上节课的两个思考题，它们的答案都触及了深度学习里很深的直觉。

### 思考题的答案

**预测噪声 vs 预测原始图像，哪个更容易？**

这是一个非常微妙的问题。在时间步 t 很大（噪声极多）时，预测 x0 极其困难——图像几乎被噪声完全淹没，网络要从一堆随机噪声里猜出原始图像长什么样，这相当于凭空想象。但预测噪声 ϵϵ 就简单得多：噪声本身就是标准高斯分布，网络只需要预测一个统计性质固定的随机量。在 t 很小（噪声极少）时，情况反转——原始图像已经依稀可见，预测 x0 变得容易，但此时噪声量极少，预测噪声反而变成了放大镜下的精细工作。选择预测噪声的深层原因是训练信号更均匀稳定——在所有时间步上，网络都在做"预测标准高斯噪声"这同一个任务，损失函数的量级一致，优化过程更稳定。这再次体现了深度学习里一个反复出现的设计哲学：**把复杂问题变换成在所有情况下都容易优化的形式**。

**四种范式的最大局限性？**

监督学习的局限是标注数据瓶颈，以及泛化性差——在训练分布之外很容易失败。无监督/自监督学习的局限是目标函数和真正"理解"之间的鸿沟——预测下一个词不等于真正理解世界。强化学习的局限是样本效率极低，以及奖励函数难以设计——现实世界里大多数有价值的行为很难被量化成一个数字。生成模型的局限是它只会"模仿分布"，不具备真正的因果推理能力——它能生成一张太阳从西边升起的图像，却不理解这违反了物理规律。把这四种范式统一起来的尝试，正是接下来我们要讨论的核心主题。

### 二、多模态模型：打通感知的边界

人类理解世界是多模态的——你同时用眼睛、耳朵、触觉感知，并且把这些信息自然地整合在一起。你看到一张图，听到描述，就能理解它们说的是同一件事。早期的深度学习是单模态的：图像模型只处理图像，语言模型只处理文字，两者是完全分离的系统。

**CLIP（2021年，OpenAI）**是打通图像和文字的第一个里程碑。它的训练数据是从互联网上爬取的 4 亿对图文对（一张图和描述它的文字），训练目标极其简洁：让配对的图文表示在向量空间里尽量靠近，让不配对的尽量远离。这个目标叫**对比学习（Contrastive Learning）**。

对比学习的损失函数本质上也是交叉熵，只不过"类别"变成了"哪个文字描述和这张图配对"：

L=−1N∑i=1Nlogexp(sim(vi,ti)/τ)∑j=1Nexp(sim(vi,tj)/τ)L=−N1i=1∑Nlog∑j=1Nexp(sim(vi,tj)/τ)exp(sim(vi,ti)/τ)

其中 vi 是图像嵌入，ti 是对应文字嵌入，τ 是温度参数。同一个 batch 里的其他文字描述都是"负样本"，分母是所有可能配对的分数之和。

CLIP 训练完成后，图像和文字被投影到同一个向量空间里，语义相似的图文对向量相近。这使得 CLIP 获得了一个惊人的能力：**零样本图像分类**。你不需要用任何标注图像重新训练，直接把类别名写成文字（"a photo of a cat"），计算图像向量和所有类别文字向量的相似度，选最近的就是分类结果。在 ImageNet 上，这样的零样本 CLIP 达到了接近有监督训练的 ResNet 的准确率，而完全没有用过 ImageNet 的一张图。

CLIP 的图像编码器后来直接成为了 Stable Diffusion 的文本编码器的基础，也是 GPT-4V 等视觉语言模型的核心组件之一。

**GPT-4V 和 Gemini** 代表了多模态的下一步——不只是图文对齐，而是让语言模型直接"看懂"图像，然后用语言回答关于图像的问题。实现方式是把图像通过视觉编码器（通常是 CLIP 的图像编码器）转化成一组向量，把这些向量作为"视觉 token"插入到语言模型的输入序列里，和文字 token 一起被 Transformer 处理。语言模型见过了足够多的图文对之后，就学会了把视觉信息和语言知识联系起来——"这张图里有一只猫坐在垫子上"，"这个数学公式写错了第二行"，"这张 X 光片显示有肺结节"。

### 三、世界模型：从感知到理解

多模态模型解决的是"感知"问题——看懂、听懂。但真正的智能还需要**理解世界的运作方式**：物体会掉落，火会烫伤，推倒多米诺骨牌会触发连锁反应。这种理解叫**世界模型（World Model）**。

世界模型的概念来自认知科学——人类在大脑里维护着一个关于物理世界的内部模型，用来预测行动的后果、规划未来的行为。AI 领域里，世界模型是指：给定当前的状态和一个行动，模型能预测下一个状态。

st+1=fθ(st,at)

这听起来简单，但要真正做好极其困难。预测"推倒这块积木之后会发生什么"，需要理解重力、摩擦力、物体的形状和质量——这些都需要从观测数据中隐式地学习，没有任何显式的物理引擎。

当前最接近这个目标的尝试来自几个方向。**DreamerV3** 是强化学习领域的代表，它让 agent 在自己学到的世界模型里做"想象中的试验"，而不是在真实环境里消耗大量样本，大幅提高了样本效率。**Sora（2024年，OpenAI）**是视频生成领域的突破，它能生成长达一分钟的高质量视频，且物理一致性惊人——物体遮挡、阴影、流体运动都符合物理规律，这暗示了它在某种程度上学到了视觉世界的物理先验。OpenAI 明确把 Sora 定位为"世界模拟器"，而不只是"视频生成器"。

世界模型和你在 SLAM 里学的内容有一个深刻的联系：SLAM 的本质也是在构建一个关于物理世界的内部模型（地图），并用观测数据不断更新它。只不过 SLAM 的世界模型是几何的（位置和形状），而深度学习的世界模型是语义的、物理的，更加丰富。这两个方向正在融合，产生了**语义 SLAM** 和**神经辐射场（NeRF）**等交叉领域。

### 四、具身智能：让模型长出手脚

世界模型解决的是"理解"，但要让 AI 真正在物理世界里行动，还需要把感知、理解、决策、执行串联起来——这个完整的闭环叫**具身智能（Embodied Intelligence）**。

具身智能的核心挑战是"感知-动作循环"：机器人用摄像头、激光雷达等传感器感知环境，经过神经网络处理，输出电机控制指令，执行动作，再感知新的状态，形成闭环。这个循环在现实世界里每秒需要运行几十次，对实时性要求极高。

2023-2024 年最令人兴奋的进展是把大语言模型（LLM）和机器人控制结合起来。**RT-2（Google，2023年）**展示了一个令人惊讶的结果：用在图文数据上预训练的视觉语言模型，直接微调来输出机器人的动作指令（比如"向左移动 5 厘米，闭合夹爪"），机器人在没有见过的新场景和新指令上表现出了强大的泛化能力。这说明语言模型里蕴含的世界知识，可以直接迁移到机器人控制——预训练的通用知识再一次证明了它的价值。

**π₀（Physical Intelligence，2024年）**更进一步，用扩散模型来生成机器人的动作序列——不是预测单个离散动作，而是生成一段连续平滑的动作轨迹，就像扩散模型生成图像一样。这个思路把你在上节学的扩散模型和机器人控制直接连接起来，是当前机器人学习里最前沿的方向之一。

对你来说，这意味着什么？你在 SLAM 那条路上打下的基础——相机模型、点云处理、位姿估计——和这里的具身智能是天然的组合。SLAM 提供感知和定位，深度学习提供语义理解和策略决策，两者合在一起才能构成一个完整的自主智能体。

### 五、AI 对齐与可解释性：我们理解自己造出来的东西吗？

前面所有的技术进步都指向一个越来越紧迫的问题：**我们造出了越来越强大的系统，但我们越来越不理解它们在做什么、为什么这样做。**

**可解释性（Interpretability）**研究的是：神经网络内部究竟在计算什么？ Anthropic 的**机械可解释性（Mechanistic Interpretability）**是这个方向最严格的尝试——不是在模型外部观察行为，而是深入模型内部，逐个分析神经元和注意力头在做什么。

2023 年的一个具体研究结果：在 GPT-2 里，研究者发现了专门负责"输出位置上的单词对应于前文出现的名字"的注意力头，以及专门追踪"当前在哪个句子位置"的神经元群。这些发现暗示，大型语言模型内部有类似"模块化"的结构，而不是一团无法解析的参数。

但可解释性研究面临一个根本困难：GPT-4 有超过一万亿个参数，对它的完整理解可能和"理解人脑"一样困难。当前的可解释性研究更多是在小模型上取得原理性突破，希望这些方法将来能扩展到大模型上。

**对齐（Alignment）**的问题更加根本：如何确保越来越强大的 AI 系统的目标和人类的价值观一致？你在上节学的 RLHF 是当前最主流的对齐技术，但它有已知的局限——奖励欺骗、奉承性、以及人类偏好本身的不一致。

更深层的问题是：随着模型能力越来越强，它们开始具备"工具性目标"——为了完成任何被分配的目标，足够聪明的系统可能会自发地学会"防止自己被关闭"、"获取更多资源"，因为这些有助于完成几乎任何目标。这不是科幻，而是在优化理论层面可以严格推导出的行为倾向。如何在能力不断增强的同时保持对 AI 系统的控制，是当前 AI 安全研究的核心问题。

### 七、整个系列的最后一个思考题

我想用一个开放性的问题结束这个系列，这个问题没有正确答案，但思考它的过程本身有价值。

我们这七节课学的所有技术——CNN、Transformer、扩散模型、大语言模型——本质上都是在做同一件事：**用大量数据拟合一个参数化函数，使得它在某个目标上的表现尽量好**。这个过程是否等价于"理解"？一个能完美预测所有句子中下一个词的语言模型，它"理解语言"了吗？一个能完美预测所有物理场景中下一帧画面的世界模型，它"理解物理"了吗？

这个问题在哲学上叫"中文房间"论证（John Searle，1980年）：一个人在房间里，有一本巨大的规则手册，可以对任何中文输入查表给出正确的中文输出，但他完全不懂中文——他在"理解中文"吗？这个类比是否真的适用于神经网络，还是神经网络的学习方式和查表有本质区别，是当前 AI 哲学里争论最激烈的问题之一。

你现在有了足够的技术背景来参与这个讨论，而不只是旁观。这，是学习一门技术最深层的意义。
