## 无监督学习 · 第一节：聚类

### 一、无监督学习在做什么

监督学习的数据长这样：

{(x1,y1),(x2,y2),…,(xN,yN)}

每个样本都有一个标签 y，告诉你"正确答案是什么"。无监督学习的数据长这样：

{x1,x2,…,xN}

没有标签，只有数据本身。任务是从数据中发现**结构**——哪些数据点彼此相似、数据分布在什么样的低维流形上、数据是由哪几种"原型"混合生成的。

一个直觉上的类比：监督学习像有老师的课堂，每道题都有标准答案；无监督学习像独自观察世界，没有人告诉你对错，但你仍然能发现规律——比如你没有人教，也能自然地把"苹果、橙子、香蕉"归为一类，把"狗、猫、鸟"归为另一类。

无监督学习最核心的两个任务是**聚类**（把数据分组）和**降维**（把高维数据压缩到低维）。这节先讲聚类。

---

### 二、K-Means：最经典的聚类算法

**K-Means** 的目标是把 N 个数据点分成 K 个簇，使得每个数据点都尽量靠近自己所在簇的中心（质心）。

形式化地，我们要找到 K 个质心 {μ1,…,μK} 和每个点的簇分配 {c1,…,cN}，最小化**簇内方差**：

L=∑i=1N∥xi−μci∥2L=i=1∑N∥xi−μci∥2

这个优化问题直接求解是 NP-hard 的（需要穷举所有可能的分配），但有一个简单的迭代算法能找到局部最优解：

**第一步（分配）**：固定质心，把每个点分配给最近的质心。

ci=argmink∥xi−μk∥2ci=argkmin∥xi−μk∥2

**第二步（更新）**：固定分配，把每个质心更新为它所在簇所有点的均值。

μk=1∣Ck∣∑i:ci=kxiμk=∣Ck∣1i:ci=k∑xi

交替执行这两步，直到分配不再变化。每一步都严格减小目标函数 L，所以一定收敛，但收敛到的是局部最优，初始质心的选择会影响结果。

这里有一个和你之前学过内容的直接联系：K-Means 的"分配步骤"和 SLAM 里的**数据关联**问题本质上相同——给定一组路标点（质心），把新的观测（数据点）分配给最近的路标。两者都是最近邻匹配问题。

用代码实现一遍，感受它的简洁：

```python
import numpy as np
import matplotlib.pyplot as plt

def kmeans(X, K, max_iter=100):
    N = X.shape[0]

    # 随机初始化：从数据点中随机选 K 个作为初始质心
    idx = np.random.choice(N, K, replace=False)
    centroids = X[idx].copy()

    for iteration in range(max_iter):
        # 分配步骤：计算每个点到每个质心的距离，分配到最近的
        # X: (N, D), centroids: (K, D)
        # distances: (N, K)
        distances = np.linalg.norm(
            X[:, np.newaxis, :] - centroids[np.newaxis, :, :], axis=2
        )
        assignments = distances.argmin(axis=1)  # (N,)

        # 更新步骤：重新计算每个簇的质心
        new_centroids = np.array([
            X[assignments == k].mean(axis=0) for k in range(K)
        ])

        # 收敛判断：质心不再移动则停止
        if np.allclose(centroids, new_centroids):
            print(f"收敛于第 {iteration+1} 次迭代")
            break
        centroids = new_centroids

    return assignments, centroids

# 生成测试数据：三个高斯分布的混合
np.random.seed(42)
X = np.vstack([
    np.random.randn(100, 2) + [0, 0],
    np.random.randn(100, 2) + [5, 5],
    np.random.randn(100, 2) + [0, 5],
])

assignments, centroids = kmeans(X, K=3)

# 可视化
colors = ['red', 'blue', 'green']
for k in range(3):
    pts = X[assignments == k]
    plt.scatter(pts[:, 0], pts[:, 1], c=colors[k], alpha=0.5)
    plt.scatter(*centroids[k], c=colors[k], marker='*', s=300, edgecolors='black')

plt.title("K-Means 聚类结果")
plt.show()
```

### 三、K-Means 的局限与 DBSCAN

K-Means 有三个明显的局限，理解它们能帮助你知道什么时候该用别的算法。

**局限一：必须预先指定 K。** 现实中你往往不知道数据有几个簇。K-Means 要求你提前告诉它 K，猜错了结果就会很奇怪。常用的启发式方法叫**肘部法则（Elbow Method）**：对K=1,2,3,…分别跑 K-Means，画出损失 L 随 K 的变化曲线，曲线的"肘部"（下降速度突然变慢的地方）往往就是合适的 K。

**局限二：只能发现球形簇。** K-Means 用欧氏距离来衡量相似性，隐含地假设每个簇是球形的。如果数据的真实结构是月牙形、环形等非凸形状，K-Means 会给出错误的分组。

**局限三：对噪声点（离群点）敏感。** 一个极端的离群点会把质心拉偏，影响整个簇的形状。

**DBSCAN（Density-Based Spatial Clustering of Applications with Noise）**解决了后两个问题。它的思路完全不同：不是"找质心"，而是"找密度连通区域"。

DBSCAN 的核心概念是：如果一个点在半径 ϵϵ 内有至少 minPts 个邻居，它就是**核心点**；核心点和它邻域内的点属于同一个簇；密度不够的点是**噪声点**，不属于任何簇。

DBSCAN 的优点是：不需要预先指定簇的数量，可以发现任意形状的簇，自动把离群点标记为噪声。代价是对参数 ϵϵ 和 minPts 比较敏感。

```python
from sklearn.cluster import DBSCAN
from sklearn.datasets import make_moons

# 生成月牙形数据——K-Means 完全无法处理，DBSCAN 轻松应对
X, _ = make_moons(n_samples=300, noise=0.05)

db = DBSCAN(eps=0.2, min_samples=5)
labels = db.fit_predict(X)

# labels == -1 表示噪声点
plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='coolwarm')
plt.title("DBSCAN 聚类结果（月牙形数据）")
plt.show()
```

### 四、高斯混合模型（GMM）：K-Means 的概率版本

K-Means 给每个点做**硬分配**——每个点只属于一个簇，非此即彼。但现实中的数据往往是模糊的：一个点可能有 70% 的概率属于簇 A，30% 的概率属于簇 B。

**高斯混合模型（Gaussian Mixture Model，GMM）**是 K-Means 的概率推广，它假设数据是由 K 个高斯分布"混合"生成的：

p(x)=∑k=1Kπk⋅N(x∣μk,Σk)p(x)=k=1∑Kπk⋅N(x∣μk,Σk)

其中 πk 是第 k 个高斯分量的权重（∑kπk=1），μk 和 Σk 是它的均值和协方差矩阵。

GMM 的学习算法叫 **EM 算法（Expectation-Maximization）**，和 K-Means 一样是两步迭代，但每步都是概率化的：

**E 步（期望）**：固定参数，计算每个点属于每个簇的**软概率**（后验概率）。

**M 步（最大化）**：固定软概率，用加权均值更新每个高斯分量的参数。

GMM 比 K-Means 更灵活——每个簇不只是一个中心点，而是有形状（协方差矩阵描述簇的拉伸方向和程度）；每个点的归属是概率性的，而不是非此即彼。你在信息论里学过的 KL 散度，在 GMM 的理论分析里也会出现——EM 算法的每一步都可以被解释为在最小化某种 KL 散度。

### 五、聚类的评估：没有标签怎么判断好坏？

监督学习可以用准确率、F1 等指标评估，因为有正确答案。无监督学习没有标签，如何评估聚类质量？

**轮廓系数（Silhouette Score）** 是最常用的无监督评估指标。对每个点 i，计算：

- ai：i 到同簇其他点的平均距离（簇内紧密度）
- bi：i 到最近邻簇所有点的平均距离（簇间分离度）

轮廓系数定义为：

si=bi−aimax(ai,bi)si=max(ai,bi)bi−ai

si 接近 1 表示这个点被很好地聚类（离自己的簇很近，离其他簇很远），接近 -1 表示聚类错误，接近 0 表示在两个簇的边界上。整个数据集的平均轮廓系数用来比较不同 K 值或不同算法的优劣。

### 六、这节课的思考题

**第一个问题**：K-Means 的初始质心是随机选的，不同的初始化可能收敛到不同的局部最优。有一个改进版叫 **K-Means++**，它在初始化时不是完全随机选质心，而是让质心之间尽量"分散"。你能想到具体的做法吗？（提示：第一个质心随机选，之后每个新质心应该优先选在哪里？）

**第二个问题**：GMM 假设每个簇是高斯分布，但如果真实数据里某个簇的形状根本不是高斯的（比如是一条曲线，或者是一个环），GMM 也会失败。你觉得有没有一种更灵活的方式来建模"簇的形状"，让聚类算法能处理任意形状？（提示：你在深度学习里学过的某个模型，它的隐空间可能有用。）

下一节我们讲**降维**——PCA 和它的深度学习版本，这是无监督学习的另一个核心任务，和聚类一起构成了经典无监督学习的完整图景。

## 第二节：降维

先来回应上节课的两个思考题。

### 思考题的答案

**K-Means++ 的初始化策略？**

K-Means++ 的做法是：第一个质心从数据中随机均匀选取；之后每选一个新质心，**每个数据点被选中的概率正比于它到已选质心的最近距离的平方**——离现有质心越远的点，越有可能被选为下一个质心。这样初始质心会自然地分散在数据空间里，覆盖不同区域，大幅降低收敛到较差局部最优的概率。理论上，K-Means++ 的最终损失在期望上不超过最优解的 $O(\log K)$ 倍，而随机初始化没有这种保证。scikit-learn 的 `KMeans` 默认使用 K-Means++ 初始化。

**任意形状的簇如何建模？**

这个问题的答案指向了深度学习和无监督学习的交叉点。GMM 在原始数据空间里假设高斯形状，失败是因为数据的真实结构在原始空间里可能很复杂。但如果你先用一个神经网络（比如 VAE 的编码器）把数据映射到一个**隐空间**，在隐空间里数据的结构可能变得更规则，然后再做聚类。这个思路叫**深度聚类（Deep Clustering）**，是当前无监督学习的活跃研究方向。另一个方向是核方法（Kernel Methods）——用核函数把数据隐式地映射到高维空间，在高维空间里线性可分的结构在原始空间里对应复杂的非线性边界。谱聚类（Spectral Clustering）就是这个思路的一个实现，能处理任意形状的簇。

### 一、为什么需要降维

设想你有一个基因组数据集：每个样本是一个病人，每个病人有 20,000 个基因的表达量，也就是说每个样本是一个 20,000 维的向量。你想可视化这些病人之间的相似关系，但人类只能理解二维或三维的图像。你需要把 20,000 维压缩到 2 维，同时尽量保留数据里有意义的结构。

这就是降维要解决的问题。但降维不只是用于可视化。在机器学习的完整流程里，降维有三个重要的实际用途。

第一是**去除噪声**。高维数据里往往有很多维度是冗余的或者充满噪声的，降维能把真正携带信息的方向保留下来，去掉噪声维度，让后续的监督学习模型更容易训练。第二是**缓解维度灾难**。在高维空间里，数据点之间的距离趋向于相等（这是一个可以严格证明的数学事实），导致基于距离的算法（K-Means、KNN）失效。把数据降到低维，距离的区分度就恢复了。第三是**特征提取**。降维后的低维表示往往比原始特征更紧凑、更有语义，可以作为下游任务的输入特征。

---

### 二、PCA：找到数据变化最大的方向

**主成分分析（Principal Component Analysis，PCA）** 是最经典的线性降维方法，思想极其优雅。

先建立直觉。想象一堆数据点在二维平面上分布成一个细长的椭圆。这些点的变化主要沿椭圆的长轴方向，沿短轴方向几乎没有变化。如果你把数据投影到长轴上，保留了大部分信息；如果投影到短轴上，得到的几乎是一条直线，信息几乎全丢了。PCA 要找的，就是这个"变化最大的方向"——数学上叫**主成分（Principal Component）**。

形式化地，PCA 寻找一组正交的方向向量 {w1,w2,…,wd}，使得数据在 w1 方向上的投影方差最大，在 w2 方向上的方差次之（且 w2⊥w1w2⊥w1），以此类推。

具体步骤是：

**第一步**：中心化数据，让每个维度的均值为 0。

x~i=xi−xˉx~i=xi−xˉ

**第二步**：计算协方差矩阵。

C=1N∑i=1Nx~ix~i⊤=1NX⊤XC=N1i=1∑Nx~ix~i⊤=N1X⊤X

**第三步**：对协方差矩阵做特征值分解，得到特征值 λ1≥λ2≥⋯≥λDλ1≥λ2≥⋯≥λD 和对应的特征向量。

**第四步**：选取前 d 个特征向量（主成分），把数据投影到这 d 个方向上，得到低维表示。

这里有一个和你之前学过内容的联系：特征值分解在 SLAM 的 Bundle Adjustment 里也出现过——Hessian 矩阵的特征值描述了优化问题在不同方向上的曲率。PCA 的协方差矩阵和 BA 的 Hessian 矩阵都在做同一件事：**描述数据或目标函数在不同方向上的"伸展程度"**。

```python
import numpy as np
import matplotlib.pyplot as plt

# 生成一个细长的二维椭圆数据集
np.random.seed(42)
# 数据主要沿 [2,1] 方向分布，沿 [-1,2] 方向几乎没有变化
mean = [0, 0]
cov = [[3, 2], [2, 2]]  # 协方差矩阵决定了椭圆的形状和方向
X = np.random.multivariate_normal(mean, cov, 300)

# ---- 手动实现 PCA ----
# 第一步：中心化
X_centered = X - X.mean(axis=0)

# 第二步：计算协方差矩阵
C = (X_centered.T @ X_centered) / len(X)

# 第三步：特征值分解
eigenvalues, eigenvectors = np.linalg.eigh(C)
# eigh 返回的特征值是升序的，我们需要降序
idx = eigenvalues.argsort()[::-1]
eigenvalues = eigenvalues[idx]
eigenvectors = eigenvectors[:, idx]

print("特征值（每个主成分解释的方差）：")
print(f"  第1主成分: {eigenvalues[0]:.3f}  "
      f"（解释了 {eigenvalues[0]/eigenvalues.sum()*100:.1f}% 的方差）")
print(f"  第2主成分: {eigenvalues[1]:.3f}  "
      f"（解释了 {eigenvalues[1]/eigenvalues.sum()*100:.1f}% 的方差）")

# 第四步：降维到 1 维（只保留第一主成分）
W = eigenvectors[:, :1]          # 投影矩阵，(2, 1)
X_reduced = X_centered @ W       # 降维后的数据，(300, 1)
X_reconstructed = X_reduced @ W.T + X.mean(axis=0)  # 重建回 2 维

# 可视化
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

axes[0].scatter(X[:, 0], X[:, 1], alpha=0.5, label='原始数据')
# 画出两个主成分方向
for i, (val, vec) in enumerate(zip(eigenvalues, eigenvectors.T)):
    axes[0].arrow(0, 0, vec[0]*val, vec[1]*val,
                  head_width=0.1, color=['red','blue'][i],
                  label=f'PC{i+1}')
axes[0].set_title("原始数据与主成分方向")
axes[0].legend()
axes[0].set_aspect('equal')

axes[1].scatter(X[:, 0], X[:, 1], alpha=0.3, label='原始数据')
axes[1].scatter(X_reconstructed[:, 0], X_reconstructed[:, 1],
                alpha=0.5, color='red', label='降到1维后重建')
axes[1].set_title("PCA 降维：投影到第一主成分")
axes[1].legend()
axes[1].set_aspect('equal')

plt.tight_layout()
plt.show()
```

运行后你会看到，红色的重建点全部落在第一主成分方向的一条直线上——这就是 1 维 PCA 的结果。数据的主要结构被保留了，只损失了沿第二主成分方向的少量变化。

### 三、PCA 的几何直觉与信息压缩

PCA 降维有一个美妙的信息论解释：在所有线性降维方法里，PCA 是**重建误差最小**的那个。换句话说，用同样的 d 个方向，没有任何其他线性投影能比 PCA 更好地保留原始数据的信息。

每个特征值 λk 代表了第 k 个主成分方向上数据的方差。**所有特征值的总和等于原始数据的总方差**。前 d 个特征值之和占总和的比例，叫做"累计解释方差比"，告诉你保留了多少比例的原始信息：

解释方差比=∑k=1dλk∑k=1Dλk解释方差比=∑k=1Dλk∑k=1dλk

实践中常见的做法是选择 d 使得累计解释方差比达到 95% 或 99%，这样在大幅压缩维度的同时，保留了绝大部分信息。

一个具体的感受：MNIST 数字图像是 784 维的，但用 PCA 保留前 50 个主成分（解释约 85% 的方差），重建的图像依然清晰可辨——这说明 784 维里绝大部分是冗余信息，数字图像的"真正自由度"只有几十个。

### 四、PCA 的局限与非线性降维

PCA 是**线性**降维——它只能找直线方向，投影后的低维空间是原始空间的线性子空间。但如果数据分布在一个非线性的低维流形上，PCA 就无能为力。

一个经典的例子是"瑞士卷（Swiss Roll）"——一张二维纸卷成三维的螺旋形。数据本质上是二维的，但 PCA 无法"展开"这个螺旋，因为展开需要非线性变换。

处理非线性结构的降维方法有几种。

**t-SNE（t-distributed Stochastic Neighbor Embedding）**是目前最流行的非线性降维可视化工具。它的核心思想是：在高维空间里，用高斯分布来衡量两点之间的相似度；在低维空间里，用 t 分布来衡量相似度（t 分布比高斯分布有更厚的尾部，能更好地处理低维空间里点的拥挤问题）。训练目标是最小化高维和低维相似度分布之间的 KL 散度：

L=∑i∑jpijlogpijqijL=i∑j∑pijlogqijpij

这里 pij 是高维空间里的相似度，qij 是低维空间里的相似度。你认出了 KL 散度——再一次，信息论的工具出现在了一个看似不相关的地方。

t-SNE 非常擅长在二维图里展示数据的"局部聚类结构"，是数据探索和可视化的标准工具。它的缺点是计算慢（O(N2) 的复杂度），而且低维坐标的绝对位置没有意义，只有相对的聚类结构有意义。

**UMAP（Uniform Manifold Approximation and Projection）**是 t-SNE 的现代替代品，速度更快，而且更好地保留了全局结构，是当前最推荐的非线性降维工具。

```python
from sklearn.manifold import TSNE
from sklearn.datasets import load_digits
```

### 五、自编码器：降维的深度学习版本

PCA 是线性降维，t-SNE 是非参数方法，两者都不能直接用于新数据（t-SNE 要对每批新数据重新训练）。深度学习给出了一个统一的解决方案：**自编码器（Autoencoder）**。

自编码器由两个网络组成：**编码器（Encoder）**把高维输入 x 压缩成低维隐向量 z，**解码器（Decoder）**把 z 重建回原始维度。训练目标是最小化重建误差：

L=∥x−Decoder(Encoder(x))∥2L=∥x−Decoder(Encoder(x))∥2

没有标签，完全自监督——输入就是目标，网络必须在低维瓶颈里保留足够的信息来重建输入。

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# 加载 MNIST
transform = transforms.ToTensor()
train_data = datasets.MNIST('./data', train=True, download=True, transform=transform)
train_loader = DataLoader(train_data, batch_size=256, shuffle=True)

class Autoencoder(nn.Module):
    def __init__(self, latent_dim=2):  # 把 784 维压缩到 2 维，便于可视化
        super().__init__()

        # 编码器：784 → 128 → 64 → latent_dim
        self.encoder = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, latent_dim),  # 瓶颈层：这就是降维后的表示
        )

        # 解码器：latent_dim → 64 → 128 → 784
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 128),
            nn.ReLU(),
            nn.Linear(128, 784),
            nn.Sigmoid(),  # 输出在 [0,1] 之间，对应像素值
        )

    def forward(self, x):
        x = x.view(-1, 784)           # 展平图像
        z = self.encoder(x)            # 压缩到低维
        x_recon = self.decoder(z)      # 重建
        return x_recon, z

model = Autoencoder(latent_dim=2)
optimizer = optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.MSELoss()

# 训练
for epoch in range(10):
    total_loss = 0
    for images, _ in train_loader:  # 注意：标签被丢弃，完全无监督
        x_recon, z = model(images)
        loss = criterion(x_recon, images.view(-1, 784))

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        total_loss += loss.item()

    print(f"Epoch {epoch+1}: loss={total_loss/len(train_loader):.4f}")

# 可视化 2 维隐空间
model.eval()
zs, ys = [], []
with torch.no_grad():
    for images, labels in DataLoader(train_data, batch_size=1000):
        _, z = model(images)
        zs.append(z)
        ys.append(labels)

Z = torch.cat(zs).numpy()
Y = torch.cat(ys).numpy()

plt.figure(figsize=(8, 6))
scatter = plt.scatter(Z[:, 0], Z[:, 1], c=Y, cmap='tab10', alpha=0.5, s=5)
plt.colorbar(scatter)
plt.title("自编码器学到的 2 维隐空间（无监督）")
plt.show()
```

你会看到，即使没有任何标签，自编码器学到的 2 维隐空间仍然展现出明显的类别分离结构——不同数字占据了不同的区域。这就是无监督学习发现的"数据的内在结构"。

自编码器和 PCA 的关系很深：**如果编码器和解码器都是线性变换，且没有激活函数，自编码器的解等价于 PCA**。非线性激活函数的引入，使得自编码器能发现 PCA 看不到的非线性结构——这正是深度学习对经典方法的系统性超越。

### 六、无监督学习的完整图景

走到这里，我们已经覆盖了经典无监督学习的核心内容，值得把它整理成一张完整的地图：

聚类方向，K-Means 是硬分配的基础算法，GMM 是软分配的概率版本，DBSCAN 处理任意形状和噪声，谱聚类处理复杂流形结构。降维方向，PCA 是线性降维的标准工具，t-SNE 和 UMAP 是非线性可视化的标准工具，自编码器是可学习的非线性降维框架，VAE（你在信息论里学过）是自编码器的概率版本，加入了 KL 散度正则项，使得隐空间具有更好的结构。

这两个方向在现代深度学习里以**表征学习（Representation Learning）**的名义统一起来：用神经网络学习数据的低维表示，使得这个表示既紧凑（降维），又有语义（聚类结构自然涌现）。CLIP 的对比学习、BERT 的预训练，本质上都是某种形式的表征学习——只是规模更大、目标更丰富。

### 七、这节课的思考题

**第一个问题**：PCA 找的是方差最大的方向，但方差最大不一定等于对下游任务最有用。比如，数据里方差最大的方向可能只是光照变化（对人脸识别没用），而真正有判别力的方向（不同人的脸的区别）方差反而小。有没有一种方法，能找到"对区分类别最有用"的方向，而不只是"方差最大"的方向？（提示：这需要用到标签信息。）

**第二个问题**：自编码器通过最小化重建误差来学习隐表示。但重建误差最小，不一定意味着隐空间的结构对下游任务最有用——网络可能学到了一些"捷径"来完成重建，而没有学到真正有语义的结构。你能想到什么方式，在训练过程中引导隐空间学到更有语义的结构？

这两个问题都指向了无监督学习和监督学习之间的桥梁——**半监督学习**和**自监督学习**，也是强化学习之前一个值得了解的过渡概念。
