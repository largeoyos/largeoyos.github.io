## 第一节：马尔可夫决策过程

先来回应上节课的两个思考题。

### 思考题的答案

**找"对区分类别最有用"的方向？**

你描述的正是**线性判别分析（Linear Discriminant Analysis，LDA）**的思路。LDA 和 PCA 都是线性降维，但目标函数完全不同：PCA 最大化投影后的总方差，LDA 最大化"类间方差 / 类内方差"的比值——让不同类别的中心尽量分开，同时让同一类别内部的点尽量聚拢。LDA 需要标签信息，所以严格来说是监督降维，不属于无监督学习。这个例子说明了一个普遍的道理：**目标函数的选择决定了你能学到什么**。你优化什么，你就得到什么；优化错了目标，数据再多也没用。

**如何引导隐空间学到更有语义的结构？**

有几个方向。第一是对比学习（CLIP 用的方法）——不只让网络重建输入，而是让语义相似的样本在隐空间里靠近、语义不同的样本远离，这样隐空间的距离就有了语义含义。第二是加入额外的正则项，比如 VAE 的 KL 散度约束让隐空间服从标准高斯分布，使得隐空间连续且可插值。第三是引入少量标签做半监督学习——用大量无标签数据学基本结构，用少量标签数据引导语义方向。这三个方向在现代自监督学习里都有大量应用。

### 一、强化学习和其他范式的根本区别

在进入数学之前，先建立一个清晰的直觉，理解强化学习和你之前学的所有内容有什么本质不同。

监督学习和无监督学习有一个共同的假设：**数据是独立同分布的（i.i.d.）**，每个样本之间没有关联，你可以打乱顺序训练。强化学习打破了这个假设。

强化学习描述的是这样一种情形：一个**智能体（Agent）**在一个**环境（Environment）**中采取**行动（Action）**，环境根据行动给出**奖励（Reward）**并转移到新的**状态（State）**，智能体的目标是学习一个**策略（Policy）**，使得长期累计奖励最大化。

关键的区别有三个。第一，**数据不是预先给定的，而是由智能体的行为产生的**——你怎么行动，就收集到什么数据，数据和学习过程是耦合的。第二，**奖励是延迟的**——下棋时你不知道某一步走得好不好，直到游戏结束才知道输赢，需要把最终结果归因到之前的每一步行动。第三，**行动会影响未来的状态**——你的每个决策不只是得到即时奖励，还改变了环境，影响了未来的可能性。

一个生动的类比：监督学习像做选择题，每道题都有标准答案告诉你对错；强化学习像下棋，没有人告诉你每步棋的好坏，只有最终的胜负，而且你的每步棋都改变了棋盘的局面，影响着未来的一切可能。

### 二、马尔可夫决策过程：强化学习的数学语言

强化学习的标准数学框架叫**马尔可夫决策过程（Markov Decision Process，MDP）**，由五个要素组成：

**状态空间 S**：环境所有可能状态的集合。比如棋盘游戏里，一个状态就是棋盘的当前布局；机器人导航里，一个状态就是机器人的位置和速度。

**动作空间 A**：智能体所有可能动作的集合。可以是离散的（上下左右四个方向），也可以是连续的（机械臂的关节角度）。

**转移函数 P(s′∣s,a)**：在状态 s 下执行动作 a 后，环境转移到状态 s′s′ 的概率。这个函数描述了环境的动力学。

**奖励函数 R(s,a,s′)**：在状态 s 执行动作 a 转移到 s′s′ 时，智能体获得的即时奖励。

**折扣因子 γ∈[0,1)γ∈[0,1)**：控制对未来奖励的重视程度。γ 接近 1 时，智能体很"有远见"，重视长期奖励；γ 接近 0 时，智能体很"短视"，只关注即时奖励。

**马尔可夫性质**是这个框架的核心假设：**未来只依赖于当前状态，与历史无关**。形式上，P(st+1∣st,at,st−1,at−1,…)=P(st+1∣st,at)。这个假设使得数学处理变得可行，而且在很多实际问题里是合理的——给定当前棋盘布局，下一步棋的最优选择和之前的棋局历史无关。

智能体的目标是学习一个策略 π(a∣s)（给定状态 s，选择动作 a 的概率），最大化**期望折扣累计奖励**：

Gt=∑k=0∞γkRt+k+1Gt=k=0∑∞γkRt+k+1J(π)=Eπ[G0]=Eπ[∑t=0∞γtRt+1]J(π)=Eπ[G0]=Eπ[t=0∑∞γtRt+1]

折扣因子 γ 的存在不只是数学上保证收敛（无限求和才有有限值），也有直觉上的合理性：未来的奖励本来就比当下的奖励更不确定，打个折扣是合理的。

### 三、价值函数：评估"当前处境有多好"

直接优化策略 π 很困难，因为 J(π) 是一个期望，需要对整个轨迹积分。强化学习引入了**价值函数**作为中间桥梁，把长期问题局部化。

**状态价值函数 Vπ(s)** 定义为：从状态 s 出发，遵循策略 π，期望能获得多少累计奖励：

Vπ(s)=Eπ[∑t=0∞γtRt+1∣S0=s]Vπ(s)=Eπ[t=0∑∞γtRt+1∣S0=s]

**动作价值函数 Qπ(s,a)**（也叫 Q 函数）定义为：从状态 s 出发，先执行动作 a，之后遵循策略 π，期望能获得多少累计奖励：

Qπ(s,a)=Eπ[∑t=0∞γtRt+1∣S0=s,A0=a]Qπ(s,a)=Eπ[t=0∑∞γtRt+1∣S0=s,A0=a]

V 和 Q 的关系是：Vπ(s)=∑aπ(a∣s)Qπ(s,a)，也就是说状态价值是在当前策略下所有动作的 Q 值的期望。

**贝尔曼方程**是价值函数最核心的性质，它把"从当前状态出发的长期价值"分解成"即时奖励 + 下一个状态的折扣价值"：

Vπ(s)=∑aπ(a∣s)∑s′P(s′∣s,a)[R(s,a,s′)+γVπ(s′)]Vπ(s)=a∑π(a∣s)s′∑P(s′∣s,a)[R(s,a,s′)+γVπ(s′)]Qπ(s,a)=∑s′P(s′∣s,a)[R(s,a,s′)+γ∑a′π(a′∣s′)Qπ(s′,a′)]Qπ(s,a)=s′∑P(s′∣s,a)[R(s,a,s′)+γa′∑π(a′∣s′)Qπ(s′,a′)]

这两个方程是强化学习所有算法的理论基础。它们的直觉是：**一个状态的价值 = 即时奖励 + 打折后的下一个状态的价值**。这是一个递推关系，把无限的长期问题变成了局部的两步问题。

你可以类比动态规划（你在数据结构里学过）：贝尔曼方程本质上就是强化学习版本的最优子结构，长期最优等于局部最优的组合。事实上，贝尔曼这个名字正是动态规划（Bellman）的发明者。

**最优价值函数**对应于最优策略 π∗π∗：

V∗(s)=maxπVπ(s),Q∗(s,a)=maxπQπ(s,a)V∗(s)=πmaxVπ(s),Q∗(s,a)=πmaxQπ(s,a)

最优贝尔曼方程（也叫贝尔曼最优方程）是：

Q∗(s,a)=∑s′P(s′∣s,a)[R(s,a,s′)+γmaxa′Q∗(s′,a′)]Q∗(s,a)=s′∑P(s′∣s,a)[R(s,a,s′)+γa′maxQ∗(s′,a′)]

如果你知道了 Q∗Q∗，最优策略就是在每个状态下选 Q 值最大的动作：π∗(s)=argmaxaQ∗(s,a)π∗(s)=argmaxaQ∗(s,a)。所以**学习最优 Q 函数，就等价于找到最优策略**——这是 Q-learning 类算法的核心思想。

### 四、用代码感受 MDP：一个简单的格子世界

在进入复杂算法之前，先用一个极简的例子让你"摸"到 MDP 的结构。

```python
import numpy as np

# ---- 定义一个 4×4 的格子世界 MDP ----
#
# 地图：
#   S  .  .  .
#   .  X  .  .
#   .  .  .  G
#
# S = 起点(0,0), G = 终点(3,3), X = 障碍物
# 动作：上(0) 下(1) 左(2) 右(3)
# 奖励：到达 G 得 +1，其他步骤得 -0.01（鼓励尽快到达）
# 折扣因子：gamma = 0.99

GRID_SIZE = 4
OBSTACLES = {(1, 1), (2, 2)}  # 障碍物位置
GOAL = (3, 3)
GAMMA = 0.99

# 状态：(行, 列)，共 16 个状态
# 动作：0=上 1=下 2=左 3=右
ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]

def is_valid(r, c):
    """判断位置是否合法"""
    return 0 <= r < GRID_SIZE and 0 <= c < GRID_SIZE and (r, c) not in OBSTACLES

def step(s, a):
    """环境转移函数：给定状态和动作，返回 (下一状态, 奖励)"""
    if s == GOAL:
        return s, 0  # 终止状态，不再移动

    dr, dc = ACTIONS[a]
    r, c = s
    nr, nc = r + dr, c + dc

    # 如果撞墙或障碍物，停在原地
    if not is_valid(nr, nc):
        nr, nc = r, c

    next_s = (nr, nc)
    reward = 1.0 if next_s == GOAL else -0.01
    return next_s, reward

# ---- 策略评估：给定策略，用迭代方法计算价值函数 ----
# 这直接基于贝尔曼方程：V(s) = R(s,a) + gamma * V(s')

def policy_evaluation(policy, theta=1e-6):
    """
    输入：policy[s] = 动作（确定性策略）
    输出：V[s] = 每个状态的价值
    """
    # 初始化价值函数为 0
    V = {(r, c): 0.0 for r in range(GRID_SIZE) for c in range(GRID_SIZE)
         if (r, c) not in OBSTACLES}

    while True:
        delta = 0  # 记录本轮最大变化量

        for s in V:
            if s == GOAL:
                continue

            a = policy[s]
            next_s, reward = step(s, a)

            # 贝尔曼方程：V(s) = R + gamma * V(s')
            new_v = reward + GAMMA * V.get(next_s, 0)
            delta = max(delta, abs(new_v - V[s]))
            V[s] = new_v

        if delta < theta:  # 价值函数收敛
            break

    return V

# ---- 策略迭代：交替做策略评估和策略改进，直到找到最优策略 ----

def policy_iteration():
    # 初始化：随机策略（所有状态都向右走）
    states = [(r, c) for r in range(GRID_SIZE) for c in range(GRID_SIZE)
              if (r, c) not in OBSTACLES]
    policy = {s: 3 for s in states}  # 3 = 向右

    iteration = 0
    while True:
        # 第一步：策略评估，计算当前策略的价值函数
        V = policy_evaluation(policy)

        # 第二步：策略改进，对每个状态选择 Q 值最大的动作
        policy_stable = True
        for s in states:
            if s == GOAL:
                continue

            old_action = policy[s]

            # 计算每个动作的 Q 值：Q(s,a) = R + gamma * V(s')
            q_values = []
            for a in range(4):
                next_s, reward = step(s, a)
                q = reward + GAMMA * V.get(next_s, 0)
                q_values.append(q)

            # 选择 Q 值最大的动作
            policy[s] = np.argmax(q_values)

            if policy[s] != old_action:
                policy_stable = False

        iteration += 1
        print(f"第 {iteration} 次迭代，策略{'稳定' if policy_stable else '更新中'}...")

        if policy_stable:
            break

    return policy, V

policy, V = policy_iteration()

# 可视化最优策略
action_symbols = ['↑', '↓', '←', '→']
print("\n最优策略：")
for r in range(GRID_SIZE):
    row = ""
    for c in range(GRID_SIZE):
        if (r, c) == GOAL:
            row += " G "
        elif (r, c) in OBSTACLES:
            row += " X "
        else:
            row += f" {action_symbols[policy[(r,c)]]} "
    print(row)

print("\n状态价值函数：")
for r in range(GRID_SIZE):
    row = ""
    for c in range(GRID_SIZE):
        if (r, c) in OBSTACLES:
            row += "  X   "
        else:
            row += f"{V.get((r,c), 0):+.3f} "
    print(row)
```

运行后你会看到：最优策略在每个格子里给出箭头，指向通往终点的最短路径；价值函数在每个格子里给出一个数字，越靠近终点的格子价值越高。这就是贝尔曼方程被迭代求解的结果——**从终点出发，价值信号向外扩散，最终覆盖整个状态空间**。

### 五、从已知环境到未知环境

上面的策略迭代算法有一个关键的前提：**我们知道转移函数 P(s′∣s,a) 和奖励函数 R**。在格子世界里，我们自己定义了环境，当然知道。

但在真实问题里——比如训练一个机器人走路，或者训练 AlphaGo 下棋——我们不知道环境的完整数学模型。我们只能通过**与环境交互**来学习：执行一个动作，观察下一个状态和奖励，从这些经验数据中估计价值函数和最优策略。

这类不依赖环境模型、直接从交互数据中学习的方法叫**无模型强化学习（Model-Free RL）**，是当前深度强化学习的主流。主要分两大类：

**基于价值的方法（Value-Based）**：学习 Q 函数，策略是"选 Q 值最大的动作"。代表算法是 Q-learning 和 DQN。

**基于策略的方法（Policy-Based）**：直接学习策略 π(a∣s)，用梯度上升优化 J(π)。代表算法是 REINFORCE 和 PPO（你在信息论里见过它的名字）。

下一节我们会把这两类方法都讲清楚，并用 DQN 实现一个真正能玩游戏的强化学习智能体。

### 六、这节课的思考题

**第一个问题**：策略迭代交替做"策略评估"和"策略改进"，每次策略评估都要迭代到收敛，计算量很大。有一种简化叫**价值迭代（Value Iteration）**：不等评估收敛，每次只做一步贝尔曼更新，同时把策略改进合并进去：

V(s)←maxa[R(s,a)+γ∑s′P(s′∣s,a)V(s′)]V(s)←amax[R(s,a)+γs′∑P(s′∣s,a)V(s′)]

你能看出这个公式和贝尔曼最优方程的关系吗？为什么这样做也能收敛到最优解？

**第二个问题**：MDP 假设智能体能观察到完整的环境状态 s。但在很多现实场景里，智能体只能看到部分信息——比如扑克牌游戏里你看不到对手的手牌，机器人只有摄像头看不到自己的精确位置。这种情形叫**部分可观测 MDP（POMDP）**。你在 SLAM 里学过的东西，和 POMDP 有什么关联？

第二个问题的答案，是 SLAM 和强化学习之间一座非常深刻的桥梁——机器人在未知环境里导航，本质上就是一个 POMDP 问题，而粒子滤波（SLAM 里用的定位方法）正是处理 POMDP 的经典工具之一。

下一节我们进入无模型强化学习的核心算法——Q-learning、DQN，以及策略梯度方法。

## 第二节：无模型算法——Q-learning 到 DQN

先来回应上节课的两个思考题。

### 思考题的答案

**价值迭代为什么能收敛到最优解？**

价值迭代的更新公式 V(s)←maxa[R+γV(s′)]V(s)←maxa[R+γV(s′)] 其实就是把贝尔曼最优方程当作一个**不动点迭代**来使用。可以证明这个更新操作是一个**压缩映射（Contraction Mapping）**，每次迭代之后，当前的 V 和真实的 V∗V∗ 之间的距离缩小到原来的 γ 倍（因为 γ<1）。根据巴拿赫不动点定理，压缩映射的迭代一定收敛到唯一的不动点——也就是 V∗V∗。策略迭代每步评估到收敛，价值迭代每步只更新一次，两者的收敛速度不同，但终点相同。这个 γ<1 的条件不只是保证求和收敛，还是算法收敛性的数学保障。

**SLAM 和 POMDP 的联系？**

这个联系非常深刻。SLAM 里，机器人不知道自己的精确位置（部分可观测），只有传感器的观测值（摄像头图像、激光点云）。粒子滤波维护一个关于"机器人可能在哪里"的概率分布，每次观测后用贝叶斯更新这个分布——这正是处理 POMDP 的标准思路：维护一个**信念状态（Belief State）**，它是对真实状态的概率分布，用来替代直接观测不到的真实状态。SLAM 的粒子滤波，在强化学习的语言里，就是在维护和更新信念状态。两个领域用不同的语言描述了同一个数学结构。

---

### 一、无模型学习的核心挑战

上节课的策略迭代需要知道 P(s′∣s,a) 和 R(s,a,s′)。现在我们进入更现实的设定：**我们不知道环境的模型**，只能通过执行动作、观察结果来积累经验数据。

这带来了一个根本性的难题，叫做**探索-利用困境（Exploration-Exploitation Dilemma）**。

想象你刚到一座陌生城市，想找一家好餐厅。此前已经发现了一家不错的拉面店（利用现有知识），但也许还有更好的餐厅你没发现（探索未知）。如果总是去拉面店，你永远不知道有没有更好的选择；如果总是去新地方，你可能一直吃到难吃的东西。

在强化学习里，这个困境更严峻：如果智能体总是选择当前认为最好的动作（纯利用），它可能永远停留在局部最优，错过真正的最优策略；如果总是随机探索，它又无法积累有效的经验。平衡探索和利用，是无模型强化学习的核心工程问题之一。

---

### 二、Q-learning：从经验中学习最优 Q 函数

**Q-learning** 是最基础的无模型算法，由 Watkins 在 1989 年提出。它的目标是直接从交互数据中学习最优 Q 函数 Q∗(s,a)Q∗(s,a)，不需要知道环境模型。

核心更新公式是：

Q(s,a)←Q(s,a)+α[r+γmaxa′Q(s′,a′)⏟TD目标−Q(s,a)]Q(s,a)←Q(s,a)+αTD目标r+γa′maxQ(s′,a′)−Q(s,a)

这个公式值得仔细拆解，因为它包含了强化学习里最重要的思想。方括号里的内容叫**时序差分误差（TD Error）**：当前的 Q 估计 Q(s,a) 和"更好的估计" r+γmaxa′Q(s′,a′)r+γmaxa′Q(s′,a′) 之间的差距。后者叫 TD 目标，它用实际观察到的奖励 r 加上对下一状态价值的估计，比当前的纯估计更可靠一些。每次更新，我们把 Q(s,a) 往 TD 目标的方向拉一步，步长是学习率 α。

这里有一个非常深刻的认识：**Q-learning 是在用"稍微好一点的估计"来改进"当前的估计"，自举（Bootstrap）地逼近真实值**。它不需要等到一局游戏结束才更新，每一步交互之后都可以更新，这使得学习非常高效。

注意 maxa′Q(s′,a′)maxa′Q(s′,a′) 的存在——无论当前的策略是什么，更新时总是假设下一步选最优动作。这个性质叫**离策略（Off-Policy）**：Q-learning 学习的是最优策略，但执行的可以是任意策略（比如带随机探索的策略）。这是一个非常强大的性质，意味着我们可以用一个探索性的行为策略来收集数据，同时学习最优策略。

最简单的探索策略叫 **ϵϵ-贪心（ϵϵ-Greedy）**：以概率 1−ϵ1−ϵ 选择当前 Q 值最大的动作（利用），以概率 ϵϵ 随机选择动作（探索）。训练早期 ϵϵ 大（多探索），随着 Q 函数越来越准确，逐渐减小 ϵϵ（转向利用）。

```python
import numpy as np

# 用上节课的格子世界，但这次假设我们不知道转移函数，只能交互
GRID_SIZE = 4
OBSTACLES = {(1, 1), (2, 2)}
GOAL = (3, 3)
GAMMA = 0.99
ALPHA = 0.1       # 学习率
EPSILON = 1.0     # 初始探索率
EPSILON_MIN = 0.01
EPSILON_DECAY = 0.995
ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]

def is_valid(r, c):
    return 0 <= r < GRID_SIZE and 0 <= c < GRID_SIZE and (r, c) not in OBSTACLES

def step(s, a):
    if s == GOAL:
        return s, 0, True  # (下一状态, 奖励, 是否终止)
    dr, dc = ACTIONS[a]
    r, c = s
    nr, nc = r + dr, c + dc
    if not is_valid(nr, nc):
        nr, nc = r, c
    next_s = (nr, nc)
    reward = 1.0 if next_s == GOAL else -0.01
    done = (next_s == GOAL)
    return next_s, reward, done

# 初始化 Q 表：Q[(s, a)] = 0
states = [(r, c) for r in range(GRID_SIZE) for c in range(GRID_SIZE)
          if (r, c) not in OBSTACLES]
Q = {(s, a): 0.0 for s in states for a in range(4)}

epsilon = EPSILON
episode_rewards = []

for episode in range(2000):
    # 每局从起点开始
    s = (0, 0)
    total_reward = 0

    for step_count in range(100):  # 最多走 100 步
        # epsilon-贪心选动作：探索 or 利用
        if np.random.random() < epsilon:
            a = np.random.randint(4)          # 随机探索
        else:
            # 选当前 Q 值最大的动作
            q_vals = [Q[(s, a)] for a in range(4)]
            a = np.argmax(q_vals)

        # 与环境交互，获得反馈
        next_s, reward, done = step(s, a)
        total_reward += reward

        # Q-learning 更新：用 TD 误差更新 Q 值
        # 这是整个算法的核心，每步都在发生
        best_next_q = max(Q[(next_s, a_)] for a_ in range(4))
        td_target = reward + GAMMA * best_next_q * (1 - done)
        td_error  = td_target - Q[(s, a)]
        Q[(s, a)] += ALPHA * td_error

        s = next_s
        if done:
            break

    # 逐渐减小探索率
    epsilon = max(EPSILON_MIN, epsilon * EPSILON_DECAY)
    episode_rewards.append(total_reward)

    if (episode + 1) % 500 == 0:
        avg = np.mean(episode_rewards[-500:])
        print(f"Episode {episode+1}: 平均奖励={avg:.3f}, epsilon={epsilon:.3f}")

# 展示学到的最优策略
action_symbols = ['↑', '↓', '←', '→']
print("\nQ-learning 学到的策略：")
for r in range(GRID_SIZE):
    row = ""
    for c in range(GRID_SIZE):
        if (r, c) == GOAL:
            row += " G "
        elif (r, c) in OBSTACLES:
            row += " X "
        else:
            best_a = np.argmax([Q[((r,c), a)] for a in range(4)])
            row += f" {action_symbols[best_a]} "
    print(row)
```

你会看到，从完全不知道环境的随机策略出发，Q-learning 在几千局游戏之后，学到了和上节课策略迭代完全相同的最优策略——但这次没有用到任何环境模型，纯粹靠交互经验。

### 三、从表格到神经网络：DQN 的诞生

Q-learning 把 Q 函数存在一张表里——每个 (s,a) 对应一个数值。这在格子世界里可行，但现实问题中状态空间往往是天文数字。以 Atari 游戏为例，每一帧画面是 84×84 的像素矩阵，可能的画面数量远超宇宙中的原子数，根本没法建表。

解决方案是用**神经网络来近似 Q 函数**：输入状态 s，输出每个动作的 Q 值。这就是 **DQN（Deep Q-Network）**，DeepMind 在 2013-2015 年提出，第一次让强化学习在高维感知输入（像素）上取得了超越人类的表现。

但直接把 Q-learning 和神经网络结合，训练会极其不稳定，甚至发散。原因有两个。

第一个问题是**数据相关性**。Q-learning 每步收集一个 (s,a,r,s′) 样本，连续的样本高度相关——第 t 步和第 t+1 步的状态几乎相同。用相关数据做梯度下降，等于反复在同一个方向更新，网络容易过拟合到局部经验，忘掉之前学的。监督学习用 i.i.d. 数据，这个问题不存在；强化学习的数据天然是时序相关的。

第二个问题是**训练目标不稳定**。Q-learning 的 TD 目标 r+γmaxa′Q(s′,a′)r+γmaxa′Q(s′,a′) 里用的是当前网络的 Q 值，但当前网络的 Q 值在训练过程中不断变化——你在追赶一个移动的靶子。这会导致训练震荡甚至发散。

DQN 用两个精妙的工程技巧解决了这两个问题。

**经验回放（Experience Replay）**解决数据相关性。智能体把每步的交互经验 (s,a,r,s′) 存入一个**回放缓冲区（Replay Buffer）**，训练时从缓冲区里**随机采样**一个 mini-batch。随机采样打破了时序相关性，使得训练数据接近 i.i.d.，就像监督学习一样稳定。这个思想非常优雅——你不需要改变数据的收集方式，只需改变数据的使用方式。

**目标网络（Target Network）**解决训练目标不稳定。维护两个结构相同的网络：**在线网络**用于选动作和做梯度更新，**目标网络**用于计算 TD 目标里的 maxa′Q(s′,a′)maxa′Q(s′,a′)。目标网络的参数每隔固定步数才从在线网络复制一次，在两次复制之间保持不变。这样 TD 目标在一段时间内是固定的，等于给网络一个稳定的学习目标，大幅改善了训练稳定性。

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
from collections import deque
import random

# ---- DQN 网络结构 ----
class DQN(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=128):
        super().__init__()
        # 输入：状态向量；输出：每个动作的 Q 值
        # 注意和监督学习的区别：输出是 Q 值（实数），而不是类别概率
        self.net = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim),  # 输出每个动作的 Q 值，不加激活函数
        )

    def forward(self, x):
        return self.net(x)

# ---- 经验回放缓冲区 ----
class ReplayBuffer:
    def __init__(self, capacity=10000):
        # deque 是双端队列，超过容量时自动丢弃最老的经验
        self.buffer = deque(maxlen=capacity)

    def push(self, s, a, r, s_next, done):
        self.buffer.append((s, a, r, s_next, done))

    def sample(self, batch_size):
        # 随机采样，打破时序相关性——这是经验回放的核心
        batch = random.sample(self.buffer, batch_size)
        s, a, r, s_next, done = zip(*batch)
        return (torch.FloatTensor(s),
                torch.LongTensor(a),
                torch.FloatTensor(r),
                torch.FloatTensor(s_next),
                torch.FloatTensor(done))

    def __len__(self):
        return len(self.buffer)

# ---- DQN 智能体 ----
class DQNAgent:
    def __init__(self, state_dim, action_dim):
        self.action_dim = action_dim
        self.gamma = 0.99
        self.epsilon = 1.0
        self.epsilon_min = 0.01
        self.epsilon_decay = 0.995
        self.batch_size = 64
        self.target_update_freq = 100  # 每 100 步更新一次目标网络
        self.step_count = 0

        # 在线网络：频繁更新，用于选动作和做梯度下降
        self.online_net = DQN(state_dim, action_dim)
        # 目标网络：缓慢更新，用于计算稳定的 TD 目标
        self.target_net = DQN(state_dim, action_dim)
        self.target_net.load_state_dict(self.online_net.state_dict())
        self.target_net.eval()  # 目标网络不做梯度计算

        self.optimizer = optim.Adam(self.online_net.parameters(), lr=1e-3)
        self.buffer = ReplayBuffer()

    def select_action(self, state):
        """epsilon-贪心选动作"""
        if np.random.random() < self.epsilon:
            return np.random.randint(self.action_dim)
        with torch.no_grad():
            q_values = self.online_net(torch.FloatTensor(state))
            return q_values.argmax().item()

    def update(self):
        """从经验回放中采样，做一步梯度更新"""
        if len(self.buffer) < self.batch_size:
            return  # 缓冲区还不够大，先积累经验

        s, a, r, s_next, done = self.buffer.sample(self.batch_size)

        # 在线网络计算当前 Q 值：Q(s, a)
        # gather 用来选取每个样本实际执行的动作对应的 Q 值
        current_q = self.online_net(s).gather(1, a.unsqueeze(1)).squeeze(1)

        # 目标网络计算 TD 目标：r + gamma * max_a' Q_target(s', a')
        # detach() 阻止梯度流入目标网络，它只提供数值，不参与训练
        with torch.no_grad():
            next_q = self.target_net(s_next).max(1)[0]
            td_target = r + self.gamma * next_q * (1 - done)

        # 损失：TD 误差的均方，和监督学习的 MSE 完全相同的形式
        # 区别在于"标签"不是人工标注的，而是用目标网络估计出来的
        loss = nn.MSELoss()(current_q, td_target)

        self.optimizer.zero_grad()
        loss.backward()
        # 梯度裁剪：防止梯度爆炸，强化学习训练中常见的稳定技巧
        torch.nn.utils.clip_grad_norm_(self.online_net.parameters(), 10)
        self.optimizer.step()

        self.step_count += 1

        # 定期把在线网络的权重复制给目标网络
        if self.step_count % self.target_update_freq == 0:
            self.target_net.load_state_dict(self.online_net.state_dict())

        # 逐渐降低探索率
        self.epsilon = max(self.epsilon_min, self.epsilon * self.epsilon_decay)
```

### 四、策略梯度：直接优化策略

Q-learning 和 DQN 都是**基于价值**的方法——先学 Q 函数，再从 Q 函数导出策略。但有另一条完全不同的路：**直接把策略参数化，然后对策略的期望回报做梯度上升**。

策略梯度方法把策略写成一个参数为 θ 的函数 πθ(a∣s)（通常是一个神经网络，输出每个动作的概率），然后直接对目标函数J(θ)=Eπθ[G0]做梯度上升。

关键问题是：J(θ) 里包含对轨迹的期望，而轨迹是由环境采样的，不可微分。怎么计算梯度？

**策略梯度定理**给出了答案：

∇θJ(θ)=Eπθ[∑t=0T∇θlogπθ(at∣st)⋅Gt]∇θJ(θ)=Eπθ[t=0∑T∇θlogπθ(at∣st)⋅Gt]

这个公式值得反复品味。∇θlogπθ(at∣st)∇θlogπθ(at∣st) 是"让这个动作在这个状态下更可能发生"的梯度方向；Gt 是从这一步开始的实际累计回报，作为权重。整个表达式的意思是：**如果这次执行动作 at 之后获得了高回报，就增大 πθ(at∣st)；如果回报低，就减小它**。这正是"试错学习"最直接的数学表达。

最简单的策略梯度算法叫 **REINFORCE**：

```python
class PolicyNetwork(nn.Module):
    """策略网络：输入状态，输出每个动作的概率（softmax）"""
    def __init__(self, state_dim, action_dim, hidden_dim=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim),
            nn.Softmax(dim=-1),  # 输出概率分布，而非 Q 值
        )

    def forward(self, x):
        return self.net(x)

def reinforce_update(policy_net, optimizer, episode_log_probs, episode_rewards, gamma=0.99):
    """
    REINFORCE 更新：一局游戏结束后，用整局的回报更新策略
    这是策略梯度定理的直接实现
    """
    # 计算每一步的折扣累计回报 G_t
    returns = []
    G = 0
    for r in reversed(episode_rewards):  # 从最后一步往前算
        G = r + gamma * G
        returns.insert(0, G)
    returns = torch.FloatTensor(returns)

    # 归一化回报：减去均值、除以标准差，减少方差，稳定训练
    # 这是策略梯度中非常重要的实践技巧
    returns = (returns - returns.mean()) / (returns.std() + 1e-8)

    # 策略梯度损失：-log π(a|s) * G_t
    # 注意负号：PyTorch 做梯度下降，我们想要梯度上升，所以加负号
    loss = -torch.stack(episode_log_probs) * returns
    loss = loss.sum()

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

策略梯度方法有一个 Q-learning 没有的天然优势：它可以处理**连续动作空间**。Q-learning 需要对所有动作取最大值，如果动作是连续的（比如机械臂的关节角度），就需要解一个连续优化问题，非常困难。策略梯度直接输出动作的概率分布（连续动作时输出高斯分布的均值和方差），采样动作即可，完全不需要枚举所有动作。

### 五、PPO：当前最主流的强化学习算法

REINFORCE 的问题是方差极大——每局游戏的回报波动很大，梯度更新方向不稳定，需要大量数据才能收敛。而且如果一步更新太大，策略可能突然变得很差，后续数据全部来自一个糟糕策略，很难恢复。

**PPO（Proximal Policy Optimization）**解决了这个问题，它是目前最广泛使用的强化学习算法，也是 ChatGPT 的 RLHF 训练使用的核心算法（你在信息论笔记里见过它的名字）。

PPO 的核心思想是：**在更新策略时，不要走太大的步子**。具体是通过限制新旧策略的比值 rt(θ)=πθ(at∣st)πθold(at∣st)rt(θ)=πθold(at∣st)πθ(at∣st) 来实现的。PPO 的损失函数是：

LCLIP(θ)=Et[min(rt(θ)A^t, clip(rt(θ),1−ϵ,1+ϵ)A^t)]LCLIP(θ)=Et[min(rt(θ)A^t, clip(rt(θ),1−ϵ,1+ϵ)A^t)]

这里 A^t 是**优势函数（Advantage Function）**，衡量动作 at 比"平均水平"好多少：A^t=Q(st,at)−V(st)。clip 操作把策略比值限制在 [1−ϵ,1+ϵ] 的范围内，防止单步更新过大。KL 散度约束（你在信息论里学过！）在某些 PPO 变体里代替 clip 来实现同样的效果。

PPO 的另一个关键组件是**演员-评论家（Actor-Critic）**结构：同时训练一个策略网络（演员，输出动作概率）和一个价值网络（评论家，估计状态价值 V(s)）。评论家提供的 V(s) 用来计算优势函数，大幅减少了梯度估计的方差，这是 REINFORCE 最大的改进。

### 六、三大算法的完整对比

走到这里，我们覆盖了强化学习最核心的三类算法，值得做一个系统的比较，因为理解它们的区别和适用场景，比单独理解每一个更重要。

Q-learning/DQN 属于基于价值的方法，优点是样本效率高（经验可以反复使用）、训练稳定（有目标网络），缺点是只能处理离散动作空间，而且策略是隐式的（从 Q 函数导出）。适合 Atari 游戏这类离散控制问题。

REINFORCE 属于纯策略梯度方法，优点是能处理连续动作，策略是显式的，缺点是方差极大，样本效率低，需要大量数据。实践中很少单独使用。

PPO 属于演员-评论家方法，结合了策略梯度的灵活性和价值函数的低方差，通过 clip 机制保证稳定性，既能处理离散也能处理连续动作。是目前最通用的算法，也是工业界默认的选择。

### 七、这节课的思考题

**第一个问题**：DQN 用目标网络来稳定 TD 目标，每隔固定步数"硬更新"（直接复制参数）。但这种硬更新会导致目标网络的参数突然跳变。有一种更平滑的更新方式叫**软更新**：θtarget←τθonline+(1−τ)θtarget←τθonline+(1−τ)θtarget，每步都做一个小幅混合（τ 很小，比如 0.005）。你觉得软更新相比硬更新有什么优缺点？

**第二个问题**：PPO 限制了策略更新的步幅，保证了稳定性，但也限制了每步能学习的量。在 RLHF 的场景里，奖励信号来自人类标注（非常稀少且昂贵），需要用极少的反馈数据学到尽量多。你觉得在这个场景下，样本效率和训练稳定性哪个更重要？两者能否同时兼顾？

这两个问题指向强化学习里两个重要的进阶方向：第一个问题是 **DDPG/TD3/SAC** 这类连续控制算法的核心组件；第二个问题是当前 AI 对齐研究里的核心工程挑战。下一节，也是强化学习的最后一节，我们把强化学习和深度学习的所有知识串联起来，讲**深度强化学习的完整图景**，以及它在机器人控制、游戏 AI、大模型训练中的具体应用。

## 第三节：深度强化学习的完整图景

先来回应上节课的两个思考题。

### 思考题的答案

**软更新 vs 硬更新？**

软更新的优点是目标网络的参数变化极其平滑，每步只做一个微小的混合，TD 目标几乎不会突然跳变，训练曲线更稳定。硬更新的目标网络在两次复制之间是完全固定的，这固然稳定，但一旦复制发生，参数会有一个较大的跳跃，可能短暂扰动训练。软更新的缺点是目标网络始终在追踪在线网络，永远有一个小的滞后——它从来不是真正固定的，理论上可能在某些情况下引入偏差。实践中，软更新被 DDPG、TD3、SAC 这类连续控制算法广泛采用，而 DQN 的原始论文用的是硬更新。两者没有绝对的优劣，取决于任务的特性和超参数的调整难度。

**RLHF 场景下，样本效率和稳定性哪个更重要？**

这是一个没有唯一答案的工程权衡，但有一个关键的现实约束：人类反馈的成本极高，每一个标注样本都很宝贵，所以**样本效率是瓶颈**。然而，如果训练不稳定导致模型崩溃（比如语言模型突然开始输出乱码），你就需要从头来过，损失更大。Anthropic 和 OpenAI 的实践表明，PPO 在 RLHF 场景里之所以成为标准，恰恰是因为它在两者之间找到了一个工程上可接受的平衡点——clip 机制保证了足够的稳定性，而 KL 散度惩罚项防止模型偏离太远。更进一步的解决方案是先用大量合成数据（AI 生成的偏好对）来预训练奖励模型，减少对昂贵人类标注的依赖，这是当前对齐研究的一个活跃方向。

### 一、从算法到系统：深度强化学习的完整闭环

前两节我们分别学了 MDP 的数学框架和核心算法。这一节我们要做一件更重要的事：**把所有知识串联成一个完整的系统视角**，看清楚深度强化学习在真实世界里是怎么运作的，又在哪些地方取得了真正的突破。

先用一张图来呈现完整的闭环：

```
        ┌─────────────────────────────────────┐
        │              智能体                   │
        │                                     │
        │   感知模块         决策模块            │
        │  (CNN/Transformer) (Policy Network)  │
        │        ↓               ↑             │
        │   状态表示 s ──→ Q(s,a) 或 π(a|s)    │
        │                    ↓                 │
        │              选择动作 a               │
        └──────────────┬──────────────────────┘
                       │ 执行动作 a
                       ↓
        ┌──────────────────────────────────────┐
        │              环境                    │
        │                                     │
        │   产生新状态 s'  +  奖励 r            │
        └──────────────┬───────────────────────┘
                       │
                       ↓
              存入经验回放缓冲区
              (s, a, r, s', done)
                       │
                       ↓
              随机采样 mini-batch
                       │
                       ↓
              计算 TD 误差 / 策略梯度
                       │
                       ↓
              梯度下降更新网络参数
                       │
                       └──────────────────────→ 回到智能体
```

这个闭环里，深度学习负责**感知**（把高维的原始输入——像素、点云、文字——压缩成有意义的状态表示），强化学习负责**决策**（在这个表示上学习最优策略）。两者的结合，是深度强化学习的本质。

### 二、AlphaGo：深度强化学习的第一个里程碑

2016 年，DeepMind 的 AlphaGo 击败了世界围棋冠军李世石，这是人工智能历史上的转折点之一。理解 AlphaGo 的技术路线，是理解深度强化学习在复杂问题上如何工作的最好案例。

围棋的状态空间极其庞大——棋盘有 19×19=361 个位置，合法局面的数量超过 10170，远超宇宙中的原子数。穷举搜索完全不可行，传统的启发式搜索（蒙特卡洛树搜索，MCTS）在没有好的评估函数时也效率低下。AlphaGo 的核心创新是用深度神经网络来引导搜索，而不是替代搜索。

AlphaGo 同时训练了两类网络。**策略网络（Policy Network）**输入当前棋盘状态，输出每个落子位置的概率分布，告诉搜索"哪些落子值得考虑"，剪枝掉绝大多数无意义的分支。**价值网络（Value Network）**输入当前棋盘状态，输出一个标量，估计当前局面的胜率，告诉搜索"这个局面对我方有多有利"，代替耗时的随机模拟来评估叶节点。

训练分三个阶段。第一阶段是**监督学习**：用人类棋手的 3000 万局棋谱训练策略网络，让它模仿人类的落子习惯，快速建立一个"还不错"的初始策略。第二阶段是**自我博弈强化学习**：让策略网络和自己的历史版本对弈，用策略梯度更新，在自我博弈中不断超越自己。这个阶段完全脱离了人类数据，纯粹靠强化学习提升。第三阶段是**价值网络训练**：用第二阶段产生的大量自我博弈数据，训练价值网络预测每个局面的最终胜负。

推理时，MCTS 在每个节点用策略网络选择值得展开的动作，用价值网络评估展开后的局面，两者的信号加权结合，引导搜索朝着最有价值的方向进行。这是一个经典的"搜索 + 学习"的协作框架，神经网络提供直觉，搜索算法提供系统性。

AlphaGo Zero（2017年）走得更远——**完全不用人类棋谱**，从随机策略出发，纯靠自我博弈强化学习，最终超越了所有使用人类数据的版本。这个结果震撼了整个 AI 领域，因为它暗示：在规则明确的领域，强化学习可以完全绕开人类知识，从零出发到达超人水平。

### 三、连续控制：让机器人学会运动

围棋是离散动作空间（落子位置有限），而机器人控制是连续动作空间（关节角度、力矩是实数值），这需要不同的算法。这里我们重点介绍 **SAC（Soft Actor-Critic）**，因为它是当前连续控制领域最先进且最稳定的算法之一，而且它的设计思想里有一个你会立刻认出来的概念。

SAC 在普通的强化学习目标（最大化累计奖励）上加了一项：**最大化策略的熵**。完整的目标函数是：

J(π)=Eπ[∑t=0∞γt(Rt+1+α⋅H(π(⋅∣st)))]J(π)=Eπ[t=0∑∞γt(Rt+1+α⋅H(π(⋅∣st)))]

其中 H(π(⋅∣st))=−∑aπ(a∣st)logπ(a∣st) 正是你在信息论第一节学过的**香农熵**，α 是温度参数，控制熵正则化的强度。

为什么要最大化策略的熵？这里有一个非常优雅的直觉。熵高意味着策略更随机、更"分散"——在没有强烈倾向的情况下，尽量保持动作的多样性。这实际上是在**自动实现探索**，不需要手动设计 ϵϵ-贪心之类的探索机制。同时，熵正则化使得策略不会过早收敛到一个局部最优动作，保持了足够的灵活性来适应环境的变化。信息论里的熵，在这里以一种完全自然的方式成为了强化学习目标函数的一部分。这再一次印证了信息论是机器学习的数学骨架这个贯穿全系列的主题。

SAC 用了演员-评论家结构，用软更新维护目标网络，策略网络输出连续动作的高斯分布（均值和方差），用重参数化技巧（Reparameterization Trick，和 VAE 里一样的手法）让梯度流过采样操作。下面是核心结构的代码：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SACPolicyNetwork(nn.Module):
    """
    SAC 的策略网络（演员）
    输出连续动作的高斯分布的均值和对数标准差
    而不是像 DQN 那样输出离散动作的 Q 值
    """
    def __init__(self, state_dim, action_dim, hidden_dim=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
        )
        # 均值和对数标准差分别用一个线性层输出
        self.mean_layer = nn.Linear(hidden_dim, action_dim)
        self.log_std_layer = nn.Linear(hidden_dim, action_dim)

    def forward(self, state):
        x = self.net(state)
        mean = self.mean_layer(x)
        # 把 log_std 限制在合理范围内，防止标准差过大或过小
        log_std = self.log_std_layer(x).clamp(-20, 2)
        return mean, log_std

    def sample(self, state):
        """
        重参数化采样：不直接采样动作，而是采样噪声，
        这样梯度可以流过采样操作，反向传播到网络参数
        这和 VAE 里的重参数化技巧完全相同
        """
        mean, log_std = self.forward(state)
        std = log_std.exp()

        # 采样标准噪声，然后缩放——这就是重参数化
        epsilon = torch.randn_like(mean)
        raw_action = mean + std * epsilon

        # 用 tanh 把动作压缩到 [-1, 1]，适配大多数连续控制任务
        action = torch.tanh(raw_action)

        # 计算动作的对数概率（用于策略梯度计算）
        # tanh 变换会改变概率密度，需要加上雅可比修正项
        log_prob = (
            -0.5 * ((raw_action - mean) / std).pow(2)
            - log_std
            - 0.5 * torch.log(torch.tensor(2 * 3.14159))
            - torch.log(1 - action.pow(2) + 1e-6)  # tanh 的雅可比修正
        ).sum(dim=-1)

        return action, log_prob

class SACQNetwork(nn.Module):
    """
    SAC 的价值网络（评论家）
    输入状态和动作，输出 Q 值
    注意：Q 网络把动作也作为输入，因为动作是连续的，无法枚举
    SAC 用两个独立的 Q 网络，取最小值来减少过估计偏差（Double Q-learning 思想）
    """
    def __init__(self, state_dim, action_dim, hidden_dim=256):
        super().__init__()
        # 状态和动作拼接后一起输入
        self.net = nn.Sequential(
            nn.Linear(state_dim + action_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1),  # 输出单个 Q 值
        )

    def forward(self, state, action):
        x = torch.cat([state, action], dim=-1)
        return self.net(x)
```

### 四、深度强化学习的实际挑战

到目前为止，我们讲的大多是算法在受控实验环境里的表现。在真实世界部署深度强化学习，会遇到几个严峻的工程挑战，了解这些挑战和应对策略，比会写算法代码更重要。

**样本效率**是最核心的挑战。DQN 训练 Atari 游戏需要和环境交互 5000 万帧，相当于人类玩 38 天不间断。但游戏模拟器速度很快，可以加速到实时的几百倍，所以实际训练时间是可接受的。但如果环境是真实的机器人——每次交互需要几秒钟，还会产生机械磨损——5000 万次交互根本不可行。提高样本效率的主要方法有三个：经验回放（让每个样本被多次使用）、模型基方法（学习环境模型，在模型里做"想象中的训练"）、以及迁移学习（先在模拟器里训练，再迁移到真实机器人，叫做 Sim-to-Real Transfer）。

**奖励稀疏性**是另一个主要挑战。在很多任务里，大部分时候奖励是 0，只有完成任务时才有奖励——比如机器人搭积木，只有最后成功搭好才得分。智能体很难从零奖励中学到任何有用的信息。应对方法包括**奖励塑形（Reward Shaping）**（设计中间奖励引导学习）、**课程学习（Curriculum Learning）**（从简单任务开始，逐渐增加难度）、以及**内在奖励（Intrinsic Motivation）**（对探索新状态本身给予奖励，即使外部奖励为零）。

**Sim-to-Real Gap** 是机器人强化学习特有的挑战。在模拟器里训练好的策略，迁移到真实机器人时往往表现大幅下降，因为模拟器的物理参数（摩擦力、质量、关节刚度）和真实世界有偏差。应对方法是**领域随机化（Domain Randomization）**：在训练时随机化模拟器的各种参数，让策略对参数变化有足够的鲁棒性，这样它在真实世界里遇到略有不同的物理参数时不会崩溃。

### 五、强化学习与你的机器人视觉背景的交汇

你在 SLAM 和机器人视觉方向打下的基础，和强化学习有几个非常直接的交汇点，这些交汇点代表了当前最前沿的研究方向。

**视觉强化学习（Visual RL）**是把 CNN 或 Transformer 作为强化学习的感知前端，直接从像素学习策略。DQN 就是这个路线的开山之作。在机器人领域，最近的工作（比如 DrQ-v2、R3M）把在大量视频数据上预训练的视觉编码器迁移到机器人控制，让机器人从第一人称视角的图像直接学习操作策略。你的相机模型、特征提取知识，在这里直接适用。

**基于模型的视觉规划（Model-Based Visual Planning）**是更雄心勃勃的方向：让智能体在像素空间里学习世界模型，用这个模型在"想象"中规划未来的动作序列。DreamerV3 就是这个方向的代表，它在一个低维隐空间里学习动力学模型，在隐空间里做规划，然后把计划映射回真实动作。这和你学过的扩散模型有深刻的联系——扩散模型也是在隐空间里做"去噪规划"。

**SLAM + RL 的融合**是最直接和你背景相关的方向。传统 SLAM 给机器人提供地图和定位，强化学习给机器人提供决策策略。最新的工作开始把两者端到端地融合：感知、建图、规划、控制全部在一个神经网络里同时学习，不再是独立的模块。这个方向叫**可学习的导航（Learnable Navigation）**，是自主机器人研究目前最活跃的前沿之一。

### 六、整个强化学习体系的完整地图

走到这里，我们覆盖了强化学习从数学基础到前沿应用的完整路径。让我把三节课的内容压缩成一张清晰的地图，让你看到整个体系的结构。

强化学习的数学基础是 MDP，它用状态、动作、转移、奖励、折扣因子五个要素描述所有的序贯决策问题。贝尔曼方程是 MDP 的核心工具，它把长期问题局部化成递推关系，是所有算法的理论根基。在已知环境模型的情况下，策略迭代和价值迭代可以精确求解 MDP；在未知环境模型的情况下，无模型 RL 通过交互数据来近似求解。

无模型 RL 分两条主线。基于价值的方法（Q-learning → DQN）学习 Q 函数，用神经网络近似处理高维状态空间，经验回放和目标网络是两个关键的稳定性技巧。基于策略的方法（REINFORCE → PPO → SAC）直接学习策略，策略梯度定理给出了可计算的梯度方向，演员-评论家结构结合了两类方法的优点，PPO 的 clip 机制和 SAC 的熵正则化分别用不同方式保证了稳定性和探索性。

深度强化学习把神经网络作为函数近似器，解决了传统强化学习无法处理高维输入的问题。AlphaGo 展示了在离散规则空间里的超人表现，SAC 展示了在连续物理空间里的灵活控制，RLHF 展示了在语言空间里的价值对齐。

### 七、整个课程的最终回顾

我们从第一节的线性回归出发，走到了这里，覆盖了现代机器学习和人工智能的完整技术栈。让我用一个统一的视角来结束这个系列。

贯穿始终的有一个数学主题：**所有的学习，本质上都是在优化某个目标函数**。监督学习优化交叉熵损失（信息论的 KL 散度）；无监督聚类优化簇内方差或 KL 散度（t-SNE、GMM）；无监督降维优化重建误差或解释方差；生成模型优化数据的对数似然（扩散模型的去噪目标等价于最大化 ELBO）；强化学习优化期望折扣累计奖励，用贝尔曼方程分解为局部的 TD 误差。信息论是这些目标函数背后统一的数学语言，而梯度下降是优化这些目标的统一工具。

贯穿始终的还有一个工程主题：**如何把人类的先验知识编码进模型结构、目标函数和训练流程**。CNN 把图像的局部性和平移不变性编码进卷积结构；Transformer 把"任意位置都可以直接关联"编码进注意力机制；VAE 把"隐空间应该平滑连续"编码进 KL 散度正则项；PPO 把"策略不应该突变"编码进 clip 约束；SAC 把"保持探索性"编码进熵正则化。好的深度学习不是暴力拟合，而是把对问题结构的理解转化成模型的归纳偏置。

这条路走到这里，是一个阶段性的终点，也是真正开始的起点。
