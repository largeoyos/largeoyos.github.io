## 第三节：随机变量——把概率从事件提升到函数

欢迎回来！在前两节里，我们一直在处理"事件"这个层面的概率——某件事发生不发生，概率多大。但很快你会发现，只用事件来描述世界是不够的。我们经常需要描述的是**数量**：明天会下多少毫米的雨？这次考试我能考多少分？这只股票明年会涨多少？这些问题的答案不是简单的"是"或"否"，而是一个**数值**，而这个数值本身又是不确定的。要描述这种"数值化的随机现象"，我们就需要一个新工具——**随机变量**。

这一节会比前两节抽象一些，但请你耐心跟我走。一旦掌握了随机变量的思想，你会觉得整个概率论变得通透起来，因为这是从"语言"到"代数"的飞跃，让我们能用数学公式精确刻画各种随机现象。

### 随机变量到底是什么

让我先给你一个直觉的描述，然后再给严格定义。**随机变量本质上是一个数值化的随机结果**。比如你掷一颗骰子，结果可能是 1 到 6 中的任何一个数，这个"将来会出现的点数"就是一个随机变量；你测量某个成年人的身高，结果是某个正实数，这个身高也是一个随机变量。简而言之，凡是"还没发生但将会取到某个数值"的量，都是随机变量。

现在我给你严格的数学定义：**随机变量 X 是从样本空间 Ω 到实数集 R 的一个函数**。也就是说，X 把每个样本点 ω 映射成一个实数 X(ω)。

这个定义初看有点奇怪——为什么"变量"被定义成"函数"？让我解释一下。在确定性数学中，"变量"是一个可以取不同值的符号，比如方程 x2=4 中的 x 可以是 2 或 -2。但在概率论中，"变量"取什么值取决于随机试验的结果——结果出来之前我们不知道，结果出来之后才确定。所以"随机变量"实际上是一个规则，它告诉你"对每一种可能的实验结果，对应的数值是多少"。这个规则就是一个函数。

举个具体例子帮你扎根。掷两颗骰子，样本空间 Ω 是 36 个有序对 (i,j)，其中 i,j∈{1,2,3,4,5,6}i,j∈{1,2,3,4,5,6}。我们可以定义随机变量 X = 两颗骰子的点数之和，那么 X((1,1))=2，X((3,4))=7，X((6,6))=12。X 把每个样本点映射成一个 2 到 12 之间的整数。我们也可以定义另一个随机变量 Y = 两颗骰子点数的最大值，那么 Y((3,4))=4，Y((6,2))=6。同一个样本空间上可以定义无数个随机变量，每个对应一种"我们感兴趣的数值"。

请你停下来理解这个观点：**样本空间是底层的"现实"，随机变量是我们从现实中"提取"出来的数值视角**。这个区分非常重要——一旦你有了随机变量，所有对它的概率描述（比如 P(X=5)、P(X≤7)）都能通过追溯到样本空间来计算。

### 离散型随机变量与概率质量函数

随机变量根据取值情况分成两大类。**离散型**随机变量的取值是可数的——要么是有限多个，要么是无穷多个但能像自然数那样排成一列。比如骰子点数（取 1 到 6）、一年中某路口发生事故的次数（取 0, 1, 2, ...）、抛硬币直到首次出现正面所需的次数（取 1, 2, 3, ...）等等。

描述离散型随机变量的工具是**概率质量函数**（probability mass function，简称 PMF）：

p(x)=P(X=x)

它告诉你 X 取每个具体值的概率。这个函数有两个基本性质：第一，所有概率非负，即 p(x)≥0；第二，所有可能取值的概率加起来等于 1，即 ∑xp(x)=1。这第二条相当于"必然会取到某个值"的概率为 1，是规范性公理的体现。

继续用骰子之和的例子。X 的概率质量函数是这样的：p(2)=1/36（只有 (1,1) 一种），p(3)=2/36（(1,2) 和 (2,1)），p(4)=3/36，p(5)=4/36，p(6)=5/36，p(7)=6/36，p(8)=5/36，p(9)=4/36，p(10)=3/36，p(11)=2/36，p(12)=1/36。把这些概率画成柱状图，你会得到一个对称的"金字塔"形状，最高点在 7。这个图就是随机变量分布的"指纹"，它完整地描述了 X 的概率行为。

### 连续型随机变量与概率密度函数

**连续型**随机变量的取值是不可数的，比如成年人身高（理论上可以是 (0,+∞) 中任何实数）、明天的气温、某个粒子的位置等等。这里出现了一个让初学者非常困惑的现象：**对连续型随机变量，任何单点的概率都是 0**。

为什么？想象一下，如果你随机选一个 [0,1] 区间内的实数，恰好选到 0.5 的概率是多少？由于实数有不可数无穷多个，每个点的"概率"必须无穷小才能让总和为 1——而无穷小本质上就是 0。但这就带来一个问题：如果每个点概率都是 0，那概率到底"在哪里"？

答案是：**概率分布在区间上，而不是点上**。我们用**概率密度函数**（probability density function，简称 PDF）f(x) 来描述，它满足：

P(a≤X≤b)=∫abf(x) dx

也就是说，X 落在区间 [a,b] 内的概率是密度函数在这个区间上的积分（即曲线下方面积）。密度函数本身也有两个基本性质：第一，处处非负，f(x)≥0；第二，全空间积分等于 1，∫−∞+∞f(x) dx=1。

这里我必须强调一个**极易被误解的关键点**：**f(x) 不是概率，只是概率的密度**。它甚至可以大于 1。比如均匀分布在 [0,0.5] 上的密度是 2（因为要让总积分为 1）。打个类比，物质的密度可以是 1000 kg/m³，但具体某一个点没有质量；只有当你考虑一段体积时，密度乘以体积才给出质量。同样，密度乘以一段长度（更准确地说，积分）才给出概率。

请你做一个练习巩固理解：设 X 的密度函数是 f(x)=2x 在 [0,1] 上，其他地方为 0。验证它是合法密度函数（积分为 1），然后计算 P(X≤0.5) 和 P(0.3≤X≤0.7)。答案分别是 1/4 和 0.4。

### 累积分布函数：统一离散和连续

无论是离散还是连续型随机变量，都有一个统一的描述工具叫做**累积分布函数**（cumulative distribution function，简称 CDF）：

F(x)=P(X≤x)

它告诉你 X 不超过 x 的概率。F 有几个重要性质：它是单调不减的（因为 x 增大时事件 {X≤x} 包含更多情况）；它在 −∞−∞ 处取值为 0，在 +∞+∞ 处取值为 1；它是右连续的。

对离散型变量，F 是阶梯函数——在每个取值点向上跳一段，跳跃的高度就是 p(x)。对连续型变量，F 是连续函数，且 F′(x)=f(x)F′(x)=f(x)（密度是分布函数的导数）。这个关系揭示了密度函数的真正含义：**它是分布函数的"瞬时增长率"**，描述概率在每个点附近积累的速度。

为什么我们需要 CDF？因为它统一了离散和连续两种情形，提供了一个通用的描述方式。在数理统计中，许多重要的概念（如分位数、随机变量的变换）都通过 CDF 来定义最自然。

### 几个必须熟悉的离散分布

现在我们来看几个最重要的离散分布。把它们当作"基本词汇"——掌握了这些词汇，你就能描述大量现实中的随机现象。

**伯努利分布**是最简单的非平凡分布，描述只有两种结果（"成功"和"失败"）的单次试验。设成功概率为 p，则 P(X=1)=p，P(X=0)=1−p。抛一次硬币、考试一道题做对与否、产品检测合格与否，都是伯努利试验。它是其他许多分布的"原子"。

**二项分布** B(n,p) 描述 n 次独立伯努利试验中成功的次数。它的概率质量函数是：

P(X=k)=(nk)pk(1−p)n−k,k=0,1,…,nP(X=k)=(kn)pk(1−p)n−k,k=0,1,…,n

这个公式怎么理解？(nk)(kn) 是从 n 次试验中选 k 次成功的方式数；pk(1−p)n−k 是某一种特定"k 次成功 n−k 次失败"序列的概率（因为试验独立，所以概率相乘）；两者相乘就是总概率。比如抛 10 次硬币恰好出现 3 次正面的概率是 (103)(0.5)3(0.5)7=120×1/1024≈0.117(310)(0.5)3(0.5)7=120×1/1024≈0.117。

二项分布的均值是 np，方差是 np(1−p)。直觉上，每次试验平均贡献 p 次成功，n 次累计就是 np，这很合理。

**泊松分布**描述单位时间或空间内"罕见事件"发生的次数，比如某医院一小时内的急诊数、一页书中的错字数、放射性物质单位时间内的衰变数等等。它的参数是 λ>0，概率质量函数是：

P(X=k)=λke−λk!,k=0,1,2,…P(X=k)=k!λke−λ,k=0,1,2,…

泊松分布有个非常优美的性质：**均值和方差都等于 λ**。它和二项分布有深刻的联系——当 n 很大、p 很小、np 适中时，二项分布 B(n,p) 近似于泊松分布 Poisson(np)。这就是为什么"罕见事件"用泊松分布建模——它本质上是大量独立小概率事件的极限情况。

**几何分布**描述独立伯努利试验中"首次成功"所需要的试验次数。P(X=k)=(1−p)k−1p，意思是前 k−1 次失败、第 k 次成功。它的均值是 1/p，符合直觉：成功率越低，等待越久。

### 几个必须熟悉的连续分布

**均匀分布** U(a,b) 是最简单的连续分布，密度在 [a,b] 内是常数 1/(b−a)，外部为 0。它描述"完全无偏好"的随机性，是建模"不知道任何信息时取某个区间内的值"的默认选择。它的均值是 (a+b)/2，方差是 (b−a)2/12。

**指数分布**描述等待某事件首次发生的时间，密度函数是 f(x)=λe−λx 当 x≥0 时（其他地方为 0），参数 λ>0 是"事件发生率"。它的均值是 1/λ（事件发生率越高，平均等待时间越短），方差是 1/λ2。

指数分布有一个独特的性质叫**无记忆性**：P(X>s+t∣X>s)=P(X>t)。意思是说，已经等了 s 时间还没等到，再等 t 时间不发生的概率，和一开始就等 t 时间不发生的概率一样。直白地说，**等待已经花的时间不会让事件"更应该"发生**。这听起来反直觉——我们常觉得"等了这么久了，应该快了吧"——但对真正符合泊松过程的事件（如放射性衰变），这是事实。无记忆性是连续分布中指数分布独有的特征，离散分布中只有几何分布有类似性质。

**正态分布** N(μ,σ2) 是概率论中最重要、最美丽的分布，没有之一。它的密度函数是：

f(x)=1σ2πexp(−(x−μ)22σ2)f(x)=σ2π1exp(−2σ2(x−μ)2)

这个公式看起来吓人，但形状很简单——就是著名的"钟形曲线"。μ 是均值（决定钟的中心位置），σ 是标准差（决定钟的胖瘦），σ2 是方差。当 μ=0、σ=1 时叫**标准正态分布**，记作 N(0,1)，它的密度通常用 φ(x) 表示，分布函数用 Φ(x) 表示。

正态分布有许多优美性质。它关于均值对称；约 68% 的概率集中在 μ±σμ±σ 内，95% 在 μ±2σμ±2σ 内，99.7% 在 μ±3σμ±3σ 内（这就是著名的"68-95-99.7 法则"）；正态分布的线性组合还是正态分布；任意正态变量都可以通过 Z=(X−μ)/σ 标准化为标准正态。

为什么正态分布如此重要？现实中身高、体重、考试成绩、测量误差、IQ、布朗运动的位置等无数现象都近似服从正态分布。这背后的根本原因是**中心极限定理**——大量独立小因素累加的结果总是近似正态。我们会在后面专门讲这个深刻的定理。

### 期望与方差：随机变量的"重心"和"散度"

光有分布还不够，我们经常想用一两个数字概括随机变量的关键特征。最重要的两个特征是期望和方差。

**期望** E(X) 是随机变量的"平均值"或"重心"，是分布的中心位置。对离散型，E(X)=∑x⋅p(x)；对连续型，E(X)=∫−∞+∞xf(x) dx。可以把它想象成一根质量分布的杠杆——每个取值 x 处放着质量 p(x)（或密度 f(x)），E(X) 就是这根杠杆的平衡点。

期望最重要的性质是**线性性**：E(aX+bY)=aE(X)+bE(Y)，无论 X 和 Y 是否独立。这个性质极其有用——它让我们可以把复杂随机变量分解成简单部分逐个求期望。比如二项分布 X∼B(n,p)X∼B(n,p) 可以看成 n 个独立伯努利变量之和 X=X1+⋯+XnX=X1+⋯+Xn，每个 Xi 期望是 p，所以 E(X)=np，比直接用定义算简单得多。

**方差** Var(X)=E[(X−E(X))2]Var(X)=E[(X−E(X))2] 衡量随机变量围绕均值的分散程度。它的平方根 σ=Var(X) 叫**标准差**，量纲和 X 相同，更有直观意义。一个非常实用的计算公式是：

Var(X)=E(X2)−[E(X)]2

这个公式比定义式好用得多。

方差有两个关键性质需要记牢：第一，Var(aX+b)=a2Var(X)——常数平移不改变方差，乘以常数则方差按平方变化。第二，对独立的 X 和 Y，Var(X+Y)=Var(X)+Var(Y)。注意这里**独立性是必需的**——一般情形下要加上协方差项，我们下一节再讲。

### 这一节的核心洞见

让我们提炼这一节的精华。随机变量是从样本空间到实数的函数，它把"事件层面的概率"提升到"数值层面的概率"，让我们能用代数和微积分工具处理随机现象。离散型用 PMF 描述，连续型用 PDF 描述，CDF 是统一两者的工具。常见分布——伯努利、二项、泊松、均匀、指数、正态——是描述随机现象的"基本词汇"，每个都对应一类典型的真实场景。期望和方差是分布的两个最重要数字特征，分别表示"中心位置"和"分散程度"。

最深的洞见在于：**随机变量的分布完整地编码了它的所有概率信息**。如果你知道 X 的分布，你就知道 X 的一切——包括它落在任何区间的概率、它的均值方差、它的各种变换的分布等等。这就是为什么后面整门课的核心都围绕"如何描述、识别、估计随机变量的分布"展开。

## 第四节：多维随机变量——当随机性不只有一个维度

欢迎回到第四节！前三节我们一直在研究"单个随机变量"——一次试验产生一个数值。但现实世界远比这复杂。一个人的身高和体重同时随机；一只股票的今日涨跌和明日涨跌相互关联；一次工厂检测同时产生温度、压力、湿度三个随机读数。**当我们需要同时研究多个随机变量，以及它们之间的相互关系时，单变量的工具就不够用了。**

这一节的核心问题是：**两个随机变量同时存在时，我们如何描述它们的整体行为？它们之间的关联是什么？如何从整体中提取单个变量的信息？** 回答这些问题，需要引入联合分布、边缘分布、条件分布、协方差与相关系数等工具。这些概念是后续讲大数定律、统计推断、回归分析的直接基础，因此值得我们仔细打磨。

### 从一维到二维：联合分布的直觉

先做一个思想实验。你有一个随机变量 X（比如一个人的身高），有一个随机变量 Y（比如同一个人的体重）。如果我只告诉你 X 的分布——比如身高服从 N(170,102)——以及 Y 的分布——体重服从 N(65,82)——你能知道"身高超过 180cm 且体重超过 80kg"的概率吗？

答案是**不能**，除非你还知道身高和体重之间的关联结构。如果身高和体重高度正相关，那么高个子重的人多，这个联合概率就大；如果两者独立，联合概率就等于两个边缘概率的乘积；如果是奇异的负相关（高个子反而轻），联合概率就小。**两个变量各自的分布，并不能决定它们的联合分布。**

这就是为什么我们需要**联合分布**——它是对两个（或多个）随机变量整体概率行为的完整描述。

### 二维离散型：联合概率质量函数

对两个离散型随机变量 X 和 Y，它们的**联合概率质量函数**（joint PMF）定义为：

p(x,y)=P(X=x,Y=y)

也就是 X 和 Y 同时取特定值的概率。把它想象成一张二维表格：行表示 X 的取值，列表示 Y 的取值，每个格子里填的是两者同时取该值的概率。所有格子里的数必须非负，且全部相加等于 1。

让我用一个具体例子让这个概念完全清晰。设 X 是随机掷一颗骰子的结果，Y 是"X 是否为偶数"（偶数时 Y=1，奇数时 Y=0）。它们的联合 PMF 如下：当 X=1 时，Y 只能是 0，p(1,0)=1/6，p(1,1)=0；当 X=2 时，Y 只能是 1，p(2,1)=1/6，p(2,0)=0；以此类推。注意这里 X 和 Y 高度相关——Y 完全由 X 决定，一点"独立"的成分都没有。我这里是用一个极端例子帮你感受：联合分布包含的信息，远超过两个边缘分布单独携带的信息之和。

### 边缘分布：从整体中"提取"单个变量

有了联合分布之后，如果我只想知道 X 单独的分布，该怎么办？答案是**对 Y 的所有可能取值求和（或积分）**，把 Y 的信息"消掉"。这个过程叫做**边缘化**，得到的单变量分布叫**边缘分布**（marginal distribution）。

对离散情形，X 的边缘 PMF 是：

pX(x)=∑yp(x,y)pX(x)=y∑p(x,y)

对连续情形，X 的边缘 PDF 是：

fX(x)=∫−∞+∞f(x,y) dy

"边缘"这个名字来自历史上的做法——把联合分布写成表格，然后在表格的边缘（最后一行或最后一列）写上行/列的汇总，这个汇总就是边缘分布。

这里有一个极其重要且常被忽视的方向性：**从联合分布可以唯一确定边缘分布，但从两个边缘分布无法唯一确定联合分布。** 边缘化是一个"有损"的操作——它丢失了两个变量之间的关联信息。这就像你知道一个班所有同学的数学成绩分布，以及语文成绩分布，但你不知道"数学好的是不是也语文好"，只有联合分布才能告诉你这件事。

### 条件分布：在已知某个变量的情况下另一个如何分布

你还记得第二节的条件概率吗？那是"在事件 B 发生的条件下事件 A 的概率"。现在我们把同样的思想推广到随机变量层面：**在已知 Y=y 的条件下，X 的分布是什么？**

这就是**条件分布**。对离散情形，X 在 Y=y 条件下的条件 PMF 是：

pX∣Y(x∣y)=P(X=x∣Y=y)=p(x,y)pY(y)pX∣Y(x∣y)=P(X=x∣Y=y)=pY(y)p(x,y)

这个公式和第二节的条件概率公式完全类比——分子是联合概率，分母是"条件"对应的边缘概率，相当于把概率空间缩小到 Y=y 的那个"切片"里，再做归一化。

条件分布在统计和机器学习中极为重要。比如在贝叶斯统计中，我们研究的核心就是"在观察到数据 Y 的条件下，参数 θ 的分布"，这正是条件分布的思想。在回归分析中，"在 X=x 的条件下 Y 的期望"就是回归函数 E(Y∣X=x)，它描述了 Y 随 X 变化的趋势。

### 独立性：最干净的关系

两个随机变量 X 和 Y 是**独立的**，当且仅当它们的联合分布等于两个边缘分布的乘积：

p(x,y)=pX(x)⋅pY(y)(离散情形)p(x,y)=pX(x)⋅pY(y)(离散情形)f(x,y)=fX(x)⋅fY(y)(连续情形)f(x,y)=fX(x)⋅fY(y)(连续情形)

独立性意味着：知道 Y 的取值，对 X 的分布毫无影响。在独立情形下，条件分布等于边缘分布——这正是"无关"的精确数学表达。独立性是数学上最简洁的假设，大数定律和中心极限定理都建立在独立性的基础上。

但请你时刻保持警惕：**现实中的随机量很少是真正独立的**。同一地区不同人的收入受共同经济环境影响；同一只股票在不同时段的涨跌有时间序列依赖；同一工厂不同产品的质量受共同生产条件影响。独立性是一种"理想假设"，应用时需要认真评估是否合理。

### 协方差：量化线性关联的方向和强度

现在我们到了这一节最核心的部分。两个随机变量之间的关联，如何用一个数字来衡量？

最自然的出发点是这样的想法：如果 X 偏大（超过 E(X)）时 Y 也偏大（超过 E(Y)），那么乘积 (X−E(X))(Y−E(Y)) 就是正的；反之，X 偏大而 Y 偏小时，乘积是负的。把这个乘积取期望，就得到了**协方差**：

Cov(X,Y)=E[(X−E(X))(Y−E(Y))]

协方差为正表示 X 和 Y 倾向于"同向"偏离各自均值（正相关）；协方差为负表示倾向于"反向"偏离（负相关）；协方差为零说明没有线性关联。

和方差一样，有一个更实用的计算公式：

Cov(X,Y)=E(XY)−E(X)⋅E(Y)

这个公式的推导是直接展开期望定义，请你自己动手验证一遍，这个过程本身就是很好的练习。

协方差有几个性质需要牢记。首先，Cov(X,X)=Var(X)——自己和自己的协方差就是方差，这很自然。其次，协方差是对称的：Cov(X,Y)=Cov(Y,X)。第三，协方差是双线性的：Cov(aX+b,cY+d)=ac⋅Cov(X,Y)，平移不影响协方差，但缩放会按乘积传递。第四，如果 X 和 Y 独立，则 Cov(X,Y)=0——因为独立时 E(XY)=E(X)⋅E(Y)。

这最后一点给了我们一个推论：**对独立随机变量，方差可以相加**，Var(X+Y)=Var(X)+Var(Y)。更一般地：

Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y)

这个公式非常重要。它告诉你，两个变量之和的分散程度，不只取决于各自有多"散"，还取决于它们是否"同步波动"。如果正相关（Cov>0），合并后更散；如果负相关，合并后反而更集中。这正是投资组合多元化的数学原理——把资产分散到负相关的投资上，整体波动性（风险）会降低。

### 相关系数：协方差的无量纲化版本

协方差有一个实践中的缺点：它的数值依赖于 X 和 Y 各自的尺度。比如身高（厘米）和体重（千克）的协方差，换成身高（米）和体重（克）之后数值会完全不同，但背后的关联关系并没有改变。为了得到一个与尺度无关、便于比较的指标，我们把协方差除以两个标准差的乘积：

ρ(X,Y)=Cov(X,Y)σX⋅σYρ(X,Y)=σX⋅σYCov(X,Y)

这就是**（皮尔逊）相关系数**。可以证明 −1≤ρ≤1。当 ρ=1 时，X 和 Y 完全正线性相关（存在 a>0 使得 Y=aX+b 几乎处处成立）；当 ρ=−1 时完全负线性相关；当 ρ=0 时称为"不相关"，意思是没有**线性**关联。

这里我必须特别强调一个常见的重大误解：**不相关不等于独立**。相关系数只衡量线性关系，可能完全错过非线性依赖。举一个极端例子：设 X∼U(−1,1)X∼U(−1,1)，令 Y=X2。显然 Y 完全由 X 决定，两者高度依赖。但可以计算 Cov(X,Y)=E(X⋅X2)−E(X)⋅E(X2)=E(X3)−0⋅E(X2)=0（因为 X3 关于 0 对称，期望为 0）。所以相关系数为 0，但两者根本不独立！

相关系数为 0 只排除了线性依赖，非线性依赖仍然可能存在。在数据分析中，仅靠相关系数就下结论是危险的，这也是为什么探索性数据分析需要画散点图——图形能揭示相关系数抓不到的非线性模式。

### 二维正态分布：最重要的多元分布

就像一维情形中正态分布是最重要的连续分布，多维情形中**多元正态分布**也处于核心地位。我们重点看二维情形，它的联合密度函数是：

f(x,y)=12πσXσY1−ρ2exp(−12(1−ρ2)[(x−μX)2σX2−2ρ(x−μX)(y−μY)σXσY+(y−μY)2σY2])f(x,y)=2πσXσY1−ρ21exp(−2(1−ρ2)1[σX2(x−μX)2−σXσY2ρ(x−μX)(y−μY)+σY2(y−μY)2])

这个公式初看吓人，但结构很清晰：它由五个参数完全确定——X 的均值 μX、Y 的均值 μY、X 的标准差 σX、Y 的标准差 σY、以及两者的相关系数 ρ。当 ρ=0 时，指数部分可以分解成两个独立部分，f(x,y) 等于 fX(x)⋅fY(y)——**对二维正态分布来说，不相关等价于独立**。这是二维正态的特殊性质，一般情形下不成立。

二维正态分布的图形是一个"山丘"：正视方向是一个钟形，俯视方向的等高线是椭圆。当 ρ>0 时，椭圆的长轴沿 45° 方向，表示 X 大时 Y 也倾向于大；当 ρ<0 时，椭圆长轴沿 135° 方向；当 ρ=0 时，椭圆退化为圆形。这个几何图像给了我们一个直观感受：**相关系数 ρ 控制着联合分布的"倾斜程度"**。

### 随机变量的函数：变换之后的分布

最后我们来讨论一个实用的问题：如果 X 已知分布，那么 Y=g(X) 的分布是什么？或者如果 X,YX,Y 已知联合分布，Z=X+Y 的分布是什么？

对离散情形，这很直接——枚举 g(X) 的所有取值，把对应的概率相加即可。连续情形稍微复杂，最系统的方法是**分布函数法**：先写出 Y 的 CDF，FY(y)=P(Y≤y)=P(g(X)≤y)，把后者化成关于 X 的事件概率来计算，最后对 y 求导得到密度 fY(y)。

一个特别重要的特例是**两个独立随机变量之和**。设 X,YX,Y 独立，Z=X+Y，则 Z 的密度是 X 和 Y 密度的**卷积**：

fZ(z)=∫−∞+∞fX(x)fY(z−x) dx

这个公式的直觉是：Z=z 可以由无数种方式实现（X=x，Y=z−x，x 可以任意），对所有方式的概率积分起来就得到 Z=z 的密度。

卷积运算有两个漂亮的结果值得记住。第一，**两个独立正态分布的和仍然是正态**：X∼N(μ1,σ12)X∼N(μ1,σ12)，Y∼N(μ2,σ22)Y∼N(μ2,σ22) 独立，则 X+Y∼N(μ1+μ2,σ12+σ22)X+Y∼N(μ1+μ2,σ12+σ22)——均值相加，方差相加。第二，**两个独立泊松分布的和仍然是泊松**：X∼Poisson(λ1)X∼Poisson(λ1)，Y∼Poisson(λ2)Y∼Poisson(λ2) 独立，则 X+Y∼Poisson(λ1+λ2)X+Y∼Poisson(λ1+λ2)。这些"稳定性"（closure properties）是这两个分布之所以特别重要的原因之一。

### 这一节的核心洞见

让我们提炼这一节的精华。联合分布是对多个随机变量整体行为的完整描述，它包含的信息超过各边缘分布的信息之和——因为它还包含了变量之间的关联结构。边缘分布是从联合分布通过"消去"某些变量得到的，这个操作是有损的。条件分布是在固定某个变量的条件下另一个变量的分布，它把第二节的条件概率思想推广到了随机变量层面。协方差和相关系数量化两个变量之间的线性关联，但相关系数为零只排除线性依赖，不排除非线性依赖，也不等于独立。

这一节最需要你内化的思想是：**两个随机变量之间的关系，是整个概率论和统计学的核心研究对象**。从这里出发，你会看到回归分析研究"Y 如何随 X 变化"，时间序列研究"随机过程在不同时刻的关联"，主成分分析研究"如何找到高维变量的主要关联方向"，这一切都根植于这一节的概念。
