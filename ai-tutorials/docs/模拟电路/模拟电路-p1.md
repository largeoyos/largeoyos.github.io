### 模拟电路的全景地图

模拟电路研究的是**连续变化的电信号**(相对于只有0和1的数字电路)。整门课其实围绕一个核心问题展开:

> **怎样用电子元件,把一个微弱的、带噪声的、形状不好的电信号,变成我们想要的样子?**

"想要的样子"可能是:更大(放大器)、更干净(滤波器)、更稳定(稳压电源)、更有特定形状(振荡器、比较器)……

整门课的知识大致是这样一层层叠起来的:

```
第 4 层:系统应用(运放电路、滤波器、振荡器、电源)
            ↑
第 3 层:核心器件(运算放大器 Op-Amp)
            ↑
第 2 层:有源器件(二极管、BJT三极管、MOS管)
            ↑
第 1 层:无源器件 + 分析方法(电阻、电容、电感 + 交流分析、相量、频率响应)
            ↑
第 0 层:基础(你已有的:KCL/KVL、欧姆定律)
```

我们会一层一层往上走。**每一层都必须牢固,否则上面会塌**——这是模电这门课很多人学崩的主要原因:他们在第2层还没懂的时候,老师已经在讲第4层了。

### 开始之前,先验证一个关键概念

在进入正文前，先用自己的语言思考以下基础问题：

**问题:电压和电流,本质上分别是什么?它们有什么区别?**

很多人会说"电压推动电流",这句话对,但是太表面。我想听你说说你理解的电压和电流——它们描述的是什么物理现象,它们在电路中扮演什么角色?

你可以用类比(比如水流),也可以用物理概念(电荷、电场、势能),怎么说都行。我想看看你的直觉在什么层面,然后我们从那里出发。
## 第 1 课:电压、电流、功率——比你想象的更深

### 1.1 电荷是起点

一切电学现象的源头是**电荷**。电子带负电,质子带正电,电荷之间通过**电场**相互作用。

一个电荷 q 处在电场中,就具有**电势能**——就像一个物体处在重力场中具有重力势能一样。这个类比非常重要,我们后面会反复用。

### 1.2 电压 = 单位电荷的势能差

**电压(电位差)的本质定义**:

UAB=WABqUAB=qWAB

意思是:把一个电荷 q 从 A 点移动到 B 点,电场力做的功是 WAB ,那么 A、B 两点之间的电压就是"每单位电荷的能量差"。

单位:1 伏特 = 1 焦耳 / 1 库仑。

**关键理解**:

- 电压是"**两点之间**"的量,说"A 点的电压"其实是默认了一个参考点(通常是地)
- 电压描述的是**能量差**,不是能量本身
- 电压的存在**不依赖于电流**——一节电池放在桌上没接任何东西,它两端照样有 1.5V 电压

用水的类比:电压 ≈ **两点之间的水位差**(高度差)。水位差存在,水**不一定**在流;但水要流,必须有水位差。

### 1.3 电流 = 电荷的流动速率

I=dqdtI=dtdq

单位:1 安培 = 1 库仑 / 秒。

**关键理解**:

- 电流是**一个时刻、一个截面上**流过的电荷速率
- 电流方向规定为**正电荷流动的方向**(这是历史遗留,实际上金属中流动的是电子,方向相反——你就记住这个约定即可)
- 电流是"穿过"一个点/截面的量,电压是"两点之间"的量——**这个区别很重要**

用水的类比:电流 ≈ **水管某个截面每秒流过的水量**。

### 1.4 电压与电流的关键区别(很多人模糊的地方)

||电压 U|电流 I|
|---|---|---|
|描述|两点间的"势差"|一点处电荷的流速|
|数学性质|跨接(across)量|穿过(through)量|
|测量方式|电压表**并联**接在两端|电流表**串联**接在回路中|
|独立存在?|可以独立存在(开路电池)|没有闭合回路就没有稳态电流|

**为什么电压表并联、电流表串联?** 因为电压是两点之间的量,必须同时接触两个点;电流是穿过某处的量,必须让它"穿过"电流表。这不是规定,是由它们的物理定义决定的。

### 1.5 功率 = 电压 × 电流

P=UI

为什么?推一下就清楚了:

P=dWdt=dWdq⋅dqdt=U⋅IP=dtdW=dqdW⋅dtdq=U⋅I

第一步:功率是能量的时间变化率。 第二步:链式法则。 第三步:dW/dq 就是电压(每单位电荷的能量),dq/dt 就是电流。

单位:1 瓦特 = 1 伏 × 1 安 = 1 焦耳/秒。

一个元件"消耗"多少能量,就看它两端的电压和流过它的电流的乘积。

---

### 1.6 关联参考方向(一个坑)

这是中国模电教材特别强调、但学生经常混的地方。

当我们写 P=UI 时,结果的正负有物理含义:

- **关联参考方向**:电流的参考方向从电压的"+"端流入元件 → P=UI ,P>0 表示元件**吸收**功率(耗能),P<0 表示**发出**功率(供能)。
- **非关联参考方向**:电流从"−"端流入 → P=−UI ,符号反过来。

```
关联参考方向:                非关联参考方向:

    + ─────┐                     + ─────┐
    │      │   I →               │      │   ← I
    U   [元件]                   U   [元件]
    │      │                     │      │
    − ─────┘                     − ─────┘

    P = UI                       P = −UI
```

**为什么需要这个约定?** 因为在复杂电路里,你一开始不知道电流实际往哪流、哪端电位高。你**先假设**一个参考方向,算完之后看符号:正号说明假设对了,负号说明实际方向相反。这是一套让你"不用猜"的工程语言。

记住一句话:**参考方向是人为假设的,真实方向由计算结果的正负决定**。

---

### 1.7 小结(这一课你必须带走的东西)

1. **电压是两点间单位电荷的能量差**,它描述"推动电荷的势"。
2. **电流是电荷流动的速率**,它描述"实际在动多少电荷"。
3. **电压可以独立存在,稳态电流必须有闭合回路**。
4. **功率 P=UI 来自链式法则**,不是凭空规定。
5. **关联参考方向下 P>0 表示吸收功率**——这是判断一个元件是"电源"还是"负载"的方式。

## 第 2 课:半导体与 PN 结——模拟电路的物理起点

模拟电路所有的"神奇"都来自一类器件:**半导体器件**。二极管、三极管、MOS 管——它们全都建立在**PN 结**这一个物理结构上。不理解 PN 结,后面全是死记硬背。

### 2.1 为什么叫"半导体"

导体(如铜)自由电子多,随便导电;绝缘体(如玻璃)几乎没有自由载流子,不导电。**半导体**(硅 Si、锗 Ge)介于两者之间——它的"导电能力"可以通过**掺杂**和**外加电场**来精确控制。

**这个"可控性"就是整个电子学的根基**。如果没有半导体,你就不可能用一个小信号去控制一个大信号,也就没有放大、没有运算、没有数字逻辑。

### 2.2 本征半导体与载流子

纯净的硅是**本征半导体**。硅原子最外层有 4 个价电子,彼此形成共价键构成晶格。

在绝对零度,所有电子都被束缚,不导电。温度升高,一部分电子获得能量挣脱共价键,成为**自由电子**(带负电),同时在原位置留下一个**空穴**(可以看作带正电的"缺位")。

**关键**:半导体中有**两种载流子**——电子和空穴。这和金属只有电子导电不一样,也是半导体器件能做出各种花样的根本原因。

本征半导体里,电子浓度 n 和空穴浓度 p 相等,都等于本征浓度 ni。室温下硅的ni≈1.5×1010 cm−3——这个数字很小,所以本征硅导电能力很弱。

### 2.3 掺杂:制造 N 型和 P 型

**N 型半导体**:在硅里掺入 5 价元素(如磷 P)。磷的 4 个价电子和硅成键,**多出 1 个电子几乎是自由的**。这样 N 型材料里电子浓度 ≫≫ 空穴浓度,电子是**多数载流子**。

**P 型半导体**:掺入 3 价元素(如硼 B)。硼少 1 个电子,留下一个空穴。P 型里空穴是多数载流子。

**重要关系**:在热平衡下,n⋅p=ni2 始终成立(**质量作用定律**)。掺杂只改变 n 和 p 的比例,不改变它们的乘积。

```
N 型硅                     P 型硅

 Si─Si─Si─Si              Si─Si─Si─Si
 │  │  │  │               │  │  │  │
 Si─P─Si─Si   ← 多出电子    Si─B─Si─Si   ← 多出空穴
 │  │• │  │               │  ○│ │  │
 Si─Si─Si─Si              Si─Si─Si─Si
```

### 2.4 PN 结的形成——这里是关键

把 N 型和 P 型半导体**紧密接触**(实际上是在同一块硅上通过不同掺杂工艺形成),接触面就是**PN 结**。

接触瞬间会发生什么?

**第 1 步:扩散**。N 区电子浓度高,向 P 区扩散;P 区空穴浓度高,向 N 区扩散。这是**浓度梯度驱动的扩散**,就像墨水滴入清水。

**第 2 步:形成耗尽区**。电子跑到 P 区后和空穴复合,留下 N 区边上**不可移动的正离子**(磷失去电子变成正离子);空穴跑到 N 区同理留下**负离子**。接触面附近形成一个没有自由载流子、只剩固定离子的区域——**耗尽区(空间电荷区)**。

**第 3 步:产生内建电场**。N 侧正离子、P 侧负离子,形成从 N 指向 P 的**内建电场 E0 **。这个电场**阻止扩散继续**——它把电子往 N 推,把空穴往 P 推。

**第 4 步:达到平衡**。扩散电流(浓度梯度驱动)和漂移电流(内建电场驱动)大小相等、方向相反,净电流为零。此时 PN 结两侧存在一个**内建电势差 Vbi ** ≈ 0.7V(硅)。

```
         耗尽区
    ┌──────┼──────┐
    │  P   │   N  │
    │ ○ ○ ○│⊕ ⊕ ⊕ │
    │ ○ ○ ⊖│⊕ • • │
    │ ○ ○ ⊖│⊕ • • │   ⊖⊕:不动的离子
    │      │      │    ○:空穴, •:电子
    └──────┼──────┘
           │
      E₀ ←─┤ (内建电场, N→P 方向)
           │
    └──V_bi ≈ 0.7V──┘
```

**⚠️ 容易搞混的点**:虽然 N 区电子多、P 区空穴多,但 N 区整体是**电中性**的——电子和磷离子电荷平衡。只有在**耗尽区内**,因为载流子被扫走了,固定离子才表现出净电荷。

### 2.5 PN 结的单向导电性

现在给 PN 结加外部电压,这才是真正有用的部分。

#### 正向偏置(P 接正极,N 接负极)

外电场方向与内建电场**相反**,削弱内建电场。扩散电流占上风——电子从 N 源源不断注入 P 区,空穴从 P 注入 N 区——**大量电流流过**,且外加电压稍微增加,电流指数式增大。

#### 反向偏置(P 接负极,N 接正极)

外电场与内建电场**同向**，耗尽区加宽，内建电场增强。扩散几乎停止，只剩下极微弱的**反向饱和电流 $I_S$**（来自少数载流子漂移），数量级为 nA～pA，可以近似视为零。

**这就是 PN 结的核心性质:单向导电性**——正向导通,反向截止。

### 2.6 肖克利方程——把物理变成公式

PN 结的 I-V 关系由**肖克利方程**描述:

iD=IS(evD/(nVT)−1)

其中:

- $I_S$：反向饱和电流（很小，约为 $10^{-12}\,\text{A}$ 量级）
- vD :PN 结两端电压(P 端相对 N 端为正)
- VT=kT/q :**热电压**,室温(300K)下 ≈26 mV
- n :理想因子,通常 1~2,分析时常取 1

**三种典型工作状态**:

|状态|条件|近似|
|---|---|---|
|正向导通|vD>0 且 vD≫VTvD≫VT|iD≈IS⋅evD/VT (指数增长)|
|零偏|vD=0|iD=0|
|反向截止|vD<0 且 $\lvert v_D \rvert$

画出来是这样:

```
     i_D ↑
         │           ╱
         │          ╱   ← 正向指数增长
         │         ╱
    ─────┼─────╱──────────→ v_D
         │   ╱ ↑
         │ ╱   ~0.7V(硅的"开启电压")
    ─────┼─ ~−I_S (反向饱和,极小)
         │
         │        击穿 ↓
         │  ───────────┐
         │             │ ← 反向击穿
         │             │
```

### 2.7 "开启电压 0.7V"从哪来

从肖克利方程你就能看出来:iD 对 vD 是**指数**关系。电压从 0.6V 升到 0.7V,电流增大约 e(0.7−0.6)/0.026≈47 倍。

所以在实际电路里,**一旦 vD 超过约 0.6~0.7V,电流急剧增大**,几乎就"钉死"在 0.7V 附近——这不是因为存在一个真正的阈值,而是因为**指数函数实在太陡**。工程上近似为"硅二极管导通压降约 0.7V"。

### 2.8 反向击穿

反向电压过大时,耗尽区的电场极强,电子被加速撞击原子,产生链式电离——**雪崩击穿**。或者非常薄的 PN 结里,强电场直接把共价键电子"拽"出来——**齐纳击穿**。

击穿本身不一定烧毁器件,只要功率 P=vDiD 不超标即可。**稳压二极管(齐纳管)就是专门工作在反向击穿区的**——因为击穿时电压几乎恒定,可以用来稳压。

---

### 这一课你必须带走的东西

1. **半导体有两种载流子:电子(N型多)和空穴(P型多)**。掺杂控制多数载流子类型。
2. **PN 结的本质**:扩散形成耗尽区,耗尽区的固定离子产生内建电场,达到扩散—漂移动态平衡。
3. **单向导电性**:正向偏置削弱内建电场 → 导通;反向偏置加强内建电场 → 截止。
4. **肖克利方程** iD=IS(evD/VT−1) 是 PN 结的"万物之源",VT≈26 mV 要记住。
5. **0.7V 导通电压是指数函数的"工程近似"**,不是一个硬阈值。

## 第 3 课:二极管——从物理到电路的第一步

上一课我们搞清楚了 PN 结的物理本质。把 PN 结封装起来,加上两个引脚,就是**二极管(Diode)**。

但是——**知道肖克利方程不等于会分析电路**。你在做题时如果每次都去解指数方程,会崩溃。工程上的做法是:**根据精度需要,用不同层次的"模型"去近似真实二极管**。这是模电的核心思想之一:**建模与近似**。

### 3.1 二极管的符号与命名

```
        阳极 (Anode, A)         阴极 (Cathode, K)
         ───┤▶├───
              P  N

     i_D 方向 →(正向电流由 A 流向 K)
     v_D 极性: +(A) ─ −(K)
```

三角形箭头指向的方向就是**正向电流**方向,也就是 P→N。阴极端通常有一条横杠(对应符号里的竖线),实物上常用色环或凹槽标记。

---

### 3.2 三种分析模型——核心内容

这是这节课的灵魂。**同一个二极管,根据场景不同,用不同的模型**。

#### 模型 A:理想二极管模型(最粗糙)

**把二极管想象成一个"单向开关"**:

- 正向偏置(vD>0 的趋势):**短路**(相当于导线,vD=0)
- 反向偏置(vD<0 的趋势):**开路**(相当于断路,iD=0)

```
    i_D ↑
        │
        │  │  ← 导通后任何电流都行,压降为 0
        │  │
    ────┼──┼────→ v_D
        │
   截止时 i_D = 0
```

**什么时候用?** 电路里的电压远大于 0.7V(比如几十 V 的电源),或者你只想定性判断"导不导通",0.7V 的误差可以忽略。

#### 模型 B:恒压降模型(最常用)

**认为二极管导通时两端电压恒为 0.7V**(硅管;锗管是 0.3V,现在几乎不用):

- 导通:vD=0.7V,电流由外电路决定
- 截止:iD=0,电压由外电路决定

```
    i_D ↑
        │
        │      │  ← 导通后竖直上升
        │      │
    ────┼──────┼────→ v_D
        │    0.7V
```

等效电路:导通时相当于**一个 0.7V 的电池**,截止时相当于**断路**。

**什么时候用?** 这是模电课本上和工程中最常用的模型。绝大多数"分析这个电路里二极管导不导通,电流多大"的题目,都用这个模型。

#### 模型 C:折线模型(带正向电阻 rD)

恒压降模型把 I-V 曲线的导通段画成竖线,但实际上是有一定斜率的——电流越大,压降会稍微增加一点。引入一个**正向导通电阻 rD **:

- 导通:vD=Von+iD⋅rD,其中 Von≈0.6V,rD 几欧到几十欧
- 截止:iD=0

等效电路:导通时 = 一个 0.6V 电池 + 一个小电阻 rD 串联。

**什么时候用?** 大电流场合或需要稍高精度时。课程里出现不多,但要知道有这个模型。

#### 模型 D:小信号模型(非常重要,后面还会深挖)

当二极管**工作在某个直流偏置点 (VD,ID) 上,再叠加一个微小的交流信号**时,我们不关心整个 I-V 曲线,只关心**工作点附近的局部斜率**。

把肖克利方程在 Q 点处泰勒展开(你数分学过):

iD=ISevD/VT⇒diDdvD∣Q=ISeVD/VT=IDVTiD=ISevD/VT⇒dvDdiDQ=VTISeVD/VT=VTID

这个斜率的倒数就是**动态电阻(小信号电阻)** rd:

rd=VTID≈26 mVIDrd=IDVT≈ID26mV

比如二极管偏置电流 ID=1 mA 时,rd≈26 Ωrd≈26Ω。

**这个公式极其重要**,后面讲三极管放大器时还要用到完全一样的思想——我们把它叫做**"大信号分析 + 小信号分析"的二元方法**,是整个模电的基本功。

### 3.3 直流分析的标准套路

给你一个含二极管的电路,求各点电压电流,怎么做?

**步骤**:

1. **假设**每个二极管的状态(导通 or 截止)
2. 按假设**替换成等效电路**(导通→0.7V 电池,截止→开路)
3. 用 KCL/KVL 求解
4. **验证假设**:
 - 如果假设导通,验证 iD>0
 - 如果假设截止,验证 vD<0.7V
5. 如果验证失败,换假设重做

**例题 1:简单判断**

```
    +10V ──[R=1kΩ]──┬──┤▶├── 0V (地)
                    │
                   V?
```

10V 通过 1kΩ 电阻和二极管连到地。二极管阳极接 R,阴极接地——如果导通,电流从 +10V 经 R 经二极管到地,是正向。

**假设导通**:二极管两端 0.7V,R 两端 10−0.7=9.3V,I=9.3V/1kΩ=9.3 mA > 0 ✓

假设成立。V 点电压 = 0.7V,电流 = 9.3 mA。

**例题 2:反向的情况**

```
    −10V ──[R=1kΩ]──┬──┤▶├── 0V
                    │
                   V?
```

这次电源是 −10V。阳极试图被拉到低电位,阴极接地——这会让二极管反偏。

**假设截止**:iD=0,R 上无压降,V = −10V。二极管两端电压 vD=VA−VK=−10−0=−10V < 0.7V ✓

假设成立。二极管截止,电路无电流。

### 3.4 整流电路——二极管的经典应用

**整流(Rectification)**:把交流变成直流(或至少是单向脉动的电流)。这是所有电源电路的第一步。

#### 半波整流

```
     ~       ┤▶├          ┌────────┐
   AC 源 ───┬──┬─── R_L ───┤负载     │
             正  负           └────────┘
```

变压器次级输出正弦电压 vs=Vmsin(ωt)。

- **正半周**(vs>0):二极管正偏导通,电流流过 RL,输出 vo≈vs−0.7V
- **负半周**(vs<0):二极管反偏截止,vo=0

波形:

```
输入 v_s:   ∿∿∿∿∿  (完整正弦)

输出 v_o:   ∩ ∩ ∩ ∩  (只剩正半周)
          ─ ─ ─ ─ ─
```

缺点:**一半时间没输出,效率低,脉动大**。

#### 全波桥式整流(最常用!)

用 4 个二极管组成一个"桥"。

```
                D1 ▶│       ▶│ D2
     A ────────┤├───┬────────┤├─────── B
                    │
     交流        R_L│负载
     输入             │
                    │
     A ────────┤├───┴────────┤├─────── B
                D4 │◀        │◀ D3

     (图有点难画,核心是:无论 A、B 哪端为正,
      总能找到一条路径让电流从"正端"→经过两个导通的二极管
      →流过 R_L →回到"负端"。)
```

**关键理解**:

- A 端为正(正半周):D1、D3 导通,D2、D4 截止
- B 端为正(负半周):D2、D4 导通,D1、D3 截止
- **无论哪半周**,流过 RL 的电流方向都一样!

输出波形:

```
输入:    ∿∿∿∿∿

输出:    ∩∩∩∩∩∩  (全部翻到上面,双倍频率)
        ─ ─ ─ ─
```

**代价**:电流经过两个二极管,压降损失 2×0.7=1.4V。

#### 加滤波电容(整流+滤波)

整流后的波形还是脉动的,不是"真直流"。**并联一个大电容**就能让它平滑得多:

```
      整流输出 ───┬──── 到负载 R_L
                 │
                 C (大电容)
                 │
      ──────────┴────
```

**工作原理**:

- 电压上升时:电容充电,电容电压跟随输入
- 电压下降时:二极管截止,电容通过 RL **缓慢放电**(时间常数 τ=RLC)
- 下一个脉冲到来时再充电

波形变成:

```
     ∩∩∩∩∩∩       整流后
     ─ ─ ─ ─

     ▔╲▁▔╲▁▔╲▁    加电容后(近似直流,带小纹波)
```

剩下的小波动叫**纹波(ripple)**,C 越大、RL 越大,纹波越小。

### 3.5 限幅与钳位——改变波形形状

#### 限幅电路(Clipper)

**把波形超过某个电压的部分"削掉"**。

```
     v_i ──[R]──┬── v_o
                │
              ──┴──
              ▼ D      ← 二极管阳极向上(反过来画的示意)
              ─┬─
               │
              [V_ref]  ← 参考电压
               │
              ─┴─ 地
```

当 vi>Vref+0.7V 时,二极管导通,vo 被钉在 Vref+0.7V;否则二极管截止,vo=vi。

效果:输入正弦波,输出"顶端被切平"的波形。

应用:**保护电路**(防止电压过高烧坏后级)、**限压**。

#### 钳位电路(Clamper)

**把整个波形平移到某个直流电平上**,形状不变。

```
     v_i ──[C]──┬── v_o
                │
                ▼ D
                │
               ─┴─ 地
```

输入正弦(比如 ±5V 摆动),输出会被钳位到**最高点在某个固定值**(比如 0.7V),整个波形向下平移。关键在电容的**充电记忆**:一旦充了电,就保持那个直流偏移。

### 3.6 稳压二极管(齐纳管)

上一课提过:工作在**反向击穿区**,击穿电压 VZ 几乎不随电流变化。

符号:普通二极管符号,阴极那条线加个折角(像个 Z)。

**稳压电路**:

```
    V_in ──[R]──┬── V_out (稳定在 V_Z)
                │
              ──┴──
              ▲ Dz   ← 反向接!阴极接高电位
              ──┬──
                │
    地 ─────────┴──
```

注意接法:**齐纳管反向工作,阴极接高电位**。

工作原理:无论 Vin 怎么波动(在一定范围内),只要流过 Dz 的反向电流足够大,Dz 两端电压就钉在 VZ。R 承担输入电压的波动,Vout=VZ 稳定。

### 3.7 这一课你必须带走的东西

1. **三种模型的适用场景**:理想模型用于定性,恒压降模型(0.7V)用于一般计算,小信号模型 rd=VT/ID 用于交流小信号分析。
2. **直流分析的"假设—验证"方法**是标准套路,做题必用。
3. **整流的核心**:半波简单但浪费,桥式全波最常用,加电容滤波后才接近真正的直流。
4. **限幅/钳位**:利用二极管的"开关"特性改造波形形状。
5. **稳压二极管**工作在反向击穿区,是最简单的稳压电路方案。
6. 贯穿整门模电最重要的思想已经出现了:**大信号定工作点,小信号分析增量行为**。这在三极管和运放分析里会大放异彩。
