## 第 4 课:双极型晶体管(BJT)——放大的起源

### 4.1 为什么需要"放大"

先想一个问题:麦克风把声音变成电信号,这个电信号只有几毫伏;但音箱驱动扬声器需要几伏、甚至几十伏。中间需要一个东西,**能用小信号"指挥"大信号**——这就是**放大器**。

但要注意:**能量不是凭空产生的**。放大器的能量来自电源(比如 +12V 直流电源),它的作用是"让小信号去**调制**电源向负载输出的能量"。

> **小信号是"指挥棒",电源是"能量池",放大器是"阀门"**。

BJT 就是这样一个"电控阀门"。

---

### 4.2 BJT 的结构——两个 PN 结"背靠背"

BJT = Bipolar Junction Transistor,**双极型晶体管**。"双极"指**电子和空穴两种载流子都参与导电**(这是和后面要讲的 MOS 管的关键区别)。

#### NPN 型结构

```
         发射极 E
             │
         ┌───┴───┐
         │   N   │  ← 发射区(Emitter,高掺杂)
         ├───────┤
         │   P   │  ← 基区 (Base,薄且低掺杂) ──── B 基极
         ├───────┤
         │   N   │  ← 集电区(Collector,中等掺杂)
         └───┬───┘
             │
         集电极 C
```

**关键结构特点**(每一条都有物理意义,不能忽略):

1. **基区极薄**(微米量级)——这是 BJT 能放大的核心秘密,等下就会看到为什么
2. **发射区重掺杂,基区轻掺杂**——让"注入"方向不对称
3. **三个区、两个 PN 结**:
 - **发射结(BE 结)**:基极-发射极之间
 - **集电结(BC 结)**:基极-集电极之间

PNP 型结构正好相反(P-N-P),工作原理完全对称,电压电流方向相反。先掌握 NPN。

#### 电路符号

```
         C (集电极)
         │
      ┌──┤
      │  │
   B──┤  │         NPN:箭头向外(Emitter 的 E 指向外)
      │  │
      └──┤
         │↘
         E (发射极,带箭头)
```

**看箭头记方向**:NPN 箭头**向外**,PNP 箭头**向内**。箭头方向 = 发射结正偏时的电流方向(这是判断管子类型最快的方法)。

---

### 4.3 BJT 怎么"放大"——物理过程(最关键的部分)

现在进入核心。我们让 NPN 管工作在**放大区**——具体偏置要求是:

- **发射结正偏**(VBE>0,约 0.7V)
- **集电结反偏**(VCB>0,即 VC>VB)

也就是说:VC>VB>VE,而且 VB−VE≈0.7V。

接下来发生了 4 件事——**这 4 步你必须记住,是理解 BJT 一切行为的基础**:

#### 步骤 1:发射结正偏 → 电子从 E 区大量注入基区

发射结正偏,就像一个正向导通的二极管。由于**发射区重掺杂**,大量电子从 N 型发射区"涌"进 P 型基区。同时也有少量空穴从基区进入发射区,但这部分可以忽略(因为基区掺杂浅)。

#### 步骤 2:电子在基区"穿越"

现在基区里有大量从 E 注入的电子。这些电子本来应该和基区的空穴复合(就像普通 PN 结那样),但是——

**基区太薄了!**

电子还没来得及复合,就扩散到了集电结边缘。只有**很少一部分**(大约 1%)的电子在基区和空穴复合,贡献了**基极电流 IB**。

#### 步骤 3:集电结反偏 → 把电子"拉"进集电区

集电结反偏,意味着 C 极电位高,形成一个从 C 指向 B 的强电场。这个电场对**电子来说是"顺势而下"**——把从基区扩散过来的电子**一股脑全部扫到集电区**,形成**集电极电流 IC**。

> **关键:反偏结对少数载流子是"抽取"状态,对从基区过来的电子不仅不阻碍,反而加速**。

#### 步骤 4:电流关系

设从 E 注入基区的电子总电流为 IE(等于发射极电流),其中:

- 约 99% 被集电极收走 →IC≈0.99 IE
- 约 1% 在基区复合 →IB≈0.01 IE

**由 KCL**:IE=IB+IC(NPN 中电流方向:E 流出,C 流入,B 流入)

---

### 4.4 两个核心参数:α 和 β

**共基直流放大系数**:

α=ICIE(通常 0.98∼0.995)α=IEIC(通常 0.98∼0.995)

**共射直流放大系数**:

β=ICIB(通常 50∼300)β=IBIC(通常 50∼300)

它们的关系可以推导:

β=ICIB=ICIE−IC=α1−αβ=IBIC=IE−IC=1−α

**验证一下**:若 α=0.99,β=0.99/0.01=99。若 α=0.995,β=199。

**为什么 β 这么大?** 因为 α 接近 1,1−α 非常小,分子除以小数得到大数。β 的大小**完全由基区的薄度和掺杂浓度决定**——这是工艺参数。

#### 这就是"放大"!

**小的 IB 能"控制"几十倍到几百倍的 IC**。

IC=β⋅IB

你给基极灌 10μA 电流,集电极就流 1mA(若 β=100)——**基极电流像一个"水龙头",集电极电流像水龙头控制的主水流**。

---

### 4.5 三种工作区——判断条件与状态

BJT 并不总是在放大。根据两个 PN 结的偏置状态,它有三种工作区:

|工作区|发射结|集电结|状态描述|
|---|---|---|---|
|**截止区**|反偏(或未达 0.7V)|反偏|相当于"开关断开",IC≈0|
|**放大区**|正偏(≈0.7V)|反偏|线性放大,IC=βIB|
|**饱和区**|正偏|正偏|相当于"开关闭合",VCE≈0.2V 很小|

**第四种——"倒置放大区"**(发射结反偏、集电结正偏),实际上极少使用,因为 BJT 结构不对称,倒着用参数很差。

#### 放大区判定(NPN)的工程速记

VBE≈0.7V,且 VCE>VCE,sat≈0.3V,则在放大区。

#### 饱和区的物理含义

当 VCE 小到一定程度(典型 0.2V),集电结不再反偏,反而正偏了。这时集电极不再有"抽走电子"的本事,即使你继续增大 IB,IC 也不再增长——**IC≠βIBIC=βIB 在饱和区不成立**。

```
    I_C ↑
        │
        │    放大区
        │   ──────── I_B=60μA
        │  /────────
        │ /─────── I_B=40μA
        │/─────────
        │/──────── I_B=20μA
        │/─────────
        │饱和区
    ────┼────────────→ V_CE
        0 0.3V
```

左边陡峭上升的部分是**饱和区**,右边几乎水平的部分是**放大区**,几乎水平意味着 IC 几乎只由 IB 决定,和 VCE 关系不大——**这就是"电流控制电流源"的直观表现**。

---

### 4.6 三种组态——共射、共基、共集

BJT 有三个引脚,信号要从一个引脚输入、一个引脚输出——剩下那个是"公共端"。公共端是哪个,就叫"共 X"组态。

```
    共发射极(CE)        共基极(CB)         共集电极(CC,也叫射极跟随器)

    输入:B              输入:E              输入:B
    输出:C              输出:C              输出:E
    公共:E(接地)       公共:B(接地)       公共:C(接电源)
```

三种组态各自有不同的"性格":

|组态|电压增益|电流增益|输入阻抗|输出阻抗|典型用途|
|---|---|---|---|---|---|
|**共射 CE**|大(数十~数百,反相)|大(β)|中|中|通用电压放大|
|**共基 CB**|大(同相)|约 1|低|高|高频放大|
|**共集 C**|约 1|大(β)|**高**|**低**|**缓冲、阻抗匹配**|

**记忆要点**:

- **共射**是"全能战士",既放大电压又放大电流,**但输出反相**
- **共基**高频好,但电流不放大,用得少
- **共集**电压不放大(约 1)但**阻抗变换能力极强**——**后面学运放时的"输出级"几乎都是共集**

---

这是模电考试最爱考的内容之一。

#### 输入特性曲线(IB vs VBE)

横轴 VBE,纵轴 IB。**形状和二极管的 I-V 曲线几乎一样**——因为发射结本来就是一个 PN 结。当 VCE 固定时,IB 随 VBE 指数增长,约 0.7V 处急剧上升。

#### 输出特性曲线(IC vs VCE,以 IB 为参数)

这个就是我上面画的那个图。**一族水平曲线**,每条对应一个 IB 值。

- 最左边陡峭部分:**饱和区**
- 中间水平部分:**放大区**,IC≈βIB
- 最下面那条几乎贴着 x 轴的:**截止区**(IB=0)
- 最右边电压太高会击穿——尽量避免

### 4.8 这一课你必须带走的东西

1. **BJT = 两个背靠背 PN 结 + 极薄的基区**。基区薄是放大的根本原因。
2. **放大的物理过程 4 步**:发射结正偏→电子注入基区→基区太薄导致绝大多数电子穿越→集电结反偏把电子扫到集电区。
3. **核心关系 IC=βIB 只在放大区成立**。β 是工艺参数,典型 50~300。
4. **三种工作区的判断**看两个结的偏置:截止(两结反偏)、放大(发射正偏+集电反偏)、饱和(两结正偏)。
5. **"控制"的本质**:IB 小,但它决定了多大比例的电子能穿越基区被集电极收走。**BJT 是电流控制电流源(CCCS)**。
6. **三种组态各有专长**,共射最常用做电压放大(记住"反相"),共集用做**阻抗变换**(缓冲器)。

## 第 5 课:BJT 放大电路的静态工作点(Q 点)

### 5.1 为什么一定要有 Q 点?

先问一个最根本的问题:**为什么不能把交流信号直接送到 BJT 的基极?**

假设有个麦克风输出的音频信号,幅值 ±20mV,你直接把它接到 BJT 基极,发射极接地。那么:

- 正半周:VBE=+20mV——**远小于 0.7V,BJT 截止,没有输出**
- 负半周:VBE=−20mV——**反偏,BJT 更加截止**

结果:**BJT 根本不导通,整个信号都消失了**。

问题出在哪?

**BJT 的放大区要求 VBE≈0.7V**。而输入信号是围绕 0V 摆动的,根本达不到 0.7V 的门槛。

**解决方案**:给 BJT 先加一个**直流偏置**,让它"先坐到放大区的工作位置上",然后再把交流信号**叠加**上去。

```
     直流偏置(V_BE = 0.7V)
              +
     交流信号(±20mV)
              ↓
         V_BE 实际 = 0.7V ± 20mV → 680mV ~ 720mV
                 始终在放大区内工作 ✓
```

**这个直流偏置下的工作状态,就叫"静态工作点 Q"(Quiescent Point)**。

"静态"的意思是:**没有交流信号输入时,电路里的电压电流值**。它由 (VBEQ,IBQ,VCEQ,ICQ) 四个量描述(常用 ICQ 和 VCEQ 作主角)。

---

### 5.2 "先直流后交流"——模电最重要的分析方法

这个思想贯穿整门模电,我要用框起来的方式强调:

> **叠加原理**:因为 BJT 在放大区可以**近似线性**,我们可以把信号分成两部分独立分析:
>
> - **直流分析**:只看直流电源,求 Q 点(**大信号**)
> - **交流分析**:只看交流信号,求增益、阻抗(**小信号**)
>
> 最终的实际电压电流 = 直流分量 + 交流分量

这就是上一课讲过的**"大信号定工作点,小信号分析增量行为"**。现在要正式用起来了。

#### 工程记号约定(要认清)

|记号|含义|
|---|---|
|VBE,IC(大写字母+大写下标)|直流量(Q 点值)|
|vbe,ic(小写字母+小写下标)|交流量(瞬时增量)|
|vBE,iC(小写字母+大写下标)|总瞬时量 = 直流 + 交流|
|VCC,VEE(大写双下标)|电源电压|

这一套记号你必须现在就适应,后面的课全都用。

---

### 5.3 最简偏置:固定偏置电路(反面教材)

先看一个"教科书反面典型"——**固定偏置电路**。学它是为了理解**为什么它不好**。

```
       V_CC (+12V)
        │
     ┌──┴──┐
     │     │
    [R_B]  [R_C]
     │     │
     ├─────┤─── v_o (输出)
     │     │
     │    ─┤ C
    ───── │
         │ NPN
         E
         │
        ─┴─ 地

    v_i ──[C1耦合电容]── 接基极
```

**直流通路分析**(信号电容 C1 对直流开路,暂时忽略 vi):

从 VCC 到地,经过 RB 和发射结:

VCC=IBQRB+VBEQIBQ=VCC−VBEQRB≈VCC−0.7VRBIBQ=RBVCC−VBEQ≈RBVCC−0.7V

然后:

ICQ=βIBQVCEQ=VCC−ICQRC

**数值例子**:VCC=12V,RB=565kΩ,RC=3kΩ,β=100。

- IBQ=(12−0.7)/565k≈20μA
- ICQ=100×20μ=2mA
- VCEQ=12−2m×3k=6V ✓(在放大区)

看起来挺好。**但这个电路有一个致命问题:**

#### 为什么"固定偏置"不好?

**问题出在 β 上**。β 这个参数:

1. **同一型号的管子,不同个体差异很大**(说明书常写 β=100∼300β=100∼300)
2. **温度变化时 β 会变**——每升温 1°C,β 约增加 0.5%
3. **一旦 β 变了,ICQ=βIBQ 就跟着变**,Q 点漂移

假设上面电路里换了一个 β=200 的管子:

- IBQ 几乎不变(还是由 RB 决定的),仍约 20μA
- ICQ=200×20μ=4mA
- VCEQ=12−4m×3k=0V ——**进入饱和区,不能放大了!**

**结论**:固定偏置把 IB 锁死,但 IC 完全随 β 起舞。**工程上绝不能用**。

---

### 5.4 王者方案:分压式偏置电路(重点!)

这是实际电路中最常用、最经典的偏置方式。**务必掌握**。

```
       V_CC (+12V)
        │
    ┌───┴───┐
    │       │
   [R_1]   [R_C]
    │       │
    ├───────┤──────── v_o
    │       │
    │      ─┤ C
    ├──────│
    │      │ NPN
   [R_2]   E
    │      │
    │     [R_E]
    │      │
    │      ├──[C_E]── 地 (发射极旁路电容)
    │      │
    └──────┴──── 地

    v_i ──[C_1]── 接基极节点
```

两个关键改动:

1. **基极用 R1、R2 分压产生稳定偏压**(不再靠 RB 单条路径)
2. **发射极串一个 RE**(引入**负反馈**,稳定 Q 点)
3. RE 两端并一个大电容 CE,交流短路,让交流信号感觉不到 RE 存在(交流分析时再讲)

#### 直流分析——"戴维南等效"法

看左边的分压网络 R1、R2,如果 IB 相对于流过它们的电流可以忽略(这是设计要求),那么基极电压近似为:

VB≈VCC⋅R2R1+R2VB≈VCC⋅R1+R2

这是一个**由电阻分压、几乎不受 β 影响的稳定值**。

#### 求 Q 点

从 VB 出发,减去 VBE,得发射极电压 VE:

VE=VB−VBE≈VB−0.7V

**关键一步**:IE=VE/RE。

IEQ=VB−0.7VREIEQ=REVB−0.7V

注意这个式子里**完全没有 β**!

然后:

ICQ≈IEQ(因为 α≈1)ICQ≈IEQ(因为 α≈1)VCEQ=VCC−ICQRC−IEQRE≈VCC−ICQ(RC+RE)

#### 数值例子

设 VCC=12V,R1=40kΩ,R2=10kΩ,RC=3kΩ,RE=1kΩ,β=100:

- VB=12×1040+10=2.4VVB=12×40+1010=2.4V
- VE=2.4−0.7=1.7V
- IEQ=1.7/1k=1.7mA
- ICQ≈1.7mA
- VCEQ=12−1.7m×(3k+1k)=12−6.8=5.2V ✓

**现在换 β=200 的管子**:

- VB 不变(还是 2.4V)
- IEQ 不变(还是 1.7mA)
- ICQ 不变
- VCEQ 不变

**Q 点几乎不受 β 影响!** 这就是分压式偏置的魔力。

---

### 5.5 为什么分压式偏置这么稳?—— 负反馈的威力

这是一个**极其重要的概念**,提前渗透,后面专门讲反馈时会回来。

想象一下:某种原因(温度升高)导致 IC 想增大。

```
    T↑ → I_C↑ → I_E↑ → V_E = I_E·R_E ↑

    但是 V_B 几乎不变(由分压锁定)

    → V_BE = V_B − V_E ↓

    → I_B↓ → I_C↓  (压制住原来的增大趋势)
```

这是一个**自动调节机制**——RE 把输出端(IE)的信息"反馈"到了输入端(VBE),并且是**反方向修正**,所以叫**负反馈**。

**$R_E$ 越大，负反馈越强，静态工作点越稳定；代价是交流增益也会降低。** 因此常在 $R_E$ 两端并联旁路电容 $C_E$，使交流信号绕过 $R_E$。

---

### 5.6 Q 点的"图解法"——直流负载线

这是模电教材的经典图,期末必考。

从 KVL:VCE=VCC−IC(RC+RE),这是一条**直线**,画在输出特性曲线上:

```
    I_C ↑
        │
    V_CC/(R_C+R_E) ┤──╲
                   │   ╲
                   │    ╲  ← 直流负载线
                   │     ╲
                   │   Q╲× ← Q 点(工作点)
                   │     ╲
                   │      ╲___ I_B=I_BQ
                   │       ╲
                   └────────╲──→ V_CE
                            V_CC
```

- 横轴截距:VCE=VCC(当 IC=0)
- 纵轴截距:IC=VCC/(RC+RE)(当 VCE=0)
- **Q 点 = 负载线与 IB=IBQ 那条输出特性曲线的交点**

---

### 5.7 Q 点的位置——**必须在放大区中央!**

这是设计放大器的黄金法则。**Q 点位置选得不好,信号就会失真**。

#### 情况 A:Q 点太靠近饱和区(VCEQ 太小)

输入交流信号的**负半周**会让 IC 增大,VCE 减小——一旦 VCE 掉到饱和区(<0.3V),VCE 就被钉住了,**波形底部被削平**——**饱和失真**。

#### 情况 B:Q 点太靠近截止区(ICQ 太小)

输入交流信号的正半周让 IC 继续减小,但 IC 不能为负——IC 被钉在 0,**波形顶部被削平**——**截止失真**(NPN 共射接法下,输出相位反相,所以波形"底部"实际对应输入"顶部")。

#### 情况 C:Q 点居中

VCEQ 约为 VCC/2,ICQ 留有足够摆动空间。**正负半周都能完整输出**——这就是 Q 点居中的设计目标。

```
    V_CE 的波形(共射接法,输出反相)

     V_CC ┤
          │
    V_CEQ ┤─ ─∿∿∿∿∿─ ─  ← Q 点位置决定波形的"中心线"
          │
    0.3V  ┤  └── 低于此线就饱和失真
          │
      0V  ┤
```

**经验设计准则**:VCEQ≈VCC/2,ICQ 视信号需要而定(一般几 mA)。

---

### 5.8 非线性失真——更深的来源

即使 Q 点选在正中央,**BJT 本身不是完全线性的**——IC 随 VBE 按指数变化:

IC=IS⋅eVBE/VT

当输入信号幅值大时,这种指数非线性会让输出波形**不对称**:正半周和负半周的增益不一样,产生**谐波分量**——这就是**非线性失真(Nonlinear Distortion)**。

**解决办法有两类**:

1. **小信号工作**:让交流摆幅远小于 VT≈26mV,使 BJT 只看到线性区
2. **负反馈**(后面专门讲):用反馈改善线性度

---

### 5.9 这一课你必须带走的东西

1. **Q 点的意义**:先给 BJT 施加直流偏置,让它"坐到放大区的位置",再叠加交流信号。**没有 Q 点,就没有放大**。
2. **"先直流后交流"的分析方法**:叠加原理把一个放大器问题拆成两个更简单的问题——先求 Q 点(这节课),再分析小信号增益(下节课)。
3. **固定偏置电路 Q 点随 β 漂移**,工程上不用。
4. **分压式偏置是标准方案**:
 - VB 由 R1、R2 分压锁定,几乎不受 β 影响
 - RE 引入直流负反馈,进一步稳定 Q 点
 - CE 让交流信号绕过 RE,不损失增益
5. **Q 点计算套路**(R1R2RE 电路):
 - VB=VCC⋅R2/(R1+R2)
 - ICQ≈IEQ=(VB−0.7)/RE
 - VCEQ=VCC−ICQ(RC+RE)
6. **Q 点位置决定波形能否完整输出**:太靠近饱和 → 饱和失真,太靠近截止 → 截止失真,居中最好。

## 第 6 课:BJT 小信号模型与交流分析

### 6.1 为什么需要"小信号模型"

Q 点确定后,BJT 已经稳稳坐在放大区。现在输入信号 vi 在 Q 点附近**小幅摆动**,我们想知道:输出 vo 被放大了多少倍?

**直接用肖克利方程?** IC=ISeVBE/VT——这是**非线性**的,算起来很痛苦。

**但是**——如果摆幅足够小,非线性曲线的一小段**可以近似当成直线**。这是模电最重要的思想之一:

> **把非线性器件在 Q 点附近"线性化"**——这就是**小信号模型**的灵魂。

从数学上讲,就是你学过的**一阶泰勒展开**:

iC(vBE)≈ICQ+diCdvBE∣Q⋅vbeiC(vBE)≈ICQ+dvBEdiCQ⋅vbe

diCdvBE∣QdvBEdiCQ 是 Q 点处的斜率,叫**跨导 gm**。

---

### 6.2 跨导 gm——BJT 的"放大本领"

对肖克利方程求导:

gm=diCdvBE∣Q=ISeVBE/VT=ICQVTgm=dvBEdiCQ=VTISeVBE/VT=VTICQgm=ICQVT≈ICQ26 mVgm=VTICQ≈26mVICQ

**这个公式极其重要,必背**。它的物理意义是:**每单位 vBE 变化,引起多大的 iC 变化**。

**例子**:ICQ=1 mAICQ=1mA 时,gm=1mA/26mV≈38.5 mSgm=1mA/26mV≈38.5mS(毫西门子)。

**注意一件美妙的事**:gm **只由 Q 点电流决定**,和 β 无关,和具体的管子型号几乎无关。这是 BJT 的一个内在本质属性。

---

### 6.3 小信号输入电阻 rbe(或记作 rπ)

BJT 的输入端(BE 结)可以被小信号"看成"什么?

BE 结是一个正向导通的 PN 结,我们第 3 课讲过它在 Q 点的动态电阻:

re=VTIEQ≈26 mVIEQre=IEQVT≈IEQ26mV

但这个是**发射极端**看到的电阻。从**基极端**看,因为 ib 只是 ie 的 1/(β+1),看到的电阻会大 (β+1) 倍:

rbe=(β+1)⋅re=(β+1)VTIEQ≈βVTICQrbe=(β+1)⋅re=IEQ(β+1)VT≈ICQβVT

**例子**:β=100,ICQ=1mA,则rbe=100×26/1=2600 Ω=2.6 kΩ。

**教材里另一种记号**:有些书用 rπ 代替 rbe,完全是一回事。

---

### 6.4 两个模型的等价性:gm 与 β

有两种等价的方式描述 BJT 的小信号行为:

**方式 1:电压控制电流源(跨导模型,混合 π 模型)**

- vbe 是"控制信号"
- ic=gmvbe

**方式 2:电流控制电流源(β 模型)**

- ib 是"控制信号"
- ic=βib

这两者必须等价,因为是同一个器件。验证:

ic=βib=β⋅vberbe=β⋅vbeβVT/ICQ=ICQVTvbe=gmvbe✓ic=βib=β⋅rbevbe=β⋅βVT/ICQvbe=VTICQvbe=gmvbe✓

**也就是说:** β=gm⋅rbe。两个模型在数学上等价,用哪个取决于你更喜欢以"电压"还是"电流"为核心思考。

---

### 6.5 BJT 的小信号等效电路(混合 π 模型)

把上面的元素组合起来,画出 BJT 在 Q 点的**线性等效电路**:

```
   基极 B ●────┬────● 集电极 C
              │    │
           [r_be]  ↓ g_m·v_be  (或 β·i_b)
              │    │           受控电流源
              │    │
   发射极 E ●─┴────┴────●

  注:实际还有一个 r_ce(输出电阻,很大,一般忽略)
```

**要点**:

- BE 之间是一个电阻 rbe
- CE 之间是一个**受控电流源**,大小为 gmvbe(或 βib)
- **没有** BC 之间的直连——这在小信号下是合理的近似
- 完整模型还有一个 rce 并联在受控源两端,表示集电极输出电阻(几十 kΩ 到几百 kΩ),**入门分析经常忽略**

**这个等效电路只在 Q 点附近、小信号条件下有效**。一旦信号幅度变大(如 vbe 接近 VT),它就不准了。

---

### 6.6 怎么画"交流通路"——关键步骤

拿到一个放大器原理图,怎么转换成小信号等效电路?**三步法**:

#### 第 1 步:电容视为交流短路

耦合电容 C1、C2、旁路电容 CE——在信号频率下容抗 1/(ωC) 很小,近似短路。

> **前提是"在信号频率下"**。后面讲频率响应时会回来——低频下电容不能短路,那就是另一回事了。

#### 第 2 步:直流电源视为交流地

VCC 是理想直流电源,**对交流信号来说阻抗为零**(因为电压恒定,不变化)——所以**直流电源节点对交流就是"地"**。

这意味着:接到 VCC 的电阻,在交流通路里变成"接地"。

#### 第 3 步:用 BJT 的小信号模型替换 BJT

把原理图中的 BJT 抠掉,替换成 rbe + 受控电流源的等效电路。

---

### 6.7 典型例子:共射放大器的交流分析

用上节课的分压式偏置共射放大器做例子:

```
  原电路:

       V_CC
        │
     ┌──┴──┐
     │     │
    [R_1] [R_C]
     │     │
     ├─────┤──[C_2]── v_o
     │     │
     │    ─┤ (BJT)
     ├────│
     │    │
    [R_2] E
     │    │
     │   [R_E]──[C_E]── 地
     └────┴───── 地

  v_i ──[C_1]── 接基极
```

#### 画交流通路

- C1、C2、CE 短路
- VCC 节点接地
- R1 的上端原来接 VCC,现在接地 → R1 和 R2 并联接在基极和地之间
- RC 的上端原来接 VCC,现在接地 → RC 接在集电极和地之间
- RE 被 CE 短路掉 → 发射极直接接地

简化后:

```
          ┌───────┐        ┌────────┐
  v_i ────┤       ├── b ───┤        ├─── c ──┬── v_o
          │ R₁∥R₂ │        │  BJT   │        │
          │       │        │        │      [R_C]
          │       │        │        │        │
          └───┬───┘        │   e    │        │
              │            │   │    │        │
             地            └───┴────┘       地
                              │
                             地
```

#### 代入 BJT 小信号模型

```
           ┌─────┐     b ●─────┬──────● c ──┬── v_o
  v_i ─────┤     ├──────────────┤            │
           │R₁∥R₂│              │            │
           │  =  │            [r_be]  ↓g_m·v_be  [R_C]
           │ R_B'│              │            │
           └──┬──┘            e │            │
              │                 │            │
              地              地 ●────────── 地
```

RB′=R1∥R2RB′=R1∥R2(两个偏置电阻并联)。

#### 推导电压增益

**第 1 步**:输入端,vbe = ?

基极到地的路径:vi 通过 C1(短路)到基极,基极到地经过两条并联路径:RB′RB′ 和 rbe。

**如果信号源是理想电压源**(内阻为 0),那么 vbe=vi。

**第 2 步**:输出端,vo = ?

集电极的电流是 ic=gmvbe(注意这个电流是**从集电极流出**,由受控源方向决定)。

这个电流流过 RC 到地。但注意方向:**受控源把电流从 C 端抽出**,这意味着 C 端电位被拉低——vo=−ic⋅RC=−gmvbe⋅RC。

更仔细地说:

```
  V_CC ──[R_C]── c 点 ── 到负载

  受控电流源 g_m·v_be 的方向:从 c 流向 e
  → 电流从 V_CC 经 R_C 流到 c,再经受控源流向 e(地)
  → 这个电流在 R_C 上产生压降
  → c 点电位 = V_CC − i_c·R_C

  交流分量:v_o = −i_c · R_C = −g_m v_be · R_C
```

**第 3 步**:电压增益

Av=vovi=vovbe=−gmRCAv=vivo=vbevo=−gmRC

或者用 β 形式表达:

Av=−βRCrbeAv=−rbeβRC

两个公式等价(因为 gm=β/rbe)。

#### 负号的意义

**负号表示输入与输出反相**:输入信号为正时,输出为负;输入上摆,输出下摆。

物理理解:vi 上升 → vbe 上升 → ic 上升 → RC 上压降变大 → **集电极电位 vC 下降**。所以输出电压减小——反相。

这是共射放大器的标志性特征——"**共射反相**"。

#### 数值验证

用第 5 课的例子:ICQ=1.7mA,β=100,RC=3kΩ。

- gm=1.7/26≈65.4 mSgm=1.7/26≈65.4mS
- rbe=100×26/1.7≈1529 Ωrbe=100×26/1.7≈1529Ω
- Av=−gmRC=−65.4×3≈−196

**电压增益约 −196 倍**——这个数量级是共射放大器的典型值。

### 6.8 输入阻抗与输出阻抗

一个放大器不是一个孤立的东西,它要连接信号源、连接后级。**放大器看起来像什么**——就是它的输入/输出阻抗决定的。

#### 输入阻抗 Ri

从输入端往里看的等效电阻:

Ri=RB′∥rbe=(R1∥R2)∥rbeRi=RB′∥rbe=(R1∥R2)∥rbe

通常 rbe(几 kΩ)远小于 R1∥R2R1∥R2(几十 kΩ),所以:

Ri≈rbe

**对共射放大器,输入阻抗不高**——几 kΩ 的量级。这是它的一个缺点。

#### 输出阻抗 Ro

从输出端往里看(**输入端信号源短路、负载端断开**的条件下)。

受控源 gmvbe 在 vbe=0 时输出为 0,相当于开路。所以从 C 端往里看,只剩下 RC 到地:

Ro=RC

(如果考虑 rce,则 Ro=RC∥rceRo=RC∥rce,但通常 rce≫RCrce≫RC,可忽略)

---

### 6.9 带负载的情形

实际电路中,输出要接负载 RL。负载的加入会改变增益:

Av=−gm(RC∥RL)Av=−gm(RC∥RL)

因为受控电流源产生的电流会同时"看到" RC 和 RL 并联后的等效电阻。

**启示**:输出阻抗 Ro 相对负载越小,带负载后增益损失越小——"**低输出阻抗好**"。

---

### 6.10 RE 不旁路的情形——交流负反馈

如果**去掉 CE**,RE 对交流信号也起作用。这时交流分析变为:

发射极不再接地,发射极电压 ve=ieRE≈icRE。

而 vbe(BJT 两端)实际等于 vi−ve:

vbe=vi−icRE=vi−gmvbeRE

解出 vbe:

vbe=vi1+gmREvbe=1+gmREvi

所以:

Av=vovi=−gmvbeRCvi=−gmRC1+gmREAv=vivo=vi−gmvbeRC=1+gmRE−gmRC

当 gmRE≫1gmRE≫1 时:

Av≈−RCREAv≈−RERC

**一个神奇的结果**:增益只由外部电阻 RC/RE 决定,**与 BJT 的参数(β、Q 点)无关**!

这就是**负反馈**的神奇之处:用"损失增益"换"稳定性、线性度、参数无关性"。后面专门讲反馈时你会深刻理解这件事。

**对比**:

- 旁路(有 CE):Av≈−200,但高度依赖 β
- 不旁路:Av≈−3(若 RC=3k, RE=1k),稳定且与 β 无关

### 6.11 h 参数模型(中国教材特色)

中国教材常用另一种等价模型:**h 参数模型**。本质上和混合 π 模型是同一回事,只是换了符号:

- hie↔rbehie↔rbe(输入电阻)
- hfe↔βhfe↔β(电流放大系数)
- hre:反向电压反馈系数(通常很小,忽略)
- hoe:输出电导(通常很小,忽略)

简化后的 h 参数模型和混合 π 模型完全一样。**不用专门学,混合 π 模型已经够用**。

### 6.12 这一课你必须带走的东西

1. **小信号模型的本质**:把 BJT 在 Q 点处一阶泰勒展开,获得**线性等效电路**,只在小信号下有效。
2. **三个核心参数**:
 - gm=ICQ/VT(跨导,只看 Q 点电流)
 - rbe=βVT/ICQ(输入电阻)
 - β=gm⋅rbe(三者的关系)
3. **画交流通路三步**:电容短路、VCC 接地、BJT 换成小信号模型。
4. **共射放大器的核心公式**:
 - Av=−gmRC=−βRC/rbe(负号代表反相)
 - Ri≈rbe
 - Ro≈RC
5. **RE 不旁路时**:Av≈−RC/RE,**增益由外部电阻决定**,这是负反馈的威力。
6. **"先直流后交流"的完整流程**——你现在已经掌握了:
 - 直流分析 → 确定 Q 点 → 算出 ICQ
 - 根据 Q 点算出 gm、rbe
 - 画交流通路 → 代入小信号模型 → 算增益、阻抗

### 7.1 共集组态(C)——射极跟随器

#### 电路结构

**信号从基极输入,从发射极输出,集电极作为公共端(交流接地)**。

```
       V_CC
        │
       ─┤ C
      ──┤
        │ NPN
        E ────── v_o (从这里输出!)
        │
       [R_E]
        │
       ─┴─ 地

    v_i ──[C_1]── 接基极 (通过偏置电路)
```

**关键特征**:集电极直接接 VCC(没有 RC),输出从发射极取。

#### 直流 Q 点

和共射的分压式偏置基本一样——只是 RC 变成了 0(C 直接接 VCC)。Q 点算法:

VB=VCC⋅R2R1+R2,IEQ=(VB−0.7)/REVB=VCC⋅R1+R2,IEQ=(VB−0.7)/REVCEQ=VCC−IEQRE

#### 小信号分析

画交流通路(电容短路、VCC 接地、BJT 换成等效模型):

```
       b ●────┬──────● c
              │      │
           [r_be]   ↓ g_m·v_be
              │      │
              e ●────┴──
              │
             [R_E]
              │
              地
   (输出 v_o 从 e 端取)
```

注意:集电极 c 在交流通路里**接地**(因为 VCC 对交流是地)。

#### 推导电压增益

设发射极电位为 vo(相对地)。KVL:vi=vbe+vo (因为 b 到 e 跨 rbe,e 到地就是 vo)。

**发射极电流 ie**:ie=ib+ic=ib(1+β)≈βib

而 ib=vbe/rbe,所以:

vo=ie⋅RE=(1+β)ibRE=(1+β)RErbe⋅vbevo=ie⋅RE=(1+β)ibRE=rbe(1+β)RE⋅vbe

再由 vi=vbe+vo:

vi=vbe+(1+β)RErbevbe=vbe⋅rbe+(1+β)RErbevi=vbe+rbe(1+β)REvbe=vbe⋅rbe+(1+β)RE

所以:

Av=vovi=(1+β)RErbe+(1+β)REAv=vivo=rbe+(1+β)RE

**这个式子永远小于 1,但非常接近 1**。

**数值例子**:β=100,rbe=1.5kΩ,RE=1kΩ:

Av=101×1k1.5k+101×1k=101102.5≈0.985Av=1.5k+101×1k=102.5101≈0.985

几乎等于 1!所以叫"**射极跟随器**"——**输出电压"跟随"输入电压**,同相位、幅度几乎相等。

#### 既然增益是 1,有什么用?

**秘密在阻抗变换**。

##### 输入阻抗 Ri

从基极往里看:

Ri′=vbe/ib+vo/ib=rbe+(1+β)RERi′=vbe/ib+vo/ib=rbe+(1+β)RE

这是一个关键结果:**基极看到的电阻 = rbe + 发射极电阻的 (1+β) 倍**。

RE 原来只有 1kΩ,从基极看进去变成了 1500+101×1000≈102.5kΩ——**放大了 100 倍左右**!

再与偏置电阻 R1∥R2R1∥R2 并联(偏置电阻一般几十 kΩ),总输入阻抗还是比共射高得多。

> **发射极电阻"被基极放大 (1+β) 倍看到"**——这个规律叫**阻抗反射**,在 BJT 分析里反复出现,要记住。

##### 输出阻抗 Ro

这里推导稍微复杂,结论是:

Ro=RE∥rbe+Rs1+βRo=RE1+βrbe+Rs

其中 Rs 是信号源内阻。如果 Rs 不大,括号里的部分可以估算:

rbe1+β=βVT/ICQ1+β≈VTICQ=re1+βrbe=1+βVT/ICQ≈ICQVT=re

**发射极看到的阻抗 = 基极侧电阻除以 (1+β)**——和阻抗反射方向相反。

**数值例子**:若 re=26/1.7≈15Ω,RE=1kΩ,则 Ro≈15Ω(被小的那个支配)。

#### 共集组态的特性总结

|参数|值|特点|
|---|---|---|
|电压增益 Av|≈1≈1|同相、跟随|
|电流增益|≈β≈β|有电流放大|
|输入阻抗 Ri|高(几十~几百 kΩ)|**重要优点**|
|输出阻抗 Ro|低(几十 Ω)|**重要优点**|

**应用**:**阻抗缓冲器(Buffer)**——不放大电压,但"让强信号源看起来像高阻(对前级友好),让弱负载看起来像低阻(驱动能力强)"。

**经典用法**:放在共射放大器**后面**,用来驱动低阻负载(如扬声器、同轴电缆)。共射输出阻抗高(几 kΩ),直接带低阻负载会损失大量增益;加一级射极跟随器做缓冲,问题就解决了。

### 7.2 共基组态(CB)

#### 电路结构

**信号从发射极输入,集电极输出,基极作为公共端(交流接地)**。

```
       V_CC
        │
       [R_C]
        │
        ├─── v_o
       ─┤ C
      ──┤
        │ NPN
       ─┤ B ───[C_B]── 地 (基极交流接地)
        │
        E ─── v_i(信号从发射极输入)
        │
       [R_E]
        │
       地
```

基极通过一个大电容 CB **交流接地**(直流上由偏置电阻提供 VB,交流上被电容短路到地)。

#### 小信号分析(直接给结论,推导方法同共射)

**电压增益**:

Av=gmRC

**注意:没有负号!**——共基是**同相**放大。

数值上和共射差不多大(gmRC),量级数十到数百。

**输入阻抗**:

Ri≈re=VTIEQRi≈re=IEQVT

**非常低**——只有十几到几十欧姆。

**输出阻抗**:

Ro≈RC

和共射差不多。

#### 共基组态的特点总结

|参数|值|特点|
|---|---|---|
|电压增益|大,同相||
|电流增益|≈1≈1(α)|**不放大电流**|
|输入阻抗|很低|一般是缺点|
|输出阻抗|高||
|**高频特性**|**极好**|**核心优点**|

**为什么高频好?** 共射组态有一个叫**密勒效应(Miller Effect)** 的东西——BJT 内部的一个小电容 Cμ(BC 间)在共射下会被"放大"几百倍,严重限制高频响应。共基组态里 Cμ 不被放大,所以带宽高得多。

**实际应用**:

- 高频/射频放大器(手机、电视调谐器)
- 和共射组合成**共射-共基级联(Cascode)** 电路——前级共射保证电压增益,后级共基消除密勒效应,综合性能极好。Cascode 在集成电路里是标配。

### 7.4 多级放大器:为什么要多级?

#### 动机

单级放大器有三个局限:

1. **单级增益有限**:共射约 100~500 倍,要做到 10000 倍就不够
2. **输入/输出阻抗不够理想**:共射 Ri 只有几 kΩ,很多信号源(如高阻传感器)会严重衰减
3. **功能单一**:一级无法同时实现"高输入阻抗 + 高增益 + 低输出阻抗"

**解决方案**:**级联**——把多个单级放大器接起来,每级各司其职。

#### 经典级联结构:"三明治"配方

```
     高阻信号源 ─┤ 共集 ├─→ 共射 ├─→ 共射 ├─→ 共集 ├─ 低阻负载
                ↑           ↑       ↑           ↑
              输入级       中间级   中间级      输出级
           (高输入阻抗)   (大增益) (大增益)  (低输出阻抗)
```

- **输入级**用共集(C):**匹配高阻信号源**,防止信号被前端电阻分压衰减掉
- **中间级**用共射(CE):**提供主要电压增益**
- **输出级**用共集(C):**低输出阻抗,驱动负载**

这就是很多实际运放内部的基本结构。

#### 级间耦合方式

放大器级与级之间怎么连?三种方式:

##### A. 阻容耦合(RC 耦合)

用**耦合电容**连接两级,像上节课共射放大器里的 C1、C2:

```
  前级 C ──[C_coupling]── 后级 B
```

- **优点**:直流隔离——前级的 Q 点不影响后级的 Q 点,各级独立偏置、独立设计
- **缺点**:**不能放大直流信号**(电容隔直);电容又大又贵,不适合集成电路

**应用**:分立元件电路、音频放大器等只放大交流信号的场合。

##### B. 直接耦合(DC 耦合)

前级的输出端**直接连到**后级的输入端,没有电容:

```
  前级 C ────直线──── 后级 B
```

- **优点**:能放大直流信号、频率响应从 0 开始、容易集成(不需要大电容)
- **缺点**:
 - **Q 点相互影响**:前级的直流输出电平 = 后级的直流输入电平,设计时必须一起考虑
 - **零点漂移**:温度变化导致前级 Q 点漂移,后级把这个漂移也放大了,最后输出端直流电平乱跳

**应用**:集成电路(芯片里不能用大电容)、运算放大器。

**零点漂移问题的解决方案**:**差分放大器**——下节课专门讲,这是运放输入级的核心。

##### C. 变压器耦合

用变压器连接两级:

- **优点**:阻抗变换、隔离直流
- **缺点**:变压器笨重、昂贵、频率特性受限

**应用**:现在已经不常用,除了功率放大的特定场合。

### 7.5 多级放大器的增益计算

关键公式:

Av,total=Av1⋅Av2⋅Av3⋯Av,total=Av1⋅Av2⋅Av3⋯

**总增益 = 各级增益的乘积**。

**但是**——**每一级的 Avk 必须考虑"被下一级加载"之后的值**。

#### 前后级相互影响(重点!)

单看第 k 级,它的输出阻抗 Rok 和第 k+1 级的输入阻抗 Ri,k+1 会**形成分压**:

```
     前级                      后级
  ──┬──[R_ok]──┬───────────────┬──
   ┌─┴─┐       │               │
   │ v │       │             [R_i,k+1]
   │ok │       │               │
   └─┬─┘       │               │
     └─────────┴───────────────┘
```

前级**空载输出** vok 经过 Rok 和 Ri,k+1 分压后,才真正进入后级:

vin,k+1=vok⋅Ri,k+1Rok+Ri,k+1vin,k+1=vok⋅Rok+Ri,k+1

所以**前级的实际增益**变成:

Avk=Avk空载⋅Ri,k+1Rok+Ri,k+1Avk=Avk空载⋅Rok+Ri,k+1

**启示**:

- 如果 Ri,k+1≫RokRi,k+1≫Rok,几乎没损失——**后级高输入阻抗是好事**
- 如果 Ri,k+1≪RokRi,k+1≪Rok,大部分信号被分压吞掉——**增益严重损失**

这就是为什么**共集(高输入阻抗、低输出阻抗)放在中间或末尾做缓冲**效果这么好:它既不"拖累"前级,又能强力驱动后级。

#### 两级共射级联的例子

```
  v_i ─── 共射1 ──── 共射2 ─── v_o
         A_v1       A_v2
         R_o1       R_i2
```

前级空载增益 Av1空载=−gm1RC1Av1空载=−gm1RC1,但实际增益:

Av1=−gm1(RC1∥Ri2)=−gm1(RC1∥rbe2)Av1=−gm1(RC1∥Ri2)=−gm1(RC1∥rbe2)

RC1 通常几 kΩ,rbe2 也是几 kΩ——**两者并联后比 RC1 小得多**,前级增益大幅损失。

**两级共射级联的总增益** ≈ 前级受损增益 × 后级增益 ≈ 一级的平方……其实没想象的那么好。这就是为什么要用**共集做缓冲**。

---

### 7.6 输入/输出阻抗在级联中的计算

**总输入阻抗** = 第一级的输入阻抗(后级不影响)。

**总输出阻抗** = 最后一级的输出阻抗(前级不影响,因为我们从输出端往里看)。

**关键**:中间级的阻抗只影响"前级增益的加载"和"后级输入信号的大小",不影响总 Ri、Ro。

### 7.7 一个完整的多级放大器例子(概念示意)

```
  ┌───────┐     ┌───────┐     ┌───────┐
  │ 共集   │──→│ 共射  │──→│ 共集   │
  │ 输入级 │     │ 增益级 │     │ 输出级 │
  └───────┘     └───────┘     └───────┘
  R_i 高         A_v 大        R_o 低
  A_v≈1          R_o 中        A_v≈1

  级间用耦合电容(分立) or 直接耦合(集成)
```

**总体性能**:

- 输入阻抗:高(来自共集输入级)✓
- 电压增益:大(来自共射增益级)✓
- 输出阻抗:低(来自共集输出级)✓

**这就是运算放大器内部架构的简化版**。下下节课讲运放时你会看到。

### 7.8 这一课你必须带走的东西

1. **共集(射极跟随器)** 的核心价值是**阻抗变换**,不是放大:
 - Av≈1,同相
 - 基极看到的阻抗 = 发射极阻抗 ×(1+β)(**阻抗反射**)
 - 发射极看到的阻抗 = 基极侧阻抗 ÷(1+β)
 - 用途:**缓冲**,匹配高阻源或驱动低阻载
2. **共基** 的核心价值是**高频**:
 - 电压增益大、同相
 - 输入阻抗极低(≈re)
 - 没有密勒效应,带宽大
 - 常与共射组成 **Cascode** 结构
3. **三种组态的"分工"**:共射放大电压、共集匹配阻抗、共基应对高频。
4. **多级放大的核心思想**:让每级各司其职,组合出单级做不到的性能。
5. **级联公式**:总增益 = 各级增益乘积,但**每级增益要用"被后级加载后"的值**,因为前后级之间存在**阻抗分压**。
6. **耦合方式的权衡**:
 - 阻容耦合:各级独立,但不能放大直流
 - 直接耦合:能放直流,适合集成,但有零漂问题(引出下节课的差分放大器)
