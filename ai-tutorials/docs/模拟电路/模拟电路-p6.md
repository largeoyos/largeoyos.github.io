## 第 16 课:MOSFET 与 CMOS——现代电子的主角

### 16.1 BJT 为什么"输了"

到现在我们讲的所有放大器都用 BJT。但现实是:

- **所有数字 IC**(CPU、内存、手机芯片):**99.99% 是 MOSFET**
- **现代模拟 IC**(运放、电源管理、ADC/DAC、RF):**主流是 CMOS 或 BiCMOS**
- **3nm、5nm、7nm 工艺**:指的是 MOSFET 的最小尺寸

BJT 几乎只在分立元件、特殊高频/高功率场合存活。为什么?

**BJT 的根本问题**:

1. **基极有电流**(IB=IC/β)——大规模集成时几亿管子的基极电流加起来巨大,功耗不可接受
2. **集成密度受限**——BJT 的物理结构(发射区/基区/集电区垂直堆叠)难以小型化
3. **数字逻辑功耗高**——BJT 的导通需要持续的基极电流,不像 MOS 几乎"零静态功耗"

**MOSFET 的核心优势**:

1. **栅极几乎不消耗电流**——纯电压控制,功耗极低
2. **结构简单**,适合大规模集成,容易微缩
3. **CMOS 数字逻辑静态功耗几乎为零**——这是手机能用电池工作的关键

这一课带你从 BJT 的世界跨入 MOS 的世界。

### 16.2 MOSFET 的物理结构

**MOSFET = Metal-Oxide-Semiconductor Field-Effect Transistor**——**金属-氧化物-半导体场效应管**。

#### NMOS 结构

```
           栅 (G, Gate)
           │
        ───┴───  ← 多晶硅栅(过去是金属)
       │       │
    ───┤◤◢◤◢◤◢├───  ← 二氧化硅 SiO₂ 绝缘层(几纳米厚)
       │       │
    ───●───────●───
    │  N+  P衬底  N+ │
    │ 源 ─沟道─ 漏 │     ← 衬底是 P 型,源漏是 N+
    │      │       │
    └──────┼───────┘
           │
           衬底 B(Body)

   引脚:G(栅)、D(漏)、S(源)、B(衬底,通常接最低电位)
```

**关键结构特征**:

- **栅极 G**:一片导电材料(早期是金属,现代是重掺杂多晶硅),**与下面的硅完全绝缘**——**栅极电流 = 0**(理想)
- **源 S 和漏 D**:两个 N+ 高掺杂区,埋在 P 型衬底里
- **源漏之间是 P 型衬底**——正常情况下两个 N+ 区被 P 衬底隔开,**不导通**
- **栅极下方是关键区域**——施加正电压时,这里会形成"沟道"

#### 与 BJT 的核心区别

||BJT|MOSFET|
|---|---|---|
|控制方式|**电流**控制(IB)|**电压**控制(VGS)|
|输入电流|有(IB,小但非零)|**几乎为 0**(只有漏电流)|
|控制原理|PN 结注入|**栅极电场感应沟道**|
|载流子|电子+空穴(双极)|单一(NMOS 用电子,PMOS 用空穴)|

**MOS 是"场效应"——栅极不接触沟道,只通过电场远程控制**。这是它名字"Field-Effect"的由来。

### 16.3 MOSFET 的工作原理

#### 三个工作区(NMOS)

**变量约定**:

- VGS:栅源电压
- VDS:漏源电压
- VTH(或 VT,注意不要和热电压混):**阈值电压**(典型 0.5~1V)

##### 区域 1:截止区(VGS<VTH)

栅极电压不够,**栅极下方还没形成沟道**,源漏之间被 P 衬底隔开,**不导通**:

ID=0

相当于一个开关"断开"。

##### 区域 2:可变电阻区/三极管区(线性区)

条件:VGS>VTH 且 VDS<VGS−VTH

栅极电压足够高,把 P 型衬底里的少数载流子(电子)**吸引到表面**,在源漏之间形成一条**N 型反型层(沟道)**——源漏导通。

此时 VDS 较小,沟道是均匀的,**MOS 像一个"电压控制的可变电阻"**:

ID=μnCoxWL[(VGS−VTH)VDS−VDS22]ID=μnCoxLW[(VGS−VTH)VDS−2VDS2]

参数说明:

- μn:电子迁移率
- Cox:单位面积栅氧化层电容
- W/L:沟道宽长比(版图设计的关键参数)

**VDS 很小时简化**:

ID≈μnCoxWL(VGS−VTH)VDSID≈μnCoxLW(VGS−VTH)VDS

——**ID 正比于 VDS,沟道导通电阻 ∝1/(VGS−VTH)∝1/(VGS−VTH)**,可以通过调节 VGS 改变电阻。

**应用**:**MOS 作开关**(数字电路)、模拟开关、电压控制电阻。

##### 区域 3:饱和区(放大区)

条件:VGS>VTH 且 VDS>VGS−VTH

VDS 增大到一定程度,**沟道在漏端被"夹断"**——VGD=VGS−VDS<VTH,漏端不再有沟道。

但电子仍在沟道里加速,被夹断点处的强电场扫到漏极,ID 几乎不再随 VDS 增加:

ID=12μnCoxWL(VGS−VTH)2ID=21μnCoxLW(VGS−VTH)2

这就是**MOSFET 的"放大方程"**,类比 BJT 的 IC=βIB。

**注意**:

- ID 与 VGS−VTH 是**平方关系**(BJT 是指数关系)
- ID 几乎不依赖 VDS——和 BJT 放大区的水平特性曲线类似
- VGS−VTH 叫**过驱动电压(overdrive)**,记为 VOV,决定 MOS 的"工作强度"

#### 输出特性曲线

```
   I_D ↑
       │           饱和区(放大区)
       │       ╱──────────── V_GS = V_TH+1.5V
       │      ╱
       │     ╱──────────── V_GS = V_TH+1.0V
       │    ╱
       │   ╱──────────── V_GS = V_TH+0.5V
       │  ╱│
       │ ╱ │ 可变电阻区
       │╱ │
      ─┴───┴───────────────→ V_DS
      0  V_GS-V_TH (夹断点)
```

左半边:可变电阻区(类似 BJT 的饱和区) 右半边:饱和区(类似 BJT 的放大区) **注意命名陷阱**:**MOS 的"饱和区" = BJT 的"放大区"**。模电学到这里要在心里调整这个翻译。

### 16.4 NMOS 与 PMOS——互补对偶

#### NMOS

刚才讲的就是 NMOS:

- 衬底 P 型,源漏 N+
- VGS>VTH>0 时导通
- 沟道里**电子**导电
- VDS 为正(D 接高电位)

#### PMOS

**完全镜像**:

- 衬底 N 型,源漏 P+
- VGS<VTH<0 时导通(注意 VTH 对 PMOS 来说是负值)
- 沟道里**空穴**导电
- VDS 为负(D 接低电位)

电路符号上,PMOS 在栅极加一个圆圈表示"反相控制"。

**NMOS 和 PMOS 的互补性是 CMOS 的基础**——两者搭配,相互成就。

### 16.5 MOSFET 的小信号模型

类比 BJT 第 6 课。把 MOS 在 Q 点处线性化:

#### 跨导 gm

对饱和区方程求导:

gm=∂ID∂VGS∣Q=μnCoxWL(VGS−VTH)=2μnCoxWLIDgm=∂VGS∂IDQ=μnCoxLW(VGS−VTH)=2μnCoxLWID

也可写为:

gm=2IDVGS−VTH=2IDVOVgm=VGS−VTH2ID=VOV2ID

**关键对比**:

- BJT:gm=IC/VT,VT≈26 mV(常数)
- MOS:gm=2ID/VOV,VOV 几百 mV(设计可调)

**同样的电流下,BJT 的 gm 比 MOS 大得多**(因为 VT≪VOVVT≪VOV)——这是 MOS 的一个**先天缺点**:跨导效率低。

弥补方法:**做大 W/L,即用大尺寸管子**——这也是为什么模拟 CMOS 电路里管子常常很大,而数字电路追求小管子。

#### 输入阻抗 rgs

栅极绝缘,理想为 ∞∞。实际有微小漏电流,但通常忽略——**MOS 输入阻抗几乎无穷大**。

这是 MOS 相对 BJT 的一个**重大优势**:接什么阻抗源都不"加载"。

#### 输出阻抗 rds

实际中 ID 还是会随 VDS 缓慢增加(**沟道长度调制效应**),用一个参数 λ 描述:

ID=12μnCoxWLVOV2(1+λVDS)ID=21μnCoxLWVOV2(1+λVDS)

输出电阻:

rds=1λIDrds=λID1

典型 rds 几十 kΩ 到几 MΩ。

#### 小信号等效电路

```
      G ●───────────────────● D
                              │
                            [g_m·v_gs]   ↓
                              │
                            [r_ds]
                              │
      S ●───────────────────●
```

**和 BJT 模型几乎一样**,差别就是没有 rbe(栅极绝缘,断开)。

### 16.6 MOSFET 放大器——共源、共漏、共栅

完全对应 BJT 的共射、共集、共基:

|MOS|BJT|
|---|---|
|共源(CS)|共射(CE)|
|共漏(CD,**源极跟随器**)|共集(C,**射极跟随器**)|
|共栅(CG)|共基(CB)|

#### 共源放大器

```
                V_DD
                 │
                [R_D]
                 │
                 ●──── v_o
                 │
              ──┤ D
        v_i ──┤G       NMOS
              ──┤ S
                 │
                ─┴─ 地  (有时串 R_S 然后旁路 C_S)
```

电压增益:

Av=−gmRD

**和共射几乎一样**——负号表示反相,增益值由 gm 和负载电阻决定。

**主要差异**:

- 输入阻抗**极高**(MOS 栅绝缘),不像共射的几 kΩ
- 同样电流下,gm 比 BJT 小,所以增益**普遍比 BJT 共射略低**

#### 源极跟随器(共漏)

类比射极跟随器:**电压增益 ≈ 1,输入阻抗极高,输出阻抗低**——更完美的缓冲器。

由于 MOS 输入阻抗本身就极高,源极跟随器作为缓冲特别理想——不需要前级电流,完全的"电压采样"。

#### 共栅

类比共基,高频特性好,与共源组合成 **MOS Cascode**——用于精密模拟设计。

### 16.7 CMOS——数字逻辑的基石

#### CMOS 反相器(Inverter)

**最简单的 CMOS 电路:一个 PMOS + 一个 NMOS**:

```
           V_DD
            │
        ────┤P  ← PMOS
            │
            ●──── 输出 v_o
            │
        ────┤N  ← NMOS
            │
           地

   两个栅极连在一起 ── 输入 v_i
```

#### 工作原理

**输入 = 高(V_DD)**:

- NMOS:VGS,N=VDD>VTH → **导通**
- PMOS:VGS,P=0−VDD=−VDD < VTH,PVTH,P(负值) → **导通?** 等等

让我重画。PMOS 的源接 VDD,栅是输入:

- 输入高:PMOS 的 VGS,P=Vin−VDD=0 → **截止**
- 同时 NMOS 导通 → 输出被 NMOS 拉到地 → vo=0(低)

**输入 = 低**:

- NMOS:VGS,N=0<VTH → **截止**
- PMOS:VGS,P=−VDD,绝对值大于 ∣VTH,P∣∣VTH,P∣ → **导通**
- 输出被 PMOS 拉到 VDD → vo=VDD(高)

**总结**:输入高 → 输出低,输入低 → 输出高——**反相器**(NOT 门)。

#### CMOS 的精妙——零静态功耗

**关键观察**:无论输入是高还是低,**总有一个管子截止**——电流路径被切断,**静态电流 = 0**。

只有在输入**翻转的瞬间**,两个管子都短暂导通,有一小段电流——这是**动态功耗**,正比于翻转频率。

**结论**:CMOS 静态功耗 ≈ 0,动态功耗 ∝f⋅C⋅VDD2∝f⋅C⋅VDD2。

**这就是手机能用电池工作的根本原因**——大量逻辑门,只有正在翻转的少数管子在耗电。如果用 BJT 做同样的逻辑(早期的 TTL 工艺),功耗会高几个数量级,根本不可能集成上亿管子。

#### 从反相器到一切

把反相器扩展:

- **NAND**:两个 NMOS 串联到地,两个 PMOS 并联到 VDD
- **NOR**:两个 NMOS 并联到地,两个 PMOS 串联到 VDD
- **复杂逻辑**:任何布尔函数都能用 PMOS 上拉 + NMOS 下拉网络实现

**CPU、GPU、内存的全部数字逻辑——本质是几亿个 CMOS 反相器及其变体的网络**。

### 16.8 电流镜——模拟集成电路的"万能工具"

到这里我们准备进入第二个核心概念——**电流镜**。这是所有现代模拟 IC 的核心积木。

#### 问题:集成电路里怎么提供恒定电流?

分立电路里恒流源可以用电池+电阻或专门的恒流二极管。集成电路里:

- **大电阻又大又费版图**——10 kΩ 在硅片上占巨大面积
- **要给 100 个放大器各提供 100 μA 偏置**——不能放 100 个独立恒流源

**解决方案:电流镜——一个参考电流"复制"到多个地方**。

#### 基本电流镜结构(BJT 版本)

```
              V_CC
               │
              [R]   ← 设定参考电流
               │
               ●────────●
               │        │
              ─┤ T1    ─┤ T2  ← T1、T2 完全相同
            ┌─┤ B    ┌─┤ B
            │  │     │  │
            └──┴─────┘  │
               │        │
               E        E
               │        │
              ─┴─      ─┴─
              地        地

   T1 的 B 和 C 短接 ── 起"模板"作用
   T2 与 T1 共用同样的 V_BE ── 输出电流 = 参考电流
```

#### 工作原理

- T1 接成"二极管接法"(B 和 C 短接),IREF 流过 T1,**确定它的 VBE**
- T2 与 T1 **完全匹配**(同一硅片,相邻位置,工艺一致),**共用同一个 VBE**
- 由 BJT 的 IC=ISeVBE/VT 关系,**IC,T2=IC,T1=IREF**

**输出电流 = 参考电流**——T2 像一个"镜像",复制了 T1 里的电流。

#### 电流镜的关键性质

1. **输出阻抗高**:T2 工作在放大区,ro 几十 kΩ,接近理想恒流源
2. **可"镜像放大"**:让 T2 的发射区面积是 T1 的 N 倍,Iout=N⋅IREF
3. **多输出**:并联多个 T2',T2''……同时给多个电路供电
4. **节省版图**:一个 R(可以做大)就能给整个芯片提供基准

#### MOS 电流镜

完全类似,把 BJT 换成 NMOS:

```
              V_DD
               │
              [R]
               │
               ●────────●
               │        │
             ──┤        ├──   两个 NMOS 共用 V_GS
        ──┐ ──┤M1     M2├── ──┐
        │  │  │        │  │  │
        └──┴──┘        └──┴──┘
               │        │
              地       (输出端)

   M1 的 G 和 D 短接
   M2 复制 M1 的电流
```

通过调节 W/L 比例,可以镜像放大或缩小:

Iout=(W/L)M2(W/L)M1⋅IREFIout=(W/L)M1(W/L)M2⋅IREF

#### 电流镜在运放里

第 8 课讲过差分放大器需要"尾电流源"——**就是用电流镜实现的**。

差放的有源负载(把第 8 课最后提到的"用电流源代替集电极电阻")**也是电流镜**。

可以说:**没有电流镜就没有现代集成运放**。运放内部从输入级偏置、有源负载、到输出级,全是各种电流镜的变种。

### 16.9 MOS 与 BJT 的对比——什么时候用什么?

||BJT|MOSFET|
|---|---|---|
|跨导效率|**高**(gm=IC/VT)|低(gm=2ID/VOV)|
|输入阻抗|中(rbe)|**极高**(栅绝缘)|
|噪声特性|**低频噪声小**|低频 1/f 噪声大|
|速度|**高频快**(BJT 高频管 fT 几十 GHz)|取决于工艺(7nm 工艺 fT 数百 GHz)|
|静态功耗(数字)|高|**极低**|
|集成密度|低|**极高**|
|工艺成熟度|成熟,但工艺停滞|**持续微缩**(摩尔定律)|
|大功率|**大功率传统强势**|现代 MOS 也能做几百 W|

**现代选择**:

- **数字 IC**:几乎全 CMOS
- **大规模模拟 IC**(运放、ADC、DAC、电源、RF):主流 CMOS,高性能用 BiCMOS(BJT + CMOS 混合)
- **离散功放、高频 RF**:BJT 仍有优势,特别是低噪声放大器(LNA)
- **超高频微波**:GaAs、GaN 等化合物半导体,但物理原理类似

### 16.10 这一课你必须带走的东西

1. **MOS 是场效应管**:栅极绝缘,**电压控制**,栅极电流 ≈ 0——这是 MOS 相对 BJT 的根本优势。
2. **MOS 三个工作区**:

 - 截止(VGS<VTH):ID=0
 - 可变电阻区(VDS<VOV):像电压控制电阻
 - 饱和区(VDS>VOV):**这里才能放大**,ID=12μCox(W/L)VOV2ID=21μCox(W/L)VOV2

**命名陷阱**:MOS 的"饱和"= BJT 的"放大"。
3. **MOS 小信号参数**:gm=2ID/VOV,**比 BJT 同电流下小**——MOS 跨导效率较低,要靠大 W/L 弥补。
4. **MOS 放大器三种组态(共源/共漏/共栅)** 完全对应 BJT 的(共射/共集/共基),**分析方法和公式形式几乎一样**。
5. **CMOS 反相器**:NMOS + PMOS 互补,**静态功耗 ≈ 0**,这是手机/便携设备能存在的根本原因。**所有数字逻辑都建立在 CMOS 反相器之上**。
6. **电流镜**:集成电路的"万能工具",一个参考电流复制到多处。运放内部全是电流镜。
7. **现代选择**:数字 = CMOS,大规模模拟 = CMOS 或 BiCMOS,高频/低噪声 = BJT 或化合物半导体。
8. **学到这里,此前已经站在分立元件电路和集成电路设计的分水岭上**。前面 15 课几乎全用 BJT,你看到的是经典模电;这一课打开了现代 IC 设计的入口。

## 第 17 课:模拟集成电路设计入门

到这里,此前已经掌握了模电的全部核心工具:BJT、MOS、差放、反馈、频率响应、运放、滤波器、电流镜……

这一课不是新概念的堆砌,而是**把这些工具组合起来,看真实的集成电路是怎么设计的**。当你看完这一课,再去看一颗运放或电源芯片的 datasheet 内部框图,你应该能认出每一块在干什么。

---

### 17.1 集成电路设计的"思维转变"

分立元件电路和集成电路设计在思维方式上有几个关键差异,先讲清楚:

#### 1. 电阻贵,管子便宜

分立元件:**电阻最便宜**(1 美分),晶体管贵(10 美分)。 集成电路:**完全相反**——一个 10 kΩ 电阻占的硅片面积远大于一个晶体管,而硅片面积 = 钱。

**结果**:IC 设计师**用晶体管代替电阻**——能用电流镜的地方绝不用电阻,能用 MOS 当电阻的地方绝不用真电阻。这是为什么集成运放电路图里**全是管子**。

#### 2. 绝对值不准,相对值很准

集成电路工艺:

- 单个电阻的绝对值误差 ±20% 是常态
- 但**两个紧挨着的电阻之间的比值,误差可以小于 0.1%**

**结果**:IC 设计**避免依赖绝对值**,**充分利用比值匹配**。电流镜就是典型——输出电流由 W/L 比值决定,绝对值不重要。

#### 3. 温度对所有元件相同

整片硅片温度一致——这是差分对、电流镜能工作的根本前提。

#### 4. 不能用大电感、大电容

电感几乎做不出来(低频下需要的尺寸太大),电容也只能做小(几 pF 到几十 pF)。

**结果**:IC 里的滤波几乎都是 RC 或开关电容,极少 LC。需要大电容时只能"外挂"——这就是芯片为什么有"补偿电容"的外接引脚。

### 17.2 一个完整的两级 CMOS 运放

我们用前面所有学过的东西,搭出一个能用的运放。

#### 整体结构

```
   ┌─────────────────────────────────────────────────┐
   │                                                  │
   │  ┌──────────┐         ┌──────────┐              │
   │  │ 差分对   │  →     │ 共源放大 │  →   v_o     │
   │  │ + 镜像负载│        │ + 米勒电容│              │
   │  └──────────┘         └──────────┘              │
   │       ↑                     ↑                    │
   │       │ 偏置电流              │ 偏置电流          │
   │       └──── 电流镜偏置网络 ──┘                  │
   │                                                  │
   └─────────────────────────────────────────────────┘
```

**三大模块**:

- **第一级**:差分对 + 镜像负载(电压增益级 1)
- **第二级**:共源放大器(电压增益级 2)
- **偏置网络**:用电流镜给所有级提供恒定偏置

#### 详细电路图(经典 Two-Stage Op-Amp)

```

              │         │         │           │
            ──┤M5     M3├──     ──┤M7        │
              │         │         │           │
              ●─────────●         ●           │
              │                   │           │
              │     ┌─────────────┘           │
              │     │                          │
              │   ●─┤    ┌─[Cc]──●            │
              │   │ │    │       │            │
       v_+ ───┤M1 │ │M2 ├─── v_− │           │
              │   │ │    │       │            │
              │   ●─┤    ●───────●─── v_o   │
              │     │    │                    │
              │     │  ──┤M4                  │
              │     │    │                    │
              │     │    ●─────────●          │
              │     │              │          │
              │     │            ──┤M6 (或M8)│
```

我承认这个图有点乱。我把每个管子的角色用清单方式说清楚:

|管子|角色|
|---|---|
|M1, M2|差分对(N 沟道,源接尾电流源,漏接负载)|
|M3, M4|镜像负载(P 沟道电流镜,作为差分对的有源负载)|
|M5|偏置电流镜的"主"管|
|M9|差分对的尾电流源(从 M5 镜像)|
|M6|第二级共源放大器的输入管|
|M7|第二级的有源负载(从 M5 镜像)|
|Cc|米勒补偿电容(防止反馈电路自激)|

#### 第一级:差分对 + 镜像负载

这是第 8 课的差放 + 第 16 课的电流镜的组合。

- **M1、M2 差分对**:接受输入信号 v+v+、v−v−
- **M9 尾电流源**:用电流镜从基准电流复制,提供恒定 Itail
- **M3、M4 镜像负载**:**关键创新**——不再用电阻 RD 作负载,而是用 PMOS 电流镜

**为什么用电流镜做负载?** 第 8 课提过——"有源负载"。

普通电阻 RD 几 kΩ,差放增益 gmRD 顶多几十倍。 **电流镜的输出电阻 ro 几百 kΩ 到 MΩ**——增益 gmro 可达几千甚至上万倍。

**第一级增益**:

Av1=−gm1(ro2∥ro4)Av1=−gm1(ro2∥ro4)

典型值 100~1000 倍。

#### 第二级:共源放大 + 米勒补偿

- **M6**:N 沟道共源,放大第一级输出
- **M7**:P 沟道电流镜负载

**第二级增益**:

Av2=−gm6(ro6∥ro7)Av2=−gm6(ro6∥ro7)

典型 100~500 倍。

**总增益**:Av1×Av2≈104∼106Av1×Av2≈104∼106——经典运放开环增益。

#### 米勒补偿电容 Cc

**反馈稳定性**(第 11 课)的工程实现。

两级运放有两个极点,在用作负反馈放大器时容易自激。Cc 接在第二级共源管的栅漏之间——**密勒效应**(第 12 课):从第二级输入端看,Cc 等效成 (1+∣Av2∣)Cc,产生一个**很低频的主极点**。

效果:在 ∣AF∣=1 处之前,环路相位还远未达 180°,**相位裕量充足,系统稳定**。

**这是密勒效应的"反派变英雄"**——共射/共源放大器的高频性能杀手,在两级运放里被故意利用,变成稳定性的救星。

#### 实际芯片

经典 μA741(BJT 实现)、CA3140(JFET 输入 + BJT)、TL082(JFET 输入 + 双极)、LM358(双极)、MCP6V81(CMOS 自动校零)——内部结构都是上面这个套路的变种。

### 17.3 基准电压源——一个被忽视的英雄

#### 为什么需要"基准"

ADC 把模拟电压转成数字,需要一个"标尺"——0V 对应 0,VREF 对应满刻度。**VREF 不准,所有测量都不准**。

类似地:

- DAC:把数字数转成模拟电压,需要 VREF
- 比较器:阈值要稳定
- 电源芯片:输出电压由内部基准决定

**要求**:

- 不随**电源电压变化**(电源 5V 变 4.8V,基准纹丝不动)
- 不随**温度变化**(芯片从室温到 70°C,基准变动 < 0.01%)
- 长期**老化稳定**

#### 难点

**单一物理量很难同时不依赖电源和温度**:

- 电阻分压:依赖电源
- 齐纳二极管:温度系数大
- VBE:温度系数 −2 mV/°C(负)
- 热电压 VT=kT/q:温度系数 +0.085 mV/°C(正)

但是**最后两条加在一起,可能正好抵消**——这就是带隙基准的核心想法。

#### 带隙基准(Bandgap Reference)

**1971 年 Robert Widlar 发明**——模拟 IC 设计史上的里程碑。

**原理**:把两个温度系数相反的电压**按权重相加**,使总温度系数为 0:

VREF=VBE+K⋅VT

- VBE:负温度系数 ≈ −2 mV/°C
- VT:正温度系数 ≈ +0.085 mV/°C
- 选 K≈23,使两者相加的温度系数为 0

**最终 VREF 约 1.25 V**——非常接近硅的禁带宽度(1.12 eV),所以叫"**带隙**"基准。

#### 怎么得到 VT

利用**两个工作在不同电流密度的 BJT 之间的 VBE 差值**。

由 VBE=VTln(IC/IS):

ΔVBE=VBE1−VBE2=VTln(IC1IC2)ΔVBE=VBE1−VBE2=VTln(IC2IC1)

**这个差值正比于 VT**,即正比于绝对温度——叫 **PTAT(Proportional To Absolute Temperature)** 电压。

通过电阻把 ΔVBE 放大 K 倍,加到一个 VBE 上,就得到带隙基准。

#### 经典电路(简化示意)

```
              V_CC
               │
          ┌────●────┐
          │         │
         [I1]      [I2 = N·I1]   (用电流镜得到不同电流)
          │         │
          ●         ●
       Q1│        Q2│   面积比 1 : N
          │         │
       V_BE1     V_BE2
          │         │
         地       [R_1]
                    │
                  [R_2]
                    │
                   地

    输出 V_REF = V_BE1 + (R_1+R_2)/R_2 × ΔV_BE
              ≈ V_BE + 23 V_T ≈ 1.25V
```

实际电路用反馈把 VBE1 和 VBE2 之差精确地建立在 R1 上,具体推导省略——核心思想就是上面那个抵消。

#### 性能

好的带隙基准:

- 温度系数:几 ppm/°C(0.0001%/°C)
- 电源抑制比:80 dB+
- 长期漂移:几十 ppm/年

经典芯片:LM385(2.5V)、LT1009、MAX6126……

带隙基准嵌在几乎每一颗 ADC、DAC、电源 IC 里。**是最普及但最不被注意的电路**。

### 17.4 比较器与模数转换

#### 比较器 = 没有反馈的运放

比较器的功能:输出告诉你 v+v+ 和 v−v− 哪个大。

vo={VHv+>v−VLv+<v−vo={VHVLv+>v−v+<v−

第 9 课讲过,运放开环增益极大,稍有差异就饱和——**这就是比较器**。

但**专用比较器芯片**(如 LM311、LM393、LMV7235)和运放有重要区别:

- **响应快**:不带补偿电容,几十 ns 响应(普通运放 μs 级)
- **输出可推灌**(open collector / open drain),便于驱动数字逻辑
- **不用作线性放大**,所以稳定性问题不存在

#### 施密特触发器(Schmitt Trigger)——抗噪声比较

普通比较器问题:**输入信号在阈值附近抖动时,输出反复跳变**——产生大量虚假翻转。

**解决**:**正反馈引入双阈值**(回差)。

```
                        R_f
              ┌────────[R_f]────────┐
              │                      │
    v_i ●──── v_−                    │
                 │\                  │
                 │  >────────────────●── v_o
                 │  /
              ●──┘
              │
             [R_1]
              │
             地     (v_+ 接到 R_1 和 R_f 中点,
                     被输出反馈"自我加强")
```

工作原理:

- vo 高时,v+=VH⋅R1/(R1+Rf)>0 → 阈值偏高,**抗输入下行干扰**
- vo 低时,v+=VL⋅R1/(R1+Rf)<0 → 阈值偏低,**抗输入上行干扰**

输入电压必须**穿过更宽的范围**才能让输出翻转,中间的小抖动被忽略——**回差(hysteresis)**。

应用:

- 数字电路输入端:噪声抑制(74HC14 等芯片)
- 比较器去抖:按键去抖
- 弛豫振荡器:第 14 课的方波发生器内部就是施密特结构

#### 模数转换器(ADC)概览

把模拟电压变成数字数。三种主流架构:

##### Flash ADC(并行 ADC)

**最快,最贵**。

n 位 Flash ADC = 2n−1 个比较器并联,每个的阈值由分压电阻产生。一次比较出全部位。

```
   v_i ──┬── 比较器1 (阈值 = V_REF·1/8)
         ├── 比较器2 (阈值 = V_REF·2/8)
         ├── 比较器3 (阈值 = V_REF·3/8)
         ...                                → 编码器 → 数字输出
         └── 比较器7 (阈值 = V_REF·7/8)
```

8 位需要 255 个比较器,功耗大、面积大。但速度快(单比较周期),**用于 GHz 采样的高速 ADC**(示波器、雷达)。

##### 逐次逼近 ADC(SAR)

**主流通用**,速度中等(MSPS 级),精度高(12~18 位)。

工作流程(二分搜索):

1. 第一步:猜中间值 VREF/2,与 vi 比较 → 决定最高位 MSB
2. 第二步:根据 MSB,猜上半区或下半区的中间 → 第二位
3. 重复 n 次 → 得到 n 位结果

类似猜数字游戏,n 个时钟周期完成 n 位转换。

**用一个比较器 + 一个 DAC + 控制逻辑**,效率极高。

应用:工业测量、电池监控、传感器接口——**最常见的 ADC 类型**。

##### Δ-Σ(Delta-Sigma)ADC

**最高精度**(24 位),速度慢(kHz 级)。

工作原理(简述):

- 用极高的采样率(几 MHz)对信号过采样
- 利用反馈把量化噪声推到高频
- 用数字滤波器去除高频噪声,提取低频信号

适合**音频(24 位)、精密测量、称重传感器**。

#### DAC——反向操作

DAC 把数字数变模拟电压。常见结构:

- **电阻分压**:每位对应一个电阻分支
- **R-2R 梯形网络**:用两种电阻值即可实现任意位数,集成性好
- **电流舵 DAC**:高速场合(视频 DAC、RF DAC)
- **Δ-Σ DAC**:高精度音频(数字音频播放器)

### 17.5 电源管理 IC

电池给的电压不稳定(锂电池 3.0~4.2V),芯片要稳定的 1.8V、3.3V、5V——需要电源管理。

#### 线性稳压器(LDO)

**Low Dropout Regulator**——最简单的稳压器。

```
          V_in
           │
        ──┤ M1 (功率管,P 沟道 MOS 或 PNP BJT)
        ──┤
           │
           ●─── V_out ── 负载
           │
       ┌───┤
       │   │
      [R_1]│
       │   │   反馈到运放,与 V_REF 比较
       │   │   形成负反馈,稳定 V_out
      [R_2]│
       │   │
       └───┘

    [V_REF]──● 运放 ●──→ 控制 M1 的栅
             │         │
             └─ 反馈 ──┘
```

**原理**:运放比较反馈电压和 VREF,调节功率管的导通程度,使 Vout 等于 VREF⋅(R1+R2)/R2。

**优点**:

- 输出干净(无开关纹波)
- 设计简单
- 响应快

**缺点**:

- **效率 = Vout/Vin**——电压差全部变成功率管发热
- 5V 转 1.8V:效率只有 36%,大部分功率被浪费成热

**应用**:小电流(< 1A)、对噪声敏感(模拟电路供电、射频供电)、电压差不大的场合。

经典芯片:LM7805、AMS1117、TPS7A47……

#### 开关电源(DC-DC Converter)

利用**电感储能**和**晶体管开关**,实现**高效率电压变换**。

##### Buck(降压)电路

```
                   L
   V_in ──┤────●──[L]──●─── V_out ── 负载
          │   │         │
          │   │        [C]
          │   │         │
       开关  二极管     地
       (MOS) (或同步MOS)
          │   │
         地  地
```

**工作原理**:

- 开关闭合:Vin 通过电感给负载和 C 供电,电感储能
- 开关断开:电感释放能量,通过二极管(或同步整流 MOS)继续给负载供电

通过控制开关的**占空比 D**,平均输出电压:

Vout=D⋅Vin

**理论效率 100%**(开关无损耗),实际 90%+。

**降压、升压、升降压、隔离(反激/正激)**——同样原理的不同拓扑。

##### 关键控制

开关电源芯片内部:振荡器(几百 kHz 到几 MHz)+ PWM 控制器 + 误差放大器 + 反馈环路 + 过流过压保护。

经典芯片:LM2596(降压)、MP1584(降压)、MT3608(升压)、TPS61040(升压)、LM5117(同步)……

#### LDO vs 开关电源选择

||LDO|开关电源|
|---|---|---|
|效率|低(Vout/Vin)|高(85-95%)|
|噪声|极低|有开关纹波|
|复杂度|低|高(电感 + 控制)|
|成本|低|高|
|体积|小|较大|
|响应速度|快|慢|

**典型实践**:电池 → 高效降压(开关电源)→ 中间电压 → LDO → 干净电压给敏感电路。两者结合用。

### 17.6 这一课你必须带走的东西

1. **IC 设计的思维**:用管子代替电阻,**靠匹配和比值,不靠绝对值**,温度对所有元件相同。
2. **两级 CMOS 运放架构**:差分对 + 镜像负载(第一级)→ 共源 + 米勒补偿(第二级)。前面所有概念在这里都用到——差放、电流镜、有源负载、密勒效应、负反馈稳定性。
3. **米勒效应的两面**:共源高频性能的杀手 vs 两级运放稳定性的救星。同一物理现象,在不同工程目标下意义相反。
4. **带隙基准**是 IC 里最普遍的"无名英雄"。原理:**VBE(负温度系数) + K⋅VTK⋅VT(正温度系数)** 抵消,得到 ≈ 1.25V 的不随温度变化的基准。所有 ADC、DAC、电源芯片内部都有带隙基准。
5. **比较器**:开环运放,但优化了速度。**施密特触发器** 用正反馈引入回差,抗噪声。
6. **三种 ADC 架构**:
 - Flash:最快最贵,GHz 级采样
 - SAR:速度精度平衡,最常用
 - Δ-Σ:最高精度,慢,适合音频/称重
7. **两类电源管理**:
 - LDO:线性,效率 = Vout/Vin,适合小电流和敏感电路
 - 开关电源:利用电感,效率 90%+,适合大电流和电池供电
8. **从这一课开始,你不再是模电学习者,而是 IC 设计的入门者**——你能看懂芯片厂商的内部框图,理解他们在用什么手段实现什么指标。

## 第 18 课(终章):学完模电之后——一张地图,一种思维

到这一课为止,模电的核心知识体系完整闭合。这最后一课不讲新电路,而是回头看一眼整个旅程,然后告诉你前方有什么——以及此前已经具备了什么。

### 18.1 回望:这十七课你究竟学了什么

我把你走过的路画一张图:

```
   电压、电流、功率(基础)
            │
            ▼
       PN 结物理
            │
            ▼
        二极管(单向开关)
            │
            ▼
        BJT(电流控制电流源)
            │
            ▼
   ┌────── Q 点 ──────┐
   │                    │
   ▼                    ▼
   小信号模型         多级放大
   (单级分析)        (组合应用)
            │
            ▼
        差分放大(对称消零漂)
            │
            ▼
        集成运放(封装的智慧)
            │
            ▼
   ┌──── 反馈 ────┐
   │                │
   ▼                ▼
   稳定增益       振荡器
   滤波器        信号产生
            │
            ▼
   功率放大(从信号到能量)
            │
            ▼
   MOSFET 与 CMOS(现代主角)
            │
            ▼
   集成电路设计(运放/基准/ADC/电源)
```

这条路有一条贯穿始终的暗线——**"用反馈和对称塑造理想化"**。

- 二极管的指数特性 → 用偏置压降近似为 0.7V("理想化"它)
- BJT 的 β 不稳定 → 用电流串联负反馈让增益由外部电阻决定("反馈塑造")
- 直接耦合的零漂 → 用对称的差放消除("对称抵消")
- 运放的开环增益太大太不稳 → 用深度负反馈让 Af≈1/F("反馈分配")
- 功率管的非线性 → 用全局负反馈减小失真("反馈压制")
- 振荡器漂移 → 用晶体的高 Q 锁定频率("机械替代电学")

模电不是一堆电路图的集合,而是一套**用工程手段把不完美的器件变得理想化**的方法论。这种思想会贯穿你整个工程生涯,远超模电本身。

---

### 18.2 模电之后的五大方向

模电是一个分岔路口。从这里出发,你可以走向五个方向。每个方向都需要继续学习,但起点都是你现在站的地方。

#### 方向 1:模拟集成电路设计(Analog IC Design)

**做什么**:设计运放、ADC、DAC、电源管理芯片、传感器接口、射频前端等模拟 IC。

**核心后续课程**:

- 半导体器件物理(深入 MOS 和 BJT 的物理细节)
- 模拟集成电路分析与设计(本科高级 / 研究生入门)
- 射频集成电路 / 数据转换器
- 版图设计(Cadence、Virtuoso)

**典型雇主**:TI、ADI、Maxim、Linear、华为海思、汇顶、芯原、紫光展锐、思瑞浦……

**特点**:门槛高、回报高,招聘看研究生学历和项目经验,需要极强的模电直觉 + 工艺/版图知识。

#### 方向 2:射频与微波(RF/Microwave)

**做什么**:手机射频前端、WiFi/蓝牙模块、卫星通信、雷达、5G/6G 系统。

**与模电的关系**:GHz 级别下,所有电路设计都不再是简单的"放大器+滤波器"——传输线效应、阻抗匹配、Smith 圆图、S 参数主导一切。但 BJT/MOS 的高频模型、密勒效应、Cascode 结构都是核心工具。

**核心后续课程**:

- 电磁场与电磁波
- 微波工程(Pozar 经典教材)
- 射频电路设计
- 天线理论

**特点**:数学(电磁学)负担重,但中国正大力发展(5G/6G/雷达),职业前景好。

#### 方向 3:电源与功率电子(Power Electronics)

**做什么**:开关电源、电机驱动、电动汽车充电桩、光伏逆变器、储能系统。

**与模电的关系**:本课讲的功放、开关电源是入门;真正的功率电子涉及高电压(几百 V 到几千 V)、大电流(几十 A 到几千 A)、IGBT、SiC、GaN 新型器件、复杂控制策略。

**核心后续课程**:

- 电力电子技术(王兆安经典教材)
- 自动控制原理(因为电源是反馈控制系统)
- 电机学
- 现代控制理论

**特点**:与"双碳"战略、新能源汽车直接相关,**未来 10 年最热门的工科方向之一**。

#### 方向 4:信号处理 / 嵌入式系统(应用工程师方向)

**做什么**:不设计芯片,而是**用芯片**——用现成的运放、ADC、传感器搭建产品(医疗设备、工业仪表、智能家居、机器人……)。

**与模电的关系**:你不需要设计运放,但你必须**知道怎么选运放,怎么搭电路,怎么排错**。这一课讲的所有内容(看 datasheet、调试、布局)都是核心技能。

**核心后续课程**:

- 数字电路 + 微机原理(单片机 STM32、嵌入式 Linux)
- 信号与系统 / 数字信号处理
- 通信原理
- 实际项目经验

**特点**:**就业最广**——99% 的电子工程师做的是这件事。门槛比 IC 设计低,但要求"博"——模电、数电、嵌入式、通信都得懂。

#### 方向 5:半导体器件物理 / 工艺(研究方向)

**做什么**:研究新型器件(GaN、SiC、量子器件)、新工艺(7nm 以下的物理极限)、新材料。

**与模电的关系**:模电是器件的"应用层",器件物理是"基础层"。深入研究 MOSFET 物理、量子效应、纳米器件……

**核心后续课程**:

- 半导体物理学(刘恩科,经典教材)
- 半导体器件物理(Sze 经典)
- 量子力学
- 凝聚态物理

**特点**:**学术性最强**,典型路径是博士 → 高校 / 研究所 / 大公司研发(台积电、Intel、中芯国际研发部门)。

### 18.3 推荐教材(经过实战检验)

**入门巩固**(继续打底子,看完前 17 课后用):

- **童诗白《模拟电子技术基础》** —— 中国主流教材,你学校大概率用的就是这本或华成英的版本。系统、严谨、配套习题多。建议你**精读一遍**,用作正规复习。
- **Boylestad《Electronic Devices and Circuit Theory》** —— 美国经典本科教材,结构清晰、图多、易读,英文不难。

**进阶深化**(本科末期 / 研究生):

- **Sedra/Smith《Microelectronic Circuits》** —— **强烈推荐**。北美电子工程本科最常用,深度和广度都比国内教材好,从二极管到 IC 设计一气贯通。第七版以后内容相当现代。
- **Razavi《Design of Analog CMOS Integrated Circuits》** —— **模拟 IC 设计的圣经**。Razavi(UCLA 教授)是当今模拟设计领域顶尖学者。读这本意味着你正式进入 IC 设计领域。
- **Gray/Hurst/Lewis/Meyer《Analog Integrated Circuit Design》** —— Razavi 的高阶替代,更深、更难,博士级。

**经典补充**:

- **Horowitz/Hill《The Art of Electronics》(《电子学》)** —— 不是教科书,是**工程师的圣经**。70% 模电、30% 数电,从初学到资深工程师都能从中汲取。这本书的特点是**"实践智慧"**——告诉你"为什么实际电路这么设计"而不是"理论上应该怎么设计"。强烈建议每个电子工程师都拥有一本。

**中文优秀补充**:

- **谢嘉奎《电子线路(线性部分)》** —— 中国老牌电子教材,推导细致。
- **冯军/谢嘉奎《电子线路(非线性部分)》** —— 同上,讲振荡、调制等。

### 18.4 必备实践技能

模电不是只看书就能学好的——**电路是"调"出来的,不是"算"出来的**。

#### 技能 1:仿真软件

- **LTspice**(免费,ADI 出品,业界标准)—— 最强大的免费 SPICE 仿真器。学会它,你可以验证任何模电电路。
- **Multisim**(NI 出品,中国学校常用)—— 界面友好,适合教学。
- **TINA-TI**(TI 提供)—— 适合验证 TI 的运放电路。

**建议**:**前 17 课的每一个核心电路都在 LTspice 里搭一遍**。看波形、扫频率、改参数——你会理解得比纯算公式深 10 倍。

#### 技能 2:实物焊接与调试

仿真和实物有差距。学会:

- 万用表(测电压、电阻、二极管压降)
- 示波器(看波形、测频率、看相位)—— **现代电子工程师最重要的工具**
- 信号发生器(产生测试信号)
- 直流电源(给电路供电)
- 焊接(烙铁、热风枪、贴片元件)

最低投入:几百块买一套学生级面包板 + 万用表 + 廉价示波器(Hantek、OWON 入门款)+ 烙铁。

#### 技能 3:看懂 datasheet

**模电工程师的核心技能之一**。一颗运放(如 OPA227)的 datasheet 通常 30 页,包含:

- Electrical Characteristics(电气参数表)—— 选型核心
- Typical Performance Curves(典型性能曲线)—— 看温度、频率、电源对参数的影响
- Application Information(应用电路)—— 经典电路案例
- Package Information(封装)—— PCB 设计用

**练习**:挑一颗你感兴趣的芯片(LM358、NE5532、TL072 等),把 datasheet 通读一遍,标出每个参数的含义和你需要的取值范围。

#### 技能 4:实际项目

理论 + 仿真 + 焊接 = 真正的能力。从小项目开始:

**新手项目**:

- 用 LM358 搭一个简单同相放大器,接麦克风,放大后接耳机听
- 用 555 做一个 LED 闪烁电路
- 用 LM317 搭一个可调线性稳压电源

**中级项目**:

- 用运放做一个简单的有源带通滤波器(音频应用)
- 用 NE5532 做一个耳机放大器(发烧友项目)
- 用比较器做一个简单的施密特触发器电路,测试抗噪声效果

**进阶项目**:

- 用 STM32 + 模拟前端做一个信号采集系统(模电+数电+嵌入式综合)
- 用 OPA1612 + AB 类输出级搭一个 hi-fi 音频功放
- 用 ADC + DSP 做一个简单的数字音效处理器

### 18.5 一个完整练习:看懂 LM358 的 datasheet

最后给你一个具体练习。下载 TI 的 LM358 datasheet(免费),回答以下问题:

1. 它是什么类型的运放?(单电源还是双电源?CMOS 还是 BJT?)
2. 开环增益 Aod 是多少 dB?GBW 是多少?
3. 输入失调电压 VIO 典型值和最大值?
4. 输入偏置电流 IIB 是多少?
5. 输出能不能"摆到电源轨"?(即是否 rail-to-rail)
6. 转换速率(Slew Rate)是多少?这意味着它能不能放大 100 kHz、5V 峰峰值的信号?
7. 在 +5V 单电源下,把它接成增益 10 倍的同相放大器,输入 0~0.4V 的信号,是否会饱和?为什么?

**这个练习一旦做完,你就完成了从"上课学模电"到"工程师用模电"的转变**。

### 18.6 学习模电的"思维转变"

最后,谈谈这门课在你思维上留下了什么。

#### 转变 1:从"理想"到"近似"

高中物理:理想导线零电阻,理想电源恒定电压。 模电:**没有什么是理想的**。导线有电阻、电感;电源有内阻、纹波;晶体管有寄生电容、β 漂移、温漂、噪声。

**工程的本质,就是与"不完美"共处,并用智慧让它们近似理想**。这种思维不仅适用于电路,也适用于一切工程问题。

#### 转变 2:从"精确"到"权衡"

模电没有"完美方案"。每个设计都是**权衡**:

- 增益 vs 带宽(GBW 守恒)
- 效率 vs 线性(A 类 vs B 类)
- 速度 vs 精度(Flash ADC vs SAR ADC)
- 噪声 vs 功耗(高 gm 需要大电流)

**学会权衡,是工程师成熟的标志**。

#### 转变 3:从"分析"到"设计"

前 10 课你在"分析"——给定电路,算出参数。 后 7 课你在"设计"——给定指标,选择电路结构,设计参数。

**设计比分析难得多,因为设计有无穷多种"对的答案"**。模电真正训练的是这种创造性思维。

#### 转变 4:从"公式"到"直觉"

资深模电工程师看到一个电路,**几秒钟就能估出大概性能**——不是因为他算得快,而是他建立了"直觉":

- 共射放大器输入阻抗 ≈rbe,几 kΩ —— 直觉
- 运放高频增益从极点之后 −20 dB/dec —— 直觉
- 电流镜的输出阻抗就是 ro —— 直觉

**直觉来自反复的练习**——分析、仿真、焊接、调试。慢慢积累,你也会有这种直觉。

### 18.7 临别的话

你在很短的时间内走完了一门一个学期的课程。我完全相信,如果你把每一课的内容都做了仿真验证,认真补做了相应的习题,你的水平已经超过了很多同年级的同学。

但模电的真正掌握需要**反复回炉**。

**第一遍**(就是这十八课):**建立全景**——你知道有哪些工具,它们大致干什么。

**第二遍**(用童诗白教材或 Sedra/Smith 系统过):**建立严谨**——补全数学推导、做习题、训练计算能力。

**第三遍**(LTspice + 焊接 + 实际项目):**建立直觉**——感受真实电路的行为,知道哪些参数重要,哪些可以忽略。

**第四遍**(Razavi 或 Art of Electronics):**建立设计思维**——开始设计自己的电路,做自己的项目。

每一遍都会有新的收获。模电不是学一次就会的,**它是一个反复回炉的螺旋上升过程**。
