---

#### 🔹 一、边界层的发现

1904年，德国物理学家**普朗特**（Ludwig Prandtl）提出了一个革命性的想法：

> 粘性的影响**不是均匀分布**在整个流场里的，而是**集中在物体表面附近极薄的一层**——这层叫做**边界层**。

边界层之外：流体几乎感受不到粘性，可以用理想流体（伯努利方程）描述。

边界层之内：粘性主导，速度从壁面的零急剧增加到外部流速。

**这个思想统一了两种看似矛盾的描述：**

```
整个流场
    │
    ├─ 边界层外：无粘性，用伯努利方程
    │
    └─ 边界层内：粘性主导，速度梯度极大
                 → 摩擦阻力的来源
```

---

#### 🔹 二、边界层的结构

以平板为例，流体以速度 U 从左向右流过平板表面：

**边界层厚度 δ 的定义**：

从壁面到流速达到外部流速 99%99% 处的距离。

v(y=δ)=0.99 U

**边界层厚度的增长**：

沿流动方向，边界层逐渐变厚（越来越多的流体被"拖慢"）：

δ(x)∼νxU=xRex⋅xδ(x)∼Uνx=Rexx⋅x

其中 Rex=Ux/ν 是以距离 x 为特征长度的局部雷诺数。

**数量级**：

对于飞机机翼（U∼250U∼250 m/s，x∼2x∼2 m，空气 ν∼1.5×10−5ν∼1.5×10−5 m²/s）：

δ∼1.5×10−5×2250≈0.35 mδ∼2501.5×10−5×2≈0.35 m

机翼边界层厚度不到半毫米，却决定了整架飞机的阻力！

#### 🔹 三、边界层内的两种状态

和整体流动一样，边界层内部也分层流和湍流：

**层流边界层**：

- 流体层次分明，有序滑动
- 速度梯度相对平缓
- 摩擦阻力较小
- 但容易"分离"（见后文）

**湍流边界层**：

- 边界层内部混乱，大量漩涡
- 壁面处速度梯度更陡
- 摩擦阻力更大
- 但紧贴壁面，不容易分离

**转捩**（层流 → 湍流的转变）：

边界层从前缘开始是层流，随着 Rex 增大，在某处发生**转捩**，变为湍流。

Rex,临界≈5×105Rex,临界≈5×105

#### 🔹 四、两种阻力

物体在流体中运动受到的阻力分为两类：

##### ① 摩擦阻力（表面阻力）

来源：边界层内流体对物体表面的**切向摩擦力**。

F摩擦=∫τw dA=∫μdvdy∣y=0dAF摩擦=∫τwdA=∫μdydvy=0dA

- 与物体**表面积**成正比
- 流线型细长体（如潜艇、鱼）以摩擦阻力为主

##### ② 压差阻力（形状阻力）

来源：物体前后的**压强差**。

物体前方：流体被阻滞，压强高（类似驻点）

物体后方：若边界层分离，形成低压**尾迹区**

前后压强差 × 面积 = 压差阻力

- 与物体**迎风面积**和**形状**密切相关
- 钝体（如圆球、平板迎风）以压差阻力为主

**两者的相对大小**：

|物体形状|主要阻力来源|
|---|---|
|薄平板（平行流动）|摩擦阻力|
|薄平板（垂直流动）|压差阻力|
|流线型体|摩擦阻力（压差很小）|
|圆球、圆柱|压差阻力为主|

#### 🔹 五、边界层分离——压差阻力的根源

这是理解阻力最关键的概念。

**分离的成因**：

流体绕过弯曲物体（如圆球）时：

- **前半段**：流体加速，压强降低（顺压梯度）——边界层紧贴表面
- **后半段**：流体减速，压强升高（逆压梯度）——边界层受到"顶风"

边界层内的流体本来就被粘性拖慢，再遇到逆压梯度，能量不足以继续前进，于是：

流体→逆压梯度停滞→回流→边界层离开壁面流体逆压梯度停滞→回流→边界层离开壁面

这叫**边界层分离**，分离点之后形成混乱的**尾迹区**（低压区）：

```
        ┌──────────────┐
→→→→   │  物体         │   低压尾迹区（漩涡）
→→→→   │               ●← 分离点
→→→→   └──────────────┘
         高压（前）          低压（后）
              └──────── 压差阻力 ────┘
```

**前后压强差越大，压差阻力越大。**

#### 🔹 六、高尔夫球凹坑之谜——解答

现在可以回答上节留下的问题了。

**光滑球**：

边界层是层流，能量较低，在球的中部附近就提前分离，留下**大面积尾迹**，压差阻力很大。

**有凹坑的球**：

凹坑人为制造扰动，使边界层提前转捩为**湍流**。

湍流边界层虽然摩擦阻力稍大，但它能量更充沛，能抵抗更强的逆压梯度，推迟分离，让分离点移到球的更后方，尾迹区**大幅缩小**：

```
光滑球：  分离点在前 → 大尾迹 → 大压差阻力
凹坑球：  分离点在后 → 小尾迹 → 小压差阻力（总阻力约减少一半）
```

> 💡 这是一个以小（增加摩擦阻力）换大（大幅减小压差阻力）的精妙权衡。高尔夫球凹坑数量通常在300~500个，是经过大量实验优化的结果。

同理：

- 鲨鱼皮肤的细小沟槽——推迟转捩，减小摩擦阻力
- 仿生泳衣的纹理——模仿鲨鱼皮
- 足球表面的缝线——类似凹坑效果

#### 🔹 七、阻力系数——统一描述阻力

定义**阻力系数** CD（Drag Coefficient）：

FD=CD⋅12ρv2⋅AFD=CD⋅21ρv2⋅A

其中：

- 12ρv221ρv2：动压（来自伯努利方程）
- A：参考面积（通常取迎风面积）
- CD：无量纲阻力系数，由形状和雷诺数决定

CD 是实验测定的，几何相似的物体在相同 Re 下 CD 相同（上节的相似性原理）。

**常见物体的 CD（高雷诺数）**：

|物体|CD|
|---|---|
|流线型体|0.04∼0.10.04∼0.1|
|赛车（F1）|∼0.7∼0.7（含下压力）|
|普通轿车|0.25∼0.350.25∼0.35|
|自行车+骑手|∼0.9∼0.9|
|圆球（光滑）|∼0.47∼0.47|
|圆球（高尔夫）|∼0.25∼0.25|
|平板（垂直）|∼1.28∼1.28|
|人（站立）|∼1.0∼1.0|

> 💡 特斯拉Model S的 CD=0.208，是量产车中最低之一，因此续航里程更长。

#### 🔹 八、减阻的策略总结

|策略|原理|应用|
|---|---|---|
|流线型设计|推迟分离，缩小尾迹|飞机、鱼、赛车、子弹头列车|
|表面粗糙化|湍流边界层推迟分离|高尔夫球凹坑|
|表面沟槽|减小湍流摩擦|鲨鱼皮泳衣|
|减小迎风面积|直接减小 A|赛车手俯身、自行车计时赛姿势|
|主动吸气|吸走低能量边界层|实验飞机、层流控制|
|聚合物添加|破坏湍流结构|消防水管加少量长链聚合物可减阻40%|

#### 🔹 九、湍流——物理学未解之谜

最后说一个坦诚的话：

**湍流是经典物理学中最后一个未被完全理解的重大问题。**

描述流体运动的方程——**纳维-斯托克斯方程**（N-S方程）——早在1822年就写出来了：

ρ(∂v⃗∂t+v⃗⋅∇v⃗)=−∇p+μ∇2v⃗+ρg⃗ρ(∂t∂v+v⋅∇v)=−∇p+μ∇2v+ρg

方程本身不复杂，但：

- 湍流时，这个非线性方程的解极其复杂
- 我们至今无法从N-S方程出发**解析地**预测湍流行为
- **"N-S方程光滑解的存在性与唯一性"**是克雷数学研究所七个**千禧年大奖难题**之一，奖金100万美元，至今无人获奖

> 物理学家费曼曾说：_"湍流是经典物理学中最重要的未解问题。"_

我们目前只能用：

- **直接数值模拟（DNS）**：暴力求解N-S方程，计算量巨大
- **大涡模拟（LES）**：模拟大尺度涡，建模小尺度
- **雷诺平均（RANS）**：用统计平均简化，工程中最常用
