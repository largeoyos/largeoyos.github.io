## YOLO 实战应用——从零到检测结果

理论学完了，现在我们把知识落地。以 YOLOv8 为例（目前最成熟、文档最好、最容易上手的版本），我会带你走完完整的应用流程，每一步都解释"为什么这样做"，而不只是"怎么做"。

---

### 先建立整体认知：应用 YOLO 有哪几种场景？

在写任何代码之前，先想清楚你要做什么。YOLO 的应用场景分三个层次，复杂度依次递增。

第一层是**直接使用预训练模型**做推理——模型已经在 COCO 数据集（80个常见类别，比如人、车、猫、狗）上训练好了，你直接拿来用，不需要任何训练。适合你要检测的东西恰好在这 80 类里的情况。

第二层是**在预训练基础上微调（Fine-tuning）**——你有自己的数据集，但数据量不大，不想从头训练。你把预训练权重作为起点，在你的数据上继续训练几个 epoch，让模型适应你的特定场景。这是最常用的工业场景。

第三层是**从头训练（Training from Scratch）**——你的数据非常特殊（比如卫星图像、显微镜图像），和 COCO 的自然图像差异巨大，预训练权重帮助不大。这种情况需要大量数据和计算资源，比较少见。

我们今天把三个层次都讲清楚，重点放在第一和第二层，因为这是 90% 的实际应用场景。

---

### 环境准备

首先安装 Ultralytics 库，这是 YOLOv8 的官方实现，封装得非常好。

```bash
pip install ultralytics
```

安装完成后，你就拥有了 YOLO 模型的完整工具链：训练、推理、评估、导出，全部包含在内。

---

### 第一层：直接推理——五行代码看到结果

```python
from ultralytics import YOLO
from PIL import Image

# 加载预训练模型。'yolov8n.pt' 中的 'n' 代表 nano，
# 是最小最快的版本。还有 s/m/l/x，越大越准但越慢。
# 第一次运行会自动下载权重文件（约 6MB）
model = YOLO('yolov8n.pt')

# 对一张图片做推理。source 可以是图片路径、视频路径、
# 摄像头编号(0)、甚至是 URL
results = model('your_image.jpg')

# 显示带有检测框的结果图
results[0].show()
```

就这五行，此前已经在做目标检测了。但我们不满足于"能跑"，我们要理解**结果对象里有什么**。

```python
result = results[0]  # 取第一张图的结果

# result.boxes 包含所有检测到的框
boxes = result.boxes

# 每个框的坐标（左上角x, 左上角y, 右下角x, 右下角y）
# 注意坐标是原图坐标系下的像素值
print(boxes.xyxy)      # shape: [N, 4]，N是检测到的物体数量

# 每个框的置信度分数——模型有多确定这里有物体
print(boxes.conf)      # shape: [N]

# 每个框的类别编号（0=person, 2=car, 15=cat...）
print(boxes.cls)       # shape: [N]

# 把类别编号转换成可读的类别名称
# result.names 是一个字典，比如 {0: 'person', 2: 'car'}
for i, box in enumerate(boxes):
    cls_id = int(box.cls)
    class_name = result.names[cls_id]
    confidence = float(box.conf)
    x1, y1, x2, y2 = box.xyxy[0].tolist()
    print(f"检测到 {class_name}，置信度 {confidence:.2f}，位置: ({x1:.0f}, {y1:.0f}) -> ({x2:.0f}, {y2:.0f})")
```

理解这个输出结构很重要，因为在实际工程中，你需要拿到这些数据去做后续处理——比如统计人数、触发报警、画自定义的框。

### 处理视频和摄像头：逐帧推理

实际场景中，视频比图片更常见。YOLO 的推理可以直接在视频流上运行。

```python
import cv2
from ultralytics import YOLO

model = YOLO('yolov8n.pt')

# 打开视频文件。如果是摄像头，把路径换成 0
cap = cv2.VideoCapture('your_video.mp4')

while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        break

    # 对每一帧做推理
    # verbose=False 关闭每帧的打印输出，避免刷屏
    results = model(frame, verbose=False)

    # result.plot() 返回一个带有检测框的 numpy 数组
    # 这比自己手动画框方便得多
    annotated_frame = results[0].plot()

    cv2.imshow('YOLOv8 检测', annotated_frame)

    # 按 q 退出
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

这里有一个很重要的工程细节：每帧都重新调用 `model()` 做推理，所以推理速度（FPS）直接影响视频的流畅度。YOLOv8n 在普通 GPU 上可以轻松达到 100+ FPS，在 CPU 上大约 10-20 FPS。

### 第二层：微调——训练你自己的检测器

这是最有价值的部分。假设你要训练一个检测器，专门检测工厂流水线上的产品缺陷，COCO 里没有这个类别，你需要自己来。

#### 第一步：准备数据集

数据集的格式是整个流程中最容易出错的地方，我们来彻底搞清楚。

YOLO 使用的标注格式非常简洁，每张图片对应一个同名的 `.txt` 文件。文件里每一行描述一个物体：

```
类别编号 x中心 y中心 宽度 高度
```

这里有一个极其重要的细节：所有坐标都是**归一化的**，也就是除以了图像的宽度和高度，值域在 0 到 1 之间。这样做的好处是坐标和图像分辨率无关，不管图片是 640×480 还是 1920×1080，标注文件的格式完全一样。

举个例子，如果图片是 640×480，图里有一只猫，猫的边界框左上角在 (100, 150)，右下角在 (300, 400)，那么标注应该是：

```
15  0.3125  0.5729  0.3125  0.5208
# 15 是 cat 的类别编号
# x中心 = (100+300)/2 / 640 = 200/640 = 0.3125
# y中心 = (150+400)/2 / 480 = 275/480 = 0.5729
# 宽度  = (300-100) / 640 = 200/640 = 0.3125
# 高度  = (400-150) / 480 = 250/480 = 0.5208
```

标注工具推荐使用 **Roboflow** 或 **LabelImg**，它们可以直接导出 YOLO 格式的标注文件，不需要手动计算归一化坐标。

#### 第二步：组织目录结构

YOLO 对目录结构有严格要求，必须按照下面这个方式组织，否则训练时会找不到数据。

```
my_dataset/
├── images/
│   ├── train/        # 训练集图片（通常占 80%）
│   │   ├── img001.jpg
│   │   └── img002.jpg
│   └── val/          # 验证集图片（通常占 20%）
│       ├── img101.jpg
│       └── img102.jpg
└── labels/
    ├── train/        # 训练集标注（文件名和图片一一对应）
    │   ├── img001.txt
    │   └── img002.txt
    └── val/
        ├── img101.txt
        └── img102.txt
```

#### 第三步：写数据集配置文件

在数据集根目录下创建一个 `dataset.yaml` 文件，这是 YOLO 找到你的数据的关键。

yaml

```yaml
# dataset.yaml

# 数据集根目录的绝对路径
path: /home/user/my_dataset

# 相对于 path 的训练集和验证集路径
train: images/train
val: images/val

# 类别数量
nc: 2

# 类别名称列表，顺序对应标注文件里的编号 0, 1, 2...
names: ['defect_scratch', 'defect_dent']
```

#### 第四步：开始训练

```python
from ultralytics import YOLO

# 关键：加载预训练权重作为起点，而不是随机初始化
# 这就是"微调"的核心——利用模型在 COCO 上学到的
# 底层视觉特征（边缘、纹理、形状），在你的数据上
# 只需要"调整"高层的语义理解
model = YOLO('yolov8n.pt')

# 开始训练
results = model.train(
    data='dataset.yaml',  # 你的数据集配置文件

    epochs=100,           # 训练轮数。数据少时50-100够了，
                          # 数据多时可以增加到 300+

    imgsz=640,            # 训练图片尺寸。YOLO 会把所有图片
                          # resize 到这个尺寸。越大越准但越慢

    batch=16,             # 每个 batch 的图片数量。
                          # 根据你的显存大小调整，
                          # 显存不够就调小

    device='0',           # 使用 GPU 0。CPU 训练用 'cpu'，
                          # 多卡训练用 '0,1,2,3'

    project='runs/train', # 训练结果保存的目录
    name='my_detector',   # 本次训练的名称

    patience=50,          # 早停机制：如果 50 个 epoch 内
                          # 验证集精度没有提升，就停止训练
                          # 防止过拟合
)
```

训练过程中，YOLO 会自动在每个 epoch 结束后在验证集上评估，打印 mAP50（IoU阈值0.5时的平均精度）和 mAP50-95（多个IoU阈值的平均）。你可以实时监控训练是否收敛。

训练结束后，在 `runs/train/my_detector/` 目录下会有：`best.pt`（验证集表现最好的权重）、`last.pt`（最后一个 epoch 的权重）、以及各种训练曲线图（损失曲线、精度曲线、混淆矩阵等）。**实际使用时永远用 `best.pt`。**

#### 第五步：用你自己训练的模型做推理

```python
from ultralytics import YOLO

# 加载你自己训练的权重，而不是预训练权重
model = YOLO('runs/train/my_detector/weights/best.pt')

# 推理方式和之前完全一样，接口没有任何变化
results = model('test_image.jpg')
results[0].show()
```

### 一个常见的工程问题：置信度阈值怎么设？

推理时，YOLO 默认只输出置信度 > 0.25 的框。这个阈值在不同场景下需要调整。

如果你的场景是**安全检测**（比如工厂危险品检测），漏检的代价远高于误报，你应该**降低阈值**（比如 0.1），宁可多报也不漏报。

如果你的场景是**自动计数**（比如统计货架上的商品），误报会导致计数错误，你应该**提高阈值**（比如 0.5 或 0.6），只保留高置信度的检测结果。

```python
# 调整推理时的置信度阈值和 NMS 的 IoU 阈值
results = model(
    'image.jpg',
    conf=0.4,   # 只输出置信度 > 0.4 的框
    iou=0.5     # NMS 时，IoU > 0.5 的重叠框会被合并
)
```
