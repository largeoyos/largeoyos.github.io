## 第二章：序列与级数

---

### 第2章:Sequences and Series

#### 2.1 开场悖论:Rearrangements of Infinite Series

Abbott 用一个让人头皮发麻的例子开场。考虑交错调和级数:

1−12+13−14+15−⋯=ln21−21+31−41+51−⋯=ln2

现在把它**重新排列**——每两个正项后面跟一个负项:

1+13−12+15+17−14+⋯1+31−21+51+71−41+⋯

可以证明这个新级数收敛到 **(3/2) ln 2**。

⚠️ 同样的项,只是顺序换了,和居然变了。这违背了我们对加法的全部直觉(交换律去哪了?)。Abbott 用这个例子告诉你:**无穷的世界很危险,需要严格的工具**。

#### 2.2 极限的 ε-N 定义(全章最重要的一节)

**定义**:序列 (aₙ) 收敛到 a,记作 lim aₙ = a,如果:

> 对任意 ε > 0,存在 N ∈ ℕ,使得当 n ≥ N 时,|aₙ − a| < ε。

这个定义你可能已经见过,但 Abbott 花了大量笔墨讲它的**结构**:

- **ε 是挑战者**:你给我一个误差容忍度,无论多小
- **N 是回应者**:我告诉你"从第 N 项之后,所有项都落在 a 的 ε-邻域里"
- **这是一场博弈**:对手出 ε,你必须找到 N。如果对任意 ε 你都能找到,序列就收敛

**经典例子**:证明 lim (1/n) = 0。

给定 ε > 0,我需要找 N 使得 n ≥ N ⟹ |1/n − 0| < ε。

|1/n| < ε ⟺ n > 1/ε。所以取 N 为任何大于 1/ε 的自然数即可(阿基米德性质保证它存在)。✓

**重要心法**:写 ε-N 证明时,你常常需要**草稿**(scratch work)——先反推出 N 该取多大,再正式写证明。Abbott 把草稿和正式证明分开展示,这是非常好的学习习惯。

#### 2.3 极限定理(Algebraic & Order Limit Theorems)

证明了 ε-N 定义后,Abbott 推导出一堆"显然但需要证明"的结论:

**代数极限定理**:若 lim aₙ = a, lim bₙ = b,则

- lim (aₙ + bₙ) = a + b
- lim (c·aₙ) = c·a
- lim (aₙ·bₙ) = a·b
- lim (aₙ/bₙ) = a/b(b ≠ 0)

**序极限定理**:

- 若 aₙ ≥ 0 对所有 n,则 lim aₙ ≥ 0
- 若 aₙ ≤ bₙ,则 lim aₙ ≤ lim bₙ
- **挤压定理**:若 aₙ ≤ cₙ ≤ bₙ 且 lim aₙ = lim bₙ = L,则 lim cₙ = L

这些定理证明本身是 ε-N 技术的好练习。比如证明乘积的极限,关键技巧是:

∣anbn−ab∣=∣anbn−anb+anb−ab∣≤∣an∣∣bn−b∣+∣b∣∣an−a∣

**加减同一个项**(这里加减 aₙb)是分析里最常用的技巧之一。

#### 2.4 单调收敛定理(MCT)

**定义**:序列 (aₙ) 单调递增,如果 a₁ ≤ a₂ ≤ a₃ ≤ ...;有界,如果存在 M 使得 |aₙ| ≤ M。

**单调收敛定理**:**单调且有界的序列必收敛**。

证明:设 (aₙ) 单调递增有界。令 A = {a₁, a₂, ...}。由完备性公理,s = sup A 存在。可以证明 lim aₙ = s。

🔑 **注意这里第一次用到完备性公理!** 这就是为什么第1章那条抽象公理这么重要——它让"递增有上界 ⟹ 收敛"这件事成立。在 ℚ 里这是错的(比如 √2 的有理逼近序列)。

**应用**:级数 Σ 1/n² 收敛。证明:部分和 sₙ = 1 + 1/4 + 1/9 + ... + 1/n² 单调递增。验证有界:用 1/k² < 1/(k(k−1)) = 1/(k−1) − 1/k 做望远镜求和,得 sₙ < 2。由 MCT 收敛。

#### 2.5 子序列与 Bolzano-Weierstrass 定理

**子序列**:从 (aₙ) 里挑出递增下标 n₁ < n₂ < n₃ < ...,得到 (aₙₖ)。

**简单事实**:若 aₙ → a,则任何子序列也收敛到 a。

**逆否命题非常实用**:如果你能找到两个子序列收敛到不同的极限,原序列就不收敛。比如 aₙ = (−1)ⁿ:偶子序列 → 1,奇子序列 → −1,所以原序列发散。

**Bolzano-Weierstrass 定理**:**ℝ 中每个有界序列都有收敛子序列**。

证明思路用**嵌套区间**:把序列装进 [−M, M]。把这个区间对半分,至少有一半含无穷多项,选这一半。再对半分……得到嵌套区间套,长度 → 0。由嵌套区间定理,交集是单点 x。每次从对应区间里挑一项,就得到收敛到 x 的子序列。

这个定理是分析里的"瑞士军刀之二",仅次于完备性公理本身。

#### 2.6 Cauchy 列

**定义**:序列 (aₙ) 是 Cauchy 列,如果:

> 对任意 ε > 0,存在 N,使得当 m, n ≥ N 时,|aₙ − aₘ| < ε。

直觉:序列后面的项**互相**越来越靠近(注意不是和某个极限靠近——你不需要先知道极限存在!)。

**Cauchy 收敛准则**:**ℝ 中,序列收敛 ⟺ 它是 Cauchy 列**。

- (⟹) 容易:如果 aₙ → a,用三角不等式 |aₙ − aₘ| ≤ |aₙ − a| + |a − aₘ| < 2ε。
- (⟸) 难,需要完备性公理:Cauchy 列必有界 ⟹ 由 BW 有收敛子序列 ⟹ 整个序列收敛到同一极限。

**为什么 Cauchy 准则重要?** 它让你能**判断序列收敛而不需要先猜出极限**。这在级数判敛中是核心工具。

#### 2.7 无穷级数

级数 Σaₙ 的收敛**定义**为部分和序列 sₙ = a₁ + a₂ + ... + aₙ 收敛。

主要判敛工具:

- **Cauchy 判别法**:Σaₙ 收敛 ⟺ 对任意 ε,存在 N,使得 n > m ≥ N 时 |aₘ₊₁ + ... + aₙ| < ε
- **比较判别法**:0 ≤ aₙ ≤ bₙ。若 Σbₙ 收敛,则 Σaₙ 收敛
- **几何级数**:Σrⁿ 收敛 ⟺ |r| < 1
- **p-级数**:Σ 1/nᵖ 收敛 ⟺ p > 1
- **绝对收敛 ⟹ 收敛**(反过来不对——比如交错调和级数条件收敛但不绝对收敛)
- **交错级数判别法**:若 aₙ 单调递减到 0,则 Σ(−1)ⁿaₙ 收敛

#### 2.8 重排定理(回到开篇悖论)

最后,Abbott 解开开头那个悖论:

**定理**:**绝对收敛**的级数,任意重排都收敛到同一个和。

**条件收敛**(Riemann 重排定理,这章未完整证明,只展示):可以重排成任何想要的实数,甚至发散!这就是为什么 1 − 1/2 + 1/3 − ... 重排后变成了 (3/2) ln 2——它只是条件收敛,不绝对收敛。

### 这章的逻辑骨架

```
完备性公理(第1章)
    ↓
单调收敛定理 ←→ 嵌套区间 ←→ Bolzano-Weierstrass ←→ Cauchy 准则
    ↓
所有级数判敛工具
```

**这五条性质在 ℝ 上互相等价**,任何一条都可以作为"完备性"的定义。Abbott 选了 sup 作为出发点,因为它最直观。

### 这章的难点

学生在这章最容易卡住的地方:

1. **ε-N 证明的不熟练**——多写几个,从 1/n、1/n²、(n+1)/n 这种开始
2. **分不清"序列收敛"和"级数收敛"**——级数收敛是部分和序列的收敛
3. **以为 Cauchy 是"相邻项靠近"**——错!是"任意两项 m, n 都靠近"。aₙ = √n 满足 |aₙ₊₁ − aₙ| → 0 但不是 Cauchy 列(它发散)
