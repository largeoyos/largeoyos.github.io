## 第四章：函数极限与连续性

---

### 第4章：Functional Limits and Continuity

#### 4.1 开场问题：Dirichlet 函数

Abbott 用一个奇怪的函数开场：

f(x)={1if x∈Q0if x∉Qf(x)={10if x∈Qif x∈/Q

问：这个函数在哪里连续？

直觉上它"处处跳动"——有理数和无理数在任何区间里都交错分布（ℚ 在 ℝ 里稠密，无理数也稠密）。答案是：**处处不连续**。

但 Abbott 还展示了一个更精妙的函数——**Thomae 函数**（也叫"爆米花函数"）：

g(x)={1/nif x=m/n（最简分数）0if x∉Qg(x)={1/n0if x=m/n（最简分数）if x∈/Q

这个函数的答案令人震惊：**在所有无理数处连续，在所有有理数处不连续**。一个函数可以在可数个点不连续、在不可数个点连续——但能不能反过来？能不能构造一个在所有无理数处不连续、在所有有理数处连续的函数？

Abbott 在后面会告诉你：**不能**（Baire 范畴定理的推论）。这就是这章要建立的精密理论的威力。

#### 4.2 函数极限的 ε-δ 定义

在定义连续之前，先定义函数极限。

**定义**：limx→cf(x)=Llimx→cf(x)=L，如果：

> 对任意 ε > 0，存在 δ > 0，使得当 0<∣x−c∣<δ 时，∣f(x)−L∣<ε。

注意两个关键细节：

- **0<∣x−c∣**：x 不等于 c。函数极限不关心 f(c) 的值，甚至不要求 f(c) 存在
- **δ 依赖于 ε**：对手出 ε，你找 δ——和第2章的 ε-N 博弈结构完全一样

**与序列极限的桥梁——序列刻画定理**：

limx→cf(x)=L  ⟺  对所有满足 xn→c 且 xn≠c 的序列，f(xn)→Lx→climf(x)=L⟺对所有满足 xn→c 且 xn=c 的序列，f(xn)→L

这个等价性非常有用：

- 想**证明**极限存在 → 用 ε-δ
- 想**证明**极限不存在 → 找两个趋近方式给出不同极限（用序列）

**例子**：证明 limx→2(3x+1)=7limx→2(3x+1)=7。

给定 ε，需要 δ 使得 |x−2| < δ ⟹ |(3x+1)−7| < ε。

|(3x+1)−7| = |3x−6| = 3|x−2| < 3δ。

所以取 δ = ε/3 即可。✓

#### 4.3 连续的 ε-δ 定义

**定义**：f 在点 c 处**连续**，如果：

limx→cf(x)=f(c)x→climf(x)=f(c)

展开就是：对任意 ε > 0，存在 δ > 0，使得 |x−c| < δ ⟹ |f(x)−f(c)| < ε。

注意与函数极限的区别：这里 x 可以等于 c（所以 |x−c| < δ 而不是 0<∣x−c∣<δ），而且明确要求 f(c) 存在且等于极限值。

**连续的三个等价条件**：

f 在 c 连续 ⟺

1. limx→cf(x)=f(c)limx→cf(x)=f(c)（极限存在且等于函数值）
2. 对任意序列 xn→cxn→c，有 f(xn)→f(c)f(xn)→f(c)
3. 对任意包含 f(c) 的开集 V，存在包含 c 的开集 U 使得 f(U)⊆Vf(U)⊆V

第三条是**拓扑语言**的连续定义——它把第3章和第4章直接连起来，也是更一般拓扑空间里连续的定义方式。

**代数连续定理**：若 f, g 在 c 连续，则 f+g、f·g、f/g（g(c)≠0）在 c 连续。多项式处处连续，有理函数在定义域内处处连续。

#### 4.4 连续函数的拓扑性质

这里是第3章概念的第一次收割。

##### 开集的原像

**定理**：f 在 ℝ 上连续 ⟺ 对任意开集 O⊆RO⊆R，原像 f−1(O) 是开集。

这是连续性最优雅的刻画。它完全不提 ε、δ，只用开集的语言——这正是一般拓扑空间里连续的定义。

##### 紧致集上的连续函数

**定理**：若 f 在紧致集 K 上连续，则 f(K) 也是紧致集。

证明：取 f(K) 中任意序列 f(xn)。因为 xn∈Kxn∈K 且 K 紧致，存在子序列 xnk→x∈Kxnk→x∈K。由连续性 f(xnk)→f(x)∈f(K)f(xnk)→f(x)∈f(K)。✓

**推论1——极值定理(Extreme Value Theorem)**：

若 f 在闭区间 [a,b] 上连续，则 f 在 [a,b] 上取到最大值和最小值。

证明：f([a,b]) 是紧致集（有界闭集），所以 sup f([a,b]) 存在且被取到。✓

**推论2——介值定理(Intermediate Value Theorem)**：

若 f 在 [a,b] 连续，且 f(a) < L < f(b)，则存在 c ∈ (a,b) 使得 f(c) = L。

证明思路（拓扑版本）：连续函数把连通集映到连通集（第3章）。[a,b] 连通，所以 f([a,b]) 连通，所以 f([a,b]) 是区间，所以 f(a) 和 f(b) 之间的所有值都被取到。✓

介值定理的应用：

- 证明 x3−x=1 有实数根（f(1) = −1 < 0, f(2) = 6 > 0，所以有根在 (1,2) 里）
- 证明每个奇数次多项式至少有一个实根
- 固定点定理：若 f:[0,1]→[0,1] 连续，则存在 x 使得 f(x) = x（考虑 g(x) = f(x)−x）

#### 4.5 一致连续(Uniform Continuity)——这章最难的概念

##### 普通连续 vs 一致连续

普通连续的定义回顾：

> 对任意 ε > 0 和任意 c，存在 δ > 0（**δ 可以依赖 c**），使得 |x−c| < δ ⟹ |f(x)−f(c)| < ε。

**一致连续的定义**：

> 对任意 ε > 0，存在 δ > 0（**δ 只依赖 ε，对所有 c 通用**），使得 |x−y| < δ ⟹ |f(x)−f(y)| < ε。

区别在于：普通连续允许 δ 随位置变化。在不同的点你可能需要不同的"精度"。一致连续要求有一个统一的 δ，对所有点都管用。

**直觉理解**：

- f(x)=x2 在 ℝ 上连续但**不**一致连续——在很大的 x 处，函数变化极快，同样的 δ 在不同位置效果完全不同
- f(x)=x2 在 [0,5] 上**是**一致连续的——有界区间上，函数的变化速率有上界

**例子：f(x)=1/x 在 (0,1](0,1] 上不一致连续**

取 ε = 1。无论你给多小的 δ，在 x 接近 0 的地方：

∣1x−1y∣=∣x−y∣xyx1−y1=xy∣x−y∣

当 x, y 很小时，即使 |x−y| < δ，分母 xy 极小，差值可以超过 1。所以没有统一的 δ 能管用。

##### Heine-Cantor 定理

**定理**：若 f 在紧致集 K 上连续，则 f 在 K 上一致连续。

这是紧致性最重要的应用之一。

证明思路：反证。若不一致连续，则存在 ε > 0，对任意 δ = 1/n，找到 xn,ynxn,yn 使得 ∣xn−yn∣<1/n 但 ∣f(xn)−f(yn)∣≥ε。因为 K 紧致，xn 有子序列 xnk→x∈Kxnk→x∈K。由三角不等式 ynk→xynk→x 也成立。由连续性 f(xnk)→f(x)f(xnk)→f(x) 且 f(ynk)→f(x)f(ynk)→f(x)，但 ∣f(xnk)−f(ynk)∣≥ε，矛盾。✓

**意义**：这解释了为什么积分理论（第7章）能在闭区间上工作得很好——闭区间上的连续函数自动有一致连续这个更强的性质。

#### 4.6 连续与导数的预备：单调函数

Abbott 在这章末尾讨论单调函数的不连续性：

**定理**：单调函数的不连续点至多是可数个。

证明思路：单调函数只能有跳跃间断点（左右极限都存在但不相等）。每个跳跃对应一个非空有理数区间（跳跃的"缝隙"里有有理数），不同跳跃对应不相交的有理数区间。有理数区间是可数的，所以不连续点可数。

### 这章的三大难点

**1. ε 和 δ 的顺序**

ε-δ 定义是"对任意 ε，存在 δ"——ε 在前，δ 在后，δ 依赖 ε。写证明时永远是：给定 ε，然后构造合适的 δ。顺序反了整个证明就错了。

**2. 一致连续与普通连续的区别**

最清晰的检验：问自己"δ 能不能对所有点统一？"如果函数在某个方向上越来越陡（比如 1/x 趋近 0，x² 趋近 ∞），δ 就必须随位置变化，不一致连续。

**3. 极值定理和介值定理的条件**

两个定理都需要：**闭区间 + 连续**。缺一不可。

- (0,1) 上的 f(x) = x 没有最大值（开区间）
- [0,1] 上的 f(x) = 1/x（在 0 不连续）没有最大值
- 只有两个条件同时满足，才能保证极值存在

### Thomae 函数的答案

回到开场问题：为什么 Thomae 函数在无理数处连续？

设 x 是无理数，g(x) = 0。给定 ε > 0，分母 ≤ 1/ε 的有理数在任何有界区间里只有**有限个**（关键！）。所以可以找到 δ，使得 (x−δ, x+δ) 里所有有理数 m/n 都满足 n > 1/ε，从而 g(m/n) = 1/n < ε。而无理数处 g = 0。所以 |g(y)−g(x)| < ε。✓

这个证明漂亮地用到了有理数的"稀疏性"与无理数的"稠密分布"之间的相互作用。
