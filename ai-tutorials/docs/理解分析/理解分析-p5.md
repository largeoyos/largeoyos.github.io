## 第五章：导数

### 第5章：The Derivative

#### 5.1 开场问题：处处连续但处处不可微的函数

Abbott 开场抛出一个19世纪让数学界震惊的结论：

**Weierstrass 函数**：

W(x)=∑n=0∞ancos(bnπx)W(x)=n=0∑∞ancos(bnπx)

其中 0 < a < 1，b 是奇数，且 ab > 1 + 3π/2。

这个函数**处处连续但处处不可微**。

在 Weierstrass 之前，大多数数学家相信"连续函数除了有限个点之外都可微"。这个例子彻底摧毁了这个直觉——连续和可微之间有巨大的鸿沟。

---

#### 5.2 导数的定义

**定义**：函数 f 在点 c 处**可微**，如果以下极限存在：

f′(c)=limx→cf(x)−f(c)x−cf′(c)=x→climx−cf(x)−f(c)

等价地，令 h = x−c：

f′(c)=limh→0f(c+h)−f(c)hf′(c)=h→0limhf(c+h)−f(c)

这是你在微积分课里见过的定义。但 Abbott 强调它的**本质**：导数是差商的极限，而极限是第4章的 ε-δ 概念。所以可微性完全建立在之前的基础上。

##### 可微 ⟹ 连续

**定理**：若 f 在 c 处可微，则 f 在 c 处连续。

证明：

f(x)−f(c)=f(x)−f(c)x−c⋅(x−c)→x→cf′(c)⋅0=0f(x)−f(c)=x−cf(x)−f(c)⋅(x−c)x→cf′(c)⋅0=0

所以 limx→cf(x)=f(c)limx→cf(x)=f(c)。✓

**逆命题不成立**：f(x) = |x| 在 x = 0 处连续但不可微（左导数 = −1，右导数 = 1，不相等）。

这个方向的关系要牢记：

可微⇒连续⇒极限存在可微⇒连续⇒极限存在反方向全部不成立反方向全部不成立

#### 5.3 求导法则

这些你都见过，但现在是严格证明的时候。

**代数求导法则**：若 f, g 在 c 可微，则：

- (f+g)′(c)=f′(c)+g′(c)(f+g)′(c)=f′(c)+g′(c)
- (fg)′(c)=f′(c)g(c)+f(c)g′(c)(fg)′(c)=f′(c)g(c)+f(c)g′(c)（乘积法则）
- (f/g)′(c)=f′(c)g(c)−f(c)g′(c)[g(c)]2(f/g)′(c)=[g(c)]2f′(c)g(c)−f(c)g′(c)（商法则，g(c)≠0g(c)=0）

乘积法则的证明用到经典的"加减同一项"技巧：

f(x)g(x)−f(c)g(c)x−c=f(x)⋅g(x)−g(c)x−c+g(c)⋅f(x)−f(c)x−cf(x)g(x)−f(c)g(c)=f(x)⋅x−cg(x)−g(c)+g(c)⋅x−cf(x)−f(c)

令 x→c，利用 f 在 c 连续（可微⟹连续），得到乘积法则。✓

**链式法则**：若 f 在 c 可微，g 在 f(c) 可微，则：

(g∘f)′(c)=g′(f(c))⋅f′(c)(g∘f)′(c)=g′(f(c))⋅f′(c)

证明有一个微妙的陷阱：直接写

g(f(x))−g(f(c))x−c=g(f(x))−g(f(c))f(x)−f(c)⋅f(x)−f(c)x−cg(f(x))−g(f(c))=f(x)−f(c)g(f(x))−g(f(c))⋅x−cf(x)−f(c)

当 f(x)=f(c)（分母为零）时这个分拆失效。严格证明需要引入辅助函数：

d(y)={g(y)−g(f(c))y−f(c)y≠f(c)g′(f(c))y=f(c)d(y)=⎩⎨⎧y−f(c)g(y)−g(f(c))g′(f(c))y=f(c)y=f(c)

由 g 可微，d 在 f(c) 连续。然后写 g(f(x))−g(f(c))=d(f(x))⋅(f(x)−f(c))，两边除以 x−c 取极限。✓

#### 5.4 中值定理(MVT)——这章的核心定理

##### Rolle 定理

**定理**：若 f 在 [a,b] 连续，在 (a,b) 可微，且 f(a) = f(b)，则存在 c ∈ (a,b) 使得 f'(c) = 0。

证明：由极值定理（第4章），f 在 [a,b] 上取到最大值和最小值。

- 若最大值或最小值在内部某点 c 取到，则 f'(c) = 0（内部极值点导数为零）
- 若最大值和最小值都在端点取到，因为 f(a) = f(b)，最大值 = 最小值，f 是常数，f'(c) = 0 处处成立

✓

**内部极值点导数为零的证明**：设 c 是内部最大值点。

f′(c)=limx→c+f(x)−f(c)x−c≤0（分子≤0，分母>0）f′(c)=x→c+limx−cf(x)−f(c)≤0（分子≤0，分母>0）f′(c)=limx→c−f(x)−f(c)x−c≥0（分子≤0，分母<0）f′(c)=x→c−limx−cf(x)−f(c)≥0（分子≤0，分母<0）

所以 f'(c) = 0。✓

##### 中值定理

**定理**：若 f 在 [a,b] 连续，在 (a,b) 可微，则存在 c ∈ (a,b) 使得：

f′(c)=f(b)−f(a)b−af′(c)=b−af(b)−f(a)

几何意义：连接 (a, f(a)) 和 (b, f(b)) 的割线斜率，一定在某个内部点被切线实现。

证明：构造辅助函数，把割线"拉平"：

h(x)=f(x)−[f(a)+f(b)−f(a)b−a(x−a)]h(x)=f(x)−[f(a)+b−af(b)−f(a)(x−a)]

则 h(a) = h(b) = 0，由 Rolle 定理，存在 c 使 h'(c) = 0，即：

f′(c)−f(b)−f(a)b−a=0✓f′(c)−b−af(b)−f(a)=0✓

##### 中值定理的推论

MVT 是分析里用途最广的定理之一：

**推论1**：若 f'(x) = 0 对所有 x ∈ (a,b)，则 f 是常数。

证明：对任意 x, y ∈ (a,b)，由 MVT：f(x)−f(y)=f′(c)(x−y)=0f(x)−f(y)=f′(c)(x−y)=0。✓

**推论2**：若 f'(x) = g'(x) 对所有 x，则 f 和 g 相差一个常数。

**推论3**：若 f'(x) > 0 对所有 x ∈ (a,b)，则 f 严格递增。

这些在微积分课里是"显然的"，但严格证明都需要 MVT——没有 MVT，"导数正 ⟹ 递增"这件事你根本没法证明。

#### 5.5 达布定理(Darboux's Theorem)

这是这章最出乎意料的定理。

**定理**：若 f 在 [a,b] 可微，且 f′(a)<L<f′(b)f′(a)<L<f′(b)，则存在 c ∈ (a,b) 使得 f'(c) = L。

直觉：这看起来像介值定理——但介值定理要求函数**连续**！导函数 f' 不一定连续。达布定理说：即使 f' 不连续，它也满足介值性质。

**证明**：构造 g(x)=f(x)−Lx。则 g′(a)=f′(a)−L<0g′(a)=f′(a)−L<0，g′(b)=f′(b)−L>0g′(b)=f′(b)−L>0。

- g′(a)<0g′(a)<0 意味着 g 在 a 附近递减，所以 g(a) 不是最小值
- g′(b)>0g′(b)>0 意味着 g 在 b 附近递增，所以 g(b) 不是最小值

由极值定理，g 在 [a,b] 上取到最小值，且最小值在内部某点 c 取到。由内部极值定理，g'(c) = 0，即 f'(c) = L。✓

**推论**：导函数不能有跳跃间断点。

这是一个强结论：如果你看到一个函数有跳跃间断点，它就不可能是某个函数的导函数。比如符号函数 sgn(x) 不是任何函数的导函数。

#### 5.6 回到 Weierstrass 函数

现在可以理解为什么 Weierstrass 函数处处不可微了（虽然完整证明比较技术性）。

关键思路：Weierstrass 函数是无穷多个余弦函数的叠加，每一层的振动频率越来越高、振幅缓慢衰减。在任意一点，差商：

W(x+h)−W(x)hhW(x+h)−W(x)

当 h→0h→0 时，高频振动的贡献越来越大，极限不存在。

更一般地：**"典型的"连续函数处处不可微**（Baire 范畴定理意义下）。可微函数反而是例外，不是常态。

#### 5.7 L'Hôpital 法则（简述）

Abbott 在这章最后讨论 L'Hôpital 法则，给出严格证明。

**定理（0/0 型）**：若 f(a) = g(a) = 0，f, g 在 a 可微，g'(a) ≠ 0，则：

limx→af(x)g(x)=f′(a)g′(a)x→alimg(x)f(x)=g′(a)f′(a)

更一般的版本用到**柯西中值定理**（Cauchy MVT）：

f(b)−f(a)g(b)−g(a)=f′(c)g′(c)g(b)−g(a)f(b)−f(a)=g′(c)f′(c)

这是 MVT 的推广，证明方法类似（构造辅助函数用 Rolle 定理）。

### 这章的三大难点

**1. 链式法则的严格证明**

"直接分拆"在 f(x) = f(c) 时失效，必须用辅助函数 d(y)。这个技巧很多教材跳过，但 Abbott 坚持做严格的。

**2. 达布定理的惊奇性**

很多人第一次看到这个定理的反应是"不就是介值定理吗"——但注意：介值定理要求连续，达布定理的对象 f' 不需要连续。这是导函数的特殊性质，不是免费得到的。

**3. MVT 的"隐形"应用**

MVT 在后续章节里无处不在，但往往很隐蔽。第6章证明一致收敛保持可微性，第7章证明微积分基本定理，核心步骤都是 MVT。要训练看到"估计函数值之差"时就想到 MVT。
