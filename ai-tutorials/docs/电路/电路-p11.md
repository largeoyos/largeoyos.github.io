## 11.1 二端口网络

### 一、先聊聊"为什么要有这个概念"

先问你一个问题：

**假设你在设计一个音响系统，信号链是**：

```
  麦克风 → 前级放大 → 均衡器 → 功放 → 喇叭
```

每一级内部都可能有几十上百个元件。**你在分析整个系统时，会去关心"前级放大器"里面每一个晶体管的工作情况吗？**

显然不会。你只关心：

- 给它一个输入电压/电流，输出是多少？
- 它的输入阻抗是多少（决定它怎么"索取"前一级信号）？
- 输出阻抗是多少（决定它怎么"驱动"后一级）？

**换句话说，你把放大器当作一个"黑箱"处理——只关心"端口上的关系"，不关心内部**。

---

**这就是二端口网络的思想**：

> 把一个电路（可以很复杂）抽象成**两对端子**（两个"端口"），只描述端口之间的电压/电流关系。

---

### 二、端口的精确定义

```
   i₁ →                    ← i₂
   ●────────┐     ┌────────●
   │        │     │        │
   + u₁     │  N  │      u₂ +
   -        │     │        -
   ●────────┘     └────────●
   i₁ ←                    → i₂
```

**端口**（port）的严格定义：

> 一对端子，**从一端流入的电流等于从另一端流出**（称为"端口条件"）。

左边两个端子叫**输入端口**（端口 1），右边两个端子叫**输出端口**（端口 2）。

**二端口网络**：有两个端口的线性网络，且**内部不含独立源**。

**四个变量**：u1,i1,u2,i2。其中任选 2 个作**自变量**，另外 2 个作**因变量**——这就是下一节四种参数的由来。

---

## 11.2 二端口网络的方程和参数

四种变量组合 → 四组参数。我们一一过。

---

### 一、Z 参数（开路阻抗参数）

**选 i1,i2 为自变量，u1,u2 为因变量**：

{U1=Z11I1+Z12I2U2=Z21I1+Z22I2

矩阵形式：

[U1U2]=[Z11Z12Z21Z22][I1I2][U1U2]=[Z11Z21Z12Z22][I1I2]

#### 四个 Z 参数的物理意义（⭐）

**每个参数都是"开路测量"得到的——所以叫"开路阻抗参数"**：

Z11=U1I1∣I2=0Z11=I1U1I2=0

**物理意义**：**端口 2 开路**时，从端口 1 看进去的**输入阻抗**。

Z22=U2I2∣I1=0Z22=I2U2I1=0

**物理意义**：**端口 1 开路**时，从端口 2 看进去的**输出阻抗**。

Z12=U1I2∣I1=0Z12=I2U1I1=0

**物理意义**：端口 1 开路时，端口 2 的电流在端口 1 产生的电压与 I2 的比值——**反向转移阻抗**。

Z21=U2I1∣I2=0Z21=I1U2I2=0

**物理意义**：端口 2 开路时，端口 1 的电流在端口 2 产生的电压与 I1 的比值——**正向转移阻抗**。

---

#### 互易性与对称性

**如果网络是"互易"的**（不含受控源，只含 R、L、C、M）：

Z12=Z21

**如果网络还是"电气对称"的**（两个端口物理上可以互换）：

Z11=Z22

---

#### 求 Z 参数的实操方法

给你一个网络，求 Z 参数就是做**两组"开路实验"**：

**实验 1**：端口 2 开路（I2=0），在端口 1 加一个电流源 I1，测 U1 和 U2 → Z11=U1/I1，Z21=U2/I1

**实验 2**：端口 1 开路（I1=0），在端口 2 加一个电流源 I2，测 U1 和 U2 → Z12=U1/I2，Z22=U2/I2

---

#### 例题：T 型网络

```
       I₁ →          ← I₂
      ●────[Za]───┬────[Zb]────●
      │           │            │
      + U₁      [Zc]         U₂ +
      -           │            -
      ●───────────┴────────────●
```

"T 型"因为三个阻抗呈 T 字形。求 Z 参数。

---

**实验 1**（I2=0，右端开路）：

I1 全部流过 Za 和 Zc（因为 Zb 右端开路）：

U1=I1(Za+Zc)  ⟹  Z11=Za+ZcU1=I1(Za+Zc)⟹Z11=Za+Zc

U2 = 右端开路电压 = Zc 两端电压（因为 Zb 上无电流无压降）：

U2=I1⋅Zc  ⟹  Z21=ZcU2=I1⋅Zc⟹Z21=Zc

**实验 2**（I1=0，左端开路）：

由对称性直接得：Z22=Zb+Zc，Z12=Zc

**结果**：

Z=[Za+ZcZcZcZb+Zc]Z=[Za+ZcZcZcZb+Zc]

验证：Z12=Z21=Zc ✓（T 型网络是互易的）

---

### 二、Y 参数（短路导纳参数）

**选 u1,u2 为自变量，i1,i2 为因变量**：

{I1=Y11U1+Y12U2I2=Y21U1+Y22U2

**测量方式**：**短路**实验（让一个端口 U=0）

Y11=I1U1∣U2=0,Y22=I2U2∣U1=0Y11=U1I1U2=0,Y22=U2I2U1=0Y12=I1U2∣U1=0,Y21=I2U1∣U2=0Y12=U2I1U1=0,Y21=U1I2U2=0

**互易性**：Y12=Y21（对互易网络）

**Y 矩阵和 Z 矩阵互为逆矩阵**：Y=Z−1

---

### 三、H 参数（混合参数，⭐ 三极管常用）

**选 i1,u2 为自变量，u1,i2 为因变量**：

{U1=H11I1+H12U2I2=H21I1+H22U2

**四个参数的单位不同**（"混合"之名由来）：

- H11：Ω（输入阻抗）
- H12：无量纲（反向电压比）
- H21：无量纲（**正向电流增益**——三极管的 β 就是这个！）
- H22：S（输出导纳）

**三极管小信号模型几乎就是 H 参数模型**，这也是电子电路课里 h 参数频繁出现的原因。

**互易性条件**：H12=−H21（对互易网络，注意**有个负号**）

---

### 四、T 参数（传输参数）

**选 u2,i2 为自变量，u1,i1 为因变量**（注意 i2 方向通常取反向，即从端口流出为正）：

{U1=AU2+B(−I2)I1=CU2+D(−I2)

**意义**：把**输出**量当输入、**输入**量当输出——专门用于**多级级联**分析！

为什么？因为 T 参数下，**多级网络级联时 T 矩阵直接相乘**：

T总=T1⋅T2⋅T3⋯T总=T1⋅T2⋅T3⋯

而其他参数做级联时没这么方便（需要复杂的矩阵组合）。

**T 参数是电话线、传输线、级联放大器分析的标准工具。**

**互易性条件**：AD−BC=1

---

### 五、四种参数对比小结

|参数|自变量|测量方式|互易条件|典型应用|
|---|---|---|---|---|
|**Z**|I1,I2|开路|Z12=Z21|理论分析|
|**Y**|U1,U2|短路|Y12=Y21|高频电路|
|**H**|I1,U2|混合|H12=−H21|三极管建模|
|**T**|U2,I2|-|AD−BC=1|级联分析|

**四种参数可以互相转换**（公式查表即可，不用背）。

**一个网络可能有些参数存在、有些不存在**——比如理想变压器的 Z、Y 参数不存在（因为开路/短路测量会出现 0 或 ∞），但 T 参数存在。

## 11.3 二端口网络的等效与互联

### 一、等效电路

给定了参数矩阵（比如 Z 参数），**是否能画出一个具体电路来实现它？**

能。最常见的两种：

#### T 型等效电路（Z 参数）

```
       I₁ →              ← I₂
      ●──[Z₁₁-Z₁₂]──┬──[Z₂₂-Z₂₁]──●
      │             │              │
      + U₁        [Z₁₂]          U₂ +
      -             │              -
      ●─────────────┴──────────────●
```

（前面 T 型网络的例子，三个阻抗和 Z 参数的对应：Za=Z11−Z12，Zb=Z22−Z12，Zc=Z12）

**对互易网络**（Z12=Z21）可以这样画。**对非互易网络**，需要加一个**受控源**来体现不对称。

#### π 型等效电路（Y 参数）

```
       I₁ →              ← I₂
      ●──────┬───[1/Y₁₂...]───┬──────●
      │     │                  │      │
      + U₁ [Y]               [Y]    U₂ +
      -     │                  │      -
      ●──────┴──────────────────┴──────●
```

（和 Y 参数的对应关系细节略。）

这两种经典结构（T 和 π）在射频、滤波器设计中是**基本单元**。

---

### 二、二端口网络的互联

当两个二端口网络 Na 和 Nb 以某种方式连在一起时，**总参数和子网络参数怎么关系？**

#### 串联（Series）：Z 参数直接相加

两个端口都串联起来：

```
     ●──┐    ┌──●
        │ Na │
     ●──┤    ├──●
        │ Nb │
     ●──┘    └──●
```

（端口 1 的两个子端口串联，端口 2 也串联。）

**总 Z 矩阵 = 子 Z 矩阵之和**：

Z=Za+Zb

#### 并联（Parallel）：Y 参数直接相加

Y=Ya+Yb

#### 级联（Cascade）：T 参数相乘 ⭐

T=Ta⋅Tb

**这是 T 参数最强大的用途**——多级系统分析时，各级 T 参数直接矩阵连乘即可。

#### 混联（Series-parallel）：H 参数相加

H=Ha+Hb

（一个端口串联，另一个端口并联——不常见，略）

---

### 三、互联必须满足"端口条件"

**⚠️ 警告**：上面这些公式并不总是成立——必须满足**"端口条件"**（每对端子流入流出电流相等）。

对于一般电路（尤其是有公共地线的电路），互联后原来的端口条件**可能被破坏**。工程上需要仔细验证；一个常用的做法是**加一个 1:1 变压器**做隔离以保证端口条件。

这部分细节属于进阶内容，你知道"有这个坑"就行。

---

### 四、典型应用：级联放大器

**场景**：三级放大器级联，每一级用 T 参数描述。

Ta=[AaBaCaDa],Tb,TcTa=[AaCaBaDa],Tb,Tc

**总系统 T 参数**：

T总=TaTbTcT总=TaTbTc

**只要做矩阵乘法，整个级联系统的特性就出来了**——不需要把三级放大器的所有内部元件放在一起联立求解。

这就是"黑箱化"的威力——**复杂度从"加法"降到了"乘法"**。

## 📋 第十一章总结

|概念|核心|
|---|---|
|二端口网络|把电路抽象成两个端口的"黑箱"|
|四组参数|Z（开路）、Y（短路）、H（混合）、T（级联）|
|测量方式|对应地开路/短路一个端口|
|互易性|Z_12=Z_21, Y_12=Y_21, H_12=-H_21, AD-BC=1|
|互联规则|串联→Z相加；并联→Y相加；**级联→T相乘**|

### 📌 如果要记住 10 个最重要的公式

1. 欧姆定律：u=Ri
2. KCL、KVL：∑i=0，∑u=0
3. 电容 VCR：iC=C du/dt
4. 电感 VCR：uL=L di/dt
5. 换路定则：uC(0+)=uC(0−)，iL(0+)=iL(0−)
6. 一阶三要素法：f(t)=f(∞)+[f(0+)−f(∞)]e−t/τ
7. 相量阻抗：ZL=jωL，ZC=1/(jωC)
8. 谐振频率：ω0=1/LC
9. 复功率：S~=U˙I˙∗=P+jQS~=U˙I˙∗=P+jQ
10. 网络函数：H(s)=L[h(t)]
