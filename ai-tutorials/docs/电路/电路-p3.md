## 第三章 电路定理

第二章我们学了三种"通用方法"——支路法、回路法、节点法。它们是万能的，但有个缺点：**方程多、算得累**。

第三章要学的五个定理，本质上是**五种"偷懒的艺术"**——在特定情况下，它们能让你几乎"一眼看出答案"。

### 3.1 置换定理（Substitution Theorem）

#### 先用一个问题引入

假设我解出了某电路的一条支路：电流 I=2I = 2 I=2 A，电压 U=6U = 6 U=6 V。

现在我把这条支路"挖掉"，换成一个 **2A 的电流源**，电路其他部分会变吗？

---

**稍停一下，请你自己想想**：

换上 2A 电流源后，原先连接这条支路的两个节点之间，电流还是 2A 吗？电压还是 6V 吗？电路其他部分的电流电压会变吗？

（凭直觉答，不用严谨证明）

---

#### 答案：不会变！

**置换定理**的内容：

> 电路中任一支路 k，若已知其电压 UkU_k Uk 和电流 IkI_k Ik，则可以用以下任一"等效元件"置换它，电路其他部分的**所有电压电流保持不变**：
>
> - 一个电压为 UkU_k Uk 的**电压源**
> - 一个电流为 IkI_k Ik 的**电流源**
> - 一个电阻满足 $R = U_k/I_k$（只要 $I_k \neq 0$）

#### 为什么？（直觉理解）

电路其他部分"看到的"这条支路，只是一个"两端之间有电压 UkU_k Uk、流过电流 IkI_k Ik"的黑箱。**黑箱里是什么不重要**，只要端口上的 U,IU, I U,I 一致，外部感受不到任何差别。

这就像你问"隔壁屋子里有人在说话"——你只听到声音，里面是录音机还是真人，你听不出区别。

#### 一个用法示例

```
   ┌──[R1]──┬──[R2]──┐
   │        │        │
  (+)      [R3]     [R4]
   U        │        │
  (-)       │        │
   │        │        │
   └────────┴────────┘
```

假设通过某种方法我算出了 R3 上电流 $I_3 = 1$ A。

**接下来想求 R4 上电压？**

- 把 R3 换成 **1A 电流源**——R3 上的电阻值对后续计算毫无影响！
- 电路变简单了：现在是"一个电压源 U，串联 R1，并联一个 1A 电流源（方向固定），再并联一个 R2-R4 支路"

这招在分析时非常省事——**已知量直接"冻结"**，让剩下的部分聚焦在未知量上。

### 3.2 叠加原理（Superposition）

#### 核心思想（一句话）

> **在线性电路中，多个独立源共同作用产生的响应，等于每个独立源单独作用时产生的响应之和。**

注意三个关键词：

1. **线性电路**（所有元件都是线性的）
2. **独立源**（受控源不参与叠加，始终保留）
3. **响应**（可以是某支路电流，也可以是某元件电压）

#### "单独作用" 是什么意思？

**让一个源单独作用** = **把其他独立源"置零"**：

- 电压源置零 = **短路**（因为电压源 U=0 就是一根导线）
- 电流源置零 = **开路**（因为电流源 I=0 就是断开）

> ⚠️ **注意**：只置零**独立源**！**受控源必须保留**（因为它不是"源"，是一种约束关系）。

#### 一个例子

```
   ┌──[2Ω]──── a ───[3Ω]──┐
   │           │           │
  (+)        [6Ω]         ↑
  12V          │          2A
  (-)          │          ↓
   │           │           │
   └───────────┴───────────┘
              地
```

求节点 a 的电压 UaU_a Ua。

**第一步：12V 单独作用**（2A 电流源开路）

```
   ┌──[2Ω]──── a ───[3Ω]──┐
   │           │           │
  (+)        [6Ω]      开路（悬空）
  12V          │
  (-)          │
   │           │
   └───────────┴──────────
```

3Ω 右端开路，故 3Ω 上无电流、无压降。所以节点 a 的电压就等于 6Ω 上的电压。

这是一个简单的分压：12V 电压源经 2Ω 接到 a，a 经 6Ω 接地。

$U_a^{(1)} = 12 \times \frac{6}{2+6} = 9 \text{ V}$

**第二步：2A 电流源单独作用**（12V 电压源短路）

```
   ┌──[2Ω]──── a ───[3Ω]──┐
   │           │           │
  短路      [6Ω]          ↑
   │           │          2A
   │           │          ↓
   └───────────┴───────────┘
```

12V 短路后，2Ω 左端直接接地。所以从 a 往左看是 2Ω，往下看是 6Ω，这两个**并联**：

$$R_{左下} = 2 \parallel 6 = \frac{2 \times 6}{2+6} = 1.5\,\Omega$$

右边 2A 电流源经过 3Ω 到 a。节点 a 对地的等效电阻路径：往右看 3Ω，然后...

等等，让我重新梳理一下。2A 电流源（假设箭头向上）接在 3Ω 右端和地之间。那么 2A 电流从地流出，经电流源向上，再经 3Ω 从右向左流入节点 a，然后从 a 分流到 2Ω 和 6Ω 去。

节点 a 看向地的等效电阻：2Ω ∥ 6Ω = 1.5Ω

流入 a 的电流为 2A（经 3Ω 进来），则：

$U_a^{(2)} = 2 \times 1.5 = 3 \text{ V}$

**叠加**：

$U_a = U_a^{(1)} + U_a^{(2)} = 9 + 3 = 12 \text{ V}$

#### 齐性定理（顺带提一下）

**齐性**（Homogeneity）：在线性电路中，**所有独立源同时放大 k 倍，所有响应也放大 k 倍**。

叠加 + 齐性 = **线性性质**的两个方面。

#### 叠加原理的典型陷阱

**❌ 功率不能叠加！**

$P = UI$ 是乘积关系，不是线性关系。

比如：电阻 R 上，源 1 单独作用时 U1,I1U_1, I_1 U1,I1，源 2 单独作用时 U2,I2U_2, I_2 U2,I2：

$P_{总} = (U_1+U_2)(I_1+I_2) \neq U_1 I_1 + U_2 I_2$

**求功率必须先叠加出总电压/总电流，再算功率！**

### 3.3 等效电源定理（本章最重要！⭐）

这是电路分析中**使用频率最高**的定理，你要熟到"看电路就条件反射"的程度。

#### 3.3.1 戴维南定理（Thévenin's Theorem）

##### 定理内容

> 任意一个**线性含源二端网络**（从外部看是两个端子的电路），对外电路而言，都等效于一个**电压源串联电阻**的组合：
>
> - 电压源值 UocU_{oc} Uoc = 该二端网络**开路电压**
> - 串联电阻 RthR_{th} Rth = 该二端网络内部所有独立源置零后的**等效电阻**

```
  复杂线性网络        戴维南等效
     ┌───┐               ┌──[R_th]──┐
     │ ? │ a              │          │ a
     │   │    ═══►      (+)
     │ ? │ b             U_oc
     └───┘               (-)
                          │          │ b
                          └──────────┘
```

##### 为什么这么有用？

想象你在设计电路：电源部分可能非常复杂（几十个元件），但你关心的"负载"只要通过**两个端子**连接上去。

→ **把电源部分打包成一个"U_oc 串 R_th"的黑箱**，负载想换什么就换什么，计算超级简单。

##### 求戴维南等效的三步法

**步骤 1：求开路电压 UocU_{oc} Uoc**

把外电路断开（端口开路），用任何方法（节点法、回路法、叠加法……）求端口电压。

**步骤 2：求等效电阻 RthR_{th} Rth**

这一步有**三种方法**，按情况选择：

**方法 A：置零法**（电路中**只有独立源**时）

- 所有独立源置零（电压源短路、电流源开路）
- 从端口看进去的电阻即为 RthR_{th} Rth

**方法 B：外加电源法**（含**受控源**时⚠️）

- 独立源置零，但受控源保留
- 在端口外加一个测试电压 $U_T$（或电流 $I_T$）
- 求端口响应电流 $I_T$（或电压 $U_T$）
- $R_{th} = U_T / I_T$

**方法 C：开路短路法**

- 求开路电压 UocU_{oc} Uoc
- 求**端口短路**时的短路电流 IscI_{sc} Isc
- $R_{th} = U_{oc} / I_{sc}$

**步骤 3：画出等效电路**

```
      ┌──[R_th]──┐
      │          │
     (+)
     U_oc       端口 a
     (-)           端口 b
      │          │
      └──────────┘
```

---

#### 3.3.2 诺顿定理（Norton's Theorem）

##### 定理内容

> 任意线性含源二端网络，对外电路而言也等效于一个**电流源并联电阻**的组合：
>
> - 电流源 IscI_{sc} Isc = 该网络**端口短路**时的短路电流
> - 并联电阻 $R_N$ 与戴维南电阻相同，即 $R_N=R_{th}$。

```
     ┌──────────┐
     │          │
     ↑        [R_N]
    I_sc        │    端口 a
     ↓          │
     │          │    端口 b
     └──────────┘
```

##### 戴维南 ↔ 诺顿 互相转换

这两种形式可以**互相转换**（电源等效变换）：

$$I_{sc} = \frac{U_{oc}}{R_{th}}, \qquad R_N = R_{th}$$

```
  戴维南                    诺顿
  ┌──[R]──┐               ┌───────┐
  │       │               │       │
 (+)      │    ═══►       ↑      [R]
  U       │               U/R     │
 (-)      │               ↓       │
  │       │               │       │
  └───────┘               └───────┘
```

**实用技巧**：求等效电路时，哪种好求就先求哪种，需要另一种时转换一下。

---

#### 经典例题：戴维南等效

```
   ┌──[2Ω]──┬──[3Ω]──┐ a
   │        │        │
  (+)      [6Ω]      │
  12V       │        │
  (-)       │        │ b
   │        │        │
   └────────┴────────┘
```

求 a-b 端口的戴维南等效电路。

**步骤 1：求 UocU_{oc} Uoc**（端口 a-b 开路）

a-b 开路意味着 3Ω 右端悬空，故 3Ω 上无电流、无压降。则：

$U_{oc} = U_{ab} = U_{6Ω} = 12 \times \frac{6}{2+6} = 9 \text{ V}$

**步骤 2：求 RthR_{th} Rth**（12V 电压源短路）

```
   ┌──[2Ω]──┬──[3Ω]──┐ a
   │        │        │
  短路    [6Ω]      │
   │        │        │
   │        │        │ b
   └────────┴────────┘
```

从 a-b 往里看：经过 3Ω，到节点 ×，往下是 6Ω、往左是 2Ω（左端接地 = 接 b 端）。

所以 2Ω 和 6Ω **并联**，再和 3Ω **串联**：

$R_{th} = 3 + (2 \parallel 6) = 3 + 1.5 = 4.5 \text{ Ω}$

**最终戴维南等效**：

```
     ┌──[4.5Ω]──┐
     │          │
    (+)         │ a
    9V
    (-)         │ b
     │          │
     └──────────┘
```

如果把负载 $R_L=4.5\,\Omega$ 接到 a-b 端口，则负载电流为 $I=9/(4.5+4.5)=1\,\mathrm{A}$，不必重新分析原电路。

→ CCVS 电压 = 3×0 = 0

→ $U_{oc} = 12$ V（12V 电源直接通过 2Ω 和 CCVS 到 a，但 2Ω 无压降，CCVS 也为 0）

**例题（含受控源的戴维南）**：

电路中有一个 10V 独立电压源、电阻 $R_1=2\,\Omega$、电阻 $R_2=3\,\Omega$，以及一个 CCVS。受控源电压为 $U_{\text{控}}=2i_1$，其中 $i_1$ 是流过 $R_1$ 的电流。

连接关系：10V 电源的 + 端经 $R_1$（电流 $i_1$ 向右为正）到节点 a；节点 a 经 $R_2$ 到 CCVS 的 + 端；CCVS 的 − 端接地；10V 的 − 端也接地。求 a-**地**端口的戴维南等效。

**这里 "端口" 就是节点 a 和地之间。**

**① 求 UocU_{oc} Uoc**

a 端开路意味着 $R_2$ 右端悬空，故 $R_2$ 支路电流为 0，$R_2$ 上无压降。

但 $R_1$ 支路是闭合回路吗？$R_1$ 右端接 a，a 开路——所以 $R_1$ 也没有电流了！$i_1 = 0$。

$\Rightarrow U_{CCVS} = 2 \times 0 = 0$

因此，$U_{oc}$ 等于节点 a 的电位，即 10 V（因为 $R_1$ 无压降，a 直接等于 10 V 电源的正极电位）。

$U_{oc} = 10 \text{ V}$

**② 求 RthR_{th} Rth**（独立源置零，10V 短路；**受控源保留**）

10V 电压源置零后等效为短路，$R_1$ 左端接地；在 a-地端口外加测试电压 $U_T$。

- 设从端口流入的测试电流为 $I_T$
- 此时 $i_1$ 表示从地经 $R_1$ 流向节点 a 的电流。

等等，现在 a 接外部 $U_T$，不是悬空了。$R_1$ 从地（原 10V 负极）到 a，如果 $U_a = U_T$，则 $i_1$ 方向是从 a 经 $R_1$ 流向地吗？让我们设 $i_1$ 向右为正（从地流向 a），那么 $i_1 = (0 - U_T)/R_1 = -U_T/2$。

$U_{CCVS} = 2 i_1 = -U_T$

应用 KVL 分析 $R_2$-CCVS 支路：从 a 经 $R_2$ 到 CCVS 的 +，CCVS 的 − 接地。

$U_a - I_{R_2} \cdot R_2 - U_{CCVS} = 0$沿这条路径 KVL，到地）

$U_T - I_{R_2} \cdot 3 - (-U_T) = 0$

$2U_T = 3 I_{R_2}$

$I_{R_2} = \frac{2U_T}{3}$（从 a 流向地）

测试电流 $I_T$ 等于流入端口的总电流，即 $I_{R_2}$ 与流向 $R_1$ 的电流之和。

流向 $R_1$ 方向的电流 = $-i_1 = U_T/2$（因为 $i_1$ 定义为从地流向 a，而测试电流是从 a 流向地）

$$I_T = \frac{2U_T}{3} + \frac{U_T}{2} = \frac{7U_T}{6}, \qquad R_{th} = \frac{U_T}{I_T} = \frac{6}{7}\,\Omega$$

**戴维南等效**：10 V 电压源串联 $\frac{6}{7}\,\Omega$。

---

我知道这个例子的推导有点冗长。**关键思路你必须记住**：

> **含受控源时，求 $R_{th}$ 应使用外加电源法**：将独立源置零、保留受控源，在端口外加测试源，然后计算 $R_{th}=U_T/I_T$。


**求 UocU_{oc} Uoc**（a-b 开路）

a 开路意味着从节点 × 到 a 没有电流。所以 4Ω 和 3A 电流源的电流必须互相"消化"——全部 3A 都流经 4Ω。

KCL @ 节点 ×：3A 从电流源流入 = 从 × 经 4Ω 流向 24V 正极的电流。

所以 4Ω 上电流 = 3A，方向从 × 流向 24V 正极（即从右向左）。

4Ω 上压降 = 3×4 = 12V，右端为 +（因为电流从右流向左，说明右端电位高）。

$$U_{oc}=U_{\times}=U_{24\mathrm{V},+}+12=24+12=36\,\mathrm{V}.$$ 

$\boxed{U_{oc} = 36 \text{ V}}$

**求 RthR_{th} Rth**（24V 短路，3A 开路）

24V 短路后 4Ω 左端接地；3A 开路后电流源支路断开。

从 a-b 往里看：只剩 4Ω，上端接 a，下端接地（b）。

$\boxed{R_{th} = 4 \text{ Ω}}$

**戴维南等效**：36V 串联 4Ω。

## 3.4 特勒根定理（Tellegen's Theorem）

这个定理是个"怪才"——它听起来平平无奇，但威力巨大。

### 定理内容

> 对**任意电路**，只要所有支路电压 uku_k uk 取"关联参考方向"下的电压，所有支路电流 iki_k ik 取同样的参考方向，则：
>
> $$\sum_{k=1}^{b} u_k i_k = 0$$

这个等式说：**全电路所有支路上 ukiku_k i_k ukik 的代数和恒等于零**。

### 它的物理意义是什么？

关联参考方向下 ukiku_k i_k ukik 就是该支路**吸收**的功率。所以这个公式说的是：

> **整个电路"吸收的总功率" = 0**

换句话说——电源释放的功率 = 所有元件吸收的功率。这就是**能量守恒**！

### 特勒根定理厉害在哪里？

关键是**它对"任意电路"成立**——包括非线性电路、时变电路。只要满足 KCL 和 KVL 就行。

更奇妙的是**特勒根定理的推广形式**：

> 有两个电路 $N$ 和 $\hat{N}$，**拓扑结构完全相同**（图相同），但元件可以完全不同。用 $u_k$ 表示 $N$ 的支路电压，$\hat{i}_k$ 表示 $\hat{N}$ 的支路电流（参考方向一致），则：
>
> $$\sum_{k=1}^{b} u_k \hat{i}_k = 0 \quad \text{和} \quad \sum_{k=1}^{b} \hat{u}_k i_k = 0$$

两个**不同电路**的电压和电流"混搭"起来，求和也等于 0！这就神奇了。

### 直觉理解

为什么会这样？

- KCL 只和**电路的图**有关（谁连着谁）
- KVL 也只和**电路的图**有关
- 只要两个电路的图相同，$N$ 的电压和 $\hat{N}$ 的电流就能按对应支路配对。

### 用途

特勒根定理主要是**理论证明工具**：

- 证明互易定理（下一节）
- 证明网络的其他对称性
- 电路灵敏度分析

**作为一年级本科生，你只需要记住**：

1. 普通形式 → 能量守恒
2. 推广形式 → 同拓扑电路电压电流的"奇妙乘积关系"
3. 这是一个"理论桥梁"，算具体数值题不常用

## 3.5 互易定理（Reciprocity Theorem）

### 先看一个神奇的现象

```
           电路 N₁（原电路）                     电路 N₂（互易后）
   ┌──[R1]──┬──[R3]──┐                 ┌──[R1]──┬──[R3]──┐
   │        │        │                 │        │        │
  (+)      [R2]     (I₂?)              │      [R2]      (+)
   U        │        │                (I₁?)     │        U
  (-)       │        │                 │        │        │
   │        │        │                 │        │        │
   └────────┴────────┘                 └────────┴────────┘
     ①左端放电源               ②把电源搬到右端（同样的U），
     测右端电流 I₂                测左端电流 I₁
```

**结论**：对于**线性无独立源、无受控源**的电路，$I_1 = I_2$。

**激励（电源）和响应（电流）位置互换，数值不变**！这就是互易定理。

### 三种形式

**形式一：电压源激励 → 电流响应**

在 1-1' 端加电压源 $U_s$，将 2-2' 端短路并测量电流 $I_2$。

把同一电压源 $U_s$ 移到 2-2' 端，将 1-1' 端短路并测量电流 $I_1$。

结论：$\boxed{I_1 = I_2}$

**形式二：电流源激励 → 电压响应**

在 1-1' 端加电流源 $I_s$，将 2-2' 端开路并测量电压 $U_2$。

把同一电流源 $I_s$ 移到 2-2' 端，将 1-1' 端开路并测量电压 $U_1$。

结论：$\boxed{U_1 = U_2}$

**形式三：电压源激励 → 电压响应（注意！要求比值）**

在 1-1' 端加电压源 $U_s$，将 2-2' 端开路并测量电压 $U_2$。

将激励换成电流源 $I_s$ 并移到 2-2' 端，再将 1-1' 端开路并测量电压 $U_1$。

结论：$\boxed{\dfrac{U_1}{I_s} = \dfrac{U_2}{U_s}}$

### 互易定理的前提（⚠️ 非常重要）

互易定理**不是对所有线性电路都成立**！必须满足：

1. **线性** ✓
2. **只含电阻**（或更一般地：**互易元件**，电容、电感、变压器也行）
3. **不含受控源**⚠️（受控源会破坏互易性）
4. **不含独立源**（激励源单独考虑，内部不能有其他独立源）

### 一个例子

```
   ┌──[2Ω]──┬──[3Ω]──┐
   │        │        │
  (+)      [6Ω]      短路
  10V       │        │
  (-)       │        │
   │        │        │
   └────────┴────────┘
```

左端施加 $10\,\text{V}$ 激励，右端短路，求短路电流 $I$。

**直接算**：

- 从 a-b 端口看进去（把 10V 短路）：2Ω 和 6Ω 并联，再和 3Ω 串联

等等，让我直接求：节点 a（上方中间）对地电压 UaU_a Ua：

节点方程：$\dfrac{10 - U_a}{2} = \dfrac{U_a}{6} + \dfrac{U_a}{3}$

解得 $U_a = 5$ V。右端短路电流 = $U_a / 3 = 5/3$ A。

**根据互易定理**：若把 10V 搬到右端（短路到地），2Ω 左端短路测电流，结果也应该是 5/3 A。（你有兴趣可以验算，会发现确实如此。）

### 互易定理的用途

- **双口网络分析**（第十一章会用到）
- **天线理论**（发射天线 = 接收天线，就是互易定理的应用）
- **电网络对称性的判定**

## 📋 第三章总结

|定理|关键公式/要点|最大陷阱|
|---|---|---|
|置换定理|已知 Uk,IkU_k, I_k Uk,Ik 可用电源替换|只能换已知支路|
|叠加原理|多源响应 = 各源单独响应之和|**功率不能叠加**；受控源不置零|
|戴维南/诺顿|$U_{oc}$ 与 $R_{th}$（或 $I_{sc}$ 与 $R_N$）|含受控源时必须用外加电源法|
|特勒根定理|$\sum u_k i_k = 0$（能量守恒）|主要用于理论证明|
|互易定理|激励-响应位置可换|**不能含受控源和独立源**|
