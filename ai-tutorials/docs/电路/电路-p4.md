## 4.1 电容元件（大学升级版）

高中你学的电容，核心是 **"电荷储存器"**——Q = CU，静电学里的元件。

大学电路里，电容的"身份"升级了：**它是一个有时间动态的元件**。我们关心的不再是"储了多少电"，而是"电压电流随时间怎么变"。

---

### 一、电容的 VCR（伏安关系）—— 核心公式

从高中的Q = CU出发，我们做一件简单的事：**对时间求导**。

Q = Cu

两边对 t 求导（C 是常数）：

$$\frac{dQ}{dt} = C\frac{du}{dt}$$

而 $\dfrac{dQ}{dt}$ 就是电流 $i$（单位时间内流过的电荷量）：

$$\boxed{i = C\frac{du}{dt}}$$

**这就是电容的 VCR**。它是本章最重要的公式，你必须刻在脑子里。

---

### 二、这个公式揭示的五个惊人事实

#### 事实 ①：电容电流取决于电压的"变化率"，不是电压本身

这和电阻截然不同：

- 电阻：i = u/R→ 电压越大，电流越大
- 电容：$i = C \, du/dt$ 电压变化**越快**，电流越大

**一个极端例子**：电容两端加一个 1000V 的**恒定**直流电压，电流是多少？

du/dt = 0（不变）→i = 0

**电容在直流稳态下等效于开路！** 这是重要结论。

#### 事实 ②：电容电压不能突变

假设电压突变（比如 0V 瞬间跳到 5V），那 $du/dt = \infty$，需要无穷大电流——物理上不可能。

$\boxed{\text{电容电压不能突变：} u_C(0^+) = u_C(0^-)}$

这条在第九章分析动态电路初始条件时是**金科玉律**。

#### 事实 ③：电容有"记忆"

把 VCR 反过来积分：

$$u(t) = \frac{1}{C}\int_{-\infty}^{t} i(\tau)\,d\tau$$

或者从某个初始时刻 $t_0$ 开始：

$$u(t) = u(t_0) + \frac{1}{C}\int_{t_0}^{t} i(\tau)\,d\tau$$

看到了吗？**t 时刻的电压，取决于过去所有时刻的电流**。这就是"记忆"——电容记得它经历过什么。

对比电阻u = Ri：电阻是"无记忆"的，此刻电压只看此刻电流。

#### 事实 ④：电容储能

从功率入手，关联参考方向下：

$p = ui = u \cdot C\frac{du}{dt}$

从 $-\infty$（电压为 0）积分到当前时刻：

$$\boxed{W_C = \frac{1}{2}Cu^2}$$

**电容储存的是电场能量**（电介质中的电场）。注意：它**储能不耗能**——能存进去、能放出来，但不消耗（理想情况）。

#### 事实 ⑤：电容是"无源"但"动态"的元件

- **无源**：长期来看能量只能"过一下手"，不能无中生有
- **动态**：VCR 里有导数/积分，所以它是"动态元件"

对比总结：

|元件|VCR|动态/静态|耗能/储能|
|---|---|---|---|
|电阻 R|u=Riu = Ri u=Ri|静态（代数关系）|耗能|
|电容 C|$i = C \, du/dt$|**动态**（微分关系）|**储能**（电场）|

---

### 三、电容的串并联

这部分规律和电阻**刚好相反**，记的时候要小心：

**并联**（电压相同，电流相加）：

$C_{并} = C_1 + C_2 + \cdots$

（像电阻串联的公式）

**串联**（电流相同，电压相加）：

$$\frac{1}{C_{串}} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots$$

（像电阻并联的公式）

**为什么规律反了？**留给你一个思考题：用Q=CU和 KVL/KCL 能推出来。

## 4.2 电感元件（全新内容，从零开始）

### 一、电感是什么？物理直觉先行

电感最常见的形式就是一个**线圈**：

```
          ┌─────────┐
     ─────┤ ∿∿∿∿∿∿ ├─────
          └─────────┘
```

**物理现象**：通电线圈会产生磁场（奥斯特实验，高中学过）。反过来，变化的磁场会在线圈里感应出电压（法拉第电磁感应定律）。

**关键一步——"自感应"**：

在线圈中通入电流 $i$ 会产生磁通 $\Phi$。当 $i$ 变化时，$\Phi$ 随之变化，线圈自身会感应出阻碍这一变化的电压。

$$u = \frac{d\Phi}{dt}$$

磁通 $\Phi$ 与电流成正比：$\Phi = Li$（$L$ 是电感系数，单位为亨利 H）。

两式合并：

$$\boxed{u = L\frac{di}{dt}}$$

**这就是电感的 VCR**。

---

### 二、电感 vs 电容——完美的"对偶"

把两个 VCR 对比着看：

||电容|电感|
|---|---|---|
|VCR|$i = C \dfrac{du}{dt}$|$u = L \dfrac{di}{dt}$|
|关心的变量|**电压**不能突变|**电流**不能突变|
|直流稳态|**开路**（电流=0）|**短路**（电压=0）|
|储能|$W = \dfrac{1}{2}Cu^2$（电场）|$W = \dfrac{1}{2}Li^2$（磁场）|
|串并联|和电阻**相反**|和电阻**相同**|

看出来了吗？**电感和电容在公式形式上完全对偶**——只要把"u"和"i"、"C"和"L"对换，两个元件的所有性质都能互换。

> 💡 **记忆技巧**：记住电容的所有性质，电感只要"对偶一下"就能推出来，不用单独记。

---

### 三、电感五个性质（对偶推出）

#### 性质 ①：电压取决于电流"变化率"

- 电流不变 →di/dt = 0→u = 0→ **直流稳态下电感等效于短路**

#### 性质 ②：电流不能突变

$\boxed{i_L(0^+) = i_L(0^-)}$

#### 性质 ③：电感有"记忆"

$$i(t) = i(t_0) + \frac{1}{L}\int_{t_0}^{t} u(\tau)\,d\tau$$

#### 性质 ④：储能公式

$$W_L = \frac{1}{2}Li^2 \quad \text{（磁场能量）}$$

#### 性质 ⑤：串并联规律（和电阻相同）

**串联**：$L_{串} = L_1 + L_2 + \cdots$  
**并联**：$\dfrac{1}{L_{并}} = \dfrac{1}{L_1} + \dfrac{1}{L_2} + \cdots$

## 4.2 耦合电感（互感）

前面讲的电感是**单独一个线圈**的"自感应"。现在我们让两个线圈**靠近**，看会发生什么。

---

### 一、先用物理直觉打地基

#### 场景想象

两个线圈 L₁ 和 L₂ 靠得很近（比如绕在同一根铁芯上）：

```
      i₁ →                    i₂ →
   ┌──[L₁]──┐             ┌──[L₂]──┐
   │  ∿∿∿∿  │             │  ∿∿∿∿  │
   + u₁  -                  + u₂  -
               ╲ 磁场耦合 ╱
                ─────────
```

**Q（请你思考）**：如果我只在 L₁ 里通电流 $i_1$（L₂ 断开不通电），L₂ 两端会有电压吗？

---

**答**：**会有！**

为什么？$i_1$ 在 L₁ 中产生磁场，这个磁场**会穿过 L₂**（因为两个线圈靠得近）。如果 $i_1$ 是变化的，穿过 L₂ 的磁通就变化，根据法拉第电磁感应定律，L₂ 里就感应出电压。

**这就是"互感"**：一个线圈的电流变化在另一个线圈中感应电压的现象。

---

### 二、数学描述

#### 自感磁通 vs 互感磁通

现在 L₁ 里的**总磁通**来自两个源：

- **本线圈**的电流 $i_1$ 产生的磁通：$\Phi_{11} = L_1 i_1$（自感磁通）
- **L₂** 的电流 $i_2$ 产生的交链磁通：$\Phi_{12} = M i_2$（互感磁通，$M$ 是互感系数）

同样 L₂ 的总磁通：

- 自感磁通：$\Phi_{22} = L_2 i_2$
- 互感磁通：$\Phi_{21} = M i_1$

理论上两个互感系数分别记为 $M_{12}$ 和 $M_{21}$。在线性互易介质中可证明 $M_{12}=M_{21}=M$，因此通常只用一个互感系数 $M$。

#### 端口电压

每个线圈两端的电压 = 总磁通对时间的导数：

$$\begin{aligned} u_1 &= L_1\frac{di_1}{dt} \pm M\frac{di_2}{dt} \\ u_2 &= L_2\frac{di_2}{dt} \pm M\frac{di_1}{dt} \end{aligned}$$

注意那个 **"±"** —— 这是耦合电感的**最大难点**。正负号取决于两个线圈的**绕向**。

---

### 三、同名端——解决"±"问题的关键

#### 问题的由来

两个线圈的磁场有可能**相互加强**（磁通方向一致），也可能**相互削弱**（磁通方向相反）——取决于它们的**绕线方向**和**电流方向**。

#### 工程上的约定：用"同名端"标记

电路图上画两个线圈时，根本看不出绕线方向（就是两个曲线而已）。工程上在每个线圈的其中一端标一个"**·**"（黑点）：

```
     ·               ·
   ┌──[L₁]──┐     ┌──[L₂]──┐
   │  ∿∿∿   │     │  ∿∿∿   │
```

**同名端的物理意义**：

> **两个黑点端**：若两个电流都**从黑点端流入**，则它们产生的磁通**方向相同**（相互加强）。

#### 互感电压的正负号规则

**一句话口诀**：

> **"入同出同取正，入异出异取负"** —— 看两个电流相对于同名端的"进出"关系。

**具体判断方法**：考察互感电压 $M \dfrac{di_2}{dt}$ 在 $u_1$ 方程中的正负号：

- 若 $i_2$ 从 L₂ 的同名端**流入**，并且 $u_1$ 的**"+"端在 L₁ 的同名端**：取 **+**
- 反之取 **−**

#### 举个实例

```
     ·  i₁→          ·  i₂→
   ┌──[L₁]──┐      ┌──[L₂]──┐
   │        │      │        │
   + u₁ -           + u₂ -

   黑点都在左上方，i₁、i₂都从黑点流入
   u₁、u₂的"+"端都在黑点端
```

此时：

$$\begin{aligned} u_1 &= L_1\frac{di_1}{dt} + M\frac{di_2}{dt} \\ u_2 &= L_2\frac{di_2}{dt} + M\frac{di_1}{dt} \end{aligned}$$

（两个互感项都取 **+**，因为电流和黑点端的关系"入同出同"）

---

### 四、耦合系数 k

问题：互感 M 能不能无穷大？

**不能**。物理限制：**一个线圈的磁场，不可能全部都穿过另一个线圈**（总有漏磁）。

定义**耦合系数**：

$$k = \frac{M}{\sqrt{L_1L_2}}, \qquad 0 \leq k \leq 1$$

- k=0k = 0 k=0：完全不耦合（两线圈离得远，磁场没交集）
- k=1k = 1 k=1：**全耦合**（所有磁通都共享，没有漏磁）—— 这是**理想变压器**的前提

所以 $M$ 的上界为 $M \leq \sqrt{L_1L_2}$。

---

## 4.3 理想变压器

### 一、从耦合电感到理想变压器

变压器本质上就是一个**耦合电感**，只不过做到了**三个极端**：

1. **全耦合**：k = 1（没有漏磁）
2. **无损耗**：线圈电阻 = 0，铁芯无涡流损耗
3. **电感趋于无穷大**：$L_1, L_2, M \to \infty$，但匝数比 $N_1:N_2$ 保持有限

把这三个条件"极端化"，耦合电感的方程就退化成一个超级简洁的形式——**理想变压器**。

---

### 二、理想变压器的两个黄金方程

设一次侧（primary）匝数 $N_1$，二次侧（secondary）匝数 $N_2$，定义**匝数比** $n = N_1 / N_2$。

#### 电压变换

$$\boxed{\frac{u_1}{u_2} = \frac{N_1}{N_2} = n}$$

#### 电流变换

$$\boxed{\frac{i_1}{i_2} = \frac{N_2}{N_1} = \frac{1}{n}}$$

**注意方向约定**：标准电路图里 $i_1$ 从 1' 端流入一次侧，$i_2$ 从 2' 端流出二次侧（或反过来，取决于同名端位置）。这种约定下上面两个公式直接成立。

```
      i₁ →              ← i₂
   ┌──[ ]──┐         ┌──[ ]──┐
   │  ∿∿∿  │ ·       · │  ∿∿∿ │
   + u₁ -             + u₂ -
      N₁                N₂
```

---

### 三、理想变压器的三个关键性质

#### 性质 ①：输入功率 = 输出功率（无损耗）

$p_1 = u_1 i_1 = (n u_2)(i_2 / n) = u_2 i_2 = p_2$

**能量从一次侧瞬时、完整地传到二次侧**。这就是"理想"的真正含义。

#### 性质 ②：阻抗变换

这是理想变压器**最有用**的性质！

假设二次侧接负载 $Z_L$，则 $u_2=Z_Li_2$。

从一次侧看进去的等效阻抗：

$$\boxed{Z_{in} = n^2 Z_L}$$

**一次侧看到的负载 = 实际负载 × 匝数比的平方**。

**工程应用**：这正是**阻抗匹配**的关键技术（第五章最大功率传输会再提）。

#### 性质 ③：注意它**不是**普通电感的极限

理想变压器**不储能**！它只是"瞬时"地把能量从一侧传到另一侧，不像电感那样储存磁场能。这是一个重要的概念区别。

---

### 四、举个简单例子

```
   ─[10V电源]──┤理想变压器 n=2:1├──[4Ω 负载]─
```

一次侧 10V，匝数比 2:1（即 n = 2）。

**二次侧电压**：$u_2 = u_1 / n = 10/2 = 5$ V

**二次侧电流**：$i_2 = u_2 / 4 = 5/4 = 1.25$ A

**一次侧电流**：$i_1 = i_2 / n = 1.25/2 = 0.625$ A

**一次侧看到的等效阻抗**：$Z_{in} = n^2 \cdot 4 = 4 \cdot 4 = 16$

**验证**：一次侧 10V / 16Ω = 0.625 A ✓

**功率**：

- 一次侧：$10 \times 0.625 = 6.25$
- 二次侧：$5 \times 1.25 = 6.25$相等，无损耗）

## 📋 第四章总结

|元件|VCR|核心性质|
|---|---|---|
|电容$i = C \, du/dt$电压不能突变；储电场能；直流稳态=开路|
|电感$u = L \, di/dt$电流不能突变；储磁场能；直流稳态=短路|
|耦合电感|$u_k = L_k \, di_k/dt \pm M \, di_j/dt$|同名端决定正负号；$M \leq \sqrt{L_1 L_2}$|
|理想变压器|$u_1/u_2 = n$；$i_1/i_2 = 1/n$|无损耗传能；阻抗变换 $n^2$ 倍|
