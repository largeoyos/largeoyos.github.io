## 5.1 正弦量

### 一、为什么全世界的电都是正弦？

先聊个开放问题，你凭直觉回答：

**你家墙上的插座，电压是 220V（中国）或 110V（美国）。这个电压是恒定不变的吗？还是变化的？如果变化，怎么变？**

---

答案你可能知道：**是正弦变化的**，50Hz（中国）或 60Hz（美国）。

但为什么是正弦？不能是方波、三角波？原因很多（发电机原理、能量传输效率、变压器只对变化的量工作……），但最根本的一个数学原因是：

> **正弦是线性系统的"特征函数"**——正弦波经过任何线性电路（R、L、C 组合），出来还是**同频率**的正弦波，只是幅值和相位可能变了。

这是后面所有分析的基石。

---

### 二、正弦量的三要素

一个正弦电流（或电压）的完整数学形式：

$i(t) = I_m \cos(\omega t + \varphi)$

```
     i(t)
      ↑
   Im ┤    ╱╲              ╱╲
      │   ╱  ╲            ╱  ╲
    0 ┼─────────────────────────→ t
      │        ╲        ╱
  -Im ┤          ╲____╱
      │←  T  →│
```

**三个要素**：

|要素|符号|名称|单位|
|---|---|---|---|
|幅值|ImI_m Im|峰值/最大值|A|
|角频率|$\omega$|每秒转过的弧度|rad/s|
|初相|$\varphi$|$t=0$ 时刻的相位|rad 或 °|

**三个要素之间的关系**：

$$\omega = 2\pi f = \frac{2\pi}{T}$$

- f：频率（每秒多少个周期），单位 Hz
- T：周期（一个周期的时长），单位 s

**例**：中国电网 $f = 50\,\text{Hz}$，则 $\omega = 2\pi \times 50 = 314\,\text{rad/s}$。因此电路中常见的 314 就是工频 50 Hz 对应的角频率。

---

### 三、有效值（RMS）—— 一个重要概念

**思考题**：你家插座说"220V"，这个 220 是正弦的**峰值** ImI_m Im 吗？

答案：**不是！** 220V 是**有效值**。

#### 有效值的定义（物理意义）

> **有效值 = 能在电阻上产生相同平均发热功率的直流电压/电流值。**

比如说，你家 220V 正弦电压给一个 100Ω 电阻供电，它平均发热功率是多少？

**用有效值算**：P=U有效2/R=2202/100=484P = U_{有效}^2 / R = 220^2 / 100 = 484 P=U有效2/R=2202/100=484 W

这就等于**用 220V 直流电压接同一个电阻的发热功率**。有效值的好处就是：**算平均功率时可以直接当直流用**。

#### 有效值与峰值的关系（对正弦）

经过数学推导（对 $\cos^2$ 在一个周期内求平均，取平方根）：

$$U = \frac{U_m}{\sqrt{2}} \approx 0.707\,U_m$$

所以 220 V 的实际峰值为 $U_m = 220\sqrt{2} \approx 311\,\text{V}$。

**电气工程的默认约定**：说电压/电流时，**默认是有效值**。只有用"峰值"、"幅值"这些词时才指 UmU_m Um。

---

### 四、相位差

两个**同频率**的正弦波之间可以比较"相位差"：

$u_1 = U_m \cos(\omega t + \varphi_1), \quad u_2 = U_m \cos(\omega t + \varphi_2)$

**相位差**：$\varphi = \varphi_1 - \varphi_2$

- $\varphi > 0$：u1u_1 u1 **超前** u2u_2 u2（u1u_1 u1 先达到峰值）
- $\varphi < 0$：u1u_1 u1 **滞后** u2u_2 u2
- $\varphi = 0$：**同相**
- $\varphi = \pm\pi$：**反相**

> ⚠️ **前提**：只有同频率的正弦波才能比相位差！不同频率比相位差是无意义的。

---

## 5.2 相量法基础 ⭐（本章核心中的核心）

现在我们要攻克"**复数表示波**"这个你的痛点。

**请你跟着我，我要慢慢把这件事讲清楚。** 这部分不着急，一步都不要跳。

---

### 一、先说说"为什么需要复数"—— 动机

假设现在有一个 RLC 串联电路，接到正弦电源 $u_s = U_m\cos\omega t$。用 KVL 列方程：

$$u_s = Ri + L\frac{di}{dt} + \frac{1}{C}\int i\,dt$$

这是一个**微分积分方程**。要求 i(t)，得解微分方程——很麻烦。

**有没有办法把这种方程变成普通的代数方程？**

有！这就是**相量法**的目的。它把**微积分方程**变成**代数方程**，代价是：**我们要用复数来表示正弦波**。

---

### 二、预备知识：复数的三种形式

快速复习一下（你说学过复数，应该不陌生）：

**代数形式**：A = a + jb（电路里用 j 不用 i，因为 i 被电流占了）

**几何形式**：A 是复平面上的一个点（或向量）

```
        Im
         ↑
         │      • A = a + jb
       b ┤     ╱
         │    ╱
       0 ┼─────────→  Re
               a
```

**极坐标形式（模角式）**：$A = |A| \angle \theta$

- 模：$|A| = \sqrt{a^2+b^2}$
- 辐角 $\theta = \arctan(b/a)$

**指数形式**（欧拉公式）：

$A = |A| e^{j\theta}$

#### 欧拉公式（⭐ 本章理论基石）

$\boxed{e^{j\theta} = \cos\theta + j\sin\theta}$

这个公式是**连接复数和三角函数的桥梁**。以后我们会反复用它。

---

### 三、把正弦波"升维"到复数（核心一跃）

现在最关键的一步来了。**请集中注意力**。

#### 第 1 步：观察一个奇妙的等式

考虑这个复指数：

$e^{j\omega t}$

由欧拉公式：$e^{j\omega t} = \cos(\omega t) + j\sin(\omega t)$

取它的**实部**：

$\text{Re}\left[e^{j\omega t}\right] = \cos(\omega t)$

正弦波 $\cos(\omega t)$ 可以写成旋转复指数 $e^{j\omega t}$ 的**实部**。

#### 第 2 步：一般的正弦波

对 $i(t) = I_m \cos(\omega t + \varphi)$：

$i(t) = I_m \text{Re}\left[e^{j(\omega t + \varphi)}\right] = \text{Re}\left[I_m e^{j\varphi} \cdot e^{j\omega t}\right]$

中间的 $I_m e^{j\varphi}$ 是一个**与时间无关**的复常数，只包含幅值 $I_m$ 和相位 $\varphi$ 的信息。

$e^{j\omega t}$ 这一部分包含时间和角频率，但在同频率电路中，它对每个量都相同。

#### 第 3 步：相量的定义

由于同频率电路中 $e^{j\omega t}$ 对所有量都相同，可以省略它，只保留包含信息的复数常数，这就是**相量**（phasor）：

$\boxed{\dot{I} = I_m e^{j\varphi} = I_m \angle \varphi}$

> **相量**是一个**复数**，包含正弦波的幅值和初相信息。频率 $\omega$ 不在相量中，因为同一电路中的频率相同。

顶上的小点（或箭头）表示"这是相量，不是普通复数"。

#### 第 4 步：有效值相量

工程上常用**有效值相量**（把幅值换成有效值）：

$$\dot{I} = I\angle\varphi = \frac{I_m}{\sqrt{2}}\angle\varphi$$

本课程之后**默认用有效值相量**，除非特别说明。

---

### 四、相量的物理图像：旋转的向量

在复平面上取一个长度为 $I_m$、初始角度为 $\varphi$ 的向量，使它以角速度 $\omega$ **逆时针旋转**：

```
   时刻 t=0                 时刻 t>0（转了 ωt）

      Im                        Im
       ↑                          ↑
       │ • I_m∠φ                  │    •←旋转向量
       │╱                         │   ╱
       │                          │  ╱
     0 ┼─→  Re                  0 ┼─────→ Re
                                  │
                                  │ 投影到实轴就是 i(t)
                                  ↓
                                cos(ωt+φ)
```

**关键图像**：

- 旋转向量的**实部投影** = 时域正弦波
- 向量的**长度** = 正弦波的幅值
- 向量**当前的辐角**等于当前相位 $\omega t + \varphi$

**相量可看作 $t=0$ 时刻旋转向量的快照**。所有量都以相同的 $\omega$ 旋转，因此相对关系不变，只需保留一个时刻的信息。

---

### 五、相量法为什么能"化微积分为代数"？

这是相量法的威力所在。我现在演示给你看。

#### 关键技巧：微分 → 乘 jω

假设 $i(t) = I_m \cos(\omega t + \varphi)$，其相量为 $\dot{I} = I_m \angle \varphi$。

求导：

$$\frac{di}{dt} = -\omega I_m\sin(\omega t+\varphi) = \omega I_m\cos(\omega t+\varphi+90^\circ)$$

这个导数对应的相量是：$\omega I_m \angle(\varphi + 90°)$

而 $\omega I_m \angle(\varphi + 90°) = I_m \angle\varphi \cdot \omega \angle 90° = \dot{I} \cdot j\omega$

（因为 $\angle 90° = \cos 90° + j\sin 90° = j$

**结论**：

$$\boxed{\frac{di}{dt} \quad \longleftrightarrow \quad j\omega\dot{I}}$$

**时域求导 = 相量域乘 jω**！

#### 类似地：积分 → 除以 jω

$$\boxed{\int i\,dt \quad \longleftrightarrow \quad \frac{\dot{I}}{j\omega}}$$

#### 这意味着什么？

回到最开始的 RLC 串联微积分方程：

$$u_s = Ri + L\frac{di}{dt} + \frac{1}{C}\int i\,dt$$

**相量化**（每一项替换）：

$$\dot{U}_s = R\dot{I} + j\omega L\dot{I} + \frac{1}{j\omega C}\dot{I}$$

提取 $\dot{I}$：

$$\dot{U}_s = \left(R+j\omega L+\frac{1}{j\omega C}\right)\dot{I}$$

**这是一个代数方程！** 没有求导、没有积分。方括号里那一坨复数叫"阻抗"（下一节详细讲）。

---

### 六、消化一下——你需要记住的核心

现在停下来，把这几件事"钉"在脑子里：

|时域|⟷|相量域|
|---|---|---|
|$i(t) = I_m\cos(\omega t + \varphi)$||$\dot{I} = I\angle\varphi$（有效值）|
|$\dfrac{di}{dt}$||$j\omega \dot{I}$|
|$\int i\,dt$|$\dfrac{\dot{I}}{j\omega}$|
|微分方程||代数方程|

**整个相量法的"交易"**：

> 我用**复数**这个更复杂的数，换来了**代数方程**这个更简单的方程。

对于正弦稳态分析，这笔交易**非常划算**。

## 5.3 电路元件的相量形式

前面我们把"正弦波"翻译成了"相量"，把"微积分"翻译成了"乘除 jω"。现在要做一件事：把电阻、电感、电容这三个基本元件的 VCR，也**全部翻译成相量形式**。

翻译完之后你会看到一个奇妙的结果：**三种完全不同的元件，将拥有同一种数学形式**。这就是相量法的真正威力。

---

### 一、电阻 R 的相量形式

时域 VCR：u = Ri

假设 $i(t) = I_m \cos(\omega t + \varphi)$，则 $u(t) = RI_m \cos(\omega t + \varphi)$。

**观察**：电压和电流**同频率、同相位**，幅值差 R 倍。

转成相量：

$\boxed{\dot{U} = R\dot{I}}$

**这就是相量形式的"欧姆定律"**，和时域形式一模一样——电阻是最朴素的，不改变相位。

**相量图**（复平面上表示）：

```
         Im
          ↑
          │
          │        → U = RI  (同方向，U 更长)
          │
          │      → I
          │
        0 ┼────────────→  Re
```

$\dot{U}$ 和 $\dot{I}$ 是**同向**的两个复向量。

---

### 二、电感 L 的相量形式 ⭐

时域 VCR：$u = L \dfrac{di}{dt}$

用我们刚学的"微分 → 乘 jω"规则：

$\boxed{\dot{U} = j\omega L \cdot \dot{I}}$

**这里面藏着两个重要信息**，请你仔细品：

---

复数 $j\omega L$ 的模为 $\omega L$，辐角为 $90°$，它会对 $\dot{I}$ 进行幅值缩放和相位旋转。

---

答案：

- **模**：$|j\omega L| = \omega L$
- **辐角**：$\angle(j\omega L) = 90°$（因为 $j = 1\angle 90°$）

所以 $\dot{U} = (\omega L)\angle 90° \cdot \dot{I}$，其含义是：

> **对电感：电压的幅值 = 电流幅值 × ωL；电压的相位比电流超前 90°**

**这正是电感的物理本质**！电感"反抗电流变化"的特性，在相量图上就是"电压领先电流 90°"。

**相量图**：

```
         Im
          ↑
          │        → U = jωL·I  (垂直方向，超前 90°)
          │        │
          │     → I
        0 ┼────────────→  Re
```

**记忆口诀**：电感"**电压超前**"。

---

### 三、电容 C 的相量形式 ⭐

时域 VCR：$i = C \dfrac{du}{dt}$

相量形式：$\dot{I} = j\omega C \cdot \dot{U}$

整理成 "电压 = ? × 电流" 的形式：

$$\boxed{\dot{U} = \frac{1}{j\omega C}\dot{I} = \frac{-j}{\omega C}\dot{I}}$$

（用到1/j = -j，因为 $j \cdot (-j) = -j^2 = 1$

**分析**：

- **模**：$\left|\dfrac{1}{j\omega C}\right| = \dfrac{1}{\omega C}$
- **辐角**：$\angle(1/j\omega C) = -90°$

所以：

> **对电容：电压幅值 = 电流幅值 × 1/(ωC)；电压相位比电流滞后 90°**

**相量图**：

```
         Im
          ↑
          │     → I
          │
        0 ┼────────────→  Re
          │     │
          │     ↓ U  (超后 90°)
```

**记忆口诀**：电容"**电流超前**"。

---

### 四、三个元件对比总结

请务必把下面这张表**刻在脑子里**：

|元件|时域 VCR|相量 VCR|$\dot{U}$ 与 $\dot{I}$ 的相位关系|
|---|---|---|---|
|电阻 $R$|$u = Ri$|$\dot{U} = R\dot{I}$|同相|
|电感 $L$|$u = L\,di/dt$|$\dot{U} = j\omega L\,\dot{I}$|$\dot{U}$ 超前 $\dot{I}$ 90°|
|电容 $C$|$i = C\,du/dt$|$\dot{U} = \dfrac{1}{j\omega C}\dot{I}$|$\dot{U}$ 滞后 $\dot{I}$ 90°|

---

**一个非常关键的观察**：三个元件的相量 VCR，**都长得像欧姆定律**！

$\dot{U} = Z \cdot \dot{I}$

只是那个"Z"对不同元件不同：

- 电阻：Z = R
- 电感：$Z = j\omega L$
- 电容：$Z = 1/(j\omega C)$

这个 Z 就叫**阻抗**——下一节的主角。

---

## 5.4 阻抗与导纳

### 一、阻抗的定义

> **阻抗**（Impedance）Z：在相量域，一个二端元件（或网络）的电压相量与电流相量之比。
>
> $$Z = \frac{\dot{U}}{\dot{I}}$$

单位：**欧姆 Ω**（和电阻相同）。

**注意**：阻抗是一个**复数**，不是时域的物理量（不要试图写 Z(t)）。

---

### 二、阻抗的几种形式

**代数形式**：

Z = R + jX

其中：

- R：**电阻**分量（实部）
- X：**电抗**分量（虚部），单位也是欧姆
 - X>0X > 0 X>0：**感性**（电感为主）
 - X<0X < 0 X<0：**容性**（电容为主）

**极坐标形式**：

$Z = |Z| \angle \varphi_Z$

- $|Z| = \sqrt{R^2+X^2}$：**阻抗模**
$\varphi_Z = \arctan(X/R)$：**阻抗角**

**阻抗角的物理意义**：电压相位超前电流相位的角度。

$\varphi_Z = \varphi_u - \varphi_i$

---

### 三、三个基本元件的阻抗

**电阻**：ZR=RZ_R = R ZR=R（纯实数）

**电感**：$Z_L = j\omega L$（纯虚数，正虚部）

- 电感的电抗 $X_L = \omega L$，称为**感抗**
- **频率越高，感抗越大**（电感对高频的阻碍越强）

**电容**：$Z_C = \dfrac{1}{j\omega C} = -\dfrac{j}{\omega C}$（纯虚数，负虚部）

- 电容的电抗 $X_C = -\dfrac{1}{\omega C}$，称为**容抗**
- **频率越高，容抗越小**（电容对高频的阻碍越弱）

---

### 四、阻抗的直观理解

**感抗 $X_L = \omega L$ 随频率变化**：

```
  X_L
   ↑
   │      ╱
 0 ┼────────→ ω
```

**容抗 $\lvert X_C \rvert = 1/(\omega C)$ 随频率变化**：

```
  |X_C|
   ↑
   │╲
   │       ─────
 0 ┼────────→ ω
```

**两个重要极限**：

- $\omega \to 0$（直流）：$Z_L \to 0$（短路），$Z_C \to \infty$（开路）——这与第四章的结论一致。
- $\omega \to \infty$（高频）：$Z_L \to \infty$（开路），$Z_C \to 0$（短路）

**工程解读**：

- 电感"喜欢直流，讨厌高频"——常用来做**扼流圈**（阻止高频干扰）
- 电容"讨厌直流，喜欢高频"——常用来做**耦合电容**（隔直流、通交流）

---

### 五、阻抗的串并联（和电阻完全一样！）

这是相量法最妙的地方——**阻抗的串并联公式，和电阻的串并联公式形式完全相同**，只不过把实数换成复数：

**串联**：$Z_{总} = Z_1 + Z_2 + \cdots$

**并联**：$\dfrac{1}{Z_{总}} = \dfrac{1}{Z_1} + \dfrac{1}{Z_2} + \cdots$

（两个阻抗并联：$Z_{总} = \dfrac{Z_1 Z_2}{Z_1 + Z_2}$）

**分压、分流公式也完全一样**，只是用复数运算。

> 💡 这意味着：第二章学的所有分析方法（节点法、回路法）、第三章学的所有定理（戴维南、叠加……），**在正弦稳态下全部适用**，只要把"电阻"换成"阻抗"，把"电压电流"换成"相量"即可。

---

### 六、导纳 Y

**导纳**（Admittance）是阻抗的倒数：

$$Y = \frac{1}{Z} = \frac{\dot{I}}{\dot{U}}$$

单位：**西门子 S**

**代数形式**：

Y = G + jB

- G：**电导**（Conductance）
- B：**电纳**（Susceptance）

**重要提醒**：$G \neq 1/R$，$B \neq 1/X$。正确的转换是：

$$Y = \frac{1}{Z} = \frac{1}{R+jX} = \frac{R-jX}{R^2+X^2}$$

所以 $G = \dfrac{R}{R^2+X^2}$，$B = \dfrac{-X}{R^2+X^2}$。

**什么时候用导纳？**

- 分析**并联**电路时，导纳相加更方便，因为 $Y_{总} = Y_1 + Y_2 + \cdots$。
- 用**节点法**分析正弦电路时，导纳是主角

## 5.5 正弦稳态电路的分析

好消息：**这一节几乎没有新东西**。

因为相量形式下，所有电路变量（电压、电流）变成了相量（复数），所有元件（R、L、C）变成了阻抗（复数），**KCL 和 KVL 仍然成立**，所以——

> **第二章和第三章的一切方法和定理，全部可以直接用，只需把"实数"换成"复数"**。

下面快速过一遍这种"平移"。

---

### 一、相量形式的 KCL 和 KVL

**KCL**（对任意节点）：

∑kI˙k=0k∑I˙k=0

**KVL**（对任意回路）：

∑kU˙k=0k∑U˙k=0

**注意**：这里是**相量相加 = 0**，不是瞬时值或幅值。相量是复数，复数加和为零。

---

### 二、方法移植清单

|直流电路方法/定理|正弦稳态下的"相量版"|
|---|---|
|支路电流法|**支路电流相量法**（未知量为 I˙kI˙k）|
|回路电流法|**回路电流相量法**|
|节点电压法|**节点电压相量法**（节点方程用 Y 不用 G）|
|叠加原理|对每个独立源单独作用，响应相量相加|
|戴维南定理|U˙ocU˙oc + Zth（戴维南阻抗是复数）|
|诺顿定理|I˙scI˙sc + ZN|
|电源等效变换|U˙s=ZI˙sU˙s=ZI˙s|

**核心替换规则**：

- 电压 U → 电压相量 U˙U˙
- 电流 $I$ → 电流相量 $\dot{I}$
- 电阻 R → 阻抗 Z
- 电导 G → 导纳 Y

## 5.6 正弦稳态电路的功率与复功率

功率是本章**第二个重点**（第一个是相量本身）。

为什么专门讲功率？因为正弦电路的功率有**多种**，不再是直流电路的单一 P=UI。

---

### 一、瞬时功率

设元件端电压和电流：

u(t)=Umcos(ωt+φu),i(t)=Imcos(ωt+φi)

**瞬时功率**：

p(t)=u(t)⋅i(t)

用积化和差公式展开（数学细节略）：

p(t)=UIcosφ+UIcos(2ωt+φu+φi)

其中 φ=φu−φi 是**阻抗角**（电压超前电流的角度），U,IU,I 是有效值。

**观察这两项**：

- 第一项 UIcosφ：**常数**（不随时间变）
- 第二项：**以 2ω 振荡**（频率是原来的 2 倍！）

**意义**：瞬时功率既不恒定、也不是简单正弦，而是"**一个恒定偏置 + 一个二倍频振荡**"。

---

### 二、平均功率（有功功率 P）

对瞬时功率在一个周期内求平均：

P=1T∫0Tp(t) dt=UIcosφP=T1∫0Tp(t)dt=UIcosφ

（第二项以 2ω 振荡，一个周期内平均为 0）

P=UIcosφ

**单位**：W（瓦特）

**物理意义**：**真正被消耗掉的功率**（变成热、光、机械能），所以叫"**有功功率**"或"**实功率**"。

#### 功率因数 cos φ

cosφ 叫**功率因数**（Power Factor），它是衡量"电能利用效率"的关键指标。

- cosφ=1（纯电阻电路，φ=0）：功率全部被消耗，效率最高
- cosφ=0（纯电感或纯电容，φ=±90°φ=±90°）：**平均功率 = 0**！电源送去的能量全部被"弹回"了
- 一般：0<cosφ<1

**工程上**为什么关心功率因数？工厂设备大多是感性负载（电机、变压器），功率因数偏低。电力公司要按"**视在功率**"（下面讲）供电，但用户只为"有功功率"付钱——功率因数低意味着电力公司要"白供"很多电流，浪费线路容量。所以工程上有"**功率因数补偿**"（在感性负载旁并联电容，把电路拉回接近纯阻性）。

---

### 三、无功功率 Q

Q=UIsinφ

**单位**：**var**（乏，volt-ampere-reactive，区别于 W）

**物理意义**：**在电源和储能元件（L、C）之间"来回摆动"的功率**。它不被消耗，只是在储能元件上"充放"——前半周期充进去，后半周期放回来。

**关键认识**：

- 电感 L：φ=+90°φ=+90°，Q=UI>0 → **吸收**无功
- 电容 C：φ=−90°φ=−90°，Q=−UI<0 → **释放**无功
- 电感和电容**互补**！一个吸收无功的时候另一个正好释放——这就是 LC 电路能"共振"的根源（第六章）

---

### 四、视在功率 S

S=UI

**单位**：**VA**（伏安）

**物理意义**：**电压有效值 × 电流有效值**。这是电源设备（变压器、发电机）需要承受的"容量"——不管负载消不消耗，电源都要扛住这么大的电压和电流。

**三个功率的关系**（功率三角形）：

```
              │
            Q │  S=√(P²+Q²)
              │╱
              ╱
             ╱│
           ╱ φ│
          ╱───┴──── P
```

S2=P2+Q2P=Scosφ,Q=Ssinφ

---

### 五、复功率 S~S~（⭐ 集大成的概念）

前面的 P、Q、S 都是三个分离的实数，能不能用**一个复数**把它们统一起来？

**能！** 这就是**复功率**：

S~=U˙⋅I˙∗S~=U˙⋅I˙∗

其中 I˙∗I˙∗ 是电流相量的**共轭复数**（实部不变，虚部取反）。

#### 为什么这样定义？

设 U˙=U∠φuU˙=U∠φu，I˙=I∠φiI˙=I∠φi，则 I˙∗=I∠(−φi)I˙∗=I∠(−φi)

S~=U∠φu⋅I∠(−φi)=UI∠(φu−φi)=UI∠φS~=U∠φu⋅I∠(−φi)=UI∠(φu−φi)=UI∠φ

展开：

S~=UIcosφ+jUIsinφ=P+jQS~=UIcosφ+jUIsinφ=P+jQ

**漂亮！** 复功率：

- **实部** = 有功 P
- **虚部** = 无功 Q
- **模** = 视在 S
- **辐角** = 阻抗角 φ（也是电压超前电流的角度）

#### 复功率的三个"脸"

S~=P+jQ=S∠φ=U˙I˙∗S~=P+jQ=S∠φ=U˙I˙∗

**每一种形式都能独立表达全部信息**。做题时挑最方便的用。

#### 为什么要用 I˙∗I˙∗ 而不是 I˙I˙？

（一个稍进阶的问题，你可能会好奇。）

如果直接用 U˙I˙U˙I˙，辐角就是 φu+φi——这个量没物理意义。用共轭 I˙∗I˙∗ 之后辐角变成 φu−φi，恰好等于阻抗角 φ，就把功率的"相位特征"抓出来了。

## 5.7 最大功率传输定理（⭐ 重点）

你的教学大纲里把这列为**重点**之一，我们重点讲。

### 一、问题场景

```
    ┌──────────┐
    │  U_oc    │ a
    │   +      │
    │ [Z_th]   │────[Z_L]────     负载阻抗 Z_L
    │   -      │
    │          │ b
    └──────────┘
      等效电源
```

给定一个等效电源（戴维南形式：U˙ocU˙oc 串联 Zth），问：

> **负载阻抗 ZL 取多少，能使负载上获得的有功功率 PL 最大？**

这是工程上非常常见的问题——比如音响放大器如何匹配喇叭、天线如何匹配收发电路、电池如何向外设供电等等，都涉及"最大功率传输"。

---

### 二、答案（三种情况）

设 Zth=Rth+jXth，ZL=RL+jXL。

#### 情况一：ZL 完全可调（实部虚部都能调）

**结论**：

ZL=Zth∗=Rth−jXthZL=Zth∗=Rth−jXth

**负载 = 戴维南阻抗的共轭复数**。这叫"**共轭匹配**"。

**为什么？**

电流大小 I=Uoc∣Zth+ZL∣I=∣Zth+ZL∣Uoc。负载有功功率 PL=I2RL。

想让 I 最大：Zth+ZL 越小越好。如果 ZL 的虚部可以任意调，选 XL=−Xth，两个虚部抵消！于是 Zth+ZL=Rth+RL（纯实数，最小）。

然后问题变成：PL=Uoc2RL(Rth+RL)2PL=(Rth+RL)2Uoc2RL，对 RL 求极值 → RL=Rth。

**最大功率值**：

PL,max=Uoc24RthPL,max=4RthUoc2

（这里 Uoc 是**有效值**）

#### 情况二：ZL 的虚部固定，只能调实部（比如纯电阻负载）

设 ZL=RL 纯电阻，则：

∣Zth+RL∣=(Rth+RL)2+Xth2

对 RL 求极值：

RL=∣Zth∣=Rth2+Xth2

**负载电阻 = 戴维南阻抗的模**。

（这时候 PL 不能达到 Uoc2/(4Rth)，比那个小。）

#### 情况三：∣ZL∣∣ZL∣ 固定，只能调辐角

（这种情况较少见，略）

---

### 三、物理理解

**为什么是"共轭匹配"？**

共轭匹配的本质：**让电源和负载的"虚部"互相抵消**。

- 电源虚部 +jXth 代表电源内部的储能元件
- 负载虚部 −jXth 代表负载的储能元件
- 两者**互为对偶**——电源释放无功时负载正好吸收，反之亦然
- **无功功率全部在电源和负载之间闭环循环，不占用"实功率通道"**
- 剩下的就是一个纯电阻 Rth 和 RL 的匹配，RL=Rth 时实功率最大（这一步你用直流电路的最大功率定理就熟悉了）

---

### 四、简单例题

戴维南等效：U˙oc=10∠0°U˙oc=10∠0° V，Zth=3+j4 Ω。

**求**：负载 ZL 取多少能获得最大功率？最大功率是多少？

---

**解**：

共轭匹配：ZL=Zth∗=3−j4ZL=Zth∗=3−j4 Ω

此时 Zth+ZL=6 Ω（纯电阻）

用公式验证：PL,max=Uoc2/(4Rth)=100/12≈8.33 W ✓
