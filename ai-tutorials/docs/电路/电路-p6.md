## 第六章 频率响应与谐振

第五章我们学了相量法，但所有分析都假定"**一个固定频率**"。现在我们要问一个新问题：

> **如果频率 ω 变化，电路的"响应"会怎么变？**

这就是**频率响应**（frequency response）——电路的"滤波特性"。收音机调台、音响的高低音调节、手机天线、5G 通信……所有这些都离不开频率响应。

## 6.1 网络函数和频率特性

### 一、先从一个问题开始

**思考**：我们以前讲电路时，总说"给定一个激励，求响应"。比如：

- **激励**：电压源 U˙sU˙s
- **响应**：某支路电流 I˙I˙，或某节点电压 U˙U˙

**问题**：如果我固定激励的幅值和初相（比如 U˙s=1∠0°U˙s=1∠0°），但改变它的**频率** ω，响应 I˙I˙ 或 U˙U˙ 会怎么变？

---

**答案**：响应的幅值和相位都会变，因为**阻抗 Z 是 ω 的函数**（ZL=jωL、ZC=1/(jωC)）！

这就是频率响应的起点。

---

### 二、网络函数 H(jω) 的定义

我们把"响应/激励"的比值定义为**网络函数**：

H(jω)=响应相量激励相量H(jω)=激励相量响应相量

**注意几个关键点**：

1. H(jω) 是 **ω 的复函数**——不同频率下它是不同的复数
2. 它**只取决于电路本身**（元件值和结构），与激励大小无关
3. "响应"和"激励"可以是同一端口也可以是不同端口

#### 四种常见的网络函数

|类型|激励类型|响应类型|记号|物理意义|
|---|---|---|---|---|
|**驱动点阻抗**|电流|同一端口的电压|Z(jω)|一个端口看进去的阻抗|
|**驱动点导纳**|电压|同一端口的电流|Y(jω)|阻抗的倒数|
|**电压传递函数**|电压|另一端口电压|Hu(jω)|电压放大/衰减比|
|**电流传递函数**|电流|另一端口电流|Hi(jω)|电流放大/衰减比|

（还有**转移阻抗、转移导纳**等，略。）

---

### 三、H(jω) 的两个面

作为复函数，H(jω) 可以分解成**模**和**辐角**：

H(jω)=∣H(jω)∣⋅ejφ(ω)

其中：

- **幅频特性** ∣H(jω)∣：幅值如何随频率变化
- **相频特性** φ(ω)：相位如何随频率变化

**画图表示**：把两者分别作为 ω 的函数画出来，就得到"**幅频特性曲线**"和"**相频特性曲线**"。这两条曲线**完全描述了电路的频率特性**。

---

### 四、一个极简例子：RC 低通滤波器

```
   ┌──[R]──┬────── u_2（输出）
   │       │
   u_1    [C]
   │       │
   └───────┴──────
```

**输入** U˙1U˙1（跨在整个电路上），**输出** U˙2U˙2（从电容两端取）。

**电压传递函数**（分压器原理）：

H(jω)=U˙2U˙1=ZCR+ZC=1/(jωC)R+1/(jωC)=11+jωRCH(jω)=U˙1U˙2=R+ZC=R+1/(jωC)=1+jωRC1

这是一个**标准形式**。令 ωc=1/(RC)（待会你会看到它的重要性），则：

H(jω)=11+j(ω/ωc)H(jω)=1+j(ω/ωc)1

---

#### 分析幅频特性

∣H(jω)∣=11+(ω/ωc)2∣H(jω)∣=1+(ω/ωc)21

**三个关键频率点**：

| 频率 | ω/ωc | ∣H∣∣H∣ | 物理含义 | |---|---|---|---| | ω=0（直流） | 0 | **1** | 输出 = 输入，无衰减 | | ω=ωc | 1 | 12≈0.70721≈0.707 | 衰减到 1/2，即 **−3 dB** | | ω→∞ω→∞ | ∞ | **0** | 完全衰减，输出为 0 |

**幅频曲线**（大致形状）：

```
  |H|
   1 ┤━━━━━╮
       │       ╲
   0.707        ╲─── ω_c 处（截止频率）
       │         ╲
       │                ╲━━━━━
     0 ┼──────────────────────→ ω
       0       ω_c
```

**这是个"低通滤波器"**：低频通过（∣H∣∣H∣ 接近 1），高频被压制（∣H∣∣H∣ 接近 0）。

#### 为什么叫"低通"？—— 物理直觉

从第四章我们知道：**电容对低频像开路，对高频像短路**。

- **低频时**：电容像开路，整个电压都压在电容上 → U2=U1
- **高频时**：电容像短路，电压被短路掉了 → U2→0U2→0

这就是低通滤波的物理本质。

---

#### 截止频率 ωc（—3dB 频率）

在 ω=ωc=1/(RC) 时 ∣H∣=1/2。这是一个**非常重要的频率点**，叫**截止频率**（cutoff frequency）或 **−3dB 频率**。

**为什么是 −3dB？**

在工程上人们喜欢用**分贝**表示增益：20log10∣H∣ dB

- ∣H∣=1/2 对应 20log(1/2)=−3.01 dB
- 功率上看，∣H∣2=1/2，功率**减半**

所以截止频率也叫"**半功率频率**"——在这个频率上，输出功率降到最大值的一半。

---

#### 分析相频特性

φ(ω)=−arctan(ω/ωc)

|频率|相位|
|---|---|
|ω=0|0°0°（同相）|
|ω=ωc|−45°−45°|
|ω→∞ω→∞|−90°−90°（输出滞后 90°）|

**相频曲线**：

```
  φ(ω)
    0 ┼━━━━━╮
      │     ╲
   -45°      ╲_ω_c
      │        ╲
   -90°              ╲━━━━
      ┼──────────────────────→ ω
```

**意义**：随着频率升高，输出电压相位**越来越滞后**。

---

### 五、类似地：高通滤波器

把 RC 的 R 和 C 位置互换，输出从 R 上取：

```
   ┌──[C]──┬────── u_2
   │       │
   u_1    [R]
   │       │
   └───────┴──────
```

**传递函数**：

H(jω)=R+1/(jωC)=jωRC1+jωRCH(jω)=R+1/(jωC)R=1+jωRC

**幅频特性**：低频 → 0，高频 → 1。这是**高通滤波器**。

物理直觉：**电容隔直流、通交流**。低频被电容挡住，只剩高频能过。

---

### 六、波特图（Bode Plot）简介

工程上通常用**波特图**绘制频率特性，特点：

- **横轴**：ω 取**对数刻度**（比如 1, 10, 100, 1000 等比分布）
- **纵轴（幅频）**：用 **分贝**（20log∣H∣）
- **纵轴（相频）**：用度或弧度，线性刻度

波特图的好处是：**复杂传递函数可以分解成"零点"和"极点"的直线近似叠加**，画起来非常方便。

这部分属于信号与系统课程，电路课程只需知道有这个概念。

## 6.2 RLC 串联电路的频率特性

我们从一个简单的 RLC 串联电路开始：

```
       ┌──[R]──[L]──[C]──┐
       │                  │
      (+)
      U_s
      (-)
       │                  │
       └──────────────────┘
```

### 一、总阻抗作为 ω 的函数

总阻抗：

Z(jω)=R+jωL+1jωC=R+j(ωL−1ωC)Z(jω)=R+jωL+jωC1=R+j(ωL−ωC1)

**实部**：R（不随频率变化）

**虚部**：X(ω)=ωL−1ωCX(ω)=ωL−ωC1

虚部这一部分超级重要，它揭示了 **感抗和容抗的竞争**：

- **低频时**：ωL 小，1/(ωC) 大 → X<0，**容性占优**
- **高频时**：ωL 大，1/(ωC) 小 → X>0，**感性占优**
- **中间某个频率**：ωL=1/(ωC) → X=0，**感抗容抗正好抵消！**

这个"中间频率"就是**谐振频率**（下一节的主角）。

---

### 二、谐振频率 ω0 的由来

令 X=0：

ω0L=1ω0C  ⟹  ω02=1LCω0L=ω0C1⟹ω02=LC1ω0=1LCω0=LC1

或频率形式：f0=12πLCf0=2πLC1

在 ω=ω0 时，Z=R——**阻抗变成纯电阻**，感抗和容抗互相抵消。

---

### 三、幅频和相频

**阻抗模**：

∣Z(jω)∣=R2+(ωL−1ωC)2∣Z(jω)∣=R2+(ωL−ωC1)2

在 ω0 处达到**最小值** ∣Z∣=R。

**阻抗角**：

φZ(ω)=arctanωL−1/(ωC)RφZ(ω)=arctanRωL−1/(ωC)

- ω<ω0：φZ<0（容性）
- ω=ω0：φZ=0（纯阻性）
- ω>ω0：φZ>0（感性）

```
  |Z|                      φ_Z
   ↑                         ↑
   │╲      ╱                 │          ━━━━
   │ ╲    ╱                  │        ╱
   │  ╲  ╱                 0 ┼───────╱────── ω
   │   ╲╱                    │      ╱
 R ┼────•────              -π/2 ━━━━
   └────────────→ ω                   ω_0
       ω_0
```

这个图展示了 RLC 串联电路的全部频率特性。**注意一个关键现象**：当激励源是电压源时，在 ω=ω0 处阻抗最小 → **电流最大**！这就是"谐振"。

---

## 6.3 串联谐振电路（⭐ 重点）

### 一、谐振现象

**谐振**（resonance）的物理意义：

> 在特定频率下，**电路中储能元件（L 和 C）之间的能量循环达到最佳状态**，电源只需补充电阻消耗的部分，**电源电流与电压完全同相**（即功率因数 = 1）。

换个说法：**电感和电容"串通一气"，把无功功率在内部全部消化，不再需要电源参与无功循环**。

---

### 二、串联谐振的三个关键特征

**特征 ①**：ω0=1/LC，此时 Z=R（纯阻性）

**特征 ②**：电源电流**最大**（因为阻抗最小）

I0=UsRI0=RUs

**特征 ③**：电感和电容两端电压**可能远大于电源电压**！（⭐ 反直觉）

---

### 三、特征 ③ 的深入分析（品质因数 Q）

谐振时，电流 I0=Us/R。此时电感和电容两端的电压：

**电感两端电压**：

UL=I0⋅ω0L=UsR⋅ω0L=ω0LR⋅UsUL=I0⋅ω0L=RUs⋅ω0L=Rω0L⋅Us

**电容两端电压**：

UC=I0⋅1ω0C=UsR⋅1ω0C=1ω0RC⋅UsUC=I0⋅ω0C1=RUs⋅ω0C1=ω0RC1⋅Us

可以验证在谐振时 ω0L=1/(ω0C)，所以 UL=UC（大小相等），且它们**相位相反**（一个超前电流 90°，一个滞后电流 90°），电路中互相抵消。

定义**品质因数**（Quality factor）：

Q=ω0LR=1ω0RC=1RLCQ=Rω0L=ω0RC1=R1CL

则：

UL=UC=Q⋅Us

**意义**：电感/电容两端电压 = **Q 倍电源电压**！

如果 Q=100（这在射频电路中很常见），**电感两端电压是电源电压的 100 倍**——这就是串联谐振"电压放大"的效应。

> ⚠️ **工程警告**：串联谐振时过高的元件电压可能烧毁元件。这是**串联谐振的"危险"**——射频电路设计时必须小心；但也是它**有用**的地方——收音机选台就靠这个把微弱信号放大。

---

### 四、Q 的另一种解释：带宽

Q 还决定了谐振的"**尖锐程度**"。

**定义通频带 BW**（bandwidth）：电流幅值降到最大值 1/2（即半功率点）时对应的频率范围。

通过数学推导可得：

BW=ω0QBW=Qω0

- **Q 大**：谐振曲线**窄而尖**（选择性好，但适用频带窄）
- **Q 小**：谐振曲线**宽而平**（适用频带宽，但选择性差）

```
  I
   ↑
   │    ╱╲            ← Q 大（尖锐）
 I0┤   ╱  ╲
   │  ╱    ╲
I0/√2├───────
   │ ╱      ╲
   │╱  BW窄  ╲
   ╱          ╲_____
   │
   └─────────────→ ω
        ω_0

  I
   ↑
   │                  ← Q 小（宽平）
 I0┤   ╱━━━━━╲
   │  ╱        ╲
I0/√2├────────────
   │╱     BW宽    ╲
   │                ╲
   └─────────────→ ω
        ω_0
```

**工程意义**：

- 收音机调台：Q 要大（选择性好，只放大目标频率）
- 音响功放：Q 要小（覆盖整个音频范围）

---

### 五、串联谐振工程应用举例

**收音机选台**：

天线接收到无数个频率的信号（所有广播电台的信号叠加）。想听某一家电台（比如 FM 97.5 MHz）——怎么办？

**方案**：调节一个 LC 串联电路（可变电容），让它在 97.5 MHz 谐振。这时：

- 97.5 MHz 的信号：正好谐振，电流/电压被放大 Q 倍 → 被后续电路检出
- 其他频率的信号：远离谐振点，电流很小 → 被忽略

**这就是"选台"的原理**。调节电容 C 就是在调节谐振频率 ω0。

## 6.4 并联谐振电路

### 一、电路与"对偶"

```
         ┌─┬──[R]─┐
         │ │      │
     I_s ↑[L]    [C]
         │ │      │
         └─┴──────┘
```

RLC 并联，由电流源驱动。

**由对偶性**，所有结论都和串联谐振**形式一致**，只是把"阻抗"换成"导纳"、"电压"换成"电流"：

**总导纳**：

Y(jω)=G+jωC+1jωL=G+j(ωC−1ωL)Y(jω)=G+jωC+jωL1=G+j(ωC−ωL1)

**谐振条件**：导纳虚部 = 0

ω0C=1ω0L  ⟹  ω0=1LCω0C=ω0L1⟹ω0=LC1

（和串联一样！）

---

### 二、并联谐振的三个特征

**特征 ①**：谐振时 Y=G（纯电导），即 Z=R（纯电阻，阻抗达到**最大值**）

**特征 ②**：当激励是**电流源**时，端电压**最大**（因为阻抗最大）

U0=Is⋅R

**特征 ③**：电感和电容的**支路电流**可能远大于电源电流！

IL=IC=Q⋅Is

其中并联电路的品质因数：

Q=Rω0L=ω0RC=RCLQ=ω0LR=ω0RC=RLC

（注意：并联电路的 Q 公式和串联**相反**！R 在分子上，不是分母。）

---

### 三、串联 vs 并联谐振对比（⭐ 记忆要点）

|性质|串联谐振|并联谐振|
|---|---|---|
|典型激励|电压源|电流源|
|谐振频率|ω0=1/LC|相同|
|谐振时阻抗|**最小**（Z=R）|**最大**（Z=R）|
|谐振时响应|电流最大|电压最大|
|危险元件|L、C 两端**电压**过大|L、C 上**电流**过大|
|品质因数|Q=ω0L/R|Q=R/(ω0L)|
|放大关系|UL=UC=QUs|IL=IC=QIs|

**记忆口诀**："串联谐振电压放大，并联谐振电流放大"

---

### 四、为什么有"对偶性"？

观察两个电路：

- 串联：KVL 绕一圈，∑Uk=0
- 并联：KCL 节点处，∑Ik=0

KCL 和 KVL 结构完全相同，只是把"电流"和"电压"互换。再加上阻抗和导纳互为倒数——**整个理论结构都是对偶的**。

|对偶关系|
|---|
|电压 ↔ 电流|
|阻抗 ↔ 导纳|
|串联 ↔ 并联|
|KVL ↔ KCL|
|电感 L ↔ 电容 C|
|电阻 R ↔ 电导 G|
|戴维南 ↔ 诺顿|

学会"对偶"思想：**记住一个结论，自动就会对偶结论**，学习效率翻倍。

第七章是从"单频信号"走向"一般周期信号"的桥梁。
