## 9.1 动态电路的方程与初始条件

### 一、什么是动态电路？

**动态电路**：含有电容或电感（或两者都有）的电路。

**为什么叫"动态"？** 因为 L、C 的 VCR 涉及微分/积分，电路方程不再是代数方程，而是**微分方程**。

**暂态**（transient）：电路从一个稳态**切换**到另一个稳态的**过渡过程**。

典型场景：**开关动作、信号突变**。

---

### 二、"换路"与换路定则

**换路**（switching）：电路的**结构或参数突变**——开关闭合、断开，电源接入、撤去，元件值突变等。

设换路发生在 t=0：

- t=0−：换路**前**的最后一瞬（稳态）
- t=0+：换路**后**的第一瞬（暂态开始）
- t>0：暂态过程

**换路定则**（第四章的结论，现在正式命名）：

uC(0+)=uC(0−),iL(0+)=iL(0−)

**物理根源**：储能元件的能量不能突变。

- 电容储能 12CuC221CuC2 → uC 突变需要无穷大电流
- 电感储能 12LiL221LiL2 → iL 突变需要无穷大电压

**注意**：换路定则**只**适用于 uC 和 iL，对其他量（如电阻上的电压、电感上的电压、电容上的电流）**不成立**——这些量可以突变。

---

### 三、求初始值的三步法

暂态分析的第一步永远是：**求 uC(0+) 和 iL(0+)**。

#### 步骤

**Step 1：求 uC(0−) 和 iL(0−)（换路前稳态）**

换路前是**直流稳态**（假设），所以：

- 电容**等效开路**
- 电感**等效短路**

用直流电路方法求出电容两端电压、电感流过电流。

**Step 2：用换路定则得到 0+0+ 值**

uC(0+)=uC(0−),iL(0+)=iL(0−)

**Step 3：如果需要其他变量在 0+0+ 的值**

画出 t=0+ 时刻的等效电路：

- **电容** 等效为 **电压值为 uC(0+) 的电压源**（因为它电压定了）
- **电感** 等效为 **电流值为 iL(0+) 的电流源**（因为它电流定了）
- 电阻保持不变，电源按换路后的情况

然后用普通直流电路方法求任何其他量。

---

开关断开，左边回路断开。但电容 C 和 R2 仍构成一个回路：**但 R2 一端在开关处悬空了**。

所以换路前**整个电路没有电流**，电容上**没有充电**：

uC(0−)=0 V

**Step 2：换路定则**

uC(0+)=uC(0−)=0 V

**Step 3：求 iR2(0+)**

t=0+ 时，电容电压 = 0 → 电容此时**等效为短路**（0V 电压源就是导线）。

此时等效电路：

```
          ┌──[R1=2Ω]──┬── 短路 ──
          │           │     ↑(电容换成导线)

          │           │

```

R1 串联后与 R2 并联（R2 和短路线并联）。等等——电容换成短路后，R2 被短路了！

所以电流全部走短路线：iR2(0+)=0 A，iR1(0+)=12/2=6 A（全部流入电容）

**这道题说明几件事**：

1. 换路瞬间，uC 连续（= 0），但电流可以突变（R1 上电流从 0 变成 6A）
2. 电容刚"接入"时像短路——这是重要直觉

## 9.2 一阶电路

### 一、什么是一阶电路？

**一阶电路** = 只含**一个**独立储能元件（一个 C 或一个 L）的电路（电阻随意多个）。

"一阶"因为描述它的微分方程是**一阶**的。

---

### 二、一阶电路的微分方程长什么样？

看最简单的 RC 电路：

```
      t=0
   ┌─○/○──[R]──┬──
   │           │
  (+)        [C]  uC
   U0          │
  (-)          │
   │           │
   └───────────┘
```

换路后 KVL（绕行方向顺时针）：

U0=Ri+uC

用电容 VCR i=CduCdti=CdtduC：

U0=RCduCdt+uCU0=RCdtduC+uC

整理：

RCduCdt+uC=U0RCdtduC+uC=U0

这就是一阶线性常微分方程。你说你会解——我们**不解它**，因为电路课里有更巧的方法。

---

### 三、三要素法（⭐ 本节核心）

**一阶电路所有响应都具有同一种形式**：

f(t)=f(∞)+[f(0+)−f(∞)] e−t/τ

**三个要素**：

1. **初始值** f(0+)：换路后第一瞬间的值
2. **终值** f(∞)：换路后新稳态的值（t→∞t→∞）
3. **时间常数** τ：反映电路"响应快慢"的参数

只要这三个值求出来，**任何变量（电压、电流）的暂态过程都直接写出来了**，不用解微分方程！

这就是"三要素法"——电路分析里极其实用的技巧。

---

#### 为什么是这个形式？（直觉理解）

观察指数 e−t/τ：

- t=0：e0=1，此时 f=f(0+) ✓
- t→∞t→∞：e−∞=0，此时 f=f(∞) ✓
- 中间：从 f(0+) 指数衰减（或上升）到 f(∞)

**物理图像**：电路从一个稳态"倾斜"到另一个稳态，速度由 τ 控制。

---

#### 时间常数 τ 是什么？

**对 RC 电路**：τ=ReqC **对 RL 电路**：τ=L/Req

其中 Req 是**从储能元件两端往外看的戴维南等效电阻**（把所有独立源置零！）

**单位检查**：

- RC 乘积：Ω · F = Ω · (C/V) = Ω · (A·s/V) = s ✓
- L/R：H/Ω = (V·s/A)/Ω = s ✓

**物理意义**：τ 小 → 电路响应快；τ 大 → 响应慢。

**经验数字**：t=3τ 后，响应已完成 95%；t=5τ 后，完成 99.3%——工程上通常认为**过了 5τ 就到稳态**了。

---

### 四、三要素法实战

回到刚才那道 RC 电路，U0=10 V，R = 1 kΩ，C = 1 μF，t=0 时开关闭合，电容初始电压 0。

**要素 ①：uC(0+)**

换路前电容开路、没有充电：uC(0−)=0 → uC(0+)=0 V

**要素 ②：uC(∞)**

换路后**新稳态**时电容开路，i=0 → 整个 R 上无压降 → 电容电压 = 电源电压：

uC(∞)=10 V

**要素 ③：τ=RC=103×10−6=10−3 s = 1 ms

**代入公式**：

uC(t)=10+[0−10] e−t/0.001=10(1−e−1000t) V

这就是经典的"**电容充电曲线**"。

```
   u_C
   ↑
 10┤         ___________
   │      ╱¯
   │    ╱
  0┼────────────→ t
   0     τ    2τ
```

**关键点**：

- t=τ（1ms）：uC=10(1−e−1)≈6.32 V（完成约 63.2%）
- t=3τ：uC≈9.5 V
- t=5τ：uC≈9.93 V（接近 10V）

---

### 五、两种典型响应（理论分类）

教材通常把一阶响应分成几类，**理解分类有助于理解物理图像**：

#### 零输入响应

**场景**：换路前电容/电感已经充能，换路后**没有外加电源**，储能元件"自己放电"。

uC(∞)=0（最终全部放掉）

uC(t)=uC(0+) e−t/τ

#### 零状态响应

**场景**：换路前储能元件"没存东西"，换路后**有外加电源激励**。

uC(0+)=0

uC(t)=uC(∞)(1−e−t/τ)

#### 全响应

**场景**：储能元件初始有储能，换路后又有外加激励。

uC(t)=uC(∞)+[uC(0+)−uC(∞)]e−t/τ

即 **"三要素法"的完整公式**。

**重要性质（叠加）**：

全响应=零输入响应+零状态响应全响应=零输入响应+零状态响应

（因为电路是线性的，分解成"初始条件单独作用"+"输入单独作用"是叠加原理的直接结果。）

---

### 六、用三要素法做 RL 电路

```
              t=0
        ┌─○/○──[R=5Ω]──┬──────
        │              │
       (+)           [L=0.5H]
       20V              │
       (-)              │
        │               │
        └───────────────┘
```

换路前开路很久，求 iL(t)（t>0）。

---

**要素 ①：iL(0+)**

换路前无电流：iL(0−)=0 → iL(0+)=0 A

**要素 ②：iL(∞)**

换路后新稳态：电感短路 → 电流 = U/R=20/5=4 A

iL(∞)=4 A

**要素 ③：τ=L/R=0.5/5=0.1 s

**写出解**：

iL(t)=4+(0−4)e−t/0.1=4(1−e−10t) A

---

### 七、三要素法的扩展——求任意变量

上面只求了 uC 和 iL。如果要求电路中**其他量**（电阻电流、电感电压等），怎么办？

**方法**：任何一阶电路的任何变量都满足同样的指数形式，所以**三要素法对任意变量都适用**：

f(t)=f(∞)+[f(0+)−f(∞)] e−t/τ

只需分别求这个具体量的 f(0+)、f(∞)、τ 即可（τ 对整个电路是统一的）。

**一个常用小技巧**：如果此前已经有了 uC(t)，那其他量直接通过 KCL/KVL 代数关系算就行，不用重新用三要素法。

---

### 八、本节核心——记住这些

1. **一阶电路只需求三个要素**：初始值、终值、时间常数
2. **τ = RC 或 L/R**，R 是从储能元件看进去的**戴维南电阻**（所有独立源置零）
3. **三要素法对任何变量都适用**
4. **任何一阶响应 = 零输入响应 + 零状态响应**

## 9.3 阶跃响应与冲激响应

这一节是你列出的难点之一。我会讲得细一点，但不会拖沓。

---

### 一、为什么要学"阶跃响应"和"冲激响应"？

先抛一个问题给你思考：

**问**：前面我们用三要素法解决了很多具体的暂态问题——换路、开关闭合、电源接入……但每来一个新电路、新激励，我们都要**重新列方程、重新求解**。有没有一种"**一劳永逸**"的方法——**只要知道电路对某种"标准输入"的响应，任何复杂输入的响应都能直接推出来**？

答案：**有**。标准输入有两种经典选择：

1. **阶跃函数 ε(t)**（单位"开关信号"）
2. **冲激函数 δ(t)**（单位"瞬时脉冲"）

对应的电路响应就叫**阶跃响应**和**冲激响应**。

这一节就是围绕它们展开的。

---

### 二、阶跃函数 ε(t)

#### 定义

**单位阶跃函数**（unit step function）：

ε(t)={0,t<01,t>0ε(t)={0,1,t<0t>0

（t=0 处定义不严格，有时写 ε(0)=1/2，但工程上一般不在意。）

```
   ε(t)
    ↑
  1 ┤       ━━━━━━━━━━━━━━━
    │
  0 ┼──────┤─────────→ t
           0
```

#### 物理意义

**ε(t) 就是一个 t=0 瞬间"拉开"的开关的信号**：

- t<0：值为 0（开关断开）
- t>0：值恒为 1（开关闭合，信号恒定输入）

**用它表达激励**：

- 在 t = 0 接入 10V 电源：激励 us(t)=10ε(t)
- 在 t = τ₀ 接入 A 电源：激励 us(t)=Aε(t−τ0)（延迟阶跃）

---

#### 阶跃响应

**定义**：电路在**零状态**下（储能元件初始无储能），对**单位阶跃** ε(t) 的响应，记作 s(t)。

"零状态"很重要——它保证响应**纯粹来自外加激励**，不受初始储能干扰。

**例**：RC 电路，输入 us(t)=ε(t) V，电容零初始电压。

用三要素法：

- uC(0+)=0
- uC(∞)=1（阶跃稳态值）
- τ=RC

s(t)=uC(t)=(1−e−t/RC)ε(t)

（乘一个 ε(t) 表示"从 t=0 开始"，t<0 时响应为 0。）

---

### 三、冲激函数 δ(t)

**这是本节最"不符合直觉"但也是最核心的概念**。

#### 不严格的直观描述

想象一个"**无限高、无限窄、面积为 1**"的信号：

```
  δ(t)
    ↑
    │
    │       ╷
    │       ║ ← 高度"无穷"
    │       ║
  0 ┼───────╨──────────→ t
            0
             ←→ 宽度"0"
```

**数学化定义**（你说你知道 δ(t)，我就直接写定义）：

δ(t)=0,t≠0δ(t)=0,t=0∫−∞∞δ(t) dt=1∫−∞∞δ(t)dt=1

**关键性质**（筛选性质）：

∫−∞∞f(t)δ(t−t0) dt=f(t0)

这个性质等一下会变得非常重要——它是卷积的基石。

---

#### δ(t) 和 ε(t) 的关系（关键！）

**ε(t) 对 t 求导 → 得到 δ(t)**：

dε(t)dt=δ(t)dtdε(t)=δ(t)

**物理理解**：ε(t) 在 t=0 处"瞬间跳变" → 它的导数在 t=0 处"瞬间爆发"，其他地方为 0。这就是 δ(t)。

**反过来**：

ε(t)=∫−∞tδ(τ) dτ

**这两条公式是阶跃和冲激之间的桥梁，一定要记住。**

---

### 四、冲激响应 h(t)

**定义**：电路在**零状态**下对**单位冲激** δ(t) 的响应，记作 h(t)。

#### 怎么求 h(t)？

**方法 1：直接算**（难，一般不用）

**方法 2：利用阶跃和冲激的关系**（⭐ 推荐）

**关键事实**：线性电路是**线性时不变系统（LTI）**，满足"**激励求导 → 响应求导**"。

既然 δ(t)=dε(t)dtδ(t)=dtdε(t)，那么：

h(t)=ds(t)dth(t)=dtds(t)

**"冲激响应 = 阶跃响应的导数"**。这是工程上求 h(t) 的最常用方法。

---

#### 举例：RC 电路的冲激响应

前面我们得到阶跃响应：

s(t)=(1−e−t/RC)ε(t)

求导（这里要用**乘积求导法则**，因为既有 ε(t) 又有 1−e−t/RC）：

dsdt=1RCe−t/RCε(t)+(1−e−t/RC)δ(t)dtds=RC1e−t/RCε(t)+(1−e−t/RC)δ(t)

**第二项在 t=0 时** 1−e0=0，所以这一项为 0。于是：

h(t)=1RCe−t/RCε(t)h(t)=RC1e−t/RCε(t)

**物理图像**：

```
  h(t)
    ↑
 1/RC┤╲
     │ ╲
   0 ┼────────────╲━━━━━━→ t
     0
```

**解读**：t=0 时输入一个"瞬间脉冲"→ 电容瞬间被"冲"上一点电荷 → 然后慢慢放电衰减（时间常数 RC）。

---

#### 冲激响应的物理本质（重要直觉）

冲激响应 h(t) 描述的是：

> **电路对"一个瞬间刺激"的自然反应。**

这个"自然反应"只依赖于电路本身的结构（R、L、C 值），完全和输入的具体形状无关——**h(t) 是电路的"身份证"**。

这就是为什么只要知道 h(t)，就能算出电路对任意输入的响应——**任何输入都可以分解成一连串"刺激"的叠加**。

**这就是卷积的思想**。

---

### 五、卷积（⭐ 本章难点）

你之前说卷积是"对一个输入从作用时间开始作用到结束的集合的积分"——这个描述基本对，但我们要把它精确化。

#### 核心想法

任意输入信号 f(t)，可以看作是**一系列"带权重"的冲激的叠加**：

f(t)=∫−∞∞f(τ)δ(t−τ) dτ

**这个式子怎么理解？** 它说：把 f(t) 想象成由许多个**位置在 τ、高度为 f(τ) 的小冲激**叠加而成。（这个公式就是 δ 的筛选性质反过来写。）

#### 关键一步（线性时不变系统）

- **单个冲激** δ(t) → 响应 h(t)
- **单个延迟冲激** δ(t−τ) → 响应 h(t−τ)（因为时不变）
- **带权重的冲激** f(τ)δ(t−τ) → 响应 f(τ)h(t−τ)（因为线性）
- **叠加所有这样的冲激** → 叠加所有的响应

所以输入 f(t) 的响应为：

y(t)=∫−∞∞f(τ)h(t−τ) dτ

**这就是卷积**，记作：

y(t)=f(t)∗h(t)=∫−∞∞f(τ)h(t−τ) dτy(t)=f(t)∗h(t)=∫−∞∞f(τ)h(t−τ)dτ

#### 对因果信号（从 t=0 开始）的简化

如果：

- 输入 f(t) 只在 t≥0 存在（f(t)=0 for t<0）
- 系统是**因果的**（h(t)=0 for t<0）

那么积分上下限可以简化：

y(t)=∫0tf(τ)h(t−τ) dτ,t≥0

**这就是你之前描述的"从作用开始到现在"的积分**——你的直觉是对的。

---

#### 卷积的几何直觉

```
  f(τ)              h(-τ) —→平移 t —→ h(t-τ)
    ↑                 ↑                ↑
    │  ╱╲              │ ╲             │    ╲
    └────────→τ        └─────→τ        └────────→τ
                                        t

  把 f(τ) 和 h(t-τ) 逐点相乘再积分 → 得到 y(t) 在 t 时刻的值
```

**操作步骤**（"翻转-平移-相乘-积分"）：

1. **翻转**：把 h(τ) 变成 h(−τ)（沿 τ 轴翻转）
2. **平移**：把 h(−τ) 平移 t，得到 h(t−τ)
3. **相乘**：计算 f(τ)h(t−τ)
4. **积分**：对 τ 积分，得到 y(t)

每个 t 值都这样做，就得到完整的 y(t)。

---

#### 卷积的核心地位

> **在线性时不变系统里，只要知道冲激响应 h(t)，就能通过卷积求任意输入的响应。**

这个定理让 h(t) 成为**系统的"基因"**——一旦 h(t) 确定，整个系统的行为就全部确定了。

---

### 六、一个完整的卷积例子

**场景**：RC 电路（R=1Ω，C=1F，所以 τ=1），冲激响应 h(t)=e−tε(t)。

输入：f(t)=ε(t)（单位阶跃）

**求响应 y(t)**。

---

**用卷积公式**：

y(t)=∫0tf(τ)h(t−τ) dτ=∫0t1⋅e−(t−τ) dτ

（因为 f(τ)=1 for τ≥0）

=e−t∫0teτ dτ=e−t[et−1]=1−e−t=e−t∫0teτdτ=e−t[et−1]=1−e−ty(t)=(1−e−t)ε(t)

**检验**：这正是我们之前用三要素法得到的 RC 阶跃响应 s(t)！✓

这就验证了一个重要关系：

s(t)=∫0th(τ) dτ

"**阶跃响应 = 冲激响应的积分**"——和前面 "冲激 = 阶跃的导数" 完全对应。

|---|---|---|---|

## 9.4 二阶电路的暂态分析

一阶电路只有一个储能元件（C 或 L）。如果电路里**同时**有 L 和 C，情况就完全不一样了。

---

### 一、为什么"二阶"这么特别？

先想一个问题。还记得第六章的 LC 谐振吗？谐振时电感和电容之间会**互相"传递"能量**——电感放能量给电容，电容再还回去，周而复始。

**问**：如果这样一个 LC 电路，再串联一个小电阻，会发生什么？电阻会消耗能量，所以"来回传递"的过程会慢慢衰减——这就是**振荡衰减**。

但如果电阻**很大**呢？能量还没来得及在 L、C 之间传几次，就被电阻全部耗光了——这时候就**不振荡**，只是单调衰减。

**这两种定性完全不同的行为**，正是二阶电路的魅力所在，也是本节的核心。

---

### 二、典型二阶电路：RLC 串联

```
      t=0
   ┌─○/○──[R]──[L]──[C]──┐
   │                      │
  (+)
  U_s
  (-)
   │                      │
   └──────────────────────┘
```

换路后 KVL：

Us=Ri+Ldidt+uCUs=Ri+Ldtdi+uC

用 i=CduCdti=CdtduC，代入并整理（以 uC 为未知量）：

LCd2uCdt2+RCduCdt+uC=UsLCdt2d2uC+RCdtduC+uC=Us

**这是二阶线性常系数微分方程**。两个储能元件 → 方程阶数是 2。

---

### 三、标准形式与关键参数

把方程改写成"标准形式"：

d2uCdt2+RLduCdt+1LCuC=UsLCdt2d2uC+LRdtduC+LC1uC=LCUs

定义两个关键参数：

**衰减系数 α**（或写作 σ）：

α=R2Lα=2LR

**谐振角频率 ω0**（和第六章同名！）：

ω0=1LCω0=LC1

方程变成：

d2uCdt2+2αduCdt+ω02uC=ω02Usdt2d2uC+2αdtduC+ω02uC=ω02Us

---

### 四、特征方程和三种情形

你说你会解常微分方程，所以直接上。齐次方程的特征方程：

s2+2αs+ω02=0

两个根：

s1,2=−α±α2−ω02s1,2=−α±α2−ω02

**根的性质取决于根号里的正负**——这正是决定二阶电路行为的关键：

#### 情形 ①：过阻尼（α>ω0，即 R>2L/C）

α2−ω02 是**实数** → 两个不同的**负实根** s1,s2

通解：

uC(t)=A1es1t+A2es2t+uC(∞)

**行为**：**单调衰减**（两个指数衰减的叠加），**无振荡**。

```
   u_C
    ↑
    │╲
    │          ╲_______ ← u_C(∞)
    │
    └─────────────────→ t
```

**物理解读**：R 太大了，能量在 L、C 之间还没来得及传就被电阻吃掉——没有振荡的机会。

#### 情形 ②：临界阻尼（α=ω0，即 R=2L/C）

α2−ω02=0 → 两个相同的实根 s1=s2=−α

通解（重根情形）：

uC(t)=(A1+A2t)e−αt+uC(∞)

**行为**：**最快**的非振荡衰减——刚好不振荡。

**物理解读**：这是**"不振荡"和"振荡"的分界线**。工程上常把临界阻尼作为设计目标（比如汽车减震——既要快速归位，又不能来回颠簸）。

#### 情形 ③：欠阻尼（α<ω0，即 R<2L/C）⭐

α2−ω02<0 → 根号里是负数 → 两个**共轭复根**：

s1,2=−α±jωd,ωd=ω02−α2s1,2=−α±jωd,ωd=ω02−α2

其中 ωd 叫**衰减振荡角频率**（damped oscillation frequency）。

通解：

uC(t)=e−αt[B1cosωdt+B2sinωdt]+uC(∞)

或统一成：

uC(t)=Be−αtcos(ωdt+φ)+uC(∞)

**行为**：**衰减振荡**！幅值按 e−αt 衰减，同时以 ωd 频率振荡。

```
   u_C
    ↑
    │╲    ╱╲
    │ ╲  ╱  ╲  ╱¯╲
    │  ╲╱    ╲╱   ╲__╱¯╲_____← u_C(∞)
    │
    └─────────────────────→ t
       包络 e^(-αt) 衰减
```

**物理解读**：R 小，电阻"吃"能量的速度慢于 L、C 互相传能的速度 → 能量在 L、C 之间振荡着"消耗"—— 典型的"衰减振荡"。

---

### 五、阻尼比 ζ（更紧凑的刻画）

工程上更常用一个无量纲参数：

ζ=αω0=R2CLζ=ω0α=2RLC

（读作"zeta"）

三种情况用 ζ 表达：

|情形|条件|特征根|行为|
|---|---|---|---|
|过阻尼|ζ > 1|两个负实根|单调衰减|
|临界阻尼|ζ = 1|重实根|临界衰减（最快非振荡）|
|欠阻尼|0 < ζ < 1|共轭复根|衰减振荡|
|无阻尼|ζ = 0（R = 0）|纯虚根|等幅振荡（LC 谐振）|

**阻尼比 ζ 在控制理论、信号处理、机械振动里都是核心概念**——你以后会反复见。

---

### 六、一个完整例题

**电路**：R = 2 Ω，L = 1 H，C = 0.25 F 串联，电压源 Us=10 V。

开关 t=0 闭合，电容初始电压 0，电感初始电流 0。

**求**：uC(t)

---

**Step 1：判断阻尼类型**

ω0=1/LC=1/0.25=2 rad/s

α=R/(2L)=2/2=1

α<ω0 → **欠阻尼**！

ωd=ω02−α2=4−1=3 rad/s

**Step 2：求稳态（终值）**

t→∞t→∞ 时 L 短路、C 开路 → 电流 = 0 → R、L 无压降 → uC(∞)=10 V

**Step 3：写通解**

uC(t)=e−t[B1cos3t+B2sin3t]+10

**Step 4：用初始条件定系数**

**条件 1**：uC(0+)=0

0=B1+10  ⟹  B1=−100=B1+10⟹B1=−10

**条件 2**：需要另一个方程。用 duCdt(0+)dtduC(0+)——回忆电容 VCR：i=CduCdti=CdtduC

所以 duCdt(0+)=i(0+)C=iL(0+)C=00.25=0dtduC(0+)=CiL(0+)=0.250=0

对通解求导：

duCdt=−e−t[B1cos+B2sin]+e−t[−B13sin+B23cos]dtduC=−e−t[B1cos+B2sin]+e−t[−B13sin+B23cos]

在 t=0⁺：

0=−B1+B23=10+3B2  ⟹  B2=−1030=−B1+B23=10+3B2⟹B2=−310

**Step 5：最终答案**

uC(t)=e−t[−10cos3t−103sin3t]+10uC(t)=e−t[−10cos3t−310sin3t]+10

合并：

uC(t)=10−203e−tcos(3t−30°) VuC(t)=10−320e−tcos(3t−30°) V

**定性解读**：

- 终态 10V
- 围绕 10V 做衰减振荡
- 时间常数 1 s，振荡角频率 √3 ≈ 1.73 rad/s

### 七、用二阶电路的思维回看控制系统

二阶系统的响应（过/临界/欠阻尼）在控制工程、机械工程里**无处不在**：

- **汽车减震器**：调到临界阻尼附近（快速归位不颠簸）
- **门挡阻尼器**：过阻尼（慢慢关，不"砰"一声）
- **音箱低音单元**：略欠阻尼（更好的瞬态响应）
- **建筑抗震**：调整阻尼比让建筑不共振

**RLC 电路就是所有这些物理系统的"数学孪生"**——电路学到这里，你其实已经掌握了通用二阶系统的分析工具。

||相量法（第5章）|拉普拉斯变换（第10章）|
|---|---|---|

**一个重要预览**：在拉普拉斯域里：

- 微分 → 乘 s（就像相量里乘 jω）

- 初始条件自然被包含进来
- 甚至卷积都变成了**简单的乘法**！

**卷积 ↔ 乘法**。这是拉普拉斯变换最震撼的性质之一。
