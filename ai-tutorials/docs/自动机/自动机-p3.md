# 自动机学 · 第五节：下推自动机（PDA）与上下文无关语言

## 一、先解答上节的练习题

上一节的练习是用泵引理证明 `L = { ww | w ∈ {a,b}* }` 不是正则语言。

选取字符串 `s = aᵖbᵖaᵖbᵖ`，它的长度是 `4p ≥ p`，满足泵引理的前提。根据泵引理，s 可以被分成 `xyz`，且 `|xy| ≤ p`，`|y| ≥ 1`。由于 `|xy| ≤ p`，xy 这一段完全落在 s 的前 p 个字符（全是 a）里，所以 y 必然形如 `aᵐ`，其中 `m ≥ 1`。

现在考虑 `xy²z`，它包含 `p + m` 个 a，然后是 p 个 b，然后是 p 个 a，然后是 p 个 b。如果这个字符串属于 L，那么它应该可以写成某个 `ww` 的形式，即前一半和后一半完全相同。但前一半有 `(p+m) + p = 2p+m` 个字符，后一半有 `p + p = 2p` 个字符，两半长度不相等（因为 `m ≥ 1`），根本不可能形成 `ww` 的结构。矛盾，所以 L 不是正则语言。

---

## 二、从有限自动机的局限说起

上一节我们看到，有限自动机无法识别 `{ aⁿbⁿ }`，根本原因是它没有足够的记忆来追踪任意大的计数。那么，如果我们给自动机加上一块"记忆"，会发生什么？

关键问题是：加什么样的记忆？最自然的想法是加一个可以无限增长的存储空间。但存储空间的访问方式有很多种——你可以随机访问任意位置，也可以只访问一端，也可以只按顺序读取。不同的访问方式，给机器带来的计算能力是截然不同的。

计算理论选择了一种最简单、最优雅的方式：**栈（Stack）**。栈是一种先进后出（LIFO）的存储结构，你只能看到栈顶的元素，可以把新元素压入栈顶（push），也可以把栈顶元素弹出（pop）。这个限制看起来很严苛，但正如我们将看到的，它恰好足够处理一大类非常重要的语言。

把有限自动机加上一个栈，就得到了**下推自动机（Pushdown Automaton，PDA）**。"下推"这个名字，正是来自于栈的"压入"操作。

---

## 三、为什么栈能处理 aⁿbⁿ？

在正式定义 PDA 之前，先用直觉感受一下栈的威力。考虑识别 `{ aⁿbⁿ }` 的策略：读到一个 a，就往栈里压一个 a；读到第一个 b，就切换策略，开始从栈里弹出 a；每读一个 b，就弹一个 a；读完整个字符串后，如果栈恰好也空了，就接受。

这个策略完美地利用了栈：a 的计数被"存储"在栈的高度里，b 的读取过程把这个计数逐一消耗。栈的无限增长能力让我们可以处理任意大的 n，而有限自动机恰恰缺少的就是这种能力。

这个直觉非常重要，因为它揭示了一个普遍的规律：**凡是需要"配对"或"嵌套"的结构，往往都可以用栈来处理**。括号匹配是如此，HTML 标签的开闭匹配是如此，算术表达式的嵌套求值也是如此。这正是为什么编译器的语法分析阶段（Parser）在理论上对应的就是 PDA。

---

## 四、PDA 的正式定义

一个 PDA 是一个六元组 `M = (Q, Σ, Γ, δ, q₀, F)`。与 DFA 的五元组相比，多了一个 **Γ**，它是**栈字母表**（Stack Alphabet），即可以被压入栈中的符号集合。栈字母表和输入字母表可以不同，通常会多一个特殊符号 `$`（或 `Z₀`）用来标记栈底。

转移函数的形式是 `δ: Q × (Σ ∪ {ε}) × (Γ ∪ {ε}) → P(Q × (Γ ∪ {ε})*)`。这个定义看起来很复杂，我们拆开来读：它的输入是当前状态、当前读入的字符（可以是 ε，即不消耗输入）、以及当前栈顶的符号（可以是 ε，即不检查栈顶）；它的输出是一个集合，集合中每个元素是一对 `(新状态, 压入栈的字符串)`。

注意这里 PDA 天生就是**非确定性**的，因为 δ 返回的是一个集合（可能有多个选择）。与 NFA 不同，非确定性 PDA 比确定性 PDA **更强大**——这是 PDA 与有限自动机的一个重要区别，我们稍后会回到这一点。

每一步转移的含义是：机器处于某个状态，读入一个输入字符（或不读），弹出栈顶符号（或不弹），然后跳转到新状态，并把某个字符串压入栈（或不压）。这四个动作同时发生，构成一次"计算步骤"。

---

## 五、用 PDA 识别 aⁿbⁿ：一个完整的例子

让我们把直觉转化成正式的 PDA。我们设计一个识别 `L = { aⁿbⁿ | n ≥ 1 }` 的 PDA。

状态集合是 `Q = {q₀, q₁, q₂}`，其中 `q₀` 是初始状态，`q₁` 是读 b 的阶段，`q₂` 是接受状态。输入字母表 `Σ = {a, b}`，栈字母表 `Γ = {A, $}`，接受状态 `F = {q₂}`。

转移规则用自然语言描述如下。首先，在 `q₀` 状态，用一个 ε-转移压入栈底标记 `$`（目的是知道栈什么时候空了）。然后在 `q₀` 状态，每读一个 `a`，就往栈里压一个 `A`，同时保持在 `q₀`。当读到第一个 `b` 时，转移到 `q₁`，同时弹出一个 `A`。在 `q₁` 状态，每读一个 `b`，就弹出一个 `A`。最后，当栈顶是 `$`（栈底标记）而输入也已经读完时，用 ε-转移跳到接受状态 `q₂`，弹出 `$`。

用字符串 `"aaabbb"` 走一遍验证：初始状态压入 `$`，栈内容是 `[$]`。读 `a`，压 `A`，栈变成 `[A, $]`。读 `a`，压 `A`，栈变成 `[A, A, $]`。读 `a`，压 `A`，栈变成 `[A, A, A, $]`。读 `b`，弹 `A`，跳到 `q₁`，栈变成 `[A, A, $]`。读 `b`，弹 `A`，栈变成 `[A, $]`。读 `b`，弹 `A`，栈变成 `[$]`。输入读完，栈顶是 `$`，跳到 `q₂`，接受。

## 六、上下文无关文法：语言的生成视角

与有限自动机对应正则表达式类似，PDA 也有一个对应的"声明式"描述工具：**上下文无关文法（Context-Free Grammar，CFG）**。

CFG 不像自动机那样描述"如何识别"一个字符串，而是描述"如何生成"一个字符串。一个 CFG 由四个部分组成：一组**变元**（Variables，也叫非终结符），一组**终结符**（Terminals，即实际出现在字符串中的符号），一组**产生式规则**（Production Rules），以及一个**起始变元**（Start Variable）。

产生式规则的形式是 `A → α`，意思是"变元 A 可以被替换成字符串 α"，其中 α 是由变元和终结符混合组成的字符串。从起始变元出发，反复应用产生式规则进行替换，直到只剩下终结符，得到的就是文法生成的一个字符串。所有可以这样生成的字符串，构成这个文法的语言。

举个例子，以下 CFG 生成的语言正是 `{ aⁿbⁿ | n ≥ 0 }`：

```
S → aSb | ε
```

这个文法只有一条规则：起始变元 S 可以替换成 `aSb`（在两侧各加一个字符），或者直接替换成 `ε`（终止）。比如，生成 `"aaabbb"` 的过程是 `S → aSb → aaSbb → aaaSbbb → aaabbb`。这个递归结构，正是嵌套语言的本质：每一层规则在字符串的两侧各"贡献"一个字符。

---

## 七、CFG 与 PDA 的等价性

正如 DFA/NFA 与正则表达式是等价的，CFG 与 PDA 也是等价的，它们描述的恰好都是**上下文无关语言（Context-Free Language，CFL）**。这个等价性的证明同样是双向的，方向和思路与正则语言的情况类似，只是技术细节更复杂一些。

上下文无关语言这个名字来自于文法的性质：在 CFG 的产生式 `A → α` 中，左侧永远只是一个单独的变元 A，它的替换不依赖于 A 周围的"上下文"——无论 A 出现在什么位置，你都可以把它替换成 α。这与更复杂的"上下文相关文法"形成对比，后者允许规则的应用依赖于变元的上下文，描述能力更强，但也复杂得多。

---

## 八、歧义性：一个微妙的问题

CFG 有一个 DFA 没有的麻烦：**歧义性（Ambiguity）**。

如果一个字符串可以由同一个 CFG 以两种不同的方式生成（即有两棵不同的语法树），这个文法就是**歧义的**。歧义性在编程语言中是一个真实的工程问题。比如，表达式 `1 + 2 * 3` 在没有优先级规定的情况下，可以被解析成 `(1+2)*3` 或 `1+(2*3)`——这两种解析对应不同的语法树，也给出不同的计算结果。

消除歧义的方法是重写文法，明确规定运算符的优先级和结合性。这也是为什么几乎所有编程语言的语法规范都花大量篇幅定义运算符优先级——它们本质上是在消除文法的歧义性。

更令人头疼的是，有些语言是**本质歧义的（Inherently Ambiguous）**：无论你怎么改写文法，只要生成的语言不变，文法就一定是歧义的。这类语言的存在说明，歧义性不只是文法设计的问题，有时候它是语言本身的性质。

---

## 九、上下文无关语言的边界

正如正则语言有泵引理来刻画其边界，上下文无关语言也有自己的**上下文无关泵引理**。它比正则版本更复杂，但核心思路类似：足够长的上下文无关语言中的字符串，必然含有两段可以同步"泵"的子串。

利用这个引理，可以证明 `L = { aⁿbⁿcⁿ | n ≥ 0 }`（n 个 a，n 个 b，n 个 c）不是上下文无关语言。直觉上，栈只能做一种"配对"——它可以把 a 和 b 配对，或者把 b 和 c 配对，但无法同时保证三者数量相等。这需要同时追踪两个独立的计数关系，而一个栈不够用。

这条边界对编程语言有实际意义：大多数编程语言的语法结构是上下文无关的（括号匹配、语句嵌套），但某些语义约束（比如变量必须先声明后使用）超出了上下文无关语言的范围，这就是为什么编译器的语法分析和语义分析是两个独立的阶段。

## 十、思考练习

这节的练习有两部分。第一部分比较简单：请写出一个 CFG，生成所有合法的括号序列，比如 `"()"`、`"(())"`、`"()()"` 都合法，`")("`、`"(()"` 不合法。思考一下这个文法的递归结构对应着什么样的直觉。

第二部分是一个思考题：我们说非确定性 PDA 比确定性 PDA 更强，你能直觉上想象出一个例子吗？也就是说，有没有一类语言，非确定性 PDA 能识别，但确定性 PDA 做不到？提示：考虑回文串 `{ w w^R | w ∈ {a,b}* }`，其中 `w^R` 是 w 的反转。

下一节我们将到达整个课程的顶点：**图灵机（Turing Machine）**。我们将看到，一条无限长的纸带，是如何把计算能力提升到"可计算"的终极边界的——以及为什么即便是图灵机，也有它永远无法逾越的高墙。
