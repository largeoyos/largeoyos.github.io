# 第 3 章：2D 变换

我们先在二维里把思想讲透。三维无非是多一个维度，原理一模一样。

## 3.1 核心思想：变换 = 矩阵乘法

图形学里所有"让物体动起来"的操作——平移、旋转、缩放——都被统一成一件事：**左乘一个矩阵**。

为什么要统一？因为矩阵乘法满足结合律：你可以把"先旋转再缩放再平移"这一长串操作**预先乘成一个矩阵**，然后对成千上万个顶点只做一次乘法。这是 GPU 能飞快渲染的根本原因之一。

## 3.2 三种基本变换（2D）

**缩放（Scale）**：$x$ 方向拉伸 $s_x$ 倍，$y$ 方向拉伸 $s_y$ 倍。 $$S = \begin{pmatrix} s_x & 0 \ 0 & s_y \end{pmatrix}$$

**旋转（Rotation）**：绕原点逆时针旋转 $\theta$ 角。 $$R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \ \sin\theta & \cos\theta \end{pmatrix}$$

（怎么推的？把基向量 $(1,0)$ 转过去变成 $(\cos\theta, \sin\theta)$，$(0,1)$ 变成 $(-\sin\theta, \cos\theta)$，这两个就是矩阵的两列。记住这个套路——**矩阵的列就是基向量变换后的位置**。）

**平移（Translation）**：每个点加一个偏移向量 $(t_x, t_y)$。

问题来了：平移**不能**写成 2×2 矩阵乘法。因为任何 2×2 矩阵都把原点 $(0,0)$ 映到 $(0,0)$，但平移不应该。

## 3.3 齐次坐标：一个漂亮的 hack

为了让平移也变成矩阵乘法，我们**升一维**。把 2D 点 $(x, y)$ 写成 3 维的 $(x, y, 1)$，然后用 3×3 矩阵：

$$\begin{pmatrix} 1 & 0 & t_x \ 0 & 1 & t_y \ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} x \ y \ 1 \end{pmatrix} = \begin{pmatrix} x + t_x \ y + t_y \ 1 \end{pmatrix}$$

平移变成了矩阵乘法。

**点和向量的区分**，现在也通过这个多出来的分量自然体现：

- **点**：$(x, y, 1)$，最后一位是 1
- **向量**：$(x, y, 0)$，最后一位是 0

你验证一下：点 $-$ 点 $= (x_1-x_2, y_1-y_2, 0)$，是个向量 ✓。点 $+$ 向量 $= (x+v_x, y+v_y, 1)$，还是个点 ✓。向量乘平移矩阵，平移部分会被那个 0 "吃掉"——**向量不受平移影响**，这完全符合几何直觉（一个"方向"不需要被平移，它本来就没有起点）。

## 3.4 组合变换：顺序很重要

现在所有变换都是 3×3 矩阵，可以自由组合。

**关键：矩阵乘法不满足交换律**，所以变换顺序非常重要。

举个例子：

- "先平移 (5,0)，再旋转 90°" → 物体被转到离原点很远的地方
- "先旋转 90°，再平移 (5,0)" → 物体就在 $(5,0)$ 那里转了一下

在图形学里，我们统一约定：**列向量 + 左乘矩阵**。所以一个点经过"先 A 后 B"的复合变换，写出来是：

$$\mathbf{v}' = B \cdot A \cdot \mathbf{v}$$

注意顺序——**先发生的变换写在右边**，因为它先作用在向量上。

## 3.5 一个经典应用：绕任意点旋转

"绕原点旋转"我们有公式 $R(\theta)$。那"绕点 $P = (p_x, p_y)$ 旋转 $\theta$"怎么做？

思路分三步：

1. 把 $P$ 平移到原点（即对整个世界做 $T(-P)$）
2. 绕原点旋转 $R(\theta)$
3. 再平移回去 $T(P)$

合起来： $$M = T(P) \cdot R(\theta) \cdot T(-P)$$

这个"**共轭**"结构在图形学里到处都是——"先变到方便的坐标系 → 干活 → 变回来"。记住这个套路。

## 3.6 实现：写一点代码感受一下

我用 Python + numpy 给你一个最小例子，把一个正方形旋转一下并显示出来：

```python
import numpy as np
import matplotlib.pyplot as plt

# 正方形的 4 个顶点（齐次坐标，第三维是 1）
square = np.array([
    [0, 0, 1],
    [1, 0, 1],
    [1, 1, 1],
    [0, 1, 1],
]).T  # 转置成 3x4，每列一个点

# 绕点 (0.5, 0.5) 旋转 45°
theta = np.pi / 4
c, s = np.cos(theta), np.sin(theta)

T_neg = np.array([[1,0,-0.5],[0,1,-0.5],[0,0,1]])
R     = np.array([[c,-s,0],[s,c,0],[0,0,1]])
T_pos = np.array([[1,0, 0.5],[0,1, 0.5],[0,0,1]])

M = T_pos @ R @ T_neg   # 注意顺序！先 T_neg 作用在点上
square_new = M @ square

# 画图
def draw(pts, color):
    pts = np.hstack([pts, pts[:, :1]])  # 闭合
    plt.plot(pts[0], pts[1], color)

draw(square, 'b-')
draw(square_new, 'r-')
plt.axis('equal'); plt.grid(); plt.show()
```
