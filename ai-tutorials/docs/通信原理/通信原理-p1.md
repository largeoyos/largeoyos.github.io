## 通信原理入门

通信的本质，是**把信息从一个地方可靠地传送到另一个地方**。听起来简单，但背后涉及深刻的数学和工程智慧。让我们从最基础的概念开始，一步一步建立完整的图景。

---

### 一、通信系统的基本模型

香农（Claude Shannon）在1948年提出了通信系统的通用模型，至今仍是整个领域的基石：

```
信源 → 编码器 → 调制器 → 信道 → 解调器 → 解码器 → 信宿
                              ↑
                            噪声
```

每个模块都有其职责：

**信源**是产生信息的地方，比如你说话的声音、发送的文字。**编码器**把信息转换成适合传输的格式（比如压缩、加纠错码）。**调制器**把数字/模拟信号"搭载"到高频载波上，方便在物理信道中传播。**信道**是信息传播的媒介，比如空气、光纤、电缆。**噪声**是不可避免的干扰。最后，接收端做相反的操作，还原出原始信息。

---

### 二、信号与频谱——信息长什么样？

#### 时域与频域

一个信号可以从两个角度看：

- **时域**：信号随时间的变化，比如声波的波形
- **频域**：信号由哪些频率成分组成

这两种视角通过**傅里叶变换**相互转化。这就好比一首交响乐，你既可以听整体的旋律（时域），也可以分析里面有多少高音、多少低音（频域）。

一个关键结论是：**任何信号都有一定的带宽**（占据一定的频率范围）。带宽越大，能传输的信息就越多——这是整个通信工程的核心矛盾之一。

#### 模拟信号与数字信号

模拟信号是连续的，比如传统电话里的声音。数字信号是离散的，只有0和1。现代通信几乎全面数字化，因为数字信号**抗噪声能力强**——即使信号有些失真，只要还能分清0和1，信息就没有损失。

---

### 三、香农定理——通信的极限

香农给出了一个惊人的结论：一个信道能传输信息的**理论上限**是：

C=Blog2(1+SN)C=Blog2(1+NS)

其中 C 是信道容量（bit/s），B 是带宽（Hz），S/N 是信噪比。

但同时也告诉工程师，只要信噪比够高、带宽够宽，原则上可以实现无误差传输。这是整个编码理论的出发点。

### 四、调制——如何把信息"搭上"载波？

信息本身的频率往往很低（比如语音在300~3400 Hz），直接发射效率极低，天线也得很长。调制就是把低频信息"搬移"到高频载波上。

#### 模拟调制

以一个正弦载波 c(t)=Acos(2πfct+ϕ)c(t)=Acos(2πfct+ϕ) 为例，可以调制三个参数：

- **AM（调幅）**：改变振幅 A，信息藏在幅度变化里。收音机的中波就是AM。
- **FM（调频）**：改变频率 fc，信息藏在频率变化里。FM收音机比AM更清晰，因为噪声主要影响幅度而不是频率。
- **PM（调相）**：改变相位 ϕϕ。

#### 数字调制

现代通信用数字调制，常见的有：

**ASK（幅移键控）** 用不同幅度表示0和1，简单但抗噪差。**FSK（频移键控）** 用不同频率表示0和1，蓝牙早期版本用过。**PSK（相移键控）** 用不同相位表示0和1，抗噪性好，4G/5G大量使用。**QAM（正交幅度调制）** 同时调制幅度和相位，一次能传多个bit，现代WiFi和5G的核心技术。

---

### 五、噪声与误码——信息为什么会出错？

信道中永远存在噪声，最典型的是**加性高斯白噪声（AWGN）**——它均匀分布在所有频率上，就像在信号上叠加了随机的"抖动"。

噪声导致**误码**：接收端把0误判为1，或把1误判为0。衡量指标是**误码率（BER，Bit Error Rate）**。

为了对抗误码，有两大武器：

**信道编码（纠错码）**：在发送的数据里加入冗余信息，让接收端即使收到错误的bit也能纠正。就像你发短信时写"明天早上8点见面"，即使有一个字乱码，对方还是能猜出意思。Turbo码、LDPC码、极化码（Polar Code，华为5G力推）都是这方面的杰作。

**分集技术**：同一份信息通过多条不同路径传输，即使一条路径信号差，另一条可能还好。4G/5G里的MIMO（多天线技术）就是这个思路的极致发挥。

---

### 六、从模拟到数字——采样定理

怎么把连续的模拟信号（比如声音）变成数字？关键是**奈奎斯特采样定理**：

> 只要采样频率 fs≥2fmax（最高频率的两倍），就能从采样值完美重建原始信号。

这就是为什么CD的采样率是44100 Hz——人耳能听到约20000 Hz，乘以2再留点余量，就得到了44.1 kHz。

采样之后还要**量化**（把连续幅值变成有限个离散值）和**编码**（变成二进制），这个过程合称**PCM（脉冲编码调制）**，是数字通信的基础。

---

### 七、整体回顾

现在我们可以把整个流程串起来看一遍：

```
声音（模拟）
  → 采样+量化+编码（变成比特流）
  → 信源编码（压缩，去掉冗余）
  → 信道编码（加纠错，对抗噪声）
  → 数字调制（搭载到高频载波）
  → 发射天线 → 无线信道（有噪声）→ 接收天线
  → 解调 → 信道解码（纠错）→ 信源解码 → 还原声音
```

这就是你打一个手机电话背后发生的事情。

## 第1章　绪论

### 1.1 通信的本质问题

通信要解决一个问题：**把信息从A点可靠、高效地送到B点。**

这句话里有两个关键词。"可靠"——不能出错，或者出错了能纠正；"高效"——用尽量少的资源（频率、功率、时间）传尽量多的信息。这两个目标往往相互矛盾，整门课都在研究如何在两者之间找到最优平衡。

### 1.2 通信系统的一般模型

香农（Claude Shannon）1948年提出了如下通用模型，它适用于一切通信系统：

```
信源 ──► 信源编码 ──► 信道编码 ──► 调制 ──► 信道 ──► 解调 ──► 信道解码 ──► 信源解码 ──► 信宿
                                              ↑
                                            噪声
```

各模块职责如下。

**信源**产生原始信息，可以是语音、图像、文字等。**信源编码**去掉信息中的冗余，做压缩，目的是提高效率，比如MP3、JPEG。**信道编码**反向操作，人为加入冗余（校验位），目的是让接收端能检测或纠正传输错误，提高可靠性。**调制**把数字或模拟信号"搬"到高频载波上，方便在物理信道中传播。**信道**是信息传播的物理媒介，如光纤、电缆、空气。不可避免地引入**噪声**。接收端做对称的逆操作，最终还原出信息送给**信宿**。

模拟通信系统和数字通信系统的主要区别在于：模拟系统没有信源/信道编码和调制/解调中的数字环节，信号始终是连续波形。现代通信几乎全面数字化，原因下面解释。

### 1.3 通信系统的两类性能指标

评价一个通信系统，主要看两个维度：

#### 有效性——传得快不快？

衡量指标是**码元传输速率**（波特率）和**信息传输速率**（比特率）。

码元传输速率 RB（单位：Baud，波特）表示每秒传输的码元个数，和每个码元携带多少信息无关。信息传输速率 Rb（单位：bit/s）才是实际信息量，两者的关系是：

Rb=RBlog2M

其中 M 是码元的进制数（比如二进制 M=2，四进制 M=4）。每个码元携带的比特越多，信息率越高，但抗噪声能力会下降——这是永恒的工程权衡。

#### 可靠性——传得准不准？

衡量指标是**误码率（BER，Bit Error Rate）**，定义为：

Pe=错误接收的比特数总接收比特数Pe=总接收比特数错误接收的比特数

实际系统中，误码率要求可能极为苛刻。4G语音通话容忍 10−3，光纤数据传输要求 10−12，差6个数量级，工程挑战截然不同。

### 1.4 信息的度量——信息量与熵

通信的对象是**信息**，那么信息怎么量化？香农给出了严格的数学定义。

一个随机事件 xi 发生的概率是 P(xi)，它携带的信息量（自信息）定义为：

I(xi)=log21P(xi)=−log2P(xi)（单位：bit）I(xi)=log2P(xi)1=−log2P(xi)（单位：bit）

这个定义非常符合直觉：概率越小的事件，发生了之后给你的信息量越大。"明天太阳从东边升起"的信息量几乎为零；"明天下流星雨"的信息量极大。

对于一个有 n 个可能取值的信源，其**信息熵**（平均信息量）定义为：

H(X)=−∑i=1nP(xi)log2P(xi)（单位：bit/符号）H(X)=−i=1∑nP(xi)log2P(xi)（单位：bit/符号）

熵衡量的是信源的**不确定程度**，也就是平均每个符号能给你多少信息。熵越大，信源越"活跃"，蕴含的信息越丰富。

> 📌 **重要结论**：当所有符号等概率时，熵取最大值 Hmax=log2n。也就是说，完全随机的信源信息量最大——这就是为什么压缩后的文件"看起来像随机数据"。

### 1.5 模拟 vs 数字通信——为什么全面数字化？

数字通信的核心优势在于**抗噪声能力**。模拟信号在信道中被噪声污染后，接收端只能"硬着头皮"还原，噪声会一直积累。而数字信号只要能区分0和1，噪声就不会累积，还可以通过纠错码进一步保障可靠性。此外数字信号便于加密、存储、处理，与计算机天然兼容。代价是需要更宽的频带。

## 第8章　信道编码

信道编码要解决的问题很朴素：信道里有噪声，比特会出错，怎么办？

答案是**主动加冗余**。发送端在原始数据里混入额外的校验信息，接收端利用这些冗余来发现错误、甚至纠正错误。代价是占用更多带宽。整章的核心就是：如何用最少的冗余，换来最强
