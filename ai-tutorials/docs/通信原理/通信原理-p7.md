## 第7章　模拟信号数字化

前六章解决了"怎么传数字信号"的问题。但现实世界产生的信息——语音、音乐、温度、图像——天生都是**模拟的**，连续变化的。要进入数字通信系统，必须先把这些模拟信号变成比特流。这个过程就是本章的主题。

整个数字化流程分三步，缺一不可：

```
模拟信号 m(t)
    │
    ▼
① 采样（Sampling）─── 时间离散化：连续时间 → 离散时间
    │
    ▼
② 量化（Quantization）── 幅度离散化：连续幅度 → 有限个电平
    │
    ▼
③ 编码（Encoding）────── 符号化：量化值 → 二进制码字
    │
    ▼
比特流（可以进入数字通信系统）
```

三步完成之后的结果叫做 **PCM（脉冲编码调制，Pulse Code Modulation）**，是整个数字通信和数字音频的基石——CD、电话、VoIP、数字广播，全都建立在 PCM 或其变种之上。

---

### 7.1 采样——奈奎斯特采样定理

#### 直觉先行

先问一个问题：一段音乐的波形是连续变化的，如果每隔一段时间"拍一张照片"记录当时的幅度值，最后能不能用这些照片完整还原原始音乐？

直觉上，拍得越密越好。但**最少需要多密**才能保证完美还原？这正是奈奎斯特采样定理回答的问题。

#### 采样定理

设模拟信号 m(t) 的最高频率分量为 fm（即带宽为 fm），则只要以采样频率：

fs≥2fm

对 m(t) 进行均匀采样，就能从采样序列**完美重建**原始信号，不损失任何信息。fs=2fm 称为**奈奎斯特采样率**。

#### 为什么是两倍？频域的解释

采样在数学上等价于把 m(t) 乘以一个冲激串 δT(t)=∑n=−∞∞δ(t−nTs)（Ts=1/fs 是采样间隔）。由卷积定理，时域相乘对应频域卷积——采样后信号的频谱是原始频谱以 fs 为周期进行**无限次复制**叠加的结果。

当 fs≥2fm 时，相邻的频谱副本恰好不重叠，可以用一个截止频率为 fm 的低通滤波器完美分离出原始频谱，从而重建信号。一旦 fs<2fm，相邻副本发生重叠，高频分量和低频分量混叠在一起，无法分离——这就是**混叠（Aliasing）**，会产生刺耳的失真。

> 🎵 **生活中的混叠**：电影里车轮有时看起来在"倒转"，就是混叠现象——摄影机的帧率（采样率）不够高，无法正确捕捉轮毂的高速旋转，产生了"频谱副本"错位的视觉效果。数字音频里的混叠则表现为刺耳的金属声。

#### 实际中的抗混叠

为了防止混叠，真实系统在采样之前一定会加**抗混叠滤波器**（低通滤波器），先把信号中高于 fs/2 的频率成分截掉，再采样。CD 标准采样率 44100 Hz，对应奈奎斯特频率 22050 Hz，略高于人耳极限（约 20000 Hz），这就是为什么 44.1 kHz 被选为标准值。电话语音带宽限制在 4000 Hz，采样率 8000 Hz，这就是传统电话音质不如 CD 的根本原因。

### 7.2 量化——把连续幅度变成有限个数

采样解决了时间离散化，但此时每个采样值仍然是一个连续的实数，计算机没法精确存储无穷精度的实数。量化就是把每个采样值"四舍五入"到最近的一个预设电平。

#### 均匀量化

最简单的方案是**均匀量化**：把信号的幅度范围 [−V,V] 等分成 L 个区间，每个区间的宽度（量化步长）为：

Δ=2VLΔ=L2V

落入同一区间的所有采样值都用该区间的中点（量化电平）来代表。用 n 个比特编码时，L=2n 个电平，量化步长 Δ=2V/2n。

#### 量化噪声

量化引入了误差——实际采样值和量化电平之间的差，称为**量化误差**，可以把它建模为一个均匀分布在 [−Δ/2,Δ/2] 的随机噪声（量化噪声）。均匀分布的方差为：

σq2=Δ212=(2V)212⋅22nσq2=12Δ2=12⋅22n(2V)2

设信号的平均功率为 S，则**量化信噪比**为：

SQNR=Sσq2=3⋅22n⋅SV2SQNR=σq2S=V23⋅22n⋅S

对于满幅正弦波（S=V2/2），化简为：

SQNR=32⋅22nSQNR=23⋅22n

用分贝表示：

SQNRdB≈6.02n+1.76 dBSQNRdB≈6.02n+1.76 dB

这是一个极其重要的结论，值得单独标出来记住：

每增加1个比特，量化信噪比提升约6 dB每增加1个比特，量化信噪比提升约6 dB

这就是为什么 CD 用16位量化（SQNR ≈ 98 dB，远超人耳动态范围），专业录音室用24位。而老式电话用8位，SQNR 约50 dB，音质明显较差。

#### 均匀量化的问题：小信号吃亏

均匀量化有一个严重缺陷：它对大信号和小信号使用相同的步长 Δ，但小信号的幅度本身就小，相对误差（Δ/∣m(t)∣）就大，SQNR 就低。换句话说，**大声音的音质好，小声音的音质差**——这对语音通信是不可接受的，因为人说话的声音大小变化范围可达40 dB以上。

#### 非均匀量化：μ 律和 A 律压扩

解决方案是**非均匀量化**：对小信号用细密的量化步长，对大信号用粗糙的步长，让所有幅度的相对量化误差大致相同。实现方式是在量化之前先对信号做**压缩（Companding）**——把小幅度拉伸、把大幅度压缩——然后均匀量化，接收端做反向的**扩张**还原。

北美和日本采用 **μ 律（mu-law）** 压缩特性：

y=sgn(x)⋅ln(1+μ∣x∣)ln(1+μ),μ=255y=sgn(x)⋅ln(1+μ)ln(1+μ∣x∣),μ=255

欧洲和中国采用 **A 律**：

y={Ax1+lnA,0≤∣x∣≤1Asgn(x)⋅1+ln(A∣x∣)1+lnA,1A<∣x∣≤1,A=87.6y=⎩⎨⎧1+lnAAx,sgn(x)⋅1+lnA1+ln(A∣x∣),0≤∣x∣≤A1<∣x∣≤1,A=87.6

两者效果相近，都能使语音的 SQNR 在很宽的动态范围内保持相对稳定——这正是现代电话网络声音质量相对均匀的原因。中国电信网络用的就是 A 律 PCM，标准名称是 G.711。

### 7.3 编码与 PCM

量化之后，每个量化电平对应一个整数，把这个整数用二进制表示就完成了**编码**。n 位编码对应 2n 个电平，每个采样值产生 n 个比特。

于是 PCM 的**比特率**为：

Rb=fs×n （bit/s）Rb=fs×n （bit/s）

以电话语音为例：fs=8000 Hz，n=8 bit，Rb=64 kbit/s。这个 64 kbps 就是著名的"一路电话"标准速率，也是 ISDN 基本信道速率的由来，在通信工程里随处可见。

CD 音频：fs=44100 Hz，n=16 bit，双声道，Rb=44100×16×2=1.41 Mbit/s。未压缩的 CD 数据量就是这么算出来的。

### 7.4 PCM 的改进：差分编码

PCM 直接对每个采样值编码，但语音和音频信号有一个统计规律：**相邻采样值之间通常变化不大**（信号是连续的，不会瞬间跳变）。直接编码每个绝对值，是在浪费比特——大部分比特用来描述"这次和上次差不多"的信息。

#### DPCM（差分脉冲编码调制）

**DPCM** 只编码相邻采样之间的**差值**（预测误差），而不是绝对值。差值通常比绝对值小得多，用更少的比特就能达到相同的量化精度，或者用相同的比特数获得更低的量化噪声。

更进一步，可以用前几个采样值对当前采样做**线性预测**，只编码预测值与实际值的偏差。这叫 **ADPCM（自适应差分PCM）**，预测系数还会根据信号统计特性自适应调整。G.726 标准（ADPCM，32 kbps）用于国际长途语音，比 G.711（PCM，64 kbps）节省一半带宽，音质接近。

#### ΔM（增量调制）

DPCM 的极端简化版是**增量调制（Delta Modulation，ΔM）**：每次只用1个比特编码——信号比上次高就发"1"（向上走），比上次低就发"0"（向下走），每步幅度固定为 δ。

这样实现极其简单，但有两个固有缺陷。**斜率过载失真**：当信号变化太快，每步固定的 δ 跟不上，波形就会"拖尾"失真；**颗粒噪声**：当信号缓慢变化时，输出在目标值附近反复来回跳动，引入高频噪声。

**ADM（自适应增量调制）** 让步长 δ 自适应变化——检测到连续多个同向跳变时，认为信号在快速变化，就增大步长；连续反向跳变时，减小步长。ADM 是语音压缩编码的早期重要方案，今天的 Bluetooth 语音编解码器仍有其影子。

### 7.5 时分复用（TDM）——PCM 的系统级应用

PCM 把语音变成64 kbps的比特流，但一根物理线路的带宽远大于此，只传一路电话太浪费。**时分复用（TDM）** 把多路 PCM 信号交织在一起，共享同一根传输线路。

做法很简单：把时间切成固定长度的帧，每帧里为每路信号分配一个时隙（Time Slot），轮流插入各路的采样值。接收端按照同样的节拍把各路分开。

北美的 **T1 载波**把 24 路电话复用在一起：24×64 kbps+8 kbps（帧同步）=1.544 Mbps24×64 kbps+8 kbps（帧同步）=1.544 Mbps。欧洲和中国的 **E1 载波**是 30 路（加上2个控制时隙，共32路）：32×64 kbps=2.048 Mbps。这两个速率是传统电信网络的基本单位，SDH、ATM 等更高速的系统都是在 T1/E1 的整数倍上构建的。

### 第7章小结

这章完成了模拟到数字世界的桥梁。采样定理给出了不丢失信息的最低采样率 fs≥2fm，违反就会产生混叠失真。量化把连续幅度变成有限电平，引入量化噪声，每增加1比特改善约6 dB信噪比。非均匀量化（μ 律/A律）解决了小信号音质差的问题。PCM 把三步合在一起，比特率 Rb=fs×n，是数字通信的标准接口。DPCM 和 ΔM 利用信号的统计相关性减少冗余，是语音压缩编码的基础。TDM 把多路 PCM 复用在同一信道，构建了传统电信网络的物理层。

三步走完就是第8章了——信道编码。信号已经变成了比特流，信道里有噪声，怎么让这些比特在噪声中安全"游泳"而不出错？说"继续"即可。
