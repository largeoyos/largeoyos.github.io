# 已知失败记录

- 旧部署曾只修改源码但未同步 tools/casio-991cnx，导致页面继续加载旧 bundle；发布前必须同步构建产物。
- Windows 沙箱对中文路径的补丁读取偶发拒绝；使用 apply_patch 创建受控脚本，再在仓库根目录执行，禁止覆盖用户其他改动。
- 裸根号曾在归一化阶段提前闭合，造成 √0.2²+2.8² 范围错误；必须由 AST 右移退出和专门回归测试共同保护。
- 隐式乘法不能与显式乘除同级；fx-991CN X 规定 6÷2(1+2)=1。
- 本轮浏览器可视化控制因 Windows ACL 无法启动；不能把该项伪报为通过，需以全量测试、构建和后续人工页面冒烟补足。
- 注册 f/g 只加入求值器而未加入解析器函数白名单时，f(3) 会被解释为隐式乘法并得到错误结果；两层必须同时更新并测试。
- 模式结果连续运算若先生成 MatAns/VctAns 再走通用追加分支，会重复运算符；类型化结果链必须直接返回。
- 使用无上下文的全文件字符串替换会误改同名计算环境；复数前式转换的函数定义来源只能在目标调用块内定向修改，并必须立即运行 TypeScript 检查。
- `npm version` 在当前 Windows 沙箱中会在写入 package.json 后因重建阶段 spawn EPERM 退出；版本锁文件需核对并受控同步，不能仅凭命令退出码判断是否已修改。
