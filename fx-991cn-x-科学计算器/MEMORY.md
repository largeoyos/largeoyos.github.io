# 项目决策记忆

- 原机基准固定为 fx-991CN X 中文说明书；原机行为优先，已有扩展不删除。
- LCD 固定 192×63 逻辑像素，Canvas 以 8 倍整数 nearest-neighbor 呈现。
- 根号范围由结构化 AST 持续接收，用户按右方向键退出；裸文本根号兼容用户既定的整段根号语义。
- 分式键在左侧已有完整操作数时将其吸附为分子。
- 默认结果为标准/精确，S⇔D 仅切换当前结果；用户可在设置中改为小数。
- 科学常数保留用户锁定的 CODATA 2022 数据，273.15 K 位于“其他”。
- 每次构建后必须同步 dist 到 ../tools/casio-991cnx，避免线上仍加载旧哈希包。
