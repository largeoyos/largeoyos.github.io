## 保留的项目扩展

- 方程模式 5–10 元精确/数值线性方程组。
- SOLVE 多实根浏览。
- 二次根式和复根式结构化精确显示、全局默认结果模式。
- 函数表绘图。
- CODATA 2022 常数值、CW 风格中文高级目录、GCD/LCM、循环小数和概率分布函数。
- 桌面侧栏历史、变量实时编辑和内置说明。

- TypeScript：`npm run lint`
- 生产构建：`npm run build`
