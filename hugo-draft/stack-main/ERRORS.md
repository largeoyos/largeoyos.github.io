# 草案验证记录

- 2026-11-04：合成大西瓜的装饰性 `.panel::after` 渐变在颜色转换后变成不透明白色，覆盖了游戏和控件；原自动检查只验证状态变化，未检查屏幕遮挡。针对该页移除装饰层并检查实际画面和投放交互。

- 2026-11-04：独立课程通过 body.menu-open 控制手机目录。样式限定到应用后，需要同步原 body 状态类到应用容器，并将该状态与新的折叠目录联动；否则按钮虽改变状态，搜索输入仍不可见。原 body 的四种初始页面类也继续保留。

- 2026-11-04：SVG 内的 style 也会影响全局 HTML；部分实验的 svg 最小宽度把主题 GitHub 图标撑至 400px。图形样式保留原几何、语义色和字体，但同样限定到 `.stack-app`。长源码文件名允许换行，KaTeX 的隐藏 MathML 定位限制在自身容器，保留显示公式及其可访问文本。

- 2026-11-04：Stack 原生脚本等待 window.load 初始化，行情 iframe 未加载完时菜单和深色开关尚不可用。通过主题支持的 custom.ts 扩展在 DOM 就绪时初始化，并加一次性守卫，避免后续 load 再次绑定事件。

- 2026-11-04：部分独立课程把保存状态和提示节点放在 body 的 footer 内。迁移时必须保留带 ID、控件或操作的功能页脚，只替换其外观；不能把它们当成纯版权页脚丢弃。

- 2026-11-04：仅排除 `**/*.html` 没有排除挂载目录根层的 HTML，静态复制与主题渲染会竞争同一目标，导致部分页面随机出现旧界面。为 HTML/CSS/JS 同时排除 `*.扩展名` 和 `**/*.扩展名`，并逐页比对所有 534 个输出的主题与正文。

- 2026-11-04：React 构建的 Tailwind 使用 CSS `@layer`，Stack 的无层基础规则优先级更高，导致 `.flex-col` 与 `main.grid` 的布局失效。导入时先展开应用自己的层，再限定到 `.stack-app`，防止应用样式影响 Stack 壳，同时保留棋盘几何布局。

- 2026-11-04：在同一同步循环中解析全量长讲义，JSDOM 窗口及解析缓存累积至 Node 默认 4GB 堆限制。改为每个子进程最多 20 页，批次结束释放解析内存；不通过无上限提高内存来掩盖问题。

- 2026-11-04：开启 `relativeURLs` 时，带子路径的 `baseURL` 导致输出如 `./stack-main-preview/scss/...`，浏览器再次拼接目录而产生 404。关闭该重写，使用主题原生 `RelPermalink` / `relURL`，并为预览设置完整 `baseURL`，用实际浏览器检查嵌套页面、搜索结果和旧页面入口。
- 2026-11-04：Stack v4.0.3 的简体中文语言包名是 `zh`。使用 `zh-cn` 会使部分按钮文字和搜索标签为空；改用 `defaultContentLanguage = 'zh'`，同时保留 `locale = 'zh-CN'`。
