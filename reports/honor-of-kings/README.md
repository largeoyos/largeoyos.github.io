# 王者荣耀全英雄图文研究报告

直接用现代浏览器打开本目录的 `index.html`。请保持 `assets/`、`data.js`、`app.js`、`styles.css` 与网页的相对位置不变。正文、英雄图片和检索无需网络；官网来源链接需要联网。

本次资料快照日期为 **2026-09-12**，制作与验收完成于 2026-09-13。覆盖官方两套名单一致返回的 **132 个条目**，合并元流之子的五种职业和孙悟空命格心魔六耳后为 **127 位英雄**。报告不混入国际服专属角色和体验服爆料。

## 阅读内容

- 游戏目标、经济、兵线、视野、推塔与前 10 局练习方法。
- 可切换的五分路示意图及各位置职责。
- 按名字、拼音、别名、技能名或打法搜索；分路、职业、操作门槛组合筛选。
- 每位英雄的官方图片、机制摘要、入门操作顺序、前期发育、团战任务、出装属性方向、易错点与搭档／对抗参考。
- 每位英雄的独立链接、上一位／下一位导航，以及可追溯的官方来源。

操作门槛按官网值分组（1–3 基础，4–6 进阶，7–10 挑战），并非编者实测或强度排名。多分路英雄可能出现在多个分路；分路筛选数量相加不等于英雄总数。

## 数据与分析

技能、名字、角色职业、官方关系名单和图像来自腾讯王者荣耀官网；打法、装备方向和失误分析为本报告自行撰写。英雄关系字段可能落后于重做，不作无条件克制结论。原始完整故事文本没有复制进成品。

- [现用英雄及美术名单](https://pvp.qq.com/zlkdatasys/heroskinlist.json)
- [分路与名单交叉核对](https://pvp.qq.com/web201605/js/herolist.json)
- 各英雄技能来源见网页详情与 `research/source-manifest.json`（包含检索时间与响应 SHA-256）。
- 每张图像来源见 `research/image-sources.json`。官方美术版权归原权利人，作为研究介绍配图使用。

已发现的差异：旧卢雅那分路字段与新技能详情冲突，采用发育路；元流刺客旧职业字段误列辅助，采用现用名单的刺客；亚瑟旧提示把最大生命伤害误述成已损血量伤害；元流法师倍率含明显录入错误；盾山、元歌、扁鹊、苍等条目存在较大重做差异。以本次现用技能正文为摘要依据，避免复刻旧提示、固定出装、倍率和无法核验的胜率。多形态英雄的摘要不替代完整客户端说明。

## 维护（从仓库根目录执行）

```powershell
node reports/honor-of-kings/research/fetch-sources.mjs
node reports/honor-of-kings/research/prepare-assets.mjs
# 阅读新的原始技能，人工更新 hero-notes.tsv 和数据差异说明，再构建。
node reports/honor-of-kings/research/build-data.mjs
node reports/honor-of-kings/research/validate.mjs
```

取回数据不会自动更新分析结论。官方名单条目数变化后，需人工调整完整性断言、统计口径和快照日期。`finalize.mjs` 仅用于本次版本记录与收尾，不属于数据更新常规流程。

仅使用原生 HTML/CSS/JavaScript，没有运行时网络接口、构建步骤或平台专属后端。可作为静态文件用于 GitHub Pages 和 Vercel；本次没有执行发布或部署。
