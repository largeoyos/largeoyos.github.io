先把知识接起来

第三章到底在解决什么问题

第二章让你会分析一个放大级；第三章要你知道：多个级接在一起，怎样既能接收微弱信号，又有足够增益，还能带动后面的负载。集成运放内部虽然管子很多，仍然由偏置、输入级、中间放大级和输出级组成。

做题先分清两件事。第一件是直流：每只管子有没有合适的静态工作点。第二件是交流：信号引起多大电流变化，这些变化又在哪个电阻上变成输出电压。题目已经说“Q 点合适”，通常就是让你直接进入第二件事。

课本部分必须会做什么为什么要讲
3.1 多级放大带上后级负载算前级，再乘各级增益解决“单级都会，接起来就算错”
3.2 运放概述认输入端、输出端和线性区，判断输出方向把内部电路与外部符号联系起来
3.3 单元电路差模/共模分解、差分增益、电流镜、互补输出本章主要计算与分析题集中在这里
3.4 整体电路把偏置网络分出去，沿信号路径判断各级训练读复杂图；不用背每根线的位置
3.5 性能指标分清失调、偏置电流、带宽与转换速率判断理想运放近似什么时候会失效
3.6—3.7 选择与使用根据输入、速度、负载和电源条件判断是否适用常见于简答与应用题，也解释计算为何不等于实物必然正常

3.1—3.2 复习：后一级既是放大器，也是前一级的负载

假设第一级单独测得空载增益 Au01、输出电阻 Ro1。接上输入电阻为 Ri2 的第二级后，第一级的输出会分压。这个损失发生在两级之间，不能等全部增益乘完再补一个随意的系数。

Au1 = Au01 · Ri2 / (Ro1 + Ri2)
Au = Au1Au2 ··· Aun

这里每个 Auk 都要包含它实际所带的负载。末级的实际负载是外接 RL。如果公式已经用了 RC∥RL，就不要再乘一次同一负载的分压系数。

直接耦合可以传递直流和缓慢变化的信号，但前一级的直流电位也会影响后一级偏置。阻容耦合隔开直流，低频时电容阻抗不能忽略。所谓“中频电容短路”，是题设频段下的近似，不是电容在任何情况下都等于导线。

运放的基本关系是 uo≈Aud(u+−u−)，只在线性范围内成立。开环增益很大，因此很小的差模输入就可能使输出饱和。看见运放符号，不能自动写“虚短”。还需要负反馈、能够维持线性等条件；这些会在后续章节系统应用。

本段最低要求：能说出直接耦合与阻容耦合的区别；能把“空载增益”和“接上后级后的增益”分开；知道同相端升高使线性区输出升高。

3.3.1—3.3.2 复习：差分电路只把“差别”当作有用输入

把两个输入分解，是差分题的第一步。两端一起上升的部分叫共模；两端不一样的部分叫差模。这是代数拆分，不需要猜信号属于哪一类。

uid = ui1 − ui2　　uic = (ui1 + ui2) / 2
ui1 = uic + uid/2　　ui2 = uic − uid/2

例如两端分别是 20 mV 和 10 mV，那么差模是 10 mV，共模是 15 mV。不能因为两个输入都是正数，就说“只有共模”。

对称的三极管差分对在纯差模作用下，两侧电流增量相反，尾部总电流的增量为零。公共发射极点可视为交流虚地。对称、无发射极退化、忽略管子输出电阻、两侧集电极各接 RC 时：

uc1 = −βRCuid/(2rbe)
uc2 = +βRCuid/(2rbe)
Aud,双端 = (uc1−uc2)/uid = −βRC/rbe
Rid = 2rbe

从第一侧单端输出，增益为双端的一半；从第二侧输出，符号相反。若负载跨接两个集电极，纯差模的半电路中每侧应放 RL/2，再与本侧 RC 并联。负载接法不同，不能照抄未带负载的结果。

纯共模时两侧电流同向变化。尾部电阻 Re 越大，这种共同变化越难发生；理想电流源的动态电阻趋于无穷，能够进一步抑制共模。对称且只用公共尾电阻的简单电路，单端共模增益为：

Auc,单端 ≈ −βRC / [rbe + 2(β+1)Re]
KCMR = |Aud/Auc|；以 dB 表示时用 20 log10KCMR

理想对称的双端输出会把两侧相等的共模变化相减掉；实际器件不完全匹配，所以共模抑制不是无限好。计算 KCMR 时，差模和共模增益必须使用相同输出端口。

必会：输入分解、静态尾电流分配、单端与双端的二倍关系及符号、负载折半条件。温度漂移这一段说明为什么需要差分结构，不必把微观过程背成长篇答案。

3.3.3—3.4 复习：电流源、输出级和整张运放图

电流镜：匹配管在相同 UBE 下有近似相同的集电极电流。简单双管镜像源若 β 有限，参考支路还要供应两只管的基极电流，因此不能无条件把 IREF 全部当成输出电流。

IREF = IC + IB1 + IB2
IO ≈ IREF / (1 + 2/β)

这里的箭头就是为了让你看清参考电流在哪个节点分成三份。题目说忽略基极电流时，才进一步取 IO≈IREF。输出管还要有足够的管压降维持放大区，电流源并非能在任何输出电压下保持恒流。

有源负载：一个支路直流能流过电流，同时交流电流却几乎不随端电压变化，因此它的动态电阻可以很大。共射级增益取决于动态负载，大动态电阻有利于获得大电压增益。这里的“恒流”不等于这条支路从电路中消失。

互补输出：上、下两管分别承担不同方向的负载电流。简单乙类输出在零点附近可能两管都不充分导通，造成交越失真；加入适当静态偏置能减轻它。输出级通常重视低输出电阻和电流驱动能力，电压增益接近 1 仍然很有价值。

读复杂运放：先圈出电源和偏置支路，再找到差分输入对，沿集电极节点找中间级与输出级，最后逐级判断输入升高会使输出升高还是降低。别把给各级供电流的偏置网络也硬算成一个信号放大级。

做题标准：会用 KCL 算简单镜像源；能辨认电流源作为尾部偏置还是作为有源负载；能解释交越失真；能在复杂图中标出信号路线。晶体管内部的全部载流子轨迹不需要逐条背诵。

3.5—3.7 复习：性能指标要对上具体错误

指标它在描述什么习题里怎么用
输入失调电压 UIO为使输出回到指定零点所需的小差模补偿估计零输入时的输出偏差
输入偏置电流 IIB两输入端静态电流的平均量与外接电阻相乘，找附加压降
输入失调电流 IIO两个输入偏置电流的不一致程度解释电阻平衡后为何仍有误差
共模抑制比放大差模、抑制共模的相对能力用一致端口的两种增益计算
带宽小信号增益随频率下降的程度看频率响应；单主极点近似下才用常见增益带宽关系
转换速率 SR输出每单位时间最多改变多少电压正弦输出需满足 2πfUom≤SR

带宽不足和转换速率不足不是同一件事。前者属于小信号频率响应；后者常在大幅度、快速变化时暴露。输出正弦峰值越大，保持不受 SR 限制的最高频率越低。

选用与保护需要检查：电源电压、输入共模范围、允许差模电压、输出摆幅、负载电流、速度及所需精度。输入偏置电流还需要直流回路；电源旁路电容用于减少供电扰动。具体限值依赖器件，本页不把某一型号的数值当成所有运放的通用规定。

优先级：先能解释指标、用单位正确的公式算简单限制；型号发展史和工艺名称作为背景认识。实物使用问题有自己的价值，不要求你为一道基本增益题先学完整本器件手册。

开始做题：每次都执行同一套顺序

  1. 查题设。是否已知 Q 点合适？是否为中频？是否忽略 rce、rds 等输出电阻？
  2. 画交流通路。直流理想电压源交流接地，充分大的耦合与旁路电容短路；偏置电阻仍保留。
  3. 分级、定端口。每级从哪一极输入、哪一极输出；用 X 标出两级之间的节点。
  4. 从后向前算负载。先求后一级输入电阻，再并到前一级输出负载上。
  5. 从前向后乘增益。每个增益都写清分子、分母，特别是有没有把输入串联电阻算进去。
  6. 分别求 Ri、Ro。求 Ro 时独立信号源置零，受控源保留，并移去外接负载。

以下 3.2 的解析采用教材的中频简化微变模型，忽略晶体管输出电阻与高频电容；ui、uo 都是题图所标端口电压。∥ 表示并联。没有另画的外接 RL 时，按题图给出的负载计算。

习题 3.1 回看：接法由输入、输出和公共端决定

三极管画在上方、箭头向内、使用负电源，都不能直接决定接法。先把电容和电源变成交流通路，然后找输入、输出对哪一极而言。

题图第一级第二级读图要点
(a)共射共基第二级从发射极输入，基极交流固定
(b)共射共射两级均由基极输入、集电极输出
(c)共射共射第一级是 PNP，发射极在上方仍可以是共射
(d)共集共基第一管从发射极输出，第二管从发射极输入
(e) 选学共源共集场效应管源极被充分旁路，后级从发射极输出
(f)共基共集第一管基极有旁路，实际信号送入发射极

这些识别图突出端口关系，省略的偏置支路不能在后面的增益计算中继续无条件省掉。判断接法与计算负载，是两步不同的工作。

做对的标准：不用背 (a) 到 (f) 的答案，而是换一张画法仍能按三个端口判断。PNP 不自动代表同相，共基也不等于基极必须真的拿导线接电源地。

习题 3.2(a) 回看：共射后接共集

这里输入端到第一管基极之间有一个串联 R1。第一级共射负责电压放大，第二级共集主要降低输出电阻。先看第二级：

Ri2 = rbe2 + (β2+1)R3
Au2 = (β2+1)R3 / Ri2

于是第一管集电极实际看到 R2∥Ri2，不能只用 R2。本题把第一级增益定义为 u1/ui，因此输入串联 R1 也必须计入：

Au1 = −β1(R2∥Ri2) / (R1+rbe1)
Au = Au1Au2　　Ri = R1+rbe1
Ro = R3 ∥ [(rbe2+R2)/(β2+1)]

求输出电阻时 ui=0，第一管的基极增量电流在本题简化模型下为零，所以其受控电流源恰好为零，T2 基极对地看到 R2。这不等于“受控源都可以关掉”。第二管受控源仍然参与输出测试电流的形成，正是它导致了除以 β2+1。

记忆抓手：共射后面接共集，关键是“前级带上共集的输入电阻”和“输出电阻由共集折算”。

习题 3.2(b)：把共集放到前面，会改变什么

这题变成共集 → 共射。不要因为仍然是一只共射加一只共集，就认为与 (a) 的 Ri、Ro 相同。放在输入端还是输出端，会决定它主要改善哪一端。

第一步：电容短路后，R3 到底去了哪里

C2 短路，把第一管发射极和第二管基极合成同一个 X 点。R3 上端接 VCC，交流时相当于接地。因此从 X 点看向地有三条路：R2、R3，以及第二管的 rbe2。

RE′ = R2 ∥ R3 ∥ rbe2

R3 虽然在直流分析中负责偏置，但交流电压变化同样能在它上面产生电流。“偏置电阻”是用途描述，不是“交流时删掉”的许可。

第二步：那一堆电流箭头，在这里就用来得到 β＋1

把第一管换成微变模型。流进基极的 ib1 经 rbe1 到发射极；集电极支路的受控电流 β1ib1 也到发射极。它们在 X 点汇合，然后一起流入 RE′。

ie1 = ib1 + β1ib1 = (β1+1)ib1
u1 = (β1+1)ib1RE′
ui = ib1rbe1 + u1

最后一行就是沿输入端到地列电压：输入电压分给了基极—发射极这一段和发射极到地这一段。两式相除：

Au1 = u1/ui
= (β1+1)RE′ / [rbe1+(β1+1)RE′]

它是正数，而且小于 1。只有在 (β1+1)RE′ 远大于 rbe1 时，才能近似等于 1。后级输入电阻很小时，会把 RE′ 拉低，跟随效果也会变差。

第三步：第二级是熟悉的共射

第二管发射极交流接地，所以 ib2=u1/rbe2。基极电流增大，集电极电流增大，R4 上的压降增大，输出节点电压降低，负号就从这里来。

Au2 = −β2R4/rbe2
Au = [(β1+1)RE′ / (rbe1+(β1+1)RE′)] · [−β2R4/rbe2]

本题没有额外外接负载；若另接 RL，第二级增益中的 R4 要换成 R4∥RL。

第四步：输入电阻要计入 R1，而且是并联

从输入端看进去，一股电流通过 R1 流向交流地，另一股流入第一管基极。两条路径共用相同输入电压，因此它们并联：

Ri = R1 ∥ [rbe1+(β1+1)RE′]
Ro ≈ R4

为什么 Ro 没有再除 β+1？因为现在从末级集电极输出。输入置零、忽略管子输出电阻时，从输出端看到的就是 R4。共集放在前面，不会把最后这个集电极自动变成低阻输出。

把结果翻译回这两级各自的任务

电压增益主要来自第二级；第一级把发射极负载折算成较大的基极输入电阻，使信号源少供一些电流。最终输入电阻仍受到并联 R1 的限制：即使晶体管输入支路的电阻很大，整个电路的 Ri 也不可能超过 R1。

如果题目另给直流元件数值，还需要先求 Q 点，再求 rbe；不能任意指定一组 rbe，就保证它与原图的偏置网络相容。本题只要求符号表达式，而且已说明 Q 点合适，因此做到上面的结果即可。

必须掌握：三条并联负载、β+1 的 KCL 来历、R1 与 (a) 的串并联区别、首级共集与末级共集各改善哪一端。

习题 3.2(c)：PNP、二极管和正负号一起出现

第一管是 NPN 共射，第二管是 PNP 共射。第二管的发射极在上方，通过一只正向导通二极管接电源；集电极在下方，通过 R3 接地，并从这里输出。

先处理二极管：直流压降和交流电阻是两件事

静态分析中可以用 UD≈0.7 V 等模型估算电位。微变分析问的是 Q 点附近“电流改一点，电压会改多少”。这个比例是动态电阻 rd。配套解答也保留了它。

rd = ΔuD/ΔiD（Q 点附近）
采用指数模型时，rd ≈ nUT/IDQ

如果题目特别指定理想恒压降模型，其增量电阻才取零。题目保留动态模型时，不要因为“二极管导通了”就直接画成导线。

从第二级看入，发射极的 rd 会被放大折算

把第二管基极流向外部的电流增量参考方向记作 ib2，集电极电流参考方向由发射极指向集电极。按图列式：

ue2 = −(β2+1)ib2rd
ue2−u1 = ib2rbe2
u1 = −ib2[rbe2+(β2+1)rd]

第一行的负号来自电阻电流：我们把电流参考方向选为从交流地经 rd 流向发射极。沿这个方向出现压降，所以发射极电位是负的增量。这里的电流是带符号的变化量，算出负数表示实际变化与所选箭头相反。

从外部输入端流入该级的电流是 −ib2，所以输入电阻仍为正：

Ri2 = u1/(−ib2)
= rbe2+(β2+1)rd

这就是电流箭头的实际用途：帮你一致地列 KCL、KVL，避免把 PNP 的符号凭感觉写反。你不必额外追踪每一个电子经过了哪里。

第二级为什么仍然反相

PNP 基极电位升高，会使正向发射结电压减小，集电极电流减小，于是 R3 上的输出电压下降。发射极有 rd 时也会跟着变化，但方向仍是反相，只是增益幅值变小。

uo = β2ib2R3
Au2 = −β2R3 / [rbe2+(β2+1)rd]

第一级依旧使用“实际集电极负载”：

Au1 = −β1(R2∥Ri2) / (R1+rbe1)
Au = Au1Au2 > 0
Ri = R1+rbe1　　Ro ≈ R3

总增益为正，原因是两个共射级连续反相两次。不是因为“出现一只 PNP，所以整个电路同相”。

rd 只有几十欧，能不能忽略

不能仅凭它的原始数值决定。假设 β2=100、rbe2=3 kΩ、rd=26 Ω、R3=3 kΩ，则：

(β2+1)rd = 2626 Ω
Ri2 = 5626 Ω
Au2 ≈ −53.32

若误把 rd 置零，会得到 Au2=−100，差别很大。判断可否忽略，应比较 (β2+1)rd 与 rbe2，而不是只比较 rd 与几千欧的电阻。

必须掌握：二极管的直流模型与微变模型不同；PNP 共射仍反相；发射极阻抗折算到基极要乘 β+1。指数模型的深入推导不是这道题的解题门槛。

选学 · 不影响三极管主线

习题 3.2(d)：场效应管共源后接三极管共射

老师尚未要求场效应管计算时，这题先掌握三个对应关系即可。第一管从栅极输入、漏极输出，源极被电容充分旁路；第二管发射极也被充分旁路，因此是共源 → 共射，两次反相，总体同相。

第二级输入电阻由基极两只偏置电阻和 rbe2 并联组成；第一管漏极除了 R4，还接着这个负载。

Ri2 = R6∥R7∥rbe2
Au1 = −gm(R4∥Ri2)
Au2 = −β2R8/rbe2
Au = Au1Au2

场效应管把栅源电压变化转换成漏极电流变化，使用 gm；三极管把基极电流变化转换成集电极电流变化，使用 β。两个模型的控制量不同，不要把 gm 当成无量纲电流倍数。

本题栅极通过 R3 连接 R1、R2 的分压中点。电源交流接地后，从输入端到地的电阻路径先经过 R3，再经过 R1∥R2：

Ri = R3 + (R1∥R2)
Ro ≈ R8

“栅极几乎不取电流”说的是器件栅极支路；输入端仍可以向偏置电阻供电流。因此整个放大电路的输入电阻不一定是无穷大。

当前掌握边界：会沿电阻路径算 Ri、知道 gm 的单位是 S、知道共源反相即可。场效应管 Q 点与 gm 的专项计算留到对应进度。

习题 3.3：增益不到 1 的级，为什么能提高整体效果

课本把两种基本电路装进方框：I 是共射放大级，II 是共集跟随级，然后接出三种组合。这里不需要重新推导整张图，先说清每个方框的特点。

共射通常有较大的电压增益，但输入电阻不算大，输出电阻也不低。共集电压增益接近 1，同时通常有较大的输入电阻、较小的输出电阻。题目讨论的是这种典型工作条件下的比较。

第一问：哪些输入电阻较大

信号源首先碰到第一级。图 (d)、(e) 的第一级是共集，所以按本题常用近似判断，(d)、(e) 输入电阻较大。这里是定性比较；实际数值仍会受到后级负载和偏置电阻影响，不能只背“看首级”就停止计算。

第二问：哪些输出电阻较小

外部负载接在末级。图 (c)、(e) 的最后一级是共集，所以(c)、(e) 输出电阻较小。两端都安排共集的 (e)，同时改善了输入和输出的衔接。

第三问：先看清分母是 us，不是 ui

us 是信号源的源电压，ui 是经过源内阻 Rs 分压后真正加到放大器输入端的电压。二者一般不同：

ui = us · Ri/(Rs+Ri)
Aus = uo/us = [Ri/(Rs+Ri)] Au

如果把整个放大器用空载增益 Au0、输入电阻 Ri、输出电阻 Ro 的单向模型表示，还可以展开成：

Aus = [Ri/(Rs+Ri)] · Au0 · [RL/(Ro+RL)]

最左边是输入损失，中间是放大器内部的空载增益，最右边是输出带负载后的损失。放在前面的共集增大 Ri，放在后面的共集减小 Ro，使两端少损失。因此本题预期的比较结论是：(e) 的 |Aus| 最大。

共集级自己虽然不能把电压变成两倍、十倍，却可以避免其他地方把电压分掉很多。它的作用是改善连接条件，所需输出能量仍来自电源。

一组完整数字：只多乘两个 0.99，为什么结果反而变大

以下是说明分压作用的自设单向模型，不是课本给定参数。共射级：空载增益 −100、RiI=2 kΩ、RoI=10 kΩ；共集级：空载增益 0.99、RiII=200 kΩ、RoII=0.1 kΩ。信号源 Rs=10 kΩ，外接 RL=2 kΩ。每个连接处都算一次分压。

(c)：Aus = (2/12) × (−100) × (200/210) × 0.99 × (2/2.1)
≈ −14.97

(d)：Aus = (200/210) × 0.99 × (2/2.1) × (−100) × (2/12)
≈ −14.97

(e)：Aus = (200/210) × 0.99 × (2/2.1) × (−100)
× (200/210) × 0.99 × (2/2.1) ≈ −80.63

(c) 的主要损失在输入端，(d) 的主要损失在输出端，(e) 把两端都改善了。这里特意选择了对称的数值，所以 (c)、(d) 的结果相等；它们一般不必相等。

适用边界：这不是“加跟随器就必定增益更高”的数学定律。如果信号源本来是理想电压源、负载又近似开路，原有两端损失已很小，再加有限增益的跟随器未必有利。课本结论针对共集能够明显改善源和负载条件的典型比较。

必须掌握：Ri 大能减少源端分压，Ro 小能减少负载端分压；Au 与 Aus 的分母不同。不要把“电压增益约 1”误解成“没有用”。

合上答案，检查这次是否真的学会

先口头回答，再展开核对。这里的六问比重新背一遍长公式更能发现漏洞。

1. 3.2(b) 中，为什么 R3 不能删掉？

它从第二管基极接到电源，交流时电源接地，所以 R3 从两级之间的 X 点接地。它既参与第二级偏置，也会加载第一管发射极。

2. (a) 与 (b) 都有 R1，为什么一个串联，一个并联？

(a) 的输入电流到基极前必须经过 R1，所以与 rbe1 串联；(b) 的输入节点分出 R1 到交流地的支路，所以 R1 与晶体管输入支路并联。串并联由节点连接决定。

3. 共集电路里的 β+1 从哪里来？

发射极节点接收基极电流 ib 和集电极电流 βib，流向发射极负载的总电流就是 (β+1)ib。它是 KCL，不是要另背一个器件规律。

4. 3.2(c) 的第二级是 PNP，为什么增益仍为负？

基极电位升高，使发射结正向电压减小、集电极电流减小，R3 上电压随之下降。因此它仍然是反相的共射级。

5. 二极管动态电阻只有 26 Ω，忽略它之前要和谁比较？

先乘 β2+1，再与 rbe2 比较。折算后的发射极阻抗可能已经与基极输入电阻同量级。

6. 题目把 Au 换成 Aus，为什么排序可能改变？

Aus 从信号源电压开始计，包含 Rs 与 Ri 的输入分压；Au 从放大器输入端电压开始计。两个量覆盖的电路范围不同。
