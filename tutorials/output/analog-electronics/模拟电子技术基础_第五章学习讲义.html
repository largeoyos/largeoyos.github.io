先约定：ui 是外部输入，uf 是输出返回的反馈电压，ud 或 u′i 是真正作用于基本放大电路的净输入电压。电流同理。F 表示反馈系数，β 仍留给三极管电流放大系数。下面写 A(f)、F(f) 时包含幅值和相位；中频纯电阻题通常可当实数处理。

5.1.1 反馈：输出返回来，改变的是“净输入”

第二章里你已经见过反馈：基极电位暂时不变，集电极电流因温度升高而增大，发射极电流也增大；RE 上电压升高，使 uBE=uB−uE 减小，原来的电流增大受到抑制。这里需要记的不是一串箭头，而是输出电流通过 RE，改变了输入端真正控制管子的 uBE。

对运放也一样。它响应的是 uP−uN，不是随便挑一个输入脚对地的电压。外部信号为 1 V，不代表内部放大电路也承受 1 V 差模输入。反馈可以把另一个端子抬到 0.999 V，使差模输入只剩 1 mV。

框图箭头只表示信号关系，不是导线上真的有一个叫“X”的电流。上面从净输入经 A 到输出，下面由输出经 F 返回。输出对净输入起抵消作用叫负反馈，起加强作用叫正反馈。“负”不是说输出电压一定为负，也不是说电压增益一定为负。

课本先举生活中的反馈，是为了建立“把结果送回去修正作用”的概念。做题时不需要背这些比喻；你需要会在图上指出输出取样点、返回路径、输入比较点这三个位置。

检查：共射放大器输出反相，所以它一定是负反馈电路吗？

不能这样判断。输出反相描述正向放大关系；负反馈描述信号绕回输入后是加强还是抵消。没有返回输入的通路，反相放大仍可以是开环放大。

5.1.2 先找通路：电阻碰到输入脚，不一定构成反馈

从输出往回找，看它能否改变 uBE、uGS、uP−uN 或相应的净输入电流。只有一条画得像“回路”的线，不能证明存在反馈。

图中 R 一端接输出，另一端与运放同相端一样接地。地把这个节点固定在零电位，输出变化不会经 R 改变它。R 只是负载；不是因为电流“流不过去”，而是因为它不能改变净输入量。这正是教材图 5.1.2(c) 要考的区别。

再分清局部反馈与总体反馈。一个多级电路可能每一级都有局部反馈，同时还有从最终输出绕回第一级的反馈。题目问某个电阻引入什么反馈，就只沿该电阻对应的闭合信号路径判断；别把所有环混成一个符号。

5.1.2 瞬时极性法：每个加减号都要有用途

按四步做：①假设输入有一个很小的正向变化；②沿正向放大路径推输出变化；③沿反馈网络推返回量变化；④把返回量放进净输入式，检查它是在抵消还是加强最初的变化。

基本方向先记三条：共射、共源的电压输出反相；射极跟随器、源极跟随器同相；运放同相端升高使输出升高，反相端升高使输出降低。这里说的是工作点附近的小变化，图中的“−”通常是“电位下降”，不等于该节点的直流电位小于 0 V。

同相电压放大器中，输入升高，输出升高；输出经 R2、R1 分压使 uN 升高。净输入式为：

ud = uP−uN = ui−uf

uf 的升高会减小 ud，因此是负反馈。图中从输出经 R2 流向 R1 的箭头，最后要变成分压式或 KCL；理解到这里就够了，不必对每一段导线都另记一个电流名称。

单个运放、普通无源电阻返回网络中，“输出返回反相端”为负反馈是一个快捷判断。但若中间多了反相级，就必须把整条路径算完。教材例 5.1.1 的 A1 和 A2 都反相：输入增大使 uo1 减小，最终 uo 增大；反馈送入 A1 的同相端，反而抵消原来从反相端输入的作用。不能只看最后接到了“＋”还是“−”。

5.1.2 直流与交流：把电容分别开路、短路，再看一次

直流反馈是在直流通路中存在的反馈，主要影响静态工作点和慢变漂移；交流反馈是在研究频段的交流通路中存在的反馈，影响动态增益、输入/输出电阻、失真与频带。它们可以同时存在。

上图将电容并在分压下臂 R1 上：直流时 C 开路，分压反馈仍在；中频把 C 视为短路，反相端被交流接地，来自输出的交流反馈量变为零。下图把 C 串在返回支路：直流时通路断开，交流时返回通路接通。因此前者是“只保留直流反馈”的典型，后者是“只保留交流反馈”的典型。

这里的“交流短路”有频段条件。到了低频，电容不能再理想短路，就必须连同容抗一起算。第二章的 RE 并联 CE 也是同一个逻辑：RE 仍能稳定直流 Q 点，但中频反馈电压被旁路。

下图只用来判断这条支路能通过什么信号。实际电路还需要建立直流工作点；不能只按这张简图串一个电容，就假定运放在直流时也能保持正常线性工作。

做题写法：先说直流时哪条支路存在，再说交流时哪条支路存在，最后分别判正负。“直接耦合所以只能有直流反馈”是错的；直接耦合电路也能传递交流。

5.2.1 四种组态，其实只问两个独立问题

第一个问题在输出端：反馈到底在检测输出电压还是某条输出电流？这决定名称前半段“电压/电流”。第二个问题在输入端：输入与返回量是用电压求差，还是在一个节点用电流求差？这决定后半段“串联/并联”。

输出检测输入以电压求差输入以电流求差
输出电压 uo电压串联：ui 控制 uo电压并联：ii 控制 uo
输出电流 io电流串联：ui 控制 io电流并联：ii 控制 io

别被“电流串联里为什么出现反馈电压”绊住。检测的是电流，返回到输入的可以是经过电阻转换后的电压。同样，电压并联可以检测电压，再经过电阻变成返回电流。名称的两半分别回答不同问题。

“稳定输出电压”指输入保持不变时，负载、参数等扰动引起的电压变化受到抑制；不是不允许输出随输入信号变化。电流反馈稳定的也可能是管子的集电极电流，未必恰好是某只外接 RL 的电流，必须先读题目标出的 io。

5.2.2 电压串联：把输出分一部分，与输入电压比较

回看前面的同相放大器。R1、R2 分压，运放输入电流近似为零，所以：

uf = uoR1/(R1+R2)
ud = ui−uf

第一行证明取样来自输出电压；第二行证明输入以电压比较。因此是电压串联负反馈。将负载 RL 在纸面上短接，输出电压为零，由输出产生的 uf 也为零，判断得到同样结论。

如果放大器的能力很强，只需要很小的 ud 就能产生有限输出，便有 ui≈uf。代入第一行：

uo/ui ≈ 1+R2/R1

例如 R1=10 kΩ、R2=90 kΩ，增益约为 10。RL 不在这个式子里，说明在放大器可提供所需输出电流的范围内，负载变化主要让输出电流变，而输出电压较稳定。

5.2.2 电流串联：负载电流流过取样电阻

这个电路的 RL 下端没有接地，而是接在取样电阻 R 上端。运放输入电流近似为零，因此流过 RL 的电流继续流过 R；图中 io 箭头直接对应下面第一行。

uf = ioR
ud = ui−uf
ud≈0 ⇒ io≈ui/R

取样的是电流，比较的是电压，所以是电流串联。负载变化时，io 近似不变，而负载两端电压 uo=ioRL 随 RL 变化。运放输出脚对地电压另为 io(R+RL)，两者不可混用。

R=1 kΩ、ui=1 V 时，输出电流约 1 mA。RL 从 2 kΩ 增为 4 kΩ，负载电压由 2 V 变成 4 V，运放输出脚由 3 V 变成 5 V。若所需电压超过实际供电允许范围，恒流关系就不能继续成立。

必须会：看到“将电压转换为稳定电流”，想到电流串联；知道 1/R 的单位为 A/V，不能把它直接当成无量纲电压增益。

5.2.2 电压并联：输入电流在同一节点分流

输入经 Rs 到 N 点，反馈电阻 Rf 从 N 点接到输出。同相端接地。图中 ii 箭头流入 N，if 箭头由 N 流向输出，进入运放的剩余电流为 iN。KCL 是：

iN = ii−if

若输入电流增加，N 点先有升高趋势，运放输出便降低；这使流经 Rf、离开 N 点的电流增加，从而分走更多输入电流，抵消净输入的增加。因此是并联负反馈。

在线性理想运放条件下，uN≈0、iN≈0，所以 ii≈if。根据箭头的起点减终点：

if = (uN−uo)/Rf ≈ −uo/Rf
uo/ii ≈ −Rf
ii≈us/Rs ⇒ uo/us≈−Rf/Rs

反馈来自输出电压，却以电流形式返回，这就是电压并联。负号来自参考方向：正输入电流需要负输出电压把它经 Rf 拉走。箭头到这里已经完成任务：它决定 KCL 和欧姆定律的符号。

运放的输入电流为零，并不表示信号源没有电流。信号电流从 Rs 进入，经 Rf 流向输出端。也不能直接把理想电压源接到求和节点，硬把 uN 钳为非零电压，却还要求“虚地”。

5.2.2 电流并联：输出电流的一部分返回输入节点

这次 RL 跨在运放输出与节点 B 之间；B 通过 R2 接地，又通过 R1 接 N。本图统一规定 io 从运放输出经 RL 向下，uo 为上正下负。参考箭头用于列式，不等于正输入时的实际电流方向；不要与教材标出的瞬时方向混用。

虚地使 N 与地电位相同。输出电流作用时，R1、R2 相当于并联分流；反馈箭头从 N 指向 B，与“io 注入 B 后分流出去”的方向相反，因此：

if = −[R2/(R1+R2)]io
ii≈if ⇒ io/ii≈−(1+R1/R2)

如果重新把 io 箭头反过来，电流增益会换符号；反馈的物理性质不变。所以不要背“电流并联一定是正增益/负增益”，要按当前图的箭头列式。

uo/us ≈ −(1+R1/R2)RL/Rs

最后一个式子先用 Rs 把输入电压换成电流，再用 RL 把输出电流换成电压。它多出两个电阻不是多背一种反馈，而是题目最后要求的量不同。

5.2.3 判断模板：先确认负反馈，再写两个判据

  1. 先画所需频段的通路。直流电容开路；中频大电容短路、独立直流电源交流接地。
  2. 用瞬时极性判断正负。说清净输入式里的哪个量被抵消；不能先假设虚短再倒过来证明负反馈。
  3. 判断输出取样。在纸面上令指定输出电压为零，检查由输出引起的反馈分量是否随之消失。消失为电压反馈；输出电流仍能形成反馈则为电流反馈。
  4. 判断输入混合。写 u′i=ui−uf 或 i′i=ii−if，分别为串联、并联。

第三步的“输出短路法”是分析方法，不是让你把实际运放输出用导线接地。还有一个容易错的点：输出电压置零后，某电阻仍可能被输入源驱动而有电流；那部分不算由输出返回的反馈量。

教材例 5.2.1 中运放驱动 NPN 管，集电极负载电流经发射极网络取样后返回反相端：是电流串联。例 5.2.2 中差分输入级的另一个基极接输出分压：净输入是两基极电位之差，输出为零时分压反馈消失，是电压串联。即使三极管基极还吸收电流，也不能因此改判成并联反馈。

5.3.1—5.3.3 一般表达式：从三行定义推出来

X′i=Xi−Xf
Xo=A X′i
Xf=F Xo

将后两行代回第一行：Xo=A(Xi−FXo)。把含输出的项移到同一边，得到：

(1+AF)Xo=AXi
Af ≡ Xo/Xi = A/(1+AF)

A 是基本放大电路的增益，F 是反馈网络的传输系数，AF 是环路增益，Af 是从外部输入到输出的闭环增益。中频按这个减法约定，负反馈对应 AF>0；A、F 本身都可为负，只要乘积为正。

把反馈电阻直接从电路中拆掉再算 A，有时会改变两端负载，得到错误的开环比较值。教材框图中的 A 已考虑反馈网络的负载效应；若题目给出了 A、F，就在这一约定下使用。普通深度反馈习题常可直接求 F，正是为了避开逐管重算 A 的工作。

一个重要边界：式子分母写成 1+AF，是因为前面明确采用“输入减反馈”的符号约定。其他资料若把负号并入环路传递函数，可能写成 1−L。不要把两套符号混着用。

5.3.2 四种组态中的 A、F、Af，单位并不相同

组态闭环增益 Xo/Xi反馈系数 Xf/Xo单位检查
电压串联uo/uiuf/uoAf、F 均无量纲
电流串联io/ui，跨导uf/ioAf 为 S；F 为 Ω
电压并联uo/ii，跨阻if/uoAf 为 Ω；F 为 S
电流并联io/iiif/ioAf、F 均无量纲

四行里 AF 都无量纲，因此可以与 1 相加。若你在电压并联电路里写出 F=−Rf，单位是 Ω，却定义 F=if/uo，就知道写倒了：应为 −1/Rf。单位检查比死记符号可靠。

为什么课本要写这一大张表？因为“闭环增益≈1/F”算出来的，未必是最后要求的电压放大倍数。最稳的写法是先写分子/分母到底是什么，再决定是否补乘负载、补除源电阻。

5.4.1 深度负反馈：忽略净输入，保留外部输入

当 |AF| 远大于 1，且处在稳定的负反馈工作范围时，分母的 1 相对很小：

Af = A/(1+AF) ≈ 1/F
X′i/Xi = 1/(1+AF)
串联：ui≈uf；并联：ii≈if

“忽略净输入”不是令外部输入为零。输入可以为 1 V，而净输入只有几微伏。也不是说任何一只三极管都不需要基极电流：串联反馈主要忽略净输入电压；并联反馈主要忽略净输入电流，所用近似必须与组态和器件模型一致。

例如 A=10⁴、F=0.01，AF=100，准确闭环增益为 99.01，深度近似为 100。以近似值 1/F 为基准，偏差为 1/(1+AF)≈0.99%。只算到两位有效数字时常足够；若要求 0.1% 精度，就不能不检查环路增益。

这节的核心：不需要先把所有三极管的小信号电路画出来；先利用输入与反馈近似相等，把反馈网络变成普通电阻题。仍要检查工作点、输出摆幅和稳定性允许这一步近似。

5.4.2 反馈网络：把输出当作激励，只求返回的那一份

分离反馈网络时，从输出取样点沿通路走回输入比较点。保留决定分压或分流的电阻；交流电源端变为地；按串联输入近似开路或并联输入近似虚地建立返回端条件。不要把输入源本身造成的电压、电流混进 F。

这个网络对应教材例 5.2.1、5.4.4 的发射极取样。iE 注入 B 后分成两路：一路经过 R3，一路经过 R2+R1。返回端近似不取电流，所以反馈电压取 R1 上的压降：

i12 = iER3/(R1+R2+R3)
uf = i12R1
F = uf/io ≈ R1R3/(R1+R2+R3)

最后一步用到 iE≈iC=io，即忽略三极管基极电流。不是“理想运放”就能自动让外围晶体管 β 无穷大。若保留 β，F 还需乘 (β+1)/β，输出电流则乘相应的 α=β/(β+1)。

很多题的难点就在这里：反馈电阻并不是唯一决定 F 的元件。R3 分走了一部分电流，R1 决定反馈压降，两者都必须保留。

5.4.3 四个例题：同一套方法，输出量不同

例 5.4.1：差分级的返回基极由 R2=10 kΩ、R4=100 kΩ 分压。电压串联，所以 F=R2/(R2+R4)=1/11，Auf≈11。输入基极与返回基极构成差分比较，不必重新计算两只管子的 β。

例 5.4.2（场效应管选学）：共源加共射，两次反相使总体同相；输出通过 Rf 返回第一级源极，与 Rs1 分压。因此 F=Rs1/(Rs1+Rf)，Auf≈1+Rf/Rs1。源极电压升高抵消栅源电压，这就是串联比较。

例 5.4.3：取样的是第二管输出电流，返回输入节点作分流。按课本参考方向，F=Re2/(Re2+Rf)，Aif≈1+Rf/Re2。要求电流增益 10、Re2=1 kΩ，得到 Rf=9 kΩ。题目还要电压增益，不能到此停下：

R′L = Rc2∥RL = 10 kΩ∥10 kΩ = 5 kΩ
Ausf≈AifR′L/Rs=10×5/1=50

这里被稳定的管子电流流进 Rc2 与 RL 的并联组合，因此应乘 5 kΩ，不能只乘 RL=10 kΩ。

例 5.4.4：用上一节电流取样网络，R1=10 kΩ、R2=100 kΩ、R3=2 kΩ、RL=5 kΩ：

F≈10×2/(10+100+2) kΩ = 0.1786 kΩ
io/ui≈1/F=5.6 mA/V
Auf≈RL/F=28

检验：输入 0.1 V，负载电流约 0.56 mA，负载电压约 2.8 V；这是 28 倍。三个数的单位都对，结果才可信。

5.4.4 虚短、虚断：先判断工作状态，再用两条规则

理想运放把开环差模增益、输入电阻、共模抑制比和带宽看成无穷大，把输出电阻、失调与内部噪声看成零。这些假设是解题模型；实际使用时，有限带宽和输出摆幅仍需另行检查。

uo=Aod(uP−uN)
有限 uo、Aod→∞ ⇒ uP≈uN（虚短）
输入电阻→∞ ⇒ iP≈iN≈0（虚断）

虚短不是真导线：两端电位相等，但不允许你画一根导线让电流从 P 流到 N。虚断不是输入脚不接电路：只表示流入运放内部的电流忽略不计，外部电阻之间仍可有很大的电流。

只有稳定负反馈、输出未饱和、输入共模范围等条件满足时，才能用虚短计算线性增益。开环、正反馈或输出碰到上限时，uP≈uN 一般不成立。虚断作为理想输入模型仍可使用，但它本身不能推出虚短。

“虚地”还要多一条条件：某个输入端真接地，再由虚短得另一个端子近似 0 V。两个输入端都处于 2 V 时，它们可以虚短，却不是虚地。

故障题固定步骤：先把开路/短路画进图，重新找反馈；若仍是有效负反馈，列节点式并检查输出范围；若返回通路失效，根据 uP−uN 的正负选择正、负饱和。第五章 5.10 和 5.17 的重点就是这件事。

5.5.1 稳定放大倍数：稳定的是“相对变化”

设反馈网络 F 不变，将 Af=A/(1+AF) 对 A 求导：

dAf/dA = 1/(1+AF)²
(dAf/Af) = [1/(1+AF)](dA/A)

第二行才是常用结论。若开环增益变化 10%，反馈深度 1+AF=100，闭环增益的相对变化约 0.1%。这是小变化近似；变化很大时，分别代入变化前后的 A 更稳妥。

把稳定性换来的代价也记住：中频增益同样缩小为原来的 1/(1+AF)。为得到既稳定又有足够大的最终增益，先做出较大的开环增益，再通过反馈确定所需增益。

但 F 自己若变化，深度反馈不会替你消掉它。更完整的微小变化关系为：

dAf/Af = [1/(1+AF)] dA/A − [AF/(1+AF)] dF/F

深度反馈时，第二项约为 −dF/F。因此精密放大器还要选稳定的电阻比。对基础习题，知道“F 固定”是公式前提即可，不必把误差分析当成本章第一优先级。

5.5.2 输入电阻：串联增大，并联减小

串联负反馈时，同样的输入电流只需在基本放大器上形成较小的净输入电压；外部输入电压还要加上反馈电压，因此从外部看，电压/电流变大：

Rif=(1+AF)Ri　（串联）
Rif=Ri/(1+AF)　（并联）

并联时，输入电流的一部分经反馈支路流走，同样的节点电压对应更大的外部输入电流，所以电压/电流变小。记这两个物理解释，比分别背四种组态的全部结论容易。

要分清测量端口。反相运放的 N 求和节点近似虚地，节点输入电阻趋近零；但信号源从 Rs 左端看进去，输入电阻约为 Rs，不是零。若题目把 Rs 算在放大电路之外，两种说法才能同时成立。

环外并联偏置电阻也不会一起被乘大。例如晶体管输入支路从 10 kΩ 提高到 1 MΩ，但输入端还并着 100 kΩ 的偏置电阻，整机输入电阻为 1 MΩ∥100 kΩ≈90.9 kΩ，不是 1 MΩ。

5.5.2 输出电阻：电压反馈减小，电流反馈增大

电压源希望负载变化时输出电压不变，所以理想输出内阻越小越好；电流源希望负载变化时输出电流不变，所以理想输出内阻越大越好。由此得到：

Rof=Ro/(1+AF)　（电压反馈）
Rof=(1+AF)Ro　（电流反馈）
组态输入电阻输出电阻对应功能
电压串联增大减小电压放大
电压并联减小减小电流转电压
电流串联增大增大电压转电流
电流并联减小增大电流放大

求实际输出电阻仍是第二章那套方法：独立输入源置零，负载取下，在指定输出端加测试源，算 Ut/It；反馈和受控源必须保留。若环外还有并联电阻，最后再并联它，不能把整机每只电阻都乘上反馈深度。

这里“带负载能力增强”在通常的电压放大语境中，是输出电压不易因接负载而下降，即输出电阻减小。它不等于运放的最大允许输出电流凭空增大。

5.5.3 展宽频带：用增益换带宽，但有条件

沿用第四章的一阶高频模型 A(f)=Am/[1+j(f/fH)]，取 F 为实数常量。直接代进一般式：

Af(f)=Am/[1+AmF+j(f/fH)]
= [Am/(1+AmF)]/{1+j[f/((1+AmF)fH)]}

所以中频增益降低，上限截止频率提高。对相应的一阶低频模型可同样得到：

fHf=(1+AmF)fH
fLf=fL/(1+AmF)

图用 Am=1000、fH=1 kHz、F=0.009，反馈深度为 10：中频从 60 dB 降为 40 dB，上限从 1 kHz 升为 10 kHz。两个 −3 dB 点分别相对各自的平台测量，不能一直拿原来 60 dB 的平台作标准。

这些等式建立在纯电阻反馈、一阶主导响应等前提下。多极点电路会出现峰化、相位裕度不足甚至振荡；那时不能直接把“展宽十倍”当作无条件答案。频率升高后 A 变小、反馈变浅，也解释了为什么高频时精密增益开始失准。

5.5.4 减小失真：纠正环内产生的误差

假设放大电路本身使正半周放得太大。这个偏大的输出也被返回输入，并从输入中减掉，于是内部净输入的正半周被压小，抵消原来过大的放大量。内部净输入可能不再是漂亮的正弦波，而外部输出反而更接近正弦，这并不矛盾。

输出端加入的误差 d，经反馈后的输出误差≈d/(1+AF)

比较失真改善时，应保持输出基波幅度相当；闭环增益变小后，通常要把输入适当增大再比较。否则只因输出变小、工作更接近小信号区，就把改善全部算给反馈，会混淆原因。

已经混在输入信号中的失真或干扰，会被电路当作输入一起放大，反馈不知道哪一部分是你想要的。发生在反馈取样点之后、没有被采到的误差，也不在这一补偿范围内。

还要注意谐波所在频率：抑制第 n 次谐波，依赖的是该谐波频率处的环路增益。不能用很大的直流 AF 去保证所有高频失真都能同样下降。严重饱和、截止或压摆率限制也不能靠这条线性公式“修回来”。

5.5.5 设计反馈：先选功能，再接线验证极性

要求“输入电阻高”选串联，要求“输入电阻低”选并联；要求“稳定输出电压”选电压取样，要求“稳定输出电流”选电流取样。两组条件组合，就确定组态。然后寻找合适的输入、输出节点，最后完整绕一圈验证确实为负反馈。

图为原题端子的重排示意，差分前级与输出级分上下画，端子编号不变。⑦在输出管发射极电阻一侧，用于电流取样；⑧在集电极输出端，用于电压取样。各电源标记对应同一供电，⑨、⑩之间是待接入的反馈电阻。

教材例 5.5.1 是连线题。按原图端子编号：增大输入电阻并增强电压带负载能力，接④—⑥、③—⑨、⑧—⑩；输入电流控制输出电流，接④—⑥、⑦—⑩、②—⑨；输入电流控制输出电压，接⑤—⑥、②—⑨、⑧—⑩。

不必死背端子号。第一组是“输出电压返回差分另一输入端”；第二组是“输出管的电流取样返回输入求和节点”；第三组是“最终输出电压返回求和节点”。选择不同的前级集电极驱动后级，是为了改变正向通道极性，使返回作用抵消输入。

同一张基本放大电路不一定能只换一根线就实现任意组态。尤其不要把反馈接到理想恒流源尾端后，就以为能改变差模输入；必须检查该节点的电位变化究竟如何影响两管的净输入。

练习：传感器近似输出电流，希望送给后级一个稳定电压，选什么？

电压并联负反馈。输入端低阻有利于接收传感电流；输出端低阻有利于提供稳定电压。典型电路就是前面的跨阻放大器，uo≈−iiRf。

5.6.1 为什么负反馈会振荡：回来的信号晚了半圈

中频时，返回量从输入中减去，起纠正作用。第四章已经说明，电容会产生相位变化。若绕环路的附加相移达到 −180°，返回量相对中频翻了方向：原本的“减”变成实际的“加”。一个很小的扰动绕一圈回来，可能被进一步放大。

定义 T(f)=A(f)F(f)。本页使用输入减反馈的约定，因此临界平衡条件为：

1+T(f0)=0
T(f0)=−1
|T(f0)|=1，∠T(f0)=−180°（或等价奇数倍 180°）

相位条件说明“回来变成加强”，幅值条件说明“绕一圈刚好维持”。若相位满足时小信号环路幅值大于 1，扰动可增长；实际电路最终会被非线性限制幅度。线性小信号模型能判断稳定性趋势，却不能单靠 |T|=1 算出最终振幅。

这就是为什么改输入幅度通常不能消除自激振荡：振荡由电路自身环路决定，无输入也能由噪声或上电扰动激发。要改变电路的环路增益或相位条件。

5.6.2 级数越多为何越危险：数的是有效极点

在直接耦合、纯电阻反馈、每级只有一个有效高频极点的教材简化模型下：一级最多滞后 90°；两级只在频率趋于无穷大时趋向 180°，此时增益趋零；三级能在有限频率达到 180°，而增益还不一定小于 1，所以可能不稳定。

真正决定相位积累的是环路的极点、零点和延时，不是三极管只数。一只实际运放内部就有多级；外接电容负载还会增加极点。“两级电路永不振荡”只能在刚才的简化条件下说，不能拿去套所有实际电路。

低频同样可能因多个耦合、旁路环节积累相移。采用直接耦合可避免这些低频耦合极点，但不会自动消除高频稳定性问题。反馈深度增加，通常使环路 0 dB 交越点移向更高频，也更容易进入相位滞后较大的区域。

5.6.3 波特图判稳：先找两个频率，再谈裕度

按教材常见的稳定开环、单次交越、低通环路模型，定义 f0 为环路相位达到 −180° 的频率，fc 为 |AF|=1 即 0 dB 的交越频率。

  1. 先在相频图找到 −180°，向上读同频率的幅值。
  2. 若该处 20lg|AF|<0 dB，返回的扰动每绕一圈都缩小；若大于 0 dB，存在失稳风险并按本章模型判不稳定。
  3. 等价地，通常 fc<f0 为稳定，f0<fc 为不稳定。相等为临界，不能当作“可靠稳定”。

图中环路模型为 T=T0/(1+jf/1 kHz)³。T0=4 时，在相位 −180° 的 f0=√3 kHz 处幅值为 0.5，即 −6.02 dB；T0=20 时，同一处幅值为 2.5，即 +7.96 dB。极点没换，只把环路放大能力提高，稳定性就变了。

相位裕度 φm = 180°+∠T(fc)
本教材的幅值裕度 Gm = 20lg|T(f0)|

特别留意教材的符号：这里稳定时 Gm 为负，课本的可靠性参考是 Gm≤−10 dB 且 φm>45°。不少控制教材把“增益裕度”定义成相反数，稳定时记正值。本章作业按本书定义，不要把 −10 dB 改填 +10 dB。

T0=4 的例子虽然稳定，但相位裕度只有约 27.1°、Gm=−6 dB，未达到本书给的两个参考要求。不振荡与有足够裕度是两档要求。若环路有右半平面极点、多个交越或显著延时，需要更完整的稳定性判据，简单比较这两个频率不够。

5.6.4 消振：让增益先降下来，或把相位往前拉

简单滞后补偿：在产生最低高频转折的节点加对地电容，使该极点提前，环路更早下降到 0 dB，避免在幅值还很大时积累到 −180°。它通过牺牲带宽换稳定性。

补偿前 fH1=1/[2π(Ro前∥Ri后)Ci]
补偿后 f′H1=1/[2π(Ro前∥Ri后)(Ci+C)]

RC 滞后补偿：用串联 RC 支路代替单电容，除降低一个极点外还能引入零点，适当选参数时可抵消或缓和另一个极点的影响，比简单加电容少损失一些带宽。它不是“随便串一个电阻就一定好”，仍要看补偿后的环路曲线。

密勒补偿：把小电容跨接在反相放大级输入与输出之间，输入侧等效电容约为 (1−K)C。例如 K=−100、C=20 pF，等效约 2020 pF，课本按 2000 pF 估算。第四章中拖慢速度的密勒效应，在这里被用来制造主极点。

例 5.6.1 特别问：同一个 40 pF 电容，普通对地接法与密勒接法都能消振，通常选哪个？按题设通常选对地接法，因为密勒把等效电容放大很多，可能造成不必要的带宽损失。若普通接法容量不够、无法消振，密勒接法才有它的优势，正对应习题 5.15。

超前补偿：在反馈上臂 R2 并联 C，令 F 本身在一定频段提供相位超前：

F(s) = [R1/(R1+R2)]·(1+sR2C)/[1+s(R1∥R2)C]
fz=1/(2πR2C)，fp=1/[2π(R1∥R2)C]，fz<fp

零点先到、极点后到，中间一段得到正的附加相移。有限电阻比下最大相位超前小于 90°，课本图的 90° 是近似极限示意，不能当任意网络的精确数值。基础考试先掌握“补在哪、破坏哪个条件、代价是什么”，具体补偿器综合并非本章首要任务。

5.6.5 运放补偿与例 5.6.2：低开环带宽不等于不能放大音频

运放内部开环增益很大，主极点可能很低；闭环后，增益降低而可用带宽扩大。对于主极点占优、已补偿的电压反馈运放，闭环带宽可粗略按单位增益频率除以噪声增益估算。同相放大器的噪声增益为 1+R2/R1；反相放大器为 1+Rf/Rs，不是只取信号增益 |−Rf/Rs|。

这里讲噪声增益，是为了防止把第四章的增益带宽关系套错反馈回路；本章基础题通常仍按给定的 A、F 算。不能由“理想运放带宽无穷大”推断实际运放没有相位问题。

例 5.6.2 的折线在 10 Hz 后以 −20 dB/十倍频下降，在 1 kHz 后变成 −60 dB/十倍频，意味着 1 kHz 叠着两个极点。在该处，第一个极点近似贡献 −90°，另两个各贡献 −45°，总相位约 −180°；图上的增益约 60 dB。

20lg|AF|≈60+20lg|F|<0
⇒20lg|F|<−60 dB ⇒ |F|<0.001

F=1 时显然不稳定。上述 0.001 是按题给折线读数得到的保守估算，不是把三个极点精确计算后的严格临界值。若题目给的是解析表达式，应直接计算对应相位处的实际幅值，习题 5.12 会示范这个区别。

5.7.1 正反馈也有用途：Howland 电流源怎样消去负载影响

进阶选学：先熟练四种基本组态和普通恒流电路，再看这一节。它的用途是回答“负载必须有一端接地，怎样仍得到稳定电流”，不是要求你背一大段代数。

图中 R2 返回反相端，R3 又把输出接到同相端所在节点 P，既有负反馈也有正反馈。以图中向下的 io 为正，在稳定线性工作条件下，令 uN=uP=v，两个输入端都不吸电流。

N 点：(ui−v)/R1 = (v−ua)/R2
P 点：(ua−v)/R3 = v/R+io

这里用 ua 表示运放输出脚电压，避免与负载电压 v 混淆。由第一行得 ua=(1+R2/R1)v−(R2/R1)ui，代入第二行：

io = [R2/(R1R3)−1/R]v − [R2/(R1R3)]ui

要让输出电流不随负载电压 v 改变，就让 v 的系数为零：

R2/R1 = R3/R ⇒ io=−ui/R

这时理想输出电阻趋于无穷大。电阻比失配会留下 v 项，恒流特性就变差；实际输出摆幅、供电和稳定性也仍有限制。正反馈在这里用来抵消负载依赖，不代表电路可以不顾反馈强弱随意工作。

5.7.2 自举：让电阻两端一起动，信号电流就变小

若一只 R 一端接输入 ui，另一端固定接地，它索取的信号电流为 ui/R。现在让另一端跟着输入变成 K ui，则：

iR=(ui−Kui)/R=(1−K)ui/R
R等效=ui/iR=R/(1−K)

K=0.99、R=10 kΩ 时，从信号源看来这条支路像 1 MΩ。电阻本身没有变成 1 MΩ；只是它两端一起抬高，差值变小，信号源不用再供那么多电流。

教材图 5.7.2 用电容把跟随电位送到偏置电阻另一端。直流时电容开路，偏置仍能建立；交流时两端近似跟随，输入电阻提高。这是交流正反馈的有益用法。K 还会随频率变化，因此“无穷大输入电阻”只是理想模型的极限，不是每个频率都能实现。

习题 5.16 的射极跟随器做的是同一件事：用射极电压经 C2 抬高 R3 的偏置端。你只需能指出这条通路、写出 R3 两端的交流电压差，并说明输入电流因此减小。

5.2 性能填空：把六个答案压成两对关系

原题 A=电压、B=电流、C=串联、D=并联。六空依次是 A、B、C、D、B、A：稳输出电压用电压反馈，稳输出电流用电流反馈；增输入电阻用串联，减输入电阻用并联；增输出电阻用电流，减输出电阻用电压。

5.3 四个判断题：把错误的因果关系拆开

(1)“只能引入负反馈”不对。自举可以利用适量正反馈提高输入电阻，Howland 电流源也利用匹配的正、负反馈。正反馈不自动等于错误接法。

(2)“越强一定越稳定”不对。中频增益对器件参数的敏感性可能下降，但动态稳定性可能变差，甚至自激。这两种“稳定”不是同一个指标；还需假设反馈网络本身稳定、误差小。

(3)“R3 上的实际电压全部是反馈电压”不对。图 T5.2(d) 中，它同时包含本级输入引起的发射极电流作用与输出经 R7 返回的作用。反馈量只取后一分量。这一题不需要精算所有支路，说明叠加来源即可。

(4)“电压、电流反馈没区别”不对。若 RL 改变，恒压输出对应电流随之改变，恒流输出对应电压随之改变。只有在负载电阻固定时，稳住其中一个才会由 u=iR 同时约束另一个；题目讨论的恰好包括负载变化。

(b)电压串联输出分压与输入在两栅极间比较
(e)电流并联第二管电流被 R1、R2 分流，返回输入节点
(f)电流串联第三管发射极电流经 R4、R2 形成返回电压，改变 uBE1

配套答案重点列出上述四张，刚好对应四种组态。但它没有逐项补全 (c)、(d)，读题时不该因此认定它们没有交流负反馈。

(c) 的源极电阻局部负反馈可按电流串联理解：源极电流的变化在等效源极电阻上形成电压，与栅极输入求差；并存的自举支路仍属正反馈，不能把两个环合为一个名称。(d) 经 R4 引入电压并联总体负反馈：输出短路使由输出产生的返回量消失，输入在基极节点以电流混合。以上是根据原图对答案遗漏项目的补充。

5.8 理想运放计算：五张图，只需虚短、虚断和一个节点方程

P5.4(d)：A1 反相端接地，总体负反馈使同相输入节点也近似为零；运放不取电流，输入 R1 的电流只能经负载流向 A2 输出。因此：

io=ui/R1，uo=ioRL
Auf=RL/R1

uo 的正端在负载上端、负端在 A2 输出；正输入时 A2 输出对地为负，所以这个跨负载增益为正。直接把运放输出脚对地电压当成题给 uo，会错一个负号。

(e)：交流时输入电容短路，uP=uN=ui。R1 电流 ui/R1 继续通过 R3，所以 Auf=1+R3/R1。R2 在同相端到地，影响输入加载，不决定理想运放端口间的闭环电压增益。

(f)：交流 C 短路，把输出直接接到反相端，uo=uN=uP=ui，故 Auf=1。直流增益仍由电阻分压决定，两种频段不能混用。

(g)：返回分压为 R1/(R1+R2)，外围 PNP 管在环内；Auf=1+R2/R1。不能再把它的电压增益额外乘一次。

(h)：反馈使对称差分前级的两栅极电位近似相等，返回端分压为 R1/(R1+R3)；忽略栅极电流，Auf≈1+R3/R1。这里还用到了差分前级对称、正常工作和总体环路增益足够大的假设；并不是只写“后级运放理想”就能省掉所有前级条件。

5.9 分立元件计算：先把被稳定的电流找准

P5.5(a)：电压并联，输入与反馈电流近似相等；净输入端电位相对信号源压降很小。

F=−1/Rf，uo/ii≈−Rf
Ausf≈−Rf/Rs

配套书此处的一行把 F 写成 −Rf，下一页却正确使用 −Rf/Rs；按 F=if/uo 的定义，前一行应是 −1/Rf。单位也能检出这个倒数错误。

(b)：电压串联，F=R1/(R1+R4)，故 Auf≈1+R4/R1。左右输入端串接的 R1 不能凭“同编号”随意合并；要找反馈下臂那一只。

(e)：按教材参考方向，第二管输出电流在 R1、R2 中分流，返回比例为 R2/(R1+R2)；最终电压取发射极负载。

F≈R2/(R1+R2)
R′L=R4∥RL
Ausf≈(1+R1/R2)R′L/Rs

这里将集电极、发射极电流近似相等，忽略基极电流。第一管为共基极，第二管为跟随，所以输出相对输入同相，结果正号可作独立检查。

(f)：不急着记带负号的 F，先从实际第三管电流变化列式。发射极电流经 R9 与 R4+R2 分流，在 R2 上得到返回电压：

uf≈ΔiC3·R2R9/(R2+R4+R9)
ui≈uf
uo≈−ΔiC3(R7∥R8∥RL)
Auf≈−(R2+R4+R9)(R7∥R8∥RL)/(R2R9)

输出集电极电流增大使集电极电位下降，这一行明确给出负号。若按辅导书把输出电流参考方向另作规定，就得到它写的 F=−R2R9/(R2+R4+R9)，最终电压增益相同。R7 不能漏：C2 将其另一端交流接地，因此它也是输出负载的一部分。

5.10 故障题：不能把每种开路都代进 1+R2/R1

正常时为电压串联负反馈，理想输入电阻趋于无穷大，Auf=1+100/10=11。ui=1 V，所需输出 11 V，没有超过 ±14 V，线性解成立。

状态（每次只改变一处）重新读图uo
R1 开路反相端只经 R2 接输出，输入不取电流使 R2 无压降，成为跟随器1 V
R1 短路反相端被固定为 0 V；输出无法再调它。差模输入为正+14 V
R2 开路输出返回断开，反相端仍经 R1 接地，差模输入为正+14 V
R2 短路输出直接返回反相端，跟随器1 V

比如 R1 短路时，盲代公式会给“无穷大增益”；真正要回答的是运放已饱和，输出由题给上限限制为 +14 V。题目问输出电压，不是让你把无穷大写进空格。

5.11 增益与稳定性一起设计：先求反馈深度

开环相对变化 1%，闭环允许相对变化 0.01%，改善因子为 100。注意 1%/0.01%=100，百分号会相消。

1+AF = 100
Af=A/(1+AF)=20 ⇒ A=2000
AF=99 ⇒ F=99/2000=0.0495

这是一阶灵敏度要求下保留分母“1”的结果。配套书按深度负反馈近似用 AF≈100、F≈1/20=0.05、A≈2000，也是本章通常接受的工程近似；不要把两套精度混着说成完全相等。

按教材近似方案，反馈下臂 10 kΩ、上臂 190 kΩ，理想闭环增益 20。若要在有限 A=2000 的模型中严格得到 20，则 F=0.0495，10 kΩ 下臂对应上臂约 192.02 kΩ。用 190 kΩ 时有限增益模型的闭环值是 2000/101≈19.802。

配套图还在同相端串 9.5 kΩ，约等于 10 kΩ∥190 kΩ，用于实际双极型输入运放的偏置电流平衡；理想输入电流为零时，它不改变电压增益。题目的得分主线是反馈深度、F、A 和电阻比，先把这四个算对。

5.12 解析式判稳：课本近似与严格临界值分别写清

A(f)=10⁴/{[1+j(f/10⁴)][1+j(f/10⁵)]²}

先假设 F 为不引入附加相移的实数负反馈系数。开环中频 80 dB，有 10⁴ Hz 一个极点、10⁵ Hz 两个重合极点。按配套书近似，在 10⁵ Hz 总相移约 −180°，实际幅值约 80−20−3−3=54 dB，所以得到 |F| 约应小于 0.002。

这个近似用于本章练习可接受，但表达式既已给全，可以进一步核对。令 x=f/10⁵，则分母为 (1+j10x)(1+jx)²。它的虚部为 12x−10x³；要使 A 为负实数，令虚部为零且取正频率：

x²=1.2 ⇒ f0=√1.2×10⁵≈109.54 kHz
分母实部=1−21x²=−24.2
|A(f0)|=10⁴/24.2≈413.22（52.32 dB）
F临界=24.2/10⁴=0.00242

对这个三实极点、实数正 F 的模型，稳定范围为 0≤F<0.00242；等号临界。配套书的 0.002 更保守，区别来自将 −180° 近似放在 100 kHz。考试若按教材估算，写清“近似 0.002”；要求精确临界时，用 0.00242。不要把 54 dB 直接当成这个函数在准确相位交越点的值。

5.13 画四种电路：每张图都要能说出传输关系

本题要求的四张图已经在正文逐张绘出，可以直接从下面四个入口对照练习：

  1. 电流转电压：电压并联电路。输入电流送求和点，Rf 接输出与求和点，同相端接地；uo≈−Rfii。
  2. 电压转电流：电流串联电路。负载放在运放输出与取样 R 之间，返回取样节点；io≈ui/R。
  3. 高输入电阻、稳定输出电压：电压串联电路。输入接同相端，输出分压接反相端；Auf≈1+R2/R1。
  4. 低输入电阻、稳定输出电流：电流并联电路。负载放在返回环内，R1、R2 分流；按本页参考箭头，Aif≈−(1+R1/R2)。

作图后一定补地、输入参考端、输出电压正负或电流箭头。尤其是两种电流输出电路，负载不一定接地；少画一个节点，就可能把恒流电路变成恒压电路。

5.14 设计恒流输出：为什么答案不是简单的 500 Ω

要求输入电压控制负载电流，选电流串联负反馈。从输出晶体管发射极经新加 Rf 返回差分对 T2 的栅极。输入升高使输出电流升高，返回栅极电压升高后减小差分输入，极性正确。

只抽出反馈网络：T2 栅极经 R1=10 kΩ 接地，输出管发射极经 R6=1.5 kΩ 接地，二者之间为 Rf。输出管发射极电流在 R6 与 Rf+R1 两条支路分流。

F≈uf/iL=R1R6/(R1+Rf+R6)
iL/ui≈1/F=10 mA/5 V=2 mS
F=500 Ω=0.5 kΩ
10×1.5/(10+Rf+1.5)=0.5（电阻统一用 kΩ）
Rf=18.5 kΩ

500 Ω 是整个反馈网络的等效“电流转电压系数”，不是新加电阻 Rf。这一题就是检查你会不会把分流和分压都保留下来。沿用题解近似，忽略输出管基极电流；实际实现还要留足负载与管子的电压余量。

5.15 判振与消振：看的是 AF，不要再乘一次 F

原图纵轴已经是 20lg|AF|。三个转折分别在 10³、10⁴、10⁵ Hz，低频平台 100 dB。10⁴ Hz 附近相移约 −135°，10⁵ Hz 附近约 −225°，因此 −180° 出现在它们之间；这一区间环路幅值仍明显高于 0 dB，按题设模型判断会失稳并可能形成自激振荡。

图中蓝线采用与原折线相符的三个一阶极点重建计算曲线，橙线为幅频渐近线。它把“相位在哪一段达到 −180°”与“同频率增益是否大于 1”放在同一横轴上，避免看错频率。

配套答案给出一种接法：在 T2 基极与地之间加补偿电容，利用前级输出电阻与该电容形成更低的主极点。具体容量须使补偿后的环路满足稳定裕度要求，题目没有要求计算容量。

若唯一的 50 pF 电容分别接各管基极与地都不足以消振，可以尝试跨在 T2 基极与集电极之间，借助密勒效应增大输入等效电容。T2 虽为 PNP，其共射电压级仍反相。这里只能说“有可能消振”，不能在没有增益、节点电阻数据时保证一定足够。

原配套文字有“|AF|>0”一类简写；判振需要的是 |AF|>1，或者 20lg|AF|>0 dB。两种表达不要漏掉对数或单位。

5.16 自举电路：把 C2 和 R3 找出来

这是射极跟随器。没有自举时，基极偏置支路要从输入索取交流电流。加 C2 后，在题设“电容交流短路”的频段，R3 的偏置端 A 跟着发射极走；基极电位升高，发射极也升高，R3 两端电压差远小于基极对地电压。

iR3≈(uB−uE)/R3
若 K=uE/uB，则 R′3=R3/(1−K)

所以 C2、R3 引入自举正反馈，提高输入电阻，减轻信号源加载，使整个电路的跟随效果改善。射极跟随器本身仍有电压串联负反馈；正反馈作用于偏置支路，不能据此把整个电路一概叫正反馈放大器。

C1 是输入耦合，C3 是输出耦合，它们不是这道题要找的自举电容。做题画箭头时，重点标出“发射极经 C2 到偏置中点，再经 R3 回基极”。

5.17 原图与答案不一致：先把这个坑挑明

这一题不能直接照配套答案套虚短。教材要求使用图 P5.4(b)，但该图 A1 的上端是“＋”、下端是“−”，A2 是反相级。因此总体是正反馈，5.4 的配套解答也明确这样判断。5.17 的配套解答却把同一电路称为电压串联负反馈，给出正常输出 11 V，两处前提冲突。

对本页已重绘的原图，设 ui=1 V、R1=10 kΩ、R2=100 kΩ。若输出为 +14 V，返回电位为 14/11≈1.273 V，A1 输出负饱和，经 A2 反相得到 +14 V，这个状态能自洽。若输出为 −14 V，返回为 −1.273 V，A1 正饱和，A2 输出 −14 V，也能自洽。因此原图不能唯一得到稳定的 11 V，饱和状态与初始条件有关。

修改版的正常线性功能可用5.10 那张单运放同相放大器实现，R1=10 kΩ、R2=100 kΩ。原正反馈图则不能等价成这个线性放大器。做作业时应注明使用的图或更正条件；这一处疑点不值得你反复怀疑自己的“虚短”知识。

5.18 测穿透电流：把几乎看不见的电流变成电压

NPN 管基极开路，集电极接 +VCC，发射极接运放反相求和节点。穿透电流 ICEO 流入节点，运放通过反馈电阻 R 将它转换成输出电压。输出电压经 R 返回求和点，是电压并联负反馈。

理想时 uN≈0，iN≈0
ICEO=(uN−uo)/R≈−uo/R
uo≈−ICEOR

例如 R=1 MΩ，输出 −0.20 V，则被测电流约 0.20 μA。输出为负正好能把从晶体管流入节点的电流经 R 拉走，这是参考方向的检查。

实际测微小电流时，输入偏置电流、失调、漏电会进入误差。保留偏置电流时 KCL 应写 ICEO=iN+(uN−uo)/R；仅测 R 两端电压不能自动消除 iN 的误差。课本建议选高输入阻抗、高精度运放，就是为了让这些误差足够小。

本题最重要的迁移是：前面的“电压并联”并非只用于普通电压放大，它天然适合小电流检测。掌握 KCL 和跨阻关系，就理解了测量原理。
