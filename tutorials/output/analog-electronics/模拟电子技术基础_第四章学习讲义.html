4.1.1 为什么原来算出的增益突然不够用了

第二、三章的计算常把耦合、旁路电容当成短路，把管内很小的电容当成开路。两种处理看似矛盾，其实都在比较容抗与周围电阻。电容的容抗大小为：

|ZC| = 1/(2πfC)

同一只电容，f 越低，容抗越大；f 越高，容抗越小。外接耦合电容往往较大，中频时已经很容易通过交流；管内结电容很小，中频时几乎不分流。因此存在一个频段，两类电容都可以作刚才的简化，这才叫中频段。它不是固定的“音频”或某个通用频率范围。

到了低频，耦合电容容抗变大，信号在它上面分掉的电压变多；到了高频，结电容容抗变小，原本能控制管子的信号电流被分走。前者让信号不容易传到下一级，后者让控制电压难以建立，两者都可能使增益下降。

这还会引起相位变化。比如输入正弦波正在过零，输出可能已经过零，也可能尚未过零。频率响应同时回答“放大几倍”和“提前或落后多少角度”，所以必须分成幅频特性与相频特性。

它为什么与做题有关：复合波形包含不同频率的分量。如果各分量得到的幅度比例或相对时序改变，输出形状就会变。即使晶体管一直在放大区，也可能出现频率失真。这与第二章大信号导致的截止、饱和削顶是两种原因，不能用同一个办法处理。

自测：把输入幅度减小，频率失真一定消失吗？

不一定。减小幅度可避免大信号非线性失真，但线性电路的频率响应仍然存在。要使所需波形得到近似无失真放大，需要其主要频率分量落在合适的幅频、相频范围内。严格说，相位不必全为零；与频率成正比的相位对应共同的时间延迟，也不改变波形形状。

4.1.1—4.1.2 之间补一座桥 · 必会

电容的电流箭头，最后要落到哪条式子上

对电容先规定两端电压 uC 的正负，再把电流 iC 的正方向指向电压的正端。这样采用的是关联参考方向，关系为：

iC(t) = C · duC(t)/dt
uC(t) = UCm sin(ωt)
⇒ iC(t) = ωCUCm sin(ωt + 90°)

这三行已经说明两件事。第一，在电容两端电压幅值相同时，频率越高，所需电流越大。第二，电容电流比电容电压超前 90°。箭头只是统一正负号：瞬时电流算成负数，就表示实际方向与所画箭头相反。你不用沿着箭头去猜电子的运动轨迹。

还要防止一句话被用错：接进实际电路以后，电容两端的电压也会随频率改变，所以不能只盯着 iC 的式子就断言整条支路电流一定无限增大。后面 RC 低通中，高频电流会受到串联电阻限制。

为什么公式里出现 j？

在正弦稳态下，电压、电流都以同一个频率变化。我们把每个正弦量的“幅值和起始相位”打包成一个复数，叫相量。本页用大写 U、I 表示相量。j 满足 j²=−1；乘以 j 表示相位增加 90°，它不是一个新的电路元件。

IC = jωCUC
ZC = UC/IC = 1/(jωC) = −j/(ωC)
电阻：ZR = R； 电容：|ZC| = 1/(ωC)

因此，电阻 R 和电容串联时，总阻抗是 R−j/(ωC)。它既有实部，又有虚部；总阻抗的模不能写成 R＋1/(ωC)。你以前在纯电阻电路里直接相加，是因为各电压同相；现在相位不同，必须先做相量相加。

自编小题：R=1 kΩ，容抗大小也为 1 kΩ，输出取 R。是分到一半吗？

不是。H=1000/(1000−j1000)=(1+j)/2。实部和虚部各为 0.5，不代表幅值为 0.5；|H|=√(0.5²＋0.5²)=0.707，相位为 +45°。输入峰值为 1 V 时，输出峰值约 0.707 V。错解 1000/(1000＋1000)=0.5 把两个不同相位的压降当成同相了。

到什么程度就够：会用 |a+jb|=√(a²+b²)，会在简单的一阶式子中求相角；有反相负号时单独计入 180°。不用先把复变函数整章重学一遍。接下来仍然用你熟悉的分压，只把电阻换成阻抗。

4.1.2 高通：输出取电阻两端，低频被挡住

先把三极管拿开，只分析教材图 4.1.1 的 RC 网络。图上电流箭头规定从输入流向 R；电压上正下负。箭头的用途是帮你写出同一条回路的分压式，不是要求你想象电子怎样绕圈。

输入电压等于电容压降与电阻压降之和；输出恰好就是电阻上的压降。串联电流相同，所以用阻抗分压：

HHP(f) = Uo/Ui = R/[R+1/(jωC)]
= jωRC/(1+jωRC)
fL = 1/(2πRC)
HHP(f) = j(f/fL)/[1+j(f/fL)]

别急着记。先代两种极端：f→0，电容近似断开，R 中几乎无电流，输出趋于零；f 很高，电容近似导线，输出接近输入。由电路就能检查公式有没有写反。

复数公式怎样变成幅值？复数 1+jx 的模是 √(1+x²)，相角是 arctan x；分子 jx 的模是 x、相角是 +90°。相除时模相除、角相减，因此：

|HHP| = (f/fL)/√[1+(f/fL)²]
φHP = 90°−arctan(f/fL) = arctan(fL/f)
频率输出/输入幅值输出相位应怎样理解
0.1fL约 0.0995约 +84.3°严重衰减，近似 +90°
fL1/√2≈0.707+45°一阶高通的截止点
10fL约 0.995约 +5.7°近似通过，仍非严格零相移

“截止”不表示信号变成零，也不表示管子进入截止区。它只是选定的性能边界：幅度降到通带参考值的 0.707。R=10 kΩ、C=0.1 μF 时，RC=1 ms，fL≈159 Hz；不是 1 kHz，后者漏掉了 2π。

最低要求：给出 R、C 会求 fL；给出 f 会算幅值和相位；知道增大 C 会降低下限，让更低频率通过。

4.1.2 低通：输出取电容两端，高频被分走

元件仍然是 R 和 C，但输出改取 C 两端，结论就反过来了。高通还是低通由连接和取样位置决定，不由“电路里有一个电容”决定。

HLP(f) = [1/(jωC)]/[R+1/(jωC)] = 1/(1+jωRC)
fH = 1/(2πRC)
HLP(f) = 1/[1+j(f/fH)]
|HLP| = 1/√[1+(f/fH)²]
φLP = −arctan(f/fH)

低频时电容电流很小，R 上压降小，输出接近输入；高频时电容容易把电流引向参考地，输出节点难以建立电压。图中向下的 iC 表示输出节点流向电容的参考电流，方程就是 iC=jωCUo。频率越高，相同输出电压需要越大的电流，信号源经过 R 供不上，输出便下降。

在 f=fH 时，幅值为通带的 0.707，相位为 −45°；在 10fH 时，幅值约 0.0995，相位约 −84.3°。这一对“高通 +45°、低通 −45°”是一阶单个环节的截止点性质，不要推广成任何多级电路在截止处都恰好 ±45°。

一个普通带通型放大器有下限 fL 和上限 fH，通频带宽度 fbw=fH−fL。只有 fH远大于 fL 时，才可写 fbw≈fH。直接耦合放大器可以把直流放大，通常取 fL=0。

自测：R=2 kΩ、C=1 nF，求上限；频率为上限两倍时，幅度和相位是多少？

RC=2 μs，fH≈79.6 kHz。f/fH=2，故 |H|=1/√5≈0.447，φ=−arctan 2≈−63.4°。幅度已经低于 0.707；不要仍按“过了拐点就固定为 −45°”处理。

单个正弦通过线性时不变电路，稳态输出仍是同频率正弦。这里讲的频率失真，主要是说含有多个频率分量的波形，各分量的相对幅度或延时发生了改变。单个正弦变小、平移，不等于出现削顶或冒出新的谐波。

“高通输出超前”也不是电路预知未来。它说的是持续正弦信号达到稳态以后，两个周期波形的相位关系；不能把它读成任意突变都能提前到达输出。

4.1.3 波特图：把乘法变成加法，把宽频率范围压进一张图

如果横轴等距画 1 Hz、2 Hz、3 Hz，就几乎没法同时放下 1 MHz。波特图改为每乘 10 占同样的横向距离，所以 1→10 和 10→100 的图上距离相同。纵轴的电压增益写成：

GdB = 20 log10|A|
|A| = 10GdB/20

常用对应关系：1 倍是 0 dB，10 倍是 20 dB，100 倍是 40 dB，1000 倍是 60 dB，10⁵ 倍是 100 dB。−100 倍也是 40 dB，反相信息去相频图里表达。分贝公式中的绝对值不能漏。

幅度下降为原来的 1/√2，对应变化 20lg(1/√2)≈−3.01 dB。因此中频增益为 40 dB 的放大器，截止处约是 37 dB，而不是纵坐标 −3 dB。只有把通带归一化为 0 dB，截止点才画在 −3 dB。

蓝线由复数表达式计算，虚线是做题常画的折线。高通在 f<fL 的低频一侧，|H|≈f/fL：频率乘 10，幅值乘 10，增益加 20 dB，所以斜率为 +20 dB/十倍频。低通在 f>fH 一侧，|H|≈fH/f，斜率为 −20 dB/十倍频。

折线在拐点相交时并没有下降 3 dB，真正曲线才比通带下降约 3 dB。题目说“近似波特图”，画折线并标拐点；题目要该频率的准确增益，就代幅值公式。不要拿折线去否定截止定义。

相频折线可以这样记：变化主要发生在 0.1fc 到 10fc 的两个十倍频程中，中心 fc 走到一半。低通从 0°走向 −90°；高通从 +90°走向 0°。端点以外取常数是画图近似，实际曲线是渐近的。

做题优先级：必须会分贝换算、找拐点、按每个一阶因子累加 ±20 dB 斜率；相频要会确定方向和几个关键点。Bode 的人名历史只需知道名称，对计算没有额外要求。

4.1.3 · 三个必须分开的量

−3 dB、负增益、半功率，分别是什么意思

做题时把下面三句话分开，很多“看懂了但算不对”的错误会直接消失。

说法实际含义不能推成什么
Au=−100幅值放大 100 倍，含一个反相负号不能说幅频增益是 −40 dB；其幅频增益是 +40 dB
增益下降 3 dB电压幅值变为参考值的约 0.708 倍；按标准半功率点精确取 1/√2，对应 −3.0103 dB不能说输出电压减半，更不能说信号消失
增益等于 0 dB|Au|=1不能说输出为零，也不能凭这一个数判断同相或反相

为什么又叫半功率点？对同一固定电阻负载，P=Urms²/R。电压降为原来的 1/√2，功率恰好变为原来的 1/2。这是在比较同一个输出负载在不同频率下得到的功率，不是在宣布整个放大器的输入、输出功率增益等于电压增益的平方。

Po/Pi = (Uo,rms/Ui,rms)² · Ri/RL
功率比的分贝：10 lg(Po/Pi)
电压比的分贝：20 lg|Uo/Ui|

上面功率关系适用于把输入、输出分别按纯电阻 Ri、RL 计算的情况。两端电阻不相等时，电压增益的 dB 数不能直接当成功率增益的 dB 数。本章幅频图纵轴明确画的是 20lg|Au|，照它的定义用即可。

自编小题：中频 Aum=−200，输入峰值 5 mV，在标准 −3 dB 截止处输出峰值多大？

中频输出峰值为 200×5 mV=1 V；截止处约为 1/√2 V=0.707 V。中频幅频增益 20lg200≈46.02 dB，截止处约 43.01 dB。此时相位需要看具体频率因子，不能只写“因为增益为负，所以在所有频率都恰好反相 180°”。

考场检查：幅频图先写绝对值；下降量相对中频参考值；反相信息另记入相位。题目不给输入幅值时，求出的只能是增益，不能凭空写出输出多少伏。

4.1.3 · 自编完整练习

把一个表达式真正画成图，再从图读回表达式

先做一个只有一个高频极点的反相放大器。给定：

Au(f) = −100 / [1 + j(f/1 kHz)]

第一步，读参考增益。f 很低时，分母近似为 1，因此幅值约 100，幅频图起点平台为 40 dB。第二步，读拐点。让 f/1 kHz=1，所以拐点为 1 kHz。第三步，定斜率。分母有一个一阶因子，拐点之后渐近线为 −20 dB/十倍频；10 kHz 处折线读 20 dB，100 kHz 处读 0 dB。

第四步，判断题目要近似图还是准确值。在 1 kHz，折线仍读 40 dB，真实值是 36.99 dB；在 10 kHz，真实值为 19.96 dB；在 100 kHz，真实值略小于 0 dB。离拐点远，折线好用；到了拐点不能把它当成精确值。

|Au| = 100 / √[1 + (f/1 kHz)²]
φ = −180° − arctan(f/1 kHz)
f = 1 kHz：|Au| ≈ 70.71，φ = −225°，等价于 +135°

选择 −180° 作为中频反相相位后，随频率升高继续往 −270° 变化，曲线就连续。−225° 和 +135° 相差 360°，表示同一个正弦相位；它们都包含反相与额外滞后，不能丢掉 −180°，只剩 −45° 就当成总相位。若题目只问“比中频多产生多少相移”，才回答 −45°。

自编反向题：已知一个电路确实是一阶低通，没有额外零点或纯延时。幅频渐近线低频平台为 60 dB，10 kHz 开始以 −20 dB/十倍频下降。求其表达式。

展开：怎样从图读回公式，以及图没有告诉你什么

先换算平台：10^(60/20)=1000。再读极点：10 kHz。于是可写 Au=σ·1000/[1+j(f/10 kHz)]，其中 σ=+1 或 −1，要靠接法或相频图确定。仅凭幅频图不能判定反相。题目若没限定“一阶、无额外环节”，更不能把同一幅值曲线唯一对应到这个表达式，因为额外全通环节或纯延时也会改变相位。

如果后来遇到两个分母一阶因子，每经过一个拐点，幅频渐近线的斜率再减少 20 dB/十倍频，两个因子的相位也要相加。这条规则先记住，多级电路在 4.5 里接着使用。

相量图里的箭头表示相位，不是电流流经的导线

思考 4.1.1 要用相量图说明两种 RC 电路的频率响应。选串联电流 I 为水平方向参考，电阻电压 UR 与 I 同相，电容电压 UC 比 I 落后 90°。把 UC 平移到 UR 的箭头端，就得到输入的矢量和 Ui=UR+UC。

思考 4.1.1：为什么高通输出超前，而低通输出滞后？

图中输入幅值归一化为 1。取 R 上电压为输出时，Uo=UR，它位于水平方向，角度大于向右下方的 Ui，所以输出超前。低频时 |UC| 很大、|UR| 很小，输出小而超前角接近 90°；频率增高后，|UR| 增大，输入逐渐转向水平，超前角趋近 0°。

取 C 上电压为输出时，Uo=UC，方向竖直向下，相角 −90°，比 Ui 的相角更小，所以输出滞后。低频时 Ui 几乎与 UC 重合，输出接近输入；高频时 |UC| 变小，Ui 逐渐水平，滞后角接近 −90°。在 f=fc 时，两条直角边等长，两个输出与输入的夹角分别为 +45°、−45°，幅值比均为 1/√2。

思考 4.1.2：100 dB 对应多大的电压放大倍数？

20lg|Au|=100，因此 lg|Au|=5，|Au|=10⁵=100000 倍。用 10lg 会错误地得到 10¹⁰。这里求出的是幅值；同相还是反相，还要看电路或相位信息。

这张图为什么值得会：它直接解释 0.707 和 ±45°，也能检查相位符号。如果考试只要求公式计算，不必画得像教材一样整齐；会画两条互相垂直的压降和它们的合成矢量，就已经能完成题意。

4.2.1 混合 π 模型：把高频时分走的电流画出来

第二章用 ic=βib。高频时，一部分外部基极电流流过结电容，已经不能全用来建立控制电压，所以 β 变成了与频率有关的复数量。教材改用内部发射结电压 ub′e 控制集电极电流，写作 ic=gmub′e。

b 是外部基极，b′ 是模型中的内部基区节点，并非多了一根可接线的引脚。rbb′ 表示基区体电阻，rb′e 表示发射结的小信号电阻。它们串起来才是第二章用的 rbe：

rbe = rbb′ + rb′e
rb′e = (β0+1)UT/IEQ = β0UT/ICQ
gm = β0/rb′e = ICQ/UT ≈ IEQ/UT

室温近似取 UT=26 mV。若 ICQ=1 mA、β0=100，则 gm≈38.5 mS，rb′e≈2.6 kΩ。若另给 rbb′=100 Ω，rbe 才是 2.7 kΩ。不能把两种电阻混成一个再到处代。

Cπ 是发射结等效电容，跨 b′、e；Cμ 是集电结电容，跨 b′、c。图中从 b′ 流向 Cπ 的支路电流不直接穿过 rb′e；外部输入电流要按节点方程分配。箭头的用处到这里十分具体：告诉你哪一项是输入，哪几项是分流，才能列 ib=ir+iCπ+iCμ。

完整物理模型还有一些很大的结电阻及输出电阻。教材在它们远大于相应外接电阻或电抗时将其略去。学习时要分两层：知道它们为什么存在；做基础计算会画并使用这里的简化模型。无需为每道入门题重新推导半导体内部物理，但也不能在题目明确给出有限输出电阻时擅自删去。

自测：rbe=2.1 kΩ、rbb′=100 Ω、β0=80，gm 是多少？

先减出 rb′e=2 kΩ，再算 gm=80/2000=0.04 S=40 mS。直接用 80/2100 会把体电阻也放进控制关系。

4.2.1 · 回答“这些电流指来指去有什么用”

在内部基极列一次 KCL，就知道为什么不能一直用常数 β

下面把模型中的电流单独标清。先看 b′ 节点：外部电流经过 rbb′ 到达这里，分别流入 rb′e、Cπ 和 Cμ。取 e 为交流参考地，令 Uπ=Ub′e，则：

Ib = Ir + ICπ + ICμ
Ir = Uπ/rb′e
ICπ = jωCπUπ
ICμ = jωCμ(Uπ−Uce)

受控源电流为 gmUπ，也等于 β0Ir。低频时两个电容支路电流很小，Ir≈Ib，才回到熟悉的 β0Ib。高频时外部输入电流还要供给电容支路，Ir 已经不等于 Ib，继续用常数 β0 乘全部 Ib 就会出错。

以上等式都是相量等式。不能把三条电流的幅值直接相加，因为它们未必同相。你可以把箭头理解成给每一项取名字、规定正负；真正的分析工作是这四行 KCL 和元件关系。

再分清一个细节：菱形源画的是“受控电流”gmUπ。在尚未单向化的完整高频网络中，集电极端口电流还受 Cμ 支路影响，不总与菱形源电流完全相同。后面的基础公式采用教材的简化模型，忽略较小的输出侧电容影响。极高频时不能把这个近似无限外推。

自编小题：为什么不直接拿 gm 乘整个基极电压 Ube？

gm 控制的是内部发射结电压 Ub′e。外部基极到内部 b′ 之间还有 rbb′ 的压降，因此 Ube=Ibrbb′+Ub′e。若这部分压降不能忽略，两种电压就不能混用。计算 gm=β0/rb′e 时，同样不能拿含 rbb′ 的 rbe 去代。

要学会的具体动作：给你一只管子，能把 b、b′、c、e 标出来；能把 Cπ 跨在 b′—e，把 Cμ 跨在 b′—c；能说清菱形源由哪一个电压控制。器件物理的作用是支持这个模型，不需要每次做题重推半导体方程。

4.2.1 密勒等效：几皮法为什么也能拖慢放大器

Cμ 麻烦在于它跨在输入、输出之间；输出一动，也会通过它影响输入电流。先看一个数字：内部输入 ub′e 增加 1 mV，反相增益 K=−100，输出便变化 −100 mV。电容两端变化量不是 1 mV，而是 1−(−100)=101 mV。

写成公式，就是电容两端的电压差。规定电容电流从输入流向输出：

K = Uce/Ub′e
ICμ = jωCμ(Ub′e−Uce)
= jω[(1−K)Cμ]Ub′e

从输入端看，它取走的电流等于一个接地电容 C′μ=(1−K)Cμ 取走的电流。这就是等效的依据。并不是元件实际变大了，而是输出反向运动，增大了跨接电容两端的电压变化。

C′π = Cπ + (1−K)Cμ
共射、发射极交流接地时：K ≈ −gmR′L
C′π ≈ Cπ + (1+gmR′L)Cμ

若 Cπ=30 pF、Cμ=3 pF、K=−100，则输入总电容为 30+101×3=333 pF。3 pF 小，但它对应的输入负担已经是 303 pF。这正是高增益共射电路高频容易下降的原因之一。

输出侧的等效电容是 C″μ=(1−1/K)Cμ。当 K=−100 时，它仅为 1.01Cμ。教材常在输出侧时间常数明显较小时忽略它，把问题约化成一个输入端低通。输入电容大，不是忽略输出电容的充分理由；还要比较各自与等效电阻相乘得到的时间常数。

三个易错点：K 取电容两端之间的电压增益，通常不是从信号源 us 到输出的总增益；反相时 1−K=1+|K|；用中频 K 做密勒单向化是这里的近似方法，极高频、多极点或强反馈情况下不保证仍精确。

4.2.1 · 密勒效应做题时最容易漏掉的前提

先确定跨接电容两端的增益，再乘密勒系数

把输入端电压记为 U1，输出端为 U2，并规定 K=U2/U1。电容 C 跨接这两个点时，从输入端流出的电流取决于 U1−U2，所以输入等效值是 (1−K)C。

自编练习：Cμ=3 pF，内部两端增益 K=−50，信号源到输出的总增益却只有 −10。该乘哪一个？乘 K=−50，所以输入侧折合 C′μ=(1+50)×3=153 pF。用 −10 得到 33 pF，会把前面的输入分压错误地算进电容两端的关系。若还有 Cπ=30 pF，总输入电容为 183 pF。

为什么输出侧常能忽略？同一例子 C″μ=(1−1/K)Cμ=3.06 pF。若输入等效电阻为 2 kΩ、输出等效电阻为 1 kΩ，则 τin=366 ns、τout=3.06 ns，输出端的变化快得多，输入端主导高频下降。如果输出电阻改成 1 MΩ，输出时间常数反而变成 3.06 μs，就不能继续因为“电容小”而丢掉它。

自编小题：K=+0.9 时，跨接 10 pF 折合到输入是多少？说明什么？

输入侧为 (1−0.9)×10=1 pF。输入、输出同向且幅度接近，两端电压差很小，取流也小。这解释了某些跟随结构为什么没有很大的输入密勒电容。但完整电路还会有其他电容和频率变化；尤其同相 K 下不能把输出侧的等效表达式机械当作一只独立正电容。本题只检验输入取流关系。

必会：减的是带符号的 K；K 的起点、终点就是电容的两个端点；C′π 还要加原来的 Cπ。会解释：能否忽略某支路，要比较时间常数和题目的工作频段。密勒变换的完整一般定理可以以后再深入。

4.2.2 fβ、fT、fα：先看谁下降，再谈截止

这三个是管子的电流传输参数；整台电压放大电路的上限频率另记 fH。概念最容易混在这里：fβ 是 β 降到低频 β0 的 0.707 时的频率，fT 是 |β|降到 1 时的频率，二者不是同一个“不能放大了”的点。

测短路电流增益时，集电极与发射极之间的交流电压为零，模型中的 K=0，输入结电容取 Cπ+Cμ，不带上普通共射电压放大时的大密勒系数。由输入电流分配可得：

β(f) = β0/[1+j(f/fβ)]
fβ = 1/[2πrb′e(Cπ+Cμ)]
|β(f)| = β0/√[1+(f/fβ)²]

令 |β(fT)|=1，得 fT=fβ√(β0²−1)。β0 足够大时，教材用 fT≈β0fβ。如果 β0=100、fβ=1 MHz，那么 fT≈100 MHz；在 1 MHz，β 仍约 70.7，不是 1。

共基电流增益 α=β/(1+β)，代入上述单极点表达式，得到：

α(f) = α0/[1+j(f/fα)]
α0=β0/(1+β0)
fα=(1+β0)fβ≈fT

所以共基电流增益的截止频率远高于共射电流增益的截止频率。这有助于理解为什么共基、共射—共基结构常用于较宽频带。具体电路的 fH 仍然还要考虑信号源电阻、负载、寄生电容等，不能直接宣布 fH=fα。

考试还常反过来给频率参数，让你求模型电容。方法很短：先由 Q 点求 rb′e，由 fT/β0 得 fβ，再算 Cπ+Cμ=1/(2πrb′efβ)，最后减掉 Cμ。如果算出 Cπ 为负，先检查 Hz、MHz、pF 是否统一，以及是否误用了 rbe。

4.2.2 · 把频率参数公式从节点方程接出来

为什么测 β 时用 Cπ+Cμ，放大电压时却用更大的密勒电容

关键是测试条件不同。晶体管短路电流增益 β 的定义，把 c—e 之间的交流电压设为零，因此 Cμ 的输出端不再反向摆动，K=0。这里的“交流短路”是小信号测试条件，不是让你在有电源的实际电路上直接短接晶体管。

于是内部输入端的两个电容并联，总电容 CΣ=Cπ+Cμ。在教材所用的简化单极点模型下：

Ib = Uπ/rb′e + jωCΣUπ
Ic ≈ gmUπ
β(f) = Ic/Ib
≈ gmrb′e / [1+jωrb′eCΣ]
= β0 / [1+j(f/fβ)]

分母又是熟悉的 1+jωRC。现在“R”是 rb′e，“C”是 CΣ，所以 fβ=1/(2πrb′eCΣ)。这就是学习 RC 低通的用处：三极管没有把计算换成另一套规则。

名称下降的是谁规定的边界
fβ共射短路电流增益 |β|降到 β0/√2
fT同一个 |β|降到 1；是单位电流增益频率
fα共基短路电流增益 |α|降到 α0/√2
整机 fH电压放大倍数 |Au|降到中频参考值的 1/√2；由实际外接网络共同决定

β0=100、fβ=1 MHz 时，在 1 MHz 仍有 |β|≈70.7；在 10 MHz 约 9.95；到约 100 MHz 才到 1。因而 fβ 既不是“电流增益变为零”的频率，也不是每个用这只管子的放大器的上限频率。

fT≈β0fβ 的乘积关系用于本章单极点近似和给定工作点。实际器件的参数随偏置、测试条件改变；题目更换 Q 点而没有说明 fT 是否保持不变时，不要把手册里的一个数字当成全范围恒定的物理定律。

4.2 综合自编练习 · 向 4.4 搭桥

从静态电流一路算到电容：每个参数都要有来处

给定 ICQ=1 mA、β0=100、rbb′=100 Ω、fT=100 MHz、Cμ=4 pF，取 UT=26 mV。交流输出负载 R′L=2 kΩ。为了先练清模型，本题把到内部节点 b′ 的信号源戴维南电阻直接给为 R′s=1 kΩ，已包含 rbb′ 等折合影响。

① 先用 Q 点求电阻和跨导

gm = ICQ/UT ≈ 38.46 mS
rb′e = β0/gm = 2.6 kΩ
rbe = rbb′ + rb′e = 2.7 kΩ

gm 的单位是 A/V，也就是西门子 S。做题写出单位，就不容易把 38.46 mS 当成一个无量纲放大倍数。

② 由 fT 求短路测试下的电容和

fβ ≈ fT/β0 = 1 MHz
Cπ + Cμ = 1/(2πrb′efβ) ≈ 61.21 pF
Cπ ≈ 61.21 − 4 = 57.21 pF

此时还没有乘密勒系数。这一步来自 K=0 的短路电流测试。先把器件本身的 Cπ 求出来，再把管子装进实际电压放大电路。

③ 用实际负载求 K，再求输入等效电容

K ≈ −gmR′L ≈ −76.92
C′π = Cπ+(1−K)Cμ
≈ 57.21 + 77.92×4 = 368.91 pF

现在同一只管子的输入负担已远大于 61.21 pF。不要把“求器件参数时的电容和”直接搬来当“这个电压放大电路的输入电容”。

④ 预习下一节：求 C′π 看到的电阻

把独立电压源置零，相当于短路它。电容 C′π 的上端 b′ 可以分别通过 R′s 和 rb′e 到交流地，所以这两只电阻并联。这里的 R′s 已经包含前面给定的折合影响，不要再加一次 rbb′。

Req = R′s ∥ rb′e = 1 kΩ ∥ 2.6 kΩ ≈ 722.22 Ω
τin = ReqC′π ≈ 266.43 ns
fH ≈ 1/(2πτin) ≈ 597.36 kHz

这次整机上限约 0.597 MHz，器件 fβ 约 1 MHz，fT 约 100 MHz，三个数各有定义。这里用固定中频 K 作密勒近似，且假定输入极点主导；输出端 C″μ≈4.052 pF，与 2 kΩ 对应约 19.64 MHz，明显高于输入极点，因此忽略输出极点在这个例子里有依据。

再追一步：图中信号源到输出的中频增益，是 −76.92 吗？

不是。先经 R′s 与 rb′e 分压，Uπ/U′s=2.6/(1+2.6)=0.7222；再乘内部增益 K，得到 Aum≈−55.56。因此本题的单极点近似是 Au(f)≈−55.56/[1+j(f/597.36 kHz)]。用于密勒系数的 K 仍为 −76.92，不改成 −55.56。

模型简化与 Q 点变化，怎样回答才算说到原因

思考 4.2.1：为什么引入 gm，又常只保留输入侧等效电容？

高频时输入电流分到电阻和电容支路，β 随频率变化。用内部发射结电压 Ub′e 控制 gmUb′e，能在本章模型范围内把“管子的受控关系”与“外围电容分流”分开。输入侧还受到密勒放大，等效电容通常较大；在输出侧时间常数远小于输入侧、输出侧容抗远大于相关负载时，可以略去输出侧电容，得到一个主导低通环节。

回答不能只说“输出电容小”。若输出电阻很大、额外负载电容很大，或题目要求较高频率的精确结果，仍要把输出环节算进去。gm 也不是脱离模型有效范围之后永远不随频率变化的绝对常量。

思考 4.2.2：Q 点沿直流负载线上移，输入发射结等效电容 C′π 怎样变化？

按常见共射电路和教材近似，“上移”表示 ICQ 增大、UCEQ 降低。固定外接交流负载且仍在放大区时，gm=ICQ/UT 增大，|K|≈gmR′L 增大，密勒项 (1+|K|)Cμ 随之增大；发射结扩散电容通常也随电流增加。因此本题应答 C′π 增大。

如果按本章参数估算，把 fT 在附近工作点看成近似不变，则 Cπ+Cμ≈gm/(2πfT)，同样能看出随电流增加的趋势。实际 Cμ、fT 等也会随偏置改变，所以这不是所有器件、所有电流范围都无条件成立的定理，更不能把 Q 点一直推入饱和后继续套用。

还不能顺口得出：“C′π 增大，所以整机 fH 必然按同一比例减小。”因为 rb′e 也随电流改变，电容看到的等效电阻可能一起变化。若题目追问上限，必须重新计算 ReqC′π，不能只看其中一个因子。

4.3 场效应管高频模型：不取直流栅流，不代表不取交流电流

选学：老师暂时跳过场效应管，可以先接 4.4.1。但“高输入电阻也会有高频电流”这句话值得保留。

栅极没有明显直流导电通路，仍有栅源电容 Cgs、栅漏电容 Cgd，以及漏源电容 Cds。交流时电容电流由 i=C·du/dt 决定，变化越快，对前级取流越明显。MOS 的“栅极绝缘”与高频电容电流完全不冲突。

共源级由 gmugs 控制漏极电流。跨在栅漏间的 Cgd 也能作密勒等效：

K≈−gmR′L
C′gs=Cgs+(1−K)Cgd
C′ds=Cds+(1−1/K)Cgd

输出侧时间常数远小时忽略 C′ds，输入就只剩一个等效电容 C′gs。计算逻辑与三极管相同，不过理想绝缘栅输入端没有 rb′e 那样的低阻分流支路。

课本思考“等效栅源电容是不是常量”，答案要分清原始器件电容和等效结果：即便把器件电容看作给定常量，C′gs 仍会随 K 改变，K 又取决于 gm、Q 点和实际负载。等效参数属于“器件装进这个电路之后”的结果。

4.4.1 同一张共射图，为什么要画三次等效电路

这里跟教材图 4.4.1：输入信号源经过 Rs 接基极，基极经 Rb 接电源，发射极接地，集电极经 RC 接电源，输出通过 C 接负载 RL。输入端没有隔直电容，这会影响后面的静态计算。

正在算什么输出耦合 C管内等效 C′π要留下的影响
中频短路开路电阻分压和管子的放大
低频保留阻抗 1/(jωC)开路耦合不充分引起的衰减与超前相移
高频短路保留阻抗 1/(jωC′π)输入分流引起的衰减与滞后相移

三张图不改变原电路；只在不同频段保留主要因素。直流电源在三张交流图里都接交流地，受控源保留。做题时先把这张表落实到图，再列方程，比从十个公式里猜一个可靠。

下面分别求中频放大倍数 Ausm、低频 Ausl、高频 Aush。下标 s 提醒你：本节教材研究的是 Uo/Us，包含信号源内阻造成的输入分压。若题目另问 Uo/Ui，就应去掉源端分压那一项。

4.4.1 中频：沿信号路线，把三次电压变化乘起来

中频时 C 短路，RL 接到了集电极，所以实际集电极负载 R′L=RC∥RL。C′π 开路，输入电阻 Ri=Rb∥(rbb′+rb′e)=Rb∥rbe。

从信号源到输出，依次发生三件事：Rs 与 Ri 分压得到 ui；内部 rbb′ 与 rb′e 再分压得到真正控制电压 ub′e；受控电流在集电极负载上形成反相输出。

Ui/Us = Ri/(Rs+Ri)
Ub′e/Ui = rb′e/rbe
Uo/Ub′e = −gmR′L
Ausm = [Ri/(Rs+Ri)]·[rb′e/rbe]·(−gmR′L)

利用 gmrb′e=β0，式子变成 [Ri/(Rs+Ri)]·(−β0R′L/rbe)，正好回到第二章。这一步是重要的检查：高频模型把电容拿掉后，应该给出熟悉的中频结果。

如果算出的增益比内部 K=−gmR′L 的幅值还大，先检查有没有把小于 1 的分压系数倒着写。电阻分压不会凭空增加电压。

4.4.1 低频：耦合电容看到的是两侧电阻相加

只把输出回路取出来，受控电流源与 RC 可以等效为一个空载电压源 U′o 串联 RC。于是 U′o 要经过 RC、C 和 RL 才得到负载电压。

Uo/U′o = RL/[RC+1/(jωC)+RL]
= [RL/(RC+RL)]·jω(RC+RL)C/[1+jω(RC+RL)C]

前面的电阻分压本来就包含在中频带载增益中。剩下的是一个高通因子：

fL = 1/[2π(RC+RL)C]
Ausl(f) = Ausm·j(f/fL)/[1+j(f/fL)]

为什么不是 RC∥RL？先把独立激励置零，再把 C 拿开，从它的两只端子看过去：左端经 RC 到地，右端经 RL 到地，端子之间只有一条经过两只电阻的通路，因此相加。中频算集电极负载时，C 被短路，两只电阻上端才合成同一个节点，此时才并联。看的是不同端口，不能搬同一个并联结果。

因为共射中频已经反相，以连续相位 −180°为基准，低频相位是 −180°+arctan(fL/f)。在下限附近约 −135°，向更低频走近 −90°。说“低频附加相移 +45°”，不是说该共射电路总相位为 +45°。

4.4.1 高频：从内部基极看出去，求的是哪一个电阻

高频时输出 C 已短路，主要影响集中在输入电容 C′π。把信号源 Us 置零，理想电压源短路，Rs 上端因此经它接地；Rb 的电源端本来也是交流地。

从 b′ 到 e 有两条并行通路：一条直接经过 rb′e；另一条先经过 rbb′ 到外部基极，再经过 Rs∥Rb 到地。所以：

RH = rb′e ∥ [rbb′+(Rs∥Rb)]
fH = 1/(2πRHC′π)
Aush(f) = Ausm/[1+j(f/fH)]

这一步的电阻既不是输入电阻 Ri，也不是随意选一个 rbe。决定你从哪里看的，是电容实际接在哪两个节点。题目让你求输出电阻时才从输出端看；这里从内部 b′、e 看。

若 Rb 远大于 Rs，可以将 Rs∥Rb 近似为 Rs，但 rbb′ 仍要按题目精度保留。减小 Rs 通常降低 RH，更容易给输入电容充放电，从而提高上限。这里也解释了为什么前一级加一个低输出电阻的射极跟随器，会改善后级的高频驱动。

共射总相位是 −180°−arctan(f/fH)，上限处约 −225°，高频渐近 −270°。−225°与 +135°只差一整圈，正弦稳态等价；画连续相频曲线时统一用同一分支，不要中途突然跳 360°。

例 4.4.1：从 Q 点到频率表达式，一次算完整

沿用上面的共射原图。教材给定 VCC=15 V，Rs=1 kΩ，Rb=20 kΩ，RC=RL=5 kΩ，C=5 μF；UBEQ=0.7 V，rbb′=100 Ω，β0=100，fβ=0.5 MHz，Cμ≈Cob=5 pF。

第一步：静态先算对，特别留意输入没有隔直电容

信号源的直流分量为零，因此静态时源端接地，但 Rs 还连着基极。Rb 提供的电流要分给 Rs 和基极。沿基极节点列 KCL：

IBQ = (15−0.7)/20 kΩ − 0.7/1 kΩ
= 0.715 mA−0.700 mA = 0.015 mA
ICQ = 100×0.015 mA = 1.5 mA
UCEQ = 15−1.5 mA×5 kΩ = 7.5 V

如果按固定偏置直接把 (15−0.7)/20 kΩ 当作基极电流，会大错，因为你遗漏了流向 Rs 的支路。此时那些电流箭头正是为了提醒你节点电流要相减。管压降结果表明 Q 点适合小信号放大。

rb′e = UT/IBQ ≈ 26 mV/0.015 mA = 1.733 kΩ
gm = β0/rb′e ≈ 57.7 mS
Cπ = 1/(2πrb′efβ)−Cμ ≈ 178.6 pF
R′L = 5 kΩ∥5 kΩ = 2.5 kΩ
K = −gmR′L ≈ −144.2

完整保留 1−K，C′π≈178.6+(1+144.2)×5=904.8 pF。教材把 1+|K|近似为 |K|，并取整，得到约 898 pF。两种结果差不到 1%，属于已说明的近似。做题中不要一边提前近似、一边又拿末位小数判断谁错。

rbe = 0.100+1.733 = 1.833 kΩ
Ri = 20∥1.833 ≈ 1.679 kΩ

≈ −85.5，教材取约 −85
20lg|Ausm| ≈ 38.6 dB

第四步：上下限分别找各自的电容回路

fL = 1/[2π(5 kΩ+5 kΩ)×5 μF] ≈ 3.18 Hz
RH = 1.733 kΩ ∥ [0.100 kΩ+(1 kΩ∥20 kΩ)] ≈ 0.655 kΩ
fH ≈ 1/(2π×0.655 kΩ×904.8 pF) ≈ 269 kHz

教材进一步把 Rs∥Rb 近似为 Rs，并使用 898 pF，得到约 263 kHz。遵循课本估算口径，可交出 fL≈3.2 Hz、fH≈263 kHz；保留较多参数算到约 269 kHz，也应把所用表达式写清楚。

第五步：写全表达式，再画幅频和相频图

Aus(f) ≈ −85·[j(f/3.2)]/{[1+j(f/3.2)][1+j(f/263000)]}

在这个单主导低频环节、单主导高频环节且上下限相隔很远的模型里，幅频图中间约 38.6 dB，左侧斜率 +20 dB/十倍频，右侧 −20 dB/十倍频。下限与上限处各自约下降 3 dB，相位分别约 −135°、−225°。

你真正要学会的是五步顺序：Q 点决定模型参数，参数与实际负载决定密勒电容，两个电容各自决定一个时间常数，最后组装频率表达式。单背 −85、3.2 Hz、263 kHz 对换一组参数的题没有用。

4.4.2 共源频响：换了管子，解题骨架不换

选学。本节按教材图 4.4.7 的条件：源极交流接地，输入信号经串联电阻 Rg 驱动栅极，输出经 C 接负载。这里 Rg 是输入串联电阻，不要自动当成栅极对地偏置电阻。

忽略栅极漏电和有限漏源输出电阻，中频栅极近似不取流，输入串联电阻上没有明显压降，ugs≈ui。因此：

R′L=RD∥RL
Aum=−gmR′L
C′gs=Cgs+(1+gmR′L)Cgd
fH=1/(2πRgC′gs)
fL=1/[2π(RD+RL)C]

高频时情况变了：输入电流会流入 C′gs，使 Rg 上出现交流压降。它与电容形成低通。低频输出耦合则与共射完全一样，两侧电阻相加。

举一个迁移练习：gm=2 mS、R′L=5 kΩ，Cgs=10 pF、Cgd=2 pF，Rg=10 kΩ。那么 Aum=−10，C′gs=32 pF，fH≈497 kHz。不能因输入电阻很高，就说 Rg 对高频无影响。

若另有栅极对地偏置电阻、有限信号源内阻或未旁路源极电阻，要重新从输入电容两端求等效电阻和电压增益。上述几个简式依赖本节电路，不是所有 MOS 放大器的统一答案。

4.4.3 怎样展宽频带，以及为什么增益不能白拿

改善低频响应是让 fL 降低。由 fL=1/(2πRC)，要增大相应时间常数，常见办法是增大耦合、旁路电容。改变回路电阻也能改变 fL，但电阻同时影响偏置、分压和增益，不能随意增大。需要传递直流或极慢变化信号时，直接耦合才是更根本的选择。

改善高频响应是让 fH 提高。它也写成 1/(2πRC)，这次要减小时间常数：减小器件及布线电容、减小驱动电阻、减弱密勒效应，或改变接法。你可以用一个统一公式判断方向，却要清楚低频希望下限向左，高频希望上限向右。

为什么课本突然讲“增益带宽积”？因为共射增益与 gmR′L 有关，输入密勒电容也随它增加。想提高增益，会让输入电容负担变大，从而降低上限。这解释了一类设计上的权衡，也常用于参数变化题。

在 Rb 足够大、|K|≫1 且密勒项主导等条件下：
|Ausm|fbw ≈ |Ausm|fH ≈ 1/[2π(rbb′+Rs)Cμ]

这不是任何放大器、任意改参数都成立的定律。它是在前述近似下得到的估算关系；改了信号源内阻、器件、偏置或主要极点，乘积也可能变化。做题看到“增益加倍、带宽减半”前，应先确认题目确实采用近似恒定的增益带宽积。

例如一类近似恒增益带宽积电路，原来 100 倍、上限 100 kHz，乘积为 10 MHz。若同样条件下改为 50 倍，可估上限约 200 kHz。这里用的是“倍数×Hz”，不是“40 dB×100 kHz”。

频带也不是越宽越好。信号只需要一个范围时，过宽的带宽会放过更多范围外的干扰，可能还牺牲增益。设计任务是覆盖所需信号，并满足失真、噪声和稳定性条件。这个解释服务于简答与设计判断；不要求你现在就完成低噪声放大器设计。

4.5.1 多级级联：放大倍数相乘，衰减也会相乘

第三章说总增益等于各级增益之积；现在各级增益都随频率变化，所以每一个频率都要做同样的乘法。各级参数应包含实际级间负载，不能拿几个互不连接时的空载数据拼起来。

A(f)=A1(f)A2(f)···AN(f)
20lg|A(f)|=Σ20lg|Ak(f)|
φ(f)=Σφk(f)

两级都有同样的上限 fH1。在那个频率，每级剩下自身中频幅值的 0.707，总共剩 0.707²=0.5，即总增益已下降 6 dB。整机定义的上限只允许下降 3 dB，所以整机上限必然比 fH1 更低。

同理，两级相同的高通环节，在原来单级的下限处总共也下降 6 dB。要恢复到总共只降 3 dB，必须把频率提高，因此整机下限升高。普通单调高通、低通级联的结果是：低端向右挤，高端向左挤，通频带变窄。

这解释了第三章的一个现象：集成运放内部级数多、开环增益很高，但开环通频带可以很窄。第五章会看到，负反馈在稳定性条件满足时可牺牲部分增益来换取更宽的闭环带宽。

必须会判断：两级每级在某频率下降 3 dB，总共下降 6 dB；三极点高频最终斜率为 −60 dB/十倍频。一个拐点处突然出现 −60 的斜率，可能代表三个相同或接近的极点，不能因为只看到一个拐点就断言只有一个极点。

4.5.2 总截止频率：先看能否由一个环节主导

若各级上限是 10 kHz、1 MHz、10 MHz，那么接近 10 kHz 时，后二级几乎不衰减，总上限接近 10 kHz。若各级下限是 1 Hz、2 Hz、100 Hz，则总下限接近 100 Hz。这是主导环节近似：高频抓最小的上限，低频抓最大的下限。

若多个截止频率相近，不能只取最差的一个。对于各级可视作一阶高通、低通且上下限相隔较远的情形，按整机下降 3 dB 定义，可分别列：

求总 fH：∏[1+(fH/fHk)²]=2
求总 fL：∏[1+(fLk/fL)²]=2

为什么右边是 2？总幅值比为各级平方根因子的倒数，要等于 1/√2；两边平方并取倒数，就得到 2。这样推一次，你便知道它不是随意增加的修正项。

教材用忽略高次项并加入经验修正的方式估算：

fL ≈ 1.1√(fL1²+fL2²+···)
1/fH ≈ 1.1√(1/fH1²+1/fH2²+···)

这两式适用于若干截止频率相近时的估算。单级无需加 1.1；一个环节明显主导时，也应优先用主导环节近似。注意高频公式的左边是 1/fH，不能误把上限频率直接平方相加。

如果 N 级完全相同，可以直接解定义式，不必用修正系数：

fH = fH1√(21/N−1)
fL = fL1/√(21/N−1)
相同级数单极点模型的精确比例教材估算比例
2fH≈0.644fH1；fL≈1.554fL1约 0.643 与 1.56
3fH≈0.510fH1；fL≈1.961fL1约 0.52 与 1.91

这里把两套结果并列，是为了避免你拿精确式做完后被辅导答案的小差异困住。考试要求“估算”且按教材时，使用教材系数并说明；需要精确求该模型的 −3 dB 点时，就解定义方程。

例 4.5.1：从折线反推表达式

教材图给出中频 80 dB、低频 10 Hz 处一个 +20 dB/十倍频环节、高频 200 kHz 处开始 −60 dB/十倍频，且各级均为共射。对应中频幅值 10⁴，一个低频高通因子，三个同拐点的高频低通因子；三次共射反相给出负号：

A(f)≈−10⁴·j(f/10)/{[1+j(f/10)]·[1+j(f/200000)]³}

下限约 10 Hz；教材估上限为 0.52×200 kHz≈104 kHz。按三个完全相同的一阶极点精确计算约为 102 kHz。200 kHz 是每个高频因子的拐点，不是整机 −3 dB 上限。这道题最重要的考点就是把这两者分开。

例 4.5.2：三个大电容，为什么旁路电容常常最难伺候

回到第二章分压偏置共射电路：输入耦合 C1、输出耦合 C2，发射极 RE 并联旁路 CE。按教材估算，研究其中一个低频电容时，先把其余低频大电容短路，管内结电容仍开路。电源接交流地，独立信号源置零，从研究对象的两端看电阻。

对于输入耦合 C1，左边是源内阻 Rs，右边是 RB1∥RB2∥rbe，所以两边相加。对于输出 C2，是 RC+RL。旁路 CE 的两端却是发射极与地，它所看到的包含从发射极看入管子的低电阻。

RC1 = Rs+(RB1∥RB2∥rbe)
RC2 = RC+RL
RCE = RE ∥ {[rbe+(Rs∥RB1∥RB2)]/(β+1)}

那个“除以 β+1”从哪里来？从发射极往管子送一个试探电流 ie，基极支路只流约 ie/(β+1)。rbe 与基极外接电阻上的压降相加，除以试探 ie，就得到它们的总电阻除以 β+1。这其实就是第二章射极跟随器输出电阻的方法。

假设 rbe=2 kΩ、β=100、Rs∥RB1∥RB2=1 kΩ、RE=1 kΩ，则管内这一支约 3000/101≈29.7 Ω，再与 1 kΩ 并联仅约 28.8 Ω。若 CE=10 μF，对应转折频率约 552 Hz。把它错算成 1/(2πRECE)，会得到约 15.9 Hz，差得非常大。

所以当三个电容容量相等，CE 所在回路电阻常常最小、时间常数最小、对应频率最高，成为低频瓶颈。要把它的对应频率降到 10 Hz 左右，按刚才的参数需约 CE≥1/(2π×28.8 Ω×10 Hz)≈553 μF。这解释了电路中旁路电容为什么经常明显大于耦合电容。

估算边界：发射极旁路环节严格说有极点也有零点：CE 失效后，共射仍可能保留未旁路 RE 下的较小增益，并非单靠它就使直流增益变成零。教材在旁路前后增益差较大时用其主要转折来估下限。若要求完整精确传递式，或两个增益平台相差不大，应保留 CE 与 RE 的完整阻抗列方程。

进一层：只考虑 CE 时，完整的极点和零点从哪里出现？

将基极侧化为串联等效 RB 的信号源。忽略 ro，令 D=rbe+RB，ZE=RE/(1+sRECE)。放大分母含 D+(β+1)ZE。相对充分旁路的增益，其因子为 (1+sRECE)/[1+(β+1)RE/D+sRECE]，有零点 1/(RECE) 和极点 1/{[RE∥D/(β+1)]CE}。这与前面的等效电阻结果一致。初学先会正确找电阻，精确传递式在题目要求时再展开。

4.6 扩展：频率响应怎样变成“上升得快不快”

所提供教材第 194 页列出阶跃响应的指标、频率与阶跃响应关系两个数字资源入口，没有附上正文。这里用一阶低通作基础补充，让你知道这段为什么出现；不把它当作对外部资源的逐句转述。

给一阶低通突然加一个电压阶跃，电容电压不能瞬间跃变，归一化输出为 y(t)=1−e−t/τ，其中 τ=RC=1/(2πfH)。t=τ 时到最终值约 63.2%，并不是已完全稳定。

常用上升时间 tr 取 10% 到 90% 之间的时间。将 y=0.1、0.9 分别代入，得到 t10=−τln0.9≈0.105τ、t90=−τln0.1≈2.303τ，所以：

tr≈2.197τ≈0.35/fH

上限 1 MHz 的单极点系统，上升时间约 0.35 μs。这是“频带越宽，响应越快”的定量版本。但 0.35 依赖一阶低通模型，不适用于所有多级、振铃或复杂补偿系统。

还要和第三章转换速率 SR 分开：小信号带宽来自线性频响；SR 限制大信号最大变化斜率。正弦输出幅值 Uom 时，最大斜率为 2πfUom，应不超过 SR。一个电路可能小信号带宽足够，却在大幅输出时受 SR 限制。看题干问“频响”还是“大信号速度”，决定用哪条条件。

学习优先级：掌握带宽与响应速度的联系、上升时间的定义；0.35/fH 要带上单极点条件。若老师不考这部分，无须先把多阶阶跃响应推导啃完再做前面的主线题。

4.7 仿真与实验：怎样证实你算出的两个截止频率

纸面只列出了仿真方法和静态工作点稳定电路频响研究的数字资源入口。这里给出不依赖某个软件版本菜单的操作目标：先验证 Q 点，再扫频，最后按相对中频增益下降 3 dB 找边界。

  1. 搭建电路并先测静态。检查基极、发射极、集电极电位，确认管子在放大区。偏置不正常时，后续频响与按放大区模型算出的结果没有可比性。
  2. 做小信号交流扫频，横轴选对数频率，范围覆盖预计 fL 的十分之一以下和 fH 的十倍以上。记录增益比 Uo/Us 或 Uo/Ui，与手算端口保持一致。
  3. 先找中间平坦区域的增益 Gm，再找 Gm−3 dB 的两处交点。不要在整个图上盲找纵坐标 −3 dB。
  4. 每次只改一个量：增大输出耦合电容，观察低端左移；改变信号源内阻，观察高端及中频增益；改变负载，观察增益与密勒电容造成的联合变化。
  5. 再以小幅正弦作时域验证，取通带中间、下限、上限三个频率测幅值比和时间差。相位由 Δφ=360°fΔt 换算，并判清输出超前还是滞后。

交流小信号分析中的“AC 幅度 1”是方便读传递函数的归一化设置，不表示真实电路允许 1 V 的大幅瞬时输入。时域验证必须选择不会使管子削顶或进入转换速率限制的幅度。

仿真与手算不同，先逐项检查：器件模型是否含更多寄生参数，Q 点是否相同，是否漏算负载，信号源内阻是否一致，取的是源端还是放大器输入端增益。不要看到曲线差一点就盲目改元件“凑答案”。

4.1 参数变化题：先分清有没有改变 Q 点

这是输入、输出各有耦合电容的共射级，Ri≈rbe。空载时，输出 C2 的有限负载效应可在 RL→∞ 的极限下忽略，下限主要由输入 C1 决定：

fL≈1/{2π[Rs+(Rb∥rbe)]C1}

减小偏置 Rb，在管子仍处于放大区的前提下，基极电流和静态集电极电流增加，rbe 减小；输入电容的时间常数变小，下限升高。接上有限 RL 后，C2 增加一个低频衰减环节，总下限也升高。因此第一组方向答案为①、①。

fH≈1/{2π[rb′e∥(rbb′+Rb∥Rs)]C′π}

令 Rs=0，输入电容回路电阻减小，上限提高，填①。注意输入仍有 C1 隔直，改变源内阻没有直接破坏原偏置；且 rbb′ 尚在，不能因此写上限无穷大。

再次减小 Rb，按辅导书采用的通常工作范围与主导效应：静态电流增大，gm 增大；密勒等效电容增大；高频响应变差，上限减小。该组三空按书中答案为①、①、③。

理解边界：最后一步不等于“任何偏置变动都必然降低上限”。RH 与结电容也会随 Q 点变化，严谨比较应代回完整的 RHC′π；若进入饱和，更不能沿用原模型。本题训练的是教材给定近似下的变化方向。

4.3 低频有两个斜率：意味着两个高通因子

A(f)≈−100·[jf/(1+jf)]·[j(f/10)/(1+j(f/10))]·1/[1+j(f/250000)]

若展开分子，(jf)·j(f/10)=−f²/10，再乘 −100，得到 +10f²。展开后分子为正，不表示中频同相。因为分母中的两个低频因子在中频也含 j，相位要整体计算。为了少出符号错，优先保留各环节相乘的形式。

这里的 1 Hz、10 Hz 是两个环节的转折，整机下限略高于 10 Hz，按主导近似约 10 Hz；不能说一个电路同时有两个“总下限”。

4.4 一个高频拐点，也可能叠着三个极点

曲线低频没有下降，教材据此判断为直接耦合。10 kHz 之后每十倍频下降 60 dB；在本章“每个单管级主要贡献一个高频极点”的模型下，对应三级放大，三个上限转折都在 10 kHz 附近。

在 10 kHz，每个低通附加相移 −45°，总计 −135°。在 100 kHz，每个环节已到其转折的十倍频；按折线近似，每个 −90°，总计约 −270°。若代入精确反正切，则是 −3arctan10≈−252.9°。书中 −270°是近似画图口径，不是反正切算错。

fH≈0.52×10 kHz≈5.2 kHz（教材估算）
相同三极点模型精确值：10 kHz×√(21/3−1)≈5.10 kHz

仅凭幅频斜率能判断极点数量的特征，不能在任意复杂电路中唯一数出三只晶体管。题目答案“三级”依赖本章所采用的电路模型。中频正负号也不能单靠这张幅频图决定。

4.5 分子 −10jf，为什么中频增益是 −100

题给 A(f)=−10jf/{[1+j(f/10)][1+j(f/10⁵)]}。要读出中频增益，先把高通分子整理成 j(f/fL)，而不是只盯着 −10：

−10jf = −100·j(f/10)
A(f)=−100·[j(f/10)/(1+j(f/10))]·1/[1+j(f/10⁵)]

于是 Aum=−100，中频 40 dB，下限约 10 Hz，上限约 100 kHz。也可在 10≪f≪10⁵ 时直接近似：第一个分母为 jf/10，第二个约 1，分子除以后得到 −100。

幅频折线依次 +20、0、−20 dB/十倍频；相位从接近 −90°，经过中频 −180°，走向 −270°。在两个截止处分别约 −135°与 −225°。画图先把平台、两个拐点和这几个相位点标出来，再连线。

4.6 两级共射：两个负号相乘，中频变成正号

题给分子 200jf，分母含 10 Hz、10 kHz、100 kHz 三个一阶因子。先改写 200jf=2000·j(f/10)，得：

A(f)=2000·[j(f/10)/(1+j(f/10))]·1/{[1+j(f/10⁴)][1+j(f/10⁵)]}

中频增益为 +2000，约 66.0 dB。下限约 10 Hz；高频两个转折相差十倍，上限由较低的 10 kHz 主导，约 10 kHz。按两极点定义精确解则约 9.90 kHz，不需要套两个相同极点的 0.644 系数。

相位以中频 0°为基准：φ=arctan(10/f)−arctan(f/10⁴)−arctan(f/10⁵)。低频向 +90°走，高频向 −180°走。若使用两级共射连续累加得到中频 −360°，整条曲线比这里低 360°，正弦物理意义相同；答题统一一套即可。

4.7 四种共射电路比较：把“电容多”换成具体的 RC

各电路静态发射极电流与相关器件参数按题设相同。四图的关键区别见下方：a 有发射极旁路电容；b 是普通双耦合共射；c 输入直接耦合但多串 7 kΩ；d 只有输入耦合，集电极 2.5 kΩ且空载。

按教材正常参数下的估算，答案为：低频最差 a；低频最好 c；高频最差 c。别把这个排列当作新口诀，要看它由什么比较得来。

a 的 CE 回路电阻含 (rbe+基极外接电阻)/(β+1)，通常远小于两个耦合电容的回路电阻。同容量下，它的时间常数最小、对应频率最高，故低频最差。

c 没有输入隔直电容，只剩输出 C，其回路电阻为 5 kΩ+5 kΩ=10 kΩ；在本题普通工作点范围，它的低频转折低于其他图的输入耦合或旁路转折，故低频最好。若极端改变工作点使 rbe 很大，则应重新按实际电阻比较，不能脱离参数条件推广。

高频时，a、b 的集电极有效负载均为 5∥5=2.5 kΩ，d 为 2.5 kΩ空载，c 也为 5∥5=2.5 kΩ；题设相同工作点使内部增益及密勒电容大体可比。c 输入串联电阻多出 7 kΩ，驱动电容的回路电阻更大，所以高频最差。同一只串联电阻，未必影响直流隔离，却会直接影响高频充放电。

4.8 场效应管比较：先认清理想信号源，也辨认答案的条件

选学。本题辅导书给出的排列为（c）、（d）、（d）。其中高频结论是在忽略输出极点、主要看输入等效电容的近似下给出；低频第一空还需要额外的回路电阻比较，不能不加条件照搬。

a、b、c 图的输入标为 ui，教材把它当作内阻为零的理想电压驱动。高频时输入耦合电容视为短路，栅极被理想源直接固定。d 是直接耦合源极跟随器，理想源与栅极之间却串有 Rg。因此，在只考虑输入电容的近似中，a、b、c 不由这一输入 RC 限制上限，而 d 的 Rg 与输入等效电容形成有限转折，书中据此选 d 为高频最差。

这不表示真实 a、b、c 的带宽无限；输出电容、器件传输及寄生因素仍会限制它们。对 d 也应使用跟随器的电容关系：源极跟随减小 Cgs 两端电压变化，输入等效电容大致为 Cgd+(1−Av)Cgs，不能把反相共源级的密勒公式原样套上。

低频最好为 d 较明确：它没有隔直耦合电容，可以传递直流。而“c 的低频最差”不能仅靠图上多了几个栅极电阻就严格推出。辅导书解释为 c 的 C1 回路电阻最小；但从原图 C1 两端求得的是 Rg3+(Rg1∥Rg2)，题干没有足以保证它最小的数值关系，同时还应比较 a、c 的源极旁路回路。

a、b 的输入 C1 回路：Rg
c 的输入 C1 回路：Rg3+(Rg1∥Rg2)
a、c 的源极旁路回路：约 RS∥(1/gm)

因此这道题的正确学习方式是：记清辅导书采用的预期答案，同时知道第一空依赖“c 确有最高低频转折”的附加条件。遇到老师给出具体电阻时，列上述时间常数再比较。不能把一个缺少充分参数支持的排序，背成 MOS 的普遍规律。

4.9 时间常数相等，不是电容容量相等

使用 4.7(b)：Rs=1 kΩ，Rb=620 kΩ，rbe=1 kΩ，RC=RL=5 kΩ。输入电阻近似 1 kΩ，所以 C1 看见约 2 kΩ，C2 看见 10 kΩ。

τ1=2 kΩ·C1；τ2=10 kΩ·C2
τ1=τ2 ⇒ C1:C2=5:1
τ=25 ms ⇒ C1≈12.5 μF，C2=2.5 μF

每个环节的转折均为 1/(2πτ)≈6.37 Hz。两个环节相同，总下限不能仍写 6.37 Hz；教材估算 1.1√2×6.37≈9.90 Hz，约 10 Hz。按两个相同一阶高通精确式是约 9.89 Hz。

做题习惯：先写 R1C1=R2C2，再移项求比例。电阻越小，要凑相同时间常数，电容必须越大。

4.10 旁路电容开路：增益小了，通频带却可能变宽

仍看 4.7(a)，CE 突然断开。它原本就不通过直流，所以在其他元件不变、原偏置正常时，静态工作点基本不变。交流则不再绕过 RE，发射极电位会随输入变化，形成局部负反馈。

中频源电压增益的幅值减小：相同输入变化先被 RE 上的电压变化抵消一部分，ube 变化变小，集电极电流变化也变小。若 A 原来为负，所谓“增益减小”在这里指 |A|，不能把有符号数 −100 变 −10 当成幅度增大。

下限通常降低：原来主要限制低频的旁路环节消失，输入电阻也因未旁路 RE 而提高，输入耦合时间常数增大。上限通常提高：电压增益降低，密勒效应减弱，虽然相关等效电阻也变化，教材给定情形下总高频时间常数减小。

本题方向：|Ausm|↓，fL↓，fH↑

这不是电路“坏了反而全面变好”，而是换到了增益更小的工作特性。新的上下限按新的中频增益作为 −3 dB 参考。第五章将系统解释这种增益与带宽的交换。

4.11 共源完整算例：两个 Rs 必须先起不同名字

选学。原图同时出现信号源内阻和源极电阻，容易都读成“Rs”。本页明确记：信号源内阻 Rsig=2 kΩ，源极电阻 RS=1 kΩ；栅极偏置 RG=1 MΩ。RD=10 kΩ，RL=3.3 kΩ，三个大电容均 10 μF；gm=5 mS，Cgs=Cgd=5 pF。

R′L=10 kΩ∥3.3 kΩ≈2.481 kΩ
Ausm=[RG/(Rsig+RG)]·(−gmR′L)≈−12.4

低频逐个比较：输入 C1 看到约 1.002 MΩ，输出 C2 看到 13.3 kΩ，旁路 CS 看到 1 kΩ∥200 Ω≈166.7 Ω。因此同容量下，旁路转折远高于另外两个：

fL1≈0.0159 Hz；fL2≈1.20 Hz
fLS≈1/(2π×166.7 Ω×10 μF)≈95.5 Hz
教材主导近似：fL≈95.5 Hz

接着算高频，不要误用 1 kΩ源极电阻。驱动栅极电容的是 Rsig∥RG≈2 kΩ：

C′gs=5 pF+(1+12.4)×5 pF≈72 pF
fH≈1/[2π(2 kΩ∥1 MΩ)×72 pF]≈1.1 MHz
Aus(f)≈−12.4·[j(f/95.5)]/{[1+j(f/95.5)][1+j(f/(1.1×10⁶))]}

上式的最后一项表示 1+j[f/(1.1×10⁶)]，频率均用 Hz。它是辅导书采用的主导环节近似，省去了很低的另外两个低频转折，并把源极旁路近似为高通。若要求完整低频特性，要保留旁路环节的零点及两个耦合因子。展开分子时 −12.4/95.5≈−0.130，所以分子应为−0.130jf；负号不能在化简时丢掉。

4.12 栅极串联 2 MΩ：小电容也能让上限很低

选学。采用正文 4.4.2 的共源模型：串联 Rg=2 MΩ，RD=RL=10 kΩ，输出 C=10 μF；gm=10 mS，Cgs=Cgd=4 pF。

R′L=5 kΩ，Aum=−0.01×5000=−50
20lg50≈34.0 dB
C′gs=4+(1+50)×4=208 pF
fL=1/(2π×20 kΩ×10 μF)≈0.796 Hz
fH=1/(2π×2 MΩ×208 pF)≈383 Hz

这是很有价值的一题：208 pF 看起来很小，但乘上 2 MΩ，时间常数已经达到 416 μs，上限就降到几百 Hz。只看电容量大小判断高频性能，忽略驱动电阻，会得到相反的直觉。

波特图平台约 34 dB，拐点 0.796 Hz 与 383 Hz；中频反相，相频曲线依次由约 −90°走向 −180°，再走向 −270°。

4.13 两级相乘：低频抓主导，高频用相同极点公式

题给第一级分子 −25jf、低频转折 4 Hz；第二级分子 −2jf、低频转折 50 Hz；两级高频转折均为 100 kHz。先分别改写：

A1=−100·[j(f/4)/(1+j(f/4))]·1/[1+j(f/10⁵)]
A2=−100·[j(f/50)/(1+j(f/50))]·1/[1+j(f/10⁵)]
A=A1A2
=10⁴·[j(f/4)]·[j(f/50)]/{[1+j(f/4)][1+j(f/50)][1+j(f/10⁵)]²}

中频为 +10⁴，80 dB。展开时分子是 −50f²，与上面的环节形式等价。低频 50 Hz 明显高于 4 Hz，故总下限约 50 Hz；按两高通定义式求得约 50.3 Hz。高频两级完全相同，所以总上限约 64.4 kHz，教材取 64.3 kHz。

画幅频折线时，4 Hz 以下斜率 +40，4—50 Hz 为 +20，之后平台；100 kHz 后斜率 −40 dB/十倍频。注意图上最后的高频折线拐点仍是 100 kHz，整机 −3 dB 点在它左边的约 64.4 kHz。相位以中频 0°为参考，从低频接近 +180°走到高频接近 −180°。

4.14 两级电路读图：前级的输出电阻变成后级的源内阻

原图是两级共射，T1 经 C2 驱动 T2。C1、C2、CE 都是 10 μF；第一级 R1=600 kΩ、R2=3 kΩ，第二级偏置电阻 R3=15 kΩ、R4=5 kΩ，集电极 R5=5 kΩ，发射极 R6=2.3 kΩ，外部 Rs=1 kΩ。

低频按电容回路比较。CE 仍然看见第二级发射极的较低等效电阻，含除以 β+1 的支路；同容量时它的时间常数最小，教材据此判断它主导总下限。

高频题设还特意说明两管静态发射极电流相等、rbb′ 与已经等效后的 C′π相等，因此可以集中比较驱动电容的电阻。第一级源侧是外部 Rs；第二级的源侧则是前级输出电阻，近似 R2。

第一级外部基极回路：Rs∥R1=1 kΩ∥600 kΩ≈0.998 kΩ
第二级外部基极回路：R2∥R3∥R4
=3 kΩ∥15 kΩ∥5 kΩ≈1.667 kΩ

两者还要各自加 rbb′，再与 rb′e 并联；共同参数相同，第二级仍较大。相同 C′π 配上更大回路电阻，第二级时间常数较大，第二级上限较低。

这题把第三章级间关系与第四章频响接起来了：前级输出端不仅给后级一个电压，它的输出电阻还决定了后级输入电容能多快充放电。
