66 全书整理完以后，下一步怎样学

这本书复变函数篇七章、数学物理方程篇五章的正文材料至此均已整理成讲义。学习可以分三次往回走：

  1. 方法骨架： 复积分与留数 → 傅里叶/拉普拉斯变换 → 方程、初值、边界分类。每一章先做最基本的例题，能说出为什么选该方法。
  2. 方程主线： 建模与定解条件 → 分离变量及正交投影 → 特殊函数 → 积分变换 → 本章基本解。重点检查边界如何筛选特征函数，以及初值如何决定系数。
  3. 混合练习： 把题目抄到另一页，遮住章标题，先判断区域、边界、时间阶数、源和初值，再求解。若离开章标题就选不出方法，优先练判断，不要继续背公式。

每次做题都固定写五行：题目数据 → 选法理由 → 核或特征基 → 系数/积分 → 验证。 做错后定位具体失败的那一行，回看对应单元，再用一题同类小题确认已经改正。

本讲义附的36道检查题都有解析，但应先遮住答案独立写。原书本章12个大题也给了路线、推导要点和结果；这不能代替你亲自完成一次计算。真正能让脑子清楚的，是把每个符号对应到“它在题目里负责什么”。
