# 论文讲解全文整理

本技能位于项目根目录的 `.agents/skills/paper-lecture-export/`。执行前读取 [讲解全文整理提示词](../../../论文讲解全文整理提示词.md)和 [项目入口的整理约定](../../../README.md#讲解全文整理)。完整版提示词规定收录范围、图表、勘误、文件结构与核对要求。

## 确定范围与收集来源

从当前论文、阅读记录及用户指定范围识别目标，明确时直接执行。维护本技能、提示词或项目文件的请求不是论文导出请求。

先检查该论文阅读记录中的完整讲解文件清单，再核对论文目录中的既有讲解、相关聊天内容及必要的可访问历史。包含略读、逐段精读、补充推导、实质性短答疑和纠错，不能只取最近回复或按字符长度筛选。

建立逐项来源清单，记录顺序、文件或可核实的聊天定位、讨论范围、对应输出章节和收录状态。不自动汇入无关聊天、其他论文或私人内容。历史讲解仍有缺口时，交付已获取内容并明确列出缺口，不将重新编写的解释冒充历史全文。

同一回复的存储副本可去重并登记；不同轮次对同一问题的再次解释应保留。文件内容发生矛盾时核对来源、保存时间与勘误关联，不凭名称相似就覆盖或删除。

## 全文汇编与输出

按照实际讲解顺序完整汇编，保留原有推导深度、例子、图表分析、问答背景、来源及观点类别。增加按论文章节或主题跳转的导航；辅助索引不替代讲解正文。保留纠错过程，并在已知错误处链接正确解释。

默认在论文所在目录生成 `<论文标识>_讲解全文.md` 和 `<论文标识>_讲解全文.html`，资源放在旁边的 `<论文标识>_讲解资源/`。先形成完整 Markdown 主文，再从同一主文生成 HTML，避免两份内容分别改写。

HTML 应具备目录锚点、适合长文阅读与打印的排版。使用可用的本地 Markdown、公式渲染及文件工具完成转换；按实际需要选用环境与模板，不直接运行其他项目中写死教材路径的历史生成脚本。核对公式渲染、原图编号、补充示意图标签、交互状态和可携带的资源路径。

已有整理文件时先核对其来源与手工批注，再增量汇入新讲解，保存旧版本或明确的新版本。不要为了凑成全文自动补讲尚未阅读的原文。

## 完整性核对

- 每一项已获取讲解均有对应输出位置，包含短答疑、公式步骤、表格、例子、图注与引用。
- 对照来源正文检查可比文本及结构；公式和图表单独核对。来源哈希、段落 ID、字数或文件数量只能辅助定位，不能单独证明完整。
- 记录去重、交互措辞调整与勘误；不得静默删减重复解释或改变论断的证据强度。
- Markdown 与 HTML 的实质内容一致，目录、引用与本地资源可用；存在缺失图表或历史内容时在文件和交付说明中明确列出。
- 以实际来源范围描述完成情况。“已讲解内容全部收录”不代表论文全文已经读完，导出不推进阅读进度。

在该论文的阅读记录中补充整理文件链接与覆盖范围，保留原有精读停止位置。最后返回可点击的 Markdown、HTML 链接，简述收录范围与仍有缺口，不在聊天中再次压缩复述全部讲解。
