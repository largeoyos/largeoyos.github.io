# 论文阅读

本技能位于项目根目录的 `.agents/skills/paper-reading/`。相对本文件读取 [项目入口](../../../README.md)，按实际请求只加载对应模式的完整版规则。

## 识别论文与模式

- 从用户指定材料、当前聊天及该论文的阅读记录核对论文身份和版本。论文明确时直接继续；确有多篇且无法判断指代时才询问。
- “略读”“介绍”“快速分析”及没有指定模式的新阅读请求，读取 [略读规则](../../../科研论文高效略读规则.md)。使用其固定输出结构，讲透动机、核心 Idea、流程、创新、实验证据与研究价值。
- “精读”“带我读”“继续读论文”，读取 [精读规则](../../../科研论文深度精读规则.md)。默认每轮约 2～5 个自然段，原文、翻译与讲解分离；关键推导、图表和算法充分展开。
- “继续略读”接续略读；明确指定章节时在指定范围内精读。恢复全文精读时使用连续精读进度，不能将略读覆盖算作精读完成。
- 只要求汇编已有讲解时，转用相邻的 `paper-lecture-export/SKILL.md`，不要重新讲一遍论文。

## 依据原文讲解

先读取对应论文的阅读记录、最近讲解与相关原文，确认本轮起点。按需使用可用的 PDF 阅读能力核对页面、自然段、公式及原图，不把提取文本的排版换行当成新段落。材料无法确认时明确指出。

严格执行所选规则，不以概括替代其要求的深入讲解。模式切换时保留已建立的背景、术语、研究问题和待验证问题，避免重新介绍无关内容。补充推导、自行构造的例子和未验证的改进设想要标明；重要数据保留指标、对照、条件及原文定位。

## 每轮保存完整讲解

在最终回复前准备好本轮完整讲解，并将同一份讲解正文保存到论文所在目录。沿用既有命名，默认采用 `<论文标识>_<讲解类型><序号>_<主题>.md`，讲解类型可为略读、精读或答疑。先检查已有文件，使用未占用的序号，不覆盖旧文件。

保存内容包括原文或依法允许的摘录、翻译、全部解释、公式推导、例子、图表分析、引用和本轮进度。纯操作日志不收录。回复的讲解正文与保存正文保持一致；保存后的文件链接可另附在回复末尾，避免为了加入链接而递归修改正文。

读取并维护该论文的 `<论文标识>_阅读记录.md`；没有记录时根据 [阅读记录模板](../../../论文阅读记录模板.md)创建。每轮完成以下更新：

1. 将本轮讲解文件加入“完整讲解文件清单”，记录顺序、模式或类型、范围、可核实的来源定位及保存状态。
2. 更新已讲解的概念、图表、公式、待验证问题和下一次起点；新答疑不擅自推进全文精读位置。
3. 分别记录略读、连续全文精读和局部精读的进度。已经存在的讲解文件可登记为既有材料，但不得推测它们覆盖了聊天中的全部讲解。
4. 读回保存文件并核对完整正文与资源链接，再说明已保存。保存失败时保留讲解内容并说明失败，不声称已经持久保存。

实质性论文追问同样保存为独立答疑文件。用户要求修改项目规范、查看文件或讨论技能配置时，不新增论文讲解轮次。

## 衔接下一轮

精读回复末尾标明当前停止位置与下一次阅读起点，并给出本轮讲解文件链接。小节结束按完整版规则总结。整篇完成与局部完成分别标记；未读附录或缺失补充材料不能默认为完成。
