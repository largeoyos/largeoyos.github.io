# 论文阅读项目指令

本文件所在目录是论文阅读项目根目录。以下路径均相对本文件解析；即使当前工作目录位于别处，也不要把规则、讲解或进度写入其他项目。

开始论文任务前读取 `README.md`。完整版规则是细节依据；用户当前明确指定的模式与范围优先。

## 选择工作流

- 论文讲解、略读、精读、论文答疑或续读：使用 `.agents/skills/paper-reading/SKILL.md`。
- “略读这篇论文”“介绍这篇论文”“快速分析这篇论文”：略读；未指定模式时默认略读。
- “精读这篇论文”“带我读这篇论文”“继续读论文”：精读；允许指定章节，按已有精读进度继续。
- “整理它”“整理他”“整理这篇论文”“把刚才的讲解整理成文件”：使用 `.agents/skills/paper-lecture-export/SKILL.md`，汇编已讲解全文，不压缩成摘要。
- 维护项目文档、讨论规则或修改 skill 时，不触发论文阅读或讲解导出，不改动论文阅读进度。

技能未出现在当前技能列表时，可直接读取上述项目内的 `SKILL.md` 并遵循其流程；不要声称已验证自动加载。

## 阅读与保存

1. 先核对论文版本、该论文的阅读记录和已保存讲解，保持背景、术语、问题与进度连续。
2. 略读参考 `科研论文高效略读规则.md`；精读参考 `科研论文深度精读规则.md`。精读按原文顺序，保留原文、翻译、必要讲解与关键推导；版权限制按对应规则处理。
3. 每轮论文讲解和实质性答疑都保存完整正文为该论文目录中的独立 Markdown 文件，并更新 `<论文标识>_阅读记录.md` 的讲解文件清单与下一起点。不能只保存摘要或进度。
4. 明确区分论文事实、作者主张、独立分析、合理推测与待验证问题。缺失原文或历史讲解时如实标明，不编造补齐。
5. 导出使用 `论文讲解全文整理提示词.md`，核对全部讲解来源；默认输出内容一致的 Markdown 与 HTML。整理不改变实际阅读完成范围。

不要覆盖既有讲解、手工批注或原论文。补充和纠错单独保存并建立关联。用户已明确授权的本地阅读、保存和整理直接执行。
