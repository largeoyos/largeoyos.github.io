  • 来源/：实际聊天消息和原有讲解文件的原始文本；原始链接和阶段性措辞保持不变，便于追溯。主文已经另行转换为可携带链接。原有阅读记录与导航在这里保留的是整理前快照。
  • 来源清单.json：20 项正文来源的聊天行号、消息标识、时间或文件位置、哈希；第 19、20 项为完整代码课和底层熵编码续讲，未冒充早先聊天内容。
  • 图片/：19 张原先已核对的原论文裁图；正文 7 图 3 表，补充 8 图 1 表。主文部分图片因不同轮次重复分析而重复出现。
  • 原论文/：NeurIPS 2021 正式版、补充 PDF 和用户提供的 bib。页码以该正式版为准。
  • 代码核查快照/：最初的选择性清单保留，现另有官方固定提交完整 2021 子目录的 31 文件清单，并按构建配置保留固定外部 rans64.h 及许可证。Python 推理与底层熵编码主链精读已完成；没有权重或模型复现实验输出。
  • 源码阅读/：19 份 Python、C++ 与头文件的离线源码页，代码引用可跳至具体行号；提供原始文件链接。
  • 代码机制核查/：独立机制例子、原始文件封装微型往返、独立 Python rANS 参考验证及结果。没有调用官方编译扩展或带权重模型。
  • 归档/ 及上一级文件名含“代码课补入前”的 Markdown/HTML：保留本次续讲之前的汇编和构建清单。
  • vendor/：Markdown-it 14.1.0、KaTeX 0.16.22 的本地发布文件及许可证；HTML 使用预渲染的 HTML+MathML 和本地字体，无需联网加载脚本。
  • 完整性核对.json：逐来源正文匹配、段落/列表/表格/公式/图片结构和本地链接检查。
  • 独立正文与资源核对.json：独立核对全部可比正文与 TeX、19 张原图字节、原有讲解稿未变更，以及 HTML 和字体引用均存在。
  • 排版核对/：桌面和手机宽度的截图、浏览器核对结果。截图是抽样排版检查，不替代来源完整性核对。

构建全文.cjs 从原始来源生成同一份 Markdown 和 HTML。运行需要 Node.js，无需再安装依赖或联网。检查阅读页.cjs 使用本机 Playwright/Chrome 进行阅读排版检查，运行路径与当前电脑有关。
