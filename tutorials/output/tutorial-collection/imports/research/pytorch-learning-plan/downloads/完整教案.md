## L02 张量与图像：形状就是接口

第 1 周 · 150 分钟

目标：区分 NCHW、HWC、逐元素运算和矩阵乘法

先修：完成 L01 的自检；不熟悉时先返回上一课

组会联系：卷积、注意力和潜变量图都依赖形状约定。

建议节奏：回顾 10 分钟 → 讲解与阅读 35 → 运行示例 25 → 独立练习 50 → 自检与记录 30。

张量是带 shape、dtype、device 的多维数组。RGB 图片常以 HWC 保存，PyTorch 卷积通常接收 NCHW。转换维度顺序用 permute，增加批量维用 unsqueeze。reshape 改的是元素排列的解释，不能代替通道交换。

uint8 的 0～255 像素转换成 float32 后除以 255，才得到 0～1。分类模型可能还需要特定均值方差归一化；压缩预训练模型通常要求 0～1，不能机械照搬分类预处理。

a*b 对应逐元素乘法，a@b 对应矩阵乘法。广播从最后一维向前匹配，维度相同或其中之一为 1 才兼容。每次运算先写出预期形状，可以提前发现大多数初学错误。

(H,W,3) → permute(2,0,1) → (3,H,W) → unsqueeze(0) → (1,3,H,W)

一张 16×20 RGB 图变成 [1,3,16,20]；两个样本堆叠后是 [2,3,16,20]。

## L03 自动微分与线性回归

第 1 周 · 150 分钟

目标：用梯度把 y=wx+b 拟合到已知直线

先修：完成 L02 的自检；不熟悉时先返回上一课

组会联系：压缩模型参数也通过同样的反传和更新学习。

建议节奏：回顾 10 分钟 → 讲解与阅读 35 → 运行示例 25 → 独立练习 50 → 自检与记录 30。

自动微分记录计算图，并按链式法则求参数对损失的导数。梯度描述局部变化方向，参数沿负梯度移动可能降低损失；步长过大会越过较好位置甚至发散。

训练循环依次计算预测和损失、清空旧梯度、反向传播、更新参数。PyTorch 默认累加梯度，所以每步一般需要清空；backward 只算梯度，不会替你更新权重。

用人工生成的 y=2x+1 做检查，可以把数据不确定性排除。先验证最终误差降低，再看 w、b 是否接近 2、1；不能用真实任务上一次随机下降代替这类检查。

L = mean((wx+b-y)²)；w ← w − η ∂L/∂w

x=1,w=0,b=0,y=3 时，单样本损失为 9，对 w 和 b 的梯度都是 −6。

Dataset 定义第 i 个样本是什么，DataLoader 决定如何组成批次、是否打乱以及并行读取。样本通常返回输入和目标；图像重建可让目标等于原图，分类则需要整数标签。

训练和验证使用不同随机种子生成不同样本，并检查不重叠。训练集可以 shuffle，验证集通常不需要；最后一批可能不足 batch_size，代码不要把批次大小写死。

batch 输入 [N,1,16,16]；分类目标 [N]，dtype=int64

10 个样本按 batch_size=4 分成 4、4、2，而不是三个相同长度的批次。

```python
def stripes(n=64, noise=.15, random_seed=42):
    g=torch.Generator().manual_seed(random_seed)
    labels=torch.arange(n)%2
    x=torch.zeros(n,1,16,16)
    x[labels==0,0,::2,:]=1
    x[labels==1,0,:,::2]=1
    x=(x+noise*torch.randn(x.shape,generator=g)).clamp(0,1)
    return x,labels.long()
```

## L05 神经网络与训练循环

第 2 周 · 150 分钟

目标：训练一个能学习横竖条纹的分类器

先修：完成 L04 的自检；不熟悉时先返回上一课

建议节奏：回顾 10 分钟 → 讲解与阅读 35 → 运行示例 25 → 独立练习 50 → 自检与记录 30。

nn.Module 组织可学习参数和前向计算。线性层后接非线性激活，才可能表达非线性关系；连续线性层若无非线性，本质仍是一个线性变换。

CrossEntropyLoss 接收未做 softmax 的 logits 和类别编号。它内部处理对数归一化；训练前多做一次 softmax 往往会改变损失的数值行为。预测类别可以直接取 logits.argmax。

先让模型在小数据上学会，再增加数据规模。每个 epoch 记录按样本加权的平均损失，而不是把大小不等的批次均值简单平均。记录随机种子与学习率，便于解释差异。

logits: [N,K]；loss = CrossEntropy(logits, labels)

[2.0,−1.0] 的 argmax 是 0；logits 不要求非负，也不要求和为 1。

```python
def seed(value=42):
    torch.manual_seed(value)
    np.random.seed(value)

def emit(name, value):
    path=OUT/name
    path.write_text(json.dumps(value,ensure_ascii=False,indent=2,allow_nan=False),encoding='utf-8')
    print(path)
    return path

def classifier(cnn=False):
    if cnn:
        return nn.Sequential(nn.Conv2d(1,4,3,padding=1),nn.ReLU(),nn.Flatten(),nn.Linear(4*256,2))
    return nn.Sequential(nn.Flatten(),nn.Linear(256,16),nn.ReLU(),nn.Linear(16,2))

def fit_classifier(model, epochs=6, lr=.08):
    x,y=stripes(); loader=DataLoader(TensorDataset(x,y),batch_size=16,shuffle=True)
    opt=torch.optim.SGD(model.parameters(),lr=lr)
    history=[]
    for _ in range(epochs):
        model.train(); total=0.
        for xb,yb in loader:
            loss=F.cross_entropy(model(xb),yb)
            assert torch.isfinite(loss)
            opt.zero_grad(); loss.backward(); opt.step()
            total+=float(loss.detach())*len(xb)
        history.append(total/len(x))
    return history
```

## L06 验证、保存与重新加载

第 2 周 · 150 分钟

model.eval() 改变 Dropout、BatchNorm 等层的行为，no_grad() 则关闭梯度记录。它们解决不同问题；评测通常两个都需要。验证过程不能调用 optimizer.step。

保存 state_dict、模型配置和实验配置。加载时先构建相同架构，再加载参数。训练设备和读取设备可能不同，用 map_location 显式控制；不要加载不可信的任意 pickle 文件。

验证保存是否成功的可靠方法是建立新模型，重载权重，在同一输入上比较输出。文件存在并不等于内容正确。准确率用正确数量除以样本总数，避免批次大小造成偏差。

accuracy = 正确预测数量 / 总样本数量

两批分别正确 4/4 和 0/1，总准确率 80%，不是两批准确率均值 50%。

## L07 卷积的通道、填充与步幅

第 3 周 · 150 分钟

建议节奏：回顾 10 分钟 → 讲解与阅读 35 → 运行示例 25 → 独立练习 50 → 自检与记录 30。

卷积核在空间上共享参数，利用局部邻域提取特征。输入通道和输出通道有不同角色：每个输出通道通常整合所有输入通道，而不是只看一个颜色。

步幅控制采样间距，padding 控制边缘处理。输出尺寸依赖核大小、步幅、填充与 dilation；先用整数公式计算，再与运行结果对照。下采样损失空间细节，网络需要在通道表示中保留有用信息。

参数量和运算量不是一回事。同样的卷积参数放在更大的图上，参数量不变，计算量却增加。组会上比较低复杂度模型时要同时交代输入尺寸。

Hout = floor((H+2p−d(k−1)−1)/s+1)；参数量 = Cout(Cin k²+1)

H=32,k=3,p=1,s=2,d=1 得到 Hout=16；3→8 通道卷积有 224 个参数。

## L09 JPEG、MSE、PSNR 与 bpp

第 3 周 · 150 分钟

目标：亲手测量图像文件大小和重建误差

先修：完成 L08 的自检；不熟悉时先返回上一课

组会联系：RD 曲线是压缩组会最常见的共同语言。

建议节奏：回顾 10 分钟 → 讲解与阅读 35 → 运行示例 25 → 独立练习 50 → 自检与记录 30。

JPEG 是有损编码。质量参数调节编码行为，不是“保存百分之多少信息”。同一质量参数处理不同图片，得到的字节数不同，因此比较应该看实际码率和失真。

MSE 对所有像素通道的平方误差取均值。PSNR 从 MSE 和像素峰值计算，峰值取 1 还是 255 必须与输入范围一致。MSE=0 时 PSNR 为正无穷，不应除零崩溃。

bpp 用总比特除以原图宽高，不再除以颜色通道数。本课 JPEG 测量包含文件头的完整字节数；重建图保存成 PNG 的大小不能代表原编码器的码率。

bpp=8×bytes/(H×W)；PSNR=10 log10(MAX²/MSE)

100×100 图像压缩文件 5000 字节，bpp=4；0～1 图像 MSE=0.01，PSNR=20 dB。

分类网络输出类别，重建网络输出与输入同尺寸的图像。编码器把 x 映射到 y，解码器由 y 生成 x_hat。中间表示较小可以形成瓶颈，但把浮点 y 存下来并不自动构成有效压缩。

先追踪每层形状，不急着训练。用上采样加卷积构造简单解码器，保证输出尺寸与目标相同。奇数尺寸要明确 padding 和最终裁剪规则。

y=g_a(x)；x_hat=g_s(y)

3×32×32 是 3072 个值，8×8×8 是 512 个值；元素压缩比不等于文件压缩比。

```python
    return (rgb+.02*torch.randn(rgb.shape,generator=g)).clamp(0,1).unsqueeze(0)

class Autoencoder(nn.Module):
    def __init__(self, channels=8):
        super().__init__()
        self.encoder=nn.Sequential(nn.Conv2d(3,8,3,2,1),nn.ReLU(),nn.Conv2d(8,channels,3,2,1))
        self.decoder=nn.Sequential(nn.Conv2d(channels,8,3,padding=1),nn.ReLU(),nn.Conv2d(8,3,3,padding=1),nn.Sigmoid())
    def forward(self,x):
        y=self.encoder(x)
        return self.decoder(F.interpolate(y,size=x.shape[-2:],mode='bilinear',align_corners=False))
```

实际编码使用模型 q，而数据来自分布 p。平均理想码长为交叉熵，等于熵加上 KL 散度。模型越偏离真实分布，编码成本通常越高；更复杂模型也可能带来时间和侧信息成本。

本课比较两套概率表，不实现完整算术编码器。实验应注明是理想码长估计；真实码流还有有限精度、终止状态和头部开销。

H(p)=−Σp log₂p；H(p,q)=H(p)+KL(p||q)

payload bits = 8 Σlen(stream)；file bits = 8×容器文件字节数

一张 65×70 图补齐为 128×128，解码后裁回 65×70；bpp 分母用原图 65×70。

```python
def real_encode(img,name,quality,path,model=None):
    model=model or load_codec(name,quality)
    x=pil_tensor(img); h,w=x.shape[-2:]; padded=F.pad(x,(0,(-w)%64,0,(-h)%64))
    with torch.inference_mode():
        start=time.perf_counter(); enc=model.compress(padded); encoding=time.perf_counter()-start
        forward=model(padded)
        estimated=sum(float(-torch.log2(p.clamp_min(1e-12)).sum()) for p in forward['likelihoods'].values())/(h*w)
    pack_stream(path,dict(model=name,quality=quality,height=h,width=w,shape=list(enc['shape'])),enc['strings'])
    meta,streams=unpack_stream(path)
    with torch.inference_mode():
        start=time.perf_counter(); decoded=model.decompress(streams,meta['shape'])['x_hat'][...,:h,:w].clamp(0,1); decoding=time.perf_counter()-start
        reference=model.decompress(enc['strings'],enc['shape'])['x_hat'][...,:h,:w].clamp(0,1)
    assert decoded.shape==x.shape and torch.equal(decoded,reference)
    to_image(decoded).save(Path(path).with_suffix('.reconstruction.png'))
    payload=sum(len(s) for group in streams for s in group)
    side=sum(len(s) for group in streams[1:] for s in group)
    return dict(image='',model=name,quality=quality,width=w,height=h,file_bytes=Path(path).stat().st_size,
      payload_bytes=payload,file_bpp=bpp(Path(path).stat().st_size,h,w),payload_bpp=bpp(payload,h,w),
```

## L21 准确测量码率与编码开销

第 7 周 · 150 分钟

模型 likelihood 得到的是估计长度；熵编码后的字节串给出 payload 长度；加头部后的文件给出实际容器长度。三者应分列，不能混成一个 bpp 字段。

超先验模型有多个 stream 分支，应全部计入。原图被 padding 后仍以原始 H×W 为分母，但 padding 也可能增加编码成本，因此所有方法需说明其策略。

estimated_bpp=−Σlog₂p/(HW)；payload_bpp=8Bpayload/(HW)；file_bpp=8Bfile/(HW)

1000 字节码流加 100 字节头部用于 100×100 图，分别为 0.8 和 0.88 bpp。

```python
def to_image(x):
    a=x.detach().cpu().squeeze(0).clamp(0,1).permute(1,2,0).numpy()
    return Image.fromarray(np.round(a*255).astype(np.uint8))

def bpp(byte_count,h,w):
    if byte_count<0 or h<=0 or w<=0: raise ValueError('invalid byte count or dimensions')
    return 8*byte_count/(h*w)

def pack_stream(path,meta,strings):
    header=dict(meta); header['stream_lengths']=[[len(s) for s in group] for group in strings]
    blob=json.dumps(header,separators=(',',':')).encode('utf-8')
    Path(path).write_bytes(MAGIC+struct.pack('>I',len(blob))+blob+b''.join(s for group in strings for s in group))

def unpack_stream(path):
    data=Path(path).read_bytes()
    if not data.startswith(MAGIC): raise ValueError('not a course bitstream')
    pos=len(MAGIC)
    if len(data)<pos+4: raise ValueError('truncated header')
    length=struct.unpack('>I',data[pos:pos+4])[0]; pos+=4
    if length>1_000_000 or pos+length>len(data): raise ValueError('invalid header length')
    meta=json.loads(data[pos:pos+length]); pos+=length; strings=[]
    for lengths in meta['stream_lengths']:
        group=[]
        for size in lengths:
            if not isinstance(size,int) or size<0 or pos+size>len(data): raise ValueError('truncated stream')
            group.append(data[pos:pos+size]); pos+=size
        strings.append(group)
    if pos!=len(data): raise ValueError('unexpected trailing bytes')
    return meta,strings

def load_codec(name,quality):
```

## L29 注意力：从矩阵乘法到特征汇总

第 10 周 · 150 分钟

建议节奏：回顾 10 分钟 → 讲解与阅读 35 → 运行示例 25 → 独立练习 50 → 自检与记录 30。

Query 与 Key 的相似性决定从哪些 Value 聚合信息。注意力并不是挑出一个最重要位置，而通常给每个可见位置一个归一化权重，再做加权和。

Q 为 Nq×d、K 为 Nk×d、V 为 Nk×dv，则分数为 Nq×Nk、输出为 Nq×dv。softmax 沿 Key 轴归一化；轴写错时形状可能仍合法，却改变语义。

缩放 1/sqrt(d) 调节分数幅度。因果 mask 把不可见位置设为负无穷，再做 softmax；窗口注意力只在局部集合内计算，不能等同全局注意力。

Attention(Q,K,V)=softmax(QKᵀ/√d + mask)V

## L31 潜变量量化与网络量化

潜变量量化决定传输符号；网络量化用整数近似权重和激活。后者通常引入 scale、zero-point、有限位宽与截断。两种量化可以同时存在，但目标和误差传播路径不同。

对称量化近似 x=sq，非对称量化还包含零点。伪量化执行量化再反量化，输出仍可能是浮点，方便模拟误差；它不证明实际卷积已使用整数指令，也不保证速度提高。

静态尺度由校准数据决定，遇到异常值可能饱和。逐通道尺度能减少部分误差，但整数算子必须处理尺度对齐。不要只把 tensor 转成 int8 就认为完成部署。

q=clip(round(x/s)+z,qmin,qmax)；x_hat=s(q−z)

s=0.1,z=0,x=0.26 得 q=3、重建 0.3；若上限 qmax=2，则饱和到 0.2。

### 相关工具实现

```python
def picture(size=32, random_seed=42):
    # Synthetic calibration image, not a natural-image benchmark.
    g=torch.Generator().manual_seed(random_seed)
    v=torch.linspace(0,1,size)
    yy,xx=torch.meshgrid(v,v,indexing='ij')
    rgb=torch.stack([xx,yy,.5+.4*torch.sin(xx*12)*torch.cos(yy*9)])
    return (rgb+.02*torch.randn(rgb.shape,generator=g)).clamp(0,1).unsqueeze(0)

def csv_write(name, rows):
    if not rows: raise ValueError('empty results')
    path=OUT/name
    with path.open('w',newline='',encoding='utf-8') as f:
        w=csv.DictWriter(f,fieldnames=list(rows[0])); w.writeheader(); w.writerows(rows)
    print(path)
    return path

def fit_autoencoder(channels=8, steps=60, random_seed=42):
    seed(random_seed); model=Autoencoder(channels); x=picture()
    opt=torch.optim.Adam(model.parameters(),lr=.01)
    initial=float(F.mse_loss(model(x),x).detach())
    old=[p.detach().clone() for p in model.parameters()]
    for _ in range(steps):
        loss=F.mse_loss(model(x),x); assert torch.isfinite(loss)
        opt.zero_grad(); loss.backward(); opt.step()
    model.eval()
    with torch.inference_mode(): out=model(x); final=float(F.mse_loss(out,x))
    assert final<initial, (initial,final)
    assert any(not torch.equal(p,q) for p,q in zip(old,model.parameters()))
    return model,dict(initial_mse=initial,final_mse=final,steps=steps,seed=random_seed,synthetic=True,train_test_overlap=True)
```
