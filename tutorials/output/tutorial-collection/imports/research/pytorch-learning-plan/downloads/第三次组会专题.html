一、具身智能：看懂指令之后，怎样输出动作

组会记录：报告围绕 Physical Intelligence 的 π 系列，讨论 VLM、Flow Matching 动作专家、任务分解、强化学习与世界模型。旧整理把版本串成单线演进，这不足以证明每个版本具体新增了什么。

问题与输入输出：VLM 接收图像和文字，常输出文字；VLA（视觉—语言—动作模型）还接收机器人自身状态，并输出动作。关节角、夹爪开合是自身状态，摄像机图像是外部观测。输入“把杯子放到架子上”后，输出不能只是“先抓杯子”，还要转成控制器能执行的数值。

教学数据流：相机图像＋指令＋关节状态 → 条件表示 → 动作块 → 控制器 → 新观测。假设每步动作 7 维，一次预测 8 步，动作块形状是 [8,7]；批量 4 个样本就是 [4,8,7]。这只是形状例子，不是 π 模型的固定配置。一步执行 0.05 秒时，8 步覆盖 0.4 秒。整块开环执行可能错过杯子被移动的变化；滚动执行前几步并重观测，能缩短反馈间隔，但要承担重新推理成本。

公开论文：π0 将视觉语言条件与连续动作的 Flow Matching 结合。阅读原文 III、IV 和附录 A-B，沿状态 token、动作 token 与动作专家追踪数据流；实验部分比较多种任务与训练条件，不能把其中某一任务成功率泛化为“任何机器人都能用”。[m03_pi0]

方法直觉：用条件 c 表示观测和指令，取噪声 z 与示教动作 a。本节选择插值 x(t)=(1−t)z+ta，目标速度为 a−z。模型学习 v(x(t),t,c)，采样时沿速度场从噪声走向动作。若 z=0.2、a=0.8，t=0.5 时 x=0.5，目标速度 0.6。这里的速度是生成空间中的变化率，不一定等于机械臂实际运动速度。不同论文的时间方向定义可能相反，先看端点再判断符号。

规划回答“先完成哪个子任务”；动作策略回答“当前怎样动”；价值函数评估未来回报；世界模型预测采取动作后的状态。四者可以组合，但不是同义词。模仿学习主要从示范学习动作，强化学习围绕回报调整策略；使用离线数据并不自动意味着机器人已能安全自主在线探索。

版本核验边界：π0.5 的书目页可确认其开放世界泛化主题；本专题不据摘要扩写完整训练细节。π*0.6／RECAP 保留为报告线索，训练细节待对应原文核验。π0.7 v1 已能定位到 IV–VI 的多样条件、IX 的实验，以及附录 A-C 的世界模型训练；其核心叙述包含子任务、子目标图像和策略元数据等条件，不能简化成“上一个模型加世界模型”。先画条件如何进入策略，再比较对应消融。[m03_pi05] [m03_pi07]

阅读与比较：先用 20 分钟画 π0 的输入输出，再用 25 分钟读其实验任务划分，最后返回 R21。比较两种动作模型时固定机器人、观测频率、动作单位、任务初态和试验次数；同时报告成功率、耗时和失败类型。更长的动作块不必然更好。

二、长视频：有限预算下，哪些证据必须留下

组会记录：六条线索为 VideoChat-Flash、ReMoRa、WFS-SB、强化学习选帧、MSJoE、FlexMem，讨论从候选帧到选择器再到记忆的全过程。

输入输出：输入视频 V 和问题 q，输出答案以及支持答案的时刻。若一帧产生 256 个 token，1000 帧就是 256000 个视觉 token；保留 16 帧是 4096 个。这里只计算视觉部分，不含文本和特殊 token，也不据此推算实际显存。帧数相同但分辨率、token 合并策略不同，计算量仍可能不同。

教学例子：视频含“拿杯子、走路、放杯子、离开”四个事件。问题是杯子最后在哪。相似度最高的 4 张图可能都是拿杯子的近景；分数高并不保证覆盖“放杯子”的证据。如果关键事件只在第 43 帧，候选生成只取 0、10、20……，后面的完美选择器也无法找回第 43 帧。应先测候选召回，再谈选择准确性。

三、生成模型：从重建输入到采样新内容

组会记录：AE→VAE→CVAE→VQ-VAE→离散先验→DALL·E 1 是一段学习汇报；随后另一段从 ELBO／层次 VAE 讲到 VDM、DDPM。箭头在这里表示阅读次序，不是所有方法严格依次替代。

问题与输入输出：AE 输入 x，经编码器得到 z，再由解码器得到重建 x̂；它只训练“把已见输入还原”。生成需要一个可采样的潜变量分布。普通 AE 不保证任取标准正态 z 都落在有效区域，但也不能断言它的潜空间在数学上必然不连续。VAE 增加概率建模，CVAE 再给生成过程加条件 c。[vae]

直觉与数值：VAE 编码器输出均值 μ 与标准差 σ，以 ε~N(0,1) 构造 z=μ+σε。μ=2、σ=0.5、ε=−1 时 z=1.5。这一步把随机性放进与参数独立的 ε，使梯度可以经过 μ、σ。程序常输出 log variance，标准差要算 exp(0.5×logvar)，直接 exp(logvar) 会用错尺度。

ELBO = E_q[log p(x|z)] − KL(q(z|x)||p(z))。第一项奖励重建数据的概率，第二项约束编码分布与先验的差异。最大化 ELBO 等价于最小化其负值；不能把重建误差与 log likelihood 的符号混用。标准正态先验下，一维 KL=0.5(μ²+σ²−1−log σ²)。μ=0、σ=1 时 KL=0；这只表示分布相同，不表示重建一定好。[vae]

CVAE 的条件 c 可以是类别或描述：编码时用 q(z|x,c)，解码时用 p(x|z,c)，先验可以设计为 p(z|c)，也可以在简化实现中固定为标准正态。比如同一个噪声 z，条件“数字3”和“数字8”应改变输出类别；要分别检查类别是否满足和样本是否多样。不能在测试时把目标图像当成已知条件，否则任务就从生成变成了重建。这个说明是条件概率的教学推广，具体网络结构应另查所选实现。

VQ-VAE 的潜变量改为码本索引。设码本为 (0,0),(1,0),(0,1),(1,1)，输入 (0.8,0.2) 到四点的平方距离分别是 0.68、0.08、1.28、0.68，选索引1。输出仍是二维向量 (1,0)，但索引只需从四个候选中指定一个。码本、索引和解码器是三种不同对象；这还不是完整的熵编码器。最近邻选择不可微，训练借助直通估计等机制；其梯度是近似，不是舍入函数的真实导数。[vqvae]

DALL·E 1 将离散图像表示和文本条件的自回归建模组合起来；其离散 VAE 不应简单当成“原版 VQ-VAE 原封不动加 Transformer”。本专题提供原论文定位，不要求训练大模型：先读 §2 的两阶段建模和图1，再看评价任务。[m03_dalle]

扩散的另一种构造：不断给真实数据加噪，训练网络在不同噪声等级恢复信息。令累计保留系数 ᾱ=0.64，x₀=0.5，ε=−1，则 x_t=√0.64×0.5+√0.36×(−1)=−0.2。噪声预测网络输入 x_t 和 t，输出 ε̂；教学损失为 (ε−ε̂)²。时间 t 告诉模型当前噪声水平，不能只输入图像。训练使用真实 x₀合成噪声样本，生成时从随机噪声出发逐步更新，这两条路径不同。[ddpm]

进阶：ELBO 如何得到，以及代码如何检查

从 log p(x)=log E_q[p(x,z)/q(z|x)] 出发，用 Jensen 不等式得到 E_q[log p(x,z)−log q(z|x)]，再拆为重建期望与 KL。这里要求 q 的支持覆盖相应积分区域。完整扩散变分目标含多个时刻的项；常用简化噪声 MSE 不是“随便删项也完全等价”。回到 DDPM §3、算法1和算法2对照训练与采样。

import math
mu, logvar, epsilon = 2.0, math.log(0.25), -1.0
z = mu + math.exp(0.5 * logvar) * epsilon
assert abs(z - 1.5) < 1e-12
alpha_bar, x0, noise = 0.64, 0.5, -1.0
xt = math.sqrt(alpha_bar)*x0 + math.sqrt(1-alpha_bar)*noise
print(round(z, 3), round(xt, 3))  # 1.5 -0.2

阅读定位：VAE §2–3 用30分钟检查下界与重参数化；VQ-VAE §3 用30分钟画码本、直通路径和损失；DDPM §2–3及算法1–2分两次读，每次30分钟。回到 R13、R14 的实验评价再判断方法。

四、可控编辑：改什么、在哪里改、改完是否符合空间关系

组会记录：一条讨论使用参考图 I₀、当前图 I_t 和文本 c，让决策器输出操作分数与空间图，再迭代编辑。另有多步任务、近大远小、指定位置、旋转、深度与遮挡关系的课题讨论。未确认发表出处的决策器按组内方案线索记录，不命名为已发表算法。

输入输出与数值例子：假设 K=8 种操作，空间网格 h=w=16，则 q 是8个分数，L 是 [8,16,16]，共2048个空间 logits，不是8个 mask 数值。sigmoid(L) 将每个位置转成0～1的软掩码。操作含停止时，停止分数应有明确使用规则，不必对“停止”的空间图赋予编辑含义。决策→局部编辑→重新观测→决策 与一次编辑不同，前一步错误会成为后一步输入。

教学几何：针孔投影 u=fX/Z+c_x。设 f=500像素、X=0.2米、Z=2米、c_x=320，则 u=370像素；保持 X 不变而 Z=1米，u=420像素。物体近移改变的不只是大小，还可能改变投影位置、遮挡与露出的背景。将二维贴片放大不能自动恢复这些关系。

公开论文：PhyEdit v1 的图2、§3.2 将物体掩码和三维变换生成的预览作为编辑条件，并联合二维与深度监督。阅读 §4 的评价设置与消融，分清外观质量与几何一致性；结果依赖深度、掩码和评价器，不能把“物理”一词理解为满足任意动力学定律。原文版本与后续项目更新可能不同，本专题固定 v1 讲机制。[m03_phyedit]

比较三种约束：文字条件表达灵活，但空间位置可能含糊；掩码明确哪里能改，但不直接编码前后关系；深度与关系先验补充几何，却可能预测错误。三种不是谁彻底取代谁，而是各自提供信息。关系 A 在 B 后面 还要约定深度方向；不要看到小于号就猜是远还是近。

实验设计：固定输入图、指令、随机种子、推理步数，比较文字条件、文字＋掩码、文字＋掩码＋几何三种配置。测目标位置误差、相对深度顺序、非编辑区域变化，并保留失败图。只有评价者知道真值时，不能把测试目标图交给模型生成条件；那会泄漏答案。

M03X01 候选帧遗漏与预算分配

任务：先预测稀疏候选是否包含关键帧，再比较补充候选后的结果；手算6个名额的比例分配。

运行：python M03X01.py

预期：missed=true，recovered=true；allocation=[1,2,2,1]，总预算6。

提示：先检查43是否在候选池；再求配额整数部分，余数按从大到小补齐，平局按索引。

解释：这个近似理想选择器直接知道事件位置，只用于演示候选上限，真实方法不可访问测试真值。最大余数法不保证每段至少一帧，也不保证事件最优覆盖。

验证：2026-09-25 Windows Python 3.12 CPU 标准库，小规模执行与断言通过

边界：无实际视频、语言模型或语义边界；分配未考虑段长度上限，应用到有限片段时必须再做容量约束。

"""Synthetic candidate omission and largest-remainder allocation; no video model."""
import json
def allocate(weights, budget):
    assert budget >= 0 and weights and all(w >= 0 for w in weights) and sum(weights)>0
    raw=[budget*w/sum(weights) for w in weights]
    counts=[int(x) for x in raw]
    order=sorted(range(len(weights)),key=lambda i:(-(raw[i]-counts[i]),i))
    for i in order[:budget-sum(counts)]: counts[i]+=1
    assert sum(counts)==budget
    return counts
def main():
    candidates=list(range(0,100,10));critical=43
    selected=sorted(candidates,key=lambda x:abs(x-critical))[:4]
    assert critical not in selected
    enriched=sorted(set(candidates+[critical]))
    improved=sorted(enriched,key=lambda x:abs(x-critical))[:4]
    assert critical in improved and len(set(improved))==4
    counts=allocate([1,3,2,2],6)
    assert counts==[1,2,2,1]
    print(json.dumps(dict(experiment='M03X01',missed=critical not in selected,recovered=critical in improved,allocation=counts,budget=sum(counts))))
if __name__=='__main__':main()

M03X02 二维向量码本量化

任务：手算最近码字索引，增加一个码字后比较固定样本平均平方距离。

运行：python M03X02.py

解释：新增码字不会使这组最近邻距离增大，但这不证明学习到更好的生成分布，也没有估算真实码流。这里的二维指向量维数，不是二维码图案。

验证：2026-09-25 Windows Python 3.12 CPU 标准库，小规模执行与断言通过

"""Two-dimensional codebook lookup, not QR codes or VQ-VAE training."""
import json
def nearest(point, book):
    distances=[sum((a-b)**2 for a,b in zip(point,word)) for word in book]
    i=min(range(len(book)),key=lambda j:distances[j])
    return i,distances[i]
def main():
    book=[(0,0),(1,0),(0,1),(1,1)]
    points=[(.8,.2),(.1,.1),(.2,.9),(.9,.8)]
    result=[nearest(p,book) for p in points]
    assert result[0][0]==1 and abs(result[0][1]-.08)<1e-12
    before=sum(d for i,d in result)/len(result)
    larger=book+[(.8,.2)]
    after=sum(nearest(p,larger)[1] for p in points)/len(points)
    assert after<=before
    print(json.dumps(dict(experiment='M03X02',indices=[i for i,d in result],mean_squared_distance=before,expanded_error=after,used_codes=len(set(i for i,d in result)),dimension=2)))
if __name__=='__main__':main()

"""Synthetic 7x5 glyph: pixel error versus a predefined middle-stroke predicate."""
import json
def mse(a,b):return sum((x-y)**2 for x,y in zip(a,b))/len(a)
def middle(g):return all(g[3*5+c]>.5 for c in range(1,4))
def main():
    glyph=[float(c==0 or c==4 or r in (0,3,6)) for r in range(7) for c in range(5)]
    missing=glyph.copy()
    for c in range(1,4):missing[3*5+c]=0
    faded=[.6 if v else .4 for v in glyph]
    assert mse(glyph,missing)<mse(glyph,faded)
    assert not middle(missing) and middle(faded)
    print(json.dumps(dict(experiment='M03X03',missing_mse=mse(glyph,missing),faded_mse=mse(glyph,faded),missing_structure=middle(missing),faded_structure=middle(faded),warning='Synthetic predicate, not OCR accuracy')))
if __name__=='__main__':main()
