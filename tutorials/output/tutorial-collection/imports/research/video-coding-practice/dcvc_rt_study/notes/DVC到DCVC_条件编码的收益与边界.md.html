从 DVC 到 DCVC 理解条件编码的收益

DCVC 2021 把条件同时引入编码变换、解码重建和熵模型。理解这条路线的关键，是辨清减去预测图后还剩下哪些相关性，以及模型是否继续利用这些信息。本文依据 DCVC 原文第 1 节、第 3.1 节与第 4.3 节，以及固定提交中的默认真实码流路径。

残差没有必然丢掉预测信息

令当前离散符号为 X，双方已知的预测为 P，残差 R=X−P。给定 P 后，X 与 R 一一对应，所以 H(X|P)=H(R|P)。再由条件熵不大于边缘熵，得到论文引言中的 H(R)≥H(X|P)。两边的差正是 I(R;P)，即残差里仍与预测相关的信息。

这个比较的右侧继续使用预测作为条件，而左侧只看残差的边缘分布。它没有证明“只要计算减法，最优码率就一定严格变差”。若残差编码器也保留同样的条件，理想离散无损熵界可以相同；若残差与预测独立，不等式直接取等号。对有损神经编码，还要考虑变换、量化、概率近似、模型容量和训练，不能把这个熵关系直接变成固定 PSNR 下的码率保证。论文原文

两个可以精确检查的小例子

令上下文标签 C 为 0 或 1，两种情况各占一半；预测 P=16C，当前符号 X=P+R。下表每一行定义一个独立的有限分布：

| 构造 | C=0 的残差 | C=1 的残差 | H(R) | H(R|P) 与 H(X|P) | 条件带来的熵差 | |---|---|---|---:|---:|---:| | 残差尺度依赖上下文 | −1 或 +1，各半 | −4 或 +4，各半 | 2 bit | 1 bit | 1 bit | | 残差分布与上下文无关 | −1 或 +1，各半 | −1 或 +1，各半 | 1 bit | 1 bit | 0 bit |

第一种情况下，预测已经准确去掉条件均值，但残差幅度仍与上下文相关。仅完成减法，没有消除这种相关性。第二种情况下，减法已经把预测与残差的统计依赖去掉，继续条件化没有理想熵收益。

这些数字是精确分布计算，不是 DVC 或 DCVC 的实测 bpp。预测被假定为双方已知；真实视频里若需要先传运动信息，应把运动和超先验等全部码率计入。计算记录

DCVC 在源码里怎样使用条件

使用位置 固定源码中的动作 作用
编码变换 当前图与 context 拼接后进入 contextualEncoder 让表示随参考信息改变，不只处理预先相减的输入
概率预测 temporalPriorEncoder(context) 与超先验参数一起进入概率融合 调整潜变量的条件分布，而不只去掉像素均值
解码重建 解码特征与同一 context 拼接后进入重建网络 把接收方已有的信息用于恢复当前图

编码端先把运动潜变量真正编码，再从已解码的运动与上一帧重建生成 context；解码端按同样顺序恢复。这个顺序保证条件来自双方可获得的信息。网络从当前原图估出的运动仍要编码发送，不能把编码端独有的信息当作免费上下文。

高维特征也不会凭空创造上一帧所没有的信息。它们提供不同的表示方式，使有限容量的网络更容易选择和利用有关的结构；“通道更多”本身不是信息论收益保证。编码与解码路径

Table 3 还报告：只保留超先验，相对完整模型增加 60.9% 码率；保留超先验和时域先验、去掉空间先验，则增加 3.8%。这是作者相应配置中的消融，并非本项目测量。其意义在于时域信息也进入概率模型，而空间自回归依赖有实际串行成本。

后续整模型比较要保持的条件

DCVC 原文使用 HEVC 序列 GOP10、其他序列 GOP12，并重新测试 DVC 与 DVCPro，使它们使用相同帧内模型。本项目 RT 的 240 帧单 I 长预测链与这个协议不同，因此不能把当前结果与原文的百分数直接拼接。长预测链可以作为共同的新测试，但应明确报告其与作者配置的区别。

固定 DCVC 的 compress 返回四条运动和内容潜变量载荷的长度之和。未来复现时仍要检查最外层文件封装的真实字节，避免把载荷 bpp 与 RT 完整文件 bpp 直接混用。

比较 DVC、DCVC、DC、FM、RT 时，应分别回答表示如何条件化、概率模型看到了什么、参考状态怎样传播、真实执行有哪些串行点。论文的整模型结果包含训练和实现差异；未经重新训练的删分支测试只能说明修改后的模型行为，不能直接充当原方法的干净消融。
