# 04 参考失效与混合编码：先判断哪里失效，再讨论门控

2026-10-19。返回[九领域导读](00_九领域深入分析.md)。本篇中的实验方案尚未执行；不把门控视为已确认的新颖方法。

## “参考不好”至少有四种含义

| 失效类型 | 例子 | 可能观察到的现象 | 不能直接得出的结论 |
|---|---|---|---|
| 对齐失败 | 快速位移、形变、遮挡 | 局部预测误差和残差变大 | 所有时间信息都无用 |
| 内容不可预测 | 场景切换、新出现的区域 | 过去与当前关联弱，当前信息需求增加 | 光流网络本身一定有错 |
| 递归状态不适配 | 长链推理超出训练分布 | 后段质量或状态统计逐渐变化 | 已证明数值溢出或某层是根因 |
| 概率失配 | 历史先验对新符号过度自信 | 码长增加，概率尾部事件多 | 重建必然失真；固定符号时熵编码应无损 |

这四类可以同时出现，但控制变量不同。把它们统称为“误差积累”，容易直接走向增加刷新频率，却不知道损失来自哪里。

## 条件编码为什么不总比残差更好

理想离散无损设置中，已知预测 C 时，`(X,C)` 与 `(X−C,C)` 可以互相转换，因此 `H(X−C|C)=H(X|C)`；同时 `H(X|C)≤H(X)`。这些结论不等于有限容量、有损条件提取、量化后的神经网络具有同样排序。

例如只编码残差却不用 C 预测残差分布时，目标是另一种概率模型；而使用压缩后的条件 φ(C) 又可能丢失有用信息。变换容量、量化误差和训练目标也都不同。条件编码的优势是给模型更多使用参考的自由，收益需要实验而非一个条件熵不等式保证。

## MaskCRT 实际混合了什么

[MaskCRT v1](../../reference/papers/MASKCRT-2023.pdf)第 3–7 页的输入为：

`u_t = (1−m)⊙x_t + m⊙(x_t−x_c) = x_t−m⊙x_c`。

m=0 时走条件编码，m=1 时走条件残差编码；中间值让网络分担当前信号与预测信号。解码时把 `m⊙x_c` 加回。原文第 4 页一处正文写作 `m⊙x_t`，与图 3 和解码端信息可得性不符；已有视觉核查采用图中的 `x_c`，保留该文字疑点。

掩码来自已解码运动和预测图像，因此无需单独传输整张掩码。但它仍有预测开销，也不是光流置信概率。第 7 页说明预测信号的幅值分布可使 m 整体偏小，所以不能把 m=0.2 解释成“20% 相信参考”。

新增核读得到一个重要边界：第 6 页测试首 96 帧、IP32、裁剪到 128 的倍数，MCL-JCV 排除屏幕内容并在场景切换处使用帧内编码。这支持其指定自然视频条件下的混合编码结果，**没有直接检验禁止切换处 I 帧时对旧场景参考的耐受性**。该边界来自原文设置，不是对作者实验的否定。

## BiECVC 与 UI²C 改变了不同环节

[BiECVC](../../reference/papers/BIECVC-2025.pdf)第 3、5–6 页结合局部运动参考与非局部注意力，利用条件编码感知门控筛选信息。它处于双向分层结构，未来参考、训练链和质量分配都与 RT 不同，不能将全部收益归为一个门控模块。

[UI²C](../../reference/papers/UIIC-CVPR2026.pdf)通过参考条件训练和统一帧内/帧间模型，提高模型在参考缺失或扰动时的能力；其两帧联合编码又改变等待与码率组织。详见[已有方法和评价笔记](../UIIC_统一帧内帧间与刷新问题.md)。仅在推理时把 RT 特征清零没有这些训练条件，不能冒充 UI²C 复现。

## 一个门控能否真正解码

| 门控依据 | 编码端可得 | 解码端可得 | 合法实现要求 |
|---|---|---|---|
| 原始当前帧与预测之差 | 是 | 通常否 | 传模式/掩码，或让已解码潜变量充分决定它 |
| 已解码运动与参考 | 是 | 是 | 两端确定性一致，仍计计算量 |
| 当前已解码部分潜变量 | 是 | 按顺序可得 | 只能作用于其后依赖的符号或重建 |
| 未来原帧 | 有前看时可得 | 未必 | 说明未来帧如何先解码及等待时间 |

利用原图挑选“最佳参考”的离线 oracle 可以诊断潜力，不能直接成为无侧信息解码策略。隐式学习到的开关也需要真实码流闭环验证。

## 当前最值得做的控制

已准备的[场景切换协议](../../experiments/research_questions_20261019/场景切换实验协议.md)使用相同 Station 目标帧和相同时间/QP 相位，分别接自然历史与 Ducks 历史，再比较 reset0/64。它观察：

`交互 = (切换历史下刷新−不刷新) − (自然历史下刷新−不刷新)`。

质量、字节分别计算，单码率不算 BD-rate。刷新仍从上一张重建图像提取特征，不是换成新场景 I 帧；因此结果只能说明这个刷新机制对历史变化的作用，不能单独隔离“帧内编码能力”。两源帧率不同，实验定义为帧索引干预，不解释为真实物理运动。

下一层诊断可把硬切换、逐步混合、遮挡和纯平移分开，以相同目标视频、多个预定切换位置和多个序列复核。训练改动之前，应先知道哪一种干预会稳定触发失败。通用参考门控已有先行研究；可研究的增量应落在明确的新约束、可验证机制或完整成本上。
