第八章 · 第01节

全章主线：让输入经过程序，变成可观察的输出

8.1.1；第3页；习题8.1

掌握要求：能画系统框图，区分核、片上外设、板上器件和软件。

背景为什么要讲：后面的寄存器最终都服务于这一条数据路径，不先认清对象容易只记函数名。

嵌入式系统面向一个具体任务：按键输入、采集传感器、计算、控制灯或电机、与其他设备通信。硬件提供供电、时序、存储和接口，软件决定什么时候做什么。不是所有嵌入式系统都需要操作系统，也不是装有Arm芯片就自动实现了功能。

原图8.1的外围按用途认识：输入有按键、开关、传感器与ADC；输出有显示、PWM、DAC、功率驱动与执行器；通信有USART、SPI、I²C、USB、CAN、以太网及电平转换；支撑有电源、时钟、复位、下载调试、外扩存储器。ADC把模拟量变数字，DAC反过来；GPIO并不能直接代替模拟转换或大功率驱动。

本章主讲STM32F103，算例默认芯片STM32F103RCT6（LQFP64、高密度，256KB Flash、48KB SRAM）。涉及C8/RB、中低密度或其他型号时另行说明。先看型号、封装、实际引脚，再谈“有几个定时器”。不要把这章的F1寄存器直接照搬到F4的MODER。

第八章 · 第03节

交叉开发：主机写程序，目标机运行程序

8.1.3 开发环境；第5—6页；习题8.3、8.5

掌握要求：解释宿主机、目标机、连接通道；区分编译器运行平台和代码目标平台。

背景为什么要讲：延续第七章，补上硬件和下载调试这一端。

宿主机提供编辑、构建、符号调试和文件管理；目标板包含MCU、存储、接口与实际被测对象；两者通过SWD/JTAG、串口、USB或网络等通道交换程序和调试信息。交叉编译器在PC运行，生成目标架构机器码；交叉调试器在PC显示目标寄存器、变量、栈和执行位置。

代码经历源文件→目标文件→链接映像→烧写/装载→执行。地址脚本规定段布局；映像入口、硬件复位向量与源码main不同。Linux应用工具链和裸机MCU工具链的运行环境不同，不能只因都有Arm前缀就混用。

区别于一般桌面应用：目标资源受限，依赖具体引脚/供电/时钟，常需烧写Flash与运行库初始化，实时行为受中断和外设影响。普通桌面链接也有布局规则，原书“只有嵌入式链接才有链接脚本”不宜绝对化。

第八章 · 第04节

工具清单按职责记，不按广告词记

8.1.3 开发工具；第6—10页；习题8.4

掌握要求：能区分PCB、PLD和软件工具；认识原书所有主要类别。

背景为什么要讲：软件版本、品牌历史只需认识；选择工具的理由是能完成当前步骤。

PCB工具做原理图、封装、网表、布局布线与电气检查；原书举Protel/Altium、OrCAD。单面、双面、多层指导电层结构，层数不是软件复杂度的直接评分。PLD/FPGA工具做HDL/原理图输入、综合、仿真、布局布线、配置与在线调试；原书举QuartusⅡ、ISE，以及VHDL/Verilog、IP、DSP Builder、SOPC等概念。

软件工具中，UltraEdit/Source Insight属于编辑与代码浏览；编译/汇编/链接分别把高级语言、汇编、多文件组合变成映像；GDB等做调试。MDK把μVision、编译/汇编、链接、库、下载与调试组合起来；IAR EWARM包含C-SPY等组件。MicroLIB、RTX、中间件和烧写算法各是不同角色。

第八章 · 第05节

五种调试方式与JTAG/SWD信号

8.1.3 调试；第10—15页；习题8.5

掌握要求：认识软件模拟器、ROM监控器、ROM仿真器、在线仿真器、片上调试的区别。

背景为什么要讲：旧设备形式会在简答题出现，实际练习主要理解片上调试。

软件模拟器在主机模拟目标指令/部分外设，便于提前验证，但不等于真实电源和时序；ROM监控器是目标驻留的调试程序，会占资源并需能先运行；ROM仿真器用可控硬件模拟ROM内容；在线仿真器是历史上较强的硬件观察/替代形式；片上调试利用芯片内部调试逻辑，经探针控制真实目标。

JTAG常见TCK时钟、TMS状态控制、TDI输入、TDO输出，nTRST复位TAP（可选）；目标系统NRST与TAP复位不能混同。VTref是目标电平参考，不随意当作探针给目标大电流供电。F103的SWD用PA13/SWDIO、PA14/SWCLK，并需要GND、参考电压，NRST有助于连接复位调试。

探针不必替代MCU；硬件断点/跟踪资源有限，某些观察与暂停会影响实时系统。原章J-Link/ULINK下载速率、接口数量是产品版本背景，不背为固定标准。烧写后要做脱离调试器的复位测试，避免程序其实依赖调试器装RAM或半主机输出。

从需求到发布：五步都要有可检查的产物

8.1.4；第15—27页；习题8.6

掌握要求：说清需求、设计、实现、测试、发布分别产出什么。

背景为什么要讲：这部分不直接算寄存器，但能回答设计题为什么要声明输入、时长、误差和边界。

需求分析形成规格：输入、输出、功能、性能、环境、功耗、尺寸、重量、成本。功能是“做什么”，非功能是“多快、多准、多省、多少成本”。硬实时强调截止期约束，软实时允许一定程度的偶发迟到，但也需要可量化目标。

第八章 · 第07节

手环实例：把需求落到引脚、总线与模块

8.1.4 手环贯穿实例；第16—24页

掌握要求：能照此方法拆解一个小系统；不要求完成计步算法产品。

背景为什么要讲：原章用同一个实例贯穿五阶段，保留它是为了看见设计过程如何相互约束。

手环的输入包括按键和三轴加速度，输出为OLED，数据处理包含计步和步数到距离/热量的转换。原书选STM32F103C8T6、ADXL345、SSD1306屏；ADXL345通过SPI/I²C取样，屏通过I²C，按键接GPIO/EXTI。ADXL345量程文字“±169”应理解并核对为±16g这一类加速度单位，不能照抄成无单位数字。

先做资源表：谁占哪个引脚、哪个外设、地址、供电与中断；同一I²C总线可共享，但器件地址、上拉、电平要兼容。再拆主模块、OLED驱动、传感器驱动、按键驱动、计步算法、单位转换。主循环处理取样/计算/显示，按键ISR只记录切屏请求。

带RTOS时按紧迫程度、周期、耦合与通信需求划任务：关键且紧迫功能及时处理，耗时计算放适当低优先级，相同触发/周期、固定顺序或紧密相关功能可合并，过细增切换成本、过粗降低响应。加RTOS不自动保证实时性。

原规格的六个月续航要由平均电流验证：210mAh/约4380h≈48µA，尚未计电池折损。MCU、传感器、屏、稳压静态电流都需进入预算；100mg整机重量与原文屏重量等明显不自洽，必须回到真实器件核对，不能当成已验证设计。

测试不只是“灯亮了”：黑盒、白盒与集成

8.1.4 系统测试/发布；第24—27页

掌握要求：会列正常、边界、错误输入与组合测试；会看波形和时间。

背景为什么要讲：工程设计题的可靠性来自验证，不来自长代码或宣传性的“稳定”。

第八章 · 第16节

五类时钟源与真正的上电默认

背景为什么要讲：所有定时与波特率计算都依赖真实时钟，不能只记一个72MHz。

ODR是输出锁存值，IDR是输入采样。开漏写1、外部另一个器件拉低时，ODR=1而IDR可为0，并不矛盾。开漏允许多设备“任何一方拉低则为低”的线与连接；推挽输出不能随意并联争驱动。上拉大小影响上升时间和低电平电流，不能无限减小或增大。

复用输出由外设提供数据，普通GPIO输出由ODR提供；外设输入仍需正确引脚模式与映射。配置复用输出但没启外设不保证产生预期波形。电平耐受与驱动电流查具体引脚，GPIO并非功率放大器。

第八章 · 第26节

CRL/CRH四位一脚，BSRR按位置位/清位

8.5.3；第79—83页；习题8.28

掌握要求：会算引脚字段和掩码；知道BSRR是写命令，不用|=回读。

背景为什么要讲：这是本章最需要独立写对的寄存器题。

CRL管0—7，CRH管8—15；每脚4位，低2位MODE，高2位CNF。MODE=00输入，01输出10MHz，10输出2MHz，11输出50MHz；输出时CNF=00普通推挽、01开漏、10复用推挽、11复用开漏。输入时CNF=00模拟、01浮空、10上/下拉，ODR相应位选上拉1/下拉0。

PC6在CRL的bit27:24；50MHz普通推挽是0011：

RCC->APB2ENR |= (1u<<4);  /* IOPCEN */
GPIOC->CRL = (GPIOC->CRL & ~(0xFu<<24)) | (0x3u<<24);
GPIOC->BSRR = 1u<<6;       /* PC6置1 */
GPIOC->BSRR = 1u<<(6+16);  /* PC6清0 */

IDR读焊盘，ODR读写输出锁存，BSRR低16位写1置对应脚，高16位写1清对应脚；写0不影响其他脚。BRR低16位写1清位。BSRR=(1u<<5)|(1u<<(4+16))一次让脚5高、脚4低，避免ODR读改写的竞争。并发复合业务仍需设计同步，不能据此说任意多步操作都原子。

LCKR按规定锁键序列锁CRL/CRH配置直到复位，不锁死所有输出数据。AFIO还有EVCR、MAPR、EXTICR1—4。原书PD15的0x08000000少移一位，应按bit31:28写0x80000000；&=~(1u<<4)不是只适用于8位的&=0xEF。

在常见reset测量定义下，CCRperiod是经过的tick数，CCRhigh为高电平tick数：f=fCNT/CCRperiod，D=CCRhigh/CCRperiod。例如1MHz下周期2000tick、高电平500tick，f=500Hz、D=25%。不把原例的(CCR+1)/(CCR+1)当通用公式；ARR+1属于计数上限周期，捕获CCR属于时间戳/间隔，它们来源不同。

第一捕获尚未有完整周期可能无效；0/100%没有所需的两种边沿，信号停止不能永远保留旧频率当新结果，需要超时判无信号。滤波延迟、计数分辨率和溢出范围都会影响精度。

抢占与子优先级：数值越小，优先级越高

发送：CPU/DMA写TDR→转入发送移位寄存器→TX逐位发送。TXE表示TDR能接下一字；TC表示发送移位过程结束且数据寄存器也空。等TXE可连续喂数据；换RS485方向、关串口/时钟前要确认TC等相应完成条件。

接收：RX→接收移位→RDR→RXNE→CPU/DMA读DR，通常清RXNE。DR是同一访问地址映射不同读/写缓冲功能，不表示收发必须共用一个物理存储字而无法全双工。未及时读下一字节导致ORE；PE/FE/NE/IDLE等用规定序列处理，典型F1为先读SR再读DR清相关错误/空闲状态。不能仅仅读SR就声称数据取走了。

寄存器组SR、DR、BRR、CR1、CR2、CR3、GTPR；CR1管UE/TE/RE、字长、校验和部分IRQ，CR2管停止/同步/LIN，CR3管CTS/RTS、DMA、错误、半双工、IrDA/智能卡，GTPR用于相关保护时间/分频。不同标志的清除方法不是一个“都ClearFlag”口诀。

题54的关键：F103没有那种多字节硬件FIFO

8.9.7；第183—185页

掌握要求：会计算页内剩余、分段写，解释随机读与写周期等待。

背景为什么要讲：这是I²C例子将总线协议连接到真实器件存储规则。

AT24C02类器件2Kbit=256B，典型8B页，共32页；A2/A1/A0选择低地址位，WP控制写保护，版本的电压/速度/页长以实物数据手册为准。PB6/PB7配置I²C1_AF_OD与上拉，USART1另外负责输出，不把芯片内部存储地址和0x50设备地址混用。

字节写：START→设备写地址→字节存储地址→数据→STOP，随后内部写周期，器件可能NACK。页写重复数据但不能越过该8B页；跨页应分块并在每块后限时ACK轮询。随机读通常先写存储地址，再Repeated START切读，最后一字节NACK+STOP。

例如从地址6写6字节，应分2+4，而不是一次跨过页边界让设备回卷覆盖。源码包给通用分页拆分函数；I2C_EE_Init、BufferRead、ByteWrite、PageWrite、WaitEepromStandbyState、BufferWrite分别承担配置/读/字节/页/等待/长写职责。原章流程为写→等内部完成→读回→比较→串口报告；仅收到总线ACK不等于数据已正确存入。

#include "stm32f10x_tim.h"
volatile uint32_t period_us,frequency_hz,overcapture;
static uint16_t previous;
static unsigned have_previous;
void TIM2_IRQHandler(void)
{
    uint32_t sr=TIM2->SR;
    if(sr&(1u<<2)) {
        uint16_t current=(uint16_t)TIM2->CCR2;
        TIM2->SR=(uint16_t)~((1u<<2)|(1u<<10));
        if(sr&(1u<<10)) { ++overcapture; have_previous=0; }
        if(have_previous) {
            uint16_t delta=(uint16_t)(current-previous);
            if(delta) { period_us=delta; frequency_hz=1000000u/delta; }
        }
        previous=current; have_previous=1;
    }
}
int main(void)
{
    GPIO_InitTypeDef g; TIM_TimeBaseInitTypeDef t; TIM_ICInitTypeDef ic;
    if(!board_clock_8mhz()) for(;;) { }

    g.GPIO_Mode=GPIO_Mode_IN_FLOATING; GPIO_Init(GPIOA,&g);
    TIM_TimeBaseStructInit(&t); t.TIM_Prescaler=7;

    ic.TIM_ICSelection=TIM_ICSelection_DirectTI;

    NVIC_ClearPendingIRQ(TIM2_IRQn); NVIC_EnableIRQ(TIM2_IRQn);

    for(;;) { } /* inspect period_us/frequency_hz; valid period <65536us */
}

#include "board.h"
volatile uint32_t ms;
int board_clock_8mhz(void)
{
    uint32_t n=1000000u;
    RCC->CR |= 1u;
    while (!(RCC->CR & 2u) && --n) { }
    if (!n) return 0;
    RCC->CFGR &= ~3u;              /* select HSI */
    n=1000000u;
    while ((RCC->CFGR & 12u) && --n) { }
    if (!n) return 0;
    RCC->CFGR &= ~((15u<<4)|(7u<<8)|(7u<<11));
    RCC->CR &= ~(1u<<24);          /* PLL no longer the system source */
    SystemCoreClock=8000000u;
    return 1;
}
void gpio_cfg(GPIO_TypeDef *p,unsigned pin,unsigned nibble)
{
    unsigned shift=(pin&7u)*4u;
    volatile uint32_t *cr=pin<8u ? &p->CRL : &p->CRH;
    *cr=(*cr & ~(15u<<shift)) | ((nibble&15u)<<shift);
}
void lights_init(void)
{
    RCC->APB2ENR |= 1u<<2;
    GPIOA->BSRR=(1u<<8)|(1u<<9);    /* off before enabling output */
    gpio_cfg(GPIOA,8,2); gpio_cfg(GPIOA,9,2); /* PP 2MHz */
}
void lights_set(unsigned red)
{
    GPIOA->BSRR = red ? ((1u<<(8+16))|(1u<<9))
                      : ((1u<<8)|(1u<<(9+16)));
}
void tick_init(void)
{
    RCC->APB1ENR |= 1u;
    TIM2->CR1=0; TIM2->DIER=0;
    TIM2->PSC=7; TIM2->ARR=999;     /* 8MHz / 8 / 1000 = 1kHz */
    TIM2->EGR=1; TIM2->SR=0; TIM2->CNT=0;
    NVIC_SetPriorityGrouping(3);   /* 4 preempt bits for this device */
    NVIC_SetPriority(TIM2_IRQn,2);
    NVIC_ClearPendingIRQ(TIM2_IRQn); NVIC_EnableIRQ(TIM2_IRQn);
    TIM2->DIER=1; TIM2->CR1=1;
}
void TIM2_IRQHandler(void)
{
    if (TIM2->SR & 1u) { TIM2->SR=(uint16_t)~1u; ++ms; }
}

#ifndef CH8_RING_H
#define CH8_RING_H
#include <stdint.h>
#define RING_N 128u
typedef struct { volatile uint8_t data[RING_N]; volatile uint16_t head,tail; } Ring;
static inline int ring_put(Ring *r,uint8_t c)
{
    uint16_t next=(uint16_t)((r->head+1u)&(RING_N-1u));
    if(next==r->tail) return 0;
    r->data[r->head]=c; r->head=next; return 1;
}
static inline int ring_get(Ring *r,uint8_t *c)
{
    if(r->head==r->tail) return 0;
    *c=r->data[r->tail]; r->tail=(uint16_t)((r->tail+1u)&(RING_N-1u)); return 1;
}
#endif

#include "uart_irq.h"
#include "ring.h"
static Ring rxq,txq;
volatile uint32_t uart_dropped,uart_errors;
void uart_init(uint32_t baud)
{
    RCC->APB2ENR |= (1u<<2)|(1u<<14);
    gpio_cfg(GPIOA,9,11); gpio_cfg(GPIOA,10,4); /* AF_PP 50MHz / floating */
    USART1->CR1=0; USART1->CR2=0; USART1->CR3=0;
    USART1->BRR=(8000000u+baud/2u)/baud; /* valid nonzero baud, 8MHz PCLK2 */
    rxq.head=rxq.tail=txq.head=txq.tail=0;
    uart_dropped=uart_errors=0;
    (void)USART1->SR; (void)USART1->DR;
    NVIC_SetPriorityGrouping(3);
    NVIC_SetPriority(USART1_IRQn,1);
    NVIC_ClearPendingIRQ(USART1_IRQn); NVIC_EnableIRQ(USART1_IRQn);
    USART1->CR1=(1u<<13)|(1u<<3)|(1u<<2)|(1u<<5); /* UE TE RE RXNEIE */
}
int uart_put(uint8_t c)
{
    uint32_t old=__get_PRIMASK(); int ok;
    __disable_irq();
    ok=ring_put(&txq,c);
    if(ok) USART1->CR1 |= 1u<<7;
    __set_PRIMASK(old);
    return ok;
}
int uart_get(uint8_t *c)
{
    uint32_t old=__get_PRIMASK(); int ok;
    __disable_irq(); ok=ring_get(&rxq,c); __set_PRIMASK(old); return ok;
}
int uart_line(const char *s)
{
    /* Atomic all-or-none enqueue; payload <= 63 bytes. No ISR caller. */
    unsigned n=0,i,free; uint32_t old;
    while(s[n] && n<=63u) ++n;
    if(n>63u) return 0;
    old=__get_PRIMASK(); __disable_irq();
    free=(txq.tail-txq.head-1u)&(RING_N-1u);
    if(free<n+1u) { __set_PRIMASK(old); return 0; }
    for(i=0;i<n;++i) (void)ring_put(&txq,(uint8_t)s[i]);
    (void)ring_put(&txq,'\n'); USART1->CR1 |= 1u<<7;
    __set_PRIMASK(old); return 1;
}
void USART1_IRQHandler(void)
{
    uint32_t sr=USART1->SR; uint8_t c;
    if(sr & ((1u<<5)|15u)) {
        c=(uint8_t)USART1->DR;  /* read after SR: service RX / clear errors */
        if(sr&15u) ++uart_errors;
        else if((sr&(1u<<5)) && !ring_put(&rxq,c)) ++uart_dropped;
    }
    if((USART1->SR&(1u<<7)) && (USART1->CR1&(1u<<7))) {
        if(ring_get(&txq,&c)) USART1->DR=c;
        else USART1->CR1 &= ~(1u<<7);
    }
}

algorithms/page_chunks.h

#ifndef CH8_PAGE_CHUNKS_H
#define CH8_PAGE_CHUNKS_H
#include <stdint.h>
#include <stddef.h>
/* Caller supplies a page transaction; it must wait with a timeout for write completion. */
typedef int (*page_writer)(uint32_t address,const uint8_t *data,size_t length);
static inline int write_pages(uint32_t address,const uint8_t *data,size_t length,
                              uint32_t capacity,uint32_t page,page_writer put)
{
    size_t count;
    if(!page || address>capacity || length>capacity-address || !put) return 0;
    if(length && !data) return 0;
    while(length) {
        count=page-(address%page); if(count>length) count=length;
        if(!put(address,data,count)) return 0;
        address+=(uint32_t)count; data+=count; length-=count;
    }
    return 1;
}
#endif
